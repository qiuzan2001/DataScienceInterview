# 2. 变量变换（Transformations）

## 速览 At a glance

**速记**

线性模型在连接函数（link function）尺度上要求「$X$ 加一，log-odds 加常数」这种直线关系。现实变量经常不配合：赔款额右偏、车辆价值与出险率是凹的、年龄与风险是 U 形、类别变量根本进不了方程。变换改的是这条关系本身——换一把尺子（对数、幂、阶梯、样条基），让「加性直线」这个假设重新近似成立。分箱是有损但可解释的版本：每箱一个水平，费率表能逐箱报；样条是有损更少的版本：分段三次多项式，箱内还留得住斜率。Box-Cox 与 Yeo-Johnson 把幂次 $\lambda$ 交给似然去挑，前者要求 $x>0$、后者能吃负值，选出来的 $\lambda$ 只是让线性更接近，不保证正态。三条必须主动说的代价：反变换有偏（对 $\log y$ 建模再直接取指数，拿到的是中位数，均值低估约 39%）；分箱边界、封顶分位点、$\lambda$ 都是从数据学到的参数，在全量数据上算就是泄漏；单调变换不改变单变量的排序，所以 AUC 一动不动，它改的是尺度上的线性与系数的含义。

**一句面试答法**

> "I look at the residual or empirical-logit shape first: if the relationship bends but stays monotone, a log or a power transform fixes it; if it turns around, no monotone transform works and I move to binning or splines; for categorical variables WOE gives me one monotone column instead of twenty dummies. The parameters — the power, the bin edges, the capping percentile — are learned on the training data only."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 变换 | transformation | 建模前作用在 $X$ 或 $Y$ 上的数学运算 |
| 分箱 | binning | 把连续变量切成区间，每箱一个水平 |
| 样条 | spline | 分段多项式，在结点（knot）处光滑拼接 |
| 幂变换 | power transformation | $x^\lambda$ 一类，含对数（$\lambda=0$） |
| 封顶 / 保底 | winsorisation / capping | 把尾部取值替换成分位点，行保留 |
| 证据权重 | weight of evidence (WOE) | 用 log-odds 把类别压成一列（[[2.3.1 WOE & IV]]） |

## 一、先看一个问题

手上有 300 张车险保单，你要预测「本年度是否出险」（出险率 35.67%）。候选变量之一是车辆价值，取值从 3.07 千元到 737.11 千元，偏度 4.60。

先按最省事的做法跑 logistic：

```
出险(0/1) ~ 车辆价值
```

系数 0.0225（每千元），标准误 0.00375，对数似然 $-160.57$，AIC = 325.1。

再换成对数尺度：

```
出险(0/1) ~ ln(车辆价值)
```

斜率 1.673，标准误 0.2175，对数似然 $-146.71$，AIC = 297.4。

**同一份数据、同一个目标、同样的 300 行，AIC 差了 27.7。** 变量一个没加、算法一行代码没改。坏掉的是「车辆价值每多 1 千元，log-odds 就多 0.0225」这句话：3 千元的车涨到 4 千元，和 700 千元的车涨到 701 千元，风险不可能同步增加。这条假设在原始尺度上站不住，在对数尺度上大致成立。

业务那边还有第二个要求：费率表要按档位报，监管要看每一档的系数。这条要求把**分箱**摆到桌面上。同一份数据上 5 个分位箱（每箱 60 单）的对数似然是 $-145.21$，比一个 $\ln x$ 的 $-146.71$ 还好一点，但它用了 4 个系数而不是 1 个，AIC 反而是 300.4；AUC 也从 0.827 掉到 0.809。

所以面试官问 "When do you need a transformation?" 的时候，他要听的是：**你怎么发现「现在这一步卡住了」，卡在哪条假设上，以及换哪一把尺子最省事。**

## 📖 标准定义

> **教材原文 ① · PSL §5.1.1 Fit a Polynomial Regression Model、§5.1.2 Choosing the Degree**（<https://liangfgithub.github.io/PSL/w5/w5_1_poly.html>）
> > "Polynomial regression is a type of regression analysis used when the relationship between the independent variable x and the dependent variable y is non-linear."
> >
> > "Polynomial regression can be seen as a specialized case of multiple linear regression."
>
> **教材原文 ② · PSL §5.2.1 Cubic Splines、§5.2.2 Linear Subspace、§5.2.3 Natural Cubic Splines**（<https://liangfgithub.github.io/PSL/w5/w5_2_spline.html>）
> > "A cubic spline is a function that’s defined piecewise by individual cubic polynomials. Specifically, for any interval divided by m knots, the cubic spline ensures smoothness by being not only continuous but also having continuous first and second derivatives at every knot."
> >
> > "A natural cubic spline is a special kind of cubic spline. While it retains the property of being a piecewise cubic polynomial function with continuity up to the second derivative, it exhibits linear behavior in the two extreme intervals."
>
> **教材原文 ③ · PSL §5.4.2 The Roughness Penalty Approach、§5.4.3 Fit a Smoothing Spline Model、§5.4.5 Choice of Lambda**（<https://liangfgithub.github.io/PSL/w5/w5_4_smoothing_spline.html>）
> > "As a solution to the arbitrariness of knot placement in regression splines, smoothing splines take a naive approach. Knots are placed at every data point, simplifying the decision-making process."
> >
> > "The best smooth function $g$ that minimizes the penalized residual sum of squares over the entire infinite-dimensional function space $S[a,b]$ happens to be a natural cubic spline (NCS) with knots at the data points x_1, …, x_n"

**标准记法**：

- $y_i = \beta_0 + \beta_1 x_i + \beta_2 x_i^2 \cdots + \beta_d x_i^d + \text{err}$，设计矩阵列向量为 $(1, x_i, x_i^2, \dots, x_i^d)$。
- 三次样条基（PSL §5.2.2 原文给出的一组）：$h_0(x) = 1$，$h_1(x) = x$，$h_2(x) = x^2$，$h_3(x) = x^3$，$h_{i+3}(x) = (x-\xi_i)_{+}^3, \ i = 1, 2, \dots, m$。
- 自由度：三次样条 $4(m+1) - 3m = m+4$；自然三次样条（两端区间线性）为 $m$。
- $\text{RSS}_\lambda(g) = \sum_{i=1}^n [y_i - g(x_i)]^2 + \lambda \int_a^b [g''(x)]^2 d x$，$g \in S[a,b]$；$\lambda$ 控制光滑程度。
- 有效自由度 $\text{df}_\lambda = \text{tr}(\mathbf{S}_\lambda)$，取值在 $2$ 与 $n$ 之间（线性项不被惩罚）。

**中文解释**：

- 多项式回归是多元线性回归的特例：把 $x, x^2, \dots, x^d$ 当作新特征，系数仍用最小二乘估。选阶数 $d$ 不能用 RSS（会偏向高阶），要用前向/后向检验、AIC/BIC 或交叉验证。缺点是全局假设、外推时尾部由高阶项主导、且系数依赖基函数选择而不易解释。
- 样条是分段多项式，在结点处拼接并保证到二阶导连续（因此看起来光滑、不像分段线性那样有折角）。自然三次样条额外要求两端区间是线性的，把自由度从 $m+4$ 降到 $m$，外推时也更稳。给定结点后所有三次样条构成线性子空间，所以可以直接当线性模型用最小二乘拟合。
- 平滑样条把结点放在每个数据点上，用粗糙度惩罚 $\lambda\int [g'']^2$ 来控制弯曲程度，等价于「把自然三次样条当 ridge 来拟合」。$\lambda$ 决定有效自由度（$2$ 到 $n$ 之间），常用 LOO-CV 或 GCV 选（GCV 是 LOO 的廉价近似）。

> 完整条目与更多来源见 [[定义原文库#D19. 多项式回归|D19 多项式回归]]、[[定义原文库#D20. 样条（回归样条 / 自然三次样条）|D20 样条（回归样条 / 自然三次样条）]]、[[定义原文库#D21. 平滑样条与 GCV|D21 平滑样条与 GCV]]

## 二、核心直觉

### 同一份数据，原始尺度 vs 变换后

变量本身不会变——变的只是你用什么尺子量它。下表每一行是一种典型的「卡住」，数字全部来自本篇第四节的验算。

| 卡在哪一步 | 原始尺度上长什么样（本篇验算的数字） | 常用变换 | 变换后长什么样 | 修的是哪条假设 |
|---|---|---|---|---|
| 关系单调但弯曲 | 车辆价值 $3.07 \to 737.11$（偏度 4.60）；`y ~ x` 斜率 0.0225、AIC 325.1 | $\ln x$ | 斜率 1.673、AIC 297.4 | 线性可加（link 尺度上的直线） |
| 右偏 + 方差随均值增长 | 赔款样本偏度 1.41，均值 8.88 是中位数 4.60 的 1.93 倍 | Box-Cox $\lambda=0$ | 偏度 0.306；$\lambda=0.25$ 时 0.623 | 同方差与近似正态（推断、区间用得上） |
| 一个极端值决定斜率 | 把最大一笔 34 换成 120：偏度 1.41 → 2.19，$\hat\lambda$ 从 $-0.194$ 移到 $-0.356$ | 封顶（winsorise） | 10 个数那例：P2.5 = 1.225、P97.5 = 98.775，行全保留 | 杠杆与影响有界 |
| U 形 / 先降后升 | 年龄类变量的 empirical logit 掉下去又抬起来 | 分箱 / 样条 | 阶梯或光滑曲线能拐弯 | 放弃单调，改成分段 |
| 名义类别进不了方程 | `Color = [Red, Blue, Green, Red, Blue]` | one-hot / dummy | 每个类别一列 0/1，系数读成「相对参考水平」 | 数值输入的接口 |
| 类别多、又要单调有序 | 几十个 dummy 列 | WOE（[[2.3.1 WOE & IV]]） | 一列 log-odds，正负直接对应风险高低 | 降维 + 可解释的次序 |

**这里像什么、不像什么**：变换像**换算汇率**——同一笔钱换成另一种货币，数字变了，钱没变，排序也没变（这就是为什么单变量的 AUC 在 $x$ 与 $\ln x$ 之间一模一样，都是 0.8270）。不像的地方在于：汇率换完就完了，而变换会**改变模型族的可加性**——`x` 的乘法效应到了对数尺度上变成加法效应，于是「系数可以逐项相加」这句话才成立。换句话说，变换之后系数的含义变了，不能拿变换前的斜率直接比。

### 先画图，再猜变换：empirical logit plot

#### Empirical Logit Plot（识别该用哪种变换的主力工具）

**MAGNet 原话：the workhorse（主力工具）。** 目标是二分类、要判断某个连续预测变量该不该变换时，先用它，而不是先猜：

1. **做法**：把预测变量按**十分位（deciles）**分箱；每一箱算

   $$\ln\!\left(\frac{\text{events} + 0.5}{\text{non-events} + 0.5}\right)$$

   然后把这个值对着**箱均值（bin mean）**画图。
2. **为什么加 0.5**：这是**拉普拉斯平滑（Laplace smoothing）**——某个箱里事件数为 0 时 $\ln 0$ 会炸，加 0.5 把比率拉回有限值。
3. **怎么读**：
   * **直线** ⇒ 变量照用（在 logit 尺度上已经线性）；
   * **有曲率** ⇒ **曲率的形状直接告诉你变换**：对比 log / 平方根 / 倒数，挑那个把曲率拉直的；
   * **U 形** ⇒ **没有单调变换（monotone transform）能救**，必须**分箱（binning）**或**样条（spline）**。
4. **连续目标怎么办**：同样思路，把 y 轴换成**箱内目标均值**（binned mean–response plot）。

第四节把这条流程走了一遍：5 个分位箱的 empirical logit 与箱中位数的相关系数是 0.851，与 $\ln(\text{箱中位数})$ 的相关是 0.972 —— 一眼看出该用对数，而不是平方根或倒数。

**其余识别手段（MAGNet §2 的清单，一起说显得系统）**：

| 手段 | 一句话 |
| --- | --- |
| 分箱均值-响应图（binned mean–response plot） | 连续目标版的 empirical plot：箱内目标均值 vs 箱均值 |
| 残差 vs 预测变量的 **LOESS 平滑** | 平滑后仍有残余结构 ⇒ 缺了某个变换或非线性项 |
| **Spearman + Hoeffding's D 配对**（见 [[5.3 Multivariate Selection]]） | 低 Spearman 但高 D ⇒ 有信号、只是非单调：要的是**变换**不是删除 |
| 先拟合 **GAM** 看形状，再参数化 | 让数据给出形状，再退回最简单的参数形式（log / 多项式 / 样条） |
| Box-Cox / Yeo-Johnson | 让似然自己选幂次（见下文 Box-Cox 一节） |

**现代保险标准工作流（MAGNet 明确点名）**：

> **树模型是发现工具，GLM 是交付物**（the tree model is the discovery tool, the GLM is the deliverable）：先用 **GBM** 拟合，读 **PDP / SHAP 依赖图**看变量的形状，再把这个形状**显式编码进 GLM**（分箱、样条或解析式变换）。好处是既保留 GLM 的可解释性与可报送性（rate filing），又不用凭直觉猜变换。

## 三、机制

### 3.1 定义与逐项说明：变换在改什么、什么时候动手

**变换（transformation）** 指的是建模之前作用在预测变量（或响应变量）上的任何数学运算。它的目标是：

1. **改善 $X$ 与 $Y$ 之间的线性性**，让线性模型（或可加模型）拟合得更好。
2. **稳定残差的方差**（homoscedasticity，同方差性）。
3. **正态化**重尾或偏斜分布，让推断（如置信区间、假设检验）更可靠。
4. **控制离群值的影响** —— 通过封顶把极端值限住。
5. **编码**类别变量为数值形式，喂给那些只吃数值输入的算法。

这五条里，第 1 条直接对着模型假设，第 2、3 条影响推断的精度，第 4、5 条是工程手段（把极端值和类别变量收拾成能进方程的形式）。先问自己改的是哪一条，就不会被「数据看起来正态了没有」牵着走。

#### 什么时候需要变换：三条诊断

1. **残差诊断（Residual Diagnostics）**

   * **残差 vs 拟合值图（residual vs. fitted plot）** 出现弯曲 ⇒ 考虑加非线性项。
   * **残差 vs 预测变量图** 出现漏斗形 ⇒ 方差不稳，试试方差稳定变换（variance-stabilizing transform）。
2. **分布检查（Distributional Checks）**

   * 特征的**直方图 / 密度图**明显偏斜。
   * **偏度 / 峰度（skewness / kurtosis）** 统计量远离 0。
   * 残差或原始 $X$ 的 **Q–Q 图**偏离直线。
3. **模型表现（Model Performance）**

   * 模型很复杂，但 $R^2$ 仍低、测试误差仍大 ⇒ 关系可能是非线性的，或存在异方差（heteroscedastic）。

> **经验法则（Rule of thumb）**：拟合基线模型之前和之后，都要先看单变量分布与残差图。

第 3 条要拿数字说话，不要停在「$R^2$ 低」：本篇开场的例子就是把 AIC 从 325.1 降到 297.4 才敢下结论。

#### 一个变量该用哪一类变换：先分类目标是否参与

### 3.2 每个方法：公式逐符号解释 → 为什么这样设计 → 什么时候用哪个

#### 不看目标的方法（Target-Unaware Techniques）

##### 3.2.1 分箱（Binning）

###### 无监督：等宽与等频（Unsupervised Binning）

**目的（Purpose）**：降低连续变量的复杂度、处理非线性关系，同时**不使用目标信息**。

**等宽分箱（Equal-Width Binning）**

**公式（Formula）**：
$$\text{bin}(x) = \left\lfloor \frac{x - \min(x)}{\text{width}} \right\rfloor$$
$$\text{where } \text{width} = \frac{\max(x) - \min(x)}{n_{\text{bins}}}$$

**详细流程（Detailed Process）**：
1. 算极差：$R = \max(x) - \min(x)$
2. 定箱宽：$w = R / n_{\text{bins}}$
3. 造边界：$[x_{\min}, x_{\min} + w, x_{\min} + 2w, \ldots, x_{\max}]$
4. 按边界把观测分到各箱

**例子（Example）**：
```
Data: [1, 5, 8, 12, 15, 18, 22, 25, 30]
5 equal-width bins:
- Range: 30 - 1 = 29
- Width: 29/5 = 5.8
- Bins: [1-6.8], [6.8-12.6], [12.6-18.4], [18.4-24.2], [24.2-30]
```

逐符号读等宽公式：$x - \min(x)$ 把最小值平移到 0；除以 `width` 把「离最小值的距离」换算成「第几个箱宽」；$\lfloor \cdot \rfloor$ 向下取整，落到箱子编号。这个设计只用了 $\min$、$\max$ 两个数，所以它对尾部一点防御都没有——数据右偏时，最小的那个箱会吞掉大部分观测。

第四节的实测就是这个后果：车辆价值范围 734.04、等宽 5 箱宽 146.81，每箱样本量是 275 / 18 / 4 / 1 / 2，AIC 从等频版的 300.4 烂到 377.7。

**分位数分箱（Quantile Binning）**

**公式（Formula）**：
$$\text{bin}(x) = \text{rank}\left(\frac{x - \text{quantile boundaries}}{n_{\text{bins}}}\right)$$

**详细流程（Detailed Process）**：
1. 把数据升序排序
2. 算分位数边界（例如四分位就是第 25、50、75 百分位）
3. 让每个箱装到相同数量的观测
4. 一致地处理并列值（ties）

**优点与局限（Advantages & Limitations）**：
- **等宽（Equal-width）**：简单、可解释，但对离群值敏感
- **分位数（Quantile）**：对离群值稳健、箱内样本量均衡，但边界未必有业务意义

**什么时候用哪个**：切点本身要能对外解释（费率档位、限额点）时用等宽或按业务切；只要「每箱样本量够、尾部不吃掉分辨率」时用等频。等频不解决尾部问题，它只是把尾部摊进最后一箱 —— 那一箱里可能同时有 700 千元和 100 万的车。

###### 有监督：卡方与熵分箱（Supervised Binning）

**目的（Purpose）**：为连续变量造出**最优分箱**，让目标类别之间的区分度最大。

**常见算法（Common Algorithms）**：

*Chi-Square Binning*

**目标（Objective）**：最大化各箱与目标之间的卡方统计量
$$\chi^2 = \sum_{i=1}^{k} \sum_{j=1}^{2} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

其中 $O_{ij}$ 是观测频数，$E_{ij}$ 是期望频数。

*Entropy-Based Binning*

**目标（Objective）**：最小化各箱的加权熵（weighted entropy）
$$\text{Entropy} = -\sum_{i=1}^{k} w_i \sum_{j=1}^{2} p_{ij} \log(p_{ij})$$

其中 $w_i$ 是箱 $i$ 的权重，$p_{ij}$ 是箱 $i$ 中类别 $j$ 的概率。

逐符号读熵那一式：$p_{ij}$ 是箱 $i$ 内第 $j$ 类的比例，$\sum_j p_{ij}\log p_{ij}$ 是这一箱内部的「混乱程度」（越纯越接近 0），$w_i$ 是这一箱占总体样本的权重。整个式子就是把每箱的混乱程度按样本量加权求和，最小化它等于「让每一箱都尽可能纯」。设计意图和卡方是一致的：卡方看的是「实际频数偏离独立假设多远」，熵看的是「箱内纯度」，两者都只看箱与目标的二维列联表。

**详细流程（Detailed Process）**：
1. **初始化（Initialize）**：从细粒度分箱或连续值开始
2. **评估切点（Evaluate splits）**：试各种可能的切分点
3. **优化准则（Optimize criterion）**：挑让区分度最大的切分
4. **递归分裂（Recursive splitting）**：继续，直到满足停止准则
5. **验证（Validate）**：确认每次切分在统计上显著

**例子（Example）**：
```
Income data with binary target (default/no default):
Initial range: [20K, 200K]
Optimal splits found at: 45K, 80K, 120K
Final bins:
- [20K-45K]: 15% default rate
- [45K-80K]: 8% default rate  
- [80K-120K]: 3% default rate
- [120K-200K]: 1% default rate
```

**优点（Advantages）**：
- **最优区分（Optimal separation）**：把判别力最大化
- **自动化（Automatic）**：不需要手工挑阈值
- **可解释（Interpretable）**：业务含义清晰
- **稳健（Robust）**：比连续变量更不受离群值影响

**什么时候用哪个**：要「最优区分」，卡方最常用（SAS 的 `PROC TRANSREG` 一类实现、评分卡工具链里都有）；要看纯度、或箱子数量多的时候做后剪枝，熵版更顺手。两者共同的问题在第四节暴露过一次：**切点是从 $Y$ 学出来的**，箱数一多就会造出「全是事件」或「全是非事件」的箱（纯箱），此时 logistic 的 MLE 不存在、系数发散，必须先合并稀有水平，见 [[1.6 Estimation Issues & Separation]]。

##### 3.2.2 样条（Splines）：基函数、结点、自由度

**目的（Purpose）**：用分段多项式（piecewise polynomials）造出灵活的非线性变换。

**数学基础（Mathematical Foundation）**：
次数为 $d$、结点为 $\kappa_1, \kappa_2, \ldots, \kappa_K$ 的样条定义为：
$$s(x) = \sum_{j=0}^{d} \beta_j x^j + \sum_{k=1}^{K} \gamma_k (x - \kappa_k)_+^d$$

其中 $(x - \kappa_k)_+^d = \max(0, x - \kappa_k)^d$

逐符号读：前半段 $\sum_{j=0}^{d}\beta_j x^j$ 是一个全局多项式，管整体形状；$(\cdot)_+$ 是**铰链函数**（截断幂），$x$ 没到结点 $\kappa_k$ 时它取 0、过了结点才开始按 $d$ 次方增长；$\gamma_k$ 是每个结点贡献的额外弯曲量。设计意图是「全局打底 + 局部修正」：多项式管不到局部，铰链逐点把多项式掰弯。这也是它比多项式稳的原因——某一区间要变形，只需要动那附近的 $\gamma_k$，远处的区间不受影响（局部性）。

**三次样条的基函数（Basis Functions for Cubic Splines）**：
$$\text{Basis} = \{1, x, x^2, x^3, (x-\kappa_1)_+^3, (x-\kappa_2)_+^3, \ldots, (x-\kappa_K)_+^3\}$$

**具体构造（Detailed Construction）**：
1. **选结点位置（Choose knot locations）**：常放在分位数处或等距摆放
2. **生成基矩阵（Generate basis matrix）**：每一列是一个基函数
3. **拟合系数（Fit coefficients）**：用标准回归方法
4. **保证连续性（Ensure continuity）**：样条在结点处连续

**两个结点的例子（Example with 2 knots）**：
```
Knots at x = 3, 7
Basis functions:
- f₁(x) = 1
- f₂(x) = x
- f₃(x) = x²
- f₄(x) = x³
- f₅(x) = (x-3)₊³
- f₆(x) = (x-7)₊³
```

**优点（Advantages）**：
- **灵活（Flexibility）**：能建模复杂的非线性关系
- **局部性（Locality）**：某个区域的改变不影响其它区域
- **光滑（Smoothness）**：在结点处导数连续
- **可解释（Interpretability）**：分段的结构容易理解

**为什么这样设计**：结点数决定弯曲的次数上限，这就是自由度。两个结点（$m = 2$）的普通三次样条有 $4(m+1) - 3m = 6$ 个基函数；同样的结点数下，自然三次样条（两端强制线性）只有 $m = 2$ 个自由度。**用自由度换尾部稳定性**，这是自然样条成为默认选择的全部理由。

**什么时候用哪个**：关系弯曲、又要能画出效应曲线给监管看 ⇒ 回归样条或自然三次样条（默认）；只要最光滑的形状、不想选结点 ⇒ 平滑样条（结点放在每个数据点上，靠惩罚 $\lambda$ 控弯曲，等价于「把自然三次样条当 ridge 拟合」）；结点数和位置由交叉验证 / GCV / AIC 选，常用分位数放结点。

##### 3.2.3 多项式项（Polynomial Terms）

**目的（Purpose）**：通过给已有特征加幂次项来捕捉非线性关系。

**数学表示（Mathematical Representation）**：
$$f(x) = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3 + \ldots + \beta_p x^p$$

**具体实现（Detailed Implementation）**：
```python
# Creating polynomial features
X_poly = np.column_stack([X**i for i in range(1, degree+1)])
```

**特征工程例子（Feature Engineering Example）**：
```
Original feature: x = [1, 2, 3, 4, 5]
Degree 3 polynomial:
- x¹: [1, 2, 3, 4, 5]
- x²: [1, 4, 9, 16, 25]
- x³: [1, 8, 27, 64, 125]
```

**关键注意点（Key Considerations）**：
- **次数怎么选（Degree selection）**：次数越高越容易过拟合
- **共线性（Multicollinearity）**：多项式各项之间高度相关
- **量纲问题（Scaling issues）**：高次幂的量级可能差好几个数量级
- **外推问题（Extrapolation problems）**：多项式在训练范围之外可能表现极差

**最佳实践（Best Practices）**：
- 从低次开始（2–3 次）
- 用交叉验证选次数
- 考虑先做标准化（standardizing）
- 用验证曲线（validation curve）盯过拟合

**为什么这样设计**：它其实是「用泰勒展开逼近任意光滑函数」的最朴素版本——项数够了什么形状都能凑，代价是每个系数都依赖基函数的选择（换一个 $x$ 的平移量，$x$ 与 $x^2$ 的系数都会变，只有预测值不变）。共线性那一条不是理论洁癖：未中心化的 $x$ 与 $x^2$ 之间相关性极高，会把主效应的 VIF 机械抬高（[[3.4.2 Variance Inflation Factor (VIF)]] 里那组数：$R_j^2 = 0.9$ 就对应 VIF = 10）。

**什么时候用哪个**：手上有「先升后降」的物理直觉（例如价格弹性）、且只需要一个解析式 ⇒ 二次项最省事；形状说不清、或者要有局部适应性 ⇒ 样条更好，因为多项式是全局的，一处弯曲全曲线跟着动。外推是多项式最弱的地方，涉及训练范围之外时优先用自然样条（边界外线性）。

##### 3.2.4 幂变换：Box-Cox 与 Yeo-Johnson

###### Box-Cox Transformation

**目的（Purpose）**：通过幂变换（power transformation）把分布正态化、并稳定方差。

**数学定义（Mathematical Definition）**：
$$x^{(\lambda)} = \begin{cases}
\frac{x^\lambda - 1}{\lambda}, & \text{if } \lambda \neq 0 \\
\ln(x), & \text{if } \lambda = 0
\end{cases}$$

逐符号读：$\lambda$ 是幂次，也是这个变换唯一要估的参数；分子 $x^\lambda - 1$ 是原始的幂函数，除以 $\lambda$ 是为了让 $\lambda \to 0$ 时整式平滑地趋于 $\ln x$（用洛必达：$\lim_{\lambda\to0}\frac{x^\lambda-1}{\lambda} = \ln x$）——没有这个除以 $\lambda$，$\lambda$ 在 0 附近会让 $x^{(\lambda)}$ 跳变，似然曲线在 0 处会有断点，就没法逐点比较。$\lambda = 1$ 时 $x^{(1)} = x - 1$，就是原始尺度差一个平移；$\lambda = 0.5$ 是平方根（压缩右尾），$\lambda = -1$ 是倒数（把最大的一笔压成最小）。

**参数怎么选（Parameter Selection）**：
最优的 $\lambda$ 通过最大化对数似然得到：
$$\ell(\lambda) = -\frac{n}{2}\ln\left(\frac{1}{n}\sum_{i=1}^n(x_i^{(\lambda)} - \bar{x}^{(\lambda)})^2\right) + (\lambda-1)\sum_{i=1}^n\ln(x_i)$$

逐项读：括号里是变换后样本的**平均平方离差**（也就是忽略自由度时的方差估计），取对数、乘 $-n/2$ 就是「正态对数似然里除常数外的全部」——这一项在罚「变换后方差大」的 $\lambda$。第二项 $(\lambda-1)\sum_i \ln x_i$ 是**雅可比（Jacobian）项**：幂变换会缩放尺度，不把它带上，$\lambda$ 就会单纯往「把方差压小」的方向跑（比如 $\lambda \to 0$ 常数化）。加上它以后，$\lambda$ 的标准才和「单位换算」无关——第四节验算过：把整份数据乘 1000，$\hat\lambda$ 仍然是 $-0.1941$，似然差仍然是 0.3459。第一项让你别把数据压扁，第二项让你别靠换单位作弊。

**常见 λ 取值（Common Lambda Values）**：
- $\lambda = 2$：平方变换（增强右偏）
- $\lambda = 1$：不做变换（原始数据）
- $\lambda = 0.5$：平方根变换
- $\lambda = 0$：自然对数变换
- $\lambda = -0.5$：倒数平方根
- $\lambda = -1$：倒数变换

**详细流程（Detailed Process）**：
1. **检查前提（Check prerequisites）**：数据必须为正（$x > 0$）
2. **网格搜索（Grid search）**：试各种 $\lambda$
3. **评估正态性（Evaluate normality）**：用 Shapiro-Wilk 检验或 Q-Q 图
4. **应用变换（Apply transformation）**：用最优 $\lambda$
5. **验证（Validate）**：检查变换是否达到预期性质

第 3 步要加一句实务修正：$\lambda$ 是拿同一份数据选出来的，再用同一份数据做正态性检验，检验会偏乐观。想要干净的正态性检验，先在训练集定 $\lambda$、到留出集上检验。

**局限（Limitations）**：
- 只适用于正值
- 未必一定能做到正态
- 解释会变复杂
- 预测时需要做反变换（inverse transformation）

**什么时候用哪个**：只有一个连续变量、要一个能报出去的解析式、且不必太在意尾部单点 ⇒ 直接用 $\lambda = 0$（对数）常常够了，第四节的数据就是这种情形（$\hat\lambda = -0.194$ 与 $\lambda = 0$ 的似然几乎相同）；需要「数据自己说话」、又要写进模型比较里 ⇒ 用似然选 $\hat\lambda$，但同时报告 $\lambda = 0$ 的结果，因为多数读者只认对数。

###### Yeo-Johnson：让 $\lambda$ 也能吃负值

**数学定义**：
$$\psi(x, \lambda) = \begin{cases}
\frac{(x+1)^\lambda - 1}{\lambda}, & x \ge 0,\ \lambda \neq 0 \\
\ln(x+1), & x \ge 0,\ \lambda = 0 \\
-\frac{(-x+1)^{2-\lambda} - 1}{2-\lambda}, & x < 0,\ \lambda \neq 2 \\
-\ln(-x+1), & x < 0,\ \lambda = 2
\end{cases}$$

逐符号读：正值段和 Box-Cox 长得一样，只是把 $x$ 平移成 $x+1$，好处是在 $x = 0$ 处也连续可导（Box-Cox 在 $x \to 0^+$ 时会往 $-\infty$ 跑）；负值段是它的**镜像**：先把 $-x$ 搬到正轴，用 $2-\lambda$ 当幂次（这个 $2-\lambda$ 是设计的关键一步，它保证整条曲线在 $\lambda = 1$ 时退化成恒等映射，两段在 $x = 0$ 处导数也对得上），最后整体取负，让映射保持单调递增。$\lambda$ 的选取和 Box-Cox 一样用轮廓似然，只是似然里的雅可比项换成两段的组合。

**手算一遍（$\lambda = 0$，5 个数）**：

$$
\psi([-2, -1, 0, 1, 2], 0) = [-4,\ -1.5,\ 0,\ 0.693147,\ 1.098612]
$$

负值段两个值：$x = -2 \Rightarrow -\frac{(1-(-2))^2 - 1}{2} = -\frac{9-1}{2} = -4$；$x = -1 \Rightarrow -\frac{2^2-1}{2} = -1.5$。正值段两个值：$\ln(1+1) = 0.693147$、$\ln(1+2) = 1.098612$。校验一下 $\lambda = 1$：$\psi(x, 1) = x$ 对 $[-2,-1,0,1,2]$ 逐点成立，这就是「$\lambda=1$ 不做变换」这条口号的来源。Box-Cox 在这组数上直接用不了：$(-2)^{-0.194}$ 在实数域没有定义。

**什么时候用哪个**：变量本身含 0 或负值（净保费增减、温度、收益率的差分）⇒ 用 Yeo-Johnson，别先「加一个常数搬正再用 Box-Cox」。为什么不能平移：平移量会顶替 $\lambda$ 干活，第四节验算过——同一份赔款数据，平移 1 让 $\hat\lambda$ 从 $-0.194$ 变成 $-0.392$，平移 10 变成 $-1.637$，平移 100 直接顶到网格边界 $-2$；解释跟着平移量一起漂，报出去没法辩护。

###### ⚠️ 高价值陷阱：反变换（back-transformation）是有偏的

因为 **$E[g(Y)] \neq g(E[Y])$**。

* 若对 $\log(y)$ 建模、再对预测取指数 $e^{\hat\mu}$，你拿到的是**中位数（median）不是均值（mean）**。
* 要拿回**均值**，需要 **smearing / Duan 校正（Duan's smearing estimator）**：把残差取指数后的**平均**当作乘子

  $$\hat{E}[Y] \;=\; e^{\hat{\mu}} \cdot \frac{1}{n}\sum_{i=1}^{n} e^{\hat{\varepsilon}_i}.$$

* **对比（这才是重点）**：**GLM 的 log link 直接对 $\log(E[Y])$ 建模**，反变换天然无偏、完全不需要 smearing —— 这正是 **GLM 在保险里取代「先变换再 OLS」的核心原因**（见 [[1.2 Generalized Linear Models (GLMs)]]）。
* **数值示例（已自己验算）**：设 $\log y \sim N(\mu,\sigma^2)$、$\sigma^2 = 1$。对数正态的均值是 $E[Y] = e^{\mu+\sigma^2/2} = e^{\mu}\cdot e^{0.5}$，而直接取指数只给 $e^{\mu}$。
  * $e^{0.5} = 1.6487$（核对：$e^{0.5}=\sqrt{e}=\sqrt{2.71828}=1.64872$）；
  * 直接取指数的**低估比例** $= 1 - \dfrac{1}{1.6487} = 1 - 0.6065 \approx \mathbf{39.3\%}$（只拿到真均值的 60.65%）。

> 一句话总结：**「变换 + OLS」的反变换要修偏（smearing），「log link 的 GLM」不用。** 报费率（rate filing）时这 39% 的差距就是真金白银。

> 来源：MAGNet §2（Box-Cox / back-transformation TRAP）；[[MAGNet 面试真题全解]]

##### 3.2.5 封顶 / 保底（Winsorisation, Capping/Flooring）

**目的（Purpose）**：通过在指定百分位处封顶，降低极端离群值的影响。

**数学定义（Mathematical Definition）**：
$$x'_i = \begin{cases}
P_{\alpha/2}, & \text{if } x_i < P_{\alpha/2} \\
x_i, & \text{if } P_{\alpha/2} \leq x_i \leq P_{1-\alpha/2} \\
P_{1-\alpha/2}, & \text{if } x_i > P_{1-\alpha/2}
\end{cases}$$

其中 $P_q$ 是第 $q$ 百分位，$\alpha$ 是 winsorization 的水平。

逐符号读：$P_{\alpha/2}$ 与 $P_{1-\alpha/2}$ 是两个学到的边界，$\alpha = 0.05$ 表示两端各切 2.5%；三条分支的意思是「低于下界抬到 2.5 分位、高于上界压到 97.5 分位」，中间段原样不动。设计意图和删行（trimming）正好相反：**留住行、只压取值**，因为「这条保单存在」本身就是信息。

**具体实现（Detailed Implementation）**：
```python
# 5% winsorization (2.5% each tail)
lower_bound = np.percentile(data, 2.5)
upper_bound = np.percentile(data, 97.5)
winsorized_data = np.clip(data, lower_bound, upper_bound)
```

**例子（Example）**：
```
Original: [1, 2, 3, 4, 5, 95, 96, 97, 98, 99]
5% Winsorization:
- 2.5th percentile: 1.225
- 97.5th percentile: 98.775
- Result: [1.225, 2, 3, 4, 5, 95, 96, 97, 98, 98.775]
```

**关键注意点（Key Considerations）**：
- **保住样本量**（与 trimming 截断不同）
- **降低偏度与峰度（skewness / kurtosis）**
- **百分位怎么选**会显著影响结果
- 极端处有**信息损失**

**⚠️ 两个必须知道的要点（保险 / 工程）**

1. **百分位点本身就是「学到的参数」⇒ 会泄漏（leakage）**：截断用的 2.5% / 97.5% 分位点是**从训练数据学到的参数**，不是固定常数。在**全量数据（含测试集）上算分位点**、或在**测试集上重算**，都是泄漏。正确做法：**在训练集（或训练折）内拟合分位点，然后全流程（验证 / 测试 / 线上）套用同一组边界**——和均值填充、标准化、PCA 一样，属于必须放进 pipeline 的步骤。
2. **保险专属做法**：对**大额损失封顶（cap large losses）**，避免**单笔巨灾索赔**把严重度（severity）系数整个带偏（对数正态 / Gamma 类严重度对极端值极其敏感）。但**被封顶掉的那部分不能凭空消失**：要把它**单独处理为「超额层（excess layer）」**（例如再保的巨灾超额），或计入**巨灾附加（catastrophe load）**，否则费率会系统性偏低。

> 来源：MAGNet §2（capping 与 leakage）；[[MAGNet 面试真题全解]]

**什么时候用哪个**：尾部有单点主导斜率 ⇒ 封顶；尾部虽然长但整体形状都对数正态 ⇒ 对数变换更省事，还能保住「每个观测贡献自己的取值」这条信息（封顶把若干个不同的值压成同一个数）。两者常一起用：先封顶再取对数。完整深潜见第八节的真题问答块。

##### 3.2.6 类别变量：One-Hot、Dummy、合并（One-Hot Encoding / Dummy Coding / Greenacre）

###### 1. One-Hot Encoding (Dummy Coding)

**目的（Purpose）**：把类别变量转成数值格式，喂给那些需要数值输入的机器学习算法。

**数学表示（Mathematical Representation）**：
对一个有 $k$ 个类别的类别变量，造 $k$ 个二值指示变量：
$$X_{ij} = \begin{cases} 1 & \text{if observation } i \text{ belongs to category } j \\ 0 & \text{otherwise} \end{cases}$$

逐符号读：$i$ 是行号、$j$ 是类别编号，$X_{ij}$ 就是「第 $i$ 行是不是第 $j$ 类」的开关。设计上每个类别各占一列，好处是列的均值直接是这个类别的占比，坏处是 $k$ 列加起来恒等于 1 —— 这条恒等式就是下面共线性的来源。

**详细例子（Detailed Example）**：
```
Original: Color = [Red, Blue, Green, Red, Blue]
After One-Hot:
Red:   [1, 0, 0, 1, 0]
Blue:  [0, 1, 0, 0, 1]
Green: [0, 0, 1, 0, 0]
```

**关键注意点（Key Considerations）**：
- **共线性（Multicollinearity）**：如果把 $k$ 列全放进去，它们之和恒为 1，于是产生完全共线性
- **参考编码（Reference Coding）**：去掉一个类别（参考水平 reference level）就能避开这个问题
- **稀疏表示（Sparse Representation）**：高基数类别会产生大量 0
- **内存影响（Memory Impact）**：可能显著扩大特征空间维度

**什么时候用（When to Use）**：
- 基数中等的名义类别变量（nominal categorical variables）
- 算法本身无法直接处理类别数据时
- 类别之间没有内在顺序时

###### 2. Dummy Coding

**目的（Purpose）**：类别编码的一种特定形式 —— 显式使用一个**参考类别（reference category）**。

**数学基础（Mathematical Foundation）**：
对 $k$ 个类别，造 $k-1$ 个二值变量：
$$\text{If category } = j, \text{ then } D_j = 1, \text{ all other } D_i = 0$$
$$\text{Reference category represented when all } D_i = 0$$

**具体实现（Detailed Implementation）**：
```
Color = {Red, Blue, Green}
Reference = Red (omitted)
Model variables:
- Blue_dummy = 1 if Blue, 0 otherwise
- Green_dummy = 1 if Green, 0 otherwise
- Red is represented when both dummies = 0
```

**解释上的好处（Interpretation Benefits）**：
- 系数表示的是**相对参考类别的差异**
- 参考类别的系数被吸收进截距（intercept）
- 在回归模型里更好解释
- 避开「虚拟变量陷阱（dummy variable trap）」

**最佳实践（Best Practices）**：
- 选一个有意义的参考类别（例如最常见的那类、对照组）
- 写清哪个类别是参考
- 考虑它对系数解释的影响

**高基数（high cardinality）dummy 编码的三个后果**（面试常从这里追问）：

* **设计矩阵爆炸**：$k$ 个类别 → $k-1$ 列，几百个水平直接把 $p$ 顶上去、把自由度吃掉。
* **稀疏水平的估计不稳**：某些水平只有寥寥几个样本 ⇒ 系数方差极大、符号在重抽样间乱跳。
* **空格子引发准完全分离（quasi-complete separation）**：某个水平下**全是事件或全是非事件**时，logistic 的 MLE 不存在 / 系数发散 —— 细节见 [[1.6 Estimation Issues & Separation]]。**这是「先合并稀有水平」最硬的理由。**

这条「纯组 ⇒ 系数发散」在第四节的分箱算例里也出现了一次：10 个分位箱时第一箱的 30 条全是非事件，那个 dummy 的系数被推到 27.8，标准误 1.09e6。分箱和类别编码在这件事上是同一个问题。

**Greenacre 方法（高基数类别合并）**：一种**凝聚式（agglomerative）**合并**名义类别（nominal categories）**的方法，**目标是最小化卡方关联（chi-square association）的损失** —— 也就是把「信息含量最接近」的类别先并在一起、一步步并到想要的水平数。用途：**在 dummy 编码之前先降低基数（reduce cardinality）**，上面三个后果都随之缓解。**面试知道名字 + 用途即可**，不必会推导。

**替代方案清单（dummy 不是唯一答案）**：

| 方案 | 一句话 | 注意 |
| --- | --- | --- |
| **Greenacre 合并** | 先按卡方关联聚类并类，再 dummy 编码 | 无监督，不看目标 |
| **WoE**（[[2.3.1 WOE & IV]]） | 每个类别换成一个 log-odds 数值列 | 要先分箱、要防泄漏 |
| **Target / mean encoding** | 用该类别的目标均值替代 | **同样是泄漏源**：必须**平滑（smoothing）+ 折外（out-of-fold）计算** |
| **有序编码（ordinal）** | 类别**真的有序**时才用 | 给名义变量强加顺序会引入假结构 |
| **Hashing** | 哈希到固定维数 | 适合**超高基数**，但不可解释、会碰撞 |
| **LightGBM / CatBoost 原生类别处理** | 树模型内部处理类别 | 树专属；GLM 交付物用不了 |

> 来源：MAGNet §2（dummy coding / Greenacre）；[[MAGNet 面试真题全解]]

**什么时候用哪个**：基数 ≤ 10 且类别有业务名字 ⇒ one-hot / dummy；基数几十上百、又要一列进 GLM ⇒ WOE；基数极高、只做预测 ⇒ 哈希或树模型原生处理。

#### 看目标的方法（Target-Aware Techniques）

###### [[2.3.1 WOE & IV | 1. Weight of Evidence (WOE)]]

**目的（Purpose）**：根据与二分类目标的关系来变换类别变量，造出**单调**的关系。

**数学定义（Mathematical Definition）**（采用学分卡主流约定：**Good = 非事件 (Y=0)**，**Bad = 事件 (Y=1)**）:
$$\text{WOE}_i = \ln\left(\frac{P(X_i|Y=0)}{P(X_i|Y=1)}\right) = \ln\left(\frac{\text{Distribution of Goods}}{\text{Distribution of Bads}}\right) = \ln\left(\frac{\%\,\text{Goods}}{\%\,\text{Bads}}\right)$$

逐符号读：$X_i$ 是第 $i$ 个箱或类别；分子是「在这个箱里，好人占全体好人的比例」，分母是「在这个箱里，坏人占全体坏人的比例」——注意两个比例都除过各自的**总数**，所以这是分布之比，不是箱内比例之比。结果是 log-odds 的量纲，可以直接和 logistic 的系数相加，这正是它能替掉一堆 dummy 的原因。

> **符号约定（全库统一）**：**WOE > 0 = 该组里好人（非事件）占比更高 = 低风险**；**WOE < 0 = 高风险**。同一约定见 [[2.3.1 WOE & IV]]、[[5.2 Univariate Selection]]。
> ⚠️ **面试真题用的是相反定义**：[[MAGNet 面试真题全解]] §2 用 `WoE = ln(%Events/%NonEvents)` ⇒ 正 WoE = 高风险，**理想系数 ≈ +1.0**（本约定的理想系数是 −1）。两者互为相反数、都自洽 —— **面试按真题口径回答，并主动说明你用哪种定义**。对照表见 [[2.3.1 WOE & IV]] 文首「符号约定」块。

**详细算法（Detailed Calculation）**：
对类别 $i$：
$$\text{WOE}_i = \ln\left(\frac{n_{i0}/n_{0\cdot}}{n_{i1}/n_{1\cdot}}\right)$$

其中：
- $n_{i0}$ = 类别 $i$ 里 **Goods（非事件，Y=0）** 的个数
- $n_{i1}$ = 类别 $i$ 里 **Bads（事件，Y=1）** 的个数
- $n_{0\cdot}$ = **Goods（非事件）** 总数
- $n_{1\cdot}$ = **Bads（事件）** 总数

**逐步例子（Step-by-Step Example）**：
```
Category | Goods (Non-Events, Y=0) | Bads (Events, Y=1) | Total | % Goods | % Bads | WOE = ln(%Goods/%Bads)
A        | 200                     | 100                | 300   | 40%     | 20%    | ln(0.4/0.2) = +0.693
B        | 150                     | 150                | 300   | 30%     | 30%    | ln(0.3/0.3) =  0.000
C        | 150                     | 250                | 400   | 30%     | 50%    | ln(0.3/0.5) = -0.511
Total    | 500                     | 500                | 1000  | 100%    | 100%   |
```

**关键性质（Key Properties）**：
- **单调编码（Monotonic encoding）**：与目标之间形成有序关系
- **能处理缺失值**：可以给缺失单独指定一个 WOE
- **降维**：每个类别压成一个数值
- **可解释**：**WOE 为正 ⇒ 该箱由 Goods 主导 ⇒ 风险更低**；WOE 为负 ⇒ 风险更高

**最佳实践（Best Practices）**：
- 保证每个类别的样本量足够（>30 个观测）
- 零计数用加一个小常数处理（拉普拉斯平滑 Laplace smoothing）
- 用折外编码（out-of-fold encoding）防过拟合
- 监控极端 WOE 值（>±3）

**什么时候用哪个**：类别与风险的关系大致单调、要一列进 GLM 且要能报费率 ⇒ WOE；关系非单调、或者只关心区分度不看单体解释 ⇒ 用有监督分箱造 dummy，把非单调留在箱的排序里。WOE 的完整推导与全部坑见 [[2.3.1 WOE & IV]]。

###### 2. Information Value (IV)

**目的（Purpose）**：衡量一个特征对二分类的预测能力。

**数学定义（Mathematical Definition）**：
$$\text{IV} = \sum_{i=1}^{n} (\text{WOE}_i) \times \bigl(P(X_i|Y=0) - P(X_i|Y=1)\bigr) = \sum_i \text{WOE}_i \times (\%\text{Goods}_i - \%\text{Bads}_i)$$

**等价写法（Alternative Formulation）**：
$$\text{IV} = \sum_{i=1}^{n} \left(\frac{n_{i0}}{n_{0\cdot}} - \frac{n_{i1}}{n_{1\cdot}}\right) \times \ln\left(\frac{n_{i0}/n_{0\cdot}}{n_{i1}/n_{1\cdot}}\right)$$

逐符号读：每一项是 $\text{WOE}_i$ 乘「该箱里好人比例与坏人比例之差」。两项永远同号（好人多的箱 WOE 为正、差也为正），所以每一项都非负，加总起来不会互相抵消。设计意图是「把所有箱的信息贡献加起来，且不让符号打架」：这就是为什么 IV 能当特征筛选的排序指标，而 WOE 不行。

**详细算例（Detailed Calculation Example）**：
```
Using the WOE example above (WOE = ln(%Goods / %Bads)):
Category | WOE    | % Goods | % Bads | Diff (%Goods-%Bads) | IV Contribution
A        | +0.693 | 0.40    | 0.20   | +0.20               | (0.693) × (0.20) = 0.139
B        |  0.000 | 0.30    | 0.30   |  0.00               | (0.000) × (0.00) = 0.000
C        | -0.511 | 0.30    | 0.50   | -0.20               | (-0.511) × (-0.20) = 0.102
Total IV = 0.139 + 0.000 + 0.102 = 0.241
```
(每项都是"同号相乘"，所以 IV 贡献恒为非负；总 IV 与 WOE 的符号约定无关，但 WOE 的方向决定了「哪些组是低风险」的解释。)

**怎么读（Interpretation Guidelines）**：
- **IV < 0.02**：几乎没有预测力（没用）
- **0.02 ≤ IV < 0.1**：弱预测力（用处有限）
- **0.1 ≤ IV < 0.3**：中等预测力（不错）
- **0.3 ≤ IV < 0.5**：强预测力（很好）
- **IV ≥ 0.5**：极强预测力（要查过拟合 / 泄漏）

**应用（Applications）**：
- **特征选择（Feature selection）**：按 IV 给特征排序
- **模型验证（Model validation）**：比较不同样本上的 IV
- **业务理解（Business understanding）**：找出关键驱动因素
- **合规报备（Regulatory compliance）**：记录特征重要性

###### 4. Generalized Additive Models (GAM) Smoothing

**目的（Purpose）**：用光滑函数捕捉特征与目标之间的非线性关系。

**数学框架（Mathematical Framework）**：
$$g(E[Y|X]) = \beta_0 + \sum_{j=1}^{p} f_j(X_j)$$

其中 $g(\cdot)$ 是连接函数（link function），$f_j(\cdot)$ 是光滑函数。

逐符号读：$g$ 是 GLM 里那个连接函数（logistic 用 logit、Gamma 用 log），$\beta_0$ 是所有光滑项都取 0 时的基线，$f_j$ 是**每个变量各自一条的函数**——把所有 $f_j$ 相加就等于线性预测子。设计意图是保留 GLM 的加法结构（所以每个变量的效应能单独画出来）而放弃「$f_j$ 必须是一条直线」。这是它比 GBM 可解释的原因，也是它抓不到交互的原因。

**具体组成部分（Detailed Components）**：

*Smooth Functions*

$f_j(X_j)$ 的常见选择：
- **样条（Splines）**：带结点的分段多项式
- **LOESS**：局部回归平滑
- **惩罚样条（Penalized splines）**：加正则化以防过拟合

*Estimation Process*

1. **Backfitting 算法（Backfitting Algorithm）**：
   - 初始化：对所有 $j$，$f_j^{(0)}(X_j) = 0$
   - 迭代到收敛：
     $$f_j^{(m+1)}(X_j) = \text{Smoother}\left(X_j, Y - \beta_0 - \sum_{k \neq j} f_k^{(m)}(X_k)\right)$$

2. **平滑参数怎么选（Smoothing Parameter Selection）**：
   - 交叉验证
   - 广义交叉验证（GCV）
   - AIC/BIC 准则

**代码示例（Practical Implementation）**：
```python
# Conceptual GAM for binary classification
from pygam import LogisticGAM, s

# Define smooth terms
gam = LogisticGAM(s(0) + s(1) + s(2))
gam.fit(X, y)

# Extract smooth functions
for i in range(X.shape[1]):
    smooth_func = gam.partial_dependence(term=i, X=X)
```

**特征工程上的用途（Feature Engineering Applications）**：
- **自动分箱（Automatic binning）**：用 GAM 的预测值当分箱边界
- **特征变换（Feature transformation）**：套用学到的光滑函数
- **交互探测（Interaction detection）**：找出非线性最要紧的地方
- **可解释性（Interpretability）**：可视化 partial dependence plots

**主要优点（Key Advantages）**：
- **灵活（Flexibility）**：任何光滑关系都能建模
- **可解释（Interpretability）**：每个特征的效应都看得见
- **自动化（Automatic）**：不用手工指定函数形式
- **正则化（Regularization）**：自带过拟合保护

**要注意（Considerations）**：
- **计算成本（Computational cost）**：比线性模型贵
- **样本量（Sample size）**：要足够数据才能得到稳定估计
- **外推（Extrapolation）**：训练范围之外的行为不确定
- **特征交互（Feature interactions）**：标准 GAM 假设可加性

**什么时候用哪个**：形状看不清、又要给每个变量一条能画的曲线 ⇒ GAM；只要区间估计和费率表、形状已经明确 ⇒ 分箱或显式变换，自由度少、能被监管逐项审。关系弯曲 + 要报送 ⇒ GAM / 自然样条；只在意排名精度 ⇒ GBM。

### 3.3 变形与口径：不同写法、参数化、软件差异

**① $\lambda$ 的参数化与尺度不变性。**

- 常见两种写法：$\frac{x^\lambda-1}{\lambda}$（本文用的这一种，优点是与 $\ln x$ 在 $\lambda=0$ 处连续衔接）与 $x^\lambda$（少了平移，$\lambda$ 在 0 附近不连续）。两者选出的 $\hat\lambda$ 相同，因为差别只是一次单调的线性重标。
- 雅可比项 $(\lambda-1)\sum\ln x_i$ 让 $\hat\lambda$ 对**单位换算不变**：第四节把整份数据乘 1000，$\hat\lambda$ 仍是 $-0.1941$，似然差仍是 0.3459。所以报 $\lambda$ 时不必说明单位，这一点和「封顶的 95 分位点」不同（分位点随单位变化，数值会变）。
- 网格搜索的粒度就是 $\lambda$ 的精度：本篇用的网格步长是 $3.5/350000 = 1\times10^{-5}$，够到小数点后 4 位。实务上跑 `MASS::boxcox` 或 `PowerTransformer(method="box-cox")` 得到 λ 的置信区间，比只报点估计有用。

**② 分箱口径。**

- **等宽 vs 等频**：两者的切点都是**从训练集学到的参数**，都必须逐折重算（同封顶分位点）。
- **分箱后的系数不能与原始斜率互换**：每箱一个 dummy 时，参照箱进入截距（见 3.2.6 的 dummy 编码），其余系数是「相对参照箱的 log-odds 差」。要读「每单位变化多少」，得看箱内均值之差，或者干脆用连续变量。
- **箱内被压平**：同一箱里所有观测共享一个拟合值，所以排序能力会因并列值下降。第四节实测 AUC 从 0.827 掉到 0.809。
- **箱数不能只看 AIC**：第四节 10 箱的 AIC（296.5）甚至比 $\ln x$（297.4）还好，但它的系数是分离造出来的（27.8 ± 1.09e6），没有任何解释价值。

**③ 样条口径。**

- 自由度与结点数不是一回事：普通三次样条 $4(m+1)-3m = m+4$，自然三次样条为 $m$（两端线性省掉 4 个自由度）。报「用了几个结点」时必须同时报是哪种样条。
- 结点放在分位数处是默认做法，好处是每个结点之间样本量不至于过小；等距放结点在右偏数据上会把大部分结点浪费在稀疏的尾部。
- 平滑样条不是「另一种基」，它是同一族函数上的惩罚拟合：$\lambda$ 由 GCV 定，有效自由度 $\text{df}_\lambda = \text{tr}(\mathbf{S}_\lambda)$ 落在 2 与 $n$ 之间。

**④ WOE 的符号口径。**

全库统一用 `WOE = ln(%Goods / %Bads)`（正 WOE = 低风险，理想系数 −1）；[[MAGNet 面试真题全解]] §2 用 `ln(%Events/%NonEvents)`（正 WOE = 高风险，理想系数 ≈ +1）。两者互为相反数，IV 不受影响。面试按真题口径回答，并主动说明用的是哪种，对照表见 [[2.3.1 WOE & IV]] 文首。

**⑤ 软件口径。**

- `np.percentile` 默认线性插值：例子 [1…99] 的 2.5 分位算出 1.225 就是这个口径；换成 `method="lower"` 会得到 1.0，封顶点会变，报数字时要写清口径。
- `sklearn.preprocessing.PowerTransformer(method="box-cox")` 要求输入全为正，`method="yeo-johnson"` 才能吃负值，两者的 $\lambda$ 都由轮廓似然估。
- R 里 `MASS::boxcox()` 给的是 $\lambda$ 的似然曲线与区间；`car::powerTransform()` 给点估计。
- GAM 的常见实现：R `mgcv::gam` 的 `s( )`，Python `pygam`；估计用 backfitting 或惩罚似然。

**⑥ 选型框架（决策顺序）。**

#### Choosing Between Techniques

##### Decision Framework:

1. **有目标可用吗（Target Available?）**
   - 有 → 考虑看目标的技法（target-aware）
   - 没有 → 用不看目标的技法（target-unaware）

2. **数据类型（Data Type）是什么？**
   - 类别型 → one-hot、dummy、WOE
   - 连续型 → 分箱、变换、样条

3. **与目标的关系（Relationship with Target）？**
   - 线性 → 简单变换
   - 非线性 → 样条、GAM、多项式

4. **可解释性要求（Interpretability Requirements）高吗？**
   - 高 → 分箱、WOE、简单变换
   - 低 → 复杂样条、高次多项式

5. **样本量（Sample Size）？**
   - 小 → 简单技法
   - 大 → GAM 这类复杂技法

这套顺序在样本量小、可解释性要求高时会把你推向分箱（自由度少、能逐箱辩护），在样本量大、只要精度时会把你推向样条或 GAM。它唯一不给答案的情形是关系非单调又要报送 —— 那时先分箱、再对箱的排序做单调性检查。

两个可复算的全例，外加一个 Yeo-Johnson 的手算小检查。所有数字用 Python（numpy）复算过，脚本逻辑写在每步里，读者照抄即可复现。

### 算例 1：Box-Cox 的 $\lambda$ 由数据定（n = 10，右偏小样本）

**第 1 步：看数据长什么样。** 10 笔赔款（千元）：

$$x = [1.2,\ 1.8,\ 2.5,\ 3.1,\ 4.0,\ 5.2,\ 7.5,\ 11.0,\ 18.5,\ 34.0]$$

均值 8.88、中位数 4.60（均值是中位数的 1.93 倍）、偏度 1.4116、$\sum \ln x = 16.709684$。典型的右偏：均值被最大的一笔拖着走。

**第 2 步：把轮廓似然在几个 $\lambda$ 上算出来。** 用 3.2.4 的公式 $\ell(\lambda) = -\frac{n}{2}\ln(\frac{1}{n}\sum (x_i^{(\lambda)}-\bar x^{(\lambda)})^2) + (\lambda-1)\sum \ln x_i$：

| $\lambda$ | $\bar x^{(\lambda)}$ | 平均平方离差 | 第一项 | 第二项 | $\ell(\lambda)$ |
|---|---|---|---|---|---|
| $-1.00$ | 0.713851 | 0.0577646 | 14.256894 | $-33.419367$ | $-19.162473$ |
| $-0.50$ | 1.026435 | 0.1967647 | 8.128735 | $-25.064525$ | $-16.935791$ |
| $0.00$ | 1.670968 | 0.9975269 | 0.012381 | $-16.709684$ | $-16.697303$ |
| $0.25$ | 2.271304 | 2.6653172 | $-4.901615$ | $-12.532263$ | $-17.433878$ |
| $0.50$ | 3.249322 | 7.9646199 | $-10.375046$ | $-8.354842$ | $-18.729888$ |
| $0.75$ | 4.915946 | 26.341108 | $-16.355654$ | $-4.177421$ | $-20.533075$ |
| $1.00$ | 7.880000 | 95.053600 | $-22.772205$ | 0.000000 | $-22.772205$ |
| $1.50$ | 23.856308 | 1516.227466 | $-36.619903$ | 8.354842 | $-28.265061$ |

读这张表只看两件事：$\lambda$ 从 1 往 0 走，第一项在往上抬（变换后方差变小），第二项在往下走（雅可比项在拉）。两项的拉锯在 $\lambda$ 略小于 0 的地方见顶。

**第 3 步：手算 $\lambda = 0$ 这一行，核对整条链。**

- $z = \ln x$ 的均值 $\bar z = 1.670968$；
- 离差平方和 $\sum (z_i - \bar z)^2 = 9.975269$，平均平方离差 $s^2 = 9.975269/10 = 0.997527$；
- 第一项：$-\frac{10}{2}\ln(0.997527) = -5 \times (-0.002476) = 0.012381$；
- 第二项：$(0-1)\times 16.709684 = -16.709684$；
- 合计 $\ell(0) = 0.012381 - 16.709684 = -16.697303$。

**第 4 步：搜出来的 $\hat\lambda$ 与它的证据够不够。**

细网格搜索（步长 $10^{-5}$）给出：

$$\hat\lambda = -0.1941,\qquad \ell(\hat\lambda) = -16.524358$$

做似然比：

$$2[\ell(\hat\lambda) - \ell(0)] = 0.3459,\qquad 2[\ell(0) - \ell(1)] = 12.1498$$

$\chi^2_1$ 的 95% 临界值是 3.8415。所以：**$\lambda = 0$（对数）与最优值没有显著差别**（0.346 < 3.84），而 **$\lambda = 1$（不做变换）被拒绝**（12.15 > 3.84，$p \approx 0.0005$）。结论不是「$\lambda$ 应该等于 −0.19」，而是「该做对数，做对数与最优的代价只有 0.173 个对数似然」。


**第 5 步：$\lambda$ 与偏度的对照（这就是「正态化」的实际速度）。**

| $\lambda$ | 1.00 | 0.50 | 0.25 | 0.00 | $-0.50$ |
|---|---|---|---|---|---|
| 变换后偏度 | 1.4116 | 0.9193 | 0.6229 | 0.3060 | $-0.3304$ |

偏度从 1.41 掉到 0.31 只用了 $\lambda = 0$ 一步；再往下压要把偏度推到负数（过校正）。想要「偏度最小」的读者注意：$\hat\lambda = -0.194$ 对应的偏度还会更低，但代价是尺度更难解释。

### 算例 1b：Yeo-Johnson 在含负值上的手算

取 $x = [-2, -1, 0, 1, 2]$，$\lambda = 0$：

| $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ |
|---|---|---|---|---|---|
| $\psi(x, 0)$ | $-4$ | $-1.5$ | $0$ | 0.693147 | 1.098612 |

负值段照 3.2.4 的公式：$x=-2 \Rightarrow -\frac{(1-(-2))^2-1}{2} = -4$；$x=-1 \Rightarrow -\frac{2^2-1}{2} = -1.5$。正值段就是 $\ln(1+x)$。检查 $\lambda = 1$：$\psi(x, 1) = x$，逐点成立（恒等映射）。Box-Cox 在这组数上无定义，说明「只有正数才行」是真的限制，只是有替代品。

### 算例 2：同一份数据上「原始尺度 / 对数 / 分箱」

**第 1 步：造一份能看出的数据（固定随机种子，可复现）。** 300 张保单，车辆价值 $x = e^{N(0,1)}\times 40$（偏度 4.5952，范围 3.07 – 737.11），真实关系是 $\text{logit}(p) = -0.7 + 1.6(\ln x - \ln 40)$。复现方式：`rng = np.random.default_rng(42)`，先抽 300 个 $x$，再用同一条随机流抽 300 个均匀数、与 $1/(1+e^{-\eta})$ 比较定出 $y$。抽出的样本出险 107 条（35.67%）。$\ln x$ 的偏度是 0.2904。

**第 2 步：三个模型并排比。**

| 模型 | 系数 | 对数似然 | 参数个数 | AIC | AUC |
|---|---|---|---|---|---|
| A：$y \sim x$ | $-1.84006$，$0.02247$（SE 0.00375） | $-160.5716$ | 2 | 325.1432 | 0.8270 |
| B：$y \sim \ln x$ | $-6.90918$，$1.67315$（SE 0.21748） | $-146.7125$ | 2 | **297.4251** | 0.8270 |
| C5：$y \sim$ 5 个分位箱 | 见下一步 | $-145.2139$ | 5 | 300.4278 | 0.8087 |

三件事同时发生：AIC 差 27.7（A 明显更差）；**AUC 一模一样**（0.8270）——因为 $x$ 与 $\ln x$ 是单调对应关系，排序根本不可能变；分箱的 AUC 反而掉了 0.018（箱内观测被压成同一个拟合值，产生并列）。

**第 3 步：5 个分位箱的明细（这一段可以完全手算）。** 每箱 60 条：

| 箱 | 样本量 | events | non-events | empirical logit $=\ln\frac{e+0.5}{o+0.5}$ | 箱内 $x$ 中位数 |
|---|---|---|---|---|---|
| 1 | 60 | 1 | 59 | $-3.68051$ | 11.96 |
| 2 | 60 | 13 | 47 | $-1.25804$ | 24.62 |
| 3 | 60 | 15 | 45 | $-1.07687$ | 36.67 |
| 4 | 60 | 33 | 27 | 0.19736 | 58.31 |
| 5 | 60 | 45 | 15 | 1.07687 | 127.67 |

**第 4 步：为什么分箱的系数就是「empirical logit 之差」（模型是饱和的）。** 单因子 + 全 dummy 的 logistic 是饱和模型，每个箱的拟合 log-odds 就等于该箱的 $\ln(e/o)$：$-4.0775,\ -1.2852,\ -1.0986,\ 0.2007,\ 1.0986$。以箱 1 为参照，系数应当是差值：

$$2.7923,\quad 2.9789,\quad 4.2782,\quad 5.1761$$

实际拟合出来的系数是 $2.79234,\ 2.97893,\ 4.27821,\ 5.17615$，逐位对上。这条校验的用处：看到一列箱系数，你能立刻反推箱内的 e/o，不用跑软件。

**第 5 步：empirical logit 指向哪个变换。** 五个箱的（平滑后）empirical logit 与箱中位数的相关系数是 **0.8509**，与 $\ln(\text{箱中位数})$ 是 **0.9715**；线性拟合的斜率分别是 0.033559 与 1.9643。上凸的形状配更高的对数相关系数 ⇒ 选对数，与第 2 步的 AIC 结论一致。**这就是 empirical logit plot 的全部工作方式：让曲率自己说该用哪把尺子。**

### 条件检验

**（i）换箱数。** 同一份数据、同一份伪随机序列，只改箱数：

| 箱数 | 每箱样本量 | 对数似然 | 参数个数 | AIC | AUC | 备注 |
|---|---|---|---|---|---|---|
| 3 | 100 | $-155.4104$ | 3 | 316.8208 | 0.7789 | 每箱 events 10 / 29 / 68 |
| 5 | 60 | $-145.2139$ | 5 | 300.4278 | 0.8087 | 见上表 |
| 10 | 30 | $-138.2499$ | 10 | **296.4997** | 0.8420 | **第 1 箱 0 事件 ⇒ 系数 27.8、SE 1.09e6** |
| 15 | 20 | $-137.0491$ | 15 | 304.0982 | 0.8432 | 第 1、3 箱 0 事件 ⇒ 系数 27.7 与 $-3.66$，SE 9.6e5 |

箱数从 3 涨到 10，对数似然一路改善，AIC 在 10 箱处甚至超过 $\ln x$（296.5 对 297.4）。**但 10 箱的系数是分离造出来的**：第 1 箱 30 条全是非事件，那个 dummy 的 MLE 不存在，软件给你 27.8 和一个 $1.09\times 10^6$ 的标准误。这就是「AIC 不能单独用」的具体样子 —— 换箱数时先看每箱的 events 数，再看指标。

**（ii）等宽 vs 等频。** 同一份数据改成等宽 5 箱（范围 734.04，箱宽 146.81，边界 149.88 / 296.69 / 443.50 / 590.31）：每箱样本量变成 275 / 18 / 4 / 1 / 2，AIC 从 300.4 掉到 377.69，AUC 从 0.809 掉到 0.5378 —— 比抛硬币还差。**等宽对右偏变量是灾难性的**：它把 92% 的样本塞进第一箱，剩下四个箱全靠 25 条记录估计。

**（iii）换样本量。** 同样的数据只留前 150 条、前 75 条：

| $n$ | 模型 A（$y\sim x$）AIC | 模型 B（$y\sim\ln x$）AIC | 5 箱 AIC | 每箱样本量 |
|---|---|---|---|---|
| 300 | 325.143 | 297.425 | 300.428 | 60 |
| 150 | 162.332 | 150.165 | 154.917 | 30 |
| 75 | 77.632 | 73.889 | 75.762 | 15 |

三个结论稳定：对数的 AIC 一直最低，分箱一直排第二，且样本越小分箱越吃亏（每箱 15 条时箱内 e/o 噪音很大）。$n = 75$ 时 $y \sim \ln x$ 的斜率涨到 2.21（全样本是 1.67），说明**样本量小的时候系数本身就不稳，别在这时候比 AIC 的第 3 位小数**。

**（iv）换 $\lambda$ 与换单位。**

| 改动 | $\hat\lambda$ | $\ell(\hat\lambda)-\ell(0)$ | 结论 |
|---|---|---|---|
| 原样本（n=10） | $-0.1941$ | 0.1730 | 对数与最优无显著差别 |
| 只留前 5 条（n=5） | 0.4733 | 0.0763 | 5 个数定不了 $\lambda$ |
| 去掉最大一笔（n=9） | $-0.1356$ | 0.0529 | 尾部不动，$\lambda$ 也不动 |
| 最大一笔 34 改成 120 | $-0.3562$ | 1.1342 | 一个极端点就能把 $\hat\lambda$ 推走 |
| 整份数据乘 1000 | $-0.1941$ | 0.1730 | **换单位不影响 $\hat\lambda$（雅可比项的作用）** |
| 平移 $+1$ 再用 Box-Cox | $-0.3919$ | — | 平移量在替 $\lambda$ 干活 |
| 平移 $+10$ 再用 Box-Cox | $-1.6365$ | — | 再平移就顶到网格边界（$-2$） |

最后两行就是不要「先搬正再用 Box-Cox」的量化理由：同一个变量，平移 1 让 $\hat\lambda$ 从 $-0.194$ 变成 $-0.392$，平移 10 变成 $-1.637$。$\lambda$ 的含义完全依附于你搬了多远。含负值的变量用 Yeo-Johnson。

## 五、什么情况下会失灵

### 承重假设一：关系是**单调**的

对数、幂、倒数这类解析变换都是单调函数，单调函数**不改变排序**，所以它救不了任何「先降后升」的形状。具体后果：年龄类的 U 形变量，empirical logit 掉下去又抬起来，硬套对数只会把两个不同的风险段压到同一个值上，模型欠拟合；这时唯一的路是分箱（阶梯）或样条（曲线）。本文算例 2 里 AUC 在两把尺子之间一动不动（0.8270），就是单调性的直接证据。

### 承重假设二：所有参数都**只在训练集里学过**

分箱边界、封顶分位点、Box-Cox 的 $\lambda$、WOE 的每箱 log-odds —— 全是学到的参数。在全量数据上算，或在测试集上重算，都是在把验证集的信息提前喂给训练。后果是留出集上的指标偏乐观、上线后回撤；正确做法是放进 pipeline，交叉验证时逐折重拟合（量化到具体哪一步，见 3.2.5 的两个要点）。

### 承重假设三：反变换仍然是**同一件事**

对 $\log y$ 建模再直接取指数，拿到的是中位数不是均值：$\sigma^2 = 1$ 时低估 39.3%（只拿到真均值的 60.65%）。要均值就得加 Duan smearing 那一乘子。这条在报费率时是真金白银：一个「对数 + OLS + 直接 exp」的严重度模型会系统性低报均值。GLM 的 log link 没有这个问题，因为它把 $\log E[Y]$ 直接当成建模对象。

### 承重假设四：$\lambda$ 与正态性检验用的是**同一份数据**

$\hat\lambda$ 是拿似然挑出来的，再用同一份数据做 Shapiro-Wilk 或 Q–Q 图，等于让数据出两次题、自己判卷，检验会偏乐观。想要可信的口径，把样本切开：训练集定 $\lambda$，留出集看正态性。同理，先试 3、5、10、15 箱再挑 AIC 最小的那个，也是在同一份数据上挑参数——条件检验表里 10 箱的 AIC（296.5）比 $\ln x$（297.4）还好，但那个「好」是挑出来的。

### 承重假设五：变量的定义域对得上

Box-Cox 要求 $x > 0$，且 $x \to 0^+$ 时 $\ln x \to -\infty$（0 值会让它炸）；含 0 或负值的变量只能用 Yeo-Johnson。对数变换在 $x$ 很小时放大噪音：赔款从 1 涨到 2（+100%）与从 100 涨到 101（+1%）在对数尺度上是同一件事，这在业务上常常不成立。

### 承重假设六：预测落在训练范围内

多项式在训练范围之外由最高次项主导，会剧烈摆动；自然三次样条在边界结点之外是线性的（这是它比普通三次样条稳的原因），但「线性」不等于「对」；分箱在训练范围之外没有箱可落，线上遇到超出末箱的取值必须单独定义动作（并到末箱、还是单开一箱）。这三条都要在交接文档里写明，否则线上第一笔超大额赔款就会撞上它。

### 与其他手段的边界

| 你想要的 | 用谁 | 为什么 |
|---|---|---|
| 一个能写进报告、能逐项辩护的解析式 | 对数 / Box-Cox / 简单幂 | 自由度少，系数含义清楚 |
| 逐箱报费率、业务能读 | 等频分箱（+ 单调性检查） | 每箱一个水平；代价是箱内信息被压平 |
| 只在意排名精度 | 样条 / GAM / GBM | 形状由数据定；可解释性让位 |
| 尾部单点不要捣乱 | 封顶（+ 超额层处理） | 行保留、影响力有界 |
| 类别变量进 GLM | WOE | 一列 log-odds，单调、防高基数 |
| 关系非单调又要报送 | 有监督分箱 | 阶梯能拐弯；但要做折外与单调性检查 |

## 六、常见误解

### 误解一：「做变换是为了让数据服从正态分布」

**错误想法**：跑完 Box-Cox 或对数，先看直方图「正态了没有」，正态了就认为处理完了。

**为什么容易这么想**：教材里 Box-Cox 举的例子常常是「把偏斜数据变成正态」，$\lambda$ 又是靠似然或正态性检验挑的，于是「正态」被当成了目的本身。

**错在哪一步**：搞混了**副产品**和**目标**。线性模型真正吃的假设是「在 link 尺度上关系是直线 + 残差同方差」；正态性只影响小样本下的区间与检验精度。算例 2 里，$\ln x$ 让 AIC 掉了 27.7（线性关系被修好），而模型对 $y$ 的分布假设一点没动；反过来，一个变量变换后很正态、但和 $Y$ 的关系是 U 形，变换仍然救不了它。判据应该是残差图与 AIC，不是直方图。

### 误解二：「变量有负值，就先加一个常数搬正，再跑 Box-Cox」

**错误想法**：$-2$ 不能取对数，那就整体加 3，全部变正，再照常做 Box-Cox。

**为什么容易这么想**：这是最省事的修补，代码只改一行，而且跑出来还能收敛、还能给出一个 $\lambda$。

**错在哪一步**：平移量不是无害的记帐，它在替 $\lambda$ 干活。第四节算过：同一份赔款数据，平移 1 让 $\hat\lambda$ 从 $-0.194$ 变成 $-0.392$，平移 10 变成 $-1.637$，平移 100 顶到网格边界 $-2$（数据全程没有变）。$\lambda$ 的解释依附于平移量，报出去没法辩护，模型比较也跟着失真。含负值的变量直接用 Yeo-Johnson：它的负值段就是这个问题的解，$\lambda = 1$ 时还是恒等映射，不会凭空造出尺度偏移。

### 误解三：「分箱一定损失信息，所以能不用就不用」

**错误想法**：连续变量信息更全，分箱只是把连续值粗糙化，属于妥协。

**为什么容易这么想**：分箱确实把箱内观测压成同一个值（并列值），AUC 的下降是可观测的 —— 算例 2 里从 0.827 掉到 0.809，像是一条「分箱更差」的明证。

**错在哪一步**：把「损失箱内分辨力」说成了「一定更差的模型」。算例 2 里 5 箱的对数似然是 $-145.21$，反而比 $\ln x$ 的 $-146.71$ 好（每箱一个水平，能容忍非单调）；它输在参数多（5 个对 2 个），AIC 才是 300.4 对 297.4。真正的判据是「箱数 × 每箱样本量 × 是否需要逐箱报费率」：要报送、要业务读，分箱的损失换来的可解释性是划算的；只要排名精度，连续或样条更好。

### 误解四：「变换是为了提高预测能力（AUC）」

**错误想法**：跑完变换先看 AUC，没涨就认为这个变换没用。

**为什么容易这么想**：AUC 是最常报的指标，而变换又确实常常「让模型看起来更好」，于是两者被直接挂钩。

**错在哪一步**：单调变换不改变单变量排序，AUC 在 $x$ 与 $\ln x$ 之间必然完全相同（0.8270 对 0.8270）。变换改的是**尺度上的线性**，影响的是系数大小、标准误、AIC、以及「系数能不能解读成边际效应」。所以评估变换该看 AIC / 对数似然 / 残差结构，AUC 只用来确认没有把排序弄坏（算例 2 里分箱的 AUC 掉 0.018，正是排序被并列值弄坏的信号）。

### 误解五：「$\lambda$ 只有 0、0.5、1 这些有名字的值可用」

**错误想法**：选 $\lambda$ 就是在「对数、平方根、不变换」里挑一个；$\hat\lambda$ 落在两个有名字的值中间，说明数据有问题。

**为什么容易这么想**：教材常常只列一张对照表（$\lambda = 0$ 是 log、$\lambda = 0.5$ 是平方根、$\lambda = 1$ 是原始数据），看起来像离散的菜单。

**错在哪一步**：$\lambda$ 是连续参数，由轮廓似然定，任何实数都合法。本篇的 $\hat\lambda = -0.1941$ 落在 $-0.5$（倒数平方根）与 $0$（对数）之间，这完全正常；真正该做的是做似然比：它与 $\lambda = 0$ 的差别是 0.346（$\chi^2_1$ 临界 3.8415，不显著），与 $\lambda = 1$ 的差别是 12.15（显著拒绝）。**选 $\lambda$ 时要在拟合等价的那一档里挑最好解释的**，这就是本篇选对数的理由。

## 七、面试怎么答

### 30 秒版

> 变换的作用是让「link 尺度上的关系是直线」这条假设重新近似成立。判断顺序是先画图：二分类画 empirical logit plot，连续目标画分箱均值-响应图。形状单调但弯曲就换尺度（对数、幂、Box-Cox），形状掉头就往分箱或样条走，类别变量用 WOE 或 dummy。参数（$\lambda$、箱边界、封顶点）全部在训练集里学。反变换要记得修偏，直接取指数拿到的是中位数。

### 2 分钟版（四块）

1. **什么时候需要**：残差 vs 拟合值有弯曲、残差 vs 变量有漏斗形、单变量偏度过大、或者模型已经很复杂但拟合仍然差。三样里最有力的是残差的形状，因为它直接对着「加性直线」这条假设。
2. **选哪一把尺子**：先用 empirical logit plot（或连续版的箱均值图）看曲率。单调弯曲 ⇒ 对数或幂变换，让似然去定 $\lambda$（要正数用 Box-Cox，含负值用 Yeo-Johnson）；要业务逐箱读 ⇒ 等频分箱；弯曲但要让曲线自己说话 ⇒ 自然三次样条或 GAM；类别 ⇒ WOE（高基数）或 dummy（低基数）。
3. **算一遍的量级**：300 张保单、车辆价值右偏时，「原始尺度」的 AIC 是 325.1，「对数尺度」是 297.4，差 27.7；5 个分位箱的对数似然更好（$-145.2$ 对 $-146.7$）但参数多，AIC 反而更差（300.4 对 297.4）。箱子加到 10 个，第 1 箱全是非事件，系数被推到 27.8、标准误 1.09e6 —— 这时候指标好看也不能用。
4. **坑**：反变换有偏（$\sigma^2=1$ 时直接 exp 低估均值 39.3%），所以保险里用 log link 的 GLM 而不是「先取对数再 OLS」；分箱边界、封顶分位点、$\lambda$ 都是学到的参数，全量数据上算就是泄漏；单变量的单调变换不改变 AUC，别用它评估变换。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「怎么判断该不该变换？」 | 残差 vs 拟合值 / 残差 vs 变量；二分类用 empirical logit plot（十分位 + 加 0.5 平滑），曲率形状直接告诉你用哪个变换；U 形说明单调变换没戏 |
| 「为什么用对数而不是平方根？两者都压右尾」 | 看 empirical logit 的相关：算例 2 里与箱中位数的相关是 0.851、与 $\ln$（箱中位数）是 0.972 ⇒ 对数更直。经验上赔款/金额类变量先试对数 |
| 「分箱和样条怎么选？」 | 报送、要逐箱读 ⇒ 分箱（等频，先查每箱 events 数）；要连续光滑、不介意解释成本 ⇒ 自然三次样条 / GAM |
| 「λ 怎么定？」 | 轮廓似然最大化（含雅可比项），或者直接报告对数这一档：算例里 $2[\ell(\hat\lambda)-\ell(0)] = 0.346 < 3.84$，与 $\lambda=0$ 无显著差别 |
| 「分箱边界会泄漏吗？」 | 会，和均值填充、封顶分位点一样是学到的参数，必须逐折重拟合；WOE 还要再加折外编码 |
| 「反变换要注意什么？」 | $E[g(Y)] \neq g(E[Y])$：直接 exp 给中位数，均值要 Duan smearing；GLM 的 log link 直接建 $\log E[Y]$，没有这个问题 |
| 「变换能提高 AUC 吗？」 | 单变量单调变换不能（排序不变，AUC 都是 0.8270）；它改的是系数尺度、SE 与 AIC |
| 「负值怎么办？」 | Yeo-Johnson（$\lambda=1$ 是恒等，两段在 0 处连续）；不要先加常数搬正，平移量会顶替 $\lambda$ |
| 「多项式为什么不直接用？」 | 全局假设、外推摆动、未中心化时 $x$ 与 $x^2$ 高度相关（VIF 被机械抬高）；要灵活用自然样条 |
| 「GAM 和 GLM、GBM 怎么选？」 | 弯曲 + 要报送 ⇒ GAM / 自然样条；纯预测 ⇒ GBM；线性够用 ⇒ GLM。GAM 默认可加，抓不到交互 |

### Q: What is capping/flooring and why do it?

> 🎯 真题问法（MAGNet §2「What is capping/flooring and why do it?」）｜ 深潜来源：MAGNet §2 capping / leakage 段；本笔记「三、机制 3.2.5 封顶 / 保底：Winsorisation」（公式、实现、示例的完整细节）

> Winsorizing —— 把高百分位以上的值替换成那个百分位的值，低百分位以下同理。**行保留、极端值对拟合的影响力被限住。**

**典型切点（三种选法各有一句）**

- **1st/99th 或 5th/95th 百分位**：最常用的默认档。
- **在拟合关系明显变平处封顶**：用 empirical plot / 残差 LOESS / GAM / PDP 找拐点，拐点之外变量几乎没有信息量。
- **按业务定义的限额**：保单限额（policy limit）、承保上限、再保分层点。

**为什么做**

- 限定**杠杆（leverage）与影响（influence）** —— 不再让一个极端点单独决定斜率。
- **不必删行**（不同于 trimming 截断：删行丢样本，且未必是随机丢的）。
- **保护你在打分（scoring）时不受训练数据范围之外的取值影响**：线上进来一个训练中从未见过的超大值，模型行为仍然有界。

**保险专属**

- **大额损失封顶（cap large losses）**，避免**单笔巨灾索赔主导严重度（severity）系数** —— Gamma / 对数正态类的严重度模型对极端值极其敏感。
- 但**被封顶的那部分不能凭空消失**：要**单独处理为超额层（excess layer）**（如再保超额）或计入**巨灾附加（cat load）**，否则费率系统性偏低。

**陷阱（会被扣分的那条）**

- **封顶的百分位点是从训练数据学到的参数**：在**全量数据上算**、或在**测试集上重算**，都是**泄漏（leakage）**。正确做法：在训练集 / 训练折内拟合边界，然后套用到验证 / 测试 / 生产；在 CV 里它属于 pipeline 的每一步，每折重拟合。

> ⚡ 先说的那一句
>
> "Capping means I replace anything above the 99th percentile with that percentile's value, and do the same at the bottom — I keep every record but stop one extreme value from driving the fit. In insurance I cap large losses so a single catastrophe claim doesn't set the severity coefficient, and I handle the excess separately as an excess layer or a cat load."

> 🔗 会被追问到
>
> - 「1/99 还是 5/95 怎么选？」→ 看尾部有多重、尾部有多少条记录、封顶后关系是否已经变平；再在留出集上比较 Gini / A/E。
> - 「封顶点会泄漏吗？」→ 会：它和均值填充、标准化、PCA 一样是**从数据学到的参数**，必须训练集内学、全流程套用。
> - 「为什么不用 log 变换代替封顶？」→ log 压缩尾部但不设上界、且改变整个尺度上的形状；封顶只动尾部、保留原尺度解释，两者常一起用。
> - 「被封顶掉的损失去哪了？」→ 单独进超额层 / 巨灾附加 / 单独建模，不能悄悄丢掉。

### Q: Splines and GAMs - what are they and when do you reach for them?

> 🎯 真题问法（MAGNet §2「Splines and GAMs - what are they and when do you reach for them?」）｜ 深潜来源：MAGNet §2；本笔记「三、机制 3.2.2 样条」（基函数细节）与「三、机制 · 看目标的方法 · Generalized Additive Models (GAM) Smoothing」（backfitting / GCV）

> 一句话先给：**样条（spline）是在结点（knots）处光滑拼接的分段多项式；GAM 是把 GLM 里每个变量的一项系数换成一条光滑函数 $f_j(x_j)$。** 前者是变换工具，后者是模型族。

**三种样条（各说一句区别）**

- **回归样条（regression spline）**：**固定结点**，用最小二乘 / MLE 拟合 —— 它仍然是线性模型，只是基函数变多了。**结点数量与位置控制灵活度**：结点越多越灵活、越容易过拟合。
- **自然三次样条（natural cubic spline）**：三次样条 + **在边界结点之外为线性**的约束。尾部行为远好于原始多项式（多项式在两端会剧烈摆动），**通常是最佳默认**。
- **平滑样条（smoothing spline）**：**每个点都放结点**，再加一个**粗糙度惩罚（roughness penalty）** 控制摆动；**平滑参数 $\lambda$ 由广义交叉验证（GCV）选**。

**GAM**

$$g(E[Y]) = \beta_0 + f_1(x_1) + f_2(x_2) + \cdots$$

- **仍然是可加的（additive）**：所以可以画出每个变量的效应曲线给监管 / 业务看 —— **保留 GLM 的可解释性故事，同时放弃线性要求**。
- **不加张量积 / 交互平滑（tensor / interaction smooths）就抓不到交互** —— 这是 GAM 与 GBM 最大的能力差。
- 常见实现：R `mgcv::gam` 的 `s( )`，Python `pygam`；估计用 backfitting 或惩罚似然。

**什么时候用**

- 关系明显弯曲（empirical plot 有曲率、U 形，或残差里仍有结构）；
- 需要可解释性（每个变量一条能画出来的效应曲线）；
- 想要**单调或形状约束（monotone splines / shape-constrained GAMs）** —— 监管友好。

**要主动说的取舍**

- **GAM 站在 GLM 与 GBM 之间**：比 GLM 灵活、比 GBM 可解释且可加约束（单调性、凸性），**但它不会替你找交互**。默认这样分：关系弯曲 + 要报送 ⇒ GAM / 自然样条；只要排名精度、不在意解释 ⇒ GBM。

> ⚡ 先说的那一句
>
> "A spline is a piecewise polynomial joined smoothly at knots — I'd default to a natural cubic spline, because it's linear beyond the boundary knots so the tails behave. A GAM is just a GLM where each variable gets a smooth function instead of a single coefficient, so I keep the interpretability — I can plot each effect for a regulator — while dropping the linearity assumption. The catch is it's still additive: it won't find interactions unless I add them explicitly."

> 🔗 会被追问到
>
> - 「结点放几个、放哪里？」→ 常用分位数放置；结点数用 CV / GCV / AIC 选，太少欠拟合、太多过拟合且尾部不稳。
> - 「为什么自然样条比普通三次样条好？」→ 边界之外强制线性 ⇒ 尾部不爆炸，这就是它成为默认的原因。
> - 「GAM、GLM、GBM 怎么选？」→ 可解释 + 形状约束 → GAM；纯预测 → GBM；线性已够、报送最简 → GLM。
> - 「GAM 能外推吗？」→ 自然样条在边界结点之外是线性的，其它基不确定 —— 外推是弱点，要主动说。
> - 「平滑参数 $\lambda$ 怎么定？」→ GCV / REML，本质是同一套偏差-方差权衡。

## 🗣️ 英文表达 / How to Say It

**When do you need a transformation**

> "I look at the shape first — residual plots, and for a binary target an empirical logit plot on deciles. If the relationship bends but stays monotone, a log or a power transform fixes it; if it turns around, no monotone transformation will help, so I go to binning or splines. I pick the power by profile likelihood, but if zero is within the confidence interval I report the log because people can interpret it."

**The numbers I actually say out loud**

> "On three hundred policies, regressing the claim indicator on vehicle value directly gave an AIC of three hundred twenty-five; on the log of vehicle value it was two hundred ninety-seven, so the log is worth twenty-eight AIC points. Five quantile bins fit the likelihood slightly better but cost four extra parameters, so their AIC is worse, and by ten bins the first bin has no events at all — the coefficient blows up and the standard error is meaningless."

**If they push back**

> "Two things I'd flag. Back-transforming a log fit gives you the median, not the mean — with a residual variance of one you're about forty percent below the mean unless you apply Duan's smearing. And every one of these knobs — the power, the bin edges, the capping percentile — is a parameter learned from data, so it has to be fit inside the training fold. One caveat on evaluation: a monotone transformation doesn't change the ranking, so AUC stays identical; it's AIC and the residual structure that tell you whether the transform helped."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 变换 | transformation | 建模前作用在 $X$ 或 $Y$ 上的数学运算 |
| 分箱 | binning | 把连续变量切成区间；无监督（等宽 / 等频）或看目标 |
| 等宽分箱 | equal-width binning | 箱宽相同，对离群值敏感 |
| 等频分箱 | quantile binning | 每箱样本量相同，边界未必有业务意义 |
| 回归样条 | regression spline | 固定结点的分段三次多项式 |
| 自然三次样条 | natural cubic spline | 边界外线性，自由度 $m$ |
| 平滑样条 | smoothing spline | 每个点放结点 + 粗糙度惩罚，$\lambda$ 由 GCV 选 |
| 结点 | knot | 分段多项式的拼接点 |
| 多项式项 | polynomial term | $x, x^2, \dots$；共线与外推是主要风险 |
| 幂变换 | power transformation | $x^{(\lambda)} = (x^\lambda-1)/\lambda$，$\lambda=0$ 即对数 |
| Box-Cox 变换 | Box-Cox transformation | 要求 $x>0$；$\lambda$ 用轮廓似然估 |
| Yeo-Johnson 变换 | Yeo-Johnson transformation | Box-Cox 的扩展，含负值可用，$\lambda=1$ 为恒等 |
| 轮廓似然 | profile likelihood | 固定 $\lambda$ 后把其余参数消掉再比似然 |
| 雅可比项 | Jacobian term | $(\lambda-1)\sum\ln x_i$，让 $\lambda$ 与单位无关 |
| 封顶 / 保底 | winsorisation / capping | 尾部分位点截断，行保留 |
| 截断 | trimming | 直接删行（与封顶相对） |
| 超额层 | excess layer | 被封顶那部分的去处，不能凭空消失 |
| 反变换 / 涂抹校正 | back-transformation / Duan's smearing | 取指数只给中位数，均值要加乘子 |
| 虚拟变量编码 | dummy coding | $k$ 类造 $k-1$ 列，系数相对参考水平 |
| 证据权重 | weight of evidence (WOE) | $\ln(\%\text{Goods}/\%\text{Bads})$，一列单调编码 |
| 信息值 | information value (IV) | $\sum \text{WOE}\times(\%\text{Goods}-\%\text{Bads})$，筛选排序用 |
| 广义可加模型 | generalized additive model (GAM) | 每个变量一条光滑函数，仍可加 |
| 后向拟合 | backfitting | GAM 的迭代估计：逐项拟合残差 |
| 广义交叉验证 | generalized cross-validation (GCV) | 选平滑参数的廉价近似 |
| 经验 logit 图 | empirical logit plot | 十分位箱内 $\ln\frac{e+0.5}{o+0.5}$ vs 箱均值，识别变换的主力工具 |
