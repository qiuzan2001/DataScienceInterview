# 1.2 广义线性模型（Generalized Linear Models, GLMs）

## 速览 At a glance

**速记**

手里的目标都不是连续对称的：续保率卡在 0 和 1 之间，月出险次数只能取非负整数，单次赔付额右偏、最小值也是正的。OLS 的「一条直线 + 常数方差」在这三类数据上都站不住 —— 直线会给出负的预测均值，常数方差又和它们真实的方差结构对不上。GLM 把模型拆成三块：先指定 $Y$ 属于指数族的哪个分布（伯努利方差 $p(1-p)$、泊松方差 $\mu$、Gamma 方差 $\phi\mu^2$），再用单调的连接函数把均值接到线性预测子 $X\beta$ 上（计数和金额用 log，二值用 logit），最后用最大似然拟合，IRLS 每一步等价于一次加权最小二乘。log link 让模型在原始尺度上乘性可加，系数直接读成费率乘数，所以保险定价一直在用它。最常见的选错方向是计数过散布：系数不明显偏，标准误偏小 —— 方差是均值的 1.8 倍时 SE 小 1.34 倍，$t$ 检验从 2.40 掉到 1.79。

**一句面试答法**

> "A GLM has three parts — a distribution from the exponential family that fixes how the variance moves with the mean, a linear predictor, and a link function that maps the mean onto the real line — so one set of formulas covers counts, binary outcomes and pure premium."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 指数散布族 | exponential dispersion family | 把密度写成 `exp((yθ−b(θ))/φ + c(y,φ))` 的一族分布 |
| 典则参数 | canonical parameter | `θ`，指数族里控制均值位置的那个参数 |
| 归一化函数 | normalization function | `b(θ)`，保证概率加总为 1 |
| 离散参数 | dispersion parameter | `φ`，给方差做整体缩放；泊松与伯努利里等于 1 |
| 方差函数 | variance function | `V(μ)`，分布自带的「方差怎么随均值变」的规则 |
| 连接函数 | link function | `g(μ) = η`，把受限的均值接到整条实轴 |
| 典则连接 | canonical link | 取 `g(μ) = θ` 的那个 link，score 方程最干净 |
| 线性预测子 | linear predictor | `η = Xβ` |
| 迭代再加权最小二乘 | iteratively reweighted least squares (IRLS) | 每步做一次加权 OLS 的拟合算法 |
| 过散布 | overdispersion | 实际方差大于分布假设，计数数据里常见，`φ > 1` |
| 费率乘数 | relativity | log link 下 `exp(β)` 就是乘上去的那个因子 |
| 纯保费 | pure premium | 频率 × 严重度，Tweedie 的建模对象 |

## 一、先看一个问题

这一篇对应的真题问法就是 **"Which distribution would you pick for an insurance target?"** —— 面试官随手给你一个建模目标，让你当场说清用哪个分布、哪个 link。

具体场景：一家车险公司给你 1000 张保单三年的记录，让你建三个模型。

| 目标 | 数据长什么样 | 用 OLS 会卡在哪 |
|---|---|---|
| 每个月有没有出险 | 36,000 行 0/1，其中 1,260 行是 1（3.5%） | 直线给出的预测值会小于 0 或大于 1 |
| 每张保单每年的出险次数 | 均值 0.35 次，样本方差 0.63 | 预测出 −0.4 次这种没有意义的期望次数 |
| 单次赔付金额 | 中位数 8,200 元，均值 21,000 元，最小值 300 元 | 5 万元的赔案和 3 千元的赔案被当成同一个 $\sigma^2$ |

三行卡在同一处：OLS 只有一种方差结构（$\sigma^2$ 是常数），而这三个目标的方差都跟着均值走 —— 3.5% 的概率对应方差 $0.035\times0.965 = 0.0338$，0.35 次的均值对应方差 0.35，21,000 元的均值对应的标准差是 18,783 元。

这句话背后在考什么：能不能把「Y 是什么」翻译成**一对（分布, link）**，并说清换掉其中一个会坏在哪里。只背出三块积木的名字不够 —— 面试官下一句通常就是「计数能不能用 identity link」。

## 📖 标准定义

> **教材原文 · LDA §8.4 Further Resources and References + LDA 词汇表（glossary）条目 "generalized linear model"**（<https://openacttexts.github.io/Loss-Data-Analytics/ChapRiskClass.html>）
> > "Poisson regression is a special member of a more general regression model class known as the generalized linear model (GLM). The GLM develops a unified regression framework for datasets when the response variables are continuous, binary or discrete. The classical linear regression model with a normally distributed error is also a member of the GLM."
> >
> > "… an extension of the linear regression model where the dependent variable is a member of the linear exponential family. glm encompasses linear, binary, count, and long-tailed, regressions all as special cases."

**标准记法**：

- 三要素（通用形式）：随机成分 $Y_i \sim$ 指数散布族（exponential dispersion family），$\mathrm{E}[Y_i] = \mu_i$，$\mathrm{Var}(Y_i) = \phi V(\mu_i)$；系统成分（线性预测子）$\eta_i = x_i^t \beta$；连接函数 $g(\mu_i) = \eta_i$。
- 常见组合：Normal 恒等连接、Bernoulli logit 连接、Poisson/NB log 连接、Gamma 倒数连接、Tweedie（复合 Poisson–Gamma）log 连接。

**中文解释**：GLM 是把线性回归推广到「响应变量属于指数散布族」的统一框架：随机成分给定分布（方差随均值变化 $\text{Var}=\phi V(\mu)$），系统成分是线性的 $x^t\beta$，两者用连接函数 $g$ 相连（count 用 log、binary 用 logit）。线性回归是它的特例。保险里频率（Poisson/NB）、严重度（Gamma）、纯保费（Tweedie）都用它。

> 完整条目与更多来源见 [[定义原文库#F28. GLM 框架|F28 GLM 框架]]

## 二、核心直觉

### 三站流水线

GLM 把「用线性模型去拟合一个受限的均值」拆成三站：

| 站 | 管什么 | 换成 GLM 之后 |
|---|---|---|
| 分布（随机成分） | 观测量是什么形状的量、方差怎么随均值变 | 从「永远 Normal、方差常数」变成按 $Y$ 的类型挑 |
| 系统成分 | 特征怎么进来 | 不变：$\eta = X\beta$ |
| 连接函数 | 均值与 $\eta$ 之间那把尺子 | 从 identity 换成 log / logit 等 |

关键是**分布和 link 可以分开挑**。OLS 把两件事绑死了：Normal 带着常数方差、identity 带着无界的均值，于是二值目标和计数目标一进来就撞墙。GLM 把这两个选择解开，于是你可以在「方差随均值平方增长」的 Gamma 上用 log link，也可以在「方差随均值线性增长」的 Poisson 上用 log link。

**类比的边界**：像装水管 —— 分布是管径，决定波动多大；link 是接头，把不同口径的管子接到同一套螺纹（那条实数轴）上。不像的地方在于：接头不改变流量，link 也不改变数据里的信息量，它改变的是「线性」发生的位置。同一份数据换 link，系数换一批数字，拟合优度却可能差不多。

**一句口诀：分布管方差，link 管均值的尺度。**

| 目标 | 分布 | $V(\mu)$ | link | $\exp(\beta)$ 读作 |
|---|---|---|---|---|
| 续保 / 欺诈（0/1） | Bernoulli | $\mu(1-\mu)$ | logit | odds 倍数 |
| 出险次数 | Poisson（过散布时 NB） | $\mu$ | log | 频率乘数 |
| 赔付金额 | Gamma | $\phi\mu^2$ | log（不用 inverse） | 金额乘数 |
| 纯保费（0 + 正尾） | Tweedie（$1<p<2$） | $\phi\mu^{p}$ | log | 纯保费乘数 |
| 连续对称量 | Normal | $\phi$（常数） | identity | 加一个单位 |

GLM 的本质，是把 OLS 那套「一条直线打天下」的假设换成三块积木：

1. 给响应 $Y$ 指定一个**指数族分布（exponential-family distribution）**。
2. 用一个**连接函数（link）**把 $Y$ 的均值接到线性预测子 $X\beta$ 上。
3. 用一套估计流程（通常是最大似然 maximum likelihood）把「正规方程」推广出去。

## 三、机制

### 3.1 指数族形式（Exponential-Family Form）

指数族里的任何分布（Gaussian、binomial、Poisson、Gamma 等）都可以写成

$$
f(y;\,\theta,\phi)
= \exp\!\Bigl(\,\frac{y\,\theta - b(\theta)}{\phi} \;+\; c(y,\phi)\Bigr).
$$

* **典则参数（canonical parameter）** $\theta$：控制 $Y$ 的位置 / 均值。
* **归一化函数（normalization function）** $b(\theta)$：保证密度（或概率）加总为 1。
* **离散参数（dispersion parameter）** $\phi$：缩放方差（很多 GLM 里 $\phi$ 已知或直接取 1）。

#### 为什么要写成这个形式？

1. **它统一了很多分布。**

   * **Gaussian** $\bigl(Y\sim N(\mu,\sigma^2)\bigr)$
     $\theta = \mu,\;\; b(\theta)=\tfrac12\theta^2,\;\; \phi=\sigma^2$.
   * **Binomial** $\bigl(Y\sim \text{Binomial}(n,p)\bigr)$
     $\theta=\log\!\tfrac{p}{1-p},\;\; b(\theta)=n\log(1+e^\theta),\;\;\phi=1$.
   * **Poisson** $\bigl(Y\sim\text{Poisson}(\lambda)\bigr)$
     $\theta=\log\lambda,\;\; b(\theta)=e^\theta,\;\;\phi=1$.

2. **矩可以从导数直接读出。**

   * 均值：
     $$
       \mu = E[Y] = b'(\theta).
     $$
   * 方差：
     $$
       \operatorname{Var}(Y) = \phi\,b''(\theta).
     $$

   **读这两行**：只要知道 $b(\cdot)$ 和 $\phi$，你立刻就知道「波动如何随 $\theta$ 变化」。这就是 GLM 能用同一套推导同时覆盖 Normal / Binomial / Poisson 的原因，也是面试里「为什么要有 $b(\theta)$」的标准答案。

**关键一步（均值为什么等于 $b'(\theta)$）**：把指数族密度取对数，

$$
\log f(y;\,\theta,\phi) = \frac{y\,\theta - b(\theta)}{\phi} + c(y,\phi).
$$

对 $\theta$ 求导得 $(y - b'(\theta))/\phi$。似然的一阶条件要求这个导数的期望为 0（score 的均值必为 0），而 $E[Y]=\mu$，于是

$$
\mu = b'(\theta).
$$

转念的地方就在这一步：**归一化函数 $b(\theta)$ 的一阶导直接把均值交出来了**，不用对每个分布单独推一遍。再对 $\theta$ 求一次导，同时用上 $\mu$ 与 $\theta$ 的对应关系，就得到 $\operatorname{Var}(Y) = \phi\,b''(\theta)$。

---

### 3.2 连接函数（Link Function）

我们要建模的是**均值** $\mu = E[Y]$ 如何依赖预测变量 $X$。在 OLS 里我们直接写

$$
\mu = X\beta.
$$

在 GLM 里，我们引入一个**连接（link）** $g$，使得

$$
g(\mu) \;=\; \eta \;=\; X\beta,
$$

其中 $g$ 是光滑的、单调的函数。

* **为什么不直接对 $\mu$ 建模？**

  1. 有时 $\mu$ 本身带约束（例如概率要求 $0<p<1$，计数要求 $\mu>0$）。
  2. 非线性的 $g$ 可以稳定方差，或者让似然的形式更简洁。

#### 典则连接（Canonical Link）

**典则连接（canonical link）**取 $g(\mu)=\theta$。又因为 $\mu = b'(\theta)$，这等价于

$$
\theta = g(\mu).
$$

这样选的好处：

* 最大似然的 score 方程会化简 —— 有一个和 OLS 正规方程对应的干净形式。
* 迭代再加权最小二乘（iteratively reweighted least squares, IRLS）成为自然的拟合算法。

**典则连接的例子**

| 分布（Distribution） | $\theta$ (canonical) | $g(\mu)$ | 解读（Interpretation） | 典型用途（Used for） |
| ------------ | -------------------- | -------- | -------------- | ------------------- |
| **Normal** (Gaussian) | $\mu$ | identity $g(\mu)=\mu$ | 退化回 OLS（recovers OLS） | 连续、对称（continuous, symmetric） |
| **Binomial** | $\log\frac{p}{1-p}$ | logit $g(p)=\log\frac{p}{1-p}$ | 把 $(0,1)\to\mathbb R$ 摊到整条实轴 | 二分类 / 比例（binary / proportion） |
| **Poisson** | $\log\lambda$ | log $g(\mu)=\log\mu$ | 保证 $\mu>0$ | 计数、频率（counts, frequency） |
| **Gamma** | $-\frac{1}{\mu}$ | inverse $g(\mu)=\frac{1}{\mu}$（实践中用 **log**） | 正数、右偏；$V(\mu)\propto\mu^{2}$ | 严重度、正偏（severity, positive-skewed） |
| **Inverse Gaussian** | $-\frac{1}{2\mu^{2}}$ | **$g(\mu)=\frac{1}{\mu^{2}}$**（实践中用 **log**） | 尾部更重；$V(\mu)\propto\mu^{3}$ | 尾部更重的严重度（heavier-tailed severity） |
| **Tweedie**（$1<p<2$） | $\frac{\mu^{1-p}}{1-p}$ | 一般不写 canonical link，**固定用 log** $g(\mu)=\log\mu$ | 0 处有**点质量（point mass）** + 连续正尾 | 纯保费 / 损失成本（pure premium / loss cost） |

> 💡 **点睛：log link 让模型在原始尺度上是乘性的（multiplicative）。** 当 $g(\mu)=\log\mu$ 时
> $$\mu \;=\; e^{\beta_0+\beta_1x_1+\beta_2x_2+\cdots} \;=\; e^{\beta_0}\cdot e^{\beta_1x_1}\cdot e^{\beta_2x_2}\cdots$$
> 也就是**基准费率 × 因子 × 因子** 的**评级计划（rating plan）**结构 —— 这正是 **log link 在保险定价里占主导**的原因：每个系数对应一个**乘数（relativity）**，费率表可以直接拼出来。面试时把这句话讲出来，比只背表格得分高得多。
>
> ⚠️ Gamma / Inverse Gaussian / Tweedie 的 canonical link（inverse、$1/\mu^{2}$、无简洁闭式）会让线性预测子与 $\mu$ **反向**行走、且系数不可解释，所以**实践中一律换成 log link**（MAGNet 原表括号里的意思）。
>
> 来源：MAGNet §1（link function / canonical links 表）；[[MAGNet 面试真题全解]]

### 3.3 五步配方与口径（Putting It All Together）

1. **选分布**
   – 依据 $Y$ 是连续（Gaussian）、二值（Bernoulli/binomial）、计数（Poisson）、正偏（Gamma）等。

2. **写出指数族形式**
   – 认准 $\theta$、$b(\theta)$ 和 $\phi$。
   – 记住 $E[Y]=b'(\theta)$、$\operatorname{Var}(Y)=\phi\,b''(\theta)$。

3. **指定线性预测子**

   $$
     \eta = X\beta.
   $$

   （和 OLS 一样：特征的加权和。）

4. **选连接函数**

   $$
     g\bigl(E[Y]\bigr) = \eta.
   $$

   – 通常用典则连接 $g(\mu)=\theta$。
   – 也可以选别的（例如二值结果改用 probit link，如果你更喜欢基于 Normal 的推断）。

5. **用最大似然（IRLS）估计**

   * 从指数族形式导出 log-likelihood。
   * 令它的导数（「score」）为零 —— 这一步会给出加权最小二乘的迭代步。
   * 反复迭代直到收敛。

> 🎯 **面试官会追问「link 和分布能不能随便搭」**：不能随便搭，但也不是唯一 —— 二值结果可以 logit / probit / cloglog；计数可以 log / identity（identity 会给出负的预测均值，实务上不用）。**分布决定方差函数，link 决定均值的尺度**，两个选择要各自说清理由。

---

#### 为什么 GLM 重要（Why GLMs Matter）

* **灵活（flexibility）：** 很多种结果类型都能放进同一把伞下。
* **可解释（interpretability）：** 系数 $\beta$ 仍然描述预测变量如何推动 link（进而推动均值）。
* **有效（efficiency）：** 分布形式配对正确，推断（标准误、检验）才成立。

---

#### 从 OLS 到 GLM 的逻辑流（Logical Flow from OLS to GLM）

1. **OLS** 假设 Normal + identity link ⇒ 方差恒定 + 结果无界。
2. **GLM** 丢掉「永远 Normal」⇒ 允许方差随 $\mu$ 变化（通过 $b''(\theta)$）。
3. **连接函数**把受限的 $\mu$ 变换到 $\mathbb R$，使线性模型在 $\mu$ 受限时依然说得通。
4. **典则连接**让数学几乎和 OLS 一样干净 —— 只是权重变成由数据驱动、反映每个观测自己的方差。

[[1.7 Assumptions]]

> 🎯 **面试官会追问「GLM 最容易在哪一步出错」**：一是分布或 link 选错（例如纯保费用 identity link），会让预测均值跑出合法范围；二是把 GLM 当成「自动处理非线性」—— 它只保证**在 link 尺度上线性**，真正的非线性仍要靠变量变换或 spline。细节见 [[1.7 Assumptions]]。

## 四、算一遍

拿「每张保单每年的出险次数」走完全程：选分布、算费率乘数、再看选错分布要付多少代价。全部数字下面都自己验算过一遍。

### 第 1 步：先看均值和方差，决定分布

1000 张保单的三年记录，摊平后每张保单每年算一条：

| 统计量 | 数值 |
|---|---|
| 平均出险次数 $\bar y$ | 0.35 次/年 |
| 样本方差 $s^2$ | 0.63 |
| $s^2/\bar y$ | **1.80** |

**为什么先算这两行**：Poisson 只有一个参数，方差必须等于均值（$V(\mu)=\mu$）。这里 $s^2/\bar y=1.80$，说明数据是**过散布（overdispersed）**的，真实模型更接近负二项。先用 Poisson 走一遍，第 4 步再算这个假设错了要付多少代价。

### 第 2 步：log link 下的乘性费率链

拟合出 $\log \mu = -1.20 + 0.20\cdot\text{折扣} + 0.35\cdot\text{城市组}$：

| 项 | 系数 | $\exp(\beta)$ | 读作 |
|---|---|---|---|
| 截距 $\beta_0$ | −1.20 | **0.3012** | 基准频率 0.3012 次/年 |
| 折扣 $\beta_1$ | +0.20 | **1.2214** | 有折扣的车是没折扣的 1.2214 倍（+22.1%） |
| 城市组 $\beta_2$ | +0.35 | **1.4191** | 城市组是其他组的 1.4191 倍（+41.9%） |

两项同时成立：

$$
\mu = e^{-1.20}\cdot e^{0.20}\cdot e^{0.35} = e^{-0.65} = 0.3012 \times 1.2214 \times 1.4191 = \mathbf{0.5220}\ \text{次/年}
$$

**为什么能直接乘**：$\mu = e^{\beta_0+\beta_1x_1+\beta_2x_2} = e^{\beta_0}\cdot e^{\beta_1x_1}\cdot e^{\beta_2x_2}$。指数把加法变成乘法，因子可以逐个乘上去，这就是费率表「基准费率 × 因子 × 因子」的形状。

**反例：把同一批系数搬到 identity link 上**。此时 $\mu = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots$，只要有两个负系数因子 —— 比如无赔款优待 −0.40、安全装置折扣 −0.50 —— 在

$$
0.30 + 0.20 + 0.35 - 0.40 - 0.50 = \mathbf{-0.05}
$$

这个组合上模型直接给出**负的期望出险次数**。换成 log link，同样的组合是 $e^{-0.05} = 0.9512$，永远为正。这就是「计数和金额用 log」的全部理由。

### 第 3 步：三个目标的方差函数各算一次

同一个 $V(\mu)$ 公式，换分布就换答案：

| 目标 | 分布 | $V(\mu)$ | 代入 | 方差 | 标准差 |
|---|---|---|---|---|---|
| 是否出险 | Bernoulli | $\mu(1-\mu)$ | $\mu=0.035$ | 0.033775 | 0.1838 |
| 出险次数 | Poisson | $\mu$ | $\mu=0.35$ | 0.35 | 0.5916 |
| 单次赔付额 | Gamma | $\phi\mu^2$ | $\mu=21{,}000,\ \phi=0.8$ | 352,800,000 | 18,783 |

读法：金额的标准差与均值成**正比**（这里是均值的 89.4%，$\sqrt{0.8}$），次数的标准差是均值的 1.69 倍，而概率的标准差只有 0.1838。想让一个常数 $\sigma^2$ 同时扛住这三个目标，做不到。


### 第 4 步（条件检验）：方差函数选错，SE 错多少

第 1 步已经看到 $s^2/\bar y = 1.80$。如果按 Poisson 拟合（假装 $\phi = 1$）：

* 系数本身不明显偏移（点估计还是一致的）；
* $\operatorname{Var}(\hat\beta)$ 被低估 1.80 倍 ⇒ **标准误要乘 $\sqrt{1.80} = \mathbf{1.3416}$**；
* 一个 $t = 2.40$ 的系数，真实 $t = 2.40 / 1.3416 = \mathbf{1.79}$ —— 掉到 1.96 以下，显著性没了。

反方向同样危险。如果数据其实是**欠散布**（$\phi = 0.5$），SE 被高估 $1/\sqrt{0.5}$ 倍，同一个 $t = 2.40$ 变成 $2.40/0.7071 = \mathbf{3.39}$，把一个不显著的系数做成「很显著」。

修法三条：换负二项（显式建模过散布）、拟泊松 / 拟似然（把 $\phi$ 估出来乘进方差）、或者直接用稳健标准误。

### 顺带验一个口径：logit 与 probit 的系数不能直接比

把 $\text{sigmoid}(\eta)$ 与标准正态 CDF $\Phi(\eta)$ 在 $\eta\in[-3,3]$ 上对齐，最优的比例因子是 **1.70**（两条曲线最多差 0.0096）。logit 的系数大约是 probit 系数的 1.6–1.8 倍，所以两个模型的 $\beta$ 不能直接比大小，把 probit 的系数当 odds ratio 读更是错的。

## 五、什么情况下会失灵

### 承重假设一：分布选对（方差函数正确）

这是 GLM 独有的一条：OLS 只要求「方差是常数」，GLM 要求「方差是 $V(\mu)$ 的那个形状」。

撤掉它，后果在上一节算过：计数数据过散布 1.8 倍时 SE 小 1.34 倍，$t$ 从 2.40 掉到 1.79；欠散布 $\phi=0.5$ 时 SE 大 1.41 倍，把 $t=2.40$ 吹到 3.39。**系数的点估计还在，坏的是标准误和 p 值。**

这条最容易在线上翻车：训练集里某一组的过散布只有 1.1，上线后涨到 2.0，系数没动，你的置信区间已经失真。

### 承重假设二：在 **link 尺度** 上线性

线性发生在 $g(\mu)$ 与 $X$ 之间，不在 $\mu$ 与 $X$ 之间。撤掉它，偏差会被指数放大：log 尺度上差 0.1，在 $\mu = 0.35$ 处等于频率差 $0.35\times(e^{0.1}-1) = 0.0368$ 次，也就是少算 10.5% 的频率。年龄与出险率常是 U 形（新手和老年司机都高），一条 log 尺度上的直线会把两端压平、中间抬高。

处理：分箱、样条，或者对 $X$ 本身做变换。

### 承重假设三：观测独立

这一条 GLM **没有**放宽。同一张保单的 36 个月记录是相关的：上个月出过险，下个月更可能再出。有效样本量远小于名义样本量 —— 你以为有 36,000 个独立观测，实际信息量可能只相当于 8,000 个，标准误被压到 $\sqrt{8000/36000} = 0.47$ 倍，p 值全线虚高。

处理：聚类稳健标准误、GEE，或带随机效应的 GLMM。

### 承重假设四：无完全共线（矩阵可逆）

IRLS 每一步都在解 $(X'WX)^{-1}$，完全共线时直接报错，高共线时系数在迭代间来回跳、不收敛。处理方式与 OLS 相同，见 [[3. Multicollinearity]]：删变量、合并、或者加惩罚（$+\lambda I$ 保证可逆）。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 系数要逐项辩护、要交给监管 | GLM（log / logit） | 系数就是乘数或 odds 倍数 |
| 目标在 0 处有点质量 + 连续正尾（纯保费） | Tweedie GLM（log link） | 一个分布同时管住 0 和正数两段 |
| 频率与严重度要分开建模 | 频率-严重度两段式 | 两段各自选分布；Tweedie 是它的单段等价写法 |
| 关系高度非线性、交互多、只要排序 | GBM / 随机森林 | 精度更高，代价是拿不出可报备的系数 |
| 保单-月份这类嵌套数据 | GLMM / GEE | 显式建模随机效应与组内相关 |
| 要因果解释 | 都不是 | 都只给关联，因果靠设计 |

## 六、常见误解

### 误解一：「GLM 能自动处理非线性」

**错误想法**：X 和 Y 的关系不是直线，所以应该换 GLM。

**为什么容易这么想**：名字里带「广义」，而且换了 link 之后画出来的拟合曲线确实是弯的，看起来像非线性回归。

**错在哪一步**：link 只是把**均值**做了一次已知形状的单调变换，弯的地方就是那条 link 的形状；$X$ 与 $\eta$ 之间仍然是直线。真需要非线性（比如 U 形的年龄效应），得靠分箱、样条或交互项。

### 误解二：「分布和 link 可以随便搭，反正预测差不多」

**错误想法**：计数用 Poisson 配 identity link 也行，反正软件不报错。

**为什么容易这么想**：OLS 就是这么搭的（Normal + identity），而且软件确实经常给你收敛的结果。

**错在哪一步**：identity link 下线性预测子可以取任意实数，负值直接变成负的期望次数 —— 前面第 2 步那个 $-0.05$ 就是这么来的。分布决定方差函数、link 决定均值的尺度，两个选择要各自说清理由，不能只看「能不能跑出来」。

### 误解三：「Gamma 是典则连接最好，所以应该用 inverse link」

**错误想法**：教材说典则连接在数学上最干净，Gamma 的典则连接是 $g(\mu)=1/\mu$，那就该用它。

**为什么容易这么想**：典则连接确实让 score 方程最简洁，IRLS 也最稳，这条结论在二值数据上是免费的午餐。

**错在哪一步**：把「数学最干净」当成了「建模最合适」。inverse link 下线性预测子与 $\mu$ 反向行走，系数读不出乘数；而且线性预测子取负值时 $1/\mu < 0$，均值直接非法。Gamma / Tweedie 实务一律用 log link，理由是边界与可解释性，不是数学便利。

### 误解四：「换了 GLM，OLS 那套假设就不用管了」

**错误想法**：都上 GLM 了，独立性、共线性这些老规矩自然作废。

**为什么容易这么想**：教材强调 GLM 放宽了正态性与同方差，两条最容易同时被记住的就是「放宽」。

**错在哪一步**：放宽的只有误差分布那两条。独立性与无完全共线性来自另外两个前提 —— 似然是各项相乘（所以要独立）、$(X'WX)$ 要可逆（所以不能共线），与选哪个分布无关。外生性同样没被豁免。

## 七、面试怎么答

### 30 秒版

> GLM 把线性回归的两件事解开了：不再固定用 Normal + 常数方差，而是按 Y 的类型从指数族里挑分布 —— 二值用 Bernoulli、计数用 Poisson、纯保费用 Tweedie，分布自带方差函数；同时加一个连接函数把均值接到线性预测子上，二值用 logit，计数和金额用 log。线性关系发生在这把尺子上，不在 Y 本身。拟合用最大似然，IRLS 每一步是一次加权最小二乘。用 log link 时系数能直接读成乘数，所以保险定价一直在用它。

### 2 分钟版（要包含的三块）

1. **动机**：三类目标各自的越界与方差问题（概率越界、负的期望次数、金额方差随均值平方增长）；
2. **机制**：三块积木 + 指数族形式 + $\mu=b'(\theta)$、$\operatorname{Var}=\phi b''(\theta)$ + 典则连接为什么让 IRLS 变干净；
3. **口径与失效**：log link 的乘性费率、$\phi\neq1$ 时标准误会错多少（过散布 1.8 倍 ⇒ SE 小 1.34 倍，$t$ 从 2.40 掉到 1.79）。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么要有 $b(\theta)$？」 | 均值是 $b$ 的一阶导、方差是 $\phi$ 乘二阶导，一套公式覆盖所有分布 |
| 「link 和分布能不能随便搭？」 | 不能。分布管方差函数、link 管均值尺度；二值可 logit/probit/cloglog，计数用 log（identity 会给负均值） |
| 「怎么发现分布选错了？」 | 看均值与方差的关系（计数看 $s^2/\bar y$）、离差残差图、显式估 $\phi$ |
| 「系数怎么讲给业务？」 | log link 下 $\exp(\beta)$ 是乘数，logit 下是 odds 倍数，两种说法不能混 |
| 「p > n 或完全共线怎么办？」 | 和 OLS 一样撞矩阵求逆；加惩罚或先做变量筛选 |
| 「GLM 和 GBM 怎么选？」 | 要系数可辩护用 GLM，要排序精度用 GBM，实战常见组合是两边各出一部分 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "A GLM has three components: a random component, which is a distribution from the exponential family; a systematic component, the linear predictor X beta; and a link function g, so that g of the mean equals X beta. Once you know b and phi, you know the moments — the mean is the first derivative of b, and the variance is phi times the second derivative of b."

**Why the canonical link matters**

> "With the canonical link the natural parameter equals the linear predictor, and that makes the score equations simplify — IRLS becomes the natural fitting algorithm. For a Bernoulli outcome the canonical parameter is the log-odds, which is exactly why the logit link is the default rather than just a convenient choice."

**If they push back**

> "A common pitfall is thinking the link is cosmetic. It isn't — the link is what makes a linear model valid when the mean is constrained, like a probability in zero-to-one or a count that has to be positive. And one caveat: GLMs still assume independent observations and no perfect multicollinearity, so those OLS habits don't go away."

| 中文 | English | 一句话 |
|---|---|---|
| 指数散布族 | exponential dispersion family | 把密度写成 `exp((yθ−b(θ))/φ + c(y,φ))` 的一族分布 |
| 典则参数 | canonical parameter | `θ`，指数族里控制均值位置的那个参数 |
| 归一化函数 | normalization function | `b(θ)`，保证概率加总为 1 |
| 离散参数 | dispersion parameter | `φ`，给方差做整体缩放；泊松与伯努利里等于 1 |
| 方差函数 | variance function | `V(μ)`，分布自带的「方差怎么随均值变」的规则 |
| 连接函数 | link function | `g(μ) = η`，把受限的均值接到整条实轴 |
| 典则连接 | canonical link | 取 `g(μ) = θ` 的那个 link，score 方程最干净 |
| 线性预测子 | linear predictor | `η = Xβ` |

| 过散布 | overdispersion | 实际方差大于分布假设（计数数据常见），`φ > 1` |
| 费率乘数 | relativity | log link 下 `exp(β)` 就是乘上去的那个因子 |
| 纯保费 | pure premium | 频率 × 严重度，Tweedie 的建模对象 |
| 离差 | deviance | GLM 里代替残差平方和的拟合损失 |
| 拟似然 | quasi-likelihood | 只指定方差函数、不指定完整分布时的估 φ 办法 |
