# 1.6.3 正则化（Regularization）

## 速览 At a glance

**速记**

过拟合是「训练误差很低、测试误差很高」。正则化在损失后面加一项惩罚：`min −ℓ(β) + λ·P(β)`，λ 调强弱。Ridge 用 L2 惩罚（系数平方和），把所有系数按 $1/(1+\lambda)$ 的比例往零压但**到不了零**，所以它能救共线性和 $p>n$；Lasso 用 L1，正交设计下的解是软阈值，$|\beta| \le \lambda/2n$ 的系数直接归零，所以它自带变量选择。几何上的原因是菱形解域有角。Elastic Net 两者混合，相关变量组倾向一起进一起出。三个前提必须记牢：**先标准化**（否则量纲大的变量被罚得更重）、**不罚截距**、**λ 用交叉验证选**。最后一条边界：CV 在完全分离的问题上常选出 λ=0 —— 正则化治的是过拟合，不是分离。

**一句面试答法**

> "Regularisation adds a penalty for complexity to the loss — we minimise the negative log-likelihood plus lambda times the penalty. Ridge uses the squared norm and shrinks coefficients smoothly; Lasso uses the absolute norm and can set them exactly to zero, which is automatic feature selection."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 正则化 | regularization | 在损失上加惩罚项，用偏差换方差 |
| 良态问题 | well-posed problem | $\mathbf{X}'\mathbf{X}$ 可逆，解唯一 |

## 一、先看一个问题

你在用几十个特征预测房价：居住面积、屋顶年龄、门的颜色、最近一棵橡树的距离……

不加约束的话，模型会从训练数据里学出这种规则：

> *「如果门是米色，而且最近的一棵橡树在 27.4 英尺外，就把价格加上 15,312 美元。」*

这就是**过拟合（overfitting）**：模型学到的是噪声，不是信号。它训练时几乎完美，换一批房源就崩。

现在问题来了。面试官不会只问「什么是过拟合」，他会接着问：

> 「那你怎么知道该罚多重？λ 取 0.1 和取 10，你手上的系数会变成什么样？」

答不上这个数，说明你知道要加惩罚项，但没真跑过。这一节先把机制讲清，再用一组正交设计的数据把 λ 从 0 扫到 10，把系数一个个算出来。

## 📖 标准定义

> **教材原文 ① · PSL §3.2 Regularization**（<https://liangfgithub.github.io/PSL/w3/w3_2_regularize.html>）
> > "Next, we’ll introduce two alternative regularization or penalty terms for beta. Ridge regression employs the L2 penalty on beta, while Lasso regression uses the L1 penalty."
>
> **教材原文 ② · PSL §3.3.1 Introduction to Ridge、§3.3.2 The Shrinkage Effect、§3.3.4 Degree-of-Freedom**（<https://liangfgithub.github.io/PSL/w3/w3_3_ridge.html>）
> > "In ridge regression, the objective function to be minimized is a smooth quadratic function of beta. This function consists of two terms: the residual sum of squares and the L2 norm of beta."
> >
> > "A key benefit of ridge regression is its applicability to design matrices that are not of full rank. This is made possible by adding $\lambda \mathbf{I}$ to $\mathbf{X}^t \mathbf{X}$ , which allows us to invert the resulting matrix. This feature sets ridge regression apart from ordinary least squares (OLS) methods, making it a versatile tool for tackling a wide range of problems."
>
> **教材原文 ③ · PSL §3.4.1 Introduction to Lasso、§3.4.2 One-dimensional Lasso、§3.4.3 Lasso vs. Ridge**（<https://liangfgithub.github.io/PSL/w3/w3_4_lasso.html>）
> > "The Lasso objective function consists of two terms: The residual sum of squares (RSS) The L1 norm of the coefficient vector beta"
> >
> > "Lasso : Implements “soft-thresholding.” Increasing lambda not only shrinks the coefficients but can also set some to zero, effectively performing variable selection."
>
> **教材原文 ④ · PSL §3.5 Discussion（页面 w3_5_discussion.html）**（<https://liangfgithub.github.io/PSL/w3/w3_5_discussion.html>）
> > "For X3, ridge regression and PCR are less effective as they tend to prioritize early principal components. Given that much of the variation in X3 is noise-driven, the top principal components are not necessarily relevant to Y. Here, methods like Lasso, which can completely zero out specific features, become increasingly important."

**标准记法**：

- Ridge：$\min \| \mathbf{y} - \mathbf{X} \boldsymbol{\beta}\|^2 + \lambda \| \boldsymbol{\beta} \|^2$；Lasso：$\min \| \mathbf{y} - \mathbf{X} \boldsymbol{\beta}\|^2 + \lambda \| \boldsymbol{\beta} \|_1$。
- $\hat{\boldsymbol{\beta}}^{\text{ridge}} = (\mathbf{X}^t \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^t \mathbf{y}$；等价于对增广数据 $\left(\begin{array}{c} \mathbf{y} \\ \mathbf{0}_{p} \end{array}\right) = \left(\begin{array}{c} \mathbf{X} \\ \sqrt{\lambda} \mathbf{I}_p \end{array}\right) \boldsymbol{\beta} + \text{error}$ 做 OLS。
- 正交设计下 $\hat{\beta}^{\text{ridge}}_j = \frac{1}{1+\lambda}\hat{\beta}^{\text{LS}}_j$；有效自由度 $\text{df}(\lambda) = \text{tr}(\mathbf{X}(\mathbf{X}^t\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}^t) = \sum_j \frac{d_j^2}{d_j^2+\lambda}$，取值连续落在 $[0, p]$。
- $\min_{\boldsymbol{\beta}} \| \mathbf{y} - \mathbf{X} \boldsymbol{\beta}\|^2 + \lambda \| \boldsymbol{\beta} \|_1$
- 正交设计下的解（soft-thresholding）：$\hat{\beta}^{\text{lasso}}_j = \text{sign}(\hat{\beta}_j^{\text{LS}}) (|\hat{\beta}_j^{\text{LS}}| - \lambda/2)$ if $|\hat{\beta}_j^{\text{LS}}| > \lambda/2$，否则 $0$。
- 同一 $\lambda$ 下的比较（通用形式）：$\text{Ridge}$ 用 $\| \boldsymbol{\beta} \|^2$，$\text{Lasso}$ 用 $\| \boldsymbol{\beta} \|_1$，Elastic Net 用 $\lambda_1 \| \boldsymbol{\beta} \|_1 + \lambda_2 \| \boldsymbol{\beta} \|^2$。

**中文解释**：

- 正则化把「变量选择」写成一个惩罚目标函数：$L_0$ 惩罚数非零系数（等于 AIC/BIC 家族），$L_2$（ridge）压缩系数，$L_1$（lasso）压缩并置零。惩罚项把偏差换方差，所以能降低测试误差。注意 $L_1/L_2$ 对尺度敏感，必须先中心化/标准化，且不罚截距。
- Ridge 在 RSS 上加 $L_2$ 惩罚，把系数按奇异值大小「按比例缩小」（大奇异值缩得少）。好处是 $\mathbf{X}^t\mathbf{X}+\lambda\mathbf{I}$ 一定可逆，能处理共线性与 $p>n$。代价是引入偏差，但有效自由度变成 $0$ 到 $p$ 之间的实数。
- Lasso 用 $L_1$ 惩罚，等价于把系数限制在菱形 $L_1$ 球里；菱形的顶点在坐标轴上，所以解容易「卡在」某个系数为 0，实现稀疏与变量选择。它没有一般闭式解，要用坐标下降。与 ridge 的线性收缩不同，软阈值是「小于阈值直接归零」。
- PSL 的取舍逻辑按设计矩阵分三种情形：特征少且挑过 → 全模型即可；特征相关但都有关（$X_2$）→ ridge / PCR 这类收缩方法有效；混入大量噪声特征（$X_3$）→ ridge/PCR 因为优先保留大方差的早期主成分反而更差，必须用能真正置零的 lasso。

## 二、核心直觉

### 模型「太能学」的时候，惩罚复杂度是唯一便宜的刹车

一个**过拟合**的模型：

* **训练误差**很低（几乎完美拟合数据），
* 但**测试误差**很高（换到新数据就失败），
* 原因是它太**灵活**、太**复杂**（也就是自由度太多）。

**正则化（regularization）** 通过**惩罚复杂度**来对抗这件事。惩罚做的是同一件事的两种说法：**把「参数可以取多大」这件事写进目标函数**，而不是事后去挑模型。

有两个常见问题会叠加放大过拟合风险：

* **多重共线性（multicollinearity）：** 高度相关的预测变量（例如 `square_footage` 与 `num_bathrooms`）会导致系数估计（$\hat{\beta}$）不稳定。数据稍微动一下，估计值就会大幅摆动 —— 即使整体预测值看上去变化不大。
* **高维（$p > n$）：** 当特征数 $p$ 超过观测数 $n$ 时，存在**无穷多个精确解**能完美拟合训练数据。像最大似然估计（Maximum Likelihood Estimation, MLE）这样的传统方法在这种情况下无法给出**唯一、稳定**的解。

正则化在这里充当**打破平局的裁判（tie-breaker）**：在无穷多个拟合得一样好的解里，它挑系数最小的那个。

**这里像什么、不像什么**：可以把它想成给模型加了一条「不许用复杂规则」的规矩，像考试时限制作答的字数。**但差别在于**：字数限制是硬约束，正则化是软约束 —— 如果某条特征真的能大幅降低误差，模型宁愿付出惩罚也要用它。真正被赶走的，是那些只把训练误差压下去一点点、却要花掉很大系数的特征。

### 它换来的是什么：偏差换方差

正则化引入了**偏差**（模型被简化），但降低了**方差**（对训练数据的敏感度）。总测试误差是这两项的和，所以曲线是 U 形：λ 太小 → 方差主导；λ 太大 → 偏差主导。

> ✅ **不惩罚** $(\lambda = 0)$ → 模型只最小化损失项 → **过拟合**风险高。
> 🚫 **惩罚很大** $(\lambda \to \infty)$ → 惩罚主导，系数被过度收缩 → **欠拟合（underfitting）**或模型过度简化。

目标是为 $\lambda$ 找到**甜点（sweet spot）**。第四节的算例里，你会看到这条 U 形曲线两端的系数长什么样。

### 贝叶斯视角：惩罚就是先验

惩罚似然（penalized likelihood）等价于**最大后验估计（Maximum A Posteriori, MAP）**：

   > $\text{Posterior}(\boldsymbol{\beta} \mid \text{Data}) \propto \text{Likelihood}(\text{Data} \mid \boldsymbol{\beta}) \times \text{Prior}(\boldsymbol{\beta})$

   * **Ridge（L2 惩罚）** ⇔ **Gaussian 先验**：相信 $\beta_j \sim \mathcal{N}(0, \tau^2)$。
   * **Lasso（L1 惩罚）** ⇔ **Laplace 先验**：相信大多数 $\beta_j$ 恰好为零，记作 $\beta_j \sim \text{Laplace}(0, b)$。

Laplace 分布在 0 处有个尖峰，这就是「L1 会把系数压到恰好为零」的概率语言版本 —— 和第三节的菱形角点是同一件事的两种讲法。

## 三、机制

### 3.1 定义与逐项说明

正则化修改的是优化目标：

> **最小化（Minimize）：**
> $\min_{\boldsymbol{\beta}} \left( \underbrace{-\ell(\boldsymbol{\beta})}_{\text{Loss}} + \underbrace{\lambda P(\boldsymbol{\beta})}_{\text{Penalty}} \right)$

逐项读：

   * **$-\ell(\boldsymbol{\beta})$：** 负对数似然 —— 这是**损失项（loss）**，衡量模型拟合数据的程度。在线性回归里，它对应**残差平方和（Sum of Squared Errors, SSE）**。
   * **$P(\boldsymbol{\beta})$：** **惩罚函数（penalty function）**，量化模型复杂度。它通常取系数向量的某个范数（例如 L1 或 L2 范数）。
   * **$\lambda$：** **调参量（tuning parameter）**，控制「拟合数据」与「惩罚复杂度」之间的权衡。$\lambda=0$ 就是普通 OLS 或 MLE。注意**它不是无量纲的**：λ 的量纲由损失项决定（见 3.3）。

**三种惩罚**：

   #### **Ridge Regression（L2 惩罚）**

   * **惩罚项：**
     $P(\boldsymbol{\beta}) = \sum_{j=1}^p \beta_j^2$
   * **效果：**
     把所有系数平滑地往零收缩，但**没有**任何一个会被压到恰好为零。适合在存在多重共线性时稳定模型。

   ---

   #### **Lasso Regression（L1 惩罚）**

   * **惩罚项：**
     $P(\boldsymbol{\beta}) = \sum_{j=1}^p |\beta_j|$
   * **效果：**
     鼓励**稀疏（sparsity）**：把一部分系数压到**恰好为零**，从而实现**自动特征选择（automatic feature selection）**。

   ---

   #### **Elastic Net（L1 与 L2 惩罚的组合）**

   * **惩罚项：**
     $P(\boldsymbol{\beta}) = \alpha \sum_{j=1}^p |\beta_j| + (1 - \alpha) \sum_{j=1}^p \beta_j^2$
   * **效果：**
     Ridge 与 Lasso 的混合。既有 Lasso 的稀疏性，又有 Ridge 的稳定性，因此在预测变量彼此相关时特别合适。

### 3.2 它是怎么来的

**Ridge：为什么加 $\lambda\mathbf{I}$ 就能求逆。**

OLS 的解是 $\hat{\boldsymbol{\beta}} = (\mathbf{X}^t\mathbf{X})^{-1}\mathbf{X}^t\mathbf{y}$。对目标 $\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|^2 + \lambda\|\boldsymbol{\beta}\|^2$ 求导并令其为零：

$$
-2\mathbf{X}^t(\mathbf{y}-\mathbf{X}\boldsymbol{\beta}) + 2\lambda\boldsymbol{\beta} = \mathbf{0}
\;\Longrightarrow\;
\hat{\boldsymbol{\beta}}^{\text{ridge}} = (\mathbf{X}^t \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^t \mathbf{y}
$$

**关键一步就在这里**：$\mathbf{X}^t\mathbf{X}$ 的特征值是 $d_j^2$，加 $\lambda\mathbf{I}$ 之后变成 $d_j^2+\lambda \ge \lambda > 0$ —— 一个都不为零，所以**这个矩阵一定可逆**。共线性（某个 $d_j^2 \approx 0$）与 $p>n$ 本来让 $(\mathbf{X}^t\mathbf{X})^{-1}$ 不存在，$\lambda$ 把这一项从「不存在」变成「存在但很大」。代价是解被压缩：把 $\mathbf{X}^t\mathbf{X}$ 对角化之后能看出

$$
\hat\beta_j^{\text{ridge}} = \frac{d_j^2}{d_j^2+\lambda}\,\hat\beta_j^{\text{OLS}}
$$

奇异值小的方向（$d_j^2$ 小，也就是共线性最严重的那个方向）被压缩得最狠，这正是它能稳定共线性系数的原因。正交设计下 $d_j^2$ 相同，整条式子退化为标准记法里的 $\hat{\beta}^{\text{ridge}}_j = \frac{1}{1+\lambda}\hat{\beta}^{\text{LS}}_j$。

**Ridge 的第二个身份：增广数据上的 OLS。** 把 $\sqrt{\lambda}\,\mathbf{I}_p$ 接到 $\mathbf{X}$ 下面、把 $p$ 个零接到 $\mathbf{y}$ 下面，就得到标准记法里那个增广形式。它的好处是能直接搬 OLS 的结论：**有效自由度**就是 hat matrix 的迹

$$
\text{df}(\lambda) = \text{tr}\bigl(\mathbf{X}(\mathbf{X}^t\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}^t\bigr) = \sum_j \frac{d_j^2}{d_j^2+\lambda}
$$

$\lambda=0$ 时是 $p$，$\lambda\to\infty$ 时是 0，取值连续 —— 所以 ridge 不是「选了几个变量」，而是「相当于几个变量」。

**Lasso：为什么会出现精确的零。**

$|\beta_j|$ 在 $\beta_j=0$ 处不可导，所以用 subgradient。对**正交**设计（$\mathbf{X}^t\mathbf{X} = \mathrm{diag}(d_j)$）逐坐标求解，得到软阈值：

$$
\hat{\beta}^{\text{lasso}}_j =
\begin{cases}
\text{sign}(\hat\beta_j^{\text{LS}})\,\bigl(|\hat\beta_j^{\text{LS}}| - \lambda/(2d_j)\bigr), & |\hat\beta_j^{\text{LS}}| > \lambda/(2d_j),\\[2pt]
0, & |\hat\beta_j^{\text{LS}}| \le \lambda/(2d_j).
\end{cases}
$$

**阈值里那个 $d_j$ 是这一节最容易错的地方**：$d_j = \sum_i(x_{ji}-\bar x_j)^2$，也就是该列的离差平方和。标准记法里写的 $\lambda/2$，对应的是「$d_j=1$」的特殊形式（列严格正交规范化）。$d_j$ 越大（样本越多、该变量方差越大），阈值越小、越杀不掉 —— 第四节的算例里 $n=100$ 时阈值就是 $\lambda/200$，所以 λ 取 10 几乎什么也删不掉。

**关键一步在这里**：ridge 是**乘一个小于 1 的数**（$|\beta|$ 变小但只有 $|\beta|=0$ 才到 0），lasso 是**减一个常数再取正部**（减到负数就归零）。所以只有 L1 能在有限的 λ 下真的把系数杀掉。同一个道理用几何讲：约束区域 $\|\beta\|_1 \le c$ 是菱形，**角点在坐标轴上**，损失等高线扩张时容易先碰到角；ridge 的 $\beta_1^2+\beta_2^2 \le c$ 是圆，边界光滑，碰到坐标轴的概率是零。

   * **Ridge Regression（L2 惩罚）：** 约束区域是一个由下式定义的**圆**
     $\beta_1^2 + \beta_2^2 \leq c$
     因为边界光滑圆润，最优解（损失等高线刚好触到约束区域的那个点）**不太可能正好落在坐标轴上**。所以 Ridge 倾向于收缩系数，但**很少把它们压到零**。

   * **Lasso Regression（L1 惩罚）：** 约束区域是一个由下式定义的**菱形**
     $|\beta_1| + |\beta_2| \leq c$
     这个菱形在坐标轴上有**尖锐的角**，于是最优解**更有可能落在某个角上** —— 也就是一个或多个系数恰好为零。这就是 Lasso 能做**特征选择**的几何原因。

**Lasso 怎么算**：没有一般闭式解（只有正交设计这种特例才有软阈值的显式解），实践中用**坐标下降（coordinate descent）**：固定其余系数，把 $\beta_j$ 更新成软阈值的那个形式，轮流扫到收敛。每一步都是一维问题，所以快。

### 3.3 变形与口径

**① 惩罚写法会改 λ 的数值。** $\|\boldsymbol\beta\|^2$ 与 $\tfrac12\|\boldsymbol\beta\|^2$ 只差一个因子 2，但整体最优解要 λ 差一倍才一样。glmnet 内部把 $P(\beta)$ 写成 $\lambda[\alpha\|\beta\|_1 + (1-\alpha)\tfrac12\|\beta\|_2^2]$，sklearn 的 `Ridge` 用 `alpha * ||beta||^2`——**同一个解，两个库报的 λ 可以差 2 倍**。跨库比 λ 之前先对齐写法。

**② 约束形式与惩罚形式等价。** $\min \text{RSS} + \lambda\|\beta\|_1$ 与 $\min \text{RSS}\ \text{s.t.}\ \|\beta\|_1 \le c$ 给出同一条解路径，λ 与 c 一一对应（反过来写就是 $c$ 越小、λ 越大）。教材里用约束形式讲几何，软件里用惩罚形式做优化。

**③ 标准化口径。** glmnet 默认 `standardize=TRUE`，在内部把每列标准化后求解、再把系数换算回原始尺度；sklearn 的 `Lasso` / `Ridge` 默认**不**标准化，要自己套 `StandardScaler`。这就是为什么同一批数据在两个库里选出的变量可能不一样（第四节的算例给出具体数字）。**两种做法没有谁对谁错，只有一致不一致**：只要建模、调参、上线三处用同一套预处理，结果就是可复现的。

**④ 有效自由度与信息准则。** Ridge 的 $\text{df}(\lambda)=\sum_j d_j^2/(d_j^2+\lambda)$ 是实数；lasso 在某个 λ 下的自由度就等于非零系数个数。有了自由度就能算 $\text{AIC}/\text{BIC}/\text{Mallows }C_p$ 这类准则，代价是它们比 CV 更依赖 $\sigma^2$ 的估计；实践中选 λ 仍以 CV 为主。

**⑤ 不只用于线性模型（Beyond Linear Models）。** 罚似然的形式对任何用 MLE 拟合的模型都成立：**logistic regression** 加上 $\lambda\|\beta\|$ 就是罚似然（完全分离的数值问题会缓解），**SVM** 用的是 hinge loss 加 L2，**神经网络**里同一项叫 **weight decay**。

**⑥ 实务工作流**：

   **第 1 步：标准化预测变量。**确保所有特征在同一尺度上（均值 = 0、标准差 = 1）。否则正则化会不公平地惩罚量纲更大的特征。

   **第 2 步：选惩罚项并调 $\lambda$**，用 **K 折交叉验证（K-Fold Cross-Validation）**：

   1. 把训练数据切成 $K$ 折。
   2. 对每个候选 $\lambda$：在 $K - 1$ 折上训练，在剩下那一折上验证，对全部 $K$ 折重复一遍。
   3. 计算平均验证误差：

      $$
      \text{CV}(\lambda) = \frac{1}{K} \sum_{k=1}^{K} \text{Error}^{(k)}(\lambda)
      $$
   4. 选出使交叉验证误差最小的 $\lambda$：

      $$
      \lambda^{*} = \arg\min_{\lambda} \, \text{CV}(\lambda)
      $$

> 🎯 **面试官会追问「$\lambda$ 到底怎么选」**：K 折 CV 选最小值；实务上常用 **1-SE 规则**（在最小值一个标准误范围内取最大的 $\lambda$），因为 CV 曲线在最优点附近很平，取大一点更稳。**⚠️ 但要注意**：在**分离（separation）**问题里 CV 往往会告诉你 $\lambda = 0$ 最好 —— 那说明正则化治的是过拟合，不是分离（见 [[1.6 Estimation Issues & Separation]]）。

   **第 3 步：分析结果。**

   * **系数路径图（Coefficient Path Plot）：** 画出系数随 $\lambda$ 增大如何被收缩 —— 看特征重要性的关键图。第四节的表就是这张图的数字版本。
   * **最终验证（Final Validation）：** 用最优 $\lambda$ 在完整训练集上重训，再到**留出的测试集（held-out test set）**上评估。

## 四、算一遍

为了让每一步都能手算到底，取一个**正交设计**：列已经中心化、标准化，且 $\mathbf{X}^t\mathbf{X} = n\mathbf{I}$，$n = 100$。这样 $d_j^2 = 100$，ridge 与 lasso 都有闭式解（软阈值那一条就是标准记法里给出的式子）。

OLS 给出 $\hat{\boldsymbol\beta}^{\text{LS}} = (1.60,\ -0.80,\ 0.40)$。

### 第 1 步：Ridge —— λ 从 0 涨到 10

用 $\hat\beta_j^{\text{ridge}} = \hat\beta_j^{\text{LS}}/(1+\lambda)$。为什么是这个式子：正交设计下三个方向互不干扰，$\lambda$ 对每个系数独立地按 $1/(1+\lambda)$ 缩放。

| $\lambda$ | $\hat\beta_1$ | $\hat\beta_2$ | $\hat\beta_3$ | 每个系数被压成原来的 | 有效自由度 $\sum \frac{100}{100+\lambda}$ |
|---|---|---|---|---|---|
| 0 | 1.6000 | −0.8000 | 0.4000 | 100% | 3.0000 |
| 0.1 | 1.4545 | −0.7273 | 0.3636 | 90.9% | 2.9970 |
| 1 | 0.8000 | −0.4000 | 0.2000 | 50.0% | 2.9703 |
| 10 | 0.1455 | −0.0727 | 0.0364 | 9.1% | 2.7273 |

三件事一眼可见：

1. **比例是乘法的，不是减法的** —— 三个系数永远保持 4 : −2 : 1 的比例。这是 ridge「不选变量」的直接后果：它改变大小，不改变结构。
2. **λ=1 时全部折半**，λ=10 时只剩 9.1%。λ 的绝对值没有含义，**它相对于 $\mathbf{X}^t\mathbf{X}$ 的量级才有含义**（这里 $d_j^2=100$）。
3. **自由度掉得很慢**：λ 从 0 到 10，自由度只从 3.000 掉到 2.727。系数已经缩到 1/10，模型复杂度几乎没变 —— 这正是「ridge 不省变量」的量化版本。

### 第 2 步：Lasso —— 同样的 λ 几乎什么也不做

用同一组 λ 套软阈值。目标写成 $\min\|\mathbf{y}-\mathbf{X}\boldsymbol\beta\|^2 + \lambda\|\boldsymbol\beta\|_1$ 时，阈值是 $\lambda/(2n) = \lambda/200$：

| $\lambda$ | 阈值 $\lambda/200$ | $\hat\beta_1$ | $\hat\beta_2$ | $\hat\beta_3$ |
|---|---|---|---|---|
| 0 | 0 | 1.6000 | −0.8000 | 0.4000 |
| 0.1 | 0.0005 | 1.5995 | −0.7995 | 0.3995 |
| 1 | 0.005 | 1.5950 | −0.7950 | 0.3950 |
| 10 | 0.05 | 1.5500 | −0.7500 | 0.3500 |

**同样的 λ，ridge 已经把系数砍掉九成，lasso 才动了 3%。** 这不是 bug：lasso 的阈值是 $\lambda/(2n)$，$n=100$ 时被摊薄了 200 倍。面试里如果被问「λ 取多少合适」，正确的答法是**说不出绝对值，只说得出一条 CV 曲线** —— 上面这两张表就是为什么。

### 第 3 步：把 λ 推到能看见「删除」的区间

要求 $|\hat\beta_j^{\text{LS}}| \le \lambda/2n$：

- $\beta_3 = 0.40$ 被删掉：$\lambda = 2 \times 100 \times 0.40 = 80$
- $\beta_2 = -0.80$ 被删掉：$\lambda = 160$
- $\beta_1 = 1.60$ 被删掉：$\lambda = 320$

| $\lambda$ | $\hat\beta_1$ | $\hat\beta_2$ | $\hat\beta_3$ | 非零个数 = 自由度 |
|---|---|---|---|---|
| 80 | 1.20 | −0.40 | **0** | 2 |
| 160 | 0.80 | **0** | **0** | 1 |
| 320 | **0** | **0** | **0** | 0 |

这就是**系数路径图**：λ 往上走，系数被一个个「按绝对值从小到大」杀掉，最小的先死。Ridge 永远不会走到这一列全是 0 的格子。

### 条件检验：标准化前后，Lasso 选出的变量会不会不一样

会。这是 L1 惩罚最容易被忽略的坑，也是一个能自己验算的例子。

设两个预测变量正交，$n = 100$，OLS 系数 $\hat\beta^{\text{LS}} = (1.00,\ 0.06)$，但两者的**量纲差 10 倍**：$X_1$ 的标准差是 1（比如一个 0/1 的哑变量），$X_2$ 的标准差是 10（比如以千英里计的年行驶里程）。于是离差平方和

$$
S_{11} = n\cdot\mathrm{sd}_1^2 = 100, \qquad S_{22} = n\cdot\mathrm{sd}_2^2 = 10{,}000
$$

取 $\lambda = 80$，两种做法各自的阈值不一样：

| 做法 | 阈值 | $\hat\beta_1$ | $\hat\beta_2$ | 选出几个 |
|---|---|---|---|---|
| **不标准化**（原始单位） | $\lambda/(2S_{11}) = 0.80$；$\lambda/(2S_{22}) = 0.008$ | $1.00-0.80 = 0.200$ | $0.06-0.008 = 0.052$ | **2 个** |
| **标准化后**（$S_{jj}$ 都变成 $n=100$） | $80/200 = 0.80$（两个变量一样） | $0.200$ | $0.60-0.80 < 0 \Rightarrow \mathbf{0}$ | **1 个** |

标准化之后 $X_2$ 的系数变成 $0.06 \times 10 = 0.60$，落到阈值以下，被删了；不标准化时它的阈值只有 0.008，$0.052$ 就活下来了。

**同一个 λ、同一批数据，选出的变量个数不一样。** 原因在前两行：不标准化的阈值 $\lambda/(2\,n\,\mathrm{sd}_j^2)$ 里带着 $\mathrm{sd}_j^2$，量纲大的变量天然被罚得轻。这就是「$L_1/L_2$ 对尺度敏感」那句话的全部内容。（把 $y$ 也标准化只会把整条 λ 路径整体缩放 $\mathrm{sd}_y^2$，不改变这个结论。）

## 五、什么情况下会失灵

### 承重假设一：变量的尺度可比

撤掉它的后果就在上面那张表里：**选出的变量会随单位变**。把面积从平方米改成平方英尺，一个真实变量就可能进不了模型。这不是「精度差一点」，而是结论直接翻转。

处理：建模前统一标准化，并保证训练、调参、上线三处用同一个 scaler（scaler 的参数只能在训练集上估计）。

### 承重假设二：系数大小 = 复杂度

惩罚的是 $\beta$ 的大小，隐含假定「系数大的模型更复杂」。两个反例：

* **量纲已经不同**时，系数不可比（需要标准化）。
* **强相关的一组变量**里，系数的大小分配是任意的：ridge 会把系数在组内**均分**（每个都变小，于是每个都不显著），lasso 会在组内**近乎随机地挑一个**留下。撤掉这条假设的后果：同一批数据重抽一次样本，lasso 选出的变量可能换人（这叫做「自变量选择的不稳定性」）。处理：Elastic Net（分组效应）或 stability selection（bootstrap 后只留出现频率高的变量）。

### 承重假设三：CV 折内、折外同分布，且选择过程也在折内

如果预处理、变量选择放在划分之前做，CV 误差会偏低、λ 会偏小，上线后误差反弹。正确做法是**嵌套 CV**：外层评估、内层选 λ。

### λ 治不了的东西：完全分离

在 logistic regression 里，某个变量能完美分开两类时，似然随系数跑到无穷而不断改善，λ 的 CV 曲线往往**在 λ=0 处最优**。这时不是模型过拟合，而是 MLE 不存在；真正给有限估计的是 **Firth 惩罚**（见 [[1.6 Estimation Issues & Separation]]）。

### 与其他手段的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 变量少、挑过、要系数原样 | 全模型 / OLS | 惩罚只会带来偏差 |
| 变量相关、都有关，要全部保留 | Ridge / PCR | 收缩能救方差，且不丢变量 |
| 变量多、混着噪声特征，要稀疏 | Lasso | 能真正置零，选出子集 |
| 相关成组、又要稀疏 | Elastic Net | 分组进出，比 lasso 稳 |
| 要解释系数、要报送费率表 | 子集选择（forward/backward/stepwise） | 系数与变量集合都能逐条辩护 |
| 只追求预测精度 | GBM 等树模型 | 不需要线性结构，交互自动 |

> ⚠️ 一个常被放在一起但实际上不同的东西：**Ridge 和主成分回归（PCR）不是一回事**，但 PSL 的讨论把它们归为同一类 —— 都是「不置零的收缩」。设计矩阵里混入大量纯噪声特征时，它们会优先保留方差大的方向，而方差大不等于对 $Y$ 有用（教材原文 ④ 的 $X_3$ 就是这种情形）。

## 六、常见误解

### 误解一：「Lasso 选出的一定是真正有关的变量」

**错误想法**：lasso 把系数压到零，所以留下来的就是「真变量」。

**为什么容易这么想**：软阈值的形状太干净了 —— 小于阈值归零、大于阈值留下的就是信号，看起来像一次统计检验。

**错在哪一步**：两个地方。第一，λ>0 带来的收缩**本身引入偏差**：留下来的系数被系统性低估（第 3 步的表里，λ=80 时真实系数 1.60 被报成 1.20）。第二，**组内选择近乎随机**：两个相关系数 r=0.95 的变量，lasso 只会挑一个，挑谁主要由样本噪声决定。所以「lasso 选出来的变量集合」不能当作「因果变量清单」用，要看重抽样下的稳定性。

### 误解二：「Ridge 也会做变量选择，只是温和一点」

**错误想法**：λ 足够大的时候，ridge 的系数也接近 0，那和删掉差不多。

**为什么容易这么想**：第一张表里 λ=10 时 $\hat\beta_1$ 只剩 0.1455，确实小得可以忽略。

**错在哪一步**：把「数值小」当成了「结构上的零」。ridge 的解是 $\hat\beta_j/(1+\lambda)$，**只有 $\lambda=\infty$ 才等于 0**；而且它同比例压缩，变量之间的相对大小永远不变 —— 拿它做筛选，排在最后的那个变量永远删不掉。要稀疏，只能换 L1。反过来，ridge 有个 lasso 没有的用处：**它能处理共线性与 $p>n$**，因为有 $\lambda\mathbf{I}$ 兜着，矩阵一定可逆。

### 误解三：「正则化是模型的内部设置，不用管预处理」

**错误想法**：加个惩罚项而已，数据该怎么进就怎么进。

**为什么容易这么想**：惩罚项写在公式里，看起来和特征工程是两个世界的事。

**错在哪一步**：惩罚作用在**系数**上，而系数的大小取决于**特征的量纲**。条件检验那张表给出了具体的翻转：λ=80 时，不标准化选出 2 个变量，标准化之后只剩 1 个。同一个模型、同一份数据，因为输入单位不同，结论就变了。这正是「$L_1/L_2$ 对尺度敏感、必须先中心化/标准化」的原因。

### 误解四：「CV 选出的 λ 就是最好的 λ，越小越不亏」

**错误想法**：既然 CV 说 λ=0 最好，那就别正则化。

**为什么容易这么想**：CV 是标准做法，最小化 CV 误差看起来无可辩驳。

**错在哪一步**：CV 曲线在最优点附近常常很平，λ=0 与 λ=0.1 的 CV 误差差在小数第三位，但系数可以从 1.60 变成 1.45 —— **换来的稳定性是免费的**，所以实务上用 1-SE 规则往大取。更重要的是：CV 只在「同类问题」上替你选参数。分离问题里 CV 选 λ=0 不是好消息，而是在提示**模型设定错了**（MLE 不存在），该换 Firth 而不是调 λ。

## 七、面试怎么答

### 30 秒版

> 正则化就是在损失后面加一项惩罚：负对数似然加 λ 乘惩罚项。Ridge 用系数平方和，把所有系数按比例往零压，但到不了零；lasso 用绝对值和，正交设计下的解是软阈值，小于阈值的直接归零，所以它自带变量选择。几何上的原因是菱形有角。两个前提：先标准化、不罚截距。

### 2 分钟版（三块）

1. **动机**：过拟合（训练低、测试高）、共线性让系数不稳、$p>n$ 时解无穷多。惩罚项在这三种情形下都是「用偏差换方差」，贝叶斯语言里就是加先验（ridge ↔ 正态、lasso ↔ Laplace）。
2. **机制**：ridge 的 $\mathbf{X}^t\mathbf{X}+\lambda\mathbf{I}$ 一定有正特征值，所以可逆 —— 这是它能救共线性的关键一步；收缩比例是 $1/(1+\lambda)$（正交设计）。lasso 的阈值是 $\lambda/2n$，减到负数归零。
3. **口径与代价**：λ 的量纲随损失项走，跨库比 λ 先对齐惩罚写法；glmnet 默认标准化、sklearn 不默认，选出的变量会因此不同。λ 治过拟合，治不了完全分离。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么 L1 能置零、L2 不能？」 | 软阈值是减常数再取正部；L2 是乘一个小于 1 的数。几何版本：菱形角点在坐标轴上 |
| 「λ 怎么选？」 | K 折 CV 取最小；再按 1-SE 规则往大取。λ 没有绝对量纲，别背数字 |
| 「lasso 和 stepwise 有什么区别？」 | 都是选变量。lasso 是连续的路径（同一目标函数的解随 λ 变），stepwise 是离散的贪心搜索；lasso 的收缩带来偏差但更稳，且能处理 $p>n$ |
| 「什么时候加 Elastic Net？」 | 变量成组相关、又需要稀疏的时候；单用 lasso 会在组内随机挑一个 |
| 「Ridge 为什么不选变量，还用它？」 | 它能处理共线性与 $p>n$，且把系数在相关组内均分，预测更稳 |
| 「正则化能修分离吗？」 | 不能真正解决：分离的根因不是过拟合，CV 常选 λ=0；要给有限估计得用 Firth 惩罚 |
| 「必须标准化吗？」 | 必须（或至少保证尺度可比），否则阈值 $\lambda/(2n\,\mathrm{sd}_j^2)$ 会偏爱量纲大的变量 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Regularisation adds a penalty for complexity to the loss — we minimise the negative log-likelihood plus lambda times the penalty. Ridge uses the squared norm and shrinks coefficients smoothly; lasso uses the absolute norm and can set them exactly to zero, which is automatic feature selection."

**Mechanism**

> "Geometrically, the lasso constraint region is a diamond with corners on the axes, so the solution is likely to land on a corner — that's where a coefficient becomes exactly zero. Ridge is a circle, so it rarely does. And from a Bayesian view, ridge is a Gaussian prior and lasso is a Laplace prior."

**If they push back**

> "A common pitfall is forgetting to standardise the predictors first, because the penalty is scale-sensitive and otherwise you're penalising whichever variable happens to be measured in bigger units. One caveat on the numbers: whether the penalty is written as the squared norm or one half of it just rescales lambda by a factor of two, so different libraries can report very different lambdas for the same solution."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 正则化 | regularization | 在损失上加惩罚项，用偏差换方差 |
| 惩罚项 | penalty | $L_2$（平方和）或 $L_1$（绝对值和） |
| 调参量 | tuning parameter | $\lambda$，控制惩罚强度 |
| 岭回归 | ridge regression | $L_2$ 惩罚，等比例收缩系数，不置零 |
| Lasso | lasso regression | $L_1$ 惩罚，可把系数压到恰好为零 |
| 弹性网 | elastic net | $L_1+L_2$ 混合，相关组一起进一起出 |
| 软阈值 | soft-thresholding | Lasso 的正交解，$\text{sign}(\beta)(|\beta|-\lambda/2)_+$ |
| 稀疏性 | sparsity | 只有少数系数非零 |
| 有效自由度 | effective degrees of freedom | $\sum_j d_j^2/(d_j^2+\lambda)$，取值连续 |
| 系数路径 | coefficient path | 系数随 $\lambda$ 变化的轨迹 |
| K 折交叉验证 | K-fold cross-validation | 选 $\lambda$ 的标准做法 |
| 1-SE 规则 | one-standard-error rule | 在最小值 1 个标准误内取更大的 $\lambda$ |
| 最大后验估计 | maximum a posteriori (MAP) | 惩罚似然的贝叶斯读法 |
| 权重衰减 | weight decay | 神经网络里对 L2 惩罚的叫法 |
| 坐标下降 | coordinate descent | Lasso 的求解算法，一次更新一个系数 |
| 增广数据 | augmented data | 把 $\sqrt{\lambda}\mathbf{I}$ 接到 $\mathbf{X}$ 下面，把 ridge 写成 OLS |
| 良态 / 可逆 | full rank / invertible | $\mathbf{X}^t\mathbf{X}+\lambda\mathbf{I}$ 的特征值都 $>0$ |
| 稳定性选择 | stability selection | 重抽样后只留出现频率高的变量 |
