# 1.8 判别分析（Discriminant Analysis：LDA / QDA / 朴素贝叶斯）

## 速览 At a glance

**速记**

判别分析走的是**生成式**路线：先学「每一类长什么样」（类先验 $\pi_k$ 加上类条件密度 $f_k(x)$），再用 Bayes 定理翻成后验 $P(Y=k\mid X=x)$ 做决策。假设 $f_k$ 是多元正态之后，判别分只差一件事 —— **各类的协方差是否共享**：共享时对数似然比里的 $x'\Sigma^{-1}x$ 与类别无关、正好抵消，边界是**直线**（LDA）；各类各有一个 $\Sigma_k$ 时它消不掉，留下二次项与交叉项，边界变成**二次曲面**（QDA）。朴素贝叶斯再进一步，假设「给定类别后特征条件独立」，等于把协方差矩阵锁成对角阵，参数从 $O(p^2)$ 降到 $O(p)$：$p=50$ 时 LDA 要估 1376 个参数、QDA 2651 个，高斯朴素贝叶斯只要 201 个。参数个数的分界点在 $p>2K-1$（$K=2$ 时就是 $p\ge4$），越过它朴素贝叶斯的参数反而比 LDA 少。三个模型在这份 2 维玩具数据上都把 10 个训练点判全对，差别在没见过的点上：LDA 把中点 $(1.5,1.5)$ 放在边界上，QDA 判给方差更大的类 1（后验 0.826）。与逻辑回归的分野：逻辑回归直接建模 $P(Y=1\mid x)$（判别式），假设更弱、更通用；正态假设成立时 LDA 更有效，特征稀疏（二值、计数）时逻辑回归更稳。

**一句面试答法**

> "LDA, QDA and Naive Bayes are all generative: we model the class priors and the class-conditional densities, then use Bayes' rule to get the posterior. The only difference between LDA and QDA is whether the classes share a covariance matrix — with a shared Sigma the quadratic term is the same for every class and cancels, so the boundary is linear; with class-specific Sigmas it survives and the boundary becomes quadratic. Naive Bayes assumes the features are conditionally independent given the class, which cuts the parameters from order p squared to order p; it is a strong regulariser that often still classifies well when the assumption is false, but the probabilities come out over-confident."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 判别分析 | discriminant analysis (DA) | 用类先验与类条件密度做分类的生成式方法 |
| 生成式模型 | generative model | 建模 $p(x,y)$，再用 Bayes 定理得到后验 |
| 判别式模型 | discriminative model | 直接建模 $P(Y\mid X)$，代表是逻辑回归 |
| 线性判别分析 | linear discriminant analysis (LDA) | 各类共享协方差 ⇒ 线性边界 |
| 二次判别分析 | quadratic discriminant analysis (QDA) | 各类各自协方差 ⇒ 二次边界 |
| 朴素贝叶斯 | naive Bayes | 给定类别后特征条件独立，高斯版每类只要 $2p$ 个参数 |

| 类条件密度 | class-conditional density | $f_k(x)=p(x\mid Y=k)$，LDA/QDA 里取多元正态 |
| 判别分 | discriminant score | $\delta_k(x)$，取最大者即预测类 |
| 池化协方差 | pooled covariance | LDA 用的那个共享 $\Sigma$，按自由度合并各类样本 |
| 马氏距离 | Mahalanobis distance | 用 $\Sigma^{-1}$ 量出的「离中心多远」，第二步就消掉 |
| 收缩 | shrinkage / regularisation | 把每类协方差拉向共享协方差，救 QDA 的过拟合 |

## 一、先看一个问题

手上有两类客户的两个特征，画在平面上是这样：类 0 挤在原点附近，像一个小十字；类 1 在 $(3,3)$ 附近，形状一样但摊得更开。

| 类 0 | 类 1 |
|---|---|
| (0, 0) | (3, 3) |
| (1, 0) | (4, 4) |
| (−1, 0) | (2, 2) |
| (0, 1) | (4, 2) |
| (0, −1) | (2, 4) |

现在要回答三个问题：**决策边界是什么形状**？**$(1.5,1.5)$ 这个点判给哪一类**？以及**先验从 0.5/0.5 改到 0.8/0.2 会怎样**？

直觉会说「边界是两类中间的线」，更进阶的直觉会说「类 1 摊得开，所以离得远的点更可能是它」。这两句话都对，但对应**两个不同的模型**：前一句是 LDA（假定两类形状相同），后一句是 QDA（允许形状不同）。第三个问题考的是先验怎么进判别分。

这一页要讲清的就是这三种方法在同一份数据上给出什么不同的答案，以及它们与逻辑回归那条路线的分工 —— banner 里那道 **"How do a linear model and a GLM differ?"** 的对照面正在这里：GLM 走判别式路线，判别分析走生成式路线。

## 📖 标准定义

> **教材原文 · PSL §9.2 Discriminant Analysis、§9.3 QDA、§9.4 LDA（页面 w9_2_DA.html / w9_3_QDA.html / w9_4_LDA.html）**（<https://liangfgithub.github.io/PSL/w9/w9_2_DA.html>）
> > "We aim to learn the joint distribution $p(x,y)$ by breaking it down into two parts:"
> >
> > "This approach, which involves learning the classifications in this manner, is commonly referred to as discriminant analysis"
> >
> > "Our primary objective is to calculate the posterior probability $P(Y=k | X=x)$"
> >
> > "This classification rule, described here, is known as quadratic discriminant analysis (QDA) . The key characteristic of QDA is that the function used to make decisions is quadratic in terms of the feature vector"
> >
> > "When we assume that all covariance matrices are the same for all classes, we essentially revert to Linear Discriminant Analysis (LDA) since the discriminant function becomes linear."

**标准记法**：

- Bayes 决策函数 $\arg\max_k \pi_k f_k(x) = \arg\max_k \big[ \log \pi_k + \log f_k(x) \big]$，$\pi_k = P(Y=k)$，$f_k(x) = p(x \mid Y=k)$。
- QDA：$f_k(x)$ 为 $N(\mu_k, \Sigma_k)$，判别分 $d_k(x) = (x-\mu_k)^t \Sigma_k^{-1} (x-\mu_k) + \log \vert \Sigma_k \vert - 2 \log \pi_k$。
- LDA：$\Sigma_k = \Sigma$，判别分对 $x$ 线性（第一项中 $x^t \Sigma^{-1} x$ 与 $k$ 无关可消去）；$\hat{\Sigma} = \frac{1}{n-K} \sum_{k=1}^K \sum_{i: y_i=k} (x_i - \hat{\mu}_k)(x_i - \hat{\mu}_k)^t$。
- （通用形式，非某本教材独有；判别分与 pooled 协方差即 PSL §9.3/§9.4 原文公式。）

**中文解释**：判别分析是「生成式」路线：估先验 $\pi_k$ 与类条件密度 $f_k(x)$，再用 Bayes 定理得到后验做决策，而不是直接建模 $P(Y=k|X=x)$。假设 $f_k$ 是多元正态：协方差各自不同 → 判别函数是二次的（QDA）；假设各类共享同一个 $\Sigma$ → 判别函数线性（LDA），可用 pooled 样本协方差估计。

> 完整条目与更多来源见 [[定义原文库#D22. 判别分析 / LDA / QDA|D22. 判别分析 / LDA / QDA]]

> **教材原文 · PSL §9.6 Naive Bayes Classifiers（页面 w9_6_NB.html）**（<https://liangfgithub.github.io/PSL/w9/w9_6_NB.html>）
> > "The “Naive” part of Naive Bayes comes from the assumption of feature independence. It assumes that the features are conditionally independent of each other given the class label. This simplifies the computation and makes it computationally efficient."
> >
> > "In Naive Bayes, we factorize the joint distribution function into individual one-dimensional distribution functions for these p elements. This concept can be seen as a way to introduce independence as a form of regularization for high-dimensional problems."
> >
> > "To test your understanding: When employing parametric Naive Bayes, how many parameters must we estimate? We indeed need p means, one for each dimension, and p variances, one for each dimension, totaling 2p parameters."
> >
> > "Some Naive Bayes packages may compute this term using the first line, i.e., by evaluating the normal probability density function (pdf) and then taking the logarithm. When $x^*$ is far from the center, the normal pdf can become very small, leading to numerical issues when applying the logarithm."

**标准记法**：

- 决策函数 $\arg\max_k P(Y=k | X=x) = \arg\max_k \pi_k f_k(x)$；朴素贝叶斯假设 $f_k(x) = f_{k1}(x_1) \times f_{k2}(x_2) \cdots \times f_{kp}(x_p)$。
- 参数化版本（高斯）判别分 $d_k(x^*) = - \log \pi_k + \frac{1}{2} \sum_{j=1}^p \big[ \log \sigma^2_{kj} + \frac{(x^*_j - \mu_{kj})^2}{\sigma_{kj}^2} \big]$，参数个数 $2p$。
- （通用形式，非某本教材独有；判别分与 $2p$ 结论即 PSL §9.6 原文。）

**中文解释**：朴素贝叶斯假设「给定类别后特征相互独立」，把 $p$ 维联合密度拆成 $p$ 个一维密度相乘，因此参数从 $O(p^2)$ 降到 $O(p)$（高斯版只需 $2p$ 个）。这层独立性假设可以理解为高维下的正则化。工程上注意很多实现的 log-pdf 截断会导致数值问题。

> 完整条目与更多来源见 [[定义原文库#D23. 朴素贝叶斯分类器|D23. 朴素贝叶斯分类器]]

## 二、核心直觉

### 先问「每一类长什么样」，再问「这个点属于谁」

判别式模型（逻辑回归）的思路是：直接把「给定 $x$、属于类 1 的概率」写成 $x$ 的函数，参数靠优化损失得到。

生成式模型（本页三种）的思路是分两步：先用每一类的**训练样本自己**估出「这一类长什么样」（一个均值、一个协方差、一个先验比例），然后用 Bayes 定理把这两块翻成后验。谁都不需要解最优化问题 —— 全是均值与协方差的算术。

代价与好处都从这一步来。好处是：正态假设成立时，模型已经把「数据是怎么生成的」写对了，参数少、方差小，小样本下常常比逻辑回归准。代价是：假设一旦不成立（特征是二值的、分布是重尾的），估出来的均值与协方差都在替错误的结构服务，逻辑回归反而更稳。

### 一条假设决定边界的形状

把 $f_k$ 取成多元正态之后，后验比较可以化简成比较一个**判别分**，它由三块组成：先验、$x$ 离第 $k$ 类中心的距离（用 $\Sigma_k^{-1}$ 度量）、协方差的行列式（惩罚摊得开的类）。三块里唯一影响边界形状的是第二块里的 $\Sigma_k$：

| $\Sigma_k$ 的假设 | 边界形状 | 参数个数（$p$ 维、$K$ 类） |
|---|---|---|
| 各类共享一个 $\Sigma$ | 线性 | $Kp+p(p+1)/2+(K-1)$ |
| 各类各自一个 $\Sigma_k$ | 二次 | $Kp+Kp(p+1)/2+(K-1)$ |
| 对角阵（特征条件独立） | 每个特征各贡献一个平方项，没有交叉项 | $2Kp+(K-1)$ |

**类比的边界**：像先描出每类点的「云团」，再看新点落在哪团云里更常见。不像的地方是：这里不是目测，云团必须是正态的；而且判别分里的 $\Sigma^{-1}$ 会把「方向」也考虑进去 —— 云团是斜的时候，边界不垂直于两中心的连线（第四节的第二步会给一个 30.96° 的例子）。

### 三个模型的分工

- **LDA**：形状相同（共享协方差），只有位置（类中心）不同 —— 参数最省、最稳、可解释方向；
- **QDA**：位置和形状都不同 —— 更灵活，代价是参数按 $K$ 倍增长，$p$ 一大就样本不足；
- **朴素贝叶斯**：干脆假设各维互不相关 —— 假设最糙、参数最少，但高维小样本时常常打不过的东西最少；
- **逻辑回归**：不做任何关于 $X$ 分布的假设，只假设 log-odds 对 $x$ 线性 —— 这就是 [[1.3 Introducing Logistic Regression]] 那一侧。

---

### 先给结论：一句话版

判别分析走的是**生成式**路线：先学「每一类长什么样」（类先验 $\pi_k$ 加上类条件密度 $f_k(x)$），再用 Bayes 定理翻成后验 $P(Y=k\mid X=x)$ 来做决策；LDA 与 QDA 之间只差一条假设——**各类的协方差是否共享**（共享就是线性边界，各自不同就是二次边界），而朴素贝叶斯再进一步假设「给定类别后各个特征条件独立」，把参数从 $O(p^2)$ 压到 $O(p)$，是超高维、小样本场景里最省样本的基线模型。

## 三、机制

### 3.1 定义与逐项说明：从 Bayes 决策规则到判别分

判别分析的出发点是 Bayes 定理，而不是「找个边界把两类分开」：

$$P(Y=k\mid X=x)=\frac{\pi_k\,f_k(x)}{\sum_{l=1}^{K}\pi_l\,f_l(x)},\qquad \pi_k=P(Y=k),\quad f_k(x)=p(x\mid Y=k)$$

- $\pi_k$ 是**类先验（class prior）**：不看 $x$ 时一个观测属于第 $k$ 类的概率；
- $f_k(x)$ 是**类条件密度（class-conditional density）**：第 $k$ 类内部的 $x$ 长什么样；
- 分母与 $k$ 无关，所以做决策只要比较 $\pi_k f_k(x)$。

**决策规则**：$\hat y=\arg\max_k \pi_k f_k(x)$，等价于比较 $\log\pi_k+\log f_k(x)$ —— 取对数既避免下溢，也把乘积变成加法。

只差最后一步假设：$f_k$ 取什么形状。取多元正态 $N(\mu_k,\Sigma_k)$ 代入，丢掉与 $k$ 无关的项，得到**判别分（discriminant score）**

$$\delta_k(x)=-\tfrac12\log\lvert\Sigma_k\rvert-\tfrac12(x-\mu_k)'\Sigma_k^{-1}(x-\mu_k)+\log\pi_k,\qquad \hat y=\arg\max_k\delta_k(x)$$

逐项读：第一项惩罚「协方差大的类」（摊得越开、峰值越低）；第二项是**马氏距离（Mahalanobis distance）**平方的一半，量 $x$ 离第 $k$ 类中心的远近，方向由 $\Sigma_k^{-1}$ 加权；第三项是先验。

> **口径提示**：PSL 把这个量写成 $d_k(x)=(x-\mu_k)'\Sigma_k^{-1}(x-\mu_k)+\log\lvert\Sigma_k\rvert-2\log\pi_k$，那是**要最小化**的版本，与本节要最大化的 $\delta_k$ 满足 $d_k(x)=-2\delta_k(x)$；单调反向，所以取 max 还是取 min 给出同样的预测。看到别人写的判别分先看他要 max 还是 min，再对系数。

#### 三种方法的假设对比

| 维度 | LDA | QDA | Naive Bayes |
|---|---|---|---|
| 类条件分布假设 | 每类都服从多元正态，且**所有类共享同一个** $\Sigma$ | 每类服从多元正态，**各自一个** $\Sigma_k$ | 给定类别后**特征条件独立**；高斯版每个维度各有一个均值与方差（等于把协方差矩阵假设成对角） |
| 决策边界形状 | **线性**（判别分对 $x$ 线性） | **二次**（含 $x$ 的平方项与交叉项） | 一般不是线性；高斯版每个特征贡献一个二次项，但没有交叉项 |
| 参数个数（$p$ 维、$K$ 类） | $Kp$（各类均值）$+\,p(p+1)/2$（共享协方差）$+\,(K-1)$（先验） | $Kp + K\,p(p+1)/2 + (K-1)$ | $2Kp + (K-1)$ |
| 何时用 | 样本量中等、各类协方差相近、想要稳的线性边界与可解释的方向 | 各类的「形状 / 方向」明显不同，且样本足够为每个类估一份协方差 | 特征很多或近似独立、样本很少；文本与计数特征的经典基线 |

**这张表最关键的一列是协方差假设**：它是让 LDA 与 QDA 分界的**唯一**条件，也是面试被追问时最该先说出的一句。参数个数的直觉也在这里：共享协方差只有 $p(p+1)/2$ 个待估量，QDA 要为 $K$ 个类各估一份（$K\,p(p+1)/2$，随 $p$ 平方增长），朴素贝叶斯干脆把所有变量间的相关性都假设成零，于是高斯版每类只要 $2p$ 个参数——**假设越强、参数越少、方差越小，但偏差越大**，这就是三者取舍的全部内容。

### 3.2 它是怎么来的：LDA 的线性边界是消出来的

拿二分类、共享协方差 $\Sigma_k=\Sigma$ 的情况手推一次。比较两类的判别分：

$$\delta_1(x)-\delta_0(x)=\log\frac{\pi_1}{\pi_0}-\tfrac12\log\frac{\lvert\Sigma\rvert}{\lvert\Sigma\rvert}-\tfrac12\Big[(x-\mu_1)'\Sigma^{-1}(x-\mu_1)-(x-\mu_0)'\Sigma^{-1}(x-\mu_0)\Big]$$

把两个二次型展开：$(x-\mu_k)'\Sigma^{-1}(x-\mu_k)=x'\Sigma^{-1}x-2x'\Sigma^{-1}\mu_k+\mu_k'\Sigma^{-1}\mu_k$。两边各有一个 $x'\Sigma^{-1}x$，**系数都是 1，相减时正好抵消** —— 这就是「LDA 的边界是线性的」的全部来源。剩下的只含 $x$ 的一次项：

$$\delta_1(x)-\delta_0(x)=x'\Sigma^{-1}(\mu_1-\mu_0)-\tfrac12(\mu_1+\mu_0)'\Sigma^{-1}(\mu_1-\mu_0)+\log\frac{\pi_1}{\pi_0}$$

**关键一步就是这次抵消。** 如果 $\Sigma_1\ne\Sigma_0$，两个 $x'\Sigma_k^{-1}x$ 的系数不同，消不掉，判别分里留下二次项与交叉项 —— QDA 的边界变成二次，来源就在这里。

$\Sigma$ 用合并样本估：$\hat\Sigma=\frac{1}{n-K}\sum_{k=1}^{K}\sum_{i:\,y_i=k}(x_i-\hat\mu_k)(x_i-\hat\mu_k)'$，也就是**池化协方差（pooled covariance）**；判别方向是 $\hat\Sigma^{-1}(\hat\mu_1-\hat\mu_0)$。

**方向不是均值连线。** $\Sigma^{-1}$ 会给各维不同的权重：取 $\Delta\mu=(3,3)$、$\Sigma=\mathrm{diag}(1/3,\ 4/3)$（第二维波动是第一维的 4 倍），则 $w=\Sigma^{-1}\Delta\mu=(9,\ 2.25)\propto(4,\ 1)$，与均值连线夹角 **30.96°**。只有当协方差是各向同性（$\Sigma\propto\mathbf I$）时，$w$ 才与 $\Delta\mu$ 平行，边界才是两中心连线的垂直平分线 —— 第四节的算例正好落在这个特例里。

### 3.3 变形与口径：与逻辑回归的关系

两者都能做二分类、都能输出后验概率，但**建模的对象完全不同**，面试里把这几点说清楚就够了：

1. **同：目标一致**。逻辑回归直接建模 $P(Y=1\mid X=x)$（判别式，discriminative）；LDA、QDA、朴素贝叶斯先建模联合分布（生成式，generative），再用 Bayes 定理翻成后验。样本量趋于无穷时，两条路线都收敛到同一个贝叶斯分类器。
2. **逻辑回归不假设 $X$ 的分布**：它只假设 log-odds 对特征线性；LDA 则假设「每一类的特征都服从正态，而且各类协方差相同」。LDA 的假设更强，所以在假设成立时它能「借力」；逻辑回归的假设更弱，所以更通用。
3. **正态假设成立时 LDA 更有效（方差更低）**：数据真满足 LDA 的假设时，LDA 用更少的参数就抓住了真实结构，估计方差更小，小样本下常比逻辑回归更准；一旦假设被破坏，LDA 会系统性偏错，而逻辑回归依然稳健——**「更有效」与「更稳健」正是这两条路线的取舍**。
4. **特征空间稀疏时逻辑回归更稳**：风控与保险里常见的是二值、计数或极度偏态的变量，正态假设明显不成立，LDA 的均值与协方差估计都不稳，这时逻辑回归（或者用「正确似然」的朴素贝叶斯）更可靠。
5. **对异常值的敏感度不同**：LDA 的判别方向由类均值与协方差决定，少数极端点会同时拉偏均值、撑大协方差，从而把判别边界整体旋转（正态似然对远处的点极其敏感）；逻辑回归的极大似然影响函数有界，单个极端点的影响相对更小，但完全分离时又会不收敛（见 [[1.6 Estimation Issues & Separation]]）。
6. **分离数据下的表现不同**：无正则化的逻辑回归遇到完全分离会发散；LDA 因为协方差矩阵本身就提供了「方向上的正则化」，即使数据分离也能给出一个有限的判别函数。
7. **加分点：两者的解往往很像**。现实中逻辑回归的 MLE 方向与 LDA 的判别方向非常接近；区别在于逻辑回归更容易加正则、加样条与交互（GAM），而 LDA 还能顺手做有监督降维（Fisher 判别方向，投影到 $K-1$ 维），这一点常被拿来和 PCA 对照。

## 四、算一遍

两类、两个特征、每类 5 个训练点。三种方法的判别分都手推一遍，同一个点上的结论摆在一起对比；所有数字都用 `numpy` 复算过。

### 数据

| 类 0（小样本、紧） | 类 1（大样本、松） |
|---|---|
| (0, 0) | (3, 3) |
| (1, 0) | (4, 4) |
| (−1, 0) | (2, 2) |
| (0, 1) | (4, 2) |
| (0, −1) | (2, 4) |

类 1 是把类 0 的十字形平移到 $(3,3)$，所以两类的**形状相同、摊开程度不同**。先验按样本比例取各 0.5。

### 第 1 步：类中心与协方差

$$\hat\mu_0=(0,\ 0),\qquad \hat\mu_1=(3,\ 3),\qquad \hat\Sigma_0=\begin{pmatrix}0.5&0\\0&0.5\end{pmatrix},\qquad \hat\Sigma_1=\begin{pmatrix}1&0\\0&1\end{pmatrix}$$

协方差用 $n-1=4$ 做分母。核对类 0：十字形的四个方向点各贡献一个 $(-1)^2$ 或 $1^2$，每个方向的和是 2，所以方差是 $2/4=0.5$；交叉项正负成对、抵消为 0，所以是对角阵。$|\hat\Sigma_0|=0.25$、$|\hat\Sigma_1|=1$ —— 类 1 摊得更开，判别分第一项 $-\tfrac12\log\lvert\Sigma_k\rvert$ 会给它加分。

### 第 2 步：LDA（共享协方差）

按自由度合并：$\hat\Sigma_p=\frac{4\hat\Sigma_0+4\hat\Sigma_1}{10-2}=0.75\,\mathbf I$，$\hat\Sigma_p^{-1}=\frac43\mathbf I$，判别方向 $\hat\Sigma_p^{-1}(\mu_1-\mu_0)=(4,\ 4)\propto(1,\ 1)$。

$$\delta_0(x)=-\log 2,\qquad \delta_1(x)=-\log 2+4(x_1+x_2)-12$$

边界 $\delta_1=\delta_0$ 给出 $x_1+x_2=3$：一条斜率为 −1 的直线，正好是两中心连线的垂直平分线（因为协方差是各向同性）。

### 第 3 步：QDA（各自协方差）

$\hat\Sigma_0^{-1}=2\mathbf I$、$\hat\Sigma_1^{-1}=\mathbf I$、$-\tfrac12\log\lvert\hat\Sigma_0\rvert=\log 2$、$-\tfrac12\log\lvert\hat\Sigma_1\rvert=0$，所以

$$\delta_0(x)=-(x_1^2+x_2^2),\qquad \delta_1(x)=-\log 2-\tfrac12\big[(x_1-3)^2+(x_2-3)^2\big]$$

边界 $\delta_0=\delta_1$ 化简成 $x_1^2+x_2^2+6(x_1+x_2)=19.3863$，配方后是

$$(x_1+3)^2+(x_2+3)^2=37.3863\quad\Rightarrow\quad R=\mathbf{6.1144}$$

一个圆心 $(-3,-3)$、半径 6.1144 的圆。**圆内判类 0（紧的那类），圆外判类 1（松的那类）** —— 类 0 的密度峰值高但衰减快，所以离远了就不像它。

### 第 4 步：三个模型在几个点上对同一个数

判别分差取 $\delta_0-\delta_1$，负数表示判类 1：

| 测试点 | LDA 分差 | LDA 判 | QDA 分差 | QDA 判 | NB 分差 | NB 判 | $P(1\mid\text{LDA})$ | $P(1\mid\text{QDA})$ |
|---|---|---|---|---|---|---|---|---|
| (1.5, 1.5) | 0.0000 | 边界上 | −1.5569 | 1 | −1.5569 | 1 | 0.5000 | 0.8259 |
| (2, 2) | −4.0000 | 1 | −6.3069 | 1 | −6.3069 | 1 | 0.9820 | 0.9982 |
| (1, 1) | +4.0000 | 0 | +2.6931 | 0 | +2.6931 | 0 | 0.0180 | 0.0634 |
| (2.5, 0.5) | 0.0000 | 边界上 | −2.5569 | 1 | −2.5569 | 1 | 0.5000 | 0.9280 |

读法：$(2.5,0.5)$ 这个点按 LDA 正落在边界上（分差 0.0000），而 QDA 说它是类 1、后验 0.928 —— **同一个问题、同一份数据、两个模型的答案不同**，差别只来自「两个类的形状是否必须相同」。

### 第 5 步：朴素贝叶斯在这份数据上做了什么

高斯朴素贝叶斯假设「给定类别后各维独立」，等价于把 $\Sigma_k$ 锁成对角阵 $\mathrm{diag}(\sigma^2_{k1},\sigma^2_{k2})$。这份数据的两个协方差**本来就是对角阵**，所以 NB 的判别分与 QDA 逐个点完全一致（上表两列一模一样）。差别要到特征相关时才出现：那时 QDA 会利用协方差里的非对角项，NB 直接把它当 0 丢掉。

参数个数也一样直观。$p$ 维、$K$ 类时：

| $p$ | LDA：$Kp+\frac{p(p+1)}{2}+(K-1)$ | QDA：$Kp+K\frac{p(p+1)}{2}+(K-1)$ | NB：$2Kp+(K-1)$ |
|---|---|---|---|
| 2 | 8 | 11 | 9 |
| 3 | 13 | 19 | 13 |
| 4 | 19 | 29 | **17** |
| 10 | 76 | 131 | **41** |
| 50 | 1376 | 2651 | **201** |

三个模型在这 10 个训练点上都是全对（10/10）；分别出现在第 2 行第 4 列 —— 参数个数的反转发生在 $p>2K-1$（$K=2$ 时 $p\ge4$），因为 NB 的参数随 $p$ 线性长，LDA 的随 $p^2$ 长。

### 条件检验：先验从 0.5/0.5 改成 0.8/0.2

判别分里先验只以 $\log\pi_k$ 的形式出现，所以改先验等于给两类的分差整体加一个常数：

$$\log\frac{0.8}{0.2}=\log 4=\mathbf{1.3863}$$

- LDA 的边界从 $x_1+x_2=3$ 挪到 $x_1+x_2=3+1.3863/4=\mathbf{3.3466}$，沿 $(1,1)$ 方向的欧氏平移 $1.3863/(4\sqrt2)=\mathbf{0.2451}$；
- 四个测试点的**判定都没有翻**，只有 $(1.5,1.5)$ 从「正落在边界上」变成判类 0；
- QDA 的圆也整个往外挪，形状不变（半径不变，圆心不动，判据从 $\delta_0$ 起算的常数项改变）。

这就是「先验是显式参数」的含义：类别极不平衡时，默认用样本比例当先验会让边界偏向多数类；LDA 与朴素贝叶斯可以直接把业务基础率填进 $\pi_k$，而逻辑回归要达到同样效果只能靠重采样或加权间接实现。

## 五、什么情况下会失灵

三种方法都建立在同一件事上：**类条件密度估得准**。它们没有损失函数，也没有「拟合不好」的反馈信号，所以失灵往往是静默的。

### 承重假设一：类条件密度真的是正态

撤掉它，均值与协方差都在替错误的结构服务。二值、计数、极度偏态的特征是重灾区：这类变量上「类均值」基本没有意义，「协方差」更是被尾部拖着走。

### 承重假设二：样本量撑得住要估的参数个数

QDA 要为每一类估 $\frac{p(p+1)}{2}$ 个协方差参数，某个类的样本数少于 $p$ 时协方差矩阵奇异，判别函数不是报错就是剧烈波动。$p=50$ 时 QDA 要估 2651 个参数，这需要非常大的样本。

### 承重假设三：先验代表部署时的真实基础率

判别分里的 $\log\pi_k$ 直接决定边界的平移量。训练集里少数类占 5%，但生产环境里占 40%，用样本比例当先验会系统性地把预测推向多数类 —— 第四节最后一段量化了这件事。

### 承重假设四（朴素贝叶斯专用）：条件独立

特征之间相关时，独立假设会把同一份证据数两遍，后验概率被推向 0 和 1。分类与排序常常还行（PSL 把这一层独立性当作**高维下的正则化**），但概率水平不可信，做阈值决策前要先校准。

### 常见坑清单：六个具体形态

- **QDA 的参数随 $p$ 平方增长，样本不够就会翻车**：每个类都要估自己的 $p(p+1)/2$ 个协方差参数，$p$ 一大、或者某个类的样本数少于 $p$，协方差就奇异，判别函数不是报错就是剧烈过拟合。处方是 `reg_param` 收缩、先做降维，或者退回 LDA / 朴素贝叶斯。
- **朴素贝叶斯的独立性假设几乎总不成立，但它依然能用**：特征相关时有偏，可是分类与排序常常还行——PSL 的视角是「独立性相当于给高维问题加了一层正则化」；代价是输出的后验概率往往过度自信（贴在 0 与 1 附近），要拿去做阈值决策或算期望损失之前，先做概率校准。
- **LDA 的对数似然比给出线性边界，这一步要能自己推**：两个正态密度相除再取对数，二次项只差一个与类别无关的 $x^t\Sigma^{-1}x$，可以直接消掉，剩下的就是 $x$ 的线性函数；一旦各类协方差不同，二次项消不掉，边界就变成二次的（QDA）。
- **先验的影响是「平移边界」**：判别分里有一项 $\log \pi_k$，改先验等于沿着判别方向平移决策面。类别极不平衡时，默认用样本比例当先验会让边界偏向多数类；而 LDA 与朴素贝叶斯的先验是**显式参数**，可以按业务基础率直接改——逻辑回归要做同一件事，只能靠重采样或加权间接实现。
- **高斯朴素贝叶斯的数值问题**：先把正态 pdf 算出来再取对数，点离中心很远时 pdf 会下溢成 0，取对数变成负无穷，PSL 原文专门点了这个坑；工程上用 log 形式或 `var_smoothing` 兜底。
- **把 LDA 只当成分类器**：它同时是有监督降维（Fisher 判别方向），二分类最多投影到 $K-1$ 维，这也是它常被拿来与 PCA 对照的原因。

## 六、常见误解

### 误解一：「LDA 和逻辑回归差不多，随便挑一个」

**错误想法**：两者都能做二分类、都能输出后验概率，实务上没区别。

**为什么容易这么想**：在真实数据上两者的判别方向确实非常接近（见 3.3 的第 7 条），而且多数软件里改一行就能换。

**错在哪一步**：两者的**假设强度**不同。LDA 假设每一类的 $x$ 服从正态且共享协方差；逻辑回归只假设 log-odds 对 $x$ 线性，对 $X$ 的分布不作要求。正态假设成立时 LDA 用更少的参数抓住结构、小样本下更有效；假设被破坏时（二值、计数、重尾特征）LDA 系统性偏错，逻辑回归仍然稳。分开它们的不是「谁更准」，而是「哪套假设在你的数据上成立」。

### 误解二：「QDA 更灵活，所以应该总是比 LDA 好」

**错误想法**：假设更少、边界更复杂，性能当然更好。

**为什么容易这么想**：QDA 把 LDA 当特例（$\Sigma_k$ 全相等就退化成 LDA），「更一般」听起来总是更安全。

**错在哪一步**：参数个数按 $K$ 倍增长（$p=50$、$K=2$ 时 1376 → 2651），估出来的协方差矩阵方差更大；某个类样本不足时它直接奇异。灵活性的代价是方差，$p$ 一大、样本一少就翻车 —— `reg_param` 这种收缩参数就是把这部分方差换回来。

### 误解三：「条件独立假设几乎不成立，朴素贝叶斯没什么用」

**错误想法**：特征之间全都相关，独立假设就是错的，模型不可用。

**为什么容易这么想**：这句话在数学上确实成立 —— 真实数据里几乎找不到条件独立的特征。

**错在哪一步**：假设错 ≠ 模型无用。独立假设把参数从 $O(p^2)$ 压到 $O(p)$，等于给高维问题加了一层强正则化：偏差大了，方差小了，分类与排序常常还很能打（文本分类的经典结果就是这么来的）。真正会坏的是**概率水平** —— 相关特征被重复计数，后验贴在 0 与 1 附近，要用它算期望损失就得先做校准。

### 误解四：「判别分析只能当分类器」

**错误想法**：LDA 就是一条线，做完预测就没了。

**为什么容易这么想**：名字里有「判别」，文档示例也只给 `predict`。

**错在哪一步**：LDA 同时是一个**有监督降维**方法：把数据投影到 Fisher 判别方向，二分类最多降到 $K-1=1$ 维，这是它与 PCA 常被放在一起对照的原因（PCA 不看标签，LDA 看）。另外，先验与协方差是**显式参数**，可以直接改成业务基础率或加收缩 —— 这是逻辑回归不容易做到的一点。

## 七、面试怎么答

### 30 秒版

> 三种方法都是生成式：估先验 $\pi_k$ 和类条件密度 $f_k(x)$，用 Bayes 定理得到后验。LDA 与 QDA 的唯一差别是协方差是否共享：共享时判别分里的二次项与类别无关、相减消掉，边界是直线；各类各有一个协方差时消不掉，边界变成二次。朴素贝叶斯再假设给定类别后特征条件独立，把协方差锁成对角阵，参数从 $O(p^2)$ 降到 $O(p)$ —— $p=50$ 时 LDA 要估 1376 个参数、QDA 2651 个，它只要 201 个。与逻辑回归相比：LDA 假设更强、正态成立时更有效；逻辑回归不做 $X$ 的分布假设，特征稀疏时更稳。

### 2 分钟版（要包含的三块）

1. **生成式 vs 判别式的分野**：建模 $p(x,y)$ 还是直接建模 $P(Y\mid X)$，以及为什么生成式在小样本、判别式在假设不成立时更有优势；
2. **一条假设决定边界形状**：共享协方差 ⇒ 线性（推导出二次项抵消那一步），各自协方差 ⇒ 二次，对角 ⇒ 无交叉项；再报出三者的参数个数公式；
3. **先验与校准**：$\log\pi_k$ 怎样平移边界（本节给了 0.2451 的平移量），朴素贝叶斯的过度自信为什么要校准，以及 QDA 在样本不足时用收缩兜底。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「LDA 与 QDA 的唯一差别」 | 协方差是否共享；共享 ⇒ 二次项抵消 ⇒ 线性边界 |
| 「为什么线性」 | 对数似然比里 $x'\Sigma^{-1}x$ 与类别无关，相减时消掉；$\Sigma_k$ 不同就消不掉 |
| 「三种模型怎么选」 | 看样本量与特征类型：协方差可信 → LDA/QDA；特征近独立或 $p$ 很大 → 朴素贝叶斯；特征稀疏偏态 → 逻辑回归 |
| 「先验怎么进模型」 | 判别分里的 $\log\pi_k$，等价于平移边界；是显式参数，可按业务基础率直接改 |
| 「参数个数」 | LDA $Kp+\frac{p(p+1)}{2}+(K-1)$；QDA $Kp+K\frac{p(p+1)}{2}+(K-1)$；NB $2Kp+(K-1)$；分界点 $p>2K-1$ |
| 「数据分离时怎么样」 | LDA 的协方差本身提供方向上的正则化，仍给有限解；逻辑回归会发散（见 [[1.6 Estimation Issues & Separation]]） |
| 「朴素贝叶斯为什么要校准」 | 条件独立被违反时证据被重复计数，后验过度自信；用 Platt / isotonic 校准 |

## 八、真题与自测

本页是 §1 与 §9 的支撑知识，对应 banner 里那条 **"How do a linear model and a GLM differ?"** 的对照面：GLM 走判别式路线（直接建模 $P(Y\mid X)$），判别分析走生成式路线（建模 $p(x,y)$ 再翻成后验）。

1. LDA 的边界为什么是线性的？（对数似然比里两个二次型的 $x'\Sigma^{-1}x$ 系数相同，相减抵消）

3. 先验从 0.5/0.5 改成 0.8/0.2，边界动多少？（分差整体加 $\log 4$；$x_1+x_2=3$ 挪到 3.3466，沿法向平移 0.2451）

```python
X, y = make_classification(n_samples=2000, n_features=10, n_informative=6,
                           n_redundant=2, class_sep=1.0, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3,
                                          stratify=y, random_state=0)

# ---- 1) LDA：各类共享协方差 -> 线性决策边界 ----
lda = LinearDiscriminantAnalysis(solver="svd")   # "lsqr"/"eigen" 支持 shrinkage 与降维
lda.fit(X_tr, y_tr)
print("LDA accuracy:", accuracy_score(y_te, lda.predict(X_te)))
print("LDA AUC     :", roc_auc_score(y_te, lda.predict_proba(X_te)[:, 1]))
print("LDA priors  :", lda.priors_)               # 默认就是训练集的类比例

# ---- 2) QDA：每个类各自一个协方差 -> 二次边界 ----
# reg_param 把每个类的协方差向共享协方差收缩，越小越像 LDA，越大越正则
qda = QuadraticDiscriminantAnalysis(reg_param=0.1)
qda.fit(X_tr, y_tr)
print("QDA accuracy:", accuracy_score(y_te, qda.predict(X_te)))

# ---- 3) 高斯朴素贝叶斯：给定类别后各维独立 -> 每类只要 2p 个参数 ----
nb = GaussianNB(var_smoothing=1e-9)              # 方差下界，防止某个类某维方差为 0
nb.fit(X_tr, y_tr)
print("NB  accuracy:", accuracy_score(y_te, nb.predict(X_te)))
print("NB  log 后验:", nb.predict_log_proba(X_te[:2]))   # 一定用 log 概率，防数值下溢

# ---- 4) 先验是可以直接改的参数：看它如何平移决策边界 ----
lda2 = LinearDiscriminantAnalysis(priors=[0.9, 0.1]).fit(X_tr, y_tr)
print("改后的先验:", lda2.priors_)
print("同一样本的后验:", lda2.predict_proba(X_te[:1]))

# ---- 5) LDA 的第二个身份：有监督降维（Fisher 判别方向） ----
Z = LinearDiscriminantAnalysis(n_components=1).fit_transform(X_tr, y_tr)
print("投影后的形状:", Z.shape)                  # 二分类最多投影到 K-1 = 1 维
```

面试里配着代码要能报出三个数：LDA 的待估参数是共享协方差 $p(p+1)/2$ 加各类均值，QDA 是它的 $K$ 倍，朴素贝叶斯只有 $2p$ ——**参数个数就是「谁更容易过拟合」的直接答案**。

## 🗣️ 英文表达 / How to Say It

1. "LDA and QDA are generative classifiers: we model the class priors and the class-conditional densities, then use Bayes' rule to get the posterior, instead of modelling the posterior directly the way logistic regression does."
2. "The only difference between LDA and QDA is whether the classes share a covariance matrix — with a shared Sigma the log-ratio is linear in x, with class-specific Sigmas it becomes quadratic."
3. "When the Gaussian assumption holds, LDA can be more efficient than logistic regression: it estimates fewer parameters and often wins on small samples; but when the assumption fails, logistic regression is the safer choice because it makes no assumption about the distribution of the predictors."
4. "For sparse features like binary or count variables the normality assumption is clearly wrong, so I would go with logistic regression, or with a Naive Bayes model built on the right likelihood."
5. "Naive Bayes assumes conditional independence of the features given the class, which is almost never true, yet it often works well because that assumption acts like a strong regulariser — you only estimate two parameters per feature."
6. "The practical warning with Gaussian Naive Bayes is over-confident probabilities, so I would recalibrate them before using them for any cost-based decision."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话说明 |
|---|---|---|
| 判别分析 | discriminant analysis (DA) | 通过类先验与类条件密度做分类的生成式方法 |
| 生成式模型 | generative model | 建模联合分布 $p(x,y)$，再用 Bayes 定理得到后验 |
| 判别式模型 | discriminative model | 直接建模 $P(Y\mid X)$，代表就是逻辑回归 |
| 线性判别分析 | linear discriminant analysis (LDA) | 假设各类正态且共享协方差，决策边界是线性的 |
| 二次判别分析 | quadratic discriminant analysis (QDA) | 各类协方差各自不同，决策边界是二次的 |
| 朴素贝叶斯 | naive Bayes | 假设给定类别后特征条件独立，参数只需 $2p$ 个 |
| 条件独立 | conditional independence | 给定类别后特征互不影响，是朴素贝叶斯的核心假设 |
| 类先验 | class prior $\pi_k$ | 每个类在总体中的比例，判别分里的 $\log \pi_k$ 项 |
| 类条件密度 | class-conditional density | $f_k(x)=p(x\mid Y=k)$，在 LDA/QDA 里取多元正态 |
| 后验概率 | posterior probability | $P(Y=k\mid X=x)$，做决策真正需要的那个量 |
| 判别函数 | discriminant function | 各类得分 $\delta_k(x)$，取最大者即为预测类 |
| 共享协方差 | shared covariance | 各类的 $\Sigma_k$ 相同，这是 LDA 与 QDA 的唯一分界 |
| 池化协方差 | pooled covariance | 用各类样本合并估计出来的那个共享协方差 |
| 收缩 | shrinkage / regularisation | 把每类协方差拉向共享协方差，用来救 QDA 的过拟合 |
| 决策边界 | decision boundary | 判别分相等的位置：LDA 线性、QDA 二次 |
| 概率校准 | calibration | 让预测概率与真实频率一致，朴素贝叶斯常需要它 |
