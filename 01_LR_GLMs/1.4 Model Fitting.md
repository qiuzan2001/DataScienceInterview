# 1.4 模型拟合（Model Fitting）

## 速览 At a glance

**速记**

[[1.1 Ordinary Least Squares (OLS)]] 讲的是 OLS 怎么解，这一篇讲的是**为什么要把它换掉**。二值结局下把概率丢进平方损失，会踩两个坑：一是**尺度**——残差 $y_i-p_i$ 被关在 $[-1,1]$ 里，平方后只剩 0.0x 量级，而且平方损失的梯度比似然多背了一个 $p(1-p)\le0.25$ 的权重，起点处正好是似然梯度的一半（3.5 对 7.0），优化慢、容易停在平地上；二是**结构**——平方损失对每个观测一视同仁，而 Bernoulli 的方差 $p(1-p)$ 随均值变化，只有似然把它写进了目标。同一份 8 点数据上，MLE 给 $\beta_1=1.2823$，平方损失给 0.9180（小 28.4%），两个解互相都不是对方的最优：平方损失的解放进似然，得分还有 $-0.72$；MLE 的解放进平方损失，梯度还有 $0.19$。最容易被说错的一条：平方损失不是「有偏」，它是**相合但效率低** —— 模拟里两个估计量的均值都贴着真值，标准差之比在 1.08–1.19 之间。逻辑回归的对数似然是凹的（Hessian $=-\mathbf X'\mathbf W\mathbf X$ 负半定），所以用 Newton / IRLS 迭代能走到全局最优，一步也不用手调学习率。

**一句面试答法**

> "Least squares is the wrong loss for a binary outcome. The residual y minus p lives between minus one and one, so squaring it gives you tiny gradients — and the squared error is damped by p times one minus p, which is at most a quarter, so at the starting point its gradient is exactly half of the log-likelihood's. More fundamentally the squared error ignores the Bernoulli variance p times one minus p, which the likelihood builds in. So we maximise the log-likelihood instead; the Hessian is negative semi-definite, so the problem is concave and IRLS converges to the global maximum."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 对数似然 | log-likelihood | $\ell(\boldsymbol\beta)=\sum_i\big[y_i\log p_i+(1-y_i)\log(1-p_i)\big]$ |
| 得分函数 | score | 梯度 $\mathbf X'(\mathbf y-\mathbf p)$，在 MLE 解处为零 |
| 海森矩阵 | Hessian | 二阶导 $-\mathbf X'\mathbf W\mathbf X$，负半定 ⇒ 似然凹 |
| 迭代再加权最小二乘 | IRLS | 每步解一个加权最小二乘的迭代算法 |
| 工作响应 | working response | $z_i=\eta_i+\frac{y_i-p_i}{p_i(1-p_i)}$，IRLS 里的「伪响应」 |
| 权重 | weight $w_i$ | $p_i(1-p_i)$，来自 Bernoulli 方差 |
| 指数族 | exponential family | 二值、计数、右偏连续分布的共同家族 |
| 连接函数 | link function | $g(E[Y])=\mathbf x'\boldsymbol\beta$，把均值接到线性预测子 |
| 相合 | consistency | 样本变大时估计量收敛到真值 |
| 效率 | efficiency | 同样样本量下方差更小 |
| 平方损失 | squared error loss | $\sum_i(y_i-p_i)^2$，概率尺度上的最小二乘 |
| 完全分离 | complete separation | 系数发散、MLE 没有有限解（见 [[1.6 Estimation Issues & Separation]]） |

## 一、先看一个问题：为什么 GLM 不能最小二乘估计？

手上有 1000 条续保记录，$Y$ 是「续没续」（0/1），你想估「报价里带不带折扣」的影响。

顺着 [[1.1 Ordinary Least Squares (OLS)]] 的惯性，第一反应是把平方损失搬过来：让 $\sum_i(y_i-p_i)^2$ 最小，其中 $p_i=\sigma(\mathbf x_i'\boldsymbol\beta)$。这个目标看起来哪都好 —— 凸的、光滑的、和 OLS 同款，甚至能直接跑梯度下降。同事还会补一句：「平方损失又简单又凸，用最小二乘不就完了。」

先摆一个能说服人的算术。$y_i$ 是 0 或 1、$p_i$ 是概率，所以残差 $y_i-p_i$ 永远落在 $[-1,1]$ 里；平方之后最多是 1，起点 $\boldsymbol\beta=\mathbf 0$ 时每个残差是 0.5、平方是 0.25。同一个点上的负对数似然是 $\log 2=0.693$，而且它没有上界：这一页 8 个点的数据里，$\boldsymbol\beta=(-8,0)$ 处负对数似然是 **32.00**，平方损失只有 **4.00**（它的上限就是样本数 8）。一个没有天花板的目标，和一个顶格 8 的目标，优化器看到的地形完全不同。

第二个反驳更硬：平方损失对 Bernoulli 数据用错了**方差结构**。二值数据的方差是 $p(1-p)$，随均值走；平方损失却给每个观测相同的权重。这两条合起来就是这一页要讲的内容。

分工先说清楚：[[1.1 Ordinary Least Squares (OLS)]] 讲 OLS 怎么解（目标、正规方程、投影几何、假设与诊断），这一篇接着讲同一套线性预测子在二值与计数结局下**为什么必须换目标**，以及换成似然以后怎么算；假设清单本身在 [[1.7 Assumptions]]，那里不重复这里的内容，这里也不重复那张表。

## 📖 标准定义

> **教材原文 · PSL §10.1 Setup 末段、§10.2 MLE**（<https://liangfgithub.github.io/PSL/w10/w10_2_mle.html>）
> > "While one might consider using the L2 loss $(y - \eta(x))^2$ , it has some limitations."
> >
> > "Squaring it further reduces the scale of the loss, resulting in small gradients, making training difficult and potentially leading to getting stuck at certain points."
> >
> > "Instead, we opt for the log-likelihood as our loss function."
> >
> > "During this iterative process, we also need to calculate the second derivative of the log-likelihood, which forms a matrix known as the Hessian matrix. The Hessian matrix is negative semi-definite, indicating that the log-likelihood function is concave. This property simplifies optimization, as any local maximum is also the global maximum."

**标准记法**：

- 伯努利似然 $P(Y = y \mid X = x) = \sigma(z)^y (1 - \sigma(z))^{1-y}$，$\sigma(z) = \frac{e^z}{1 + e^z}$，$z = x^t \beta$。
- 对数似然 $\ell(\beta) = \sum_{i=1}^n \big[ y_i x_i^t\beta - \log\big(1 + \exp(x_i^t\beta)\big) \big]$（通用形式）；MLE 解 $\nabla \ell(\beta) = \mathbf{X}^t(\mathbf{y} - \mathbf{p}) = \mathbf{0}$，无闭式解。
- Hessian $\frac{\partial^2 \ell}{\partial \beta \partial \beta^t} = -\mathbf{X}^t \mathbf{W} \mathbf{X}$（$\mathbf{W} = \text{diag}(\eta_i(1-\eta_i))$），负半定 ⇒ 对数似然凹 ⇒ 局部最优即全局最优；用 Newton–Raphson / IRLS 求解。

**中文解释**：逻辑回归用 MLE：最大化伯努利似然（等价最大化对数似然），而不是最小化 $(y-\eta(x))^2$。原因很实际：$y-\eta$ 本来就小于 1，平方后梯度太小、训练容易卡住。对数似然对 $\beta$ 是凹函数（Hessian 负半定），所以任何局部最优就是全局最优，用 Newton–Raphson 迭代求解。

> 完整条目与更多来源见 [[定义原文库#E25. MLE（为什么用似然而不是 L2 损失）|E25 MLE（为什么用似然而不是 L2 损失）]]

## 二、核心直觉

### 两个目标在问两个不同的问题

平方损失问的是「拟合的概率离 0 或 1 差多远」。

似然问的是另一件事：**如果真实概率是 $p_i$，那么观察到手上这组 0/1 的概率有多大**。每个观测的贡献是 $y_i\log p_i+(1-y_i)\log(1-p_i)$：真值 1 的点，$p_i$ 越接近 1 贡献越大；真值 0 的点，$p_i$ 越接近 0 贡献越大。

差别在极端处最明显。一个 $y_i=1$ 的点被预测成 $p_i=0.01$：似然给它 $\log 0.01=-4.61$ 的罚分，平方损失只给它 $(1-0.01)^2=0.98$。另一头，$p_i=0.5$ 这种「什么都不说」的预测：似然扣 $\log 2=0.693$，平方损失只扣 0.25。所以平方损失对**自信的错**和**含糊的对**一样宽容，似然只奖励把概率压到正确的那一侧。

**类比的边界**：像两种评分规则，一种按「离目标多远」扣分，另一种按「你给对了多大的把握」记分。不像的地方是，这不止是风格差异：似然用的是数据**真实的分布**，所以它的解在统计上有相合性与渐近有效性；平方损失只是一个更方便的目标。

### 另一个更实际的差别：梯度有多大

二值残差被关在 $[-1,1]$ 里，平方之后更小。写成公式，平方损失的梯度是

$$\nabla \sum_i (y_i-p_i)^2=-2\sum_i (y_i-p_i)\,p_i(1-p_i)\,\mathbf x_i$$

而似然的得分函数是 $\nabla\ell(\boldsymbol\beta)=\sum_i(y_i-p_i)\mathbf x_i$。两者之间只差一个权重 $p_i(1-p_i)$，这个权重永远不超过 0.25，因此平方损失的梯度最多只有似然的一半 —— $\boldsymbol\beta=\mathbf 0$ 处所有 $p_i=0.5$、权重全是 0.25，比例正好是 **0.5**。梯度小一半意味着同样步长下走得慢，也更容易停在平坦区域，这就是 PSL 说的「梯度太平、训练困难」。

### 先给结论：一句话版

因为 **GLM 是为「误差非正态、方差非常数」的结果变量设计的**，而 **LSE 只在那些特定假设成立时才成立**。

> 这句话要在面试里补全：不是说「平方损失有偏」，而是三条 ——（一）梯度被 $p(1-p)$ 压住，优化困难；（二）它用错了方差结构，效率更低；（三）它对 0/1 因变量不是一个良定义的估计目标。下面三节分别对应这三条，第四节给出数字。

## 三、机制：错配在哪里

### 3.1 错配一：LSE 的三条前提在 GLM 上不成立

最小二乘估计（Least Squares Estimation, LSE）最小化的是「实际值减预测值」的平方和：

$$
\text{Loss} = \sum_{i=1}^n (y_i - \hat{y}_i)^2
$$

只有在下面这些条件都成立时，它才给出**最佳线性无偏估计量（Best Linear Unbiased Estimators, BLUE）**：

* 误差**服从正态分布**
* 误差**方差恒定（homoscedasticity）**
* 结果变量是**连续的**

👉 但 GLM 恰恰是为**非正态分布**设计的，例如：

* **Binomial**（例如 logistic regression）
* **Poisson**（计数数据）
* **Gamma**（右偏的连续数据）

所以在这类分布下，最小化平方误差在统计上和数学上都说不通。

---

### 3.2 错配二：GLM 的目标量不是 $Y$ 本身，而是 $g(E[Y])$

GLM 不是直接对 $y$ 与 $\hat{y}$ 的差建模，而是建模：

$$
g(\mathbb{E}[Y]) = \beta_0 + \beta_1 X_1 + \dots + \beta_p X_p
$$

其中：

* $g$ = 连接函数（link function）（例如二值用 logit、计数用 log）
* $\mathbb{E}[Y]$ = 在**非正态分布**下结果变量的期望值

➡️ 平方误差**和这些变换后的尺度、以及非 Gaussian 的似然都对不上**。

---

### 3.3 错配三：MLE 用对了分布，但没有闭式解

GLM 建立在**指数族（exponential family）**分布之上。对这类分布，**最大似然估计（Maximum Likelihood Estimation, MLE）**才是数学上正确的方法，因为：

* 它用的是结果变量**真实的概率分布**。
* 在一般条件下，它给出**一致（consistent）、有效（efficient）、渐近正态（asymptotically normal）**的估计量。

#### MLE 的目标长什么样，IRLS 怎么解

把 logistic 的似然写全（$p_i=\sigma(\mathbf x_i'\boldsymbol\beta)$）：

$$\ell(\boldsymbol\beta)=\sum_{i=1}^n\Big[y_i\log p_i+(1-y_i)\log(1-p_i)\Big]=\sum_i\Big[y_i\,\mathbf x_i'\boldsymbol\beta-\log\big(1+e^{\mathbf x_i'\boldsymbol\beta}\big)\Big]$$

- **一阶导（得分函数）**：$\nabla\ell(\boldsymbol\beta)=\mathbf X'(\mathbf y-\mathbf p)$。令它为零就是 MLE 的定义。这里没有 OLS 那种「解一个线性方程组」的余地，因为 $\mathbf p$ 是 $\boldsymbol\beta$ 的非线性函数 —— 所以 MLE 没有闭式解。
- **二阶导（海森矩阵）**：$\nabla^2\ell(\boldsymbol\beta)=-\mathbf X'\mathbf W\mathbf X$，$\mathbf W=\mathrm{diag}\big(p_i(1-p_i)\big)$。它负半定，所以对数似然是**凹函数**：局部最优即全局最优，这是敢用 Newton 迭代的底气。
- **Newton 步**：$\boldsymbol\beta^{(t+1)}=\boldsymbol\beta^{(t)}+(\mathbf X'\mathbf W\mathbf X)^{-1}\mathbf X'(\mathbf y-\mathbf p)$。
- **它为什么叫 IRLS**：定义工作响应 $z_i=\eta_i+\frac{y_i-p_i}{p_i(1-p_i)}$（$\eta_i=\mathbf x_i'\boldsymbol\beta$），上面那一步恰好等于对 $z$ 做权重为 $w_i=p_i(1-p_i)$ 的**加权最小二乘**的解。所以 GLM 的迭代里确实有最小二乘，只是每一步都是加权、而且权重随当前参数更新 —— 这是面试里区分「背过」和「懂过」的地方。

---

### 3.4 落到 logistic：平方损失错在哪

设想用 LSE 去拟合 logistic regression。平方误差损失会写成：

$$
\sum (y_i - p_i)^2, \quad \text{where } p_i = \frac{1}{1 + e^{-X_i^\top \beta}}
$$

这个目标函数的问题：

* 违反「方差恒定」的假设（二值数据的方差是 $p(1 - p)$）
* 用错了 **loss 的尺度**：残差 $y_i - \eta_i \in [-1,1]$，平方后更小（多数样本只有 0.0x 量级）⇒ **梯度太平、训练困难、容易卡住**。这是 PSL §10.1 给出的权威理由——不是"L2 会有偏"。
* 更根本地：**LSE 对 0/1 因变量不是良定义的估计目标**——线性预测 $\eta$ 无界，会把预测概率推到 $[0,1]$ 之外（越界），而且它并不等价于对 Bernoulli 似然的优化（没有把 $p(1-p)$ 的方差结构考虑进去）。

> 🎯 **面试官会追问「那到底为什么不能用平方损失」**：一句话 —— 二值残差 $y-\eta$ 落在 $[-1,1]$，平方之后只剩 0.0x 量级，**梯度太平、优化困难**（PSL §10.1）；再加一条：它对不上 Bernoulli 似然的方差结构 $p(1-p)$。**不要**把理由说成「L2 损失是有偏的」——那是错的说法。

**补一条能写出来的公式**：把平方损失与似然的梯度并排看，$\nabla\sum_i(y_i-p_i)^2=-2\sum_i(y_i-p_i)p_i(1-p_i)\mathbf x_i$，$\nabla\ell(\boldsymbol\beta)=\sum_i(y_i-p_i)\mathbf x_i$，差别只有那个 $\le0.25$ 的权重。起点处两个梯度的大小是 3.5 对 7.0，第四节把这笔账算完。

### 3.5 一张对照表：LSE vs MLE

| 特征（Feature）              | 最小二乘（Least Squares, LSE） | 最大似然（Maximum Likelihood, MLE） |
| ---------------------------- | ----------------------------- | ------------------------ |
| 假设正态（Assumes Normality）    | ✅ 需要                        | ❌ 不需要                |
| 假设方差恒定（Assumes Constant Variance） | ✅ 需要             | ❌ 随分布变化            |
| 适用于二值 / 计数数据（Works for Binary/Count Data） | ❌ 不行     | ✅ 可以                  |
| 与连接函数匹配（Aligns with Link Function） | ❌ 不匹配          | ✅ 匹配                  |
| 产生有效估计（Produces Efficient Estimates） | 仅在强假设下成立 | ✅ 一般都可以            |

---

### 3.6 收尾：这条判断的边界

GLM 之所以用 MLE，是因为它要**适配结果变量真实的分布**、并配合**连接函数**——于是平方误差损失不再合适。LSE 很强大，但只服务于**正态、同方差、连续**的结果变量 —— 而这正是 OLS 的假设。

## 四、算一遍

8 个点、1 个预测变量、二值结局。同一份数据上把 MLE 与「概率尺度上的最小二乘」都解出来，看两个答案差在哪、谁在哪一项上吃亏。所有数字都用 `numpy` 复算过。

### 数据

| $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| $x_i$ | −3 | −2 | −1 | 0 | 1 | 2 | 3 | 4 |
| $y_i$ | 0 | 0 | 0 | 1 | 0 | 1 | 1 | 1 |

$\sum_i x_i=4$、$\sum_i x_i^2=44$、$\sum_i y_i=4$（4 个事件、4 个非事件），所以 $\mathbf X'\mathbf X=\begin{pmatrix}8&4\\4&44\end{pmatrix}$。数据故意留下一对「冲突点」：$x=0$ 是事件、$x=1$ 不是事件 —— 有冲突才有内点最优解，两个目标都能收敛。

### 第 1 步：起点上的两笔账

$\boldsymbol\beta=\mathbf 0$ 时 $p_i=0.5$：

- 负对数似然 $-\ell=8\log 2=\mathbf{5.5452}$；
- 平方损失 $\sum_i(y_i-p_i)^2=8\times0.25=\mathbf{2.0}$；
- 得分函数 $\mathbf X'(\mathbf y-\mathbf p)=\big(4-4,\ 9-0.5\times4\big)=(0,\ \mathbf{+7})$（负对数似然的梯度就是它的相反数），所以 $\lVert\nabla\ell\rVert=\mathbf{7.0}$；
- 平方损失的梯度 $-2\,\mathbf X'\big[(\mathbf y-\mathbf p)\odot p(1-p)\big]=-2\times0.25\times(0,\ 7)=(0,\ \mathbf{-3.5})$，所以 $\lVert\nabla L_2\rVert=\mathbf{3.5}$。

同一个起点，**平方损失的梯度正好是似然的一半**。0.5 这个比例不是巧合：$p(1-p)$ 在 $p=0.5$ 处取到最大值 0.25。

### 第 2 步：IRLS 的每一步

权重 $w_i=p_i(1-p_i)$，第 $t+1$ 步是 $\boldsymbol\beta^{(t+1)}=\boldsymbol\beta^{(t)}+(\mathbf X'\mathbf W\mathbf X)^{-1}\mathbf X'(\mathbf y-\mathbf p)$：

| 迭代 | $\beta_0$ | $\beta_1$ | $-\ell(\boldsymbol\beta)$ | $\lVert\nabla\ell\rVert$ |
|---|---|---|---|---|
| 0 | 0.0000 | 0.0000 | 5.54517744 | 7.0e+00 |
| 1 | −0.3333 | 0.6667 | 2.90492442 | 1.6374 |
| 2 | −0.5094 | 1.0187 | 2.55913766 | 0.4659 |
| 3 | −0.6118 | 1.2236 | 2.50546465 | 0.0839 |
| 4 | −0.6395 | 1.2791 | 2.50305663 | 0.004338 |
| 5 | −0.6411 | 1.2823 | 2.50304970 | 1.3e−05 |
| 6 | −0.6411 | 1.2823 | 2.50304970 | 1.2e−10 |

**第 1 步可以手核**：$\mathbf W=0.25\,\mathbf I$，于是 $\mathbf X'\mathbf W\mathbf X=0.25\begin{pmatrix}8&4\\4&44\end{pmatrix}=\begin{pmatrix}2&1\\1&11\end{pmatrix}$，其逆为 $\frac1{21}\begin{pmatrix}11&-1\\-1&2\end{pmatrix}$；$\mathbf X'(\mathbf y-\mathbf p)=(0,7)$，所以增量是 $\frac1{21}(-7,\ 14)=\mathbf{(-1/3,\ 2/3)}$，与表里第 1 行一致。

到第 6 步已经收敛：**MLE 解 $\hat{\boldsymbol\beta}=(\mathbf{-0.6411},\ \mathbf{1.2823})$**，$-\ell=2.50305$。

### 第 3 步：同一份数据上的平方损失解

换成最小化 $L_2(\boldsymbol\beta)=\sum_i(y_i-p_i)^2$，数值解是

$$\hat{\boldsymbol\beta}_{L_2}=(\mathbf{-0.4590},\ \mathbf{0.9180})$$

斜率比 MLE 小 **28.4%**（$0.9180/1.2823=0.7159$）。两个目标互相打分：

| 解 | $-\ell$ | $L_2$ | 在对方目标处的梯度 |
|---|---|---|---|
| MLE $(-0.6411,\ 1.2823)$ | **2.50305**（更低） | 0.89387 | $\partial L_2/\partial\beta_1=\mathbf{+0.1947}$ |
| 平方损失解 $(-0.4590,\ 0.9180)$ | 2.61845 | **0.85194**（更低） | $\partial(-\ell)/\partial\beta_1=\mathbf{-0.7202}$ |

两个解互相都不是对方的最优 —— 这是「目标换了，答案就换了」的直接证据。拟合概率的差别有方向：**平方损失把概率往 0.5 拉**。

| $x$ | −3 | −1 | 0 | 1 | 4 |
|---|---|---|---|---|---|
| $p$（MLE） | 0.0111 | 0.1275 | 0.3450 | 0.6550 | 0.9889 |
| $p$（$L_2$） | 0.0387 | 0.2015 | 0.3872 | 0.6128 | 0.9613 |

在 0.5 阈值下两套概率的分类结果完全一样（都是 6/8，两个冲突点判错）。差别在**概率水平**上：$x=-3$ 那个点，MLE 给「不是事件」的把握是 0.9889，平方损失只给到 0.9613。要报费率、要算期望损失，这种差别会直接进钱。

### 第 4 步：两个目标量级上的差别

同一个「坏」系数 $\boldsymbol\beta=(-8,0)$ 处：$-\ell=\mathbf{32.00}$，而 $L_2=\mathbf{4.00}$。不是巧合：$y_i-p_i\in[-1,1]$，所以 $\sum_i(y_i-p_i)^2$ 永远不超过样本数 8；负对数似然没有上界，某个 $y_i=1$ 的点被推到 $p_i\to0$ 时它是 $\log(1/p_i)$，随系数的量级一起长。优化算法感受到的坡度差的就是这个。

### 条件检验：数据变多以后，两个解会靠近吗

换一组良性的设计：真值 $\boldsymbol\beta=(0,0.8)$，$x$ 取 −2 到 2 之间的 9 个等距值、各重复 10 次（$n=90$），每个种子模拟 3000 次：

| 随机种子 | MLE 的 $\beta_1$ | 平方损失解的 $\beta_1$ | 标准差之比 |
|---|---|---|---|
| 1 | 0.8364 ± 0.2144 | 0.8518 ± 0.2547 | 1.188 |
| 2 | 0.8276 ± 0.2105 | 0.8388 ± 0.2351 | 1.117 |
| 3 | 0.8328 ± 0.2134 | 0.8473 ± 0.2484 | 1.164 |
| 7 | 0.8322 ± 0.2186 | 0.8452 ± 0.2598 | 1.188 |
| 20260916 | 0.8250 ± 0.2124 | 0.8356 ± 0.2299 | 1.083 |

两层读法。第一层：**平方损失不是有偏的估计**。五个种子里两个均值都贴着真值 0.8（差不超过 0.052），样本变大时都收敛 —— 所以面试里不能说「L2 损失有偏」。第二层：它**效率更低**。$\sum_i(y_i-p_i)^2$ 给每个观测相同的权重，等于把 $p$ 接近 0.5 的点（信息量最小）和接近 0/1 的点（信息量最大）一视同仁；似然按 Fisher 信息自然加权。代价就是标准差大 8%–19%，落到置信区间和 p 值上，就是「同一个效应更容易被判成不显著」。

## 五、什么情况下会失灵

这一节有两个方向：**平方损失方案**什么时候站不住（本篇的主张），以及 **MLE + IRLS** 这套做法本身什么时候也有边界。

### 承重假设一：你写下来的分布是对的

MLE 的全部合法性来自「模型的分布假设写对了」。二值就写 Bernoulli。如果事件之间不独立（同一客户多条记录）、或者计数数据过度分散（方差大于均值）、或者有零膨胀，那么写进似然的分布就是错的，IRLS 会给一个漂亮收敛的结果和一份错的标准误。这时要换的是**分布**（Poisson → 负二项、Tweedie），不是换回平方损失。

### 承重假设二：似然在有限参数处取到最大值

分离。如果某个 $\mathbf x$ 组合能把 0/1 完全分开，$\lVert\boldsymbol\beta\rVert\to\infty$ 时似然一直朝 0 爬，MLE 没有有限解 —— 表现为不收敛警告、巨大系数、爆炸的标准误。注意平方损失在这类数据上**同样**发散（数据可分时它的目标也能被推到 0），所以别指望换损失来躲开分离，要换的是估计量：Firth 惩罚或贝叶斯先验。机制与算例见 [[1.6 Estimation Issues & Separation]]。

### 承重假设三：你在比较同一件事

「MLE 更好」有条件：分布假设对、样本量够（经验法则 10–20 个少数类事件/预测变量）。小样本、接近分离、或者你只想要一个排序时，这个优势会缩水；此时该花精力在正则化与校准上，而不是纠结用哪个损失。

### 与其他方法的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 二值结局、事件数够 | logistic + MLE（IRLS） | 用对分布，推断自带正确的方差结构 |
| 连续、同方差、正态结局 | OLS + 最小二乘 | 此时「平方和最小」与「似然最大」指向同一个解 |
| 计数数据、方差大于均值 | 负二项 / 拟似然 / Tweedie | 要改的是方差函数，不是损失函数 |
| 完全分离、又要系数与 p 值 | Firth 惩罚 / 贝叶斯先验 | 让目标函数在有限处取到最大值 |
| 只要排序、不做推断 | 树 / GBM / 任意单调损失 | 目标函数的作用下降，排序比概率稳 |
| 高维、$p$ 远大于 $n$ | 带 $L_1$ / $L_2$ 的惩罚似然 | 惩罚进目标，迭代从 IRLS 变成坐标下降一类 |

## 六、常见误解

### 误解一：「L2 损失是有偏的，所以 GLM 不能用它」

**错误想法**：最小二乘只在正态、同方差下无偏，二值数据违反这些假设，所以平方损失的估计有偏。

**为什么容易这么想**：OLS 的招牌结论是无偏与 BLUE，而「假设不成立 ⇒ 有偏」是这门课里最顺手的推论，直接搬过来很自然。

**错在哪一步**：平方损失在概率尺度上的估计方程是 $\sum_i(y_i-p_i)p_i(1-p_i)\mathbf x_i=0$，在真值处它期望为零（因为 $E[y_i-p_i]=0$），所以那个解是**相合**的，不是有偏的。第四节的模拟就是证据：五个种子下它的均值离真值不超过 0.052。真正的问题是梯度尺度与效率，PSL 给出的权威理由也是尺度。

### 误解二：「IRLS 里有最小二乘，说明最小二乘也能用来拟合 logistic」

**错误想法**：既然 GLM 的迭代每步都在解最小二乘，那直接对 $y$ 做最小二乘有什么不行？

**为什么容易这么想**：IRLS 的名字里就有 least squares，而且工作响应 $z$ 看起来就是一个连续变量，很像回归的 $y$。

**错在哪一步**：那一步解的是**加权**最小二乘，响应是 $z_i=\eta_i+\frac{y_i-p_i}{p_i(1-p_i)}$，权重是 $p_i(1-p_i)$ 并且随当前参数更新；它不是对原来的 $y$ 做最小二乘，权重信息来自 Bernoulli 的方差结构。把「加权、迭代、权重来自分布」这三件事删掉，剩下的就不是同一件事了。

### 误解三：「梯度小就调大学习率，平方损失照样能训」

**错误想法**：梯度太小是优化问题，调步长、加动量、换 Adam 都能解决。

**为什么容易这么想**：深度学习的经验里，梯度尺度几乎总是超参数的活。

**错在哪一步**：优化可以调参，**统计不能**。把步长调大只让你更快走到第四节那个解 $(-0.4590,\ 0.9180)$ —— 斜率和 MLE 差 28.4%，概率系统性往 0.5 靠。目标函数选错，收敛得再漂亮也是收敛到另一个估计量上；而且那个估计量的方差更大。

### 误解四：「MLE 是一套依赖正态分布的方法」

**错误想法**：最大似然听起来很「正态」，二值数据大概不适用。

**为什么容易这么想**：MLE 的经典例子（样本均值、方差）都在正态模型下讲，OLS 的 $t$、$F$ 检验也是。

**错在哪一步**：似然只依赖你写下来的那个分布。logistic 的似然是 Bernoulli 似然，正态性根本没进模型；「要正态」的是 OLS 的小样本推断（见 [[1.7 Assumptions]]）。MLE 的一般结论——相合、渐近正态、渐近有效——也不要求数据正态，只要求模型设定正确。

## 七、面试怎么答

### 30 秒版

> GLM 用 MLE 而不是最小二乘，有三个层次的理由。第一层是尺度：残差 $y_i-p_i$ 在 $[-1,1]$ 里，平方之后只剩 0.0x 量级，而且梯度还被 $p(1-p)\le0.25$ 压住 —— 起点处正好是似然梯度的一半，3.5 对 7.0。第二层是结构：平方损失给每个观测同一个权重，而 Bernoulli 的方差是 $p(1-p)$，只有似然把它写进目标。第三层是定义：对 0/1 因变量，最小化平方误差不是一个良定义的估计目标。换成对数似然后，Hessian $-\mathbf X'\mathbf W\mathbf X$ 负半定，问题凹、局部即全局，用 IRLS 迭代求解。要补一句最容易被说错的：平方损失不是有偏，它是相合但效率更低。

### 2 分钟版（要包含的三块）

1. **损失错配**：两个目标在问不同的问题（平方损失问「离 0/1 多远」，似然问「这组 0/1 在哪个参数下最可能」），以及梯度尺度与 $p(1-p)$ 权重；
2. **方法错配**：GLM 建模的是 $g(E[Y])$，配指数族分布；MLE 的相合、渐近正态、渐近有效，以及没有闭式解这件事；
3. **量化与边界**：同一份数据上两个解差多少（斜率 1.2823 对 0.9180），为什么不能说「L2 有偏」，以及小样本 / 分离 / 只排序这三种情况下结论怎么变。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「平方损失训练 logistic 到底行不行」 | 能跑、能收敛，但解不同（斜率小 28.4%）、效率更低；PSL 的理由是梯度尺度，不是有偏 |
| 「IRLS 是什么」 | 每步解一个加权最小二乘：权重 $w=p(1-p)$、工作响应 $z=\eta+(y-p)/w$ |
| 「为什么可以用 Newton」 | Hessian 负半定 ⇒ 似然凹 ⇒ 任何局部最优就是全局最优 |
| 「MLE 的前提是什么」 | 分布写对 + 大样本；相合、渐近正态、渐近有效都建立在模型设定正确之上 |
| 「事件数不够怎么办」 | EPV 10–20 的经验法则；Firth 惩罚或贝叶斯先验 |
| 「为什么不用梯度下降」 | 可以，但 IRLS/Newton 用了二阶信息，几步就到；大数据下的 SGD 变体也是同一族 |
| 「deviance 和平方损失什么关系」 | 高斯分布下的 deviance 就是 RSS；二值下换成 $-\ell$ 的两倍，量纲不同 |

## 八、真题与自测

本页对应的真题问法（banner 里那条）：**"How do a linear model and a GLM differ?"** —— 差异有三处：连接函数、分布假设、估计方法。前两处的答案在 [[1.2 Generalized Linear Models (GLMs)]]，第三处就是这一页。

自测三个问题，能开口答出来就算过关：

1. 为什么二值残差平方以后「梯度太小」？（$|y_i-p_i|\le1$，起点 0.5、平方 0.25；再乘 $p(1-p)\le0.25$）
2. IRLS 每一步在解什么？（对工作响应 $z=\eta+(y-p)/[p(1-p)]$ 做权重 $p(1-p)$ 的加权最小二乘）
3. 平方损失解是有偏还是低效？（相合但低效：模拟里均值贴真值，标准差比 MLE 大 8%–19%）

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Least squares is the wrong loss for a binary outcome. The residual y minus p lives between minus one and one, so squaring it gives you very small gradients; on top of that the squared error is damped by p times one minus p, which is at most a quarter — at the starting point its gradient is exactly half of the log-likelihood's."

**Why the variance structure matters**

> "The squared error weights every observation the same way, but for a Bernoulli outcome the variance is p times one minus p and it changes with the mean. The likelihood builds that in, which is why the maximum likelihood estimator is consistent and asymptotically efficient."

**If they push back**

> "A common mistake is to say the squared-error solution is biased. It is not — it is consistent; it is simply less efficient. In a simulation with ninety observations, the squared-error estimate of the slope had a standard deviation about eight to nineteen percent larger than the MLE, and it pulled the fitted probabilities towards one half. Practically, the squared error is also bounded by the sample size, so the gradients stay flat and training gets stuck."
