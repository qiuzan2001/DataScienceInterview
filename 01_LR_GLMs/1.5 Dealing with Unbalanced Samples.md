# 1.5 不平衡样本（Dealing with Unbalanced Samples）

## 速览 At a glance

**速记**

不平衡伤的不是拟合，是「默认阈值 0.5 + accuracy 评估」这两个默认设置。1000 行里只有 10 个坏客户（1%）时，全判「好」的准确率是 99%，可召回率是 0。四种策略改的其实是同一件东西 —— 先验 / 决策边界，只是改的位置不同：重采样改训练集的类别频率；类权重在损失里给两类不同权重；调阈值直接切概率；换指标只是把这个权衡画出来。其中类权重有个能算出来的含义：取 $w_1=1/n_1$、$w_0=1/n_0$ 时，它把每一档的 log-odds 整体加上 $\ln(w_1/w_0)$（1% 基础率下等于 4.5951），于是「加权 + 阈值 0.5」等价于在原始概率上取阈值 $1/(1+99)=1\%$，正好是基础率。重采样之后概率会整体平移，要还给业务就得做截距校正：1:1 抽样对应减掉 $\ln 99 = 4.5951$，换成 1:4 抽样则只减 3.2088 —— 不校正就没法跨模型比 PD。排序指标（AUC / KS）对这些平移不敏感，动的是概率水平。offset 与截距校正是同一个自由度，二选一，否则概率会被压掉两个量级。

**一句面试答法**

> "Imbalance doesn't break the fit — it breaks the default threshold of one half and it breaks accuracy as a metric. So I'd fix the metric first, then the decision threshold or class weights, and only resample if that isn't enough; and if I do resample, the probabilities are shifted by the prior and I have to put the population prior back with an intercept correction or an offset."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 类不平衡 | class imbalance | 两类的样本量差出几个量级 |
| 重采样 | resampling | 过采样 / 欠采样，改的是训练集的类别频率 |
| SMOTE | synthetic minority over-sampling technique | 在少数类近邻之间插值造新点 |
| 类权重 | class weights | 在损失里给两类不同权重，不动数据 |
| 阈值调优 | threshold tuning | 在验证集上按业务代价挑 $T$ |
| 精确率 | precision | $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$，依赖基础率 |
| 召回率 | recall / sensitivity | $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$，不依赖基础率 |
| 基础率 | base rate / prevalence | 总体里事件的比例，本例 1% |
| 先验 | prior | 模型看到的类别比例，重采样改的就是它 |
| 截距校正 | intercept correction | 按样本先验与总体先验的 log-odds 之差平移截距 |
| 抽样率 | sampling rate | $r_1$、$r_0$：事件与非事件被抽进训练集的概率 |
| 偏移项 | offset | 写进模型的已知常数，等价于改截距 |
| 校准 | calibration | 预测概率与实际频率是否对得上 |

## 一、先看一个问题

**"How do you deal with an unbalanced sample?"** —— 面试官想听的不是「SMOTE 还是欠采样」，而是「不平衡坏了哪一步，你按什么顺序修」。

场景：1000 行申请里只有 10 个坏客户（1%），模型输出的是「分档 + 概率」。三档的命中情况是：

| 档 | 行数 | 坏客户数 | 档内坏率 |
|---|---|---|---|
| A | 700 | 2 | 0.29% |
| B | 200 | 4 | 2.0% |
| C | 100 | 4 | 4.0% |

三档概率都在 0.5 以下，默认阈值下一个坏客户都不会被标出来 —— 召回率 0，准确率 99%。你要解释的其实只有一句：**坏掉的是「阈值 0.5」和「accuracy」这两个默认设置，不是拟合**。

接下来必须能立刻答出三个数：换阈值之后 precision / recall 各是多少、类权重把决策边界搬到了哪里、重采样之后概率要减掉多少。这三个数在第四节全部算出来。

## 📖 标准定义

> **教材原文 · PSL §10.5.3 Retrospective Sampling、§10.5.4 The Challenge（页面 w10_5_sampling.html）**（<https://liangfgithub.github.io/PSL/w10/w10_5_sampling.html>）
> > "An alternative approach is to select a hundred patients but ensure that they comprise a balanced representation. In this case, we might draw 50 samples from a group of cancer patients and 50 from a control group, representing individuals without cancer. Consequently, our training dataset comprises 50 samples from each category."
> >
> > "Introduce an indicator variable, denoted as “Z,” to determine whether an individual has been sampled. Consequently, when analyzing retrospective samples, our obtain an estimate of the probability $P(Y=1 | Z=1, X=x).$ However, our ultimate goal is to learn the probability"
> >
> > "It’s interesting to note that for logistic regression models, the coefficients estimated from a retrospective sample are almost the same as those obtained from an ordinary random sample except the intercept."
> >
> > "This finding underscores the robustness of logistic regression in handling retrospective data, with the primary distinction often being the intercept, which can be adjusted to align the model with the characteristics of the broader population."

**标准记法**：

- 抽样指示变量 $Z$：回顾性样本估的是 $P(Y=1 \mid Z=1, X=x)$，目标却是 $P(Y=1 \mid X=x) = \frac{\exp(\alpha + x^t \beta)}{1 + \exp(\alpha + x^t \beta)}$。
- 若病例组抽样比例 $\tau_1 = P(Z=1 \mid Y=1)$、对照组 $\tau_0 = P(Z=1 \mid Y=0)$，则 $\hat\alpha_{\text{pop}} = \hat\alpha_{\text{sample}} + \log(\tau_0/\tau_1)$（斜率不变、只平移截距；通用形式）。

**中文解释**：回顾性（病例对照）抽样是按结果 $Y$ 抽样的：比如各抽 50 个病人与 50 个对照，样本里两类比例是 50-50，而总体不是。这违反了「训练与测试同分布」的常规假设，但对逻辑回归友好——斜率的估计几乎不变，只有截距需要按已知的抽样比例调整。

> 完整条目与更多来源见 [[定义原文库#E27. 回顾性抽样（retrospective / case-control sampling）|E27 回顾性抽样（retrospective / case-control sampling）]]

> **一句话**：不平衡本身不会破坏 logistic regression 的系数估计——它破坏的是「默认阈值 0.5 + accuracy 评估」。重采样 / 加权改变的是**先验（prior）**，代价与收益都必须显式处理。

## 二、核心直觉

不平衡数据上发生的事拆成两句就够：

**第一，拟合和决策是两件事。** logistic 拟合的是概率，阈值把概率变成标签。不平衡伤的是后者（外加评估指标）。10 个事件已经足够把斜率估出来，坏的是你拿 0.5 去切它。

**第二，重采样和类加权改的是先验。** 你在训练集里把 1% 放大成 50%，模型学到的就是「先验 50%」那个世界的截距。斜率基本不动，截距平移，平移量可以精确算：1:1 抽样对应 $+\ln 99 = +4.5951$，校正时减掉同一个数。

**类比的边界**：像给天平换砝码。换砝码能让你看清轻的那一端，但读数不再是原来那台秤的读数 —— 想要原来的读数，得把换算关系（截距校正 / offset）记下来。

**一句口诀：排序指标几乎不动，动的是概率水平。**

## 三、机制：四种策略各自的代价

### 3.1 不平衡到底伤在哪里（Why Imbalance Matters）

设想一个疾病筛查：只有 1% 的人真的患病。在 10 000 人的数据集里：

* **正类（positive class）**（患病）：100
* **负类（negative class）**（健康）：9 900

一个**永远**预测「健康」的朴素分类器，准确率就已经是 99% —— 但它一个病人都抓不到！

**要点：**
*Logistic regression 的训练过程（maximum likelihood）会努力去拟合两类的概率；出问题的不是拟合，而是**把概率转成标签**的那一步 —— 用默认阈值 0.5，你几乎永远判成多数类。再拿原始 accuracy 去评估，还会被这个 99% 哄住：模型看起来「很棒」，实际上漏掉了每一个正类。*

---

### 3.2 策略 1：对训练数据重采样（Resampling the Training Data）

思路：把训练集重新配平，让模型「看到」的正负样本数量大致相当。

| 做法 | 做什么 | 优点 | 缺点 |
| -------------------------- | ----------------------------------------------------------------------------- | --------------------------------------------------------- | ---------------------------------------- |
| **随机过采样（random oversampling）** | 复制少数类样本，直到两类配平 | 实现简单 | 会对复制出来的行过拟合 |
| **SMOTE** | 在少数类近邻之间做插值，合成新的少数类点 | 比单纯复制的过拟合更轻；还能给样本带来多样性 | 可能造出模棱两可（贴着边界）的点 |
| **随机欠采样（random undersampling）** | 随机丢掉一批多数类样本 | 快；数据集变小 | 丢掉了可能有用的信息 |
| **有信息量的欠采样（informed undersampling）** | 丢掉靠近少数类的多数类点（如 Tomek links、NearMiss） | 只保留「难分」的负样本 | 调参更复杂 |

> **SMOTE 的直觉（how SMOTE works）**：
> 对每个少数类点 $x$，挑一个最近的少数类邻居 $x'$，然后造出一个新点
>
> $$
> x_{\text{new}}
> = x + \alpha\,(x' - x),
> \quad \alpha\sim U(0,1).
> $$
>
> 它是在少数类的特征空间里「填空档」，而不是把原有样本原样复制一份 —— 这正是它比随机过采样更不容易过拟合的原因。

**逻辑上的权衡（logical trade-off）**：
重采样改变的是模型看到的**经验类别频率（empirical class frequencies）**。这可以改善分类表现，但它同时也扭曲了类别的真实**患病率 / 事件率（prevalence）** —— 所以只要你关心**校准过的概率（calibrated probabilities）**，后面就必须把这个扭曲修回来（例如回到原始分布上重新校准）。推论是：**需要校准概率时优先避免重采样**，改用**类权重（class weights）+ 截距校正**，或事后做 **Platt scaling / isotonic regression**。

> ⚠️ 实操坑：**SMOTE 必须在每一折的训练集内部做**。先对全量数据重采样再切折，等于把合成样本泄漏进验证折，CV 分数会虚高。

---

### 3.3 策略 2：类加权的损失函数（Class-Weighted Loss）

不动数据，改的是**目标函数（objective）**。标准的 logistic regression 最小化

$$
-\sum_{i=1}^n \bigl[y_i\log p_i + (1-y_i)\log(1-p_i)\bigr].
$$

加上**权重（weights）** $w_i$ 之后，就变成

$$
-\sum_{i=1}^n w_i\;\bigl[y_i\log p_i + (1-y_i)\log(1-p_i)\bigr].
$$

一种常见取法是

$$
w_i =
\begin{cases}
\displaystyle \frac{1}{\#\text{positives}}
&\text{if }y_i=1,\\[6pt]
\displaystyle \frac{1}{\#\text{negatives}}
&\text{if }y_i=0.
\end{cases}
$$

这样两个类对损失的贡献相同，优化器就会「更在意」稀有那一类。

* **优点**：不复制、不删数据，信息全保留。
* **缺点**：可能需要调（例如给少数类再稍微加一点权重）；权重给得太大可能让收敛变得不稳定。
* **与重采样的关系**：类加权在期望意义上近似于按权重重采样，但它不会凭空造出新的样本点，信息量也不受损。

---

### 3.4 策略 3：调阈值（Threshold Tuning）

Logistic regression 输出的是概率 $\hat p_i$。默认的判法是

$$
\hat y_i = 
\begin{cases}
1 & \hat p_i\ge0.5,\\
0 & \hat p_i<0.5.
\end{cases}
$$

但类别不平衡时，你常常想要一个**更低**的阈值：用一点 precision 换更多 recall（抓到更多正类）：

$$
\hat y_i = 
\begin{cases}
1 & \hat p_i \ge T,\\
0 & \hat p_i < T,
\end{cases}
$$

其中 $T$ 由你对**假正（false positive）与假负（false negative）相对代价**的容忍度来定（例如 0.2 或 0.1）。

> **怎么挑 $T$**
>
> 1. 先切出一个验证集（validation set）。
> 2. 对每个候选 $T$，在这个验证集上算 precision 与 recall。
> 3. 选那个让你最在意的指标最好的 $T$（F1；或在「precision 不低于某个下限」的约束下最大化 recall，等等）。

---

### 3.5 策略 4：换更合适的评估指标（Better Evaluation Metrics）

类别不平衡时，**accuracy 会骗人**。要看的是这些：

1. **混淆矩阵（confusion matrix）**

   * 真正例（true positives, TP）、假正例（false positives, FP）、真负例（true negatives, TN）、假负例（false negatives, FN）。

2. **精确率（precision）** $\displaystyle \frac{\text{TP}}{\text{TP}+\text{FP}}$
   – 你判为正的样本里，有多少真的是正的？

3. **召回率（recall / sensitivity）** $\displaystyle \frac{\text{TP}}{\text{TP}+\text{FN}}$
   – 所有真正的正类里，你抓到了多少？

4. **F1 score**：precision 与 recall 的调和平均。

5. **ROC 曲线**：阈值从高扫到低，画真正例率（true positive rate）对假正例率（false positive rate）。

   * **AUROC**（曲线下面积）与阈值无关；但正类极度稀有时会偏乐观 —— 注意这个偏乐观来自**正样本绝对数量太少**（估计方差大），而不是「采样比例不平衡」本身。

6. **Precision–Recall 曲线**：阈值变化时画 precision 对 recall。

   * **AUPRC**（PR 曲线下面积）在重度不平衡下通常信息量更大，因为它盯的是少数类的表现。

> 一句话记住：**光看重采样造成的类别比例变化，排序类指标（AUC / Gini / lift）几乎不动**；动的只是概率水平（校准）。所以「不平衡伤 AUC」的说法要小心表述。

### 3.6 病例对照 / 过采样之后：如何回到总体概率（PSL §10.5.3–10.5.4）

风控/保险面试的高频追问：**"我用 1:1 过采样（或病例对照）训练的模型，输出的概率还能当成真实违约率吗？"**

### 关键词：回顾性抽样（retrospective / case-control sampling）

不是"从总体里随机抽 N 个人再看 $X,Y$"，而是**先按 $Y$ 抽**（例如拿走全部坏客户，再随机抽同样多的好客户），然后回看 $X$。它有一个非常好的性质：

* **除截距外，系数估计与随机抽样几乎一致**（$\hat\beta_1,\dots,\hat\beta_p$ 不受抽样比例影响）。
* **差异只在截距** $\beta_0$：抽样把总体先验 $\pi = \Pr(Y=1)$ 换成了样本先验 $\tilde\pi$，而 logistic regression 的截距恰好就是**先验 log-odds**。
* 推论：**排序不受影响**（AUC / KS / 评分顺序不变），**只有概率水平（calibration）受影响**。所以只看 AUC 会觉得过采样"无害"，一旦要 PD 就必须校正。

### 校正方法（两选一，本质等价；不要重复用）

**① offset = ln(w)（用抽样权重）**

给每个样本一个 offset，等价于把截距换成 $\beta_0 + \ln w_i$：

$$
\text{logit}\,\Pr(Y=1\mid x_i) \;=\; \ln w_i \;+\; \beta_0 + \beta_1x_{i1}+\dots+\beta_px_{ip}
$$

其中 $w_i = 1/\Pr(\text{样本 } i \text{ 被选入训练集})$：

* **过采样**：少数类被复制 $k$ 倍 ⇒ 这些样本取 $w = 1/k$；
* **病例对照**：病例取 $w \propto \pi/\tilde\pi$、对照取 $w \propto (1-\pi)/(1-\tilde\pi)$（即逆抽样概率加权，IPW）。

**② 截距校正公式**

设总体 $Y=1$ 比例为 $\pi$、训练样本里为 $\tilde\pi$：

$$
\beta_0^{\text{corrected}}
= \beta_0^{\text{sample}}
- \ln\!\left(\frac{\tilde\pi}{1-\tilde\pi} \cdot \frac{1-\pi}{\pi}\right)
= \beta_0^{\text{sample}}
- \bigl(\operatorname{logit}(\tilde\pi) - \operatorname{logit}(\pi)\bigr)
$$

直觉：样本里坏人被"放大"了 ⇒ 模型以为先验更高 ⇒ 截距被抬高；把这份先验差减回去即可。

**显式公式（用抽样率写出来，MAGNet §1）**：若做（或已经做了）过采样 / 病例对照抽样，**斜率照用，截距要校正**：

$$
\beta_0^{\text{corrected}}=\beta_0^{\text{sampled}}-\ln\!\frac{r_1}{r_0}
$$

其中 $r_1$、$r_0$ 分别是**事件**与**非事件**的**抽样率（sampling rate）**。

直觉：抽样改变了事件与非事件的比例，而 log-odds 的可加结构让这一变化**只体现为截距的一个平移**。

**数字例（验算过）**：真实事件率 $1\%$、训练集 $50/50$：

* 总体 odds $=0.01/0.99=0.010101$，训练集 odds $=1$；
* 抽样率之比 $r_1/r_0=1\div(0.01/0.99)=99$（均衡样本把事件放大约 99 倍）；
* 偏移量 $=-\ln 99=\ln(0.010101/1)=\mathbf{-4.5951}$（即 $-4.595$）⇒ $\beta_0^{\text{corrected}}=\beta_0^{\text{sampled}}-\mathbf{4.5951}$。

> 另一种等价读法：把 $r_1/r_0$ 读成「事件率 : 非事件率」（即 odds），则偏移量 $=\ln\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{训练}}}$，得到的还是同一个 $-4.5951$——与上面 $\pi/\tilde\pi$ 的版本一致。

> 来源：MAGNet §1（Q: How do you deal with an unbalanced sample?）；[[MAGNet 面试真题全解]]

> ⚠️ 若模型里已经用了 offset $\ln w$，就**不要**再做截距校正。

### 为什么这在保险/风控里是硬需求

* 概率本身是要用的：**定价、准备金、预期损失 = PD × LGD × EAD** 都吃 PD 的绝对值，光调阈值不够。
* 换个抽样比例（1:1 → 1:4）后，排序指标几乎不变，但 **PD 的整体水平会平移**——不校正就没法跨模型比较，也没法算资金占用。
* 常见做法：训练时用重采样解决不平衡，**打分前**用 $\ln w$ offset 或截距校正把概率拉回总体水平，再用评分卡映射（PDO）输出。

**面试 30 秒答案**：*抽样改变的是先验，只影响截距；系数与排序几乎不变。要恢复总体概率，就用 offset = ln(w) 或按样本先验与总体先验的 log-odds 之差校正截距（PSL §10.5.3–10.5.4）。*

### 3.7 归总：拿到不平衡数据按这个顺序走（Putting It All Together）

1. **先看数据（inspect your data）**：算类别频率，以及「全判多数类」的基线准确率。
2. **再选策略（choose your strategy，也可以组合）**：

   * 如果丢掉一部分数据无所谓：可以考虑欠采样。
   * 如果想留下全部数据：用类权重或过采样。
   * 不管用哪种重采样或加权，都**必须在交叉验证内部验证**（在训练折里 fit）。
3. **在留出集上把决策阈值调好（tune the decision threshold）**，落到你想要的 precision / recall 权衡点上。
4. **报告正确的指标（report the right metrics）**：混淆矩阵、precision、recall、F1，以及 ROC 与 PR 曲线。

这条链路上真正需要记住的是几个数：默认阈值下召回率是 0、类权重等价于把决策边界搬到基础率 1%、过采样成 1:1 之后概率要减掉 4.5951 才能还给业务。换任何一个条件（阈值、抽样比例、代价比）都要重新算一遍，思路不变。

## 四、算一遍

用第一节那张三档表把四个策略各算一遍。所有数字都用 Python 验算过，含类权重、阈值与截距校正三处交叉验算。

### 第 0 步：分档概率与默认阈值

1000 行申请里有 10 个坏客户（基础率 1%），分三档：

| 档 | 行数 | 坏客户数 | 档内坏率 = 模型概率 $\hat p$ | logit |
|---|---|---|---|---|
| A | 700 | 2 | 0.2857% | −5.8551 |
| B | 200 | 4 | 2.0000% | −3.8918 |
| C | 100 | 4 | 4.0000% | −3.1781 |

为什么概率等于档内坏率：单变量、三个水平的**饱和模型**里，每档的拟合值就是那一档的经验频率（和 [[1.3 Introducing Logistic Regression]] 里单二值预测变量的算法一致）。斜率部分：B 相对 A 是 $1.9633$，C 相对 A 是 $2.6770$。

### 第 1 步：默认阈值 0.5 下发生了什么

三档概率全都小于 0.5 ⇒ 全判「好客户」：

| | 预测坏 | 预测好 |
|---|---|---|
| 实际坏（10） | TP = 0 | FN = 10 |
| 实际好（990） | FP = 0 | TN = 990 |

召回率 $= 0/10 = \mathbf{0}$，准确率 $=(0+990)/1000 = \mathbf{99\%}$。什么都不标的基线准确率也是 99%。**准确率在这一步没有任何区分力**，坏掉的是阈值这个默认设置，不是拟合。

### 第 2 步：挪阈值，逐行看 precision / recall

| 阈值 $T$ | 标哪些档 | TP | FP | FN | TN | precision | recall | F1 | accuracy |
|---|---|---|---|---|---|---|---|---|---|
| 0.50 | 无 | 0 | 0 | 10 | 990 | 无定义 | 0% | 0 | 99.0% |
| **0.03** | C | 4 | 96 | 6 | 894 | **4.00%** | 40% | 0.0727 | 89.8% |
| **0.015** | B、C | 8 | 292 | 2 | 698 | **2.67%** | 80% | 0.0516 | 70.6% |
| **0.002** | 全部 | 10 | 990 | 0 | 0 | **1.00%** | 100% | 0.0198 | 1.0% |

三处读法：

1. precision 的分母是 $\mathrm{TP}+\mathrm{FP}$，$T=0.5$ 时这个分母是 0，所以 precision **无定义**，不是 0；
2. 阈值一路降下来，recall 从 0 涨到 100%，precision 从无定义掉到 1%（正好等于基础率）—— 每降一档都是在拿 precision 换 recall；
3. **F1 最大的那一行是 $T=0.03$（只标最高档）**，也就是说在 1% 基础率下，「让 F1 最大」会把阈值推到很高的位置，召回率只剩 40%。F1 隐含 precision 与 recall 等权，业务代价不对称时它选出来的阈值不一定是想要的。

### 第 3 步：类权重把决策边界挪到了哪

取常用的权重 $w_1 = 1/\#\text{坏客户} = 1/10 = 0.1$，$w_0 = 1/\#\text{好客户} = 1/990 = 0.0010101$。加权拟合的结果可以精确写出来：**每一档的 log-odds 整体加上 $\ln(w_1/w_0)$**，

$$
\ln\frac{0.1}{0.0010101} = \ln 99 = \mathbf{4.5951}
$$

| 档 | 原概率 | 加权后的拟合概率 | 验算 $\mathrm{sigmoid}(\text{logit}+4.5951)$ |
|---|---|---|---|
| A | 0.2857% | **22.10%** | $\mathrm{sigmoid}(-1.2600) = 0.22098$ ✓ |
| B | 2.0000% | **66.89%** | $\mathrm{sigmoid}(0.7033) = 0.66892$ ✓ |
| C | 4.0000% | **80.49%** | $\mathrm{sigmoid}(1.4170) = 0.80488$ ✓ |

**关键一步**：加权后的概率再套默认阈值 0.5，等价于在**原始概率**上取阈值

$$
\mathrm{sigmoid}(-\ln 99) = \frac{1}{1+99} = \mathbf{1\%}
$$

正好是总体事件率。所以「类权重 + 默认 0.5」的真实含义是**把决策边界搬到基础率上**：

| 做法 | 标哪些档 | TP | FP | FN | TN | precision | recall |
|---|---|---|---|---|---|---|---|
| 原始概率 + $T = 1\%$ | B、C | 8 | 292 | 2 | 698 | 2.67% | 80% |
| 加权模型 + $T = 0.5$ | B、C | 8 | 292 | 2 | 698 | 2.67% | 80% |

两行完全相同。类权重不是新算法，它把阈值这一步换了写法 —— 代价是输出的概率不再是可以直接上报的 PD。

### 第 4 步：过采样之后，概率要校正多少

设这 1000 行是总体的随机样本，总体事件率 $\pi = 1\%$。现在把训练集过采样成 1:1（$\tilde\pi = 50\%$）：全部 10 个坏客户留下（$r_1 = 1$），再从 99,000 个好客户里抽 1000 个（$r_0 = 1000/99000 = 1.0101\%$），比值 $r_1/r_0 = 99$。要恢复总体概率，截距要减掉

$$
\beta_0^{\text{corrected}} = \beta_0^{\text{sample}} - \ln\frac{r_1}{r_0} = \beta_0^{\text{sample}} - \ln 99 = \beta_0^{\text{sample}} - \mathbf{4.5951}
$$

两个写法算出同一个数：$\text{logit}(0.5) - \text{logit}(0.01) = 0 - (-4.5951) = 4.5951$ ✓。

### 第 5 步（条件检验）：把抽样比例从 1:1 换成 1:4

同一个总体（$\pi=1\%$），只换抽样比例：事件全留、好客户抽 4 倍 ⇒ 训练集先验 $\tilde\pi = 20\%$。

| 训练集先验 | 校正量（= 等价 $r_1/r_0$） | 同一个分数 $\beta_0 = -5.8551$ 的**未校正**输出 |
|---|---|---|
| 50%（1:1） | 4.5951 | 22.10% |
| 20%（1:4） | 3.2088（$= \ln 24.75$） | 6.62% |

同一个原始分数，两种抽样比例下的未校正概率差了 **3.34 倍**。校正之后两者都回到 0.2857%。

结论有两层：不校正就没法跨模型比较 PD（换个抽样比例就要重新标定）；但**排序不受影响** —— 三档的次序 A < B < C 在哪种抽样比例下都一样。

## 五、什么情况下会失灵

### 承重假设一：训练与线上的先验一致（或你已经校正过）

撤掉它的后果不是「精度下降」，而是概率整体平移：同一个分数，1:1 抽样下输出 22.10%、1:4 抽样下输出 6.62%，真值 0.2857%。拿这个概率去定价，保费会差两个量级。做 PD 的模型必须有一步显式的校正（offset 或截距校正），并且 **两个不能同时用**：再用一次 $\ln 99$ 等于把 odds 再除 99，0.2857% 会被压到 0.0029%，低估 99 倍。

### 承重假设二：重采样只发生在训练折内部

撤掉它（先对全量数据重采样、再切折），合成样本会同时出现在训练折和验证折里。SMOTE 的新点是少数类近邻的凸组合，它天然落在原来那几个点的邻域里，验证折里几乎必然有近邻 —— CV 分数被自己抄自己抬高，而且抬高的幅度随过采样倍数增长。正确做法：把重采样（以及所有插补参数）写进 pipeline，在每一折内部 fit。

### 承重假设三：阈值绑了业务代价

撤掉它（用 0.5，或者用「F1 最大」），第 2 步的表就是后果：F1 最优的阈值是 0.03，只标最高档，召回率 40%。如果漏掉一个坏客户的代价是误报的 10 倍，正确做法是按代价算期望损失最小的阈值，而不是让某个通用指标最大。

### 承重假设四：少数类事件数够

不平衡本身不伤拟合，但**事件太少**会伤：EPV 低于 10 时 MLE 有偏、标准误不稳，再往下走到完全分离，系数直接发散（见 [[1.6 Estimation Issues & Separation]]）。修法不是「平衡数据」，而是减变量、加惩罚（Firth），或者干脆换一个更粗的目标。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 要概率的绝对值（定价、PD） | logistic + 权重 / 截距校正 | 概率可校正，系数可解释 |
| 只要排序 | 任何模型 + 不动数据 | AUC / KS 对先验平移不敏感 |
| 代价矩阵已知 | 直接按期望代价定阈值 | 比任何「平衡」技巧都直接 |
| 少数类事件数极少（< 50） | 惩罚似然（Firth）/ 树 + 集成 | MLE 不稳，树对类别比例更宽容 |
| 反欺诈这类「异常检测」问题 | 异常检测 / 无监督 | 坏样本可能不是「同一类」，是有标注的少数 |
| 需要跨模型比较 PD | 统一先验 + 统一校正 | 否则比的是抽样比例，不是模型 |

## 六、常见误解

### 误解一：「不平衡让模型偏向多数类，所以必须先把数据配平」

**错误想法**：模型学歪了，得先过采样到 50/50 才能学对。

**为什么容易这么想**：accuracy 99% 看起来太荒谬，而「数据本身不平衡」是最直观的解释；再加上软件里做重采样是标准动作。

**错在哪一步**：把「默认阈值不合适」错记到「数据比例有问题」上。第 1 步那张表里 TP = 0 是全判负的结果 —— 拟合没坏，是切的位置坏了。10 个事件足以把斜率估出来（$1.9633$），这点事件数在 10 万行里也一样能估；重采样改变的是模型看到的先验，代价是概率需要校正。

### 误解二：「过采样会把 AUC 抬高，欠采样会把 AUC 压低」

**错误想法**：重采样动了数据分布，所以排序指标也会跟着变。

**为什么容易这么想**：重采样确实改了数据，而 AUC 又是最常见的指标；「AUC 高低」常被当成「模型好坏」。

**错在哪一步**：类权重只给 log-odds 加了一个常数（第 3 步的 4.5951），是单调变换，AUC / KS / Gini 在单调变换下**完全不变**。真正让 AUC 在小样本下偏乐观的原因是**正样本的绝对数量太少**（估计方差大），跟采样比例不是一回事 —— 把 10 个事件过采样成 1000 个「事件」，也不会多出任何信息。

### 误解三：「SMOTE 比复制样本更聪明，随便用没风险」

**错误想法**：插值造点比复制强，所以 SMOTE 基本是免费的。

**为什么容易这么想**：插值确实降低了「复制同一行」造成的过拟合，教材上的对比实验也都这么写。

**错在哪一步**：SMOTE 的新点落在少数类近邻的连线上，如果这两个近邻分处决策边界两侧，合成点会落到多数类的区域里、标签却仍是 1 —— 训练集里凭空多了贴边界的错标点。另外对类别型特征，「最近邻」的距离定义本身就是拍的。用它就得接受这两条，并且只在训练折内做。

### 误解四：「校正做得越多越准」

**错误想法**：offset 加一次、截距校正再来一次，双保险。

**为什么容易这么想**：两个公式长得不一样（一个是 $\ln w$，一个是 $\ln(r_1/r_0)$），看起来像两件独立的事。

**错在哪一步**：它们是同一个自由度的两种写法。重复用会把校正量算两遍：再用一次 $\ln 99$，odds 被再除以 99，0.2857% 变成 0.0029%，低估两个量级。判断办法很简单：校正后再看样本内的平均预测概率，如果它和总体事件率对不上，说明用多了或者用错了。

## 七、面试怎么答

### 30 秒版

> 不平衡伤的不是拟合，是「默认阈值 0.5 + accuracy 评估」。我先算三个数：全判多数类的基线准确率（本例 99%）、真实基础率（1%）、以及少数类事件数（10 个）。然后按顺序修：先换指标（PR 曲线、precision / recall），再用类权重或调阈值，最后才考虑重采样。类权重有个能算出来的含义：$w_1 = 1/n_1$、$w_0 = 1/n_0$ 时，它把决策边界搬到了原始概率等于基础率的地方（本例 1%）。真要重采样，训练后必须做截距校正 —— 1:1 抽样对应减掉 $\ln 99 = 4.5951$ —— 否则输出的概率不能当 PD 用。

### 2 分钟版（要包含的三块）

1. **诊断**：基础率、事件数、基线准确率、以及「排序指标 vs 概率指标」的用途区分；
2. **机制**：阈值、类权重、重采样三者改的都是同一个东西（先验 / 决策边界），只是改的位置不同；附上 $1/(1+99)=1\%$ 与 $-\ln 99$ 两个可复算的数；
3. **代价**：重采样会让概率失真、必须在 pipeline 内做、以及 offset 与截距校正不可重复。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么不直接过采样到 50/50？」 | 概率会整体平移；排序不变、水平错了；要校正才敢用于定价 |
| 「类权重和重采样区别？」 | 期望意义上等价（按权重重采样）；权重不复制行、信息不损失 |
| 「阈值怎么定？」 | 按 FP / FN 的美元代价或运营产能，在留出集上按期望成本最小化 |
| 「AUC 会不会虚高？」 | 正样本绝对数量少会带来估计方差，不是采样比例问题 |
| 「SMOTE 有什么坑？」 | 只能在训练折内做；合成点可能落在多数类区域；类别型特征的距离定义随意 |
| 「概率已经过采样了还能救吗？」 | 能：offset $\ln w$ 或截距校正，二选一；之后做一次校准曲线验证 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Imbalance doesn't break the coefficient estimates — it breaks the default threshold of one half and it breaks accuracy as a metric. So the order I'd work in is: change the metric first, then class weights or threshold tuning, and only resample if that isn't enough."

**Mechanism**

> "Class weights just make each class contribute equally to the loss, and threshold tuning picks T on a validation set against the cost of a false positive versus a false negative. Resampling changes the empirical class frequencies, which effectively changes the prior the model sees."

**If they push back**

> "A common pitfall is using the probabilities straight after SMOTE — they're systematically shifted, so they have to be recalibrated, by Platt scaling, isotonic regression, or an intercept correction. And there's a nice result behind that: under case-control sampling the slopes are essentially unchanged and only the intercept shifts, which is exactly why we can put the population prior back by correcting the intercept or using an offset of log w."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 类不平衡 | class imbalance | 两类的样本量差出几个量级 |
| 重采样 | resampling | 过采样 / 欠采样，改的是训练集的类别频率 |
| SMOTE | synthetic minority over-sampling technique | 在少数类近邻之间插值造新点 |
| 类权重 | class weights | 在损失函数里给两类不同权重，不动数据 |
| 阈值调优 | threshold tuning | 在验证集上按业务代价挑 $T$ |

| 召回率 | recall / sensitivity | $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$，不依赖基础率 |
| 基线率 / 患病率 | base rate / prevalence | 总体里事件的比例，本例 1% |
