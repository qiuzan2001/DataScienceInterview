# 1.3 逻辑回归（Logistic Regression）

## 速览 At a glance

**速记**

二值结局不能直接套 OLS：直线会给出小于 0 或大于 1 的预测，而且 Bernoulli 的方差 `p(1−p)` 随均值变化，同方差假设当场作废。逻辑回归的解法是**不建模概率本身，改建模 log-odds**：`ln(p/(1−p))` 把取值从 `(0,1)` 拉到整条实数轴，于是能挂上线性预测子。代价有三条——系数只在 log-odds 尺度上可解释（`exp(β)` 是 odds 倍数，**不是概率变化**）；没有闭式解，靠 MLE + IRLS 迭代；某个变量能完美分开两类时系数会跑到无穷，普通 MLE 给不出有限解。

**一句面试答法**

> "A straight line gives you predictions below zero and above one, so we model the log-odds instead of the probability. That keeps the fitted probability in range and lets us write the model as linear in the predictors."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 几率 | odds | `p/(1−p)`，取值范围 `(0, ∞)` |
| 对数几率 / logit | log-odds / logit | `ln(p/(1−p))`，取值范围 `(−∞, +∞)` |
| 线性预测子 | linear predictor | `η = Xβ` |
| S 形函数 | sigmoid | logit 的反函数 `1/(1+e^{−η})` |
| 迭代再加权最小二乘 | IRLS | 解 logistic 似然的迭代算法 |

## 一、先看一个问题

手上有 1000 张车险保单的续保记录。你想知道「报价里带不带折扣」和「客户续不续保」是什么关系，于是顺手跑了一条 OLS：

```
续保(0/1) ~ 是否含折扣(0/1)
```

跑完发现 37 张保单的预测值是 **−0.08**，还有 12 张是 **1.14**。

现在要给业务讲结果。你能说的第一句话是什么？「这批客户的续保概率是负的百分之八」——没法说。删掉越界的再报平均？那是在掩盖模型本身错了。

问题不在实现细节。二值结局套线性回归，坏掉的正是后面做推断要依赖的两条假设。所以我们要换一个建模对象。

## 📖 标准定义

> **教材原文 · PSL §10.1 Setup**（<https://liangfgithub.github.io/PSL/w10/w10_1_setup.html>）
> > "As we have learned before, in the binary case, the best classifier depends on $\eta(x)= P(Y=1 | X=x).$ One type of approaches for classification is to directly model or estimate \(\eta(x)\) . Since $\eta(x)$ is constrained to between $0$ and $1$, as it represents a probability. Therefore, it's challenging to model $\eta(x)$ directly with a linear model because linear models are unconstrained. Instead, we model its transformation (or referred to as a link function ) with a linear model: $g(\eta(x)) = x^t \beta.$ Here, for simplicity, we incorporate the intercept into \(x\) , so \(\beta\) represents all the coefficients, including the intercept. In logistic regression, we use the so-called logit link function, which is equal to $\text{logit}(\eta(x)) = \log \frac{\eta(x)}{1 - \eta(x)}.$"

**标准记法**：

- $\eta(x) = P(Y=1 \mid X=x)$；$g(\eta(x)) = x^t \beta$，logistic 回归取 logit link：$\text{logit}(\eta(x)) = \log \frac{\eta(x)}{1 - \eta(x)} = x^t \beta$。
- 反函数（sigmoid）：$\eta(x) = \frac{\exp(x^t \beta)}{1+\exp(x^t \beta)} = \sigma(x^t\beta)$，$\sigma(z) = e^z/(1+e^z)$。

**中文解释**：分类的最优规则只依赖 $\eta(x)=P(Y=1|X=x)$，但 $\eta$ 被限制在 $[0,1]$，不能直接用无约束的线性模型建模；于是改成对它的变换（link function）建线性模型。logistic 回归选 logit：$\log\frac{\eta}{1-\eta}=x^t\beta$，值域覆盖整个实数轴，且 $\eta=0.5 \Leftrightarrow$ logit $=0$。

> 完整条目与更多来源见 [[定义原文库#E24. 逻辑回归的设定（setup）与 logit link|E24 逻辑回归的设定与 logit link]]

**注意**：上面这段是**面试要说出口的措辞**，不是学习入口。下面先讲直觉，把这段的意思嚼碎了，再回头看它就不难了。

## 二、核心直觉

### 换一个建模对象，而不是换一个拟合算法

失败的根源是**建模对象选错了**：我们盯着概率 $p$ 想用直线去拟合它，而 $p$ 被关在 `(0,1)` 里。

那就不拟合 $p$。改拟合一个**取值范围不受限**的、且和 $p$ 一一对应的量。这个量就是 **log-odds**。

三步走，每一步都在放宽取值范围：

| 量 | 定义 | 取值范围 | 这一步解决了什么 |
|---|---|---|---|
| 概率 $p$ | — | `[0, 1]` | 卡住 |
| 几率 odds | $p/(1-p)$ | `(0, +∞)` | 上界打开了，下界还是 0 |
| 对数几率 log-odds | $\ln\frac{p}{1-p}$ | `(−∞, +∞)` | 整条实数轴，可以和 $X\beta$ 对接 |

**这里像什么、不像什么**：可以把 logit 想成一个「拉伸器」，把挤在 `(0,1)` 里的概率拉开铺到整条数轴上。但要注意它**不是均匀拉伸** —— 在 $p$ 接近 0 或 1 的地方拉得很狠，在 $p=0.5$ 附近几乎不动。后面「系数不能解释成概率变化」这条，根子就在这里。

### 为什么必须用 log-odds，而不是随便找个无界函数

可以用 probit（正态 CDF 的逆），也可以用互补对数-对数。选 logit 有两个具体理由：

1. **它是二项分布的典则连接（canonical link）** —— 数学上让充分统计量正好是 $X'y$，IRLS 的收敛性质最好。
2. **系数能翻译成 odds ratio** —— `exp(β)` 就是 odds 的倍数，业务能听懂。

## 三、机制

### 3.1 模型形式与逐项说明

$$
\ln\!\Bigl(\frac{p_i}{1-p_i}\Bigr) = \beta_0 + \beta_1 X_{i1} + \dots + \beta_k X_{ik}
$$

逐项读：

- $p_i$：第 $i$ 个观测的事件概率，也就是 $P(Y_i=1\mid X_i)$。
- $\frac{p_i}{1-p_i}$：odds，写的是「是 1」相对「是 0」的倍数。$p=0.8$ 时 odds $=4$，读作四比一。
- 左边的 $\ln$：把 odds 取对数，于是左边可以取任意实数。
- 右边 $\eta_i = \beta_0 + \sum_j \beta_j X_{ij}$：**线性预测子**。它是线性的，但线性是发生在 **log-odds 尺度**上的，不是在概率尺度上。
- $\beta_0$：所有 $X$ 都为 0 时的 log-odds。
- $\beta_j$：$X_j$ 每增加一个单位，**log-odds** 增加 $\beta_j$，其他变量不变。

把 $p_i$ 解出来得到反函数：

$$
p_i = \frac{1}{1+e^{-\eta_i}} = \sigma(\eta_i)
$$

这是 sigmoid。它的输出永远落在 $(0,1)$——第一个问题（预测越界）解决了。

### 3.2 它是怎么来的：为什么 OLS 在这里坏掉

**问题一：预测越界。** 线性拟合 $\hat Y = X\hat\beta$ 的取值是整个实数轴，但概率只能在 `[0,1]`。数据里 $Y$ 只有 0 和 1，OLS 会给出 `−0.08` 和 `1.14` 这种值。可以事后截断到 `[0,1]`，但截断只是遮盖症状：截断后的「概率」在边界上堆成尖峰，不再随 $X$ 变化。

**问题二：方差随均值变化。** $Y_i \sim \text{Bernoulli}(p_i)$ 的方差是：

$$
\operatorname{Var}(Y_i) = p_i(1-p_i)
$$

这个量**取决于 $p_i$**。$p=0.5$ 时方差最大（0.25），$p$ 接近 0 或 1 时趋近 0。而 OLS 假设 $\operatorname{Var}(\varepsilon)=\sigma^2$ 是常数——这条在这里被直接违反。后果不是估计有偏（$\hat\beta$ 仍无偏），而是**标准误算错**，于是 t 检验和置信区间都不可信。

**关键一步在这里**：既然方差是均值的函数，就不该硬把它压成常数，而应该**把方差结构写进模型**。这正是 GLM 的做法——选一个分布（这里 Bernoulli），方差由该分布自动决定。所以 logistic 回归的推断是「自带正确方差」的，不需要额外做方差稳定变换。

### 3.3 拟合：没有闭式解，用 MLE + IRLS

OLS 有闭式解 $(X'X)^{-1}X'y$。logistic 没有，因为要解的是非线性方程。

**第一步，写似然。** 对相互独立的 $Y_i \sim \text{Bernoulli}(p_i)$：

$$
L(\beta) = \prod_{i=1}^n p_i^{Y_i}(1-p_i)^{1-Y_i}
$$

**第二步，取对数。** 连乘变连加，数值上稳定得多：

$$
\ell(\beta) = \sum_{i=1}^n \Bigl[Y_i\log p_i + (1-Y_i)\log(1-p_i)\Bigr]
$$

**第三步，令梯度（score）为零。** 得到的方程没有闭式解，用 **IRLS（iteratively reweighted least squares）** 迭代。

**怎么理解 IRLS**：每一步都是在当前 $\beta$ 处做一次**加权 OLS**，权重是每个观测的方差 $p_i(1-p_i)$。方差小的观测（$p$ 接近 0 或 1 的）信息量小、权重低；方差大的（接近 0.5 的）权重高。所以 IRLS 是 OLS 的自然推广，不是另起一套算法。

**为什么不用平方损失**：`(y−η)²` 在 0/1 结果上尺度太小（残差本来就小于 1，平方后更小），**梯度过平、训练困难**。这是 PSL §10.1 给出的理由，不是「平方损失有偏」。

软件后台完成迭代，报告：

- 系数 $\hat\beta$
- 标准误（来自观测信息矩阵 observed information matrix）
- Wald 检验、似然比检验（likelihood-ratio test）、离差（deviance）

### 3.4 接回 GLM 框架

Logistic 回归是 GLM 在 Bernoulli 结果下的特例：

| GLM 成分 | logistic 回归里是什么 |
|---|---|
| 随机成分 | $Y_i \sim \text{Bernoulli}(p_i)$，独立 |
| 系统成分 | $\eta_i = X_i\beta$ |
| 联系函数 | logit（**典则连接**） |
| 指数族参数 | $\theta = \log\frac{p}{1-p}$，$b(\theta)=\log(1+e^\theta)$，$\phi=1$ |

用的是 canonical link，所以 GLM 那套 IRLS 化简能直接套用。软件默认给 logit，不只是因为「方便」，而是因为数学上它让算法最干净。

## 四、算一遍

用一个**单二值预测变量**的例子。这种情况下 MLE 有闭式解，所以能从头算到尾，不用迭代。

### 数据

1000 张车险保单，看「报价含不含折扣」和「是否续保」：

| | 续保（Y=1） | 未续保（Y=0） | 合计 | 续保率 |
|---|---|---|---|---|
| **无折扣（X=0）** | 120 | 680 | 800 | 15.0% |
| **有折扣（X=1）** | 80 | 120 | 200 | 40.0% |
| **合计** | 200 | 800 | 1000 | 20.0% |

### 第 1 步：写出两个 cell 的经验 log-odds

为什么这么起手：单二值预测变量时，模型对每个 $X$ 值给出一个常数概率，所以这两条经验 log-odds 就是 $\beta_0$ 和 $\beta_0+\beta_1$。

$$
\text{logit}(\hat p_{X=0}) = \ln\frac{120}{680} = \ln 0.17647 = -1.7346
$$

$$
\text{logit}(\hat p_{X=1}) = \ln\frac{80}{120} = \ln 0.66667 = -0.4055
$$

**注意分母**：写的是「续保数 ÷ 未续保数」，即 odds，不是除以总数。写 $\ln\frac{120}{800}$ 就错了——那是概率的对数，不是 log-odds。

### 第 2 步：解出系数

$$
\beta_0 = -1.7346
$$

$$
\beta_1 = -0.4055 - (-1.7346) = 1.3291
$$

### 第 3 步：把 $\beta_1$ 翻译成 odds ratio

$$
e^{\beta_1} = e^{1.3291} = 3.778
$$

**验算**（这一步必须做，否则前面算错了也不知道）：

$$
\frac{\text{odds}_{X=1}}{\text{odds}_{X=0}} = \frac{0.66667}{0.17647} = 3.7778 \quad\checkmark
$$

读法：**收到折扣报价的客户，续保的几率是没收到折扣客户的 3.78 倍。**

### 第 4 步：换回概率

$$
\hat p_{X=0} = \frac{1}{1+e^{1.7346}} = 0.15, \qquad
\hat p_{X=1} = \frac{1}{1+e^{-(-0.4055)}} = \frac{1}{1+e^{-0.4055}}= 0.40
$$

和表里的经验续保率一致——单变量饱和模型本来就该这样。

### 条件检验：同一个 $\beta_1$，换一个基础率会怎样

这是这个例子最值钱的一步。$\beta_1 = 1.3291$ **锁死不变的**，但概率效应会变：

| 无折扣时的续保率 $\pi_0$ | $\text{logit}(\pi_0)$ | 有折扣时的续保率 $\pi_1$ | 概率变化 |
|---|---|---|---|
| 2% | −3.8918 | 7.16% | **+5.16 pp** |
| 5% | −2.9444 | 16.59% | +11.59 pp |
| **15%**（本例） | −1.7346 | **40.00%** | **+25.00 pp** |
| 30% | −0.8473 | 61.82% | **+31.82 pp** |
| 50% | 0.0000 | 79.07% | +29.07 pp |
| 80% | +1.3863 | 93.79% | +13.79 pp |

（pp = percentage points，百分点）

**同一个系数，概率效应从 +5 个百分点变到 +32 个百分点。** 最大值出现在 $\pi_0 \approx 34\%$ 附近。

## 五、什么情况下会失灵

### 承重假设

**假设一：观测相互独立。** 这是最容易被忽略、后果也最直接的一条。

撤掉它的后果：同一客户的 3 张保单都进了样本，它们的误差是相关的。$\hat\beta$ 仍然大致无偏，但**标准误会算小**——你以为是 1000 个独立样本，实际有效样本量可能只有 400。p 值因此虚高。

处理：用聚类稳健标准误（clustered robust SE），或者用 GEE / 混合效应模型。

**假设二：logit 尺度上线性。**

撤掉它的后果：如果真实关系是 U 形（中年龄段续保率最高，年轻和年老的都低），一条直线会系统性地低估两端、高估中间。模型不会报错，残差图也未必看得出来——**这是最安静的一种失效**。

处理：分箱、样条，或先看经验 logit 图。

**假设三：事件数足够。**

撤掉它的后果：稀有事件 + 小样本时，MLE 本身有偏（小样本偏差）。经验法则是每个预测变量至少 10–20 个**少数类**事件（EPV），不是总样本量。

### 完全分离

如果某个变量能完美分开两类——比如「是否已经理赔过」在某个小险种里恰好等于「是否续保」——那么 $\beta$ 无界，似然随系数跑到无穷而不断改善，**MLE 不存在**。软件会报「algorithm did not converge」或给出 `|β|` 十几二十几的离谱值配巨大标准误。

**注意**：此时 Ridge / Lasso **不能真正解决**，因为 CV 往往会选出 λ = 0（分离的根因不是过拟合）。真正给有限估计的是 **Firth 惩罚**。但有个安慰：**决策边界本身是稳定的**，只做排序的话影响有限。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 需要概率准（定价、期望损失） | logistic / GLM | 输出是校准过的概率 |
| 需要系数可解释、要报备 | logistic / GLM | 系数即 odds ratio，单调性由构造保证 |
| 需要 X 空间之外外推 | logistic / GLM | 线性外推（树模型做不到） |
| 只要排序、关系高度非线性 | GBM 等 | 精度更高，但不给概率的绝对水平 |
| 需要因果解释 | 都不是 | 都只给关联；因果要靠设计（实验/工具变量） |

## 六、常见误解

### 误解一：「系数就是概率的变化量」

**错误想法**：β₁ = 1.33，所以折扣让续保概率提高 1.33。

**为什么容易这么想**：线性回归里系数就是「X 加 1，Y 平均加 β」，这个直觉被带过来了；而且当我们已经在 log-odds 尺度时，这个说法在**数量级上**看起来没错。

**错在哪一步**：漏掉了「logit 是非均匀拉伸」这一步。系数作用在 **log-odds** 上，而 log-odds 到概率是非线性的。第四节的条件检验就是反例：同一个 $\beta_1=1.3291$，在 15% 基础率下概率提升 25 个百分点，在 2% 下只提升 5 个百分点。**要报概率效应，必须指定基础率。**

### 误解二：「exp(β) = 2 意味着概率翻倍」

**错误想法**：odds ratio 是 2，所以概率也变成两倍。

**为什么容易这么想**：odds 和概率在数值小时确实很接近（$p=0.1$ 时 odds $=0.111$），小概率场景下两者几乎一样，于是形成习惯。

**错在哪一步**：把 odds 当成了概率。概率 $0.1 \to 0.2$ 是翻倍，但 odds 从 $0.111 \to 0.25$ 是 2.25 倍；反过来 odds ratio = 2 时，概率从 0.1 只到 0.1818。**基础率越高，两者差得越远。**

### 误解三：「正类只有 2%，所以要先把数据平衡到 50/50」

**错误想法**：不平衡会让模型「偏向多数类」，必须先过采样或欠采样。

**为什么容易这么想**：在准确率这个指标上确实是这样——全预测为负就能拿 98% 准确率，这看起来很荒谬，于是归因到「数据不平衡」。

**错在哪一步**：把「准确率这个指标不合适」错当成「数据的比例有问题」。logistic 回归只需要**足够的少数类事件数**，不需要平衡的比例；500 个事件散在 10 万行里完全可以拟合。而且一旦重采样，**预测概率就不再是真实概率**，必须做截距校正 $β_0 - \ln(r_1/r_0)$ 才能拿去做定价。更稳的做法是保留原比例，用类权重或直接调阈值。

## 七、面试怎么答

### 30 秒版

> 二值结局不能直接套 OLS，因为直线会给出小于 0 大于 1 的预测，而且 Bernoulli 的方差 `p(1−p)` 不是常数。逻辑回归不改拟合算法，改的是**建模对象**：不建模概率，建模 log-odds。`ln(p/(1−p))` 把 `(0,1)` 映到整条实数轴，于是可以写成 `Xβ`。系数解释成 log-odds 的增量，`exp(β)` 是 odds 倍数。

### 2 分钟版（要包含的三块）

1. **动机**：越界 + 异方差，两个 OLS 假设同时被违反。
2. **机制**：概率 → odds → log-odds 三步放宽取值范围；反函数是 sigmoid，保证输出在 `(0,1)`；用 MLE 拟合，IRLS 是加权 OLS 的迭代。
3. **解释的分寸**：`exp(β)` 是 odds 倍数；说概率效应必须指定基础率。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么不用平方损失？」 | `(y−η)²` 尺度太小 → **梯度过平、训练困难**（不是「有偏」） |
| 「logit 和 probit 怎么选？」 | 数学上都是 link；logit 是 canonical link 且有 odds ratio 的可解释性 |
| 「样本不平衡怎么办？」 | 先问要不要校准概率；只要排序就不动数据、调阈值；要概率就用权重 + 截距校正 |
| 「完全分离怎么办？」 | Ridge/Lasso 只缓解（CV 常选 λ=0）；Firth 惩罚给有限估计 |
| 「怎么验证线性假设？」 | 经验 logit 图：分位分箱、算 `ln((events+0.5)/(non-events+0.5))`、对箱均值作图 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Logistic regression solves two problems you get from fitting a straight line to a 0/1 outcome: predictions outside the zero-to-one range, and a variance that changes with the mean. The fix is to model the log-odds instead of the probability — the log of p over one minus p equals X beta."

**Mechanism**

> "Solving for p gives you the sigmoid, which always lands between zero and one. There's no closed form, so we fit it by maximum likelihood with iteratively reweighted least squares. Each coefficient is a change in log-odds per one-unit increase, so the odds ratio is e to the beta."

**If they push back**

> "A common pitfall is reading the coefficient as a change in probability. It isn't — the effect on the probability depends on where you already are on the curve. And for small coefficients, e to the beta minus one is roughly the percentage change in the odds, which is the easiest version to give to a business audience."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 广义线性模型 | generalized linear model (GLM) | 随机成分 + 系统成分 + link 三件套 |
| 联系函数 | link function | 把均值连到线性预测子 |
| 典则联系函数 | canonical link | 使充分统计量为 $X'y$、IRLS 最干净的那个 link |
| 几率 | odds | `p/(1−p)` |
| 对数几率 | log-odds | `ln(p/(1−p))`，即 logit |
| S 形函数 | sigmoid | `1/(1+e^{−η})`，logit 的反函数 |
| 线性预测子 | linear predictor | `η = Xβ` |
| 几率比 | odds ratio | `exp(β)`，odds 的倍数 |
| 边际效应 | marginal effect | `β·p(1−p)`，概率尺度上的斜率 |
| 极大似然估计 | maximum likelihood estimation (MLE) | logistic 的拟合方法 |
| 迭代再加权最小二乘 | iteratively reweighted least squares (IRLS) | 每步一次加权 OLS |

| 完全分离 | complete separation | 某变量完美分开两类 → β 无界 |
