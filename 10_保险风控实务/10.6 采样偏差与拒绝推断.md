# 10.6 采样偏差与拒绝推断（Sampling Bias and Reject Inference）
<!-- real-exam-questions -->
> [!question] 🎯 **真题问法**（[[MAGNet 面试真题全解]] §1）
> - "How do you deal with an unbalanced sample?"
> 🔎 逐题导航：[[MAGNet 答案对照表]]

## 速览 At a glance

**速记**

建模样本的分布**不等于**上线后遇到的分布，这造成两类偏差，处置完全不同。第一类是**采样改了先验**：过采样/欠采样在数学上就是病例对照抽样（case-control sampling），结论是**除截距外系数几乎不变**（渐近一致），截距能校正回来——真实事件率 1%、训练集 50% 时偏移量是 $\ln(0.0101/1)=\ln(1/99)=-4.595$，训练集里的 80% 换算回真实先验只剩 **3.88%**；AUC/KS 这类排序指标几乎不动，动的是概率、阈值和校准。第二类是**选择偏差**（selection bias）：只有被批准的样本才有标签，被拒的高风险人群不可见，这个不是改个数字能解决的，要靠拒绝推断——而拒绝推断的四种做法（parcelling 增补标签、reweighting 加权、fuzzy augmentation 外推、Heckman 两阶段模型）各自都带着一个**无法用数据验证**的假设。最关键的一句：**拒绝推断不会消除偏差，它只是把假设显式化**；所以能验证的只有时间外样本和业务指标。

**一句面试答法**

> "There are two separate problems. If I oversampled, that's case-control sampling: the slopes stay consistent, so I only adjust the intercept — a one-percent true rate against a fifty-fifty training set is a shift of about minus 4.6 in log-odds. The harder one is selection bias: I only observe outcomes for approved policies, so I'd use reject inference — parcelling, reweighting by the inverse approval probability, fuzzy augmentation, or a two-stage selection model — but each of those assumes something I can't validate. It doesn't remove the bias, it just makes the assumption explicit, and I'd only ever validate it out-of-time with business metrics."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 采样偏差 | sampling bias | 训练样本的分布与上线总体不一致 |
| 选择偏差 | selection bias | 只有满足某条件（被批准）的样本才被观测到 |
| 病例对照抽样 | case-control sampling | 按标签抽样的标准名字；过采样/欠采样是它的特例 |
| 先验 / 基础率 | prior / base rate | 总体里事件占的比例 |
| 截距校正 | intercept correction | 只平移 $\beta_0$，其余系数不动 |
| 抽样率 | sampling rate ($r_1,r_0$) | 事件/非事件被抽进训练集的比例 |
| 拒绝推断 | reject inference | 给只观测到「被批准」样本的模型补上拒绝段信息 |
| 分组推断 | parcelling | 按分数分组，用同组批准样本的实际坏率给被拒者赋标签 |
| 模糊增强 | fuzzy augmentation | 用现有模型给被拒者预测 $\hat p$，复制成好坏两条加权重训 |
| 逆概率加权 | inverse probability weighting (IPW) | 按 $1/P(\text{批准})$ 加权，把样本拉回申请总体 |
| 选择模型 | selection model (Heckman) | 把「批准」与「表现」联合建模的两阶段做法 |
| 有效样本量 | effective sample size | 权重悬殊时真正起作用的样本量 |
| 时间外样本 | out-of-time (OOT) | 拒绝推断唯一可接受的验证方式 |

## 一、先看一个问题

审批模型只用通过样本训练，被拒客户的表现谁知道？

具体一点。某车险公司只保「风险评分在阈值以下」的车主，模型就是拿这批已承保保单训练出来的。看数据的时候你会发现一个结构性的空洞：

- 申请里评分差的那些人，**在你们的保单表里根本不存在**——不是「数据缺失」，是永远没有；
- 他们的表现你也不会观测到（他们出险不出险发生在别家保险公司）；
- 更麻烦的是，核保阈值本身就是**用打分卡的**：被拒的人和被批准的人不是随机分开的，而是按你手里的分数分开的。

第四步那份小数据里，800 个申请人有 340 个被拒（**42.5%**），接受样本观测到的坏率是 **4.35%**。这句话要先回答一个问题：**4.35% 描述的是谁？** 它描述的是「已经被你挑过一遍之后」留下来的人，不是你面对的全部申请人。如果被拒的人风险更高（拒保政策就是为了这个），那这个数字对「申请总体」的坏率是系统性偏低的。

卡住的那一步在于：「被拒的人真实表现如何」这件事**没有数据**。任何算法都不能从「不存在」里读出信息，只能引入一个关于他们的假设。这就是本页与 [[10.5 模型评估与监控]] 的分工——那边判模型好不好，这边判样本是不是代表了你要预测的人群。

还要先把一个常见混淆拆开：

| 情况 | 是不是采样偏差 | 后果 |
|---|---|---|
| 事件只有 2%，样本是总体的随机切片 | **不是**（只是不平衡） | 系数与校准都对，只需要换指标与阈值 |
| 把事件过采样到 50% | 是（改了先验） | 概率全错，截距可校正 |
| 只留被批准的样本 | 是（选择偏差） | 排序与校准在低分段都会偏，且标签不可得 |

第四步会用一份接受/拒绝各若干的小数据，用**逆概率加权（inverse probability weighting, IPW）**算出修正后的坏率，与「只用接受样本」的坏率对比，把偏差量化；然后改一次「被拒者坏率」的假设，看修正结果怎么跟着变。

## 二、核心直觉

### 两类偏差，处置完全不同

| | 采样改了先验 | 选择偏差 |
|---|---|---|
| 谁造成的 | 你自己动手采样（过采样/欠采样） | 业务规则先筛了一遍（审批、核保、报案） |
| 缺什么 | 什么都不缺，只是比例被改了 | 缺**标签**：被拒者的表现永远观测不到 |
| 影响什么 | 概率/校准/阈值；排序几乎不动 | 低分段的排序与校准都偏（那正是决策最密集的地方） |
| 怎么修 | 截距校正（一行代码） | 拒绝推断：要引入假设，且无法验证 |

先验那一列最容易被高估难度：改先验只动一个参数，剩下的系数是一致的，所以「截距减去 $\ln(r_1/r_0)$」就完了。选择偏差那一列相反，看着只是「补点数据」，其实补进去的每个标签都是编的。

### 为什么改先验那么容易修

**像什么**：像换了一把量尺。odds 是「事件比非事件」，抽样按标签把两类按固定比例放大或缩小，等于给 odds 乘了一个常数——乘常数在对数尺度上就是加常数。于是模型里除截距外的所有东西原位不动，只有截距平移。

**不像什么**：它不像「重新训练一遍」。如果你把样本比例改回真实先验再重训，得到的系数在渐近意义上是一样的（只是小样本下会有波动）；也就是说这一步是**换算**，不是**重新估计**。边界在这里：只有当抽样完全由标签（事件/非事件）决定时这条才成立；如果你还按某个变量挑样本（比如只保留某几个地区的样本），那就同时引入了选择偏差，截距校正救不了。

### 为什么选择偏差修不掉

被拒客户的标签不存在。所以「拒绝推断」这个名字容易误导——它听起来像一种估计，实际上是**把一组结构化假设写进训练数据**：假设同分段的被拒者与批准者风险相同（parcelling）、假设现有模型在拒绝段的外推是正确的（fuzzy augmentation）、假设批准与否只依赖可观测分数（reweighting）、或者假设存在一个能识别批准方程的排除性变量（Heckman 型选择模型）。

每个假设都可以说出来，但没有一个能用训练集验证——因为验证需要被拒者的真实标签，而那正是缺的东西。能验证的只有两处：**时间外样本**（上线后再看真实表现）和**业务指标**（通过率、风险结构、赔付率）。

**顺带记住一条**：拒绝推断会改变**概率水平**，对**排序指标**帮助有限。这与 [[10.5 模型评估与监控]] 的条件检验是同一个道理——排序指标对先验和选择权重都不敏感，校准才敏感。

## 三、机制

### 3.1 定义与逐项说明

#### 回顾性 / 病例对照抽样（PSL §10.5.3–10.5.4）

把事件（Bad）大量复制或把非事件（Good）大量删除（**过采样 / 欠采样**），本质就是**病例对照抽样**。结论（来源：UIUC PSL §10.5.3–10.5.4，基于 ESL）：

> **除截距外，逻辑回归的系数几乎不变（渐近一致）；截距可以校正回总体。**

为什么？因为 $P(y=1\mid x)\propto P(x\mid y=1)\cdot\pi$，
$$\text{odds}_{\text{总体}}(x)=\text{odds}_{\text{样本}}(x)\times\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{样本}}}
\ \Longrightarrow\ \log\text{odds}\ \text{只整体平移一个常数}$$

逐符号读：$P(x\mid y=1)$ 是**类内**的变量分布，抽样只按标签做，所以它不变；$\pi$ 是先验，抽样改的正是它；乘一个与 $x$ 无关的常数，在 log-odds 尺度上就是加常数。这就是「只有截距动」的全部机制，3.2 会把这一步写成似然。

#### 截距校正（必须能现场算）

设总体事件率 $\pi$、训练集事件率 $\pi_s$，记 $\text{odds}=\dfrac{\pi}{1-\pi}$（事件:非事件）：
$$\boxed{\ \beta_{0,\text{总体}}=\beta_{0,\text{训练}}+\ln\!\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{训练}}}\ }$$

逐符号读：$\beta_{0,\text{训练}}$ 是均衡样本上学出来的截距；$\ln\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{训练}}}$ 是平移量（**可为负**，总体先验更低时就是负的）；其余 $\beta_j$ 一个都不动。

**数值示例：真实先验 $1\%$ vs 训练集 $50\%$**
- $\text{odds}_{\text{总体}}=\dfrac{0.01}{0.99}=0.0101010$，$\ \text{odds}_{\text{训练}}=\dfrac{0.50}{0.50}=1$
- 偏移量 $=\ln\dfrac{0.0101010}{1}=\ln(0.0101010)=-\ln(99)=\mathbf{-4.5951}$
- 所以 $\beta_{0,\text{总体}}=\beta_{0,\text{训练}}-\mathbf{4.5951}$；其余系数**不动**。

**概率换算**（把训练集概率 $p_s$ 换成真实概率）：
$$p_{\text{总体}}=\frac{1}{1+\dfrac{1-p_s}{p_s}\cdot\dfrac{\text{odds}_{\text{训练}}}{\text{odds}_{\text{总体}}}}
=\frac{1}{1+\dfrac{1-p_s}{p_s}\times 99}$$

| $p_s$（训练集，均衡样本） | 似然比 $\text{odds}_s$ | 真实概率 $p_{\text{总体}}$ | 备注 |
|---|---|---|---|
| 0.50 | 1 | **1.00%** | 无信息 → 回到先验（必校验点） |
| 0.60 | 1.5 | **1.49%** | |
| 0.80 | 4 | **3.88%** | 常考的「80% 变几？」 |
| 0.90 | 9 | **8.33%** | |
| 0.99 | 99 | **50.0%** | 似然比极强时会很高，别觉得「不可能」 |

> 直观记住：偏移是 $\ln 99 = 4.595$；训练集概率 0.5 一定映射回先验 1%，这是一个免费的自我检查。

#### 显式公式（用事件 / 非事件的抽样率写，措辞与 [[1.5 Dealing with Unbalanced Samples]] 一致）

> 若做（或已经做了）过采样 / 病例对照抽样，**斜率照用，截距要校正**：
> $$\beta_{0,\text{corrected}}=\beta_{0,\text{sampled}}-\ln\!\frac{r_1}{r_0}$$
> 其中 $r_1$、$r_0$ 分别是**事件**与**非事件**的**抽样率（sampling rate）**。
> 直觉：抽样改变了事件与非事件的比例，而 log-odds 的可加结构让这一变化**只体现为截距的一个平移**。

**数字例（与上文 $-4.5951$ 同一个数，两种读法）**：真实事件率 $1\%$、训练集 $50/50$：

* 读法 A（抽样率）：均衡样本把事件放大约 $99$ 倍 ⇒ $r_1/r_0=99$ ⇒ $\beta_{0,\text{总体}}=\beta_{0,\text{训练}}-\ln 99=\beta_{0,\text{训练}}-\mathbf{4.5951}$。
* 读法 B（odds 之比）：偏移量 $=\ln\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{训练}}}=\ln\frac{0.010101}{1}=\mathbf{-4.5951}$ —— 与上文 $\beta_{0,\text{总体}}=\beta_{0,\text{训练}}+\ln\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{训练}}}$ 完全一致。

> 来源：MAGNet §1（Q: How do you deal with an unbalanced sample?）；[[MAGNet 面试真题全解]]

#### 采样对指标的影响

| 指标 | 过采样/欠采样后的变化 |
|---|---|
| 系数（除截距） | 几乎不变（渐近一致） |
| 截距 / 概率 / 校准 | **变**（必须校正） |
| AUC / KS / 排序 | 影响很小（模型正确设定下渐近不变） |
| 混淆矩阵 / 准确率 / 阈值 | 变（阈值要按真实先验重定） |

读这张表的口径是「**渐近**」：有限样本下重采样确实会改变估计值（少了样本、少了信息），只是不改变它的概率极限。所以面试里说「AUC 影响很小」比说「AUC 不变」安全。

#### 拒绝推断（Reject Inference）

**问题**：只观测到**被批准**样本的标签 → 被拒绝人群的风险未知，而他们的风险通常更高 → 模型在低分段的排序与校准都会偏（**选择偏差 / selection bias**）。
保险语境（安全表述）：只对「已承保通过」的保单建模，被拒保、被加费、主动放弃的风险体不进样本；或只对「已报案」的赔案建模。

| 做法 | 机制 | 需要的假设 | 主要风险 |
|---|---|---|---|
| **Parcelling（分组推断）** | 给拒绝样本按分数分组（如 10 组），组内按**已批准样本的实际 bad 比例**给拒绝样本分配标签，合并重训 | 「同分数即同风险」：组内被拒者与批准者同质 | 若批准政策本身就是按分数卡的，同组内被拒者风险更高 → 低估风险 |
| **Fuzzy augmentation（模糊增强）** | 用当前模型给拒绝样本预测 $\hat p$，把每条拒绝样本复制成「good（权重 $1-\hat p$）」+「bad（权重 $\hat p$）」两条，加权重训（可迭代） | 「当前模型在拒绝段的外推是正确的」 | 把现有模型的偏差**固化并放大**（自我实现） |
| **Reweighting（重加权）** | 给已批准样本权重 $1/P(\text{批准}\mid \text{score})$，把样本分布拉回**申请总体** | 批准与否近似只依赖可观测分数（近似 MAR） | 权重方差大；极端权重会主导训练；需要能估出批准概率 |
| （加分）选择模型 | Heckman 型 / 双变量 probit，把「批准」与「表现」联合建模 | 需要可识别的排除性变量 | 复杂、可解释性差、实现成本高 |

按机制归类，这四种正好覆盖面试常说的四条路：**简单增补**（parcelling 给被拒者造标签）、**加权**（reweighting，也就是下文的 IPW）、**外推**（fuzzy augmentation 用现有模型把分数外推到拒绝段）、**两阶段**（选择模型，把「批准」和「表现」两个方程一起估）。

**三条共同的风险（面试必说）**：
1. **无法验证**：拒绝样本没有真实标签，任何「拒绝推断后 AUC 提升了」都不是证据（标签是自己造的）。只能用**时间外样本** + 业务指标（通过率、风险结构、组合赔付率、坏账/赔付率）验证。
2. **自我实现**：模型在拒绝段本来就偏 → 推断把偏差放大 → 上线后再看数据又「验证」了它。
3. **业界有分歧**：有研究认为在模型正确设定时拒绝推断提升有限（**具体文献需核对**）；做法名称与优劣各团队口径不一，**必须结合业务判断**，不要宣称某一种必胜。

#### 纯保费建模里的对应物

这套东西在 [[10.1 频率-严重度与纯保费]] 里到处都有影子，面试时能对上号很加分：

| 纯保费里的情形 | 对应哪一类问题 | 为什么 |
|---|---|---|
| 频率模型的分母是「已承保暴露」 | 选择偏差 | 被拒保、被加费后放弃的风险体不进分母，组合费率描述的是「承保后」的人群；要报「申请总体」的费率就得按批准概率加权或分层 |
| 严重度模型只在 $y>0$ 的赔案上拟合（[[10.3 严重度模型与 Gamma]]） | 样本选择，但修法是截断/两阶段 | 小额不报案、快赔渠道差异都会筛一遍样本；评估口径要说清是「已报案」而不是「已出险」 |
| 只对「已报案」的赔案建模 | 选择偏差 | 报案决策本身就是一次筛选，和「被批准」同一结构 |
| 续保流失模型只用已承保客户 | 选择偏差 + 右删失 | 主动放弃的人不进样本；观察窗没结束的保单标签还没回来 |
| 暴露 offset（[[10.2 计数模型与 offset]]） | 不是偏差，是**已知常数** | offset 系数固定为 1、改的是均值结构；抽样权重乘在似然上、改的是权重分配。两者都能写成「往线性预测子里加一项」，但作用位置不同 |

### 3.2 它是怎么来的

**关键一步：抽样的似然里只多了一个常数。** 设真实模型是 $\text{logit}\,P(y=1\mid x)=\beta_0+x'\beta$。抽样时事件被抽到的概率是 $r_1$、非事件是 $r_0$，于是样本里的后验是

$$P_s(y=1\mid x)=\frac{r_1P(y=1\mid x)}{r_1P(y=1\mid x)+r_0P(y=0\mid x)}$$

两边写成 odds 形式：

$$\text{odds}_s(x)=\frac{r_1}{r_0}\cdot\text{odds}(x)\ \Longrightarrow\ \log\text{odds}_s(x)=\log\text{odds}(x)+\ln\frac{r_1}{r_0}$$

右边那个 $\ln(r_1/r_0)$ 与 $x$ 无关，所以它**只能被截距吸收**：$\beta_{0,s}=\beta_0+\ln(r_1/r_0)$，而 $\beta$ 一动不动。反过来解就是 3.1 的校正公式 $\beta_0=\beta_{0,s}-\ln(r_1/r_0)$。这也顺带解释了为什么校正之后要重定阈值——概率换个尺度，阈值也跟着换。

**关键一步：IPW 用一个分母把被观测到的标签放大回总体。** 记 $A=1$ 表示样本被批准（因此才有标签 $y$），$\hat e(x)=P(A=1\mid x)$ 是批准概率。若给定 $x$ 之后「批不批准」与「会不会坏」独立（$Y\perp A\mid X$，即 MAR），则

$$E\!\left[\frac{A\,y}{\hat e(X)}\right]=E\!\left[E\!\left[\frac{A\,y}{\hat e(X)}\Big| X\right]\right]=E\!\left[\frac{P(A=1\mid X)}{\hat e(X)}\,E[y\mid X,A=1]\right]=E[y]$$

所以 $\frac1n\sum_i \frac{A_i y_i}{\hat e(x_i)}$ 是**申请总体**坏率的估计：被拒样本的分母是 0，什么都不贡献；被批准样本按「它代表了几个申请人」放大。注意这里**没有造标签**——它假设的是「给定可观测分数，被拒者与批准者同风险」，而不是去猜被拒者的风险。第四步会看到，这个假设恰好等价于「拒绝样本坏率 = 同段批准样本坏率」（倍数 $m=1$）。

### 3.3 变形与口径

**工程上的 3 种修法**（选一种，别同时用两套逻辑）：
1. **改截距**：训练完手改 $\beta_0$（最省事、最透明）
2. **加权 / 频率权重**：让加权后的先验回到 $\pi$。设训练集 bad:good $=1{:}1$，要回到 $\pi=1\%$，需要
   $\dfrac{w_{\text{bad}}\cdot N_{\text{bad}}}{w_{\text{good}}\cdot N_{\text{good}}}=\dfrac{\pi}{1-\pi}=\dfrac{1}{99}$ ⇒ $\dfrac{w_{\text{bad}}}{w_{\text{good}}}=\dfrac{1}{99}$（只比值重要；绝对尺度只影响有效样本量）
3. **把 $\ln(w_i)$ 当 offset**（系数固定为 1，思路与 10.2 的暴露 offset 完全相同）——**不同软件对 offset 的符号约定不同，落地前用小样本对拍（需核对）**

三个口径细节：

- `freq_weights`（复制式，等价于把这条数据重复 $w$ 次）与 `var_weights`（精度权重，把这条数据的方差缩小 $w$ 倍）**不是一回事**，混用会让标准误与点估计都不对；要改先验用前者。
- IPW 有**两种写法**：Horvitz–Thompson 式 $\frac1n\sum\frac{A y}{\hat e}$ 与自归一化的 Hájek 式 $\frac{\sum A y/\hat e}{\sum A/\hat e}$。前者在 $\hat e$ 定准、样本量足够时无偏；后者对 $\hat e$ 的尺度不敏感、方差通常更小，代价是略有偏。两个都要报的时候以业务口径为主。
- 权重悬殊要**截尾**（winsorize，比如把 $\hat e$ 截在 0.05 以上）并报告**有效样本量** $\frac{(\sum w)^2}{\sum w^2}$——否则少数几个 $1/\hat e$ 很大的观测会主导训练。

**为什么风控/保险很少用 SMOTE（反直觉考点）**：
1. **合成样本不是真实客户/投保人**：定价与核保要能追溯到真实风险体与业务依据。
2. **破坏校准**：SMOTE 后输出的概率不再是真实频率，而定价、准备金、资本计提要的就是真实频率。
3. **可能生成物理上不存在的组合**（如「车龄 20 年 + 里程 0」），业务一眼看出问题。
4. **收益有限**：采样主要改的是先验，排序指标（AUC/KS）通常提升不大。
5. **行业更常用**：保持原始类比例 + **类权重** + **阈值/成本敏感决策**（见 [[1.5 Dealing with Unbalanced Samples]]）+ 用 KS/AUC/Lift 而不是准确率。

> 说法标注：这是**行业常见判断（各团队有差异，经验性结论）**，不是定理；面试时把理由（校准、可审查、收益有限）讲清楚即可。

**名称口径**：parcelling 也叫 coarse classification / 分组推断，fuzzy augmentation 有的团队叫「软标签」，reweighting 在因果推断里就是 IPW，选择模型在计量里叫 Heckman / 双变量 probit。名字不同，要讲的是同一个东西——**你用哪个假设去填那块没有标签的地方**。

## 💼 保险场景

**场景 A（续保流失，示例数据）**：真实流失率 1%，为了训练把流失样本过采样到 50%
- 训练完得到 $\beta_{0,\text{训练}}=-0.85$，其他系数不动
- 校正：$\beta_{0,\text{总体}}=-0.85-4.5951=-5.445$
- 一个「训练集概率 0.8」的保单，真实流失概率只有 **3.88%**
- 如果直接拿 0.8 去做挽留预算，会严重高估成本；这就是「不校正 = 决策失误」

**场景 B（车险核保，示例）**：某车险公司只保「风险评分在阈值以下」的车主
- 训练集里永远看不到「被拒的高风险车主」，于是模型在**低分段**（高风险段）缺乏数据
- 后果：核保阈值附近的排序和概率都不准，而**阈值附近恰恰是决策最密集的地方**
- 常见落地组合：先用 reweighting 把样本拉回申请总体，再用 parcelling 补拒绝段标签；上线后用 OOT + 通过率/赔付率双指标盯住

**场景 C（一个别搞混的点）**：样本不平衡 ≠ 采样偏差。不平衡只是「事件少」，只要**样本是总体的随机切片**，系数和校准都是对的，只需要换评估指标与阈值；而采样偏差（过采样改了先验、只留批准样本）才会真的破坏校准。

场景 B 就是第四步的例子：那份数据里被拒的占 42.5%，忽略他们会让坏率少报一半。

/* 1) 加权 logistic：把加权后的先验拉回总体（weight 语句） */
proc logistic data=train_bal;

run;

/* 2) 手改截距（最透明；改完再算概率） */
%let pi_pop   = 0.01;              /* 总体事件率 */
%let pi_train = 0.50;              /* 训练集事件率 */
data pred;
  set pred;
  shift = log( (&pi_pop/(1-&pi_pop)) / (&pi_train/(1-&pi_train)) );   /* = -4.5951 */
run;
/* 把 logistic 的线性预测子拿出来加 shift，再转成概率；或直接在 DATA 步里
   p_true = 1/(1 + (1-phat_train)/phat_train * ((&pi_train/(1-&pi_train))/(&pi_pop/(1-&pi_pop)))); */

/* 3) offset 写法（若所用版本支持 offset=，符号约定需在自己环境里对拍核对） */
proc logistic data=train_bal;
  model y(event='1') = x1-xk / offset=ln_weight;
run;

/* 4) 拒绝推断：parcelling 的骨架（分组内按批准样本的实际比例分配标签） */
proc rank data=all_apps groups=10 out=grp;
  var phat;
  ranks g;
run;
proc sql;
  create table approve_rate as                    /* 每组内批准样本的实际 bad 率 */
    select g, mean(y) as bad_rate_appr, count(*) as n_appr
    from grp
    where approved = 1
    group by g;
quit;
/* 之后按组把 bad_rate_appr 作为拒绝样本的标签比例抽样/加权，再合并重训
   —— 注意这是「造标签」，验证只能靠时间外样本，见 10.5 */

### Python

```python
import numpy as np, pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf

PI_POP, PI_TRAIN = 0.01, 0.50

# 1) 训练（均衡样本）
m = smf.logit("y ~ x1 + x2", data=train_bal).fit()

# 2) 截距校正：beta0_pop = beta0_train + ln(odds_pop/odds_train)
shift = np.log((PI_POP/(1-PI_POP)) / (PI_TRAIN/(1-PI_TRAIN)))   # -4.5951
b = m.params.copy()
b["Intercept"] += shift

# 3) 校正后的概率（与直接套公式一致）
p_train = m.predict(train_bal)
p_pop   = 1/(1 + (1-p_train)/p_train * ((PI_TRAIN/(1-PI_TRAIN))/(PI_POP/(1-PI_POP))))
print(p_train.head().round(3).tolist(), p_pop.head().round(4).tolist())

# 4) 类权重：只用比值；freq_weights（复制式）与 var_weights（精度权重）别混用
w = np.where(train_bal["y"] == 1, 1/99, 1.0)          # w_bad:w_good = 1:99
m_w = smf.glm("y ~ x1 + x2", data=train_bal,
              family=sm.families.Binomial(),
              freq_weights=w).fit()

# 5) Parcelling：组内用批准样本的实际 bad 率给拒绝样本赋标签
def parcelling(all_apps, approved="approved", y="y", score="phat", groups=10):
    d = all_apps.copy()
    d["g"] = pd.qcut(d[score].rank(method="first", ascending=False), groups, labels=False)
    rate = d[d[approved] == 1].groupby("g")[y].mean()
    rng = np.random.default_rng(42)
    d["y_parcel"] = d[y]
    mask = d[approved] == 0
    d.loc[mask, "y_parcel"] = (rng.random(mask.sum()) < d.loc[mask, "g"].map(rate)).astype(int)
    d["w_parcel"] = np.where(mask, 1.0, 1.0)          # 也可给拒绝样本更小权重
    return d

# 6) Fuzzy augmentation：复制成 good/bad 两条，权重为 1-p̂ 与 p̂，加权重训（可迭代）
def fuzzy_augment(all_apps, approved="approved", score="phat"):
    a = all_apps[all_apps[approved] == 1].copy()
    r = all_apps[all_apps[approved] == 0].copy()
    r_good, r_bad = r.copy(), r.copy()
    r_good["y"] = 0; r_good["w"] = 1 - r["phat"].values
    r_bad["y"]  = 1; r_bad["w"]  = r["phat"].values
    a["w"] = 1.0
    return pd.concat([a, r_good, r_bad], ignore_index=True)

aug = fuzzy_augment(all_apps)
m2 = smf.glm("y ~ x1 + x2", data=aug, family=sm.families.Binomial(),
             freq_weights=aug["w"]).fit()
# 迭代：用 m2 重新给拒绝样本打分 -> 再 augment -> 直到系数稳定（通常几轮）

# 7) Reweighting：按 1/P(批准|score) 加权已批准样本
m_appr = smf.logit("approved ~ phat", data=all_apps).fit()
w_rej = 1 / np.clip(m_appr.predict(all_apps), 1e-6, 1.0)
```

**代码里第 7 段与第四步是同一件事**：`w_rej = 1 / P(批准|score)` 就是 IPW 的权重，第四步那份 800 人的小数据会把它算到底。

## 四、算一遍

### 设定

申请总体 800 人，按模型分数切成两段，核保政策对两段的批准率不同。标签只对**被批准**的人可见：

| 分段 | 申请人数 | 批准率 $\hat e$ | 批准 | 拒绝 | 接受样本观测坏率 | 观测坏数 |
|---|---|---|---|---|---|---|
| 低风险段 | 500 | 0.80 | 400 | 100 | 2% | 8 |
| 高风险段 | 300 | 0.20 | 60 | 240 | 20% | 12 |
| **合计** | **800** | 0.575 | **460** | **340** | 4.35% | **20** |

被拒的 340 人（42.5%）**没有标签**——不是缺失值，是这件事永远不会被观测到。坏 = 出险/违约，只在批准的人身上记得到。

### 第 1 步：只用接受样本，坏率是多少

$$\text{坏率}_{\text{接受样本}}=\frac{8+12}{400+60}=\frac{20}{460}=\mathbf{4.3478\%}$$

这是所有建模脚本默认会报的数字。它描述的是「已经被挑过一遍之后」留下来的人。

### 第 2 步：逆概率加权的两个分量

IPW 的做法是给每条**被批准**的观测乘 $1/\hat e$，把「它代表了几个申请人」补回来：

$$\sum_i\frac{A_i y_i}{\hat e_i}=\frac{8}{0.80}+\frac{12}{0.20}=10+60=\mathbf{70}\ \Longrightarrow\ \text{坏率}_{\text{IPW}}=\frac{70}{800}=\mathbf{8.75\%}$$

读这两个数：低风险段每批准 1 个人代表 $1/0.8=1.25$ 个申请人，所以 8 个坏观测放大成 10 个；高风险段每批准 1 个人代表 $1/0.2=5$ 个申请人，12 个坏观测放大成 60 个。被拒的 340 人在这里的贡献是 0（$A_i=0$），**没有一条标签是编的**。

### 第 3 步：核对——IPW 等于哪个假设

如果直接假设「同一分段里被拒者与批准者风险相同」，总体坏数就是：

$$\underbrace{500\times2\%}_{=10}+\underbrace{300\times20\%}_{=60}=70\ \Longrightarrow\ \frac{70}{800}=\mathbf{8.75\%}\ \checkmark$$

与 IPW 完全一致。这不是巧合，正是 3.2 那个期望等式 $E[Ay/\hat e(X)]=E[y]$ 的算术版本：**IPW 不猜被拒者的风险，它假设的是「给定可观测分数，批不批准与坏不坏无关」**（$Y\perp A\mid X$）。

### 第 4 步：偏差有多大

| 口径 | 坏率 | 相对「申请总体」 |
|---|---|---|
| 只用接受样本 | **4.35%** | 少报 **4.40 个百分点**，相对少报 **50.3%** |
| IPW（按 $1/\hat e$ 加权） | **8.75%** | 基准 |

拿 4.35% 去算组合赔付率、挽留预算或核保定价，就是少报一半。这也解释了为什么「模型指标都挺好，业务数字对不上」常常出在这里。

### 条件检验：拒绝样本坏率假设改变时会怎样

把假设写成一个倍数 $m$：**被拒者的坏率 = $m$ × 同分段批准样本的坏率**。总体坏数随 $m$ 变成

$$\bigl(8+100\times0.02m\bigr)+\bigl(12+240\times0.20m\bigr)=20+50m\ \Longrightarrow\ \text{总体坏率}=2.5\%+6.25\%\,m$$

| $m$ | 拒绝段坏率（低 / 高） | 申请总体坏率 | 比「只用接受样本」高 |
|---|---|---|---|
| **1.0**（IPW 的隐含假设） | 2% / 20% | **8.75%** | +101% |
| 1.5 | 3% / 30% | **11.875%** | +173% |
| 2.0 | 4% / 40% | **15.0%** | +245% |
| 3.0 | 6% / 60% | **21.25%** | +389% |

三句读法：

1. **只用接受样本在任何 $m\ge1$ 下都偏低。** 拒保政策本来就是按分数卡的，被拒者只会更差，所以这是**系统性低报**，不是随机误差。方向性这一点面试必说。
2. **IPW 给的是 $m=1$ 那一格，它不随 $m$ 变**——因为它的假设就是 $m=1$。真实值落在哪一格，取决于「同一个分数段里被拒者和批准者有多像」；分段越细，这个假设越弱（细到每个人一格时，假设就变成「条件独立」，而那是不可检验的）。这也是为什么审批规则与评分卡越接近，选择偏差越严重。
3. **别只报一个点。** 正确的报法是「区间 + 假设」：按 $m=1$ 的 IPW 是 8.75%，如果被拒者风险是批准者的两倍就是 15%；上线后用通过率与赔付率一起校准这个假设。

### 复算脚本（本节每个数字都由它产出）

```python
# 只用标准库；IPW 坏率与 m 敏感性重算一遍
n1, n2 = 500, 300                 # 低风险段 / 高风险段申请人数
e1, e2 = 0.80, 0.20               # 两段的批准率
r1, r2 = 0.02, 0.20               # 两段批准样本的观测坏率
acc1, acc2 = n1 * e1, n2 * e2     # 批准 400 / 60
rej1, rej2 = n1 - acc1, n2 - acc2 # 拒绝 100 / 240
bad1, bad2 = acc1 * r1, acc2 * r2 # 观测坏数 8 / 12
n_pop, acc = n1 + n2, acc1 + acc2

naive = (bad1 + bad2) / acc
ipw   = (bad1 / e1 + bad2 / e2) / n_pop
print(f"只用接受样本 = {naive:.6f}")                                    # 0.043478
print(f"IPW          = {ipw:.6f}")                                      # 0.087500
print(f"低估 {ipw-naive:.6f}（相对 {(ipw-naive)/ipw:.2%}）")             # 0.044022 / 50.31%

# IPW 等价于「同分段同风险」（m = 1）
direct = (n1 * r1 + n2 * r2) / n_pop
print(f"同分段同风险 = {direct:.6f}")                                   # 0.087500

# 条件检验：拒绝样本坏率 = m × 同段批准样本坏率
for m in (1.0, 1.5, 2.0, 3.0):
    tot = bad1 + rej1 * r1 * m + bad2 + rej2 * r2 * m
    print(f"m={m}: 坏数 {tot:.0f}  总体坏率 {tot/n_pop:.6f}  公式 {0.025+0.0625*m:.6f}")
    # m=1.0 -> 70 / 0.087500     m=1.5 -> 95  / 0.118750
    # m=2.0 -> 120 / 0.150000    m=3.0 -> 170 / 0.212500

# 有效样本量（权重悬殊时真正起作用的样本量）
w = [1 / e1] * int(acc1) + [1 / e2] * int(acc2)
print(f"有效样本量 = {sum(w)**2/sum(x*x for x in w):.1f}（批准数 {acc:.0f}）")
```

最后一行是落地时要一起报的数：权重悬殊会把「460 个批准样本」的有效信息量打折，这个例子里是 **301.2**（只相当于 460 个样本的 65.5%）——$1/\hat e$ 从 1.25 到 5 的差距已经把有效样本量削掉三分之一；批准率更低（1% 上下）的场景权重更大，必须做截尾。

## 五、什么情况下会失灵

### 承重假设

**假设一（只对改先验的修法）：抽样完全由标签决定。** 撤掉它的后果：如果你还按某个变量挑样本（只留三个渠道的数据、删掉某个地区、只保留 2024 年之后起保的保单），那就同时引入了选择偏差，截距校正救不了——这时要按变量分层或做 IPW。诊断办法是拿训练样本与申请总体对每个变量的分布，看有没有除了标签之外的系统性差异。

**假设二（IPW / parcelling 的承重假设）：给定可观测分数，被拒者与批准者同风险。** 这个假设没法用训练数据验证（被拒者的标签不存在）。撤掉它的后果是可量化的：条件检验那张表里，$m=2$ 时真实的总体坏率是 15%，而 IPW 仍报 8.75%——**低估 6.25 个百分点**。缓解手段只有两个方向：把分段切细（假设变弱），或者承认这个区间并在上线后校准。

**假设三：批准概率 $\hat e$ 能估得准，而且不会小到不可用。** 撤掉它的后果：$\hat e$ 估偏 → 权重系统性错；$\hat e$ 极小 → 权重极大 → 有效样本量暴跌（本例 460 个批准样本只相当于 301.2 个），少数几条观测主导训练。落地要求：批准率极低的段要么合并、要么截尾，并报告有效样本量。

**假设四：批准政策在训练窗内稳定。** 撤掉它的后果：中途调了核保阈值、改了渠道规则，历史拒绝样本的含义就变了（同样的分数在老政策下会被拒、在新政策下会被批），跨期合并等于把两种政策混成一份数据。**被拒原因本身也是变量**，这是最容易漏的一条。

**假设五：标签本身可观测、口径一致。** 撤掉它的后果跟 10.5 里那条一样：观察窗还没结束（右删失）、赔案还没报完（IBNR）、坏的定义换了口径——这些都会让「后来才知道的结果」系统性偏向一边，而它与采样偏差叠在一起时，两个方向可能互相抵消，也可能互相放大，报数前要分开看。

### 与其他方法的边界

| 场景 | 用谁 | 为什么不用别的 |
|---|---|---|
| 事件稀有，但样本是随机切片 | 保持原比例 + 类权重 + KS/AUC/Lift 评估 | 不平衡不改系数与校准，不需要采样 |
| 已经过采样，但只做排序 | 什么都不用做 | AUC/KS 渐近不变 |
| 已经过采样，要报概率/定价 | 截距校正（或 `freq_weights`） | 换算是确定的，不用重训 |
| 观测到的是被批准样本，只要报总体坏率 | IPW（$1/\hat e$ 加权） | 不造标签，假设写在明面上 |
| 要重训模型、还要补拒绝段信息 | parcelling / fuzzy augmentation | 要接受「自我实现」与无法验证两条代价 |
| 审批与表现互相影响，且有排除性变量 | Heckman 型两阶段 | 能识别，但实现与解释成本高 |
| 想让偏差根本不出现 | 放松阈值、分层承保、随机放款一小批再收集标签 | 最好的「拒绝推断」是让样本不再被选择 |

## 六、常见误解

### 误解一：「拒绝推断能消除采样偏差」

**错误想法**：跑完拒绝推断，样本就代表申请总体了，偏差解决了。

**为什么容易这么想**：名字听起来像一种估计方法，而且软件包里确实有现成的接口，跑完还会看到「拒绝样本已补标签」这样的日志。

**错在哪一步**：把「补数据」当成「补信息」。被拒者的标签不存在，所以任何做法都是在注入假设：parcelling 注入「同组同风险」，fuzzy augmentation 注入「现有模型外推正确」，IPW 注入「给定分数可忽略」（例子里就是 $m=1$）。它把这些假设**显式化**了，这是它的价值；但假设错了，结果一样错——$m=2$ 时 IPW 仍低估 6.25 个百分点，而且这个错误**不能用训练集发现**。

### 误解二：「事件只有 2%，必须先过采样再建模」

**错误想法**：不平衡会让模型偏向多数类，所以先把事件过采样到 50%。

**为什么容易这么想**：在准确率这个指标上确实如此——全预测为「不发生」就能拿 98% 分，看起来很荒谬，于是归因到「数据不平衡」。

**错在哪一步**：把「指标选错了」当成「数据的比例有问题」（[[1.3 Introducing Logistic Regression]] 误解三讲过同一件事）。逻辑回归需要的是**足够的事件数**，不是均衡的比例；一旦重采样，预测概率就不再是真实频率，定价与准备金要的就是真实频率，所以必须校正回来。更稳的做法是保持原始比例 + 类权重 + 成本敏感阈值。

### 误解三：「拒绝推断后 AUC 提升，说明推断有效」

**错误想法**：加进拒绝样本重训，验证集 AUC 涨了，说明这次推断做得对。

**为什么容易这么想**：平时判断改动好不好，就是看指标涨没涨，这个习惯被直接搬过来了。

**错在哪一步**：那些拒绝样本的标签是**自己按假设造的**，模型拟合它们拟合得更好只能说明「模型和自己的假设一致」，不是证据。真正的验证只有两条：时间外样本（上线后回来的真实标签）和业务指标（通过率、风险结构、赔付率）。

### 误解四：「只有核保模型才有选择偏差」

**错误想法**：不批准就不建模，选择偏差是审批类模型才有的问题。

**为什么容易这么想**：「拒绝推断」这个术语是从信贷审批场景长出来的，别的场景没人这么叫。

**错在哪一步**：选择偏差的结构是「进入样本需要满足一个与结果相关的条件」，只要这个结构在，就有偏差。频率模型的样本是「已承保保单」（核保门槛筛过一遍）、严重度模型的样本是「已报案赔案」（报案决策筛过一遍）、续保模型的样本是「已承保客户」（主动放弃的人不在里面），全都一样。识别方法很简单：问一句「**样本是被什么规则筛进来的，这条规则和我要预测的结果有没有关系**」。

## 七、面试怎么答

### 30 秒版

> 先分成两类问题。**过采样/欠采样**本质是病例对照抽样，除掉截距以外系数几乎不变，截距可以校正：真实事件率 1%、训练集 50/50 时偏移量是 $-4.595$，训练集里的 80% 换算回真实先验只有 3.88%；排序指标几乎不动，动的是概率、阈值和校准。**只观测到被批准样本**是选择偏差，被拒者的标签不存在，要靠拒绝推断——增补（parcelling）、加权（reweighting/IPW）、外推（fuzzy augmentation）、两阶段（Heckman）——它们的共同点是**都带着一个无法验证的假设**：拒绝推断不会消除偏差，只是把假设显式化。所以我只会用 OOT 加业务指标去验证，落地更倾向保持原比例 + 类权重 + 成本敏感阈值。

### 2 分钟版（要包含的四块）

1. **改先验这一类**：病例对照抽样 → 类内分布不变、只有先验变成倍数 → log-odds 只平移一个常数；例：1% vs 50% 是 $\beta_0-\ln 99=\beta_0-4.5951$，80% 映射到 3.88%；工程修法三选一（改截距 / `freq_weights` / $\ln w$ 当 offset），校正完必须重定阈值。
2. **选择偏差这一类**：只有批准样本有标签，被拒者风险更高且在低分段缺数据，而低分段正是决策最密集处；四种做法与各自假设（同段同风险 / 现有模型外推对 / 给定分数可忽略 / 有排除性变量）。
3. **共同风险**：无法验证（拒绝样本标签是造的）、自我实现（偏差被放大后又被「验证」）、业界对效果有分歧；所以验证只能靠 OOT + 通过率/赔付率。
4. **一个可算的接口**：IPW 的坏率 = $\frac1n\sum A_i y_i/\hat e_i$；第四步那份数据里，只用接受样本 4.35%、IPW 8.75%，差 4.40 个百分点（相对少报 50.3%）；把「被拒者坏率 = $m$ × 同段批准样本坏率」当假设扫一遍，$m=2$ 时是 15%。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「过采样后系数为什么不变？」 | 抽样只按标签做 → 类内分布不变、先验被乘一个常数 → odds 乘常数 → log-odds 加常数 → 只有截距动；斜率渐近一致（见 [[1.5 Dealing with Unbalanced Samples]]） |
| 「截距怎么校正？」 | $\beta_0-\ln(r_1/r_0)$；1% vs 50% 就是 $-4.5951$；校正后概率从 0.8 变 3.88%，阈值要重定 |
| 「加权和 offset 选哪个？」 | 改先验用 `freq_weights`（复制式）；`var_weights` 是精度权重、不是一回事；offset 写法要核对符号约定 |
| 「拒绝推断具体怎么做？」 | 四种做法 + 各自假设 + 共同风险；说清「它不消除偏差，只把假设显式化」 |
| 「IPW 的假设到底是什么？」 | 给定可观测分数后 $Y\perp A$（近似 MAR）；本例等价于 $m=1$（8.75%）；分段越细假设越弱；$\hat e$ 极小时要截尾并报有效样本量 |
| 「怎么验证拒绝推断？」 | 训练集内无法验证（标签是自己造的，AUC 涨不是证据）；只能看 OOT 和通过率/风险结构/赔付率 |
| 「保险里哪些地方会遇到？」 | 频率模型分母只含已承保暴露、严重度只对已报案赔案建模、续保模型只含已承保客户；报「申请总体」要加权，报「组合」要写清口径 |
| 「为什么不用 SMOTE？」 | 破坏校准、合成样本不可追溯、收益有限（只改先验）；行业更常用类权重 + 成本敏感阈值 |

## 🗣️ 面试速答（30 秒）

> 先说两类问题。第一类是**采样改了先验**：过采样/欠采样本质是病例对照抽样，PSL 的结论是**除截距外系数几乎不变**，截距可以校正回来。真实事件率 1%、训练集 50% 时，偏移量是 $\ln\frac{0.0101}{1}=\ln(1/99)=-4.595$，所以把训练截距减 4.595 就回到总体先验；训练集里 80% 的概率实际只有 3.88%。第二类是**选择偏差**：只有被批准的样本才有标签，被拒的高风险人群不可见。三种主流做法——parcelling 组内按批准样本比例补标签、fuzzy augmentation 把拒绝样本按预测概率复制成好坏两条加权重训、reweighting 按 $1/P(\text{批准})$ 加权。它们的共同风险是**自我实现**：模型在拒绝段本来就偏，推断会把偏差放大，而且没法用训练指标验证，只能看 OOT 和业务指标；业界对这些做法的效果有分歧，所以我更倾向保持原始类比例 + 类权重 + 阈值成本敏感，而不是 SMOTE——SMOTE 会破坏校准，而保险定价要的就是真实频率。

## ⚠️ 常见坑
- **校正方向搞反**：$\beta_0^{\text{总体}}=\beta_0^{\text{训练}}+\ln\frac{\text{odds}_{\text{总体}}}{\text{odds}_{\text{训练}}}$，总体先验更低时 shift 是**负**的（−4.595）。
- **校正了截距却忘了重定阈值**：阈值也必须按真实先验重算，否则业务规则全错。
- **把 SMOTE 后的概率当真实概率**去算挽留成本、赔付率。
- **用「拒绝推断后训练 AUC 提升」当证据**：拒绝样本的标签是自己造的，不构成验证。
- **忘了被拒原因本身是变量**：批准政策变化（阈值调整）会让历史拒绝样本的含义改变，跨期合并要小心。
- **不平衡 = 偏差 的混淆**：随机切片下的不平衡不改系数，只影响阈值与指标选择。
- **重加权后忘了有效样本量**：权重方差极大会让某些观测主导训练，最好报告有效样本量并做截尾（winsorize）。
- **报了一个点估计就完事**：被拒者坏率是假设，不是数据；要么给区间（本例 $m=1$ 是 8.75%、$m=2$ 是 15%），要么说清假设再报数。

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话说明 |
|---|---|---|
| 采样偏差 | sampling bias | 训练样本分布与上线总体不一致的总称 |
| 选择偏差 | selection bias | 样本的入选条件与结果相关，被拒段标签不可得 |
| 病例对照抽样 | case-control sampling | 按标签抽样的标准名字，过采样/欠采样是特例 |
| 先验 / 基础率 | prior / base rate | 总体里事件的比例 |
| 抽样率 | sampling rate ($r_1$, $r_0$) | 事件 / 非事件被抽进训练集的比例 |
| 截距校正 | intercept correction | $\beta_0-\ln(r_1/r_0)$，只平移截距 |
| 频率权重 | frequency weight | 等价于把观测重复 $w$ 次，用来改先验 |
| 精度权重 | analytic / variance weight | 把观测的方差按 $w$ 缩放，与频率权重不同 |
| 拒绝推断 | reject inference | 给只有批准样本标签的模型补拒绝段信息 |
| 分组推断 | parcelling | 按分数分组，用组内批准样本坏率给被拒者赋标签 |
| 模糊增强 | fuzzy augmentation | 按预测概率把被拒样本复制成好坏两条加权重训 |
| 逆概率加权 | inverse probability weighting (IPW) | 按 $1/\hat e$ 加权，把样本拉回申请总体 |
| 批准概率 / 倾向得分 | approval probability / propensity score ($\hat e$) | IPW 的分母，通常用 logistic 估 |
| 可忽略性 / 随机缺失 | ignorability / MAR | $Y\perp A\mid X$：给定观测变量后选择与结果无关 |
| 选择模型 | selection model (Heckman) | 把批准方程与表现方程联合估计的两阶段做法 |
| 有效样本量 | effective sample size | $(\sum w)^2/\sum w^2$，权重悬殊时会远小于样本数 |
| 截尾 | winsorizing | 把极端权重压到分位点，防止少数观测主导训练 |
| 合成少数类过采样 | SMOTE | 生成新样本的采样法；保险里少用，因为破坏校准 |
| 时间外样本 | out-of-time (OOT) | 拒绝推断唯一可接受的验证方式 |
