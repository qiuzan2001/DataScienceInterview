# 10.7 SAS 实操速查

## 🎯 一句话
保险公司里模型大多跑在 SAS 上，所以面试常问「这段 SAS 什么意思、输出怎么看」——这一页把风控建模最常用的 7 个 PROC 的**关键语句 + 输出解读**压成一页，能照着写、能照着讲。

> ⚠️ **本页所有 SAS 语法需在实际环境中验证**（版本、组件、发行包不同，选项名与可用性可能不同）。凡是拿不准的选项，我都标了「需核对」，**不要当成确定事实背下来**。

---

## 📐 核心公式 / 速查表

| 任务 | PROC | 一句话 |
|---|---|---|
| 逻辑回归建模 | `PROC LOGISTIC` | 评分卡的主力模型，`model y(event='1')=...` |
| 变量聚类降共线性 | `PROC VARCLUS` | 把相关变量分簇，每簇挑一个代表 |
| 分箱 | `PROC HPBIN` / `PROC FREQ` | 连续变量切箱 + 统计每箱 good/bad |
| 缺失值插补 | `PROC MI` + `PROC MIANALYZE` | 多重插补 m 份 + 汇总标准误 |
| 频率/严重度/纯保费 | `PROC GENMOD` | `dist=` / `link=` / `offset=` 三件套 |
| 决策树 | `PROC HPSPLIT` | `grow` + `prune`，输出可解释规则 |
| 梯度提升 | `PROC GRADBOOST` | 树数 + 学习率 + 采样比例（Viya/CAS 环境） |

评分卡上线用的刻度化公式（细节见 [[10.4 评分卡与 WOE 落地]]）：
$$\text{score}=A-B\ln(\text{odds}),\quad B=\frac{\text{PDO}}{\ln 2},\quad A=\text{base\_score}+B\ln(\text{base\_odds})$$
SAS 里 `log()` 就是自然对数，所以 `B = PDO / log(2);`。

## 💼 保险场景

**一个典型的「从保单表到可上线费率/风险模型」的 SAS 全流程（示例）**：

1. 数据准备：暴露期 `log(exposure)`、赔付聚合、按保单/赔案粒度对齐
2. 变量筛选：`PROC VARCLUS`（去共线性）→ `PROC LOGISTIC` 的 `selection=stepwise`
3. 缺失值：`PROC MI` + `PROC MIANALYZE`
4. 分箱 + WOE：`PROC HPBIN`/`PROC FREQ` + `PROC SQL`（WOE/IV 代码见 [[10.4 评分卡与 WOE 落地]]）
5. 主模型：
   - 二分类风险模型 → `PROC LOGISTIC`（评分卡刻度化）
   - 频率 → `PROC GENMOD` `dist=poisson / offset=log(exposure)`
   - 严重度 → `PROC GENMOD` `dist=gamma link=log`
   - 纯保费 → `PROC GENMOD` `dist=tweedie`
6. 对照/发现：`PROC HPSPLIT`（可解释规则）、`PROC GRADBOOST`（性能上限、变量重要性）
7. 评估与监控：`PROC RANK` + `PROC MEANS` 出十分位 Lift 表，`outroc=` 算 KS，`PROC SQL` 算 PSI（见 [[10.5 模型评估与监控]]）
8. 上线：`PROC SCORE` 或 DATA 步打分

## 🛠️ 代码

### 1. `PROC LOGISTIC` —— 建模全流程
```sas
proc logistic data=mydat descending;                 /* descending：按响应水平降序建模（需核对缩写） */
  class veh_type age_bnd (ref='base') / param=ref;   /* param=ref：基准类别系数=0，输出即相对数 */
  model y(event='1') = x1-xk veh_type age_bnd
        / selection=stepwise slentry=0.05 slstay=0.05
          lackfit rsquare ctable pprob=0.5;
  output out=pred p=phat;
  roc;                     /* 也可写成 PROC 语句的 plots=roc */
  units x1=1 x2=10 / label;   /* 按「每 1 单位 / 每 10 单位」输出 odds ratio */
run;
```
**输出怎么读（2–4 句）**
- `Analysis of Maximum Likelihood Estimates`：`Estimate` 是 $\beta$，`Pr > ChiSq` 是 p 值，取 `exp(Estimate)` 就是 odds ratio / 相对数。
- `Model Fit Statistics`：AIC/SC 用于**同一数据集上的嵌套/竞争模型比较**；`R-Square` 是广义 $R^2$。
- `Hosmer and Lemeshow Goodness-of-Fit`（`lackfit`）：整体拟合检验，对大样本和分组方式敏感，**参考即可**。
- `ctable` + `pprob=`：输出分类表（混淆矩阵）；`roc` / `plots=roc` 出 ROC 曲线与 AUC；`selection=stepwise` + `slentry/slstay` 控制进出（也叫 stepwise 门槛 0.05）。
- 上线打分：另加 `score data=newdata out=scored;`（`PROC SCORE` 也可以，见 10.4）。

### 2. `PROC VARCLUS` —— 变量聚类 / 降共线性
```sas
proc varclus data=mydat maxeigen=1 proportion=0.7 short summary outtree=tree;
  var x1-xk;
run;
/* maxeigen= 与 proportion= 控制「簇怎么继续拆」：前者看第二特征值，
   后者要求新簇至少解释一定比例的方差；二者取先触发者（默认值以 SAS 文档为准，需核对） */
```
**输出怎么读（2–4 句）**
- 每个 cluster 列出变量及其 `R-squared with Own Cluster`（$R^2_{own}$）与 `R-squared with Next Closest`（$R^2_{next}$）。
- 关键的 `1-R**2 Ratio` $=\dfrac{1-R^2_{own}}{1-R^2_{next}}$：**大于 1 说明这个变量放在别的簇更合适**，是「该不该挪变量」的判据。
- `summary` 给每个簇的变量数与解释方差；实务做法是**每簇挑一个代表变量**（如 $R^2_{own}$ 最高、业务最可解释的那个）再进模型。
- 与 [[3.5.2 SAS VARCLUS]] 是同一件事：先用聚类去冗余，再用 GLM 拟合。

### 3. `PROC HPBIN` / `PROC FREQ` —— 分箱与箱内统计
```sas
/* 分箱：把连续变量切成粗箱 */
proc hpbin data=mydat numbin=20;         /* numbin= 指定箱数 */
  input x1-xk;
run;
/* 等频 / 等宽 / 自定义切点等选项名与默认行为以 SAS 文档为准（需核对）；
   WOE 计算所需的「每箱 good/bad 计数」用 PROC FREQ 或 PROC SQL 统计 */

proc freq data=binned noprint;
  tables bin_var * y / sparse out=cell_counts(drop=percent);
run;
```
**输出怎么读（2–4 句）**
- `PROC HPBIN` 给出**切点与每箱样本数**，先看每箱占比是否均衡（有些箱太小就要合并）。
- `sparse` 让零计数的组合也出现在输出里，方便后面加 0.5 平滑算 WOE（否则 $\ln(0)$）。
- `cell_counts` 就是 WOE/IV 的输入表（列：箱、y、频数）；完整 WOE/IV 的 `PROC SQL` 骨架见 [[10.4 评分卡与 WOE 落地]]。
- 分箱后一定要人工看 WOE 是否**单调**；不单调就合并相邻箱。

### 4. `PROC MI` + `PROC MIANALYZE` —— 多重插补
```sas
proc mi data=mydat nimpute=10 seed=12345 out=miout;
  mcmc;                      /* 马尔可夫链蒙特卡洛；假设多变量正态，可处理任意缺失模式 */
  var x1-xk;
run;

proc logistic data=miout descending;
  by _imputation_;           /* 对每一份插补数据各拟合一次 */
  model y(event='1') = x1-xk / covb;
  ods output parameterestimates=miparm;    /* 需要协方差矩阵时同时抓 covb */
run;

proc mianalyze parms=miparm;               /* 若有 covb= 数据集，一并写上 covb=mipcov */
  modeleffects Intercept x1-xk;
run;
```
**输出怎么读（2–4 句）**
- `PROC MI` 产出 $m$ 份数据集（`nimpute=` 份，`_Imputation_` 编号）；`seed=` 固定随机种子，保证可复现。
- `PROC MIANALYZE` 的 `Multiple Imputation Parameter Estimates` 给出合并后的估计、标准误、$t$、$p$、95% CI——**这才是能写进报告的结果**，不要只报某一份。
- 同时会给出方差分解（Within / Between / Total variance）、`Relative Efficiency` 与 `Fraction of Missing Information`：组间方差大 = 插补之间差异大 = 缺失信息多。
- `mcmc` 假设多变量正态；若变量类型复杂/模式复杂，可考虑 `fcs` 语句（选项与版本支持需核对）。对应库内 [[4. Missing Data]] 的 MICE 思路。

### 5. `PROC GENMOD` —— 频率 / 严重度 / 纯保费
```sas
/* 频率：Poisson + offset（offset 系数固定为 1） */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model clm_count = veh_type age_bnd
        / dist=poisson link=log offset=ln_exposure;
  lsmeans veh_type / diff cl;         /* 相对数：对 estimate 取 exp */
run;

/* 过散布：准 Poisson（系数不变，标准误被放大；选项名以文档为准，需核对） */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model clm_count = veh_type age_bnd
        / dist=poisson link=log offset=ln_exposure scale=pearson;
run;

/* 负二项（过散布的似然模型） */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model clm_count = veh_type age_bnd
        / dist=negbin link=log offset=ln_exposure;
run;

/* 严重度：Gamma + log link（每行 = 一次赔案） */
proc genmod data=claims_sev;
  class veh_type age_bnd / param=ref;
  model loss_amt = veh_type age_bnd / dist=gamma link=log;
run;

/* 纯保费：Tweedie（power p 的指定方式以版本文档为准，需核对；p 一般在 1–2 之间按 AIC 搜） */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model pure_premium = veh_type age_bnd
        / dist=tweedie link=log offset=ln_exposure;
run;

/* 零膨胀：PROC COUNTREG（分布名 dist=zip / dist=zinb，各版本支持情况需核对） */
proc countreg data=claims;
  model clm_count = veh_type age_bnd / dist=zip;
run;
```
**输出怎么读（2–4 句）**
- `Criteria For Assessing Goodness Of Fit`：`Pearson Chi-Square/DF` 明显大于 1 → 过散布（考虑 quasi-Poisson / 负二项）；`Scaled Deviance` 用于比较嵌套模型与算 deviance。
- `Analysis Of Maximum Likelihood Parameter Estimates`：`Estimate` 取 `exp()` = 相对数；`Scale` 是 $\phi$ 的估计。
- `Type 3 Analysis`：看每个因子**整体**是否显著（有多个水平的类别变量必看这个，不要只盯某一个 dummy）。
- `lsmeans` 输出各类别的最小二乘均值与两两差异；也可以 `estimate 'A vs B' veh_type 1 -1 / exp;` 直接给相对数（`exp` 选项名以版本为准，需核对）。
- 对应的公式与业务解释见 [[10.1 频率-严重度与纯保费]]、[[10.2 计数模型与 offset]]、[[10.3 严重度模型与 Gamma]]。

### 6. `PROC HPSPLIT` —— 决策树
```sas
proc hpsplit data=mydat seed=12345 cvmodelfit;
  class y veh_type age_bnd;
  model y = veh_type age_bnd x1-xk;
  grow entropy;              /* 也可 grow gini; */
  prune costcomplexity;      /* 也可 prune reducederror; */
run;
/* 深度/叶节点等超参用 grow 语句的选项控制（如 maxdepth=、minleafsize=），
   选项名与默认值以 SAS 文档为准（需核对）；cvmodelfit 输出交叉验证拟合表 */
```
**输出怎么读（2–4 句）**
- `Model Information` / `Dimensions`：确认因变量水平、观测数与候选变量数。
- 树的叶节点表 = **规则清单**，可以直接翻译成业务语言（如「车龄 >10 年且上年无赔付 → 高风险」），这是业务和监管最愿意看的产出。
- `cvmodelfit` 的交叉验证表给出不同复杂度下的拟合/验证指标，用来看是不是过拟合。
- 变量重要性/竞争表现可与 `PROC GRADBOOST` 对比；方法本身见 [[7.5 CART Algorithm]] 与 [[7.2.2.4. Pruning Decision Trees]]。

### 7. `PROC GRADBOOST` —— 梯度提升
```sas
proc gradboost data=mydat seed=12345;
  target y / level=nominal;              /* 目标：分类 */
  input x1-xk / level=interval;          /* 连续变量 */
  input veh_type age_bnd / level=nominal;/* 类别变量 */
  ntrees=200;
  learningrate=0.1;
  subsample=0.5;                          /* 行采样比例；列采样等选项以文档为准（需核对） */
  partition fraction(validate=0.2);       /* 划分验证集 */
run;
/* ⚠️ PROC GRADBOOST 属 SAS Viya / CAS 环境的机器学习过程；
   SAS 9.4 里通常没有它（9.4 侧的对照可用 PROC HPFOREST / PROC HPSPLIT，组件可用性需核对） */
```
**输出怎么读（2–4 句）**
- `Model Information` 与 `Number of Trees`：确认迭代次数是否已到上限（若到上限，考虑加大 `ntrees=` 或调 `learningrate=`）。
- 变量重要性表：用于**发现强变量和交互**，可以反过来指导 GLM 的变量清单。
- 验证集上的拟合曲线/评估指标：看随树数增加的收敛与过拟合点。
- 报价与费率场景下，GBM 主要作为**基准与变量发现**，不是最终费率表（原因见 [[10.1 频率-严重度与纯保费]]）。

### 8. 配套：评估与上线（细节见对应笔记）
```sas
/* 十分位 Lift 表 */
proc rank data=scored groups=10 out=deciles;
  var phat;  ranks decile;          /* 默认升序：decile=1 是分数最小 */
run;
proc means data=deciles nway noprint;
  class decile;  var y;
  output out=lift n=n_obs sum=n_bad mean=bad_rate;
run;

/* KS：outroc= 输出 ROC 坐标，KS = max(_SENSIT_ - _1MSPEC_) */
proc logistic data=card;
  model y(event='1') = woe_x1-woe_xk / outroc=roc;
run;

/* PSI */
proc sql;
  create table psi as
  select sum((pct_act - pct_exp) * log(pct_act/pct_exp)) as psi
  from dist_cmp;
quit;

/* 批量打分（系数数据集结构、截距处理以 SAS 文档为准，需核对） */
proc score data=newdata score=scorecard_out out=scored type=parms;
  var woe_x1-woe_xk;
run;
```

## 🗣️ 面试速答（30 秒）

> SAS 里建风控模型的标准链路是：`PROC VARCLUS` 去共线性、`PROC LOGISTIC` 建评分卡，用 `selection=stepwise slentry=0.05 slstay=0.05`、`lackfit`、`ctable pprob=0.5`、`plots=roc` 看拟合与区分度；缺失值用 `PROC MI` 插补 $m$ 份 + `PROC MIANALYZE` 汇总；保险特有的频率-严重度用 `PROC GENMOD`，Poisson 带 `offset=log(exposure)`、严重度 `dist=gamma link=log`、纯保费 `dist=tweedie`；树模型用 `PROC HPSPLIT`（可解释规则）和 `PROC GRADBOOST`（性能上限）。输出层面我最关心三件事：`exp(Estimate)` 是不是相对数、`Pearson Chi-Square/DF` 说明有没有过散布、变量重要性/Type 3 是否支持业务方向。

## ⚠️ 常见坑
- **选项名张冠李戴**：`scale=pearson`、`dist=negbin`、Tweedie 的 power 选项等在不同版本/组件里写法不同——**报错先看 log，不要硬背**。
- **忘了 `param=ref`**：默认效应编码下输出的是「与均值之差」，不是相对数。
- **`offset=` 忘取对数**：`offset=ln_exposure` 要求变量本身已经是 log 值。
- **`PROC MI` 之后直接跑一次模型**：必须 `by _imputation_;` + `PROC MIANALYZE` 汇总，单份结果不能报。
- **`PROC GRADBOOST` 当成 SAS 9.4 过程**：它属于 Viya/CAS 环境（**需核对所在环境**）。
- **把 `PROC HPSPLIT` 的树直接当费率表**：不可外推、不单调（[[10.1 频率-严重度与纯保费]]）。
- **忘了固定随机种子**（`seed=`）：多重插补、树模型、采样都不可复现，面试聊到「可复现」会扣分。
