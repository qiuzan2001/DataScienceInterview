# 10.3 严重度模型与 Gamma（Severity Modeling and Gamma）

> - (§1) "Which distribution would you pick for an insurance target?"
> - (§2) "What is capping/flooring and why do it?"
> 🔎 逐题导航：[[MAGNet 答案对照表]]

## 速览 At a glance

**速记**

单次赔付金额是**正的、右偏的、重尾的**，所以不能用正态：正态会给出负的赔付预测，尾部衰减太快会低估大额赔案，还假设常数方差。严重度模型用 **Gamma** 配 **log link**：$E[Y\mid x]=e^{x'\beta}$ 保证预测为正，系数是乘性相对数，方差 $=\phi\mu^2$、变异系数恒为 $\sqrt{\phi}$（不管平均赔付多高，相对波动一样）。尾部更重就换 **lognormal**（对 $\log Y$ 做正态回归，回代均值必须乘 $e^{\sigma^2/2}$，否则系统性低估），再重就上 **Pareto / GB2**。选择的实质是拿参数换尾部：Pareto 的尾指数 $\alpha\le2$ 时方差不存在，样本均值、标准误、CLT 全不可靠，而再保层与准备金恰恰要看这段尾部——所以必须参数化外推，不能只报样本平均。

**一句面试答法**

> "Severity is a positive, right-skewed, heavy-tailed amount, so a normal model is wrong: it can predict negative losses, it decays too fast in the tail, and it assumes constant variance. I'd fit a Gamma GLM with a log link, where the mean is exp(x'beta) and the coefficient of variation is constant; if the tail is heavier I'd switch to a lognormal — remembering the mean back-transform factor — or to a Pareto / GB2 for the extreme layers, because that's the part reinsurance and reserving actually depend on."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 严重度 | severity | 单次赔付金额，取值为正的右偏连续量 |
| 形状参数 | shape parameter $\alpha$ | 决定偏度与尾部厚度；Gamma 里 $CV=1/\sqrt{\alpha}$ |
| 尺度参数 | scale parameter $\theta$ | 只改水平不改相对波动（注意 rate 参数化是 $1/\theta$） |
| 离散参数 | dispersion parameter $\phi$ | GLM 写法里 $\operatorname{Var}=\phi\mu^2$，$\phi=1/\alpha$ |
| 对数连接 | log link | $\log\mu=x'\beta$，保证 $\mu>0$、系数乘性可解释 |
| 变异系数 | coefficient of variation (CV) | $SD/\text{mean}$；Gamma 里恒为 $\sqrt{\phi}$ |
| 对数正态 | lognormal | 对 $\log Y$ 做正态回归；均值回代要乘 $e^{\sigma^2/2}$ |
| 均值回代 | mean back-transform | 从中位数（或 log 尺度均值）换回均值的修正 |
| 帕累托 | Pareto | 重尾分布；$\alpha\le2$ 时方差不存在 |
| 尾指数 | tail index | Pareto 的 $\alpha$，越小尾越重 |
| 免赔额 | deductible | 低于它的损失观测不到（截断/删失的来源） |
| 赔偿限额 | limit | 高于它的赔付被截顶 |
| 广义贝塔第二类 | generalized beta type II (GB2) | 4 参数、覆盖很重的尾 |
| 再保层 | reinsurance layer | 只赔「超过自留额的部分」，观测极少 |

## 一、先看一个问题

面试官的原话是 "Which distribution would you pick for an insurance target?"，这句话背后在考什么：你会不会先看目标的形状，再决定用哪个分布。

具体一点。某车险一年里有 6 次车损赔案，金额是 **400、800、1,200、3,600、5,000、12,000** 元。你要拿这组数回答两类问题：

1. 定费率要用「平均每次赔多少」；
2. 定价单里最贵的那些档位（再保层、赔偿限额、风险附加）要看「赔得很大」的概率。

先把均值算出来：$\bar X=23{,}000/6=\mathbf{3{,}833.33}$ 元。这个数有三个问题：

- 它比中位数（$(1{,}200+3{,}600)/2=\mathbf{2{,}400}$ 元）高 **59.7%**：右偏把均值拽上去了，「平均赔付」和「典型赔付」不是同一个数；
- 它由最大的那笔决定：12,000 元那一笔占总额的 **52.2%**（$12{,}000/23{,}000$）。删掉它，均值掉到 **2,200** 元（$11{,}000/5$）——一次赔案就能把「平均」改写 42.6%；
- 它对「明年最大的一笔会是多少」几乎没有信息：那是分位数问题，均值回答不了。

再想模型。如果直接对赔付额跑 OLS（误差服从正态），这条线会给出**负的拟合值**和负的预测区间——赔付额不可能为负；而且正态的尾部衰减太快，会把大额赔案的概率算小。所以严重度建模的第一个决定就是：**用什么分布描述这条右偏长尾**。第四步会用一组显式参数把 Gamma 的均值、方差、分位数和尾部概率算出来，再和「均值、变异系数相同」的 lognormal 比同一段尾部。

## 📖 标准定义

> **教材原文 · LDA §3.2.1 Gamma、§3.2.2 Pareto、§3.2.3 Weibull（ChapSeverity.html）**（<https://openacttexts.github.io/Loss-Data-Analytics/ChapSeverity.html>）
> > "When frequency and severity are modeled separately it is common for actuaries to use the Poisson distribution (introduced in Section 2.2.3.2 ) for claim count and the gamma distribution to model severity."
> >
> > "The continuous variable $X$ is said to have the gamma distribution with shape parameter $\alpha$ and scale parameter $\theta$ if its probability density function is given by"
> >
> > "Since all moments exist for any positive $k$ , the gamma distribution is considered a light tailed distribution"
> >
> > "It is a positively skewed and heavy-tailed distribution which makes it suitable for modeling income, high-risk insurance claims and severity of large casualty losses."
> >
> > "… raw moment of the Pareto distributed random variable exists, if and only if, $\alpha > k$"
> >
> > "It can be easily seen that the shape parameter $\alpha$ describes the shape of the hazard function of the Weibull distribution. The hazard function is a decreasing function when $\alpha < 1$ (heavy tailed distribution), constant when $\alpha = 1$ and increasing when $\alpha > 1$ (light tailed distribution)."

**标准记法**：

- Gamma$\,(\alpha, \theta)$：$f_X(x) = \frac{(x/\theta)^{\alpha}}{x\,\Gamma(\alpha)}\exp(-x/\theta)$，$\mathrm{E}(X) = \alpha\theta$，$\mathrm{Var}(X) = \alpha\theta^2$（轻尾，所有矩存在）。
- Pareto$\,(\alpha, \theta)$（两参数，LDA 式 (3.1)）：$f_X(x) = \frac{\alpha\theta^{\alpha}}{(x+\theta)^{\alpha+1}}$，$\mathrm{E}(X) = \frac{\theta}{\alpha-1}$（$\alpha>1$），第 $k$ 阶矩存在的条件为 $\alpha > k$。
- Weibull$\,(\alpha, \theta)$：$f_X(x) = \frac{\alpha}{\theta}\big(\frac{x}{\theta}\big)^{\alpha-1}\exp\big(-(x/\theta)^{\alpha}\big)$，$\mathrm{E}(X) = \theta\,\Gamma(1 + 1/\alpha)$；危险率随 $\alpha<1$ 递减、$\alpha=1$ 恒定、$\alpha>1$ 递增。
- （公式即 LDA §3.2 原文。）

**中文解释**：严重度建模常用三者：Gamma（右偏、轻尾，所有矩存在，是「频率 Poisson + 严重度 Gamma」的经典搭配）、Pareto（重尾，$k$ 阶矩仅在 $\alpha>k$ 时存在，适合大额赔案/极端损失）、Weibull（形状参数控制危险率单调方向，可靠性/寿命数据常用）。选哪个，本质是选尾部：重尾选 Pareto 类，否则 Gamma/Weibull。

> 完整条目与更多来源见 [[定义原文库#F32. 严重度分布（Gamma / Pareto / Weibull）|F32. 严重度分布（Gamma / Pareto / Weibull）]]

## 二、核心直觉

### 三个词定性，直接排除正态

严重度是**正的、右偏的、重尾的**。这三个词各自对应正态的一条硬伤（面试必说的 4 条）：

1. **支撑集错**：赔付 $>0$，正态会给负的预测值。
2. **右偏 + 重尾**：正态尾部衰减太快，会低估大额赔付概率——而大额赔付正是保险最在乎的部分。
3. **方差随均值增长**：赔付的波动随平均水平放大（异方差是天然的），正态假设常数方差。
4. **MSE 被少数大额主导**：最小二乘下几个巨额赔案就能把系数拉走；GLM 的 deviance 与参数化尾部更稳。

### log link 在做的事：把乘法变成加法

严重度模型要的是「某车型的赔付水平是基准的 1.28 倍」这种乘性结论，但 GLM 的线性预测子只能加减。取对数就把两者接上了：

$$E[Y\mid x]=e^{x'\beta}\quad\Longleftrightarrow\quad \log E[Y\mid x]=x'\beta$$

两个副作用都是我们要的：$\mu$ 永远为正；系数相加 → 相对数相乘。

**像什么**：像一个「只调整倍数、不改变形状」的费率旋钮——Gamma 的变异系数恒为 $\sqrt\phi$，正是这个旋钮的数学版本：平均赔付从 2,000 涨到 20,000，相对波动不变。**不像什么**：真实数据里「更危险的那一组」尾部往往更重（CV 上升），$\alpha$ 不变只是 Gamma 的假设；这是后面要换 Pareto/GB2 的动机。

### 严重度模型要报两个数

均值用于定价，分位数用于风险决策。重尾下这两个数会差很远：第四步里 Gamma 的中位数比均值低 8.2%，而「赔超过 5 倍均值」的概率只有百万分之三——均值告诉你「收多少」，分位数告诉你「要留多少资本、再保层买多厚」。只报均值在面试里会被追问「那最大一笔呢」。

## 三、机制

### 3.1 定义与逐项说明：Gamma GLM（log link）

$$Y\sim\text{Gamma}(\mu,\phi),\qquad E[Y]=\mu,\qquad \operatorname{Var}(Y)=\phi\,\mu^2$$
$$\text{log link: } g(\mu)=\log\mu=x'\beta
\qquad\Longrightarrow\qquad \boxed{\ E[Y\mid x]=e^{x'\beta}\ }$$

逐符号读：$Y$ 是单次赔付金额（正的连续量）；$\mu=E[Y\mid x]$ 是给定费率因子下的平均单次赔付；$\phi$ 是离散参数（dispersion），方差与均值平方成正比；$x'\beta$ 是各因子在对数尺度上的线性组合；$e^{\beta_j}$ 是因子 $j$ 的乘性相对数（relativity），基准类别 = 1。

- **变异系数恒定**：$\text{CV}=\sqrt{\phi}$ 与 $\mu$ 无关——这是 Gamma 在保险里非常好用的性质（不管平均赔付多高，相对波动一样）。
- **canonical link 不是 log 而是 inverse（$1/\mu$）**；用 inverse link 时线性预测子可能给出负的拟合值，而且系数不是乘性解释，所以实务几乎都用 **log link**。
- $\phi$ 越大越离散；估计与检验里同样会遇到「dispersion 要不要固定」的问题（与 10.2 的过散布同源）。

### 3.2 它是怎么来的：从 $(\alpha,\theta)$ 到 GLM 的 $(\mu,\phi)$

LDA 的 Gamma 用形状、尺度两个参数 $(\alpha,\theta)$ 写，GLM 用均值、离散两个参数 $(\mu,\phi)$ 写，两者是同一个分布换了个坐标：

$$\mu=\alpha\theta,\qquad \operatorname{Var}(X)=\alpha\theta^2=\frac{(\alpha\theta)^2}{\alpha}=\frac{\mu^2}{\alpha}$$

**关键一步**：把方差写成「均值的函数」——令 $\phi=\dfrac{1}{\alpha}$，就得到 $\operatorname{Var}(X)=\phi\,\mu^2$，这正是 $V(\mu)=\mu^2$ 的方差函数（指数族里 Tweedie $p=2$ 的那一端）。同时 $\text{CV}=\dfrac{\sqrt{\alpha}\theta}{\alpha\theta}=\dfrac{1}{\sqrt{\alpha}}=\sqrt{\phi}$：**CV 只由形状参数决定**，尺度参数 $\theta$ 只平移水平。所以 Gamma GLM 估的 $\phi$ 就是「1/形状」，$\phi$ 越大分布越散。

lognormal 那条路则是换目标：对 $\log Y$ 建正态回归 $\log Y\sim N(x'\beta,\sigma^2)$，那么

$$E[Y\mid x]=e^{x'\beta+\sigma^2/2},\qquad \text{median}=e^{x'\beta}$$

**关键一步**：对数正态的均值不等于「中位数的指数」。$E[e^{Z}]=e^{\mu_Z+\sigma^2/2}$ 多出来的 $e^{\sigma^2/2}$ 是**均值回代因子**，漏掉它就会系统性低估平均赔付：

- 例：$\sigma^2=1.2$，$e^{0.6}=1.8221$ → 真实均值比「naive 回代」高 **82.2%**；反过来，naive 值低估均值 $1-1/1.8221=45.1\%$。
- 业务上要清楚：给「平均赔付」和给「中位赔付」是两个数，重尾下差很多。

### 3.3 变形与口径

**（1）Gamma 的参数化口径。** 同一个尺度参数在不同软件里含义不同：numpy / LDA 的 `scale` 是 $\theta$（$\mathrm{E}=\alpha\theta$），R 的 `rgamma` 默认用 `rate = 1/θ`，而 10.8 里复合 Poisson–Gamma 的重参数化用的是 rate 参数 $\gamma$（$\mathrm{E}[X]=\alpha/\gamma$）。换算只有一步：$\gamma=1/\theta$。把 rate 当 scale 用，均值会差 $\theta^2$ 倍。第四步会用同一个例子把两套参数都写出来。

**（2）lognormal 回代与拟合方式。**

$$ \log Y\sim N(x'\beta,\ \sigma^2)\qquad \Longrightarrow\qquad E[Y|x]=e^{x'\beta+\sigma^2/2},\ \text{median}=e^{x'\beta}$$

lognormal **不是指数族**（不能作为标准 GLM 直接拟合）：做法是对 $\log Y$ 做正态回归（即 OLS on log scale），再按上式回代。$\sigma^2$ 本身是估出来的，它的不确定性会直接放大到均值上（第四步条件检验三）。

**（3）Pareto（重尾的参数化）。** 单参数 Pareto 的生存函数（LDA §3.2.2；两参数/Lomax 等参数化不同，**需核对**）：

$$S(x)=\Pr(X>x)=\left(\frac{\theta}{x}\right)^{\alpha},\quad x>\theta,\ \alpha>0$$

- $E[X]$ 有限 $\iff \alpha>1$；$\operatorname{Var}(X)$ 有限 $\iff \alpha>2$。
- $\alpha\le2$ 时**方差不存在**：样本方差、标准误、CLT 全部不可靠，「用经验分布估平均赔付」就是错的——必须参数化尾部。
- 尾部厚度经验排序（**经验性排序，具体取决于参数与定义，需核对**）：Pareto ≳ lognormal > Gamma。

**（4）其它分布（LDA Ch3）。** Weibull（§3.2.3）、**GB2 / 广义贝塔第二类**（§3.2.4，4 个参数、覆盖很重的尾，常用于收入与损失分布），以及 inverse Gaussian。分布越灵活 → 尾部拟合越好，但**参数估计越不稳、越容易被少数大额点主导**。

**（5）Gamma vs lognormal 对比表（面试可直接背）。**

| 维度 | Gamma | lognormal |
|---|---|---|
| 是否指数族 | **是**（标准 GLM，IRLS 可拟合） | 否（对 $\log Y$ 做正态回归） |
| 尾部 | 指数式衰减（相对轻） | 比 Gamma 重（log 尺度的慢衰减） |
| 参数 | 均值 $\mu$ + 离散 $\phi$，$\text{CV}=\sqrt{\phi}$ | $\mu_{\log},\sigma^2$ |
| 常用 link | **log**（canonical 是 inverse） | log（在 log 尺度上直接建模） |
| 均值 | $e^{x'\beta}$ | $e^{x'\beta+\sigma^2/2}$ |
| 拟合方式 | MLE / IRLS | OLS on $\log Y$ / MLE |
| 典型用途 | 平均赔付、IBNR 平均成本 | 索赔额、再保层、收入/损失分布 |

## 💼 保险场景

**场景 A（车损险，示例数据）**
- 输入：车型/车价、车龄、驾驶人年龄、地区、是否全险
- 输出：$\hat E[X\mid x]$（平均单次赔付）
- 数值示例：
  - 基准类别 $\hat\beta_0=8.0064 \Rightarrow e^{8.0064}=\text{3{,}000}$ 元
  - 某 SUV 车型 $\hat\beta=0.25 \Rightarrow e^{0.25}=1.2840$
  - 该车型平均赔付 $=3{,}000\times1.2840=\text{3{,}852}$ 元
  - 这就是「乘性费率」在严重度侧的样子：**系数相加 → 相对数相乘**

**场景 B（家财险）**：小额高频（漏水、玻璃）+ 极少额巨额（火灾）。均值被巨额主导，所以做决策时要同时报**中位数**与**分位数**；给再保定价时必须用参数化尾部外推。

**场景 C（再保险 / 准备金）**：再保合约只赔付「超过自留额的部分」（例如 100 万以上的层），这意味着**观测数据恰好落在这个层里的样本极少**。经验分布在这层几乎没有信息，只能用参数化分布（Pareto/GB2）外推，并做敏感性分析。风险度量（VaR、TVaR）的设计正是为了让这种尾部风险可量化（LDA Ch10）。

**场景 D（一个容易漏掉的实务点）**：免赔额（deductible）与赔偿限额（limit）会让观测到的严重度**被截断/删失**（低于免赔额看不到，超过限额被截顶），直接对「观测赔付」建模会偏。LDA 关于覆盖率修改（免赔额/限额/共保）与截断-删失的处理有专节（具体节号需核对）。

## 🛠️ 代码

### SAS

```sas
/* 1) Gamma GLM + log link：严重度（每行 = 一次赔案） */
proc genmod data=claims_sev;
  class veh_type age_bnd region / param=ref;
  model loss_amt = veh_type age_bnd region
        / dist=gamma link=log;           /* log link 保证拟合值 > 0 */
  lsmeans veh_type / diff cl;            /* 取 exp 得到相对数 */
  output out=sev_pred pred=mu_hat resdev=devres;
run;
/* 输出怎么读：
   - "Criteria For Assessing Goodness Of Fit" 里 Scale 是 phi 的估计；deviance/df 若远大于 1，说明尾部/异质没吃干净
   - Parameter Estimates 取 exp() = 相对数
   - 用 deviance residual 画 QQ / 残差图看大额点是否主导 */

/* 2) lognormal：对 log(loss) 做正态回归 */
data sev2;
  set claims_sev;
  log_loss = log(loss_amt);
run;
proc glm data=sev2;
  class veh_type age_bnd;
  model log_loss = veh_type age_bnd / solution;
run;
/* 输出怎么读：
   - 参数是 log 尺度上的；取 exp 得到的是【中位数】倍数
   - 要得到均值必须乘 exp(MSE/2)（MSE = 残差均方 = sigma^2 的估计）
   - 别直接把 exp(estimate) 当平均赔付 */

/* 3) 更重的尾：SAS/ETS 的 PROC SEVERITY 专门拟合索赔额分布
      （支持 gamma / lognormal / Pareto / GB2 等，可用分布清单与选项以版本为准，需核对） */
```

### Python（statsmodels）

```python
import numpy as np, pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf

# 1) Gamma GLM + log link
m_g = smf.glm("loss_amt ~ C(veh_type) + C(age_bnd)",
              data=df_sev,
              family=sm.families.Gamma(link=sm.families.links.Log())).fit()
print(np.exp(m_g.params))                 # 相对数
print(m_g.scale)                          # phi 的估计 -> CV = sqrt(phi)

# 2) 分散程度诊断：deviance/df
print(m_g.deviance / m_g.df_resid)

# 3) lognormal：对 log(y) 做正态回归 + 均值回代
df_sev = df_sev.assign(log_loss=np.log(df_sev["loss_amt"]))
m_ln = smf.ols("log_loss ~ C(veh_type) + C(age_bnd)", data=df_sev).fit()
sigma2 = m_ln.mse_resid
pred_median = np.exp(m_ln.fittedvalues)
pred_mean   = np.exp(m_ln.fittedvalues) * np.exp(sigma2 / 2)   # 关键修正项
print("sigma^2 =", sigma2, " 修正倍数 =", np.exp(sigma2 / 2))

# 4) 尾部诊断：画 log-log 生存函数，或用 Hill estimator 粗估 Pareto 尾指数
#    注意：alpha <= 2 时样本方差没有意义（需核对所用估计量）
```

## 四、算一遍

### 设定

$X\sim\text{Gamma}(\text{shape }\alpha=4,\ \text{scale }\theta=500)$。两套写法都记一下：尺度参数 $\theta=500$，rate 参数 $\gamma=1/\theta=0.002$。下面所有数字都从 $(\alpha,\theta)=(4,500)$ 出发。

### 第 1 步：均值、方差、变异系数

$$E[X]=\alpha\theta=4\times500=\mathbf{2{,}000},\qquad \operatorname{Var}(X)=\alpha\theta^2=4\times250{,}000=\mathbf{1{,}000{,}000}$$
$$\text{SD}=\sqrt{1{,}000{,}000}=\mathbf{1{,}000},\qquad \text{CV}=\frac{1{,}000}{2{,}000}=\mathbf{0.5}=\frac{1}{\sqrt{4}}=\sqrt{\phi}\ \Rightarrow\ \phi=0.25$$

**怎么读**：CV 只由形状 $\alpha$ 决定；把 $\theta$ 从 500 改成 5,000，均值变成 20,000，CV 还是 0.5。核对 GLM 写法：$\phi\mu^2=0.25\times2{,}000^2=1{,}000{,}000$ ✓。

### 第 2 步：只看均值会漏掉什么（分位数与尾部）

对同一个 Gamma$(4,500)$：

| 量 | 数值 | 读法 |
|---|---|---|
| 中位数 | 1,836.03 | 比均值低 8.2%；**一半以上的赔案低于均值** |
| 90 分位 | 3,340.39 | 定价档位/免赔额设计看这个 |
| 95 分位 | 3,876.83 | 几乎等于「两个均值」 |
| 99 分位 | 5,022.56 | 均值 + 3 个标准差左右 |
| $P(X>2{,}000)$ | 43.35% | 高于均值的赔案占四成多 |
| $P(X>3\times\text{均值}=6{,}000)$ | 0.229% | 约每 437 次赔案一次 |
| $P(X>5\times\text{均值}=10{,}000)$ | $3.20\times10^{-6}$ | 约每 31 万次赔案一次 |

**注意最后两行**：3 倍均值的概率还有千分之二，到 5 倍均值就掉到百万分之三——**这是 Gamma 的「轻尾」在数字上的样子**。和 Pareto 比，这个衰减还是快的；所以「用哪个分布」最终取决于你要不要为 5 倍以上那段尾部负责。

### 第 3 步：条件方差展开——一年 $N$ 次赔付的总赔付

设这一年出险次数 $N\sim\text{Poisson}(\lambda=0.5)$，每次金额 $X\sim\text{Gamma}(4,500)$，两者独立。总赔付 $S=\sum_{k=1}^{N}X_k$，用**条件方差展开**（先固定 $N$，再对 $N$ 取期望）：

$$E[S]=E\bigl[E[S\mid N]\bigr]=E[N]\,E[X]=0.5\times2{,}000=\mathbf{1{,}000}$$

$$\operatorname{Var}(S)=\underbrace{E\bigl[\operatorname{Var}(S\mid N)\bigr]}_{\text{每次赔多少的波动}}+\underbrace{\operatorname{Var}\bigl(E[S\mid N]\bigr)}_{\text{出险几次的波动}}
=0.5\times1{,}000{,}000+0.5\times2{,}000^2$$

$$=\mathbf{500{,}000}+\mathbf{2{,}000{,}000}=\mathbf{2{,}500{,}000}\ \Longrightarrow\ \text{SD}=\mathbf{1{,}581.14},\ \text{CV}(S)=\mathbf{1.5811}$$

**两项的读法**：第二项（$\lambda(E[X])^2$）是第一项的四倍——**低频场景下，总赔付的不确定性主要来自「出几次」，而不是「每次赔多少」**。Poisson 下还有个捷径：$\operatorname{Var}(S)=\lambda E[X^2]$，本例 $0.5\times(1{,}000{,}000+4{,}000{,}000)=2{,}500{,}000$ ✓。

把 CV 写成闭式：$\text{CV}(S)^2=\dfrac{1+\text{CV}_X^2}{\lambda}=\dfrac{1+0.25}{0.5}=2.5$ ✓。这个式子马上会用来做条件检验。

### 第 4 步：与 Tweedie 参数交叉核对

$S$ 是复合 Poisson–Gamma，所以它也是 Tweedie（幂 $p=\dfrac{\alpha+2}{\alpha+1}=\dfrac{6}{5}=1.2$）。用 $E[S]=\mu=1{,}000$、$\operatorname{Var}(S)=\phi\mu^{p}$ 解出 $\phi$：

$$\phi=\frac{2{,}500{,}000}{1{,}000^{1.2}}=\mathbf{627.97}$$

再从 10.8 的换元式反推，应该回到设定值：

$$\lambda=\frac{\mu^{2-p}}{\phi(2-p)}=\frac{1{,}000^{0.8}}{627.97\times0.8}=\mathbf{0.5}\ \checkmark,\qquad
\frac{1}{\gamma}=\phi(p-1)\mu^{p-1}=627.97\times0.2\times1{,}000^{0.2}=\mathbf{500}\ \checkmark$$

第二行回到的是 $\theta=500$（注意 10.8 的复合公式用 rate 参数 $\gamma=1/500=0.002$）；再由 $\alpha=\dfrac{2-p}{p-1}=\dfrac{0.8}{0.2}=4$ ✓。**四个数从两个方向算都能对上**，说明手里的 Gamma 与 Tweedie 是同一个东西的两种参数化。

### 条件检验一：出险频率降十倍，纯保费的相对波动升到 5 倍

固定严重度 Gamma$(4,500)$，只改 $\lambda$：

| $\lambda$ | $E[S]$ | $\operatorname{Var}(S)=\lambda E[X^2]$ | $\text{CV}(S)=\sqrt{(1+0.25)/\lambda}$ | 隐含 Tweedie $\phi$（$p=1.2$） |
|---|---|---|---|---|
| 0.05 | 100 | 250,000 | **5.000** | 995.27 |
| 0.5 | 1,000 | 2,500,000 | 1.5811 | 627.97 |
| 2.0 | 4,000 | 10,000,000 | 0.7906 | 475.91 |

**结论**：严重度分布一个字都没改，只是出险频率从 0.5 降到 0.05，纯保费的 CV 就从 1.58 涨到 5.0。**低频险种（家财险、责任险）的费率天生更难估**——这就是为什么不能只看严重度的 CV，也是为什么低频数据必须靠参数化分布借力。

### 条件检验二：同均值、同 CV 的 lognormal，尾部差多少

给 lognormal 配同样的均值 2,000、CV 0.5：$\sigma^2=\ln(1+0.25)=0.2231$、$\sigma=0.4724$、$\mu_{\log}=\ln2{,}000-\sigma^2/2=7.4893$，中位数 $e^{7.4893}=1{,}788.85$（比 Gamma 的 1,836.03 还低一点）。

| 尾部事件 | Gamma$(4,500)$ | lognormal（同均值同 CV） | 倍数 |
|---|---|---|---|
| $P(X>3\times\text{均值}=6{,}000)$ | **0.229%** | 0.520% | 2.27× |
| $P(X>5\times\text{均值}=10{,}000)$ | **$3.20\times10^{-6}$** | $1.35\times10^{-4}$ | **42×** |

**结论**：两个分布在 90% 分位、均值、CV 上都能配平，差别只在远端。中段尾部（3 倍均值）差 2 倍多，再保层（5 倍均值）差 42 倍。**「选 Gamma 还是 lognormal」这个问题，在均值层面看不出来，必须在你要负责的那段尾部上比。**

### 条件检验三：均值回代因子的不稳定性

若真实 $\sigma^2=1.2$ 但样本估到 $1.0$ 或 $1.4$，均值修正因子 $e^{\sigma^2/2}$ 从 1.6487 变到 2.0138——**光 $\sigma^2$ 的估计误差就能让平均赔付差 22.1%**。中位数 $e^{x'\beta}$ 完全不受影响。这就是「重尾下均值比中位数难估」的量化版本，也是为什么 lognormal 的均值预测要连区间一起报。

## 五、什么情况下会失灵

### 承重假设

**假设一：观测赔付 = 真实损失（没有免赔额/限额的截断）。** 撤掉它的后果：低于免赔额的赔案看不到（截断），超过限额的被截顶（删失），严重度被系统性压低。若免赔额是 2,000 元，则所有观测值都 ≥2,000，样本均值不再接近损失均值；尾部被剪掉后，用 Gamma 拟合会低估再保层。处理：按截断/删失似然拟合，或只在两阶段流程里对严重度侧做修正。

**假设二：同一保单内的多次赔付独立同分布。** 撤掉它的后果：一次事故同时报车损和三者（相关赔付）会让条件方差展开漏掉协方差项，$\operatorname{Var}(S)$ 被低估。第四步的 $2{,}500{,}000$ 建立在独立同分布上；正相关时真实方差更大。

**假设三：尾部形状由所选分布族决定，且参数估得稳。** 撤掉它的后果：Pareto 的 $\alpha\le2$ 时方差不存在，样本方差、标准误、CLT 全不可靠；用 Gamma 外推 5 倍均值以上的层会低估（条件检验二：42 倍的差距）。处理：报数时同时给中位数与分位数，用 Pareto/GB2 做尾部敏感性分析。

**假设四：跨年赔付已做通胀调整。** 撤掉它的后果：系数被时间污染（赔付水平逐年上行），同一车型在不同年份被给出不同的相对数，费率表在通胀下失真。

**假设五：$\log Y$ 回归里的 $\sigma^2$ 稳定。** 撤掉它的后果：均值回代因子 $e^{\sigma^2/2}$ 的不确定性直接放大到均值（条件检验三：22.1%）；分组方差差异大时，全局一个 $\sigma^2$ 会给某些组系统性偏低的均值。

### 与其他方法的边界

| 场景 | 用谁 | 为什么不用别的 |
|---|---|---|
| 严格正值、尾部中等 | Gamma + log link | 指数族、CV 恒定、可直接 GLM 拟合 |
| 尾部更重、要报均值 | lognormal（记得回代） | Gamma 尾太轻；但回代因子引入额外不确定性 |
| 再保层 / 极端损失 | Pareto / GB2 + 敏感性分析 | Gamma/lognormal 在这段外推不足 |
| 有免赔额 / 限额 | 截断-删失似然 | 直接拟合观测赔付会偏 |
| 0 与正值混在一起 | Tweedie（[[10.8 Tweedie GLM 专章]]） | Gamma 装不下 0 |
| 只要出险次数 | Poisson + offset（[[10.2 计数模型与 offset]]） | 严重度模型不涉及暴露期 |
| 要拆频率与严重度因子 | 两阶段（[[10.1 频率-严重度与纯保费]]） | 单阶段系数拆不开 |

## 六、常见误解

### 误解一：「把赔付额取 log 再做 OLS，就等于 Gamma GLM」

**错误想法**：反正都是「在 log 尺度上建模」，`log(Y) ~ x` 的 OLS 和 Gamma GLM + log link 是一回事。

**为什么容易这么想**：两者的线性预测子长得一模一样（$\log\mu=x'\beta$），软件输出的系数符号也常常接近。

**错在哪一步**：两件事不同。①**误差结构不同**：log-OLS 假设 $\log Y$ 上有常数方差的加性误差，Gamma GLM 假设 $Y$ 的方差 $\phi\mu^2$、CV 恒定——回到原尺度后，log-OLS 的预测波动和 GLM 不一样。②**预测的刻度不同**：log-OLS 的回代 $e^{x'\beta}$ 是**中位数**，要乘 $e^{\sigma^2/2}$ 才是均值；Gamma GLM 的 $e^{x'\beta}$ 直接就是均值。③**拟合准则不同**：OLS 在 log 尺度上最小化平方误差，Gamma 的 MLE 用 Gamma 离差，重尾下对系数的拉扯也不同。所以「取 log」是接近了，但不等价——面试里说成等价，会被追问回代因子。

### 误解二：「GLM 的 link 应该用 canonical 的，所以 Gamma 该用 $1/\mu$」

**错误想法**：逻辑回归用 logit、Poisson 用 log，都是 canonical link；那 Gamma 的 canonical 是 inverse，就应该用 $1/\mu$。

**为什么容易这么想**：前两个模型的 canonical link 恰好也是行业标准，形成「canonical = 正确」的惯性。

**错在哪一步**：canonical link 的优点是数学上的（充分统计量、IRLS 收敛），不是业务上的。用 $1/\mu$ 时线性预测子的符号和大小不再有费率含义，而且 $\eta\to0$ 附近拟合值会炸；**乘性相对数只在 log link 下成立**（$e^{\beta_j}$ 才是倍数）。这也是为什么 SAS 的 `dist=gamma` 默认 link 的讨论里，实务一律写 `link=log`。

### 误解三：「只要均值报得对，严重度模型就够用了」

**错误想法**：反正定价用的是平均赔付，中位数、分位数是「描述统计」，不影响费率。

**为什么容易这么想**：定价公式里确实只有均值。

**错在哪一步**：均值只回答「收多少」，回答不了「要留多少资本、再保买多厚、限额定在哪」。同一条 Gamma$(4,500)$，均值 2,000 但 99 分位是 5,022.56（2.5 倍均值）；到了 5 倍均值，Gamma 给的概率是 $3.2\times10^{-6}$，换成同均值同 CV 的 lognormal 是 $1.35\times10^{-4}$，差 42 倍。**尾部差异不体现在均值上，但体现在赔穿概率和资本占用上**；报数时要成对给（均值 + 分位数），并且说明用的是哪个分布族。

### 误解四：「预测值出现负数，截断到 0 就行」

**错误想法**：正态回归跑出来的负预测值，把负的截成 0 就解决了。

**为什么容易这么想**：实现上一行 `np.maximum(pred, 0)` 就完事，看起来修补了「赔付不能为负」。

**错在哪一步**：截断只改了输出的支撑集，没改模型的三条错误假设——方差仍随均值增长（异方差）、尾部仍太薄（低估大额）、损失函数仍被少数大额点主导（MSE）。截断之后偏差还在，只是被藏起来了：真正要做的是换分布（Gamma/lognormal）和换损失（deviance），让模型本身把「正、右偏、重尾」装进去。

## 七、面试怎么答

### 30 秒版

> 严重度是单次赔付金额——**正的、右偏的、重尾的**，所以不能用正态：会给负的预测、低估大额赔案、还假设常数方差。我用 **Gamma GLM + log link**：$E[Y\mid x]=e^{x'\beta}$，方差 $\phi\mu^2$，CV 恒为 $\sqrt\phi$，系数取指数就是乘性相对数。尾部更重就换 **lognormal**（对 $\log Y$ 回归，均值回代要乘 $e^{\sigma^2/2}$）或 **Pareto/GB2**——Pareto 的 $\alpha\le2$ 时方差不存在，而再保层和准备金恰恰要看这段尾部，所以选择分布本质上是选择要为哪段尾部负责。

### 2 分钟版（要包含的四块）

1. **为什么不是正态**：支撑集（负预测）、尾部（低估大额）、方差结构（异方差）、损失函数（MSE 被巨额主导）。
2. **Gamma 机制**：$(\alpha,\theta)$ 换成 $(\mu,\phi)$，$\operatorname{Var}=\phi\mu^2$、CV $=\sqrt\phi$；log link 保证正、系数乘性；canonical 是 inverse，但实务用 log。
3. **一个数字**：Gamma$(4,500)$ 均值 2,000、方差 $1\times10^6$、CV 0.5；一年出险 $\lambda=0.5$ 时，总赔付 $E[S]=1{,}000$、$\operatorname{Var}(S)=2{,}500{,}000$（条件方差展开：50 万 + 200 万），对应 Tweedie $p=1.2$、$\phi=627.97$。
4. **尾部与口径**：3 倍均值概率 0.229%、5 倍均值 $3.2\times10^{-6}$；同均值同 CV 的 lognormal 在 5 倍均值处是 42 倍；lognormal 回代漏 $e^{\sigma^2/2}$ 会低估 45%；免赔额/限额会截断删失。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么不用正态？」 | 四条：负预测、尾太薄、异方差、MSE 被大额主导 |
| 「Gamma 和 lognormal 怎么选？」 | 尾部：中段差 2 倍多、5 倍均值处差 42 倍；lognormal 的均值要靠 $e^{\sigma^2/2}$ 回代且带额外不确定性 |
| 「Gamma 的 link 为什么不用 canonical？」 | canonical 是 $1/\mu$；log link 才有乘性相对数、保证 $\mu>0$，实务只讨论 log |
| 「CV 恒定是什么意思？」 | $\text{CV}=\sqrt\phi$ 与均值无关；换算过来 $\phi=1/\alpha$，只有形状影响相对波动 |
| 「免赔额/限额怎么办？」 | 观测被截断/删失；按截断-删失似然处理，或两阶段里单独修严重度侧 |
| 「重尾下均值还能用吗？」 | 要看尾指数：Pareto $\alpha\le2$ 时方差不存在，样本均值/标准误不可靠；报均值同时给分位数 |
| 「怎么和 Tweedie 对上？」 | $p=(\alpha+2)/(\alpha+1)$、$\operatorname{Var}=\phi\mu^p$；例子里 $p=1.2$、$\phi=627.97$，反推 $\lambda=0.5$、$\theta=500$ 都对得上 |

## 🗣️ 面试速答（30 秒）

> 严重度是单次赔付金额，**正的、右偏的、重尾的**，所以不能用正态：正态会给负的赔付预测，尾部衰减太快会低估大额赔案，还假设常数方差。我用 **Gamma GLM + log link**：$E[Y\mid x]=e^{x'\beta}$，方差 $\phi\mu^2$，变异系数恒为 $\sqrt{\phi}$，系数取指数就是乘性的相对数。如果尾部更重就用 **lognormal**（对 $\log Y$ 做正态回归，均值回代要乘 $e^{\sigma^2/2}$，否则会低估），再重就用 **Pareto / GB2**——Pareto 的尾指数 $\alpha\le2$ 时方差不存在，经验分布不可靠，而再保险层和准备金恰恰要看这个尾部。所以严重度模型的选择，本质是**用多少参数换多准的尾部**。

## ⚠️ 常见坑
- **lognormal 均值回代漏掉 $e^{\sigma^2/2}$**：这是最经典的错误，$\sigma^2=1.2$ 时低估 45%。
- **把 Gamma 的 canonical link 当成 log**：Gamma 的 canonical link 是 $1/\mu$（inverse），用 log 是实务选择，要说得清为什么。
- **拿 Gamma 外推极端尾**：Gamma 的尾比 lognormal/Pareto 轻，用它估再保层会低估；分位数场景优先 Pareto/GB2。
- **样本单位混乱**：一行 = 一次赔案 还是 一张保单？混用会让「严重度」和「纯保费」互相污染。
- **忽略免赔额/限额的截断-删失**：观测到的赔付不是完整的损失分布。
- **不做通胀调整（trend）**：跨年赔付要先化到同一价格水平，否则系数被时间污染。
- **只看均值不看分位数**：重尾下均值不稳定，报数时要同时给中位数与高分位数。
