# 10.2 计数模型与 offset
<!-- real-exam-questions -->
> [!question] 🎯 **真题问法**（[[MAGNet 面试真题全解]] §1）
> - "Which distribution would you pick for an insurance target?"
> 🔎 逐题导航：[[MAGNet 答案对照表]]

## 🎯 一句话
保单的暴露期不一样长（有的一整年、有的只保了三个月），**offset 就是把暴露期按已知常数写进模型的那一招**——它的系数被固定为 1，于是模型的输出自动变成「每单位暴露的期望次数」，也就是可以横向比较的费率基础。

---

## 📐 核心公式

### 1. Poisson GLM + offset（Loss Data Analytics §8.2.3）
第 $i$ 个投保人的**已知**暴露期记为 $m_i$，期望索赔次数记为 $\mu_i$，则
$$\mu_i=E(y_i\mid x_i)=m_i\cdot\lambda_i=m_i\cdot e^{x_i'\beta},
\qquad y_i\sim\text{Pois}(\mu_i)$$
取对数：
$$\boxed{\ \log\mu_i=\log m_i+x_i'\beta\ }$$

LDA §8.2.3 原文：

> "Adding $\log m_i$ … we can always specify this as an extra explanatory variable, as it is a **known constant**, and **fix its coefficient to 1**. In the literature the log of exposure, $\log m_i$, is commonly called the **offset**."

中文要点：
- $\log m_i$ 作为**额外解释变量**进入线性预测子，但**系数固定为 1**（不估计）。
- 为什么固定为 1：暴露期是**已知常数**，不是待估参数。若让它自由估计，就变成「用数据去学暴露的影响」，会与 $\lambda_i$（每单位暴露的强度）混淆，而且会破坏「暴露翻倍 → 期望次数翻倍」的物理含义。
- 输出的 $\hat\lambda_i=e^{x_i'\beta}$ 就是**单位暴露的期望频率**（如「次/车年」）。

### 2. 乘性费率与相对数（multiplicative tariff）
$$f_j=e^{\beta_j}\quad\text{（因子 }j\text{ 的相对数 relativity）},\qquad \text{基准类别相对数}=1$$

LDA 例中的一组系数与相对数（可用于核对「取指数」这一步）：

| 系数 $\beta$ | $e^{\beta}$（相对数） |
|---|---|
| $-2.3359$（截距 $\beta_0$） | $0.0967$ |
| $-0.3004$ | $0.7405$ |
| $-0.7837$ | $0.4567$ |
| $-1.0655$ | $0.3445$ |

> 注意 $\beta_0$ 取指数后不是「某个因子的相对数」，它对应基准类别的水平（$\hat\lambda_{\text{base}}=m\,e^{\beta_0}$）；费率表里的相对数一律以基准类别 $=1$ 为准。

### 3. 过散布（overdispersion）：Poisson 的最大问题
Poisson 只有一个参数，**均值恒等于方差**：$E[y]=\operatorname{Var}(y)=\mu$。真实索赔数据几乎总是 $\operatorname{Var}>\text{Mean}$（个体异质、聚集出险、遗漏变量）。LDA §8.2.3 的结论原话：

> "the Poisson distribution can be restrictive in the sense that it has a single parameter and its **mean and the variance are always equal**. There are other count regression models that allow more flexible distributional structure, such as **negative binomial regressions and zero-inflated (ZI) regressions**."

**诊断**：Pearson $\chi^2/df$ 或 deviance$/df$ 明显大于 1（经验上 $>1.5$ 就要当心——**经验值，各机构不一致**）。

| 处理方式 | 形式 | 效果 | 代价 |
|---|---|---|---|
| Quasi-Poisson | 点估计不变，标准误乘 $\sqrt{\hat\phi}$ | 修 p 值 | 不是似然模型，**AIC 不可比** |
| 负二项 NB2 | $\operatorname{Var}=\mu+\mu^2/\theta$（等价 $\mu(1+\mu/\theta)$） | 真正的似然模型，可 AIC 比较 | 多一个参数；$\theta\to\infty$ 退回 Poisson |
| 零膨胀 ZIP / ZINB | $P(0)=\pi+(1-\pi)e^{-\mu}$；$P(y)=(1-\pi)e^{-\mu}\mu^{y}/y!,\ y\ge1$ | 处理「结构零」 | 需要假设「两类人群」 |
| Hurdle | 两阶段：logit(是否 $>0$) + 对 $>0$ 部分做截断计数回归 | 零与非零机制分开 | 两套系数要分别解释 |

> **过散布 vs 零膨胀不是一回事**：过散布是「方差大于均值」（异质/聚集），零膨胀是「零比 Poisson 应有的还多」（结构性零：一类人从不索赔）。先做诊断（比较实际零的个数 vs Poisson 预测的 $e^{-\hat\mu}$ 之和），再决定用哪个。

另外 3 个常用的计数回归：**Poisson 回归、负二项回归、ZI 回归**（LDA §8.2.3 点名）；可补充 **hurdle / 截断 Poisson**、**quasi-likelihood**。

## 💼 保险场景

**场景 A（车险，示例数据）**：一张保单年暴露 $m_i$
- 输入：$m_i$（暴露，如 0.75 年）、车型、驾驶人年龄带、地区
- 输出：$\hat\lambda_i$（次/车年）→ 乘上严重度（10.3）得到纯保费
- 若 A 的相对数 $0.7405$、B 的相对数 $1$，则 A 的期望次数是 B 的 $0.74$ 倍；**这个「倍」与暴露期无关**，正因为 offset 把 $m$ 的影响固定住了。

**场景 B（真实的公开数据）**：新加坡车险索赔数据
- $n=7{,}483$ 份车险保单（Frees & Valdez 2008 的子集），来自 General Insurance Association of Singapore；
- LDA 中使用的 R 代码（可直接背下来对照 SAS 写法）：
```r
glm(Claims ~ VtypeF + AgebndF, data = mydat1,
    family = poisson(link = log), offset = log(Expsr))

glm(Clm_Count ~ SexF + TypeA:AgeCatF + VAgecat1F,
    offset = LNWEIGHT, poisson(link = log))     # 注意：LNWEIGHT 已经是 log 后的暴露
```
- 第二行两个细节：**暴露取对数后预先存成变量**（`LNWEIGHT`），并且模型里可以有**交互项**（`TypeA:AgeCatF`）。

**场景 C（零膨胀的真实动机）**：车险里「一年 0 次出险」的两类人——① 低风险、本来就很少出险；② 结构性的「零」：不开车/车停库/保单刚起保。用 ZIP 才能把 $\pi$ 单独估出来。

## 🛠️ 代码

### SAS

```sas
/* 关键：先把 log 暴露算成变量（SAS 不会自动取对数） */
data claims;
  set claims;
  ln_exposure = log(exposure);        /* exposure: 车年 / 保单年 */
run;

/* 1) Poisson + offset：offset 的系数被固定为 1 */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model clm_count = veh_type age_bnd
        / dist=poisson link=log offset=ln_exposure;
  lsmeans veh_type / diff cl;          /* 相对数：对差异取 exp */
run;
/* 输出怎么读：
   - "Criteria For Assessing Goodness Of Fit" 的 Pearson Chi-Square/DF 明显 >1 → 过散布
   - "Parameter Estimates" 的 Estimate 取 exp() 就是相对数
   - Type 3 Analysis 看每个因子整体是否显著 */

/* 2) 准 Poisson：系数不变，标准误被 scale 放大（选项名以所用版本文档为准，需核对） */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model clm_count = veh_type age_bnd
        / dist=poisson link=log offset=ln_exposure scale=pearson;
run;

/* 3) 负二项 NB2 */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model clm_count = veh_type age_bnd
        / dist=negbin link=log offset=ln_exposure;
  /* 输出里的 dispersion / k 与 "Var = mu + k*mu^2" 的参数化以 SAS 文档为准（需核对） */
run;

/* 4) 零膨胀模型（PROC COUNTREG 提供 zip / zinb；分布名各版本可能不同，需核对） */
proc countreg data=claims;
  model clm_count = veh_type age_bnd / dist=zip;    /* 零膨胀 Poisson */
  model clm_count = veh_type age_bnd / dist=zinb;   /* 零膨胀负二项 */
run;
```

### Python（statsmodels）

```python
import numpy as np, pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf

# 1) Poisson + offset：offset 就是 log(exposure)，系数固定为 1
m_pois = smf.glm("clm_count ~ C(veh_type) + C(age_bnd)",
                 data=df,
                 family=sm.families.Poisson(),
                 offset=np.log(df["exposure"])).fit()
print(m_pois.summary())
print(np.exp(m_pois.params))            # 相对数（multiplicative tariff）

# 2) 过散布诊断
print("Pearson/df =", m_pois.pearson_chi2 / m_pois.df_resid)
print("Deviance/df =", m_pois.deviance / m_pois.df_resid)

# 3) 准 Poisson：系数不变，标准误 x sqrt(phi)
phi = m_pois.pearson_chi2 / m_pois.df_resid
se_quasi = m_pois.bse * np.sqrt(phi)

# 4) 负二项 NB2（statsmodels 的参数化需按其文档核对）
m_nb = smf.negativebinomial("clm_count ~ C(veh_type) + C(age_bnd)",
                            data=df).fit()

# 5) 零膨胀 Poisson（statsmodels 的离散模型不自动加常数项；
#    新版本支持 from_formula，具体以版本为准，需核对）
x_cols = ["suv", "age_young", "region_high"]
X = sm.add_constant(df.loc[:, x_cols])
Z = sm.add_constant(df.loc[:, ["ln_exposure"]])   # 零膨胀部分的自变量
m_zip = sm.ZeroInflatedPoisson(df["clm_count"], X, exog_infl=Z).fit()

# 6) 零膨胀 vs Poisson 的诊断：实际零个数 vs Poisson 预测零个数
n_actual_zero = int((df["clm_count"] == 0).sum())
n_pred_zero   = float(np.exp(-m_pois.fittedvalues).sum())
print(n_actual_zero, n_pred_zero)       # 实际零远多于预测零 → 结构性零
```

## 🗣️ 面试速答（30 秒）

> 保单暴露期长短不同，所以我用 Poisson GLM 加 **offset**：$\log\mu_i=\log m_i+x_i'\beta$，其中 $\log m_i$ 是**已知常数**，**系数固定为 1**，不参与估计——这就是 LDA 说的 offset。固定为 1 是因为暴露翻倍、期望次数就该翻倍，让它自由估计会把「暴露的影响」和「单位暴露的强度」混在一起。这样 $\hat\lambda_i=e^{x_i'\beta}$ 就是每单位暴露的期望次数，$e^{\beta_j}$ 直接是费率相对数。Poisson 的问题是**均值恒等于方差**，真实索赔数据往往方差更大，我就看 Pearson $\chi^2/df$：大于 1 就改用 quasi-Poisson（系数不变、标准误放大）或负二项；如果零特别多，那是**结构性零**，要用零膨胀或 hurdle 模型。

---

## ⚠️ 常见坑
- **offset ≠ 权重（weight）**：offset 是「系数固定为 1 的解释变量」，weight 是「观测的重要性」。把 exposure 当普通变量丢进 `model` 会估出一个 $\ne1$ 的系数，相对数会被污染。
- **offset 必须已经是 log 值**：SAS/Python 都不会帮你取对数（R 里也是 `offset=log(Expsr)` 或预先算好的 `LNWEIGHT`）。忘了取对数 → 指数级错误。
- **过散布不修**：系数还能用，但**标准误被低估、p 值假显著**，因子显著性判断会错。
- **AIC 不能拿 quasi-Poisson 跟 Poisson 比**：quasi 不是似然模型。
- **零膨胀 vs 过散布混为一谈**：机制不同，处理不同，先做诊断。
- **暴露期与观测窗不对齐**：保单中途退保/起保，$m_i\in(0,1)$，别默认 $m_i=1$。
- **单位暴露的定义要写清**：是「每车年」还是「每保单年」，换单位后 $\beta_0$ 变、$\beta_j$ 不变（这正是 offset 的好处）。
