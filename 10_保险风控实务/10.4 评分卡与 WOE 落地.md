# 10.4 评分卡与 WOE 落地（Scorecard Scaling & WOE）

## 速览 At a glance

**速记**

评分卡把 logistic 回归的 $\log\text{-odds}$ 线性组合**换成一个整数分数**：`score = A − B·ln(odds)`，于是「分数每降 20 分，风险翻倍」这种话业务能直接听懂，模型也就能上线、能监控、能报备。两个常数由两个条件锁死：odds 每翻一倍分数变 PDO 分 ⇒ $B=\text{PDO}/\ln 2$；基准点（base_score 对应 base_odds）⇒ $A=\text{base\_score}-B\ln(\text{base\_odds}_{\text{good}})$。例：base 600、基准 50:1（good:bad）、PDO=20 ⇒ $B=28.85$、$A=487.12$，即 600 分对应 50:1，每多 20 分 good:bad 翻一倍、坏率大约减半。变量侧先做 WOE（库内口径 `ln(%Good/%Bad)`，正 WOE = 低风险），分箱合并到每箱 ≥5%、无零计数、顺序变量上单调；logistic 系数理想为 −1，实际拟合出来通常靠近 −1，符号必须与业务方向一致。落地三件事：把系数折成「基准分 + 各箱加减分」的整数表、切点与映射固化、阈值在未取整分数上定并用 PSI 监控。

**一句面试答法**

> "A scorecard is an affine transform of the log-odds: score equals A minus B times ln of the odds, where B is PDO over ln two, fixed by points-to-double-the-odds, and A is fixed by the base score and base odds — 600 at 50 to 1 with a PDO of 20 gives B of 28.85 and A of 487.12. Each variable is WOE-encoded first, so a bin's contribution is just minus B times beta times its WOE; add the base score and the bin points and you get an integer card the business can threshold and monitor."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 评分卡 | scorecard | 把 log-odds 线性映射成整数分的部署形态 |
| 刻度化 | scaling | 确定 A、B 两个常数，把 log-odds 换算成分数 |
| 翻倍分 | points to double the odds (PDO) | odds 每翻一倍分数变化的点数，决定分辨率 |
| 基准分 / 基准 odds | base score / base odds | 锚定 A 的一个已知点（如 600 分 ↔ 50:1） |
| 事件几率 | odds (bad:good) | $P(\text{Bad})/P(\text{Good})$；本页用它配 `A − B·ln(odds)` |
| 证据权重 | weight of evidence (WOE) | `ln(%Good/%Bad)`，正 = 低风险（库内口径） |
| 信息值 | information value (IV) | `Σ(%Good−%Bad)·WOE`，筛变量用 |
| 起评分 | base points | $A-B\beta_0$，摊在每个变量上的基准部分 |
| 群体稳定性指标 | population stability index (PSI) | 分数 / 分箱分布的漂移监控 |
| 未取整分数 | unrounded score | 定业务阈值要用它，避免取整后的边界抖动 |

## 一、先看一个问题

真题里的 "Explain Weight of Evidence coding." 只问了输入端，但 WOE 被大规模使用的地方是评分卡：模型跑完，你手里的是 log-odds，业务要的是能写进规则、能对外解释的整数分。

具体卡在哪：一个客户的线性预测子算出 $\eta=0.736$（log-odds 尺度）。你对业务说什么？「这个客户的 log-odds 是 0.736」——没人能拿它定阈值。换成「466 分，基准 600 分对应 50:1 的好坏比」——业务立刻能接话：「那 500 分以上算低风险吗」「他比另一个客户差多少」。而且「差多少」还能精确回答：分数每多 20 分，good:bad 翻一倍。

本页做两件事。先把 WOE 的口径钉死：与 [[2.3.1 WOE & IV]] 完全一致，连示例数据都用同一份 5,000 行车龄表，同一个符号约定。再给出刻度化公式的完整推导（PDO 定 B、基准点定 A），最后手算一张卡：从两个客户的 WOE 箱出发算出整数分，再从分数反解回 odds。

## 📖 标准定义

评分卡的刻度化没有 PSL / LDA 这类教材条目，它是信用评分（credit scoring）行业的通行约定；下面是通用记法与口径。

**标准记法（通用形式，非某本教材独有）**：

$$\text{score}=A-B\ln(\text{odds}),\qquad B=\frac{\text{PDO}}{\ln 2},\qquad A=\text{base\_score}\pm B\ln(\text{base\_odds})$$

- $\text{odds}$ 必须写明方向：事件 odds（bad:good）配 `A − B·ln(odds)`，风险越大分越低；good:bad 配 `A + B·ln(odds)`。两种写法只差 A 的移项，数值一致。
- $B=\text{PDO}/\ln 2$ 来自「odds 翻一倍 ⇒ 分数变 PDO 分」；$A$ 来自「base odds ⇒ base score」这两个条件。

**中文解释**：刻度化不改变模型的排序能力，它只是把 log-odds 线性映射到一个业务约定的整数刻度；A 定基准点，B 定「每翻一倍 odds 少多少分」。

**面试怎么用**：先报两个条件（PDO 与 base），再报 A、B，最后一定补一句 odds 的分子分母。

> 教材原文：**未取得该来源的原文**（评分卡刻度化是行业约定，本库权威来源 PSL / LDA / ISLR / ESL 未收录；符号与口径与 [[2.3.1 WOE & IV]] 一致）。

## 二、核心直觉

### 分数不是新信息，是一次线性换算

公式 `score = A − B·ln(odds)` 里，A 定「零点」，B 定「每格多大」。像摄氏度换华氏度：线性换算、零点不同、刻度不同，但「哪边更热」一分不变——所以分数不改变 AUC / Gini，改变的是可读、可传递、可设阈值。**边界**：仿射等价性是数学上的，**取整**和**截断**会真的动排序（原坑表最后两条），所以阈值必须在未取整分数上定。

### 为什么刻度要建在 log-odds 上，而不是概率上

因为 $\eta=\ln(\text{odds}_\text{bad})$ 已经是 logistic 的线性预测子：变量对 $\eta$ 的贡献是可加的（$\beta_j x_j$），换算成分数后每个变量、每个箱的加分依然可加，才能做出「基准分 + 一列加减分」的整数表。若换成概率 $p$，换算经过 sigmoid，两个变量同时变化时加分不再相加，评分卡就做不成表。

### WOE 在这一步里的角色

WOE 把每个变量压成一列 $\eta$ 的贡献，而且理想系数是 −1（[[2.3.1 WOE & IV]]）：WOE 越正（越低风险），$\eta$ 越小，分数越高。所以评分卡能写成「每个箱一个加减分」，加减分的来源是可以追溯到分箱与系数的。

## 三、机制

### 3.1 WOE 的口径与符号（与 [[2.3.1 WOE & IV]] 一致）

$$\text{WOE}_k=\ln\!\Big(\frac{\%\,\text{Good}_k}{\%\,\text{Bad}_k}\Big),\qquad
\%\,\text{Good}_k=\frac{\text{Good}_k}{\text{Good}_{\text{total}}}\ ,\quad \%\,\text{Bad}_k=\frac{\text{Bad}_k}{\text{Bad}_{\text{total}}}$$
- **Good = 非事件（没出险/没违约）、Bad = 事件（出险/违约）**
- **正 WOE = 低风险**（该箱里好人多），负 WOE = 高风险
- 方向千万不要搞反：这是库内统一口径，所有笔记一致
- 零计数用 **+0.5 平滑**（Laplace/Jeffreys），否则 $\ln(0)$ 爆炸

$$\text{IV}=\sum_k\big(\%\,\text{Good}_k-\%\,\text{Bad}_k\big)\cdot\text{WOE}_k$$

| IV 区间 | 常用解释（源于信用风险，已被广泛沿用；**经验值，各机构不一致**） |
|---|---|
| $<0.02$ | 无用 |
| $0.02$–$0.10$ | 弱 |
| $0.10$–$0.30$ | 中 |
| $0.30$–$0.50$ | 强 |
| $>0.50$ | 可疑 / 过拟合风险 |

**分箱工作流与单调性**：

**分箱工作流（5 步）**：fine classing（10–20 个等频箱）→ 合并（每箱 ≥5% 样本、无 0 计数、顺序变量上 WOE 尽量单调；缺失值单独一箱）→ 算 WOE → 用 WOE 变量做 logistic，检查符号与 VIF → 刻度化上线。

**单调性为什么重要**：
- 业务可解释：不会出现「车龄更老反而更便宜」
- 监管偏好：费率因子的方向要能自证合理（**一般性原则**）
- 上线稳定：单调约束减少小样本波动导致的分数跳变
- 实现手段：合并相邻箱；GBM 侧用单调约束（如 xgboost 的 `monotone_constraints` 一类机制）；SAS 侧人工调 `PROC HPBIN` 的切点

**WOE 与 logistic 的符号（容易搞反，面试常问）**

把每个变量换成 WOE 后：$\ \text{logit}\big(P(\text{Bad})\big)=\ln\dfrac{P(\text{Bad})}{P(\text{Good})}=\beta_0+\sum_j\beta_j\,\text{WOE}_j$。

- 朴素贝叶斯独立性假设下，**预测「Bad」的 log-odds 时理想系数是 $-1$**（WOE 越大 → 越安全 → Bad 的 log-odds 越小）；若预测的是「Good」的 log-odds，则理想系数是 $+1$。
- ⚠️ 与 [[2.3.1 WOE & IV]] 的口径对齐：该页同样用「正 WOE = 低风险」，预测 Bad 的 log-odds 时理想系数也是 −1，不是 +1。真题来源 [[MAGNet 面试真题全解]] §2 用的是相反定义 `ln(%Events/%NonEvents)`（正 WOE = 高风险），同一份数据下它的 WOE 与系数全部变号（≈ +1）。面试先说清「你预测的是哪一类、用的是哪种定义」，别被绕进去。
- 实务上拟合出来通常是负系数、绝对值接近 1；**符号必须与业务方向一致，否则整箱重做**。

### 3.2 刻度化：逐步推导

$$\boxed{\ \text{score}=A-B\cdot\ln(\text{odds})\ },\qquad
B=\frac{\text{PDO}}{\ln 2},\qquad
A=\text{base\_score}+B\cdot\ln(\text{base\_odds})$$
- $\text{odds}$ 必须明确是 **事件(bad):good** 还是 **good:bad**。本节用**事件 odds**（$\text{odds}_{\text{bad}}=P(\text{Bad})/P(\text{Good})$），所以风险越大分越低，符号自洽。
- **PDO = Points to Double the Odds**：odds 每翻一倍，分数变化 PDO 分（所以 $B=\text{PDO}/\ln2$）。
- 等价写法：$\text{score}=A'+B\cdot\ln(\text{odds}_{\text{good}})$，$A'=\text{base\_score}-B\ln(\text{base\_odds}_{\text{good}})$。**两种写法只要 A 跟着调，最终分数完全一致**——别在符号上纠结，要在纸面上验算。

**推导链**（四个待定的事，一步步锁死）：

**第 1 步：为什么是「A 减 B·ln(odds)」。** 本页用事件 odds（$\text{odds}_\text{bad}=P(\text{Bad})/P(\text{Good})$）：风险越大，$\ln(\text{odds}_\text{bad})$ 越大；分数要「越大越安全」，所以系数取负。若改用 good:bad 的 odds，写成 `A + B·ln(odds_good)` 更顺手，两种写法通过 A 的移项完全等价。

**第 2 步：PDO 定 B（关键一步）。** PDO 的定义是「odds 翻一倍，分数变化 PDO 分」。在本页口径下风险翻倍意味着扣分，所以：

$$A-B\ln(2\cdot\text{odds})=A-B\ln(\text{odds})-\text{PDO}\ \Longrightarrow\ -B\ln 2=-\text{PDO}\ \Longrightarrow\ \boxed{B=\frac{\text{PDO}}{\ln 2}}$$

这一步只剩 B 和 PDO 两个量：**PDO 是业务要的分辨率，B 不是自由参数**。

**第 3 步：基准点定 A。** 指定「odds 等于 base odds 时分数等于 base score」：

$$A-B\ln(\text{base\_odds}_\text{bad})=\text{base\_score}\ \Longrightarrow\ A=\text{base\_score}+B\ln(\text{base\_odds}_\text{bad})$$

若 base odds 给的是 good:bad（50:1 这种写法），则 $\ln(\text{odds}_\text{bad})=-\ln(\text{odds}_\text{good})$，于是 $A=\text{base\_score}-B\ln(\text{base\_odds}_\text{good})$。

**第 4 步：两个条件都要回代验证。** 把 A、B 代回去，检查 base 点得分是 base_score、翻倍点是 base_score−PDO。下面这组数字就是这么来的。

#### 完整数值示例（背下来就能现场推）
设 $\text{base\_score}=600$、$\text{base\_odds}=50{:}1$（**good:bad**，即基准坏率 $1/51=1.96\%$）、$\text{PDO}=20$：

$$B=\frac{20}{\ln 2}=\frac{20}{0.6931472}=28.8539$$
$$A=600-B\cdot\ln(50)=600-28.8539\times3.9120230=600-112.8771=487.1229$$
$$\Rightarrow\ \text{score}=487.12+28.85\cdot\ln(\text{odds}_{\text{good}})=487.12-28.85\cdot\ln(\text{odds}_{\text{bad}})$$

**验算（必须一致）**：

| $\text{odds}_{\text{good}}$ | good:bad | score $=487.12+28.85\ln(\text{odds})$ | 对应 bad 率 $=1/(1+\text{odds})$ |
|---|---|---|---|
| $12.5$ | 12.5:1 | $487.12+28.85\times2.5257=560.0$ | $7.41\%$ |
| $25$ | 25:1 | $487.12+28.85\times3.2189=580.0$ | $3.85\%$ |
| $50$ | 50:1 | $487.12+28.85\times3.9120=600.0$ | $1.96\%$ |
| $100$ | 100:1 | $487.12+28.85\times4.6052=620.0$ | $0.99\%$ |
| $200$ | 200:1 | $487.12+28.85\times5.2983=640.0$ | $0.50\%$ |

- 每 **+20 分**（一个 PDO）⇒ good:bad 翻倍 ⇒ bad 率大约减半。这就是「PDO 的业务含义」。
- 反向换算（把分数还原成 odds）：$\ \text{odds}_{\text{good}}=\exp\big((\text{score}-A)/B\big)$。验算：$(600-487.1229)/28.8539=3.91202=\ln 50$ ✓

### 3.3 把系数折成分值

#### 把一个 $\beta$ 换算成分数
因为 $\text{score}=A-B\big(\beta_0+\sum_j\beta_jx_j\big)$，所以：
- **第 $j$ 个变量每 $+1$ 单位 ⇒ 分数变化 $-B\beta_j$**
- **WOE 版：某箱的加分/扣分 $=-B\,\beta_j\,\text{WOE}_k$**

| 情形 | 计算 | 结果 |
|---|---|---|
| 原始变量系数 $\beta=0.62$（越高越危险），每 $+1$ 单位 | $-28.8539\times0.62$ | **$-17.9$ 分** |
| WOE 变量系数 $\beta_{\text{woe}}=-0.95$，某箱 $\text{WOE}=-0.99$（高风险箱） | $-28.8539\times(-0.95)\times(-0.99)$ | **$-27.1$ 分**（扣分） |
| 同上，某箱 $\text{WOE}=+0.50$（低风险箱） | $-28.8539\times(-0.95)\times(+0.50)$ | **$+13.7$ 分**（加分） |
| 最差箱 vs 最好箱的差距 | $-B\beta\,\Delta\text{WOE}=-28.8539\times(-0.95)\times(-1.49)$ | **$-40.8$ 分** |

> 表里的 $\beta=0.62$、$\beta_{\text{woe}}=-0.95$ 是**示例系数**，用于演示换算；实际用 ODS 输出的估计值替换。
> 常见做法：$A-B\beta_0$ 这部分叫**基准分**，可以按变量数平均分配成每个变量的「基础分」，再叠加各箱的 WOE 分值，得到一张全整数、可直接上线的分数表。

## 💼 保险场景

**某车险公司续保流失（示例）**：目标 $y=1$ 表示「保单到期未续保」。
- 变量：上年是否出险、缴费方式、保费变动幅度、投保年限、代理人渠道、是否有多次小额赔付
- 分箱 → WOE → logistic → 刻度化成 300–850 分
- 落地用法：
  - **续保运营**：分 <580 的保单进「高流失风险」名单，做定向挽留（成本敏感阈值，见 [[1.5 Dealing with Unbalanced Samples]]）
  - **定价/核保辅助**：分数作为风险分级的一档输入
  - **监控**：每月看分数分布与 PSI（见 [[10.5 模型评估与监控]]）
- 为什么不用原始概率：概率是 0.037 这种小数，业务看不懂也不方便在系统间传递；分数是整数、方向明确、阈值可调，还能直接对外解释成「相对风险档位」。

## 🛠️ 代码

### SAS

```sas
/* 1) 等频分箱（先做 20 个细箱） */
proc rank data=card groups=20 out=card_fine;
  var veh_age;
  ranks fine_bin;                      /* rank 默认升序，1 = 最小值 */
run;

/* 2) 每箱 Good/Bad 计数（sparse 保证零计数的组合也出现，方便加 0.5 平滑） */
proc freq data=card_fine noprint;
  tables fine_bin * y / sparse out=cell_counts(drop=percent);
run;

/* 3) WOE / IV：PROC SQL 一次算完（log() 在 SAS 里就是自然对数） */
proc sql;
  create table totals as
    select sum(y=0) as tot_good, sum(y=1) as tot_bad
    from card_fine;

  create table woe as
    select c.fine_bin,
           sum(c.count*(c.y=0)) as n_good,
           sum(c.count*(c.y=1)) as n_bad,
           log( ((sum(c.count*(c.y=0))+0.5)/(t.tot_good+1))
              / ((sum(c.count*(c.y=1))+0.5)/(t.tot_bad +1)) ) as woe,
           calculated woe * ( ((sum(c.count*(c.y=0))+0.5)/(t.tot_good+1))
                            - ((sum(c.count*(c.y=1))+0.5)/(t.tot_bad +1)) ) as iv_contrib
    from cell_counts as c, totals as t
    group by c.fine_bin;
quit;
/* 输出怎么读：woe 列要按 fine_bin 升序看是否单调；iv_contrib 求和就是变量 IV */

/* 4) 用 WOE 变量建 logistic */
proc logistic data=card_woe;
  model y(event='1') = woe_veh_age woe_age_drv woe_prior_clm
        / selection=stepwise slentry=0.05 slstay=0.05
          rsquare lackfit ctable pprob=0.5;
  output out=pred p=phat;
  roc;
run;
/* 输出怎么读：
   - Parameter Estimates：Estimate 就是 beta（WOE 变量上通常为负），检查符号方向
   - ctable + pprob=0.5：看混淆矩阵；roc / plots=roc 看 AUC
   - lackfit：Hosmer-Lemeshow，整体拟合，对大样本与分箱方式敏感，仅作参考 */

/* 5) 刻度化：B = PDO/ln2，A = base_score - B*ln(base_odds_good:bad) */
data scorecard;
  set parms;                 /* ODS 输出的 parameterestimates */
  B = 20 / log(2);           /* PDO = 20 */
  A = 600 - B*log(50);       /* base_score=600, base_odds=50:1 (good:bad) */
  points_per_unit = -B * estimate;
run;
/* 输出怎么读：intercept 那行对应基准分的一部分；每个系数乘 -B 就是「每 +1 单位的分值」 */

/* 6) 离线打分：score = A - B*(b0 + sum(bj*xj)) */
data scored;
  set card_woe;
  B = 20/log(2);
  A = 600 - B*log(50);
  eta = -1.2034                       /* 示例：换成实际截距 */
      + (-0.9461)*woe_veh_age         /* 示例系数 */
      + (-1.0217)*woe_age_drv;
  score = A - B*eta;
  round_score = round(score, 1);
run;

/* 7) 批量上线：PROC SCORE（系数数据集结构、截距处理以 SAS 文档为准，需核对） */
proc score data=newapps score=scorecard_out out=scored type=parms;
  var woe_veh_age woe_age_drv;
run;
```

### Python

```python
import numpy as np, pandas as pd
import statsmodels.formula.api as smf

# 1) 分箱 + WOE / IV
def woe_table(df, col, y="y", bins=10):
    df = df.copy()
    df["_bin"] = pd.qcut(df[col], q=bins, duplicates="drop")
    g = df.groupby("_bin", observed=True)[y].agg(n="count", bad="sum")
    g["good"] = g["n"] - g["bad"]
    g["pct_good"] = g["good"] / g["good"].sum()
    g["pct_bad"]  = g["bad"]  / g["bad"].sum()
    g["woe"] = np.log((g["pct_good"] + 1e-6) / (g["pct_bad"] + 1e-6))  # 0.5 平滑的近似
    g["iv"]  = (g["pct_good"] - g["pct_bad"]) * g["woe"]
    return g, g["iv"].sum()

# 2) WOE 映射回样本（注意 missing / 越界单独一箱）
def apply_woe(df, col, table):
    m = dict(zip(table.index, table["woe"]))
    return pd.qcut(df[col], q=len(table), duplicates="drop").map(m).astype(float)

df["woe_veh_age"] = apply_woe(df, "veh_age", t_veh)

# 3) logistic（WOE 变量）
m = smf.logit("y ~ woe_veh_age + woe_age_drv", data=df).fit()
print(np.exp(m.params))                  # 检查符号方向

# 4) 刻度化
base_score, base_odds_good, PDO = 600, 50.0, 20
B = PDO / np.log(2)                      # 28.8539
A = base_score - B*np.log(base_odds_good)   # 487.1229
print(B, A)

# 5) 每个变量每 +1 单位的分值 / 每个 WOE 箱的分值
points_per_unit = -B * m.params.drop("Intercept")
print(points_per_unit)

# 6) 打分 + 反解 odds
eta = m.params["Intercept"] + m.params["woe_veh_age"]*df["woe_veh_age"] \
      + m.params["woe_age_drv"]*df["woe_age_drv"]
score = A - B*eta
odds_good = np.exp((score - A) / B)       # 反解：score -> odds
print(score.head(), odds_good.head())
```

**代码里的数字与本页公式一一对应**：`B = 20/log(2)` 是 PDO 那条，`A = 600 - B*log(50)` 是基准点那条；`points_per_unit = -B * estimate` 就是「每 +1 单位 = −Bβ 分」；最后 `odds_good = np.exp((score - A) / B)` 是反解公式。

## 四、算一遍

数据、分箱与 WOE 数值全部沿用 [[2.3.1 WOE & IV]] 的算例（同一份 5,000 行车险数据），这里只做评分卡需要的增量：合并、刻度化、手算一张卡、反解 odds。

### 第 0 步：先用同一份数据把 WOE 摆出来

| 车龄 | Good | Bad | %Good | %Bad | WOE | IV 贡献 |
|---|---|---|---|---|---|---|
| 0–2 年 | 400 | 100 | 0.10 | 0.10 | $0.000$ | 0.000 |
| 3–5 年 | 1,600 | 200 | 0.40 | 0.20 | $+0.693$ | 0.139 |
| 6–7 年 | 700 | 120 | 0.175 | 0.12 | $+0.377$ | 0.021 |
| 8–9 年 | 700 | 180 | 0.175 | 0.18 | $-0.028$ | 0.000 |
| 10+ 年 | 600 | 400 | 0.15 | 0.40 | $-0.981$ | 0.245 |
| **合计** | **4,000** | **1,000** | 1.00 | 1.00 | — | **IV $\approx0.405$（强）** |

WOE 序列 $0,\ +0.6931,\ +0.3773,\ -0.0282,\ -0.9808$ **不单调**（先升后降）。按「合并相邻箱」修：把 0–2 与 3–5 并成 0–5（WOE $+0.5108$、IV 合计 0.3683），序列变成单调递减；再按业务常用切法把 6–7 与 8–9 并回 6–9：

| 车龄（粗分箱） | Good | Bad | %Good | %Bad | WOE | IV 贡献 |
|---|---|---|---|---|---|---|
| 0–5 年 | 2,000 | 300 | 0.50 | 0.30 | $+0.511$ | 0.102 |
| 6–9 年 | 1,400 | 300 | 0.35 | 0.30 | $+0.154$ | 0.008 |
| 10+ 年 | 600 | 400 | 0.15 | 0.40 | $-0.981$ | 0.245 |
| **合计** | **4,000** | **1,000** | 1.00 | 1.00 | — | **IV $\approx0.355$** |

- WOE 单调递减 = 车龄越大风险越高，符合业务；IV 从 0.4047（5 箱）经 0.3683（4 箱）到 **0.3551（3 箱）**，**用一点判别力换可解释性和稳定性，是划算的**。
- 注意损失不是白给的：这张表就是上线用的粗分箱与 WOE 映射，切点从此固化（新数据只套用，不重新分箱）。

### 第 1 步：从拟合出的系数到每个箱的分值

如果卡上只有车龄这一个 WOE 变量，系数是**精确**的（[[2.3.1 WOE & IV]] 已验算）：$\hat\beta_0=\ln(1000/4000)=-1.3863$、$\hat\beta_\text{车龄}=-1.0000$。真实卡上有多个变量，条件独立只是近似，系数会偏离 −1；下面用三个示例系数演示换算（实际值从 ODS 输出的 Parameter Estimates 取）：

$$\beta_0=-1.2034,\qquad \beta_\text{车龄}=-0.9461,\qquad \beta_\text{驾龄}=-1.0217$$

- **基准分**：$A-B\beta_0=487.1229-28.8539\times(-1.2034)=521.8457\approx521.85$。
- **某个箱的分值**：$-B\,\beta_j\,\text{WOE}_k$。车龄 10+ 箱（WOE $=-0.9808$）：$-28.8539\times(-0.9461)\times(-0.9808)=-26.78$ 分；车龄 0–5 箱（WOE $=+0.5108$）：$+13.94$ 分。

### 第 2 步：手算两名客户的分数

驾驶人年龄带的两个 WOE 沿用 [[2.3.1 WOE & IV]] 的 Age 例（18–25 → $-0.99$；36–50 → $+0.50$），换算成箱分值：

| 变量箱 | WOE | 箱分值 $=-B\beta\,\text{WOE}$ |
|---|---|---|
| 车龄 10+ 年 | $-0.9808$ | $-28.8539\times(-0.9461)\times(-0.9808)=\mathbf{-26.78}$ |
| 车龄 0–5 年 | $+0.5108$ | $-28.8539\times(-0.9461)\times(+0.5108)=\mathbf{+13.94}$ |
| 驾驶人 18–25 | $-0.99$ | $-28.8539\times(-1.0217)\times(-0.99)=\mathbf{-29.19}$ |
| 驾驶人 36–50 | $+0.50$ | $-28.8539\times(-1.0217)\times(+0.50)=\mathbf{+14.74}$ |

| 客户 | 车龄箱 | 驾龄箱 | 基准分 | 车龄分值 | 驾龄分值 | 未取整总分 | 取整 |
|---|---|---|---|---|---|---|---|
| 甲（高风险） | 10+ 年 | 18–25 | 521.85 | $-26.78$ | $-29.19$ | $\mathbf{465.89}$ | **466** |
| 乙（低风险） | 0–5 年 | 36–50 | 521.85 | $+13.94$ | $+14.74$ | $\mathbf{550.53}$ | **551** |

两名客户相差 $550.53-465.89=84.65$ 分。84.65 分是几个 PDO？$84.65/20=4.23$ 个，所以 good:bad 相差 $2^{4.23}\approx18.8$ 倍——这个倍数马上要在反解里对上。

### 第 3 步：某客户出分数后反解 odds

拿客户甲：得分 465.89（取整 466）。用反向公式：

$$\text{odds}_\text{good}=\exp\!\Big(\frac{\text{score}-A}{B}\Big)=\exp\!\Big(\frac{465.89-487.1229}{28.8539}\Big)=\exp(-0.7360)=0.4790$$

即好 : 坏 $\approx0.479{:}1$，换成更常用的说法：坏 : 好 $\approx1{:}2.09$，**坏率 $\approx2.09/(1+2.09)=67.6\%$**（这是示例系数下的读数，不是概率模型直接输出）。

用客户乙核对倍数：$\text{odds}_\text{good}=\exp\!\big((550.53-487.1229)/28.8539\big)=\exp(2.1975)=9.0029$；$9.0029/0.4790=18.79\approx2^{4.23}$ ✓，与 PDO 的读法一致。

### 条件检验一：PDO 就是分辨率

把 PDO 改成 10（base 600、base odds 50:1 不变）：$B=10/\ln2=14.4270$、$A=600-B\ln50=543.5614$。同样两名客户：

$$\text{甲}=543.5614-14.4270\times0.7360=532.94,\qquad \text{乙}=543.5614+14.4270\times2.1975=575.27$$

分差 42.32 分，正好是原来的**一半**。PDO 小不是「更准」，它只是把同样的风险差异压缩成更小的读数——所有阈值、分档、名单都要跟着重定。

### 条件检验二：取整与阈值

客户甲未取整 465.89、取整 466；用 466 反解 $\text{odds}_\text{good}=\exp((466-487.1229)/28.8539)=0.4809$，与未取整的 0.4790 差 **+0.4%**。数值上无所谓，但如果业务阈值正好卡在 466，边界客户会因为取整换边。所以：**先用未取整分数定阈值，再取整发布**。

## 五、什么情况下会失灵

### 承重假设

**假设一：模型输出的 log-odds 就是公式里的 $\ln(\text{odds}_\text{bad})$，方向配套。** 撤掉它（把 good:bad 的 base odds 直接塞进 bad-odds 公式）：A 从 487.12 变成 712.88，同一个客户甲从 465.89 分变成 691.64 分——差的不是小数，225.75 分（正好是 $2B\ln 50$）的整段错位，所有阈值失效。修法：公式和 base odds 一律标注分子分母。

**假设二：base score 与 PDO 上线后固定。** 撤掉它（中途改基准或改分辨率）：旧阈值、旧报表、旧拒绝原因码全部失效。条件检验一给了幅度：PDO 从 20 改到 10，同样两名客户的分差从 84.65 压到 42.32，风险差异被压进同一档。

**假设三：WOE 切点与映射固化。** 撤掉它（新数据上重新分箱）：同一个客户换箱，分数按 $-B\beta\,\Delta\text{WOE}$ 跳变。相邻粗箱的 WOE 差是 0.3567（0–5 vs 6–9）与 1.1350（6–9 vs 10+），按示例 $\beta_\text{车龄}=-0.9461$ 折算，切点移动一下边界客户就跳约 **9.7 分**或 **31.0 分**——一个档位的差别。

**假设四：系数符号与业务方向一致。** 撤掉它（拟合出正系数或远离 −1）：要么分箱方向反了，要么 WOE 定义方向与模型不配套，要么存在泄漏或共线。评分卡相对 GBM 的主要卖点就是可解释（费率报备、因子归因），符号讲不通的卡不能上线，要整箱重做。

**假设五：缺失值与边界值有唯一归属箱。** 撤掉它：线上用 fallback 箱、线下用缺失箱，两边分数对不上；边界值（$x=$ 切点）归左还是归右也要写死。

### 上线前的检查清单（原「⚠️ 常见坑」）

- **WOE 方向搞反**：库内口径是「正 WOE = 低风险」。反了会让所有系数符号看起来都「不对」。
- **odds 是 good:bad 还是 bad:good 没写清**：公式里必须注明，否则 A 的符号会错；两种写法数值一致，但**不能混用**。
- **WOE 与 logit 的理想系数 ±1 弄混**：预测 Bad 的 log-odds 时理想系数是 $-1$。
- **不检查单调性就上线**：非单调箱会让费率表出现「更安全更贵」。
- **IV > 0.5 直接采信**：很可能是泄漏、时间穿越或小样本，必须 OOT 复核（见 [[10.5 模型评估与监控]]）。
- **分箱在训练集上定好却在新数据上重新分**：切点必须固化，否则线上分数漂移。
- **分数取整后做业务阈值**：先用未取整的分数定阈值，再取整，避免边界抖动。
- **线上线下分数不一致**：八成是缺失值箱、边界值（$x=$ 切点）或变量单位没对齐。

## 六、常见误解

### 误解一：「分数每降 20 分，风险翻倍」

**错误想法**：PDO 是分数的分辨率，所以「每 20 分风险翻倍」这句话怎么说都不会错。

**为什么容易这么想**：原始说法听起来已经很明确——分数降，风险升，方向天然。

**错在哪一步**：方向对，但它依赖 **odds 的分子分母写清**。本页用事件 odds（bad:good）：分数每降 20 分 ⇒ bad:good 翻倍 ⇒ 风险翻倍。若公式与阈值标的是 good:bad，同一句话必须改成「分数每降 20 分 ⇒ good:bad 减半」；报告、接口、阈值表只要有一处省掉分子分母，就会出现「分数变低但风险也被说成变低」的错。写公式时把 odds 的下标带上，这一条永远不会错。

### 误解二：「分数就是概率的另一种写法」

**错误想法**：600 分的客户，风险大概就是某个概率值。

**为什么容易这么想**：模型确实输出概率，评分卡只是换了单位，容易觉得两者一一对应。

**错在哪一步**：分数是 log-odds 的**仿射**变换，回到概率要两步：$\text{odds}_\text{good}=\exp((\text{score}-A)/B)$，再 $p_\text{bad}=1/(1+\text{odds}_\text{good})$。而且这两步依赖 A、B 两个约定——换 base、换 PDO，同一个概率就对应另一个分数。分数适合跨系统传递和设阈值，但别把它当概率念出来。

### 误解三：「IV 高的变量一定进卡」

**错误想法**：IV>0.3 是强变量，直接入选最保险。

**为什么容易这么想**：IV 的阈值表看起来就是在给变量排座次。

**错在哪一步**：IV 是训练集上的**样本统计量**：分箱细、样本小都会虚高（[[2.3.1 WOE & IV]] 条件检验一：一个零计数箱平滑后单箱 IV 0.53，比整份数据的有效 IV 还大），在训练集上按 IV 挑变量还有选择偏差（赢家诅咒）。遇到 IV>0.5 先查泄漏、时间穿越、小箱，用 OOT 复核；入选与否还要看符号、单调性、以及与已有变量的相关性（VIF）。

### 误解四：「系数正负无所谓，分数能排序就行」

**错误想法**：反正 AUC 一样，WOE 系数是正是负不影响模型好坏。

**为什么容易这么想**：排序确实不因符号改变——只要分数用同一套公式算。

**错在哪一步**：WOE 变量的系数按定义应该在 −1 附近；出现明显正系数或远离 −1，通常说明分箱方向反了、WOE 定义方向与模型不配套、或存在泄漏/共线。评分卡是给业务和监管看的，符号解释不通意味着这张卡不能上线——先整箱重做，再谈精度。

## 七、面试怎么答

### 30 秒版

> 评分卡就是把 logistic 的 log-odds 换成整数分：$\text{score}=A-B\ln(\text{odds})$，$B=\text{PDO}/\ln2$，$A=\text{base\_score}+B\ln(\text{base\_odds})$。举例：base 600、基准 odds 50:1、PDO=20，则 $B=28.85$、$A=487.12$，也就是 600 分对应 50:1，每多 20 分 good:bad 翻一倍。变量先做 WOE：$\text{WOE}=\ln(\%Good/\%Bad)$，正 WOE 是低风险，箱要合并到每箱样本足够、无零计数、顺序变量上单调；用 IV 筛变量。然后把系数换算成分值：每个变量每 +1 单位是 $-B\beta$ 分，WOE 箱是 $-B\beta\,\text{WOE}$ 分，凑出一张全整数、可直接上线的分数表。

### 2 分钟版（要包含的四块）

1. **刻度化**：两个条件锁死 A、B——PDO 定 $B=\text{PDO}/\ln2$，base 点定 $A=\text{base\_score}-B\ln(\text{base\_odds}_\text{good})$；例：600 分、50:1、PDO=20 ⇒ B=28.85、A=487.12。
2. **WOE 侧**：库内口径 `ln(%Good/%Bad)`、正 = 低风险、理想系数 −1；分箱合并到每箱 ≥5%、无零计数、顺序变量上单调。
3. **一张卡**：基准分 $A-B\beta_0=521.85$；车龄 10+ 箱 −26.78、驾龄 18–25 箱 −29.19 ⇒ 465.89，取整 466；反解 $\text{odds}_\text{good}=0.479$（坏:好 ≈ 1:2.09）。
4. **上线纪律**：切点固化、未取整定阈值、缺失与边界值单独处理、PSI 监控分数漂移。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「PDO 是什么、怎么定？」 | Points to Double the Odds：odds 翻倍分数变化 PDO 分 ⇒ $B=\text{PDO}/\ln2$；PDO 就是分辨率，10 分比 20 分细一倍（同两名客户分差 84.65 → 42.32） |
| 「A 怎么定？」 | 基准点：base_score 对应 base_odds；$A=\text{base\_score}-B\ln(\text{base\_odds}_\text{good})=487.12$（600 分 ↔ 50:1） |
| 「odds 用 good:bad 还是 bad:good？」 | 必须写清；本页用事件 odds（bad:good）配 `A − B·ln(odds)`；换 good:bad 只是 A 移项，数值一致但不能混用 |
| 「WOE 系数为什么接近 −1？」 | 条件独立时 log-odds 可加；WOE 与数据同源、方向配套时是恒等式（单变量车龄例：β̂₀=ln(1000/4000)、β̂=−1.0000）；多变量与共线时偏离，符号仍由定义方向决定 |
| 「分数怎么反解 odds？」 | $\text{odds}_\text{good}=\exp((\text{score}-A)/B)$；465.89 分 ⇒ 0.479，坏:好 ≈ 1:2.09 |
| 「为什么不用概率直接定阈值？」 | 概率是非线性刻度，变量加分不可加，做不成分值表；log-odds 上模型本来就是线性的 |
| 「上线后分数漂移怎么办？」 | 切点与映射固化、缺失值单独一箱、PSI 监控分箱分布，样本外/时间外复核（见 [[10.5 模型评估与监控]]） |

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话说明 |
|---|---|---|
| 评分卡 | scorecard | 把 log-odds 线性映射成整数分的部署形态 |
| 刻度化 | scaling | 由 PDO 定 B、由 base 点定 A，把 log-odds 换算成分数 |
| 翻倍分 | points to double the odds (PDO) | odds 每翻一倍分数变化的点数，决定分辨率 |
| 基准分 / 基准 odds | base score / base odds | 锚定 A 的一个已知点（如 600 分 ↔ 50:1） |
| 事件几率 | odds (bad:good) | $P(\text{Bad})/P(\text{Good})$，配 `A − B·ln(odds)` 使用 |
| 证据权重 | weight of evidence (WOE) | `ln(%Good/%Bad)`，正 = 低风险（库内口径） |
| 信息值 | information value (IV) | `Σ(%Good−%Bad)·WOE`，整变量筛选 |
| 起评分 | base points | $A-B\beta_0$，摊在每个变量上的基准部分 |
| 箱分值 | bin points | $-B\beta\,\text{WOE}_k$，某个箱的加分/扣分 |
| 反解 | back-solve | 由分数还原 odds：$\exp((\text{score}-A)/B)$ |
| 单调性 | monotonicity | 顺序变量上 WOE（及分数）方向一致，评分卡上线的前提 |
| 群体稳定性指标 | population stability index (PSI) | 分数 / 分箱分布随时间的漂移监控 |
| 未取整分数 | unrounded score | 定业务阈值要用它，避免取整后的边界抖动 |
| 样本外时间验证 | out-of-time (OOT) | 用更晚的数据复核分箱与 IV 的稳定性 |
