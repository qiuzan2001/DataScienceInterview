# 10. 保险风控考点总览

> - （本笔记是真题 §1.4（保险目标选分布）与 §7.3（GLM or GBM）的章节导览，非直接对应题）
> 🔎 逐题导航：[[MAGNet 答案对照表]]

## 速览 At a glance

**速记**

这一章不教新算法，它把前 8 章的通用 ML 换到保险语境里用一遍：**面试官问的不是公式，而是你能不能把公式翻译成费率、准备金和风控决策**。他问的是「定价为什么用 GLM 不用 XGBoost」「保单暴露期不一样长怎么比」「纯保费里一堆 0 怎么处理」「模型分数怎么变成费率档」。主线只有一条——**纯保费（pure premium）= 频率 × 严重度**，或者用单阶段的 **Tweedie** 一次建出来；往下接评分卡与 WOE、模型评估与监控、采样偏差与拒绝推断。贯穿全章的三条纪律是**偏移量（offset）**、**校准（calibration）优先于排序**、以及**时间外验证（out-of-time, OOT）**。

**一句面试答法**

> "Insurance interviews use the same machine learning toolkit but ask different questions: they want to know how a model becomes a rate, how exposure enters the model, how you handle the mass of zeros, and how you keep the rate explainable and calibrated. So I'd frame every answer around pure premium — frequency times severity, or a single Tweedie — and then connect it to rating factors, the scorecard, calibration, and out-of-time validation."

## 一、按什么顺序学这一章

顺序不是按编号，而是按「谁用到谁」：

| 先学 | 再学 | 最后 |
|---|---|---|
| 10.1 纯保费框架 → 10.2 频率侧 → 10.3 严重度侧 | 10.8 单阶段 Tweedie → 10.9 完整项目 | 10.4 评分卡 → 10.5 评估监控 → 10.6 采样偏差 → 10.7 SAS |

- **先看 10.1 再决定拆不拆**：不知道纯保费是什么，10.2 和 10.3 就只是两个孤立的回归；10.1 讲清「频率 × 严重度」与 Tweedie 两条路线之后，才知道自己在学哪一条。
- **10.2 和 10.3 是同一件事的两半**：频率侧处理暴露期与过散布，严重度侧处理右偏与尾部。两篇的算例都刻意用了小数据，能亲手复算。
- **10.8 是「不想拆」时的主路**：零点质量 + 复合 Poisson–Gamma，$E[Y]=\mu$、$\operatorname{Var}=\phi\mu^{p}$；10.9 用真实项目演示单阶段与两阶段的实测差距与踩坑。
- **10.4–10.6 是风控那条线**：从赔付预测转到二值目标（违约/坏客户），核心是评分刻度、校准与排序、以及样本偏差的修补。
- **10.7 是工具箱**：SAS 语句速查，前面的模型都要能落到 `PROC` 上。

## 三、串讲路径：从纯保费公式到 Tweedie 到评分卡

把这一章串成一串，面试官顺着问也不怕：

1. **起点是一张保单的期望赔付**：频率 0.08 次/车年 × 平均赔付 4,500 元 = 纯保费 360 元/车年（10.1）。任一个因子只影响严重度、相对数 1.28 时，纯保费变成 $0.08\times(4{,}500\times1.28)=460.8$ 元。
2. **拆开做**：频率侧的关键是暴露期——`log μ = log m + x'β`，offset 系数锁死为 1（10.2）；严重度侧的关键是尾部——Gamma / lognormal / Pareto 的选择决定大额赔案的概率（10.3）。
3. **合起来做**：不拆就用 Tweedie 一步建纯保费，$E[Y]=\mu$、$\operatorname{Var}=\phi\mu^{p}$、$1<p<2$ 对应「0 + 正值」，`p` 当超参数调（10.8）；10.9 演示了单阶段比两阶段在实测里高出的排序能力。
4. **从赔付转到分数**：风控场景把二值目标（违约/坏客户）的 log-odds 线性变换成评分 `score = A − B·ln(odds)`，PDO 决定刻度、WOE 保证单调，模型这才变成能落地的档位（10.4）。
5. **证明它没坏**：KS / Gini / Lift 看排序，PSI 看群体漂移，OOT 看时间外表现；**保险要的是校准好的真实频率，不是漂亮的 AUC**（10.5）。
6. **修样本偏差**：过采样会压缩截距，要校正；只用批准样本建模要做拒绝推断（10.6）。
7. **落到工具上**：SAS 语句与输出解读（10.7）。

三条纪律贯穿全章：**offset 处理暴露期**、**校准优先于排序**、**OOT 才是上线表现**。

## 四、通用 ML 知识库缺什么 / 保险面试多问什么

现有 1–8 章的内容本身没问题，但**默认语境是互联网/信贷**。保险面试官会把同一个知识点拧到保险语境上：

| 你已有的通用答案        | 保险面试想要的答案                                         | 差异点                                       |
| --------------- | ------------------------------------------------- | ----------------------------------------- |
| 「逻辑回归输出概率」      | 概率 → **纯保费 / 相对数 relativity**（`exp(β)`）           | 要点出系数的乘性解释，而不是 odds ratio 说完就停            |
| 「Poisson 回归做计数」 | Poisson + **offset = log(exposure)**，系数固定为 1      | offset 这一条是保险面试的经典筛人题                     |
| 「过散布就用负二项」      | 先分清 **过散布 vs 结构零（零膨胀）**，再选 NB / ZIP / hurdle      | 保险数据零特别多（一年不出险）                           |
| 「不平衡就 SMOTE」    | 保险/风控**很少用 SMOTE**：会破坏概率校准，而定价必须校准                | 反直觉，答对加分明显                                |
| 「AUC 0.8 模型很好」  | AUC 高 ≠ 定价好；看 **校准（预测频率 vs 实际频率）**+ 单调性 + OOT     | 保险要的是真实频率，不是排序                            |
| 「树模型效果好就用树」     | 费率模型要**可解释、可外推、单调、能报备** → GLM 为主，树做辅助             | 这是 10.1 的核心考点                             |
| 「交叉验证」          | **OOT（out-of-time）**才是上线表现；还要注意赔付数据「发展期未满」        | 保险数据是时间序列 + 长尾发展                          |
| 「KS 是评估指标」      | KS 的定义式、与 AUC 的关系、经验分档                            | 风控面试的高频名词                                 |
| 「正则化解决分离」       | 完全分离：Ridge/Lasso 不能真正解决（CV 会选 λ=0），用 **Firth 惩罚** | 对应 [[1.6 Estimation Issues & Separation]] |
