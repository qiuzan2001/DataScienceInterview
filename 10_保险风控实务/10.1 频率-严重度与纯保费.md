# 10.1 频率-严重度与纯保费
<!-- real-exam-questions -->

> - (§1) "Which distribution would you pick for an insurance target?"
> - (§1) "Compare GLM to RF/GBM."
> - (§7) "You work at an insurance company. GLM or GBM?"
> 🔎 逐题导航：[[MAGNet 答案对照表]]

## 🎯 一句话
保险定价的基本单位不是「赔了多少钱」，而是**每单位暴露的期望赔付额**，它等于**索赔频率 × 平均单次赔付（严重度）**——而 GLM 之所以成为行业标准，是因为它能把这两个因子各自拆成一张可解释、可外推、可报备的乘性费率表。

---

## 📖 标准定义

> **教材原文 · LDA §8.3.1 Rating Factors and Tariff、§8.3.2 Multiplicative Tariff Model**（<https://openacttexts.github.io/Loss-Data-Analytics/ChapRiskClass.html>）
> > "Thus we can imagine that, with a small number of rating factors, there will be many policyholders falling into the same risk class, charged with the same premium."
> >
> > "Each unique combination of the rating factors in a tariff is called a tariff cell"
> >
> > "The multiplicative form (8.16) is easy to understand and use, because it clearly shows how the expected loss count (per unit exposure) changes as each rating factor varies."
> >
> > "This over-parametrization, meaning that many different sets of parameters arrive at an identical model, obviously calls for some restriction on $f_{1j}$ and $f_{2k}$"
> >
> > "The standard practice is to make one relativity in each rating factor equal to one."
> >
> > "… is generally interpreted as the Poisson rate of the base tariff cell"
> >
> > "In non-life insurance, the parameters $f_{1j}$ and $f_{2k}$ are known as relativities"

**标准记法**：

- 乘性费率模型：$\lambda_{jk} = f_0 \times f_{1j} \times f_{2k}$；取对数 $\log \lambda_{jk} = \log f_0 + \log f_{1j} + \log f_{2k}$（即泊松回归的线性预测子，$\log f$ 扮演 $\beta$）。
- 基准类约束：每个 rating factor 的一个 relativity 固定为 1（如 $f_{11} = 1$、$f_{21} = 1$），base tariff cell 的费率 $\lambda_{11} = f_0$ 为基准值。
- 实际费率（relativity 的用法）：$\text{rate} = f_0 \times \prod_{\text{factor}} f_{\text{factor, level}}$。
- （公式即 LDA 式 (8.16)–(8.18) 原文。）

**中文解释**：乘性费率假设各 rating factor 对预期损失的影响相乘：$\lambda_{jk}=f_0\times f_{1j}\times f_{2k}$，每个 $f$ 就是 relativity（相对基准类的倍数）。因为相乘会「过度参数化」（分子分母可任意配对），每个因子必须把一个水平的 relativity 设为 1 作为基准。取对数后就是普通的泊松回归，$\log f$ 对应 $\beta$。默认假设因子间无强交互。

> 完整条目与更多来源见 [[定义原文库#F30. 乘性费率 / relativity（相对数）|F30. 乘性费率 / relativity（相对数）]]

## 📐 核心公式

### 1. 纯保费分解
把第 $i$ 个风险单位（一张保单、一辆车、一个保单年）的暴露期记为 $m_i$，索赔次数记为 $N_i$，第 $k$ 次赔付金额记为 $X_{ik}$，则聚合赔付
$$S_i=\sum_{k=1}^{N_i}X_{ik}
\qquad\Longrightarrow\qquad
\text{纯保费}_i=\frac{E[S_i]}{m_i}=\underbrace{\frac{E[N_i]}{m_i}}_{\text{频率}}\times\underbrace{E[X_i]}_{\text{严重度}}$$
> **关键前提：$N\perp X$（次数与单次金额独立）**。该式成立是为了把「频率」和「严重度」两块分开建模。实务中两者常常不独立（例如同一场冰雹既提高出险概率又提高单次损失），所以 Tweedie 直接对纯保费建模可以绕开这个假设（见下）。

- **相对数（relativity）**：若频率模型为 $\log\lambda_i=x_i'\beta$，则因子 $j$ 的相对数 $f_j=e^{\beta_j}$，基准类别相对数 $=1$。
- **毛保费（gross premium）** 的常见口径（各公司口径不同，需核对）：
  $$\text{毛保费}=\frac{\text{纯保费}+\text{固定费用}}{1-\text{费用率}-\text{安全附加率}}$$
  至少要能说清「纯保费 ≠ 保费，还要加费用、利润与风险附加」。

### 2. Tweedie 分布：一个模型直接建纯保费
Tweedie 族用**方差函数** $V(\mu)=\mu^{p}$ 参数化：$\operatorname{Var}(Y)=\phi\,\mu^{p}$。

**常见对应关系**（来源：LDA Ch5 §5.3.4 与统计文献；不同教材对 p 的记法略有差异，需核对所用软件）：

| 幂 $p$ | 对应分布 | 保险用途 |
|---|---|---|
| $p=0$ | 正态 Normal | 一般连续数据（非保险场景） |
| $p=1$ | Poisson | 索赔次数 |
| $p=2$ | Gamma | 严重度（正的连续金额） |
| $1<p<2$ | 复合 Poisson–Gamma | **有零的连续正数** → 聚合赔付 / 纯保费 |

- $1<p<2$ 的直觉：$Y=0$（这一年没出险）与 $Y>0$（出险了，金额为正）在同一个分布里，正好对应「频率 × 严重度」的复合结构。
- 若 $N\sim$ Poisson、$X\sim$ Gamma(shape $\alpha$)，则复合损失的 Tweedie 幂为 $p=\dfrac{\alpha+2}{\alpha+1}$（$\alpha\to\infty \Rightarrow p\to1$；$\alpha\to0 \Rightarrow p\to2$）——**此关系式标注需核对**（Jørgensen 的参数化，使用时请对照 LDA Ch5 §5.3.4 或 SAS/Python 文档确认）。
- **实务中 $p$ 不套固定值**：在 (1, 2) 上做网格搜索 + profile likelihood / AIC 选 $p$；具体常用取值各机构不一致，**需核对**。

## 💼 保险场景

**某车险公司（示例数据）**：一张私家车保单暴露 1 个车年。
- 输入（费率因子）：驾驶人年龄、车龄、车型/车价、地区风险等级、年行驶里程、历史索赔次数
- 输出（两部分）：
  - 频率模型：$\hat\lambda=0.08$ 次/车年
  - 严重度模型：$\hat E[X]=4{,}500$ 元
  - **纯保费** $=0.08\times4{,}500=360$ 元/车年
- 如果某车型的相对数为 $1.28$（$\beta=0.2469$，$e^{0.2469}=1.28$），且它只影响严重度，则该车型纯保费 $=0.08\times(4{,}500\times1.28)=0.08\times5{,}760=460.8$ 元。

**家财险**：暴露可按「保额年 / 承保年」计，严重度重尾（一次水暖管爆裂可能顶掉几千张小额保单的赔付），所以家财险的严重度模型比车险更依赖参数化尾部（10.3）。

### 为什么保险公司偏爱 GLM（面试要能列 5 条）
1. **可解释、可审计**：一个因子一个系数，$e^{\beta}$ 直接就是费率相对数，能落进费率表被人读。
2. **可外推**：新区间（新车型、新地区、通胀后的赔付水平）在线性预测子上仍然有定义；树模型只能给分段常数。
3. **监管与报备**：个人险费率通常要向监管机构报备，需要说明费率因子、系数、依据、可复现——黑箱模型很难报备。（一般性事实：美国个人险费率受州级监管，报备口径各州不同，需核对。）
4. **数据稀疏**：每个风险类别的观测常常只有几百条，GLM 的乘性结构 + 类别合并 + 信度加权（LDA Ch9）能给出稳定估计。
5. **不确定性可量化**：系数有标准误、有置信区间，可做信度（credibility）加权与情景分析。

### 为什么树模型在费率制定里受限（面试要能列 4 条）
1. **不可外推**：树输出是训练数据范围内的分段常数；通胀后的赔付、新车型只能落在最近的叶子里。
2. **不单调、有断点**：相邻区间可能出现分数反转（更安全的车反而更贵，rate inversion），业务和监管都不接受。
3. **难解释、无可报备费率表**：没有「某因子 +10%」这种可直接写进档位的东西。
4. **难做可信度加权**：与 LDA Ch9 的信度框架不衔接。

> **实务折中（安全说法）**：树/GBM 用于**变量发现、交互探测、残差诊断、欺诈排序、以及给 GLM 做基准对照**；最终费率表用 GLM（或带单调约束的 GBM 做敏感性对照，如 `monotone_constraints` 一类机制）。不要宣称某个单一模型「一定更好」。

## 🛠️ 代码

### SAS：拆成两半 + 一体建模

```sas
/* (0) 暴露：一定要先算 log(exposure)，SAS 不会自动帮你取对数 */
data claims;
  set claims;
  ln_exposure = log(exposure);          /* exposure 单位统一（如车年） */
run;

/* (1) 频率：Poisson GLM + offset */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;                 /* param=ref：基准类别系数=0，直接得到相对数 */
  model clm_count = veh_type age_bnd
        / dist=poisson link=log offset=ln_exposure;
  lsmeans veh_type / diff cl;                          /* 相对数：对 estimate 取 exp */
run;

/* (2) 严重度：Gamma GLM + log link（每行 = 一次赔案，不是一张保单） */
proc genmod data=claims_sev;
  class veh_type age_bnd / param=ref;
  model loss_amt = veh_type age_bnd / dist=gamma link=log;
run;

/* (3) 一体建模：直接对纯保费做 Tweedie */
proc genmod data=claims;
  class veh_type age_bnd / param=ref;
  model pure_premium = veh_type age_bnd
        / dist=tweedie link=log offset=ln_exposure;
  /* Tweedie 的 power p 用额外选项指定（选项名与取值以所用 SAS 版本文档为准）；
     通常做法是在 1–2 之间按 AIC / profile likelihood 搜索，不要写死 */
run;
```

**输出怎么读**：`Analysis of Maximum Likelihood Parameter Estimates` 表里 `Estimate` 就是 $\beta$，`exp(Estimate)` 是相对数；`Criteria For Assessing Goodness Of Fit` 里的 `Pearson Chi-Square/DF` 偏离 1 太多说明过散布（10.2），`Scaled Deviance` 用于比较嵌套模型。

### Python（statsmodels）

```python
import numpy as np
import statsmodels.api as sm
import statsmodels.formula.api as smf

# (1) 频率：Poisson + offset（offset = log(exposure)，系数固定为 1）
m_freq = smf.glm("clm_count ~ C(veh_type) + C(age_bnd)",
                 data=df, family=sm.families.Poisson(),
                 offset=np.log(df["exposure"])).fit()

# 相对数：exp(beta)
relativity = np.exp(m_freq.params)

# (2) 严重度：Gamma + log link（只保留有赔付的赔案）
sev = df[df["loss_amt"] > 0]
m_sev = smf.glm("loss_amt ~ C(veh_type) + C(age_bnd)",
                data=sev,
                family=sm.families.Gamma(link=sm.families.links.Log())).fit()
# 注意：statsmodels 0.14+ 里 link 类名改为小写（sm.families.links.log()），版本不同写法不同（需核对）

# (3) 纯保费 = 频率 x 严重度：按因子组合相乘
grid = pd.DataFrame({"veh_type": ["sedan", "suv"], "age_bnd": ["18-25", "18-25"]})
freq_pred = m_freq.predict(grid, offset=np.zeros(len(grid)))   # 单位暴露下的频率
sev_pred  = m_sev.predict(grid)
pure_premium = freq_pred.values * sev_pred.values

# (4) 一体建模：Tweedie（var_power 就是 p，先在 1-2 上搜索）
m_tw = smf.glm("pure_premium ~ C(veh_type) + C(age_bnd)",
               data=df,
               family=sm.families.Tweedie(link=sm.families.links.Log(),
                                          var_power=1.5),   # 1.5 仅为示例，务必按数据搜索
               offset=np.log(df["exposure"])).fit()
```

## 🗣️ 面试速答（30 秒）

> 保险定价建的是**纯保费**，等于**频率 × 严重度**：一张保单的期望赔付 = 期望出险次数 × 平均单次赔付。拆开建模是因为两块的驱动因子完全不同——频率受驾驶行为、里程影响，严重度受车价、维修成本影响。所以保险公司用 GLM：每个因子一个系数，$e^{\beta}$ 就是费率相对数，可解释、可外推、能报备、能给稀疏类别做稳定估计；树模型不能外推、不单调、说不出相对数，所以主要用来做变量发现和对照。如果不想拆两块，就用 **Tweedie**（方差函数 $\text{Var}(Y)=\phi\mu^{p}$，$1<p<2$ 对应复合 Poisson–Gamma，用来建「有零的连续正数」也就是聚合赔付/纯保费）。

## ⚠️ 常见坑
- **纯保费 ≠ 保费**：还要加费用、利润/风险附加；说「纯保费就是费率」会被追问。
- **$N\perp X$ 假设不写在卷面上**：这是拆分的代价，Tweedie 能绕开（但 Tweedie 本身仍隐含复合 Poisson–Gamma 结构，需核对）。
- **暴露期单位不统一**：车年 vs 保单数 vs 天数，offset 用错单位，相对数整体偏掉。
- **用 RMSE 选定价模型**：赔付重尾，RMSE 被少数大额主导；用 deviance / AIC 比拟合，用 OOT 的校准 + 相对数稳定性比业务效果。
- **AUC 高 ≠ 定价好**：定价要的是**校准**（预测频率要接近实际频率）与单调费率，排序能力只是必要条件（10.5）。
