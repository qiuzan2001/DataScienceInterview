# 10.8 Tweedie GLM 专章

## 🎯 一句话
保险的**纯保费（pure premium）**是「大量 0 + 右偏连续正值」的混合数据，而 **Tweedie 分布**正好就是「**零点质量 + 正数值分布的混合**」（mixture of zero and a positive valued distribution），它就是复合 Poisson-Gamma，因此可以**一步建出纯保费**，不用把频率和严重度拆开再相乘。

---

## 📐 分布定义

### 1. 构造：复合 Poisson-Gamma（compound Poisson-Gamma）

一张保单一年内的**总赔付**是「随机个数的正数之和」：

$$S_N=\sum_{i=1}^{N}X_i,\qquad N\sim\text{Poisson}(\lambda),\qquad X_i\overset{iid}{\sim}\text{Gamma}(\text{shape }\alpha,\ \text{scale }\gamma)$$

- $N=0$（这一年没出险）$\Rightarrow S_N=0$：所以这个分布在 **0 点有正的质量（point mass at zero）**；
Loss Data Analytics §5.3.4（Loss Data Analytics，开源精算教材：https://openacttexts.github.io/Loss-Data-Analytics/ ）的结论：

Loss Data Analytics §5.3.4（开源精算教材，见本页「🔗 相关」）的结论：

> Tweedie 分布可视为「**零点质量 + 正数值分布的混合**」（mixture of zero and a positive valued distribution），"which makes it a convenient tool for modeling insurance claims and for calculating pure premiums".

**这一句就是面试要背的核心**：它把「没出险的 0」和「出了险的正的金额」放进同一个分布，而这正好就是**纯保费**要预测的东西。

### 2. 重参数化：从 $(\lambda,\alpha,\gamma)$ 换到 $(\mu,\phi,p)$

LDA §5.3.4 给出的换元：

$$\lambda=\frac{\mu^{2-p}}{\phi(2-p)},\qquad \alpha=\frac{2-p}{p-1},\qquad \frac{1}{\gamma}=\phi(p-1)\mu^{p-1}$$

于是复合分布完全由三个量刻画——**均值 $\mu$、离散参数 $\phi$、幂 $p$**——而 GLM 只认 $(\mu,\ \text{方差函数})$，所以这个写法才让 Tweedie 能进 GLM。

适用条件：$$\boxed{\ 1<p<2\ }$$（复合 Poisson-Gamma 情形）。

> 顺带一个能自检的细节：由 $\alpha=\dfrac{2-p}{p-1}$ 反解得到 $p=\dfrac{\alpha+2}{\alpha+1}$，与 [[10.1 频率-严重度与纯保费]] 里那条关系式是**同一个式子**（那里标了「需核对」，LDA §5.3.4 的重参数化给了它依据）。
> 直觉方向：$p\to1$ 时 $\alpha\to\infty$（单次金额越来越集中）；$p\to2$ 时 $\alpha\to0$（单次金额重尾越来越强，损失由少数大额赔付驱动）。

---

## 📐 均值与方差

LDA §5.3.4：

$$E(S_N)=\mu,\qquad \operatorname{Var}(S_N)=\phi\,\mu^{p}$$

- 方差函数（variance function）$V(\mu)=\mu^{p}$ → 这就是 Tweedie 族的定义方式；
- 把方差与均值的比例写出来：

$$\frac{\operatorname{Var}(S_N)}{E(S_N)}=\phi\,\mu^{\,p-1}$$

**$1<p<2\Rightarrow p-1>0$，所以均值越大的风险，相对波动越大**（变异系数 $\sqrt{\phi\,\mu^{p-1}}$ 随 $\mu$ 递增）。这一条同时解释了两件事：

1. 一份「平均赔付本来就高」的高风险保单，其不确定性按幂次放大 → 定价必须留风险附加；
2. 「大量 0」（均值很小的一侧）与「高偏度大额赔付」（均值很大的一侧）能被**同一个方差函数**装下——这正是它能统一频率与严重度两块的原因。

对照两端（这三个式子连起来看最清楚）：

| 分布 | 方差 | 相对波动 |
|---|---|---|
| Poisson（$p=1$） | $\operatorname{Var}=\mu$ | 方差/均值 $=1$ 恒定 |
| **Tweedie（$1<p<2$）** | $\operatorname{Var}=\phi\mu^{p}$ | 方差/均值 $=\phi\mu^{p-1}$ **随均值递增** |
| Gamma（$p=2$） | $\operatorname{Var}=\phi\mu^{2}$ | CV $=\sqrt{\phi}$ 恒定（见 [[10.3 严重度模型与 Gamma]]） |

---

## 📐 $p$ 的取值意味着什么

LDA §5.3.4 的两个极限情形：

- **$p\to1$ 得到 Poisson 分布**（纯计数，方差 = 均值）；
- **$p\to2$ 得到 Gamma 分布**（严格正值、CV 恒定）。

原文：

> "the Tweedie model accommodates the situations in between the gamma and Poisson distributions, which makes intuitive sense as it is **the Poisson sum of gamma random variables**".

**$1<p<2$ 就是复合 Poisson-Gamma**：既有「出险次数」的计数成分（Poisson），又有「单次金额」的连续成分（Gamma）——所以它是「Poisson 个 Gamma 之和」，直觉上正好落在 Poisson 与 Gamma 之间。

其他 $p$ 的常见对应关系（**注：$p=0$ 与 $p=3$ 这两行不是 LDA §5.3.4 的原文结论，是「其他 $p$ 的常见对应关系」，用之前请对照所用软件文档**）：

| 幂 $p$ | 对应分布 | 方差函数 $V(\mu)$ | 保险用途 |
|---|---|---|---|
| $p=0$ | 正态（Normal） | $1$ | 一般连续数据，非保险场景 |
| $p=1$ | Poisson | $\mu$ | 索赔次数 |
| $1<p<2$ | **复合 Poisson-Gamma** | $\mu^{p}$ | **有零的连续正数 → 纯保费 / 聚合赔付（本页主角）** |
| $p=2$ | Gamma | $\mu^{2}$ | 严重度（严格正值，不能装 0） |
| $p=3$ | 逆高斯（inverse Gaussian） | $\mu^{3}$ | 右侧尾更重的正值数据 |

### 实践中 $p$ 是**超参数**，不是背下来的常数

$p$ 不套固定值，做法是：**在 $(1,2)$ 上网格 + 交叉验证，和正则化强度 $\alpha$ 一起选**。

项目实测（见 [[10.9 项目实战：法语车险纯保费定价]]）：12 组 `(power, alpha)` 网格里，CV 选出 $\hat p=1.9$——**最靠近 Gamma 的那一端**。业务解读：这批车险数据的信号主要来自「严重度的重尾」，而不是「泊松计数的结构」。

> ⚠️ 但要说实话：CV 前几名的差距**远小于 1 个标准差**（34.0823 vs 34.1429，SD ≈ 0.51），所以正确说法是「数据支持 $p$ 落在 1.7–1.9 这一段」，而不是「$p=1.9$ 显著更好」。详见 10.9 的调参一节。

## 📐 与 GLM 的关系

### 1. 为什么能直接当 GLM 用

Tweedie 是**指数散布族（exponential dispersion model, EDM）**的特例，因此**可以直接作为 GLM 的随机成分（random component）**：

$$f(y;\theta,\phi)=\exp\!\left\{\frac{y\theta-b(\theta)}{\phi}+c(y,\phi)\right\},\qquad b'(\theta)=\mu,\quad b''(\theta)=V(\mu)=\mu^{p}$$

- 这就是 [[1.2 Generalized Linear Models (GLMs)]] 的 EDM 框架 —— 方差函数换成 $\mu^{p}$ 而已；
- canonical link 是 $\theta=\mu^{1-p}/(1-p)$（$p\ne1$）：
  - $p=1$ 退化为 $\log\mu$（与 [[10.2 计数模型与 offset]] 的 Poisson 一致）；
  - $p=2$ 退化为 $1/\mu$（inverse，与 [[10.3 严重度模型与 Gamma]] 里 Gamma 的 canonical link 一致）。
  - 这两个端点自洽 ✓（**实务仍然用 log link**，见「常见坑」）。

### 2. log link 下的写法（费率表的语言）

$$\log\mu_i=x_i'\beta\ \ (+\log\text{exposure}_i)\qquad\Longrightarrow\qquad \hat\mu_i=e^{x_i'\beta}$$

- 系数是**乘性**的：$e^{\beta_j}$ = 相对数（relativity），基准类别 = 1 → 可以直接翻译成费率因子；
- 两种等价写法：
  - **目标 = 纯保费** $y_i/\text{exposure}_i$，**权重 = exposure**（本项目做法）；
  - **目标 = 总赔付** $y_i$，**offset = $\log(\text{exposure}_i)$**（[[10.2 计数模型与 offset]] 的写法）。

### 3. 离差（deviance）

Tweedie 的 unit deviance（$p\ne1,2$ 的一般式；**常数因子依实现而定，有的实现不含前面的 2**）：

$$d(y,\mu)=2\left[\frac{y^{2-p}}{(1-p)(2-p)}-\frac{y\,\mu^{1-p}}{1-p}+\frac{\mu^{2-p}}{2-p}\right]$$

面试只要说清这三条性质：

- $p=0$ → 退化为平方误差（scikit-learn 文档口径：`mean_tweedie_deviance(power=0)` 与 `mean_squared_error` 等价）；
- $p=1$ → **Poisson 离差**；$p=2$ → **Gamma 离差**；
- ⚠️ **常数因子 / 归一化依实现而定**，所以**不同 $p$ 的离差数值不可直接比较**（这是本项目调参时要固定 $p$ 打分的原因，见「常见坑」）。

## 💼 保险场景

### 1. 纯保费 = 频率 × 严重度的「乘积分布」

$$S=\sum_{k=1}^{N}X_k,\qquad E[S]=E[N]\cdot E[X]$$

- 拆开建模（two-stage）要先算频率再算严重度，然后**手动相乘**；
- Tweedie 是**直接对 $S/\text{exposure}$ 建一个似然**，一步得到纯保费。

### 2. 为什么单阶段可能优于两阶段（面试重点）

> 先说一个**容易说错、说对了加分**的点：复合 Poisson-Gamma 构造**本身也假设了 $N\perp X_i$**，所以 Tweedie 并不是「绕开独立性假设」；它的好处是**用单一似然同时估计两部分**。下面是真正的理由：

1. **避免分布外预测（out-of-distribution）**：两阶段的严重度模型只在「有索赔」的子集上训练（本项目里 ≈ 5% 的保单），却要对**全部**保单预测——绝大多数保单在训练时根本没进过严重度模型的样本。这是两阶段方法的**固有弱点**。
2. **误差不再相乘**：两阶段把频率模型与严重度模型各自的误差乘在一起，Tweedie 直接对乘积目标（纯保费）做似然，误差在同一个目标函数里被处理。
3. **实测证据**：同一条流水线、同一份数据，单阶段 Tweedie 的 Gini 从 0.1797 提到 0.2802（**+56%**），离差从 34.8097 降到 34.6383（≈0.5%）。见 [[10.9 项目实战：法语车险纯保费定价]]。

### 3. 代价（要主动说出来）

Tweedie 的系数**不再能拆成「频率因子 / 严重度因子」**。而费率报备、因子归因、业务沟通通常都需要拆开看——所以实务里常见的是**两条路线并行**：Tweedie 做定价主模型，两阶段做因子解释与对照。

## 🛠️ 代码

### Python（骨架取自库内真实项目，见 10.9）

```python
"""单阶段 Tweedie GLM 直接建纯保费"""
import numpy as np
from sklearn.linear_model import TweedieRegressor
from sklearn.metrics import mean_tweedie_deviance
from sklearn.model_selection import KFold

# 目标 = 纯保费（每单位暴露的期望赔付）；权重 = 暴露期
y = (df["ClaimAmount"] / df["Exposure"]).values
w = df["Exposure"].values
X = X_encoded                       # one-hot 后 46 维（见 10.9）

# ---- 1) power 与 alpha 必须【一起】调，不是先定 p 再调 alpha ----
power_grid, alpha_grid = [1.3, 1.5, 1.7, 1.9], [1e-4, 1e-2, 1.0]
kf, results = KFold(n_splits=5, shuffle=True, random_state=42), []
for power in power_grid:
    for alpha in alpha_grid:
        folds = []
        for fit_i, val_i in kf.split(X):
            m = TweedieRegressor(power=power, alpha=alpha, link="log", max_iter=300)
            m.fit(X[fit_i], y[fit_i], sample_weight=w[fit_i])
            pred = m.predict(X[val_i])
            # 关键：所有候选都用【同一个 power=1.9】打分，跨网格才可比
            folds.append(mean_tweedie_deviance(y[val_i], pred,
                                               sample_weight=w[val_i], power=1.9))
        results.append((power, alpha, float(np.mean(folds)), float(np.std(folds))))

best = min(results, key=lambda r: r[2])        # 本项目选到 power=1.9, alpha=1.0
print(best)                                     # (1.9, 1.0, 34.0823, 0.5148)

# ---- 2) 用最优配置在完整训练集上重拟合 ----
model = TweedieRegressor(power=best[0], alpha=best[1], link="log", max_iter=300)
model.fit(X, y, sample_weight=w)
print(np.exp(model.coef_)[:10])                 # exp(系数) = 相对数（relativity）

# ---- 3) 评估：三个层次都要做 ----
#    (a) 离差（平均拟合）：mean_tweedie_deviance(..., power=1.9)
#    (b) Lorenz 曲线 / Gini（风险排序能力）：numpy 2.x 用 np.trapezoid，旧版用 np.trapz
#    (c) 十分位校准（分段）：按预测纯保费切 10 组，比较加权平均预测 vs 加权平均实际
```

statsmodels 的等价写法（参数名是 `var_power`）：

```python
import statsmodels.api as sm
m = sm.GLM(y, X, family=sm.families.Tweedie(
        link=sm.families.links.Log(), var_power=p)          # var_power 就是 p
    ).fit()
```

> 注意：scikit-learn 的 `TweedieRegressor` 只提供 `link="log"`；`power` 与 `alpha` 是它暴露给你的两个旋钮。

## ⚠️ 常见坑

1. **$p$ 必须 $1<p<2$**（复合 Poisson-Gamma 情形）。$p=1$ 是 Poisson（方差 = 均值，装不了连续金额），$p=2$ 是 Gamma（**严格正值，不能装 0**）——两端都是极限情形。
2. **`alpha`（正则化）与 `power` 要一起调**：只调一个、固定另一个，很可能选到噪声里的名次（本项目前 4 名差异 < 1 个 SD）。
3. **只有 `log` link 被常用实现支持**：`TweedieRegressor` 只给 `link="log"`；canonical link $\mu^{1-p}/(1-p)$ 理论上存在，实务不用、软件常不支持。
4. **零值不是缺失值**：一年没出险是**真实观测** $Y=0$。把零当缺失删掉 → 均值被系统性放大 → **保费定高**。（可以只在正值子集上拟合的，是两阶段里的严重度模型，不是 Tweedie。）
5. **离差可比性**：不同 $p$ 的 deviance 数值**不可直接比较**（尺度不同）→ 在网格里评分时必须**固定一个 $p$**（项目用 `power=1.9`），否则「哪个配置更好」这个结论本身就是假的。
6. **权重用 exposure、目标用「每单位暴露」**：`y = ClaimAmount / Exposure`、`sample_weight = Exposure`；不乘 exposure 会把短暴露保单的信息量和长暴露保单等价处理。
7. **别用 MSE / $R^2$ 评价**：零点质量 + 重尾下，平方损失会被少数大额点主导，且与泊松/伽马似然不可比。用 **离差 + Gini/Lorenz + 分段校准**三件套。
8. **离差小 ≠ 排序好**：平均拟合好、风险排序差，在保险定价里是致命的（见 10.9 的实测：离差差 0.5%，Gini 差 56%）。

> 纯保费是「大量 0 + 右偏连续正值」，所以我不拆成频率×严重度两个模型，而是直接用 **Tweedie GLM** 建纯保费——Tweedie 可以看成**零点质量 + 正数值分布的混合**，本质上就是复合 Poisson-Gamma：保单一年内的赔付是「Poisson 个 Gamma 之和」，所以 $1<p<2$ 时它落在 Poisson 与 Gamma 之间。用 LDA §5.3.4 的换元，复合分布由均值 $\mu$、离散 $\phi$、幂 $p$ 刻画，**$E=\mu$、$\operatorname{Var}=\phi\mu^{p}$**，于是它作为指数散布族成员直接当 GLM 的随机成分；$p\to1$ 是 Poisson、$p\to2$ 是 Gamma。实践上我把 $p$ 当超参数，和 L2 强度 $\alpha$ 一起做 CV——我自己的项目在 678,013 份法国车险保单上选出 $p=1.9$（最靠近 Gamma 一侧），Gini 0.2802，比两阶段的 0.1797 高 56%。但我也要主动说：最优配置的 CV 差距小于 1 个标准差，属于噪声范围，按 1-SE 规则应该选更正则的模型，而且**十分位校准显示最高风险组高估约 2 倍**——所以我的结论是「Tweedie 是正确的主力分布」，不是「这个模型可以直接上线报价」。

## 🗣️ 英文表达 / How to Say It

面试时可以直接说出口的完整句子（不要只堆术语）：

1. "I'd model pure premium directly with a Tweedie GLM, because it handles the mass at zero and the positive, right-skewed claim amounts in a single compound Poisson-Gamma distribution."
2. "Tweedie is a special case of the exponential dispersion family, so it can serve directly as the random component of a GLM, and with a log link the coefficients come out as multiplicative rating factors."
3. "The power parameter p sits between one and two for compound Poisson-Gamma: as p goes to one you get a Poisson, as p goes to two you get a Gamma, so p equals 1.9 means the variance grows almost quadratically with the mean."
4. "The mean is mu and the variance is phi times mu to the power p, so the variance-to-mean ratio increases with the mean — which is exactly the pattern we see in claim data."
5. "In practice I treat p as a hyperparameter and tune it jointly with the L2 penalty by cross-validation, rather than fixing it at some textbook value."
6. "The subtle part is that deviances at different p values aren't comparable, so I score every candidate in the grid at a fixed power — we used 1.9 — to keep the comparison apples-to-apples."
7. "One thing I'd flag: zeros here are real observations, not missing values — a policy with no claim is a genuine zero, so dropping them would bias the average claim cost upward."
8. "If aggregate deviance looks fine but the top decile is off by a factor of two, the GLM isn't capturing the nonlinear tail, and that's where I'd bring in a gradient-boosted model with a Tweedie objective."

| 复合 Poisson-Gamma | compound Poisson-Gamma | 「Poisson 个 Gamma 之和」，$1<p<2$ 的 Tweedie 就是它 |
| 零点质量 | point mass at zero | $P(Y=0)>0$：这一年没出险的保单都落在这个点上 |
| 纯保费 | pure premium | 每单位暴露的期望赔付，$E[S]/\text{exposure}$，定价的建模目标 |
| 幂参数 | power parameter $p$ | 控制方差随均值增长快慢；$1<p<2$ 为复合 Poisson-Gamma |
| 方差函数 | variance function $V(\mu)$ | Tweedie 族里 $V(\mu)=\mu^{p}$，决定 $\operatorname{Var}=\phi\mu^{p}$ |
| 指数散布族 | exponential dispersion model (EDM) | 能直接当 GLM 随机成分的分布族，Tweedie 是其中一员 |
| 离散参数 | dispersion parameter $\phi$ | 方差里的比例常数，与 $\mu$ 无关 |
| 对数连接 | log link | $\log\mu=x'\beta$，保证预测为正，系数可解释为相对数 |
| 相对数 | relativity | $e^{\beta_j}$，费率因子的乘性倍数，基准类别为 1 |
| 离差 | deviance | 拟合优度（proper scoring rule）；不同 $p$ 之间不可直接比 |
| 暴露期 | exposure | 保单承保时长（年），Tweedie 建模时作样本权重或 offset |
| 样本权重 | sample_weight | `TweedieRegressor.fit()` 里传 exposure，等价于按暴露期加权似然 |
| 复合分布 / 聚合损失 | compound / aggregate loss | 随机个数的随机金额之和 $S=\sum_{k=1}^{N}X_k$ |
