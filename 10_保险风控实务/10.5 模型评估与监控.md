# 10.5 模型评估与监控

## 🎯 一句话
风控模型的评估分两层：**上线前**看排序能力（KS、Gini/AUC、Lift 十分位表）**和校准**（预测频率 vs 实际频率）；**上线后**看稳定性（PSI/CSI）——而真正代表上线表现的是 **OOT（时间外样本）**，不是随机交叉验证。

---

## 📐 核心公式

### 1. KS（Kolmogorov–Smirnov 统计量）
$$\boxed{\ \text{KS}=\max_s\big|\text{CDF}_{\text{Good}}(s)-\text{CDF}_{\text{Bad}}(s)\big|\ }$$
- 把分数 $s$ 从小到大扫一遍，Good 的累积分布与 Bad 的累积分布之间的**最大垂直距离**。
- **等价算法**（更常用）：按预测风险从高到低排序，$\ \text{KS}=\max(\text{TPR}-\text{FPR})$，也就是 ROC 曲线上离对角线最远的那一点。
- **KS 只看一个切点**，AUC/Gini 看全阈值——两个模型 AUC 相同、KS 可以差很多，所以一起看。
- 业务含义：KS 对应的那个切点就是「区分度最好」的阈值，方便选截断分数。

| KS 经验分档（**经验值，各机构口径不一**） | 解读 |
|---|---|
| $<0.2$ | 弱 |
| $0.2$–$0.4$ | 中 |
| $0.4$–$0.6$ | 强 |
| $>0.6$ | 先查**数据泄漏/时间穿越**，别急着高兴 |

> 有的机构口径是「>0.3 算良好」，有的用 <0.2/0.2–0.4/0.4–0.6 这套，**阈值不是通用标准**，面试时说明「这是行业常用经验值」。

### 2. Gini 与 AUC
$$\boxed{\ \text{Gini}=2\cdot\text{AUC}-1\ }$$
- 也叫 **Accuracy Ratio (AR)**，或与 Somers' D 同源；AUC 是 ROC 曲线下面积，$[-1,1]$ 的 Gini 就是把它线性映射过来。
- 直觉：Gini = 「随机抽一好一坏，模型把坏排在前面的概率」相对随机的增益。
- ⚠️ **与决策树的 Gini 不纯度同名不同物**（[[7.5 CART Algorithm]] 里的 Gini 是 $\sum p(1-p)$），别混。
- 经验对照（**经验值**）：Gini 0.3 ≈ AUC 0.65，Gini 0.4 ≈ AUC 0.70，Gini 0.6 ≈ AUC 0.80。

### 3. 十分位 Lift 表（排序业务化的标准动作）
构造步骤（5 步）：
1. 用模型给每个样本打分
2. 按分数**从高到低**排序（= 风险从高到低；**方向搞反是常见事故**）
3. 等频切 10 组（每组约 10% 样本）
4. 每组算：样本数、事件数、**组内事件率**、Lift
5. 累计：累计事件捕获率、累计样本占比、累计 Lift
$$\text{Lift}_k=\frac{\text{组内事件率}_k}{\text{整体事件率}},\qquad
\text{累计捕获率}_k=\frac{\sum_{j\le k}\text{事件}_j}{\text{事件总数}}$$

### 4. PSI（Population Stability Index，分数层）与 CSI（变量层）
$$\boxed{\ \text{PSI}=\sum_k\big(\%\,\text{Actual}_k-\%\,\text{Expected}_k\big)\cdot\ln\!\frac{\%\,\text{Actual}_k}{\%\,\text{Expected}_k}\ }$$
- **Expected = 基准期（训练期）分布，Actual = 当前期分布**；切点用基准期定好（通常 10 个等频箱），不要在新数据上重新分箱。
- 公式对 Actual/Expected **对称**（两项互换只改变符号再相加，结果一样），所以不用纠结谁在前。
- 每个分箱占比加一个小常数（如 $10^{-6}$）避免 $\ln(0)$。

| PSI（**经验值，各机构不一致**） | 处置 |
|---|---|
| $<0.1$ | 稳定 |
| $0.1$–$0.25$ | 关注 / 排查 |
| $>0.25$ | 重训或重标定 |

- **CSI = 对每个变量单独算 PSI**（变量分布漂移），常见经验规则：某变量 CSI $>0.1$ 就去看它的分箱占比发生了什么（**经验值**）。
- PSI 对**分箱数量敏感**：箱数越多 PSI 越大，所以同一套监控必须固定箱数与切点（条数选择属于经验约定，**需核对所在团队口径**）。

### 5. 校准（Calibration）——保险比排序更看重
- **排序好 ≠ 数字准**。定价、准备金、资本计提要的是「预测频率 ≈ 实际频率」。
- 做法：把预测值分 10 组，比较**组内预测均值** vs **组内实际发生率**；或画 calibration curve。
- 保险特有话术：模型预测组合赔付 1,000 万，实际 1,300 万 → 排序再好也不能拿去定价（差 30% 会直接反映成核保亏损）。
- 过采样/样本加权会**破坏校准**（见 [[10.6 采样偏差与拒绝推断]]），必须在评估阶段修回来。

### 6. OOT（out-of-time）验证 vs 随机 CV
| 维度 | 随机 K-fold CV | OOT |
|---|---|---|
| 假设 | 样本 i.i.d. | 时间上可迁移，但允许漂移 |
| 代表什么 | 「同分布下的泛化」 | **上线后的真实表现** |
| 风险 | 泄漏时间信息（用未来数据训练） | 更保守，指标一般更低 |
| 做法 | 随机切 | 按保单生效期/赔付期切：早期训练、最近期验证 |

保险为什么必须 OOT：费率与赔付水平随时间变（通胀、维修价格、法规、理赔流程、销售渠道结构），i.i.d. 假设不成立。

## 💼 保险场景

**某车险公司续保流失模型（示例数据）**：1,000 张到期保单，其中 100 张未续保（事件率 10%）。

按预测风险**从高到低**切 10 组（每组 100 张）：

| 组 | 事件(bad) | 非事件(good) | 组内事件率 | Lift | 累计捕获率 | 累计样本占比 | 累计 %Bad | 累计 %Good | $\lvert$差$\rvert$ |
|---|---|---|---|---|---|---|---|---|---|
| 1（最高风险） | 40 | 60 | 40% | **4.0** | 40% | 10% | 0.400 | 0.067 | 0.333 |
| 2 | 20 | 80 | 20% | 2.0 | 60% | 20% | 0.600 | 0.156 | 0.444 |
| 3 | 12 | 88 | 12% | 1.2 | 72% | 30% | 0.720 | 0.253 | **0.467** ← KS |
| 4 | 8 | 92 | 8% | 0.8 | 80% | 40% | 0.800 | 0.356 | 0.444 |
| 5 | 6 | 94 | 6% | 0.6 | 86% | 50% | 0.860 | 0.460 | 0.400 |
| 6 | 5 | 95 | 5% | 0.5 | 91% | 60% | 0.910 | 0.566 | 0.344 |
| 7 | 4 | 96 | 4% | 0.4 | 95% | 70% | 0.950 | 0.672 | 0.278 |
| 8 | 3 | 97 | 3% | 0.3 | 98% | 80% | 0.980 | 0.780 | 0.200 |
| 9 | 2 | 98 | 2% | 0.2 | 100% | 90% | 1.000 | 0.889 | 0.111 |
| 10（最低风险） | 0 | 100 | 0% | 0.0 | 100% | 100% | 1.000 | 1.000 | 0.000 |
| **合计** | **100** | **900** | 10% | — | — | — | — | — | — |

- **KS = max(累计 %Bad − 累计 %Good) = 0.467**（出现在第 3 组）→ 按经验分档属于「强」。
- 第 1 组 **Lift = 4.0**：只抓最危险 10% 的保单，就能命中 40% 的流失。
- 业务用法：前 2 组（累计 60% 流失）优先做挽留；阈值取在 KS 最大处附近最有区分度。

**监控节奏（示例口径）**：月度看分数分布的 PSI + 各关键变量 CSI；季度看 OOT 上的 KS/Gini 与**校准曲线**。**注意：这些都是行业常见做法，具体频率与阈值各机构不一致。**

## 🛠️ 代码

### SAS

```sas
/* 1) AUC/ROC + KS：outroc= 输出 ROC 坐标 */
proc logistic data=card;
  model y(event='1') = woe_x1-woe_xk / outroc=roc;
  roc;
run;

/* KS = max(sensitivity - (1 - specificity))：OUTROC 里 _SENSIT_ 与 _1MSPEC_ */
data ks;
  set roc end=last;
  retain ks_max 0;
  ks_max = max(ks_max, _sensit_ - _1mspec_);
  if last then output;
  keep ks_max;
run;

/* 2) 十分位 Lift 表 */
proc rank data=scored groups=10 out=deciles;
  var phat;
  ranks decile;                 /* 默认升序：decile=1 是分数最小（最低风险） */
run;
/* 业务表一般从最高风险看起：展示时按 decile 降序，或另算 11 - decile */

proc means data=deciles nway noprint;
  class decile;
  var y;                        /* 单变量时才能这样命名输出统计量 */
  output out=lift n=n_obs sum=n_bad mean=bad_rate;
run;

proc sql;
  select mean(y) into :overall_rate from scored;     /* 整体事件率 */
quit;

data lift;
  set lift;
  if missing(decile) then delete;      /* 去掉汇总行（nway 一般不产生） */
  lift = bad_rate / &overall_rate;
run;
/* 输出怎么读：bad_rate 应从高风险组到低风险组单调下降；不单调说明分箱/模型有问题 */

/* 3) PSI：基准期 vs 当前期，切点用基准期定义（两表结构：bin, pct_exp, pct_act） */
proc sql;
  create table psi as
    select sum((pct_act - pct_exp) * log(pct_act/pct_exp)) as psi
    from dist_cmp;
quit;
/* 输出怎么读：psi<0.1 稳定；0.1-0.25 关注；>0.25 考虑重训（经验值，各机构不一致） */
```

### Python

```python
import numpy as np, pandas as pd
from sklearn.metrics import roc_auc_score, roc_curve
from scipy.stats import ks_2samp

# 1) AUC / Gini / KS
auc  = roc_auc_score(y, p)
gini = 2*auc - 1
fpr, tpr, thr = roc_curve(y, p)
ks = np.max(tpr - fpr)                    # 排序方向：p = 事件概率
ks2, _ = ks_2samp(p[y == 1], p[y == 0])   # 与 CDF 最大差等价
print(auc, gini, ks, ks2)

# 2) 十分位 Lift 表
def lift_table(df, score="phat", y="y", groups=10):
    d = df.copy()
    d["_grp"] = pd.qcut(d[score].rank(method="first", ascending=False),
                        groups, labels=False) + 1        # 1 = 最高风险
    g = d.groupby("_grp").agg(n=("y", "size"), bad=("y", "sum"))
    g["bad_rate"]   = g["bad"] / g["n"]
    g["lift"]       = g["bad_rate"] / d[y].mean()
    g["cum_capture"] = g["bad"].cumsum() / g["bad"].sum()
    g["cum_sample"]  = g["n"].cumsum() / g["n"].sum()
    g["cum_lift"]    = g["cum_capture"] / g["cum_sample"]
    return g

print(lift_table(df).round(3))

# 3) KS 也可以直接从十分位表算（与上面结果一致）
t = lift_table(df)
cdf_bad  = t["bad"].cumsum() / t["bad"].sum()
cdf_good = (t["n"] - t["bad"]).cumsum() / (t["n"] - t["bad"]).sum()
print("KS from table =", (cdf_bad - cdf_good).abs().max())

# 4) PSI（切点用基准期定义，再套到当前期）
def psi(expected, actual, bins=10, eps=1e-6):
    e, a = pd.Series(expected), pd.Series(actual)
    cuts = np.unique(np.quantile(e, np.linspace(0, 1, bins + 1)))
    e_pct = np.histogram(e, bins=cuts)[0] / len(e)
    a_pct = np.histogram(a, bins=cuts)[0] / len(a)
    e_pct, a_pct = np.clip(e_pct, eps, None), np.clip(a_pct, eps, None)
    return float(np.sum((a_pct - e_pct) * np.log(a_pct / e_pct)))

print("PSI(score) =", psi(base["phat"], cur["phat"]))
print("CSI(x1)    =", psi(base["x1"],   cur["x1"]))       # 逐变量即 CSI

# 5) 校准：预测均值 vs 实际发生率
cal = df.assign(bin=pd.qcut(df["phat"], 10, duplicates="drop")) \
        .groupby("bin", observed=True).agg(pred=("phat", "mean"), actual=("y", "mean"))
print(cal)          # 两列应接近；差很多说明需要重标定（如过采样后未修截距）
```

## 🗣️ 面试速答（30 秒）

> 上线前我看三样：**排序**用 KS 和 Gini，$\text{KS}=\max|\text{CDF}_{good}-\text{CDF}_{bad}|=\max(\text{TPR}-\text{FPR})$，$\text{Gini}=2\text{AUC}-1$；**业务可读性**用十分位 Lift 表——按分数从高到低切 10 组，看每组事件率、Lift 和累计捕获率；**校准**看预测均值 vs 实际发生率，这个对保险定价最关键，因为要的是真实频率而不是排序。上线后看稳定性：$\text{PSI}=\sum(\%\text{Actual}-\%\text{Expected})\ln(\%\text{Actual}/\%\text{Expected})$，小于 0.1 稳定、0.1–0.25 关注、大于 0.25 重训；逐变量算就是 CSI。验证方式一定是 **OOT** 而不是随机 CV，因为保险的费率、赔付成本、渠道结构都在随时间漂移。这些阈值都是行业经验值，各家不同。

---

## ⚠️ 常见坑
- **只用随机 CV 报指标**：随机 CV 会泄漏时间信息，报告的数字比上线表现好看；OOT 才是诚实答案。
- **排序方向搞反**：Lift 表按分数**升序**分组时，第一组会是低风险组，Lift 小于 1，容易被误判成模型失效。
- **KS 与 AUC 当成一回事**：KS 只看一个点，AUC 看全曲线；两者不可互相推导。
- **Gini 与决策树 Gini 混用**：一个是排序统计量，一个是不纯度。
- **PSI 切点每期重算**：必须固化基准期切点，否则 PSI 恒为小值，监控失效。
- **PSI 只看总分不看变量**：总分稳定但某个变量已经漂移（如某车型占比翻倍）是常见漏检，要配 CSI。
- **忽略校准**：AUC 0.8 + 校准差 30% 的模型拿去定价 = 直接亏损。
- **保险特有的坑：赔付数据「发展期未满」**。最近几个月的赔案还没报完（IBNR），用它算实际事件率会**系统性偏低**，看起来像「模型高估了」；切 OOT 时要留发展期缓冲，或只用已充分发展的赔案期（LDA Ch11 的链梯法就是干这个的）。
- **样本量幻觉**：KS/PSI 在小样本上波动大，分组（如按地区/车型）后每组可能只有几十条，别把小样本噪声当漂移。
