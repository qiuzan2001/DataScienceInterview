## 📖 标准定义

> **教材原文 · PSL §4.3.1 Boosting、§4.3.3 Discussion（页面 w4_3_gbm.html）**（<https://liangfgithub.github.io/PSL/w4/w4_3_gbm.html>）
> > "At its core, boosting is a forward stage-wise greedy algorithm aimed at solving an additive model. An additive model consists of ‘T’ functions, $F(x) = f_1(x) + f_2(x) + \cdots + f_T(x)$ and you can think of each function as corresponding to a regression tree."
> >
> > "However, a word of caution: boosting can easily lead to overfitting. This is why regularization is critical. In Gradient Boosting Machines (GBM) or Extreme Gradient Boosting (XGBoost), packages for boosting, one of the key regularization parameters is the learning rate, ‘eta’, which shrinks the contribution of each individual tree."
> >
> > "From an optimization standpoint, you could also view ‘eta’ as the “learning rate” that governs how big a “step” the algorithm should take in the optimal direction."
> >
> > "It’s worth noting that the choice of T is often inversely related to the learning rate eta. Specially, a smaller learning rate generally necessitates a larger T for the model to effectively learn and generalize."
> >
> > "When it comes to the complexity of the individual trees, i.e., their depth, it’s advisable to keep them relatively shallow, as boosting is designed to work with weak learners."
> >
> > "Now, comparing GBM and RandomForest: RandomForest boasts fewer tuning parameters. GBM has more. However, with the right tuning, GBM can outperform RandomForest."

**标准记法**：加性模型 $F(x) = f_1(x) + f_2(x) + \cdots + f_T(x)$；第 $t$ 步把树加到当前模型上，$F_t(x) = F_{t-1}(x) + \eta\, f_t(x)$，$f_t$ 拟合当前残差（梯度提升下为伪残差）。（$F_t = F_{t-1} + \eta f_t$ 是通用形式；PSL §4.3.1 原文写作「Add the tree to the target function F(x)」并把 $\eta$ 描述为收缩每棵树贡献的学习率。）

**中文解释**：GBM 是前向分步的贪心算法：每一步用一棵小树去拟合当前残差并加到模型里。$\eta$ 收缩每棵树的贡献，既是学习率也是防过拟合的正则化；$\eta$ 小则需要的树数 $T$ 大（反向关系），树要浅（弱学习器），还可以加子采样。RF 调参更少更稳，GBM 调好了通常更强——PSL 的原话。

> 完整条目与更多来源见 [[定义原文库#C14. GBM / 学习率 eta / 调参要点|C14. GBM / 学习率 eta / 调参要点]]

Boosting 这一族，整体上是在建一个**加性模型（additive model）**

$$
F_M(x)=\sum_{m=1}^{M}\beta_m\,h_m(x)
$$

每次只拟合一个**基学习器（base learner）** $h_m$。
在 **AdaBoost** 里你已经见过一种具体配方：

* **损失（loss）**　固定（指数损失）
* **β 权重（β-weights）**　有闭式解
* **重赋权（re-weighting）**　由损失隐式完成

**Gradient Boosting（GB）** 保留了同样的*加性*味道，但把 AdaBoost 那套僵硬的机制换成了一个**通用的「函数空间里的最速下降（steepest-descent in function space）」** 视角。
就这一处改动，让我们可以：

* 优化**任意可微损失（any differentiable loss）**（平方误差、logistic、Huber、分位数……）；
* 用**任意基学习器**（树、线性规则、样条，甚至神经网络）；
* 通过**学习率（learning rate）**和其他正则化手段来*控制过拟合*。

---

### 1 | 从 AdaBoost 到 Gradient Boosting 的四步（From AdaBoost to Gradient Boosting）

| AdaBoost 里的概念                            | Gradient Boosting 的推广                                      |
| ------------------------------------------- | --------------------------------------------------------------------- |
| 指数损失 $e^{-yF}$                  | **通用可微损失** $L(y,F)$                              |
| 闭式解 $\alpha_t$                      | **数值线搜索（numerical line search）**（或固定的小步长）                       |
| 用损失导数更新权重 $D_{t+1}$ | **损失的梯度**给出残差 / 伪响应（pseudo-responses）               |
| 二分类标签 $\pm1$                        | 回归或分类（概率）都能直接支持 |

所以可以这样记：「**AdaBoost = 用指数损失 + 极小决策树桩的 gradient boosting**。」

---

### 2 | 核心数学：函数空间里的梯度下降（Gradient Descent in Function Space）

1. **目标（objective）**：最小化

   $$
   \mathcal{L}(F)=\sum_{i=1}^{N}L\bigl(y_i,\;F(x_i)\bigr)
   $$

   其中 $L$ 对第二个参数是任意可微损失。

2. **把 $F$ 看成一个（巨大的）函数空间里的点。**
   训练点上 $\mathcal{L}$ 对 $F$ 的**负梯度（negative gradient）**是

   $$
   r_{im}=-\left.\frac{\partial L(y_i,F)}{\partial F}\right|_{F=F_{m-1}(x_i)}
   $$

   这些 $r_{im}$ 就叫**残差（residuals，回归情形）**或**伪响应（pseudo-responses，分类情形）** —— 也就是**伪残差（pseudo-residual）**：负梯度。

3. **最优下降方向（best descent direction）**：拟合一个基学习器 $h_m(x)$ 去逼近这些残差：

   $$
   h_m \approx \arg\min_{h\in\mathcal{H}}\sum_{i=1}^{N}\bigl(r_{im}-h(x_i)\bigr)^2
   $$

4. **线搜索 / 步长（line search / step size）**：求

   $$
   \beta_m=\arg\min_{\beta}\sum_{i=1}^{N}L\bigl(y_i,\;F_{m-1}(x_i)+\beta\,h_m(x_i)\bigr)
   $$

   （常简化为一个**收缩因子（shrinkage factor）** $\nu$，例如 $\beta_m=\nu$。）

5. **更新加性模型（update additive model）**：

   $$
   F_m(x)=F_{m-1}(x)+\beta_m h_m(x)
   $$

对 $m=1,\dots,M$ 重复。

---

### 3 | 具体损失长什么样（Connecting the Dots with Concrete Losses）

#### 3.1  **平方误差损失（Squared-Error Loss）**　（经典回归）

*损失*　$L(y,F)=\tfrac12(y-F)^2$
*梯度*　$r_{im}=y_i-F_{m-1}(x_i)$（就是通常意义上的残差）
于是每一轮 boosting：

1. **拟合 $h_m$** 到普通残差上。
2. **线搜索**有闭式解：$\beta_m=1$。
   结果：**Gradient Boosting = 逐步加性回归（stage-wise additive regression）**（也就是 Friedman 的 MART）。

#### 3.2  **Logistic 损失（Logistic Loss）**　（概率层面的分类）

*损失*　$L(y,F)=\ln\!\bigl(1+e^{-2yF}\bigr)$
（其中 $y\in\{\pm1\}$，所以 $F$ 是 log-odds 的一半。）
*梯度*　$r_{im}= \frac{2y_i}{1+e^{2y_iF_{m-1}(x_i)}}$
这样得到的是一批「软残差（soft residuals）」，落在 $-2$ 与 $+2$ 之间。

用这个损失去 boosting **决策树**，正是主流库（XGBoost、LightGBM、CatBoost）做分类时在干的事。

### 4 | 算法速查（Algorithm Cheat-Sheet）

```
Input : {(x_i, y_i)}, differentiable loss L, base-learner family H,
        learning rate ν (0<ν≤1), rounds M
Init  : F_0(x) = argmin_c Σ_i L(y_i, c)      # e.g. mean(y) for squared error
for m = 1 … M:
    # 1. Compute negative gradient (pseudo-residuals)
    r_im = -∂L/∂F |_{F=F_{m-1}(x_i)}   for i=1…N
    # 2. Fit base learner to residuals
    h_m = argmin_{h∈H} Σ_i (r_im - h(x_i))^2
    # 3. Step size
    β_m = argmin_β Σ_i L(y_i, F_{m-1}(x_i)+β h_m(x_i))
          (often β_m←ν if expensive to solve)
    # 4. Update model
    F_m(x) = F_{m-1}(x) + β_m h_m(x)
Output: F_M(x)   # use argmax/ sign/ identity depending on task
```

### 5 | 为什么用树？（Why Trees? — Gradient-Boosted Decision Trees, GBDT）

* 浅树（深度 3–8）几乎不用特征工程就能捕捉**非线性交互（non-linear interactions）**。
* 每棵树只修正*当前的误差* → 集成整体保持灵活，同时避免单棵树长得巨大。
* 训练与推断在特征维、样本维上都容易并行。

现代变体（XGBoost、LightGBM、CatBoost）额外加了：

| 技巧                                | 目的                                          |
| ------------------------------------ | ------------------------------------------------ |
| 直方图 + GPU 分裂点查找        | 更快、更省内存                                   |
| 列采样 + 行采样 | 进一步降方差（随机森林那一味） |
| 叶节点上的 $L_1/L_2$ 正则   | 收缩过于具体的叶节点取值               |
| 单调约束 / 类别特征处理 | 注入领域知识、支持类别变量 |

### XGBoost 相对传统 GBM 加了什么

**算法层（algorithmic）**

* **正则化目标（regularized objective）**：在损失函数里**显式加入对叶节点权重的 L1/L2 惩罚**——正则化成为优化的一部分，而不是事后加的。
* **二阶（牛顿）优化（second-order / Newton）**：同时用梯度与**海森矩阵（Hessian）**，叶节点取值与分裂增益算得更准，**迭代更少就收敛**。
* **原生稀疏 / 缺失值处理（native sparsity-aware split finding）**：每个分裂为缺失值**学一个默认方向**，不需要插补。
* **加权分位草图（weighted quantile sketch）+ 直方图分箱**做近似分裂查找，替代逐点扫描候选分裂点。
* **深度优先生长后再按 `gamma` 剪枝**，而不是每个节点贪心早停——因此**能发现藏在一次坏分裂后面的好分裂**。

**工程层（engineering）**

* 并行化分裂查找、缓存友好访问（cache-aware access）、**超内存数据的 out-of-core 计算**、分布式训练、GPU 支持。

**实用层（practical）**

* 内置 CV 与早停；**单调约束与交互约束（monotonic / interaction constraints）**；**目标函数库包含 Poisson、Gamma、Tweedie**。

> 再补一句：**LightGBM 加了 leaf-wise 生长、GOSS 采样、原生类别处理，大数据上通常更快；CatBoost 加了 ordered boosting（对抗目标编码的泄漏）和最强的类别处理。**

> 来源：MAGNet §9（Q: What does XGBoost add over traditional GBM?）；[[MAGNet 面试真题全解]]

### 单调约束（monotone constraints）的监管意义

`monotone_constraints` 强制某个变量的效应**单调（monotone）**——**这是让 GBM 能被监管接受的关键手段**：模型仍然非线性，但方向不可能反直觉，费率表不会出现「更安全反而更贵」。

这也是防过拟合清单的第 8 条：**单调约束 = 注入真实先验知识，是「不损失可信度」的正则化（regularization that costs you nothing in credibility）**。

落地衔接（评分卡 / WOE 侧的同类做法）：[[10.4 评分卡与 WOE 落地]]。

> 来源：MAGNet §9；[[MAGNet 面试真题全解]]

### GBM 防过拟合的 8 步清单（按影响力排序）

1. **在验证集上早停（early stopping）** —— 最重要的一个。
2. 低学习率 + 更多树（`learning_rate` ↓、`n_estimators` ↑）—— 二者成对调。
3. 浅树（`max_depth` 3–6）。
4. `min_child_weight` —— 别让叶节点太小。
5. `subsample` + `colsample_bytree` —— 随机性。
6. 叶权重的 L1/L2 惩罚 + `gamma` 剪枝。
7. 每个调参决策都用**交叉验证**，而不是单次划分。
8. **单调约束** —— 注入真实先验知识的正则化。

> 来源：MAGNet §9（Q: How do you keep a GBM from overfitting?）；[[MAGNet 面试真题全解]]


### Q: How does GBM compute variable importance?

> 🎯 真题问法（MAGNet §9）｜ 深潜来源：MAGNet §9 Variable importance ＋ [[7. Random Forest]] §4「Quantifying Feature Importance」＋ [[10.4 评分卡与 WOE 落地]]

> ⚡ 先说的那一句
> 「GBM 默认报的是 **gain** —— 该特征所有分裂带来的**损失总改进**（平方误差损失下就是 H2O 报的 squared error improvement）；**cover 是次要的，weight / frequency 偏向高基数连续变量、不要引用**；**要方向就上 SHAP**。」

| 度量 | 是什么 | 评价 |
|---|---|---|
| **gain** | 该特征所有分裂带来的**损失总改进**。平方误差损失下就是 H2O 报的「squared error improvement」 | **默认，也是要引用的那个** |
| **cover** | 该特征的分裂**触碰到的观测数** | 次要 |
| **weight / frequency** | 该特征被用来分裂的**次数** | **偏向高基数连续变量，不要引用这个** |
| **Permutation** | 打乱该特征后**样本外**性能的下降 | 模型无关；**相关特征下不可靠** |
| **SHAP** | 逐记录的**加性归因** | **现代答案** |

**要划出的区别**：**gain 告诉你某特征贡献了多少，但不告诉方向**；**SHAP 给大小也给方向**，能落到**单条记录级别**（因此可以解释**一次具体的拒保或一次具体的费率**），并支持**依赖图与交互图**。**如果问「怎么向监管或客户解释树模型」→ SHAP + 单调约束。**

**同样的 caveat 三连**：**相关特征分摊贡献**、**重要性不是显著性**、**都不是因果**（呼应 [[7. Random Forest]] 里 MDI 偏向高基数变量的那条）。

> 🔗 会被追问到
> - 「**gain 高就说明该进 GLM 吗？**」→ 不能直接进：**gain 不区分子效应、不给方向、高基数变量占优**；进 GLM 前要在 **WOE / 单变量经验图**上确认方向与单调性（见 [[5.3 Multivariate Selection]]）。
> - 「**相关特征怎么办？**」→ 用**分组重要性（grouped / clustered importance）**：把相关变量归成一组后整体打乱；或直接读 **SHAP 依赖图**看谁在承担信号。
> - 「**SHAP 会不会自相矛盾？**」→ 相关特征下 SHAP 也会**分摊**、且依赖背景分布；但它是**一致（consistent）**的加性归因，仍是**逐记录解释**的首选。
> - 「**监管要方向怎么办？**」→ **`monotone_constraints` + SHAP**：单调约束保证方向不反直觉，SHAP 解释单条决策（见上「单调约束的监管意义」）。
> - 「**重要性稳定吗？**」→ 换折 / 换种子后应大致稳定；**排名剧烈变化 = 特征不稳定**，要报告多折重要性的分布，而不是单次跑出来的排名。

### 6 | 与 AdaBoost 的关系一览（Relationship to AdaBoost at a Glance）

| 方面                     | AdaBoost                               | Gradient Boosting                             |
| -------------------------- | -------------------------------------- | --------------------------------------------- |
| 损失                       | 指数损失                            | **任意**可微损失（也含指数损失） |
| 步长 $\beta_m$        | 闭式解 $\tfrac12\ln\frac{1-e}{e}$ | 数值线搜索 / 常数收缩      |
| 基学习器的关注点         | 通过样本权重隐式体现            | 通过残差显式体现                        |
| 典型基学习器       | 决策树桩（decision stump）                         | 更深的树（或其他）                      |
| 对异常值的敏感度        | 高（权重会爆炸）                 | 取决于损失（Huber、分位数更稳健）  |
| 可解释性（M 小的时候） | 高（只有几个树桩）                       | 中等（有很多棵小树）                   |

AdaBoost 是**一个特例（special case）**：指数损失 + 步长有精确解 + 用权重视角而不是残差视角。

### 7 | 实用超参数与建议（Practical Hyper-parameters & Tips）

| 旋钮                                  | 典型范围    | 作用 / 建议                                             |
| ------------------------------------- | ---------------- | ----------------------------------------------------------- |
| **学习率（learning rate）$\nu$**               | 0.01 – 0.3       | 越小 ⇒ 需要更多轮，但泛化往往更好。 |
| **轮数（number of rounds）$M$**              | 100 – 10 000     | 与 $\nu$ 一起调。在验证损失上早停。     |
| **树深（tree depth）**                        | 3 – 8            | 深度 = 能捕捉的交互阶数。                         |
| **min\_child\_weight / 每个叶节点的样本数** | 因库而异 | 防止叶节点太小（起正则化作用）。                          |
| **行采样 Subsample（rows）**                  | 0.5 – 1 ／ 真题 **0.5 – 0.8** | 增加随机性、抗过拟合、加速训练。            |
| **列采样 Colsample（features）**              | 0.5 – 1 ／ 真题 **0.5 – 0.8** | 宽数据集上有帮助。                                    |

**`subsample` / `colsample` 的区间口径（MAGNet §9）**：**库内表写 0.5–1；真题常用 0.5–0.8，面试按后者更稳。**

* **`subsample`（行采样）**：每棵树的**行采样**（0.5–0.8）→ **随机梯度提升（stochastic gradient boosting）**，**降方差并加速训练**。
* **`colsample_bytree` / `_bylevel` / `_bynode`（特征采样）**：**RF 式的去相关（decorrelation）**，宽数据集上尤其有用。

**树深 = 交互阶数（MAGNet §9）**：`max_depth` 控制模型能表达的**交互阶数（interaction order）**——**深度 d 最多允许 d 阶交互**；**`depth 1`（stump）给出一个纯加性模型（purely additive model，无任何交互）**。这个框架是很强的回答点。

**`gamma` / `min_split_loss`**：做一次分裂所需的**最小损失下降（minimum loss reduction）**，用于**剪掉弱分裂（prune weak splits）**。

> 来源：MAGNet §9；[[MAGNet 面试真题全解]]

**工作流程（workflow）**：先用网格搜索定 $(\nu, M)$，再微调树结构与采样类参数。

### Q: What's your tuning strategy?

> 🎯 真题问法（MAGNet §9）｜ 深潜来源：MAGNet §9 Tuning strategy ＋ 本文件 §7 超参表 ＋「GBM 防过拟合的 8 步清单」

> ⚡ 先说的那一句
> 「我给的是**有序配方**，不是一张清单：**先固定 `learning_rate = 0.1`、用早停找到合理树数拿到快速基线；再调树复杂度；然后随机性；然后正则化；最后把学习率降到 0.01–0.05、配更多树 + 早停榨出最后几个点**。第 2–4 步用**随机搜索或贝叶斯优化**跑，而不是全网格，**始终配 CV 与早停**。」

1. **固定 `learning_rate = 0.1`**，在验证集上用**早停（early stopping）**找出合理的树数。**快速基线。**
2. **调树复杂度**：**`max_depth`（或 `num_leaves`）与 `min_child_weight` 一起调** —— **它们才是主要的偏差/方差旋钮**。
3. **调随机性**：**`subsample` 与 `colsample_bytree`**（常用 0.5–0.8）。
4. **调正则化**：**`gamma`、`reg_lambda`、`reg_alpha`**。
5. **最后把学习率降到 0.01–0.05**，配**更多树 + 早停**，榨出最后几个点。
6. **用随机搜索或贝叶斯优化跑第 2–4 步**，而不是全网格；**始终配 CV 与早停**。

**为什么是这个顺序**：学习率与树数**成对**（`learning_rate` 减半 → 树数约翻倍），所以**先把它固定住**，其它参数才可比；**先动偏差/方差主旋钮（深度、叶节点大小），再动随机性与正则化**（后两者只做微调）。

> 🔗 会被追问到
> - 「**为什么不直接搜学习率？**」→ 学习率与树数**互相决定**，同时搜会让网格**乘起来**；先用 0.1 拿到可比基线，最后再用低学习率**榨点**。
> - 「**早停会不会泄漏验证集？**」→ 会引入**轻微**乐观偏差（验证集参与了停止点选择），所以**最终仍要一个未动过的测试集**；调参很密集时用**嵌套 CV**。
> - 「**`max_depth` 和 `min_child_weight` 为什么一起调？**」→ 一个**自上而下**限制复杂度，一个**自下而上**限制叶节点噪声；单独调任何一个都可能被另一个掩盖。
> - 「**换 LightGBM 怎么改？**」→ 把 `max_depth` 换成 **`num_leaves`**（leaf-wise 生长下的容量主旋钮），并把叶节点最小样本设成 `min_data_in_leaf`。
> - 「**调参调不出提升怎么办？**」→ 先怀疑**特征与切分**（out-of-time、泄漏、目标定义），再怀疑参数；调参是最后 1–2 个点的手段，不是前 5 个点。

#### 7.1 几个必记的工程细节（PSL §4.3）

* **$\eta$（= 上面的 $\nu$）的意义**：学习率 / 步长（shrinkage）。**树数 $M$ 与 $\eta$ 大致成反比**——$\eta$ 越小，每步走得越短，需要的树越多（$\eta=0.1$ 常配几百棵，$\eta=0.01$ 常需几千棵）。
* **树必须浅**：GBDT 的基学习器是**弱学习器**（深度 3–8，常见 4–6）。单棵树高偏差，靠多轮加性修正补回来；树一深，方差立刻上来。
* **子采样**：现代实现（`gbm` / XGBoost / LightGBM）默认做行采样（stochastic gradient boosting，0.5–1）与列采样，用来抗过拟合、加速训练。
* **调参成本对比**：Random Forest **调参少**（`n_estimators` / `max_features` / `max_depth`，对超参数不敏感、开箱即用），GBM **调参多**（$\nu$、$M$、树深、子采样、正则项都要管），但**调好之后通常比 RF 更强**。
* **工程限制（类别特征）**：R 的 `randomForest` **不能处理超过 32 个水平的类别变量**；`gbm` 的上限是 **1024** 个水平；**XGBoost 只接受数值输入**（类别要先做 one-hot / WOE / target encoding）。这三点是"模型能不能直接喂原始类别列"的常见面试考点。

### 8 | 手算小例（平方误差 + 深度 1 的树）

| $x$ | $y$ |
| --- | --- |
| 1   | 5   |
| 2   | 7   |
| 3   | 6   |
| 4   | 10  |

**第 0 轮（Round 0）**　$F_0$ = 均值 = 7.0
残差 $r_{i1}=y_i-7=[-2,0,-1,3]$

**拟合树桩 $h_1(x)=\begin{cases}6.0 & x<3\\8.5&x\ge 3\end{cases}$**（最小二乘在 $x=3$ 处切分）
学习率 $\nu=0.1$ ⇒ $\beta_1=0.1$

更新
$F_1(x)=7+0.1\,h_1(x)$（做了收缩）

重复：算出新的残差 $y−F_1$，再拟合一个小树桩，如此往复。
大约 100 轮之后，这一组浅树的集成就能以很低的方差把这个模式抓住了。

### 9 | 优点与缺点（Strengths & Weaknesses）

| **优点（Pros）**                                                          | **缺点（Cons）**                                                         |
| ----------------------------------------------------------------- | ---------------------------------------------------------------- |
| 能处理多种损失；回归与分类通用。 | 训练是串行的 ⇒ 在 $M$ 很大时比 bagging 慢。 |

### 10 | 关键结论（Key Takeaways）

1. **与 AdaBoost 同一种加性精神**，只是由*梯度*驱动，而不是固定的公式。
2. **换替代损失 = 控制模型行为**（平方损失 → 预测均值，logistic → 输出概率，等等）。
3. **残差拟合的视角**让 GB 既好理解又好实现。
4. **收缩（shrinkage）+ 很多棵小树** > 少数几棵大树 —— 这是偏差-方差的那个甜点。
5. 现代库加了很多工程技巧，但*心脏*仍然是：

> *算梯度 → 用它拟合一个学习器 → 迈一小步。*

把这个循环吃透，你不仅能把 Gradient Boosting 讲清楚，也能顺带理解它那些工业化后代：**XGBoost、LightGBM、CatBoost**，甚至 **Gradient-Boosted Neural Nets**。

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Gradient boosting is steepest descent in function space. We keep an additive model — F sub m equals F sub m minus one plus beta times h sub m — and at each round we fit a base learner to the negative gradient of the loss, which are the pseudo-residuals."

**Mechanism**

> "It generalises AdaBoost: exponential loss and a closed-form step size is one special case, but here any differentiable loss works. For squared error the pseudo-residual is the ordinary residual; for logistic loss you get soft residuals between minus two and plus two. With shrinkage the step is just nu, and the number of rounds is roughly inversely related to it — small eta, many trees."

**If they push back**

> "A common pitfall is growing deep trees. The base learner has to stay weak — depth three to eight, often four to six — because the bias gets chipped away over many rounds, and a deep tree brings the variance straight back. And one caveat on tuning: I'd early-stop on a validation set rather than fix the number of rounds in advance, because eta and the number of rounds have to be tuned together."
