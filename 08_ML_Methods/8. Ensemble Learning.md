# 8 集成学习（Ensemble Learning）

## 速览 At a glance

**速记**

一个模型出错有两个来源：换一份训练数据预测就跳（方差），或者怎么换数据都稳定地偏（偏差）。集成学习按这两个来源分工，三个家族各修各的：**bagging** 从同一份数据里抽 B 个有放回样本、各训一棵深树再平均，它只能压方差 —— 深树的偏差本来已经很低，平均不会把预测均值推向真值，只是收紧散布；**boosting** 串行地一棵一棵加浅树，每棵新树拟合「当前集成还没修掉的那部分误差」，压的是偏差，代价是训练不能并行、轮数与学习率必须设闸；**stacking** 不重采样也不纠错，它把几个异质模型的**折外**预测当特征，再训一个元模型学「什么时候该信谁」。三者共用一个前提：基模型不能在同一处犯错。5 个各自 70% 准确的模型，错误独立时多数投票准确率 83.69%；若 20% 的样本上它们一起错（每个模型边际准确率仍是 70%），集成只剩 78.72%；共同错误吃满单个模型全部错误的三成时，集成与单模型打成平手。

**一句面试答法**

> "Ensembles combine several base models, and the three families fix different terms. Bagging resamples the data, trains models in parallel and averages them, which only cuts variance. Boosting adds shallow models sequentially on what the current ensemble still gets wrong, which mainly cuts bias. Stacking feeds the out-of-fold predictions of several different models into a meta-learner."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 集成 | ensemble | 多个基模型的组合 |
| 基学习器 | base learner | 被集成的单个模型 |
| 偏差 | bias | 系统性偏离，换数据也去不掉 |
| 方差 | variance | 换一份训练数据预测变化的幅度 |
| 装袋 | bagging / bootstrap aggregating | 有放回抽样 + 平均，降方差 |
| 提升 | boosting | 顺序纠错，降偏差 |
| 堆叠 | stacking / stacked generalization | 折外预测当特征，再训元模型 |
| 折外预测 | out-of-fold prediction (OOF) | 由没见过该行的模型给出的预测 |
| 元学习器 | meta-learner | stacking 第二层的模型 |
| 多样性 | diversity | 基模型不在同一处犯错 |
| 收缩 | shrinkage | 每轮只走一小步，靠轮数补回来 |
| 袋外样本 | out-of-bag (OOB) | 某次 bootstrap 没抽中的那些行 |

## 一、先看一个问题

面试官的原话就四个词：**"Bagging vs. boosting vs. stacking."** 背三段定义也能说完，但这句话真正在考的是：**三个词分别在修哪一个误差项**。

看一份具体成绩单。你有 300 万行保单，先跑了一棵不剪枝的深树：训练集 AUC 0.86，五折交叉验证 AUC 0.74。再换成深度 2 的浅树：训练 AUC 0.68，交叉验证 AUC 0.67。

两张成绩单指向两个不同的问题：

- 第一棵树的**训练与验证差 12 个点**。它的预测均值没有跑偏，是每一份数据拟合出的那棵树不一样 —— 方差问题。
- 第二组模型的**训练本身只有 0.68**。换哪份数据都差不多低 —— 偏差问题。

决定用哪种集成，不需要先试一遍模型。看诊断就能定方向：方差 → 用平均把多份模型凑起来（bagging）；偏差 → 一轮轮纠错（boosting）。两个误差项都不突出、而是「几种不同类型的模型各有各的看法」时，才轮到 stacking。

三条路都能让指标上去一点，但上去的原因完全不同，代价也不同。所以先把两个误差项拆开看。

## 二、核心直觉

### 三个词分别在修什么

| 方法 | 机制一句话 | 动的是哪个误差项 | 为什么是它 |
|---|---|---|---|
| bagging | 有放回抽 B 份数据，各训一个模型，再平均 | 方差 | 基模型是深树，偏差已经很低；平均只收紧散布，不动均值位置 |
| boosting | 一个接一个加浅模型，每个拟合当前集成没修掉的残差 | 偏差 | 单棵浅树高偏差，但系统性误差被一轮轮啃掉 |
| stacking | 几个异质模型的折外预测当特征，再训元模型 | 取决于元学习器够不够简单 | 它学的是「哪种模型在哪种区域更可信」，这一层自己不能太强 |

三者的共同命门是**多样性（diversity）**：每个基模型都在同一处犯错，投票多少轮都是那个错。bagging 用重采样造多样性，boosting 用「难样本权重上升」把后续模型的注意力挪开，stacking 用换算法、换特征空间造多样性。手法不同，目标一样 —— 让错误不重合。

### bagging 像什么、不像什么

像一个 100 人的气象员小组各自写下明天的气温，再取平均。**像的地方**：个体的随机抖动会在平均里相互抵消。**不像的地方**：气象员的错误大致独立，而同一份数据上长出来的两棵深树不是 —— 强预测变量会反复主导分裂，两棵树长得像、错的样本也像。所以平均能压掉的部分比「完全独立」小得多，压不干净的那一块由树之间的相关性决定，这也是随机森林要抽特征的原因（见 [[8.3. Bagging (Bootstrap Aggregating)]]）。

### boosting 像什么、不像什么

像校对：第一遍通读标出错别字，第二遍专盯这些地方。**像的地方**：注意力确实一轮轮压到还没修好的样本上。**不像的地方**：校对只要把错字改对就行；boosting 每一步改的是整个函数的取值，一步迈大了会连原本对的样本一起弄坏。所以要小学习率加早停，而不是一次改到位。

### 集成给的三个好处，分别有条件

- **精度**：前提是基模型与集成之间的错误别重合。错误完全重合时精度一点不提。
- **稳健**：对训练集里的噪声与离群点没那么敏感 —— 这条对 bagging 成立，对 AdaBoost 反而相反（难样本权重会越滚越大）。
- **泛化**：只在基模型本身的假设没错时成立。所有树都用同一个错误假设时，集成会把这个假设学得更稳，错得也更稳。

## 三、机制

### 3.1 三个家族的模型形式

**bagging（回归取平均，分类取多数投票）：**

$$
\hat{f}(x) = \frac{1}{B}\sum_{b=1}^{B} f_b(x),
\qquad
\hat{y}(x) = \operatorname{mode}\bigl\{f_1(x),\ f_2(x),\ \dots,\ f_B(x)\bigr\}
$$

- $f_b$：在第 $b$ 个 bootstrap 样本（有放回抽 $n$ 个点）上训出来的基学习器。
- $B$：抽的份数，也就是模型个数。
- 式子里**没有权重**：每个 $f_b$ 地位相同，因为它们抽自同一个数据分布。

**boosting（加性模型）：**

$$
F_M(x) = F_0(x) + \sum_{m=1}^{M}\nu\,h_m(x)
$$

- $F_0$：初始常数预测，回归下取目标均值。
- $h_m$：第 $m$ 轮加进来的弱学习器（常用浅树）。
- $\nu$：学习率 / 收缩系数（shrinkage），$0<\nu\le1$。
- 与 bagging 的实质差别在**依赖结构**：训练 $h_m$ 用到了 $F_{m-1}$，所以 $h_1,\dots,h_M$ 互相不独立，这一族天生不能并行。

**stacking（元学习）：**

$$
\tilde{y} = g\bigl(z_1(x),\ z_2(x),\ \dots,\ z_K(x)\bigr)
$$

- $z_k(x)$：第 $k$ 个基模型对 $x$ 的**折外预测**，横跨全部样本拼成一列，成为元特征。
- $g$：第二层的元学习器（逻辑回归、小 GBM 等），通常刻意选简单的。
- 整个设计的关键在 $z_k$ 的来源：必须由**没见过这一行**的模型给出。

### 3.2 bagging 为什么降方差：关键一步在相关性

设每个单独预测器 $f_b(x)$ 的方差都是 $\sigma^2$，任意两个之间的相关系数是 $\rho$，那么平均后的方差是

$$
\operatorname{Var}\Bigl(\frac{1}{B}\sum_{b=1}^{B} f_b(x)\Bigr)
= \rho\,\sigma^2 + \frac{1-\rho}{B}\,\sigma^2
$$

逐项读：

- $\sigma^2$：单个基学习器的方差。
- $\rho$：两两相关系数（平均），衡量「它们是不是一起犯错」。
- 第一项 $\rho\sigma^2$：与 $B$ 无关的部分。
- 第二项 $(1-\rho)\sigma^2/B$：随 $B$ 一起缩小的部分。

**关键一步**：当 $B\to\infty$ 时，第二项消失，但第一项不动。$B$ 从 1 加到 100，方差不会归零，只会逼近 $\rho\sigma^2$。代入 $\sigma^2=1$：$\rho=0$ 时 $B=100$ 给出 0.010；$\rho=0.9$ 时给出 0.901 —— 树多了 100 倍，方差只从 1.000 降到 0.901。

由此得到两条操作结论：**树数 $B$ 治不了相关性**；要再降方差只能去压 $\rho$，这正是随机森林在每次分裂时只从随机抽出的 $m$ 个特征里挑分裂的原因。

### 3.3 boosting 为什么降偏差

**函数空间的视角**：把每个训练点的预测值看成一个坐标，整个模型 $F$ 就是函数空间里的一个点。损失函数 $L$ 在这空间里也有梯度，负梯度方向就是让损失下降最快的方向。第 $m$ 轮做的事：

1. 算每个点的负梯度（平方损失下就是普通残差 $y_i-F_{m-1}(x_i)$）。
2. 训一个弱学习器 $h_m$ 去拟合这些残差。
3. 沿这个方向走一小步：$F_m = F_{m-1} + \nu h_m$。

**关键一步**：新学习器拟合的是 $F_{m-1}$ **还没修掉的那部分系统性误差**，不是原始目标。所以每加一棵树，偏差就掉一块；树浅不要紧，因为深度欠下的那部分由轮数补回来（浅树单棵高偏差，靠 $M$ 轮累积才把偏差压下去）。

对偏差的效果和对树数的关系，正好和 bagging 相反：bagging 的曲线在十几个模型之后就基本平了，boosting 的偏差随轮数持续下降 —— 这也是它更容易过拟合的原因，训练后期每轮都在拟合越来越细的残余，噪声也在里面。

### 3.4 stacking 的折外流程与几个口径

流程（$k$ 折）：

1. 把训练集切成 $k$ 折。
2. 对每个基模型：用其中 $k-1$ 折训练，在留出的那一折上预测，把这些预测记下来；跑完 $k$ 轮后，这个模型对**全部训练样本**都有一条「它没在这条上训练过」的预测 —— 这就是折外预测。
3. 把所有基模型的折外预测按列拼起来，配上真实标签，构成元特征矩阵。
4. 在这个新矩阵上训练元学习器。
5. 预测新数据时，先用**全部**训练数据重新训练每个基模型，再用它们对新样本的预测喂给元学习器。

第 5 步是常见口径分歧点：训元学习器时基模型只看过 $k-1$ 折，出预测时基模型看过全量数据，两套模型的预测分布并不完全一致，所以基模型要不要在全量上重训，得明确写下来。

**blending 与完整 stacking 的区别**：blending 只切一份固定的留出集，元特征来自这一份留出集，实现简单，但留出集小的时候元模型学不准、也没用完数据；$k$ 折 stacking 把每一行都用上，代价是训练和调参更复杂。

### 3.5 三类方法的工程对照

| 维度（Aspect）                 | Bagging                                        | Boosting                                             | Stacking                                               |
| ---------------------- | ---------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------ |
| **Bias Reduction**（是否降偏差）     | 否                                             | 是                                                  | 取决于元学习器                                |
| **Variance Reduction**（是否降方差） | 是                                             | 有条件：学习率小 + 树浅 + 早停 → 可控或下降；无正则化轮数过多 → 上升 | 是                                                    |
| **Parallelizable**（可并行性）     | 完全可以                                          | 有限（只有树内部能并行）               | 中等（基学习器之间可并行）           |
| **Complexity**（复杂度）         | 低                                             | 中到高                                          | 高                                                   |
| **Typical Use-Cases**（典型场景）  | 高方差的基学习器（例如深树） | 降偏差是关键时；处理偏斜数据 | 想把多种模型组合起来冲最好效果时 |

### 3.6 三类方法共用的实操旋钮

1. **数据预处理**：三者都受益于特征缩放、缺失值处理和类别变量编码。
2. **超参数**：
   - Bagging / Random Forest：树的数量、最大深度、特征子集大小。
   - Boosting：学习率、树的数量、树深、正则化参数。
   - Stacking：基学习器 / 元学习器的选择、折数、用 blending 还是完整 stacking。
3. **过拟合控制**：交叉验证监控性能；boosting 上做早停；剪枝或限制树深。
4. **可解释性**：单棵决策树可解释，集成整体不可解释；用 SHAP 或 permutation importance 补。

## 四、算一遍：多数投票什么时候真的有用

用二分类投票，因为这一步能闭式算出来。

### 设定

5 个基模型，每个单独准确率 0.70，且**错误相互独立**。多数投票（5 票里至少 3 票）出错意味着至少 3 个模型同时错。

### 第 1 步：写出投票出错的概率

为什么用二项分布：每个模型独立地以 0.30 的概率出错，5 个模型里错的个数服从 $B(5, 0.3)$。

$$
P(\text{投票错}) = \sum_{k=3}^{5}\binom{5}{k}0.3^{k}0.7^{5-k}
$$

逐项算：

| $k$（错的模型个数） | $\binom{5}{k}$ | $0.3^k$ | $0.7^{5-k}$ | 这一项的贡献 |
|---|---|---|---|---|
| 3 | 10 | 0.027 | 0.49 | 0.13230 |
| 4 | 5 | 0.0081 | 0.70 | 0.02835 |
| 5 | 1 | 0.00243 | 1 | 0.00243 |
| | | | **合计** | **0.16308** |

所以准确率 $=1-0.16308=0.8369$。单模型 0.70 → 五个模型投票 0.8369，涨了 13.69 个百分点。

### 第 2 步：换模型个数，看边际收益在哪

同样的 0.70 单模型准确率，只改 $n$：

| $n$ | 投票出错概率 | 投票准确率 | 相对单模型的增益 |
|---|---|---|---|
| 1 | 0.30000 | 0.7000 | — |
| 3 | 0.21600 | 0.7840 | +8.40 pp |
| 5 | 0.16308 | 0.8369 | +13.69 pp |
| 9 | 0.09880 | 0.9012 | +20.12 pp |
| 15 | 0.05001 | 0.9500 | +25.00 pp |

$n=3$ 那一行的算式：$3\times0.09\times0.7+0.027=0.216$，即恰好 2 个错加 3 个错。

曲线是凹的：从 1 到 5 个模型买到 13.69 个点，从 9 到 15 只买到 4.88 个点，而训练成本是线性涨的。

### 第 3 步：条件检验——把「独立」这条撤掉

改成一个更贴近现实的情况：**20% 的样本上五个模型一起错**（共同错误，比如同一个没见过的取值区间），为了让每个模型的边际准确率仍然停在 0.70，剩下 80% 的样本上单个模型的错误率必须降到

$$
q = \frac{0.30-0.20}{0.80} = 0.125
$$

注意这一步：不能既保留 30% 的错误、又让它们全在共同错误区里，那样单模型准确率会掉到 0.70 以下。改的是错误的**结构**，不是错误的总量。

$$
P(\text{投票错}) = 0.20 + 0.80\times\sum_{k=3}^{5}\binom{5}{k}0.125^{k}0.875^{5-k}
= 0.20 + 0.80\times 0.01605 = 0.21284
$$

准确率 $0.7872$，比独立情形低 4.98 个百分点。三个 $\rho$ 一起看：

| 共同错误占比 $\rho$ | 剩余样本里的独立错误率 $q$ | 5 模型投票准确率 | 准确率上限（$n\to\infty$） |
|---|---|---|---|
| 0 | 0.300 | 83.69% | 100% |
| 0.10 | 0.222 | 83.12% | 90% |
| 0.20 | 0.125 | 78.72% | 80% |
| **0.30** | **0** | **70.00%** | **70%** |

最后一行的意思值得记住：当共同错误吃满单个模型的三成错误时，剩余样本上模型全对（$q=0$），投票无从发挥，集成与单模型**一模一样**。多出来的 4 个模型只贡献了计算量。

如果基模型比随机猜还差，投票还会帮倒忙：单模型准确率 0.45、错误独立的 5 个模型投票后准确率是 0.4069，比单个更低。

## 五、什么情况下会失灵

### 承重假设：基模型不同时犯错

这是三根柱子顶一块板的那根柱子。撤掉它的后果已经在上一节量化过：

- $\rho$ 从 0 升到 0.2（单模型准确率固定 0.70）：五个模型带来的增益从 +13.69 pp 掉到 +8.72 pp。
- $\rho$ 升到 0.30：增益归零，集成等于单模型。
- 树/模型数量救不了这一项。$B\to\infty$ 时剩下的就是 $\rho$ 那一块，与 $B$ 无关。

处理办法只有一条：去改数据或特征，让基模型看到的样本不一样（重采样、行采样、列采样、换算法）。

### 承重假设：基模型比随机猜略好

多数投票的前提是每个模型的准确率大于 0.5。撤掉它：单模型 0.45、错误独立时，5 个模型投票准确率 0.4069，投票把结果推得更偏。AdaBoost 对这种情况的处理是让投票权 $\alpha_t$ 取负值、把该学习器反着用，而不是简单丢弃（见 [[8.4.2.1 AdaBoost (Adaptive Boosting)]]）。

### 承重假设：平方损失下的误差可加

「bagging 降方差、boosting 降偏差」这句话的严格版本是 MSE 的偏差-方差分解，对回归成立。分类用的 0-1 损失没有这种加法形式，多数投票的收益只能像上一节那样单独算，不能直接套 MSE 的账。

### 承重假设：stacking 的元特征取自折外

撤掉它会得到什么后果：基模型在它训练过的行上输出近乎完美，元学习器把这些预测当成可靠信号，权重全压到「最会背训练集」的那个基模型上；换一份没见过的数据，这个权重立刻失效。这类错误的现场特征是：元学习器在训练折上极好，出样本后不如最好的单模型。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 训练误差远低于验证误差 | bagging / 随机森林 | 平均抹掉随机波动，属方差问题 |
| 训练误差本身就高 | boosting / GBM | 逐轮纠残差，属偏差问题 |
| 手上有几种异质模型都想用 | stacking | 元学习器自己学权重，不用手调 |
| 要校准过的概率、要报系数 | 单个 GLM | 集成给排序强，绝对水平和系数解释都弱 |
| 标签有噪声、样本很小 | 单个正则化模型 | AdaBoost 会把标错的点权重越顶越高；GBM 会记住噪声 |
| 要因果解释 | 都不是 | 三者都只给关联 |

## 六、常见误解

### 误解一：「集成就是把多个模型平均一下，平均总比单个好」

**错误想法**：手上有 5 个模型，平均起来一定比其中最好的那个强。

**为什么容易这么想**：在小数定律的直觉里，「多观察几次取平均」确实总能把噪声压小，而且实践中 bagging 几乎没让指标变差过。

**错在哪一步**：漏掉了两个前提 —— 单模型要**比随机猜好**，错误要**不重合**。第四节数字：单模型 0.45 时，5 个独立模型投票准确率 0.4069，比单个更低；共同错误占 0.30 时，5 个模型和 1 个模型打成 0.70 平手。集成不是对数量的平均，是对**独立错误**的平均。

### 误解二：「bagging 和 boosting 都能降方差，也都能降偏差，只是快慢不同」

**错误想法**：两者都是「多个模型合起来」，差别只在并行还是串行。

**为什么容易这么想**：两个名字都带「聚合」的意思，很多总结表又只写「集成 = 降低偏差和方差」。

**错在哪一步**：把「对方的误差项也可能顺带变化」当成了「主要作用」。bagging 的基学习器是深树，偏差本来就低，平均不动均值位置，所以它**不降偏差**；boosting 对**方差**的影响是条件性的 —— 学习率小 + 树浅 + 早停时方差可控甚至下降，轮数过多又没有正则化时方差上升。写「boosting 降方差」在面试里多数情况下会被追问到答不上来。

### 误解三：「stacking 的元模型可以直接用基模型在训练集上的预测来训」

**错误想法**：先用全部训练数据训好 3 个基模型，让它们对训练集出预测，把这 3 列当特征训元模型，省掉切折的麻烦。

**为什么容易这么想**：折外预测要多训 $k$ 倍模型，看起来很浪费；而基模型的训练集预测本身就是现成的。

**错在哪一步**：漏看了这些预测的**生成方式**。基模型在自己训练过的行上误差接近 0（深树几乎能背下来），元学习器看到的是一组「完美」特征，会把权重压给最会背的那个模型，学到的不是「谁更准」，而是「谁背得更熟」。这就是折外预测存在的全部理由：让元特征和真实预测风险同分布。

### 误解四：「模型越多越好，50 个总比 5 个好」

**错误想法**：既然平均能消噪声，那就多堆一些。

**为什么容易这么想**：bagging 曲线看起来一直在涨，也确实很少变差，于是「加就完了」。

**错在哪一步**：看错了斜率也看漏了代价。第四节里 $n$ 从 9 到 15，准确率只多 4.88 个点，还要多付 6 个模型的训练与存储；有相关性时更早撞上 $\rho$ 那块地板。而且 stacking 里加一个和现有模型高度同质的基学习器，收益接近零，元学习器还多了一列噪声特征。判断标准是**这一列元特征有没有带来新的错误模式**，不是模型总数。

## 七、面试怎么答

### 30 秒版

> 三个词修的是不同的误差项。bagging 从同一份数据抽很多有放回样本、各训一个深树再平均，深树偏差本来就低，平均只是收窄散布，所以它降的是**方差**，能降多少由树之间的相关性封顶。boosting 一棵一棵加浅树，每棵拟合当前集成还没修掉的残差，降的是**偏差**，代价是串行、需要早停和收缩。stacking 不重采样，它把几个不同模型的**折外**预测当特征，再训一个简单的元模型来分配权重。

### 2 分钟版（要包含的三块）

1. **误差项与诊断**：训练远低于验证 = 方差 = bagging；训练本身就低 = 偏差 = boosting；两者都不是而是「模型类型各有看法」= stacking。三者共同前提是基模型不同时犯错，共同错误一上来，集成收益就被 $\rho$ 封顶。
2. **机制**：bagging 的方差分解 $\rho\sigma^2+(1-\rho)\sigma^2/B$，地板是 $\rho\sigma^2$，随机森林抽特征就是压 $\rho$；boosting 是函数空间里的最速下降加上收缩，轮数与学习率成对；stacking 的关键是折外预测，出样本时基模型在全量数据上重训，这个口径要写清楚。
3. **代价与选择**：bagging 好并行、几乎不用调、可解释性差；boosting 精度通常更高但要调参、要防过拟合；stacking 最灵活也最容易因为元学习器太强或折没切好而失效。选择还要看算力和可解释性要求。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「bagging 为什么不降偏差？」 | 基学习器是长到尽的深树，偏差已经很低；平均不改变预测均值的位置，只压小围绕均值的散布 |
| 「随机森林比 bagging 多了什么？」 | 每次分裂只从随机抽出的 $m$ 个特征里挑分裂点，目的是把树之间的 $\rho$ 压低，让 $\rho\sigma^2$ 那块地板跟着下降 |
| 「stacking 为什么必须折外预测？」 | 否则元学习器看到的是基模型背过答案后的输出，权重会压给最会背训练集的模型 |
| 「为什么 boosting 更容易过拟合？」 | 每轮盯的是残余误差，训练后期残余里主要是噪声；要靠小学习率、浅树、早停压住 |
| 「三种能混用吗？」 | 能，而且常见：RF 的叶节点索引当 GBM 的特征；stochastic gradient boosting 就是在 boosting 里嵌了 bagging 的行采样 |
| 「集成会不会把因果效应搞得没法解释？」 | 集成只改善预测；因果要靠设计（实验、工具变量），与用不用集成无关 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Ensembles combine several base models, and there are three families: bagging, which resamples and averages in parallel; boosting, which fits sequentially on the previous errors; and stacking, which learns a meta-model on top of the base models' predictions."

**Mechanism**

> "Stacking needs out-of-fold predictions: train each base learner on k minus one folds, predict the held-out fold, and use those predictions as features for the meta-learner. That out-of-fold detail is what keeps the meta-features honest."

**If they push back**

> "A common pitfall is being vague about what each family does to the bias-variance trade-off. Bagging mainly reduces variance; boosting mainly reduces bias, with the effect on variance depending on regularisation and early stopping; and for stacking it depends on the meta-learner. Also, stacking overfits if the meta-learner is too powerful or if the cross-validation isn't done properly, so I'd keep the meta-learner simple."
