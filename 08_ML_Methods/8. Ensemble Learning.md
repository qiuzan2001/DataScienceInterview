> - "Bagging vs. boosting vs. stacking."

* **Definition（定义）：** 集成学习（ensemble learning）把多个「弱」模型或基模型（base model）组合起来，构成一个更强的预测器（predictor）。单个模型各有各的错，集成做的是「把多个不完美的意见汇总成更稳的判断」。
* **Rationale（为什么要这么做）：**

  * 单个模型的误差来自方差（variance，过拟合）、偏差（bias，欠拟合），或者两者兼有。
  * 集成通过**汇总多样化的意见**来压低这些误差 —— 与其指望一次做对，不如让多个模型互相纠错。
* **Key Benefits（主要收益）：**

  1. **Accuracy improvement（精度提升）：** 汇总后的预测抹平了个体模型的随机错误。
  2. **Robustness（稳健性）：** 对训练数据里的噪声与离群点没那么敏感。
  3. **Generalization（泛化）：** 在没见过的新数据上通常比单个模型表现更好。

## 2. Why Ensembles Work: A Conceptual View

1. **Bias–Variance Tradeoff（偏差-方差权衡）：**

   * **Bias（偏差）：** 来自错误假设的误差（例如模型太简单）。
   * **Variance（方差）：** 来自对数据微小扰动敏感的误差（例如模型太复杂）。
   * 集成可以**降方差**（靠平均多个模型），某些方法还能**降偏差**（靠逐轮纠错）。也就是说：集成不是笼统地「提升」，而是分头去打这两个误差来源。
2. **Wisdom of Crowds（群体智慧）：**

   * 如果每个个体模型都**准确**（比随机猜好）且**多样**（各自犯的错误不相关），那么它们的多数意见大概率是对的。
   * 反面例子：所有模型都犯同一个错，投票再多次也没用 —— 所以「多样性」是集成的命门。
3. **Diversity Induction（如何造出多样性）：**

   * 强集成的关键在于：保证基学习器（base learner）不是在同一处犯错。
   * 常见手段：重采样数据（bagging）、给样本重新加权（boosting）、使用不同算法 / 特征（stacking）。

## [[8.3. Bagging (Bootstrap Aggregating)]]

### 3.1. Core Idea

* 在训练数据的不同 bootstrap 样本（有放回随机抽样）上，训练同一个基学习器的多个副本。
* 汇总预测：分类用多数投票（majority vote），回归用平均（averaging）。

### 3.2. Algorithmic Steps

1. **Bootstrap Sampling（自助抽样）：** 做 *B* 轮，每轮从原 *n* 个样本的数据集中**有放回**地抽 *n* 个样本。
2. **Model Training（训练基模型）：** 在每个 bootstrap 样本上拟合一个基学习器（例如决策树）。
3. **Prediction Aggregation（汇总预测）：**

   * **Regression（回归）：** 把 *B* 个预测平均：

     $$
       \hat{f}(x) = \frac{1}{B}\sum_{b=1}^B f_b(x)
     $$
   * **Classification（分类）：** 对类别标签输出做多数投票。

### 3.3. Strengths & Weaknesses

* **Pros（优点）：**

  * 显著降低方差（variance）。
  * 简单、可并行（每个模型互相独立）。
* **Cons（缺点）：**

  * **不降偏差**（如果基学习器本身偏差很高）。
  * 集成规模大时很吃计算资源。

### 3.4. Random Forest (an Extension)

* **Enhancement（增强点）：** 每次树分裂时，只在一个随机特征子集里挑最优分裂。
* **Effect（效果）：** 进一步降低树之间的相关性（de-correlate），从而让降方差效果更强。

## [[8.4. Boosting]]

### 4.1. Core Idea

* 顺序地构建模型：每个新模型都在试图纠正「当前已累计的集成」所犯的错误。
* 通过重新加权（reweighting）或基于梯度的调整，把注意力放到「难」样本上。

### 4.2. Common Variants

1. **AdaBoost (Adaptive Boosting)：**

   * 初始给所有训练样本相同权重。
   * 每训练完一个基学习器，就把分错样本的权重调高、分对样本的权重调低。
   * 最终预测是基学习器的加权多数投票，权重反映各自准确率。
2. **Gradient Boosting（梯度提升）：**

   * 把 boosting 看成**函数空间里的梯度下降（gradient descent in function space）**。
   * 每个新学习器都去拟合当前集成损失函数的**负梯度**（negative gradient，也就是残差方向）。
3. **XGBoost / LightGBM / CatBoost：**

   * 梯度提升的工程化实现，加了正则化、树剪枝、直方图分裂等机制，为了更快、更不容易过拟合。

### 4.3. Algorithmic Outline (Gradient Boosting)

1. 用常数预测初始化模型（例如目标均值）。
2. 对 *m* = 1 到 *M*：
   a. 为每个训练样本计算残差（负梯度）。
   b. 用这些残差拟合一个基学习器。
   c. 计算步长（学习率 learning rate），用来缩放这个学习器的贡献。
   d. 把缩放后的学习器加进集成，更新预测。
3. 最终模型是所有学习器之和。

### 4.4. Strengths & Weaknesses

* **Pros（优点）：**

  * **主要降偏差（mainly reduces bias）：** 每一轮拟合的是当前集成的残差 / 伪残差，所以系统性误差（偏差）掉得很快。**对方差的影响取决于正则化与早停（regularization and early stopping）：** 学习率小 + 树浅 + 早停时，方差通常可控甚至下降；轮数过多且没有正则化时，方差会上升。
  * 高度灵活：支持任意可微损失函数（differentiable loss）。
* **Cons（缺点）：**

  * **顺序训练（sequential）** → 比 bagging 更难并行。
  * 对噪声数据和离群点敏感（没有正则化就会过拟合）。
  * 超参数多，要调（学习率、树的数量、树深）。

## 5. Stacking (Stacked Generalization)

### 5.1. Core Idea

* **Meta-learning（元学习）：** 先在原始数据上训练多个第一层（基）学习器。
* 把它们的预测（来自留出集或交叉验证）当成特征，喂给第二层的「元学习器（meta-learner）」，由它给出最终预测。

### 5.2. Workflow

1. **Split Data（切分数据）：** 把训练集分成 *k* 折。
2. **First-Level Training（第一层训练）：** 对每个基模型：

   * 做 *k* 折交叉验证。
   * 每一折上：用 *k–1* 折训练，在留出的那一折上预测 → 收集**折外预测（out-of-fold prediction）**。
   * 跑完 *k* 轮后，你就得到了这个模型对**全部样本**的预测。
3. **Meta-Feature Construction（构造元特征）：** 把所有基模型的折外预测拼起来，形成一个新特征矩阵。
4. **Meta-Learner Training（训练元学习器）：** 在这个新矩阵上（配上真实标签）训练最终模型（例如逻辑回归、梯度提升）。
5. **Prediction on New Data（新数据上的预测）：**

   * 先用**全部**训练数据重新训练每个基模型，再对新的数据生成预测。
   * 把这些预测喂给元学习器，得到集成的输出。
   * 这一步很关键：训练元学习器时用的是折外预测，预测新数据时基模型是在全量数据上重训的 —— 两者可以不同，但必须清楚自己是按哪一套流程走的。

### 5.3. Strengths & Weaknesses

* **Pros（优点）：**

  * 可以组合**异质（heterogeneous）**基学习器（树、SVM、神经网络）。
  * 常能捕捉到简单聚合方法漏掉的复杂模式。
* **Cons（缺点）：**

  * 实现和调参更复杂。
  * 元学习器太强、或交叉验证没做对时，容易过拟合。
  * 计算量大（多折 × 多模型）。

## [[8.6 Bagging VS Boosting| 6. Choosing the Right Ensemble Method]]（如何选择集成方法）

| 维度（Aspect）                 | Bagging                                        | Boosting                                             | Stacking                                               |
| ---------------------- | ---------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------ |
| **Bias Reduction**（是否降偏差）     | 否                                             | 是                                                  | 取决于元学习器                                |
| **Variance Reduction**（是否降方差） | 是                                             | 有条件：学习率小 + 树浅 + 早停 → 可控或下降；无正则化轮数过多 → 上升（见 §4.4） | 是                                                    |
| **Parallelizable**（可并行性）     | 完全可以                                          | 有限（只有树内部能并行）               | 中等（基学习器之间可并行）           |
| **Complexity**（复杂度）         | 低                                             | 中到高                                          | 高                                                   |
| **Typical Use-Cases**（典型场景）  | 高方差的基学习器（例如深树） | 降偏差是关键时；处理偏斜数据 | 想把多种模型组合起来冲最好效果时 |

## 7. Practical Considerations & Tips

1. **Data Preprocessing（数据预处理）：**

   * 这三类方法都受益于特征缩放、缺失值处理和类别变量编码。
2. **Hyperparameter Tuning（超参数调优）：**

   * Bagging / Random Forest：树的数量（number of estimators）、最大深度（max depth）、特征子集大小。
   * Boosting：学习率（learning rate）、树的数量（number of estimators）、树深、正则化参数。
   * Stacking：基学习器 / 元学习器的选择、折数、blending 还是完整 stacking。
3. **Overfitting Control（过拟合控制）：**

   * 用交叉验证监控性能。
   * 在 boosting 里做早停（early stopping）。
   * 剪枝或限制树深。
4. **Interpretability（可解释性）：**

   * 单棵决策树可解释；集成整体上不可解释。
   * 可以用 SHAP 或 permutation importance 这类工具来解释集成的预测。

## 8. Summary & Logical Flow

1. **Ensemble learning** 通过组合多个模型来应对偏差-方差权衡。
2. **Bagging**（并行、重采样）擅长降方差。
3. **Boosting**（顺序、盯着错误）**主要降偏差**；对方差的影响取决于正则化与早停 —— 学习率小 + 树浅 + 早停时方差可控（往往更低），轮数过多又无正则化则会把它推上去（代价是潜在过拟合与复杂度）。
4. **Stacking**（元学习）融合多样化的学习器以取长补短，但必须小心做交叉验证，否则元学习器会过拟合。
5. **方法选择**取决于数据特点、算力，以及性能与可解释性之间的取舍。

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Ensembles combine several base models, and there are three families: bagging, which resamples and averages in parallel; boosting, which fits sequentially on the previous errors; and stacking, which learns a meta-model on top of the base models' predictions."

**Mechanism**

> "Stacking needs out-of-fold predictions: train each base learner on k minus one folds, predict the held-out fold, and use those predictions as features for the meta-learner. That out-of-fold detail is what keeps the meta-features honest."

**If they push back**

> "A common pitfall is being vague about what each family does to the bias-variance trade-off. Bagging mainly reduces variance; boosting mainly reduces bias, with the effect on variance depending on regularisation and early stopping; and for stacking it depends on the meta-learner. Also, stacking overfits if the meta-learner is too powerful or if the cross-validation isn't done properly, so I'd keep the meta-learner simple."
