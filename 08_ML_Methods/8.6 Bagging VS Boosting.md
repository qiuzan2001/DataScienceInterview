#### 1. Recap: What are **Bias** and **Variance**?

对任何在数据 $\mathcal D$ 上训练出来的模型 $\hat f$，有

$$
\mathbb{E}_{\mathcal D}\!\big[(\hat f(\mathbf x)-f(\mathbf x))^{2}\big]
=\underbrace{\big(\mathbb{E}_{\mathcal D}[\hat f(\mathbf x)]-f(\mathbf x)\big)^{2}}_{\textbf{Bias}^{2}}
+\underbrace{\mathbb{E}_{\mathcal D}\!\big[(\hat f(\mathbf x)-\mathbb{E}_{\mathcal D}[\hat f(\mathbf x)])^{2}\big]}_{\textbf{Variance}}
+\sigma_\text{noise}^{2}.
$$

* **Bias（偏差）** = 系统性误差（模型「瞄偏了」）：换多少份训练数据，预测的平均值都偏离真值。
* **Variance（方差）** = 对具体样本的敏感度（一重训，预测就「抖」）。

好的模型要求**两者都小**，但不同的集成技巧是从不同角度下手的：bagging 打方差，boosting 打偏差。

> ⚠️ 前提：这是**平方损失的期望测试误差分解**（对回归成立）。0-1 损失（分类）没有这种加法形式，不要直接套。

---

#### 2. **Bagging = Bootstrap Aggregating ⇒ Variance Killer**

1. **Process（流程）**

   * 抽 $M$ 个 bootstrap 样本（与训练集同大小，**有放回**抽样）。
   * 在每个样本上训练一个**不稳定（unstable）**的基学习器（例如不加剪枝的深树）。
   * 把预测平均（回归）或多数投票（分类）。

2. **How it shrinks variance（方差是怎么降下来的）**

   *画面：$M$ 个气象员各自独立预报明天的气温；取平均，日常的小波动就相互抵消了。*

   * 每个学习器的方差：$\sigma^{2}$。
   * 如果它们**完全独立**，集成方差会是 $\sigma^{2}/M$。
   * 现实中树之间是相关的（它们经常看到重叠的样本点），所以实际是

     $$
     \text{Var}(\text{Bag}) = \rho\,\sigma^{2} + \frac{1-\rho}{M}\,\sigma^{2},
     $$

     其中 $\rho$ = 学习器之间的平均相关系数。
     树越多 ⇒ 第二项越小。Bootstrap + 特征子采样（随机森林）则让 $\rho$ 变小。
     **关键**：$\rho\sigma^2$ 是**地板** —— 它只由相关性决定，加再多树也压不下去；要再降方差，只能去降 $\rho$（这正是随机森林抽特征的理由）。

3. **Why bias barely budges（为什么偏差几乎不动）**

   每棵树都是**长到尽**（不剪枝）。完全长成的树偏差很低 —— 它已经把训练集背下来了 —— 所以集成的预测均值与任何单棵树的均值几乎一样。平均不会把这个均值往真值方向推，只是压小了围绕均值的散布。

4. **When bagging shines（什么时候 bagging 好用）**

   * 高方差的基学习器（深树；数据不大时的神经网络）。
   * 数据里有随机波动、不希望最终模型去追这些波动时。

---

#### 3. **Boosting = Sequential Error-Correcting ⇒ Bias Buster**

1. **Process (AdaBoost / Gradient Boosting view)（流程）**

   * 先从第一个弱学习器 $h_1$ 起步（例如浅树）。
   * 看它的**残差**（做错的部分），把注意力压上去，训练 $h_2$ 专门修 $h_1$ 的错误。
   * 如此重复得到 $h_3, h_4,\dots,h_T$；最终模型是**加权**和 $F_T=\sum_{t=1}^T\alpha_t h_t$。

2. **How it trims bias（偏差是怎么被削掉的）**

   *可以理解成反复校对：每一轮修掉剩下的错别字。*

   * 每一步都在**函数空间**里加一个指向损失负梯度方向的小向量 ⇒ 相当于朝 Bayes 最优函数做梯度下降。
   * 浅树（几个叶节点）单看是**高偏差**的，但每一步都啃掉一点系统性误差，于是 $\text{Bias}^2$ 随 $T$ 快速下降。

3. **What happens to variance（方差会怎样）**

   *每一轮都增加参数 ⇒ 灵活性更大，因此可能更「抖」。* 更准确的说法是：**Boosting 主要降偏差；对方差的影响取决于正则化与早停**。

   * 学习率小（shrinkage）+ 树浅 + 早停（+ 子采样）时：每轮只加很小的修正，**方差通常可控，甚至会下降** —— 这也是现代 GBDT 的默认配方。
   * 轮数过多且没有正则化时：模型容量持续膨胀，开始拟合训练集的个体噪声 ⇒ **方差上升**，最终盖过偏差收益（经典过拟合曲线）。

   **Controls（控方差的旋钮）**：小学习率（shrinkage）、子采样（stochastic GB）、早停（early stopping）。

4. **When boosting shines（什么时候 boosting 好用）**

   * 欠拟合场景（模型太简单、漏掉了模式）。
   * 数据里的细微结构比多出来的一点方差更重要的场景。
   * 竞赛 / 表格数据里 Gradient Boosting Trees 占统治地位的场景。

#### 4. Side-by-Side Intuition

| 维度（Property）                | **Bagging**                                                 | **Boosting**                                       |
| ----------------------- | ----------------------------------------------------------- | -------------------------------------------------- |
| 基学习器风格（Base learner style）      | **复杂、高方差**（深树）                      | **简单、高偏差**（stump / 3 层树）         |
| 训练方式（Learner training）        | *并行*、相互独立                                     | *顺序*、每个学习器看的是加权残差 |
| 主要压低的误差项（Main error term reduced） | **方差（Variance）**：平均掉随机波动                 | **偏差（Bias）**：迭代地修残差            |
| 要盯住的风险（Risk to watch）           | 每棵树都有偏则仍偏；树之间的相关性 | **无正则化 / 无早停**时多轮之后 **方差上升**（过拟合） |
| 正则化旋钮（Regularisation knobs）    | 树的数量、特征 / 样本子采样、最大深度                    | 学习率、轮数、子采样、树深     |
| 类比（Analogies）               | 民调平均、群体智慧                            | 接力校对的编辑团队、梯度下降            |

#### 5. A Tiny Numerical Thought Experiment

假设一棵深树的表现是：

*Bias* ≈ 0.2　　*Variance* ≈ 1.0

---

**Bagging 100 trees**

* Bias 保持 ≈ 0.2。
* Variance ≈ $1.0/100 = 0.01$（忽略相关性）。
* Total MSE ≈ $0.2^{2} + 0.01 = 0.05$。

---

**Boosting 100 shallow trees**

* Bias 可能降到 ≈ 0.05。
* Variance 可能升到 ≈ 0.4（整体模型更复杂）。
* Total MSE ≈ $0.05^{2} + 0.4 = 0.4025$。

如果在第 30 轮就停止 boosting：bias ≈ 0.07、variance ≈ 0.15 ⇒ MSE ≈ 0.1549 —— 比两个极端都好。
*Lesson（结论）*：偏差-方差权衡永远是在找那个甜点（sweet spot）；这两种技术只是把曲线往不同方向推。

---

#### 6. Practical Rules of Thumb

1. **Diagnose first（先诊断）**
   *交叉验证*误差远高于训练误差 → 高方差 → 考虑 Bagging / Random Forests。
   训练误差也高 → 高偏差 → 考虑 Boosting（再加上更深的树或更丰富的特征）。

2. **Combine wisely（组合要有讲究）**
   Random Forest 做稳定底座；把它的*叶节点索引（leaf-indices）*当特征喂给上层的 Gradient Boosting；反过来也可以用 **bagged boosted trees**（在每轮 boosting 里也加随机性）。现代库（例如 XGBoost、LightGBM）本身就已经把两边的技巧混在一起了。

3. **Tune with a leash（调参要有缰绳）**

   * Bagging：树多了很少会变差，但注意运行时间；用特征采样控制相关性。
   * Boosting：宁可**小学习率 + 多轮 + 早停**，也不要大学习率。

---

### Take-Away Sentence

> **Bagging** 用平均把随机性洗掉 —— 擅长驯服**方差**；而 **Boosting** 沿着一条直线不停地修残差 —— 擅长压缩**偏差**（但推进过程中要盯住方差）。 🚀

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "The one-line version is that bagging reduces variance and boosting reduces bias. Bagging trains independent deep trees on bootstrap samples and averages them in parallel; boosting trains shallow trees sequentially, each one on what the previous ensemble got wrong."

**Mechanism**

> "Each bagged tree is grown to exhaustion, so its bias is already low and averaging only damps the scatter — the error converges as the number of trees grows. Boosting starts from a high-bias weak learner, but each stage moves the function in the direction of the negative gradient, so the bias drops steeply with the number of rounds."

**If they push back**

> "A common pitfall is saying boosting reduces variance as well. What it does to variance depends on regularisation and early stopping: a small learning rate, shallow trees and early stopping usually keep variance controlled or even reduce it, but many unregularised rounds push it up. My rule of thumb for choosing: if cross-validated error is much worse than training error, that's variance — go bagging; if training error is high too, that's bias — go boosting."
