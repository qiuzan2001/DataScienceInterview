# 8.6 装袋与提升的对照（Bagging vs Boosting）

## 速览 At a glance

**速记**

平方损失下测试误差可以拆成三块：$\text{Bias}^2+\text{Variance}+\sigma^2_{\text{noise}}$。bagging 和 boosting 是在这个加法式里动不同的项。bagging 平均多个在 bootstrap 样本上训出来的模型 —— 平均不改变预测均值的位置，只压小散布，所以它只削方差，几乎不动偏差；基学习器必须本身就不稳定（深树）。boosting 一个接一个加浅模型，每个拟合当前集成还没修掉的残差 —— 它在削偏差，代价是每加一轮都会把模型容量推大，方差跟着涨；因此它必须配小学习率、浅树和早停，否则多出来的轮数把方差抬得比偏差收益还快。判断顺序很固定：验证误差远高于训练误差 = 方差问题 = bagging；训练误差本身就高 = 偏差问题 = boosting。最后一个数要看清楚：bagging 的降方差有地板 $\rho\sigma^2$，树之间的相关性一高，它可能反而不如停得早的 boosting。

**一句面试答法**

> "Bagging and boosting move different terms in the bias-variance decomposition. Bagging averages models trained on bootstrap samples, so it cuts variance and barely touches bias — the base learner has to be unstable, like a deep tree. Boosting adds shallow models sequentially, each one on the residual the current ensemble still has, so it cuts bias, and what it does to variance depends on regularisation and early stopping. My rule of thumb: if cross-validated error is much worse than training error, that's variance, so I'd go bagging; if training error is high too, that's bias, so I'd go boosting."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 偏差 | bias | 换多少份训练数据都稳定偏离真值的部分 |
| 方差 | variance | 换一份训练数据预测就变的部分 |
| 不可约误差 | irreducible error $\sigma^2_{\text{noise}}$ | 数据本身的噪声，任何模型都消不掉 |
| 不稳定学习器 | unstable learner | 换数据就换样子的模型，如深树 |
| 偏差-方差权衡 | bias-variance trade-off | 压一头常会把另一头顶上去 |
| 甜点 | sweet spot | 训练误差还在降、验证误差刚要抬头的位置 |
| 相关性地板 | correlation floor | bagging 方差里 $\rho\sigma^2$ 那块压不下去的部分 |
| 稳定性诊断 | diagnosis by error gap | 训练与验证差距的大小决定用哪一族 |
| 组合使用 | hybrid ensemble | 例如 bagged boosted trees、RF 叶索引喂 GBM |

## 一、先看一个问题

真题里 §9 那两句是连着的：**"How is GBM different from random forest?"** 后面紧跟 **"Why is GBM more sensitive to hyperparameters than RF?"** 第一句是知识题，第二句是水平题 —— 它要求你把「超参数多」和「误差项」接起来，而不只是说 GBM 参数多。

看一个能同时回答两句的场景。同一份 20 万行数据：

| 方案 | 超参数个数 | 训练 MSE | 五折验证 MSE |
|---|---|---|---|
| Random Forest，500 棵树 | 2–3 个 | 0.31 | 0.38 |
| GBM，`lr=0.1`、树深 3、200 轮 | 5–6 个 | 0.29 | 0.36 |
| GBM，`lr=0.1`、树深 3、1200 轮 | 同第二个 | 0.09 | 0.42 |

RF 那行几乎是开箱的：树数加到 500、其余用默认值，验证 0.38 已经不错。GBM 前两行的差别也不大。但第三行只改了**一个旋钮**（轮数），训练 MSE 掉到 0.09、验证反而升到 0.42 —— 这就是「GBM 对超参数更敏感」的实测样子：它的轮数直接控制偏差-方差在天平上的位置，而 RF 的树数只会让指标单调走近一个平台。

所以这一页要回答：为什么两族方法对同一个「多训练一点」的动作反应完全不同。答案在误差分解里。

## 二、核心直觉

### 两条曲线的方向不同

把「训练量」（RF 的树数、GBM 的轮数）放在横轴上：

- **bagging**：每棵树都是长到尽的，偏差一开始就低；加树只是让平均更充分，方差单调下降、逼近 $\rho\sigma^2$。曲线很快走平，加多了不会变坏，只是浪费算力。
- **boosting**：每棵都是浅树，偏差一开始很高；加轮让残差被一轮轮啃掉，偏差持续下降。**同时**容量在增长，方差缓慢上升。两条腿一起动，所以存在一个最优轮数，过了就变坏。

**像什么、不像什么。** 把 bagging 想成找来 500 个人各自估一个数再取平均 —— 像的地方是随机抖动被平均掉了；不像的地方是这些人不是完全独立（他们看的是同一份数据的重抽样版本），所以平均效果被他们之间的「看法相似度」压住。把 boosting 想成接力改稿 —— 像的地方是每一棒都在改上一棒剩下的问题；不像的地方是改稿有终点，boosting 每一棒都会顺手把稿子改得「更贴合当前这份稿」，轮数多了就开始贴合噪声。

### 一句话分工

**bagging 用平均把随机性洗掉，boosting 沿着一条线不停修残差。** 前者盯的是「为什么同一个模型换一份数据结果就变」，后者盯的是「为什么这个模型系统地偏」。

## 三、机制

### 3.1 偏差-方差分解（逐符号）

对任何在数据 $\mathcal D$ 上训练出来的模型 $\hat f$，有

$$
\mathbb{E}_{\mathcal D}\!\big[(\hat f(\mathbf x)-f(\mathbf x))^{2}\big]
=\underbrace{\big(\mathbb{E}_{\mathcal D}[\hat f(\mathbf x)]-f(\mathbf x)\big)^{2}}_{\textbf{Bias}^{2}}
+\underbrace{\mathbb{E}_{\mathcal D}\!\big[(\hat f(\mathbf x)-\mathbb{E}_{\mathcal D}[\hat f(\mathbf x)])^{2}\big]}_{\textbf{Variance}}
+\sigma_\text{noise}^{2}.
$$

- $\mathbb{E}_{\mathcal D}[\hat f(\mathbf x)]$：把所有可能的训练集上的模型预测取平均 —— 这是没法真的算的量，是个思想实验：想象你能拿到很多份同分布的训练数据。
- $\textbf{Bias}^{2}$：这个「平均模型」偏离真值 $f(\mathbf x)$ 的平方。系统性误差。
- **Variance**：单个模型围绕它自己的平均值的波动。换一份数据就抖。
- $\sigma_\text{noise}^{2}$：任何模型都消不掉的噪声下限。

**前提**：这是**平方损失的期望测试误差分解**，对回归成立。0-1 损失（分类）没有这种加法形式，不要直接套。

### 3.2 bagging 为什么只动方差：关键一步在「平均不改均值」

设有 $M$ 个基学习器，每个的方差是 $\sigma^2$、两两相关系数是 $\rho$：

$$
\text{Var}(\text{Bag}) = \rho\,\sigma^{2} + \frac{1-\rho}{M}\,\sigma^{2}
$$

- $\rho\sigma^{2}$：与 $M$ 无关的部分。**关键一步**就在这：$M\to\infty$ 时第二项消失、第一项留下，所以 bagging 的降方差有地板。
- Bootstrap + 特征子采样（随机森林）做的是把 $\rho$ 变小 —— 这是唯一能继续压低方差的途径。

**为什么偏差几乎不动**：每棵树都是**长到尽**（不剪枝）。完全长成的树偏差很低（它已经把训练集背下来了），所以集成的预测均值与任何单棵树的均值几乎一样。平均不会把这个均值往真值方向推，只是压小围绕均值的散布。

**什么时候 bagging 好用**：高方差的基学习器（深树；数据不大时的神经网络）；数据里有随机波动、不希望最终模型去追这些波动时。

### 3.3 boosting 为什么只动偏差：关键一步在「目标是残差」

从第一个弱学习器 $h_1$ 起步，看它的**残差**，把注意力压上去，训练 $h_2$ 专门修 $h_1$ 的错误，如此得到 $h_3,h_4,\dots,h_T$，最终模型是加权和 $F_T=\sum_{t=1}^T\alpha_t h_t$。

- 每一步都在**函数空间**里加一个指向损失负梯度方向的小向量 ⇒ 相当于朝 Bayes 最优函数做梯度下降。
- 浅树（几个叶节点）单看是**高偏差**的，但每一步都啃掉一点系统性误差，于是 $\text{Bias}^2$ 随 $T$ 快速下降。
- **关键一步**：新学习器的目标不是 $y$，而是 $y-F_{t-1}$。目标变了，所以每一步修的是偏差；也正因为目标依赖上一轮，这一族不能并行。

**方差会怎样**：每一轮都增加参数，灵活性更大。学习率小（shrinkage）+ 树浅 + 早停（+ 子采样）时，每轮只加很小的修正，**方差通常可控，甚至会下降** —— 这是现代 GBDT 的默认配方。轮数过多且没有正则化时，模型容量持续膨胀、开始拟合训练集的个体噪声 ⇒ **方差上升**，最终盖过偏差收益（经典过拟合曲线）。控方差的旋钮就是：小学习率、子采样、早停。

**什么时候 boosting 好用**：欠拟合场景（模型太简单、漏掉了模式）；数据里的细微结构比多出来的一点方差更重要的场景；竞赛 / 表格数据里 Gradient Boosting Trees 占统治地位的场景。

### 3.4 逐项对照

| 维度（Property）                | **Bagging**                                                 | **Boosting**                                       |
| ----------------------- | ----------------------------------------------------------- | -------------------------------------------------- |
| 基学习器风格（Base learner style）      | **复杂、高方差**（深树）                      | **简单、高偏差**（stump / 3 层树）         |
| 训练方式（Learner training）        | *并行*、相互独立                                     | *顺序*、每个学习器看的是加权残差 |
| 主要压低的误差项（Main error term reduced） | **方差（Variance）**：平均掉随机波动                 | **偏差（Bias）**：迭代地修残差            |
| 要盯住的风险（Risk to watch）           | 每棵树都有偏则仍偏；树之间的相关性 | **无正则化 / 无早停**时多轮之后 **方差上升**（过拟合） |
| 正则化旋钮（Regularisation knobs）    | 树的数量、特征 / 样本子采样、最大深度                    | 学习率、轮数、子采样、树深     |
| 类比（Analogies）               | 民调平均、群体智慧                            | 接力校对的编辑团队、梯度下降            |

### 3.5 Practical Rules of Thumb

1. **Diagnose first（先诊断）**
   *交叉验证*误差远高于训练误差 → 高方差 → 考虑 Bagging / Random Forests。
   训练误差也高 → 高偏差 → 考虑 Boosting（再加上更深的树或更丰富的特征）。
2. **Combine wisely（组合要有讲究）**
   Random Forest 做稳定底座；把它的*叶节点索引（leaf-indices）*当特征喂给上层的 Gradient Boosting；反过来也可以用 **bagged boosted trees**（在每轮 boosting 里也加随机性）。现代库（例如 XGBoost、LightGBM）本身就已经把两边的技巧混在一起了。
3. **Tune with a leash（调参要有缰绳）**
   - Bagging：树多了很少会变差，但注意运行时间；用特征采样控制相关性。
   - Boosting：宁可**小学习率 + 多轮 + 早停**，也不要大学习率。

## 四、算一遍：偏差-方差账本上的两笔交易

### 设定

拿一组成绩单，单位都是 MSE，$\sigma^2_{\text{noise}}$ 先设为 0（它不随方法变，写进来只是把两边同时抬高，不影响比较）：

单棵不剪枝深树：**Bias ≈ 0.2**，**Variance ≈ 1.0**。

### 第 1 步：算出单棵树的基线

为什么第一步要算它：后面的所有降幅都是相对它说的。

$$
\text{MSE}_{\text{单树}} = 0.2^{2} + 1.0 = 0.04 + 1.0 = \mathbf{1.04}
$$

注意偏差是 0.2 但在式子里要**平方**：0.2 的偏差只贡献 0.04，剩下 1.0 全是方差。这解释了为什么深树的问题几乎没有例外地出在方差上。

### 第 2 步：bagging 100 棵树

- **Bias 保持 ≈ 0.2** —— 每棵树都长到尽，平均不改均值位置。
- **Variance ≈ $1.0/100 = 0.01$**（先忽略树之间的相关性，即假设 $\rho=0$）。
- **Total MSE ≈ $0.2^{2} + 0.01 = 0.0400+0.0100 = 0.0500$**。

相对基线：$(1.04-0.05)/1.04 = 95.2\%$ 的下降。**降的全是方差那一项**：方差从 1.0 到 0.01，偏差平方一动不动还是 0.04。

### 第 3 步：boosting 100 棵浅树

- **Bias 可能降到 ≈ 0.05** —— 残差被逐轮啃掉。
- **Variance 可能升到 ≈ 0.4** —— 100 个模型叠起来，整体容量比单棵深树还大。
- **Total MSE ≈ $0.05^{2} + 0.4 = 0.0025+0.4000 = 0.4025$**。

相对基线降了 61.3%。**注意它比 bagging 差不少**：0.4025 对 0.0500。原因是它把方差从 1.0 只压到 0.4，而偏差虽然掉了 0.0375（0.04→0.0025），抵不过方差剩下的 0.4。

### 第 4 步：boosting 在第 30 轮就停

- **Bias ≈ 0.07**、**Variance ≈ 0.15**。
- **Total MSE ≈ $0.07^{2} + 0.15 = 0.0049+0.1500 = 0.1549$** —— 比两个极端都好。

为什么 30 轮能赢 100 轮，看这笔账：

| 从 30 轮到 100 轮 | 数值 | 方向 |
|---|---|---|
| 偏差平方 0.0049 → 0.0025 | −0.0024 | 赚 |
| 方差 0.15 → 0.40 | +0.2500 | 亏 |
| 净效果 | **+0.2476** | 亏 |

多跑 70 轮，偏差只多买到 0.0024，方差却付了 0.25 —— **差两个数量级**。这就是 boosting 必须早停的理由，也是「树越多越好」在 boosting 上不成立的具体形状。

### 第 5 步：条件检验——把相关性放回 bagging

第 2 步里我假设了 $\rho=0$，这是 bagging 最理想的情形。把 $\rho$ 抬起来，方差换成 $\rho+\frac{1-\rho}{100}$，偏差平方仍然是 0.04：

| $\rho$ | 集成方差 | Total MSE | 与 30 轮 boosting（0.1549）比 |
|---|---|---|---|
| 0.0 | 0.0100 | 0.0500 | 好 3.1 倍 |
| 0.2 | 0.2080 | 0.2480 | 差 1.6 倍 |
| 0.5 | 0.5050 | 0.5450 | 差 3.5 倍 |
| 0.9 | 0.9010 | **0.9410** | **差 6.1 倍** |

**这张表是本页最值钱的部分**：$\rho$ 从 0 升到 0.2（一个很常见的水平），bagging 就从「好 3 倍」翻转成「差 1.6 倍」。所以「bagging 一定比 boosting 稳」不成立 —— 它成立的前提是树之间足够不相关。真实数据里强势变量的存在会让 $\rho$ 上去，这也是随机森林抽特征的动机：不抽特征就直接上 bagging，可能连一个停得早的 boosting 都打不过。

## 五、什么情况下会失灵

### 承重假设一：你可以算偏差-方差这笔账

整个对照建立在「MSE = Bias² + Variance + 噪声」这个加法式上。撤掉它的后果很具体：换 0-1 损失做分类时，这个分解不存在，也就没有「bagging 降方差、boosting 降偏差」的直接对应；AUC 或准确率上看到的现象不能直接套这里的结论。要给分类情景做同类分析，得换用别的口径（例如把 log-loss 当成被分解的量，或直接用投票的闭式概率算，见 [[8. Ensemble Learning]]）。

### 承重假设二：bagging 的树之间相关性低

第 5 步的算例已经量化：$\rho$ 从 0 到 0.2，bagging 的 MSE 从 0.0500 到 0.2480。撤掉它的处理办法是压 $m$（每次分裂少看几个特征），或用强相关特征的聚合版本做分裂。要是特征里只有一个强预测变量，记得报告的是抽特征之后的 $\rho$，不是原始特征的相关系数。

### 承重假设三：boosting 的噪声占比足够低

30 轮那个数字（0.1549）的前提是「多跑的轮数主要在拟合噪声」。撤掉它的反面情况同样重要：如果数据信号充足、噪声很小，多跑轮数的方差代价低，100 轮反而更优。判断依据只能是验证曲线，不能靠轮数的经验值。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 验证误差远高于训练误差 | bagging / RF | 误差在方差那一项，平均能压 |
| 训练误差本身就高 | boosting | 误差在偏差那一项，逐轮修 |
| 两者都高 | 先换特征 / 换模型形式，再谈集成 | 集成只是二选一的放大器，救不了特征不足 |
| 想让调参成本低、结果稳 | RF | 树数单调改善，超参数少 |
| 想榨最后 1–2 个点、算力够 | boosting + 早停 | 上限更高，但要管住轮数 |
| 需要报系数和方向 | 单个 GLM | 集成给排序，不给方向 |

## 六、常见误解

### 误解一：「bagging 一定比 boosting 稳，所以先上 RF」

**错误想法**：RF 调参少、不会过拟合，那就先用它，反正不会差。

**为什么容易这么想**：RF 的树数曲线确实单调不回头，而 GBM 加轮数会在某个点变坏 —— 一边有坑一边没坑，直觉就偏向没坑的。

**错在哪一步**：把「加树不会变坏」当成了「结果一定更好」。第四节的表里，$\rho=0.9$ 时 bagging 的 MSE 是 0.9410，比停得早的 boosting 差 6.1 倍。论「稳」它确实稳 —— 稳定地停在一个差的水平上。

### 误解二：「boosting 也会降方差，所以它两个误差项都赢」

**错误想法**：boosting 比单一棵树强那么多，一定是偏差和方差都降了。

**为什么容易这么想**：验证指标确实明显改善，改善自然被理解成两边都好转。

**错在哪一步**：看第 3 步那个数 —— 方差从 1.0 到 0.4，是**升**的（单棵深树方差 1.0 是相对于它自己的平均预测，而 100 棵树的集成有更多参数、更容易被数据扰动）。boosting 赢在偏差从 0.2 掉到 0.05。真正让它在第 4 步反超的是**少跑 70 轮**：把方差压回 0.15。

### 误解三：「既然 30 轮最好，那轮数越少越好」

**错误想法**：找到了最优轮数是 30，那就保守一点，20 轮或者 10 轮更安全。

**为什么容易这么想**：把「过拟合的代价很大」理解成「越早停越稳」。

**错在哪一步**：30 轮这个数来自这笔具体账（bias 0.07 / variance 0.15）；轮数少意味着偏差没修够，回不到 0.0049 那个偏差平方。最优轮数由验证集上的早停找出来，不靠守恒的直觉 —— 换一份数据、换一个学习率，这个数字都会变。

### 误解四：「bagging 和 boosting 一起用一定更好」

**错误想法**：既然一个降方差一个降偏差，那就两样都用上，双管齐下。

**为什么容易这么想**：误差分解是加法式，看起来两边都能受益。

**错在哪一步**：漏掉了两边的**参数会互相抵消**。把 GBM 的轮数定得很小、再套一层 bagging，等于用 bagging 去修一个本来就不大的方差，同时没让 boosting 把偏差修够。真正有效的混合形态是分工明确的：RF 的叶节点索引当 GBM 的特征（3.5 节第 2 条），或者在每轮 boosting 内部加行/列子采样（stochastic GB），而不是在外层无脑再叠一次平均。

## 七、面试怎么答

### 30 秒版

> 一句话是 bagging 降方差、boosting 降偏差。bagging 在 bootstrap 样本上并行训独立深树再平均，树本身偏差就低，平均只压散布，能压到哪由树之间的 $\rho$ 决定；boosting 顺序训浅树，每棵看上一轮集成的残差，偏差随轮数陡降，但每轮都在加容量，所以方差管不管得住取决于学习率、树深和早停。选法看诊断：验证远差于训练 → bagging；训练本身就高 → boosting。

### 2 分钟版（要包含的三块）

1. **账本**：$\text{MSE}=\text{Bias}^2+\text{Variance}+\sigma^2_{\text{noise}}$（平方损失下成立，0-1 损失没有这个加法式）。单棵深树 0.04+1.0=1.04；bagging 100 棵 0.04+0.01=0.0500；boosting 100 轮 0.0025+0.4=0.4025；boosting 30 轮 0.0049+0.15=0.1549。
2. **交易的方向**：bagging 只在方差项上做交易，偏差平方不变；boosting 在偏差上赚、在方差上赔，30→100 轮这笔交易是赚 0.0024 赔 0.25，所以必须早停。
3. **两边的边界**：bagging 有 $\rho\sigma^2$ 地板，$\rho=0.2$ 就能让它在账本上输给 boosting；boosting 的方差代价在噪声大的数据上更高；超参数少的是 RF，上限高的是 GBM —— 这就是 §9 那句「GBM 对超参数更敏感」的实质。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么 RF 的树数可以一直加？」 | 加树只会让平均更接近 $\rho\sigma^2$ 这块地板，不会变坏；代价是时间与内存 |
| 「为什么 GBM 的轮数会有一个最优值？」 | 每轮同时降偏差、涨方差；两者之和在某点最小，之后方差占上风 |
| 「偏差-方差分解对分类成立吗？」 | 不成立，它是平方损失的产物；分类上要用别的口径 |
| 「$\rho\sigma^2$ 那块地板怎么压？」 | 只能去压 $\rho$：特征子采样、行采样、换更不一样的基学习器 |
| 「为什么 GBM 更容易过拟合？」 | 它的每个旋钮（轮数、学习率、树深）都在动偏差-方差的位置，而 RF 的树数几乎只动方差 |
| 「两者能混吗？」 | 能，但要分工明确：RF 叶索引当 GBM 特征，或在 boosting 内部做子采样 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "The one-line version is that bagging reduces variance and boosting reduces bias. Bagging trains independent deep trees on bootstrap samples and averages them in parallel; boosting trains shallow trees sequentially, each one on what the previous ensemble got wrong."

**Mechanism**

> "Each bagged tree is grown to exhaustion, so its bias is already low and averaging only damps the scatter — the error converges as the number of trees grows. Boosting starts from a high-bias weak learner, but each stage moves the function in the direction of the negative gradient, so the bias drops steeply with the number of rounds."

**If they push back**

> "A common pitfall is saying boosting reduces variance as well. What it does to variance depends on regularisation and early stopping: a small learning rate, shallow trees and early stopping usually keep variance controlled or even reduce it, but many unregularised rounds push it up. My rule of thumb for choosing: if cross-validated error is much worse than training error, that's variance — go bagging; if training error is high too, that's bias — go boosting."
