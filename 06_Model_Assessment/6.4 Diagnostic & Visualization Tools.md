# 6.4 诊断与可视化工具（Diagnostic & Visualization Tools）

## 速览 At a glance

**速记**

每张图只回答一个问题，所以先问「我要回答什么」再选图。**排序**看 ROC 曲线（receiver operating characteristic curve）：横轴是假正例率（False Positive Rate, FPR），纵轴是真正例率（True Positive Rate, TPR），把每个阈值下的取舍连成一条轨迹；面积 AUC（Area Under the Curve）等于「随机正例的得分高于随机负例」的概率，0.5 等于随机猜，`Gini = 2·AUC − 1`；KS（Kolmogorov–Smirnov statistic）是同一条轨迹上离对角线最远那点的 `TPR − FPR`，只看一个切点。基础率低时换成 PR 曲线，它的随机基线就是基础率本身。**结构**看残差图：横轴拟合值、纵轴残差，弯曲是函数形式设错、喇叭形是异方差；Q-Q 图看尾部，杠杆值与 Cook 距离找「一个点说了算」的观测。**收益**看 Lift / Gain 图：按分数排序取前 X%，读运营产能那一点能捞回多少事件。**校准**看预测概率与真实频率对不对齐。本文算例只有 12 单：AUC 0.750、KS 0.625，可只查前 3 单时命中率只有 33%——排序漂亮和能上线之间隔着一段距离。

**一句面试答法**

> "I pick the plot by the question I need to answer: ROC and PR curves for ranking, residual and Q-Q plots for structure and assumptions, a lift or gain chart for the payoff at my operating capacity, and a calibration curve if the predicted probability is going to be used as a frequency."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 受试者工作特征曲线 | ROC curve | 全阈值下 TPR 对 FPR 的轨迹 |
| 真正例率 / 召回率 | true positive rate (TPR) / recall | $TP/(TP+FN)$，ROC 的纵轴 |

## 一、先看一个问题

模型训练完了，报告摊在桌上：验证集 AUC 0.750、KS 0.625。风控主管只问两句——「能不能上？」「往哪改？」

这两句各自背后是一串更小的问题。能不能上，要回答的是：我准备用的那个产能点上能捞回多少事件（不是全曲线的面积）、预测出来的概率能不能直接当频率用、哪类错误更贵。往哪改，要回答的是：残差里还剩没剩结构、这是欠拟合还是过拟合、要不要补数据。

面试官的原话是 "Explain a lift chart and a gain chart. How do you read one?"，这句话背后在考什么：你能不能把「排序好」翻译成「在某个产能点上值多少钱」。只有面积、没有阈值和产能点的答案，业务那边落不了地。

本文用一个 12 单的小样本把这件事算一遍：4 单真正的正例，另有一单负例的分数排到了第一（完全分错）。算完你会看到 AUC 0.750 的模型在前 3 单里只命中 1 单。

## 二、核心直觉

### 每张图都是把一类错误翻译成一种形状

| 图 | 它把哪种错误翻译成什么形状 |
|---|---|
| 残差图 | 「模型没学到的结构」→ 一条弯曲的线、一个喇叭口 |
| Q-Q 图 | 「尾部不符假设」→ 两端翘起或整体 S 形 |
| 杠杆值 / Cook 距离 | 「某个点说了算」→ 一个孤立且远离中心的点 |
| ROC / PR 曲线 | 「排序能力」→ 一条轨迹离对角线（或离基线）有多远 |
| Lift / Gain 图 | 「前 X% 产能的收益」→ 一条向左上角鼓的累计曲线 |
| 校准曲线 | 「概率能不能信」→ 点压不压 45° 线 |

一条判据：先认横纵轴分别是什么量，再问「这个形状在我的业务里对应什么代价」。同一张弯曲的残差图，在预测保费时可能是致命的结构错误，在看趋势时可能完全无所谓。

### 类比和它的边界

这些图像体检报告：每项只筛查一类问题，组合起来才是一个判断。**不像的地方有两条**。体检有正常值范围，图没有——同一形状是否要紧，取决于你打算怎么用这个模型（排序、定阈值、还是把概率当频率）。第二，图上看到的只是「可见的」部分：OLS 残差与自变量正交、还被杠杆值摊平，所以一张看着干净的残差图并不证明同方差成立（下一节和第五节的算例都会碰到这条）。

### 一张图回答一个问题

后面三节按这个顺序走：残差图看结构与异方差，学习曲线看**数据量够不够**，验证曲线看**超参数**，校准曲线看**概率能不能信**，SHAP 与偏依赖图（partial dependence plot, PDP）看方向与交互。面试时按「我要回答哪个问题 → 选哪张图」来组织即可。

## 三、机制

### 3.1 排序类图：ROC、PR 与 KS

这一节回答「模型排得开吗」。三个工具用的是同一份东西：按分数把样本走一遍，每一步记下抓到了多少正例、误伤了多少负例。

#### ROC 曲线（Receiver Operating Characteristic Curve）

* **用途（purpose）**：评估**二分类器（binary classifier）**在不同阈值设定下的表现。ROC 曲线画的是**不同阈值**下**真正例率（True Positive Rate, TPR）**与**假正例率（False Positive Rate, FPR）**之间的权衡，用来直观地看这个二分类器把正负两类分得有多开。
* **两个轴（axes）**：

  * **X 轴**：假正例率（False Positive Rate, FPR）
  * **Y 轴**：真正例率（True Positive Rate, TPR）或召回率（recall）

##### 📊 **关键组件（Key Components）**

| 指标 | 公式 | 怎么读 |
| ----------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| **真正例率（True Positive Rate, TPR）**  | TPR = TP / (TP + FN)                                                                 | 又叫**召回率（Recall）**。衡量真正的正样本里，有多少被正确识别出来。 |
| **假正例率（False Positive Rate, FPR）** | FPR = FP / (FP + TN)                                                                 | 衡量真正的负样本里，有多少被错判成了正。 |
| **阈值（Threshold）**                 | 一个 0 到 1 之间的判定值，决定样本被判为正还是负。 | 把阈值调低会提高 TPR，但也可能把 FPR 一起抬高。 |

* **AUC（Area Under the Curve）**：
  * 取值范围 0 到 1。
  * AUC 越高，类别可分性越好。
  * AUC = 0.5 表示完全没有区分能力（等于随机猜）。
  * 等价定义（面试常被追问）：**AUC = P(随机正样本的得分 > 随机负样本的得分)**；配套的换算关系是 **Gini = 2·AUC − 1**。
* **使用场景（use case）**：比较不同分类器，尤其在类别不平衡时。

![[Pasted image 20250605145035.png]]

**怎么读这条曲线**：从左下角 (0, 0) 往右上角 (1, 1) 走，每遇到一个负例就向右挪一步（FPR 上升），每遇到一个正例就向上挪一步（TPR 上升）。曲线越靠左上角，说明在同样的误杀水平下能抓到更多正例。

**阈值是自由的，0.5 不是**：软件把 0.5 当默认截断值，而 0.5 只是一个约定。同一条曲线上的每个点都对应一个阈值，选哪个点由成本结构决定——这一点与 [[6.3 Performance Metrics]] 的混淆矩阵口径完全一致。

#### PR 曲线（Precision-Recall Curve）

横轴换成召回率（就是 TPR），纵轴换成精确率（precision = TP/(TP+FP)）。两个视图看的是同一组阈值，差别在于纵轴对基础率敏不敏感：

$$\text{Precision} = \frac{\text{TPR}\cdot \pi}{\text{TPR}\cdot \pi + \text{FPR}\cdot (1-\pi)}$$

逐符号读：$\pi$ 是总体的正类比例（基础率）；分子是「真命中的那一块」，分母是「真命中 + 误杀」，其中误杀来自 FPR 乘上负类的占比 $1-\pi$。所以 ROC 上的一个点 $({\rm FPR}, {\rm TPR})$ 不动，基础率一变，PR 上的对应纵坐标就会跟着动。

**两条基线不一样**：ROC 的随机基线是对角线，与基础率无关；PR 的随机基线是水平线 precision = $\pi$，基础率越低基线越低。正类比例很小时（**经验值：低于 10%**），PR 曲线更能拉开模型的差别，因为 FPR 的分母是海量的负例，误杀的绝对数量在 ROC 上看不出来。

**PR 曲线不一定单调**：排序第一名如果是误杀，召回还停在 0 的时候精确率已经掉到 0，随后才回升。第四节的算例里排第一的正好是一个负例，换算成 PR 曲线时就会出现这样一个点。

#### KS 与 Gini：把曲线压成数

* **KS 统计量（Kolmogorov–Smirnov statistic）** = $\max(\text{TPR} - \text{FPR})$，也就是 ROC 上离对角线最远的那一个点到对角线的垂直距离。等价定义是正负样本得分分布的**最大间距** $\max |\text{CDF}_\text{正} - \text{CDF}_\text{负}|$，两条路算出来必须是同一个数。
* **KS 只看一个切点**，AUC 看整条曲线：两个模型可以 AUC 相同而 KS 差很多（第四节给了实例），所以报告里通常一起给。
* **Gini = 2·AUC − 1**：信用风险场景常用它报指标。KS 的经验分档与十分位 lift 表的做法在 [[10.5 模型评估与监控]]（**经验值，各机构口径不一**）。

### 3.2 结构类图：残差图、Q-Q 图、杠杆与 Cook 距离

这一节回答「哪里错了、该往哪改」。图的形状对回 [[6.2 Model Diagnosis_Bias-Variance Tradeoff|偏差-方差]] 的两项，以及 [[1.7 Assumptions]] 的假设清单。

#### 残差图（Residual Plot）

^7d9647

* **用途（purpose）**：通过画误差（残差）来评估**回归模型（regression model）**的表现。
* **残差（residual）** = 实际值 − 预测值。
* **要看什么（what to look for）**：
  * **随机散布（random scatter）**：说明拟合得不错。
  * **出现形状（例如弯曲、漏斗形）**：说明可能存在非线性或异方差（heteroscedasticity，方差不齐）之类的问题。
* **能诊断出什么（helps diagnose）**：
  * 模型结构设定错误（misspecified model structure）。
  * 回归假设被违反（例如同方差假设、线性关系假设）。

![[Pasted image 20250605150014.png]]

**横纵轴的口径**：横轴通常是拟合值（fitted value），也可以换成单个自变量；纵轴一律是残差。用拟合值当横轴时，弯曲对应函数形式，喇叭口对应方差结构。

**形状对动作（逐条对齐 6.2 与 1.7）**：

| 残差图的形状 | 它在说什么 | 对应哪一项 | 修正动作 |
|---|---|---|---|
| U 形 / 倒 U 形弯 | 函数形式设错，漏了非线性 | 高偏差（bias²） | 加二次项、样条、变换自变量；或换模型族 |
| 喇叭口（右宽左窄） | 异方差 | 系数无偏、坏的是 SE | 加权最小二乘、稳健标准误、对 $y$ 取 log / Box-Cox |
| 残差随预测值成倍放大 | 乘性误差结构 | 同上 | 对目标取对数（[[2. Transformations]]） |
| 几个孤立的远点 | 高杠杆或强影响点 | 方差的额外来源 | 看 Cook 距离，缩尾或单独报告 |
| 残差随记录顺序成段 | 独立性被破坏 | 独立性假设 | 聚类稳健标准误、把分组变量放进模型 |

**算一遍：二次关系硬套直线**。真实关系 $y = 1 + 2x + 0.5x^2$，8 个点 $x = 1,\dots,8$，用最小二乘直线 $y = -6.5 + 6.5x$ 拟合：

| $x$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 真实 $y$ | 3.5 | 7 | 11.5 | 17 | 23.5 | 31 | 39.5 | 49 |
| 直线拟合值 | 0 | 6.5 | 13 | 19.5 | 26 | 32.5 | 39 | 45.5 |
| 残差 | **+3.5** | +0.5 | −1.5 | −2.5 | −2.5 | −1.5 | +0.5 | **+3.5** |

残差的和是 0，形状是一头一尾正、中间负的「倒 U 形」：本来应该交替出现的符号变成了 3 段连号，中间四点的残差均值是 −2.0，两端四点是 +2.0。这张图给出的动作是「加一个 $x^2$ 项」，不是「换模型」。

**这张图的盲区**：OLS 残差与 $X$ 正交、而且被杠杆值摊平，所以残差图对「高杠杆点上的大方差」不敏感；撤掉这条前提，你会得到一个看着很干净的残差图和一个错了几十倍的标准误（[[1.7 Assumptions]]）。补救办法是用标准化残差、得分残差，或者直接跑 White / Breusch–Pagan 这类检验作参考。

**logistic 回归里残差图不查正态**：逻辑回归该看经验 logit 图（线性）、EPV（事件数）与校准曲线；残差图在这里的用途是找异常点与看校准。

#### Q-Q 图（Quantile-Quantile Plot）

横轴是理论分位数（正态分布或 GLM 假定分布的分位数），纵轴是样本分位数（通常是标准化残差的分位数），点压住 45° 直线就算对上了。

* **两端上翘**：尾部比假设分布重（大误差比预期多）。
* **整体 S 形**：偏态。
* **个别点远远甩出去**：异常点，先去查这条记录本身。
* GLM 版本用的是 **deviance 残差**，同时看 `deviance/df` 是否接近 1 来查过散布（over-dispersion），见 [[1.2 Generalized Linear Models (GLMs)]]、[[99.9 GLM 进阶题库]]。

**要小心的口径**：正态性只影响小样本下检验统计量的分布，系数的无偏性与标准误的相合性都不靠它，大样本有中心极限定理兜底；真正不会随样本量自愈的是异方差与相关性（[[1.7 Assumptions]]）。所以看到 Q-Q 图偏离直线，先问「样本量多大、我要不要做检验」，再决定要不要动模型。

#### 杠杆值与 Cook 距离（Leverage, Cook's Distance）

* **杠杆值（leverage）** $h_i$：第 $i$ 个观测在自己拟合值上的话语权，来自设计矩阵的 $(X^\top X)^{-1}$ 的对角元素。[[6.2 Model Diagnosis_Bias-Variance Tradeoff]] 里算过的 $\lVert w\rVert^2$ 就是它——同一个量既决定该点的预测方差，也决定这个点在残差图上的拉扯力。
* **Cook 距离（Cook's distance）** $D_i$：把第 $i$ 个点删掉重拟合，系数的变化有多大。杠杆高、残差又大，$D_i$ 才会大。
* **经验值**：杠杆超过 $2p/n$ 或 $3p/n$（$p$ 是参数个数）值得单看，Cook 距离大于 1（小样本里也有用 $4/n$ 的口径）值得单看。各本书的阈值不一样。
* **动作顺序**：先查数据录入错误 → 再看是不是极值该缩尾（[[2. Transformations]]）→ 最后报「含 / 不含该点」两版结果。默认删点等于把不利证据删掉。

#### 校准曲线、学习曲线、验证曲线

| 图 | 横轴 | 纵轴 | 正常长相 | 异常时的动作 |
|---|---|---|---|---|
| 校准曲线（calibration curve） | 预测概率（分箱后的组中值） | 每箱的实际频率 | 点压在 45° 线上 | 高于线 = 低估风险，低于线 = 高估；做保序回归（isotonic）或 Platt 校准 |
| 学习曲线（learning curve） | 训练样本量 | 训练 / 验证误差 | 验证曲线还在降、两线 gap 明显 | 补数据；两条都平在高位 → 加容量 |
| 验证曲线（validation curve） | 超参数取值 | 训练 / 验证误差 | 验证误差有明确的谷底 | 就在谷底取值，不要靠训练误差挑 |

**校准是概率类业务的硬指标**：AUC、KS 对校准完全不敏感，而费率、准备金这类用途要的是「预测 3% 就真赔 3%」。逐箱的 A/E（actual vs expected）是同一件事的表格版，见 [[10.4 评分卡与 WOE 落地]]、[[10.5 模型评估与监控]]。

### 3.3 收益类图：Lift / Gain 图

这一节回答「前 X% 产能值多少钱」。曲线本身不看面积，看的是你那条产线上的一个点。

* **用途（purpose）**：评估分类器的**排序能力（ranking ability）** —— 在**定向营销**或**风险建模**里尤其常用。
* **Lift 图（lift chart）**：

  * 把模型的预测能力与随机挑选做对比。
  * **Lift = 模型表现 / 基线表现（model performance / baseline performance）**。
* **Gain 图（gain chart）**：

  * 沿着排序名单从上往下走，累计捕获了多少比例的正例响应。
* **使用场景（use case）**：

  * 你要挑出 top n% 去做动作时（例如只给 top 10% 的客户打电话）。

#### 🔬 批判性阅读 Lift / Gain（critical reading）

**构造步骤（两个图相同）**：① 在**验证集**上打分 → ② 按预测概率（或预测赔付成本）**降序**排列 → ③ 切十等分（或 20 等分）→ ④ 算每箱的**实际响应率（actual response rate）**。

* **Gain（累计响应）图**：x 轴 = **累计目标人群占比**，y 轴 = **累计捕获事件占比**。
  * **45° 线是随机基线（random baseline）**——随机抽 20% 人群只能拿到 20% 的事件。
  * 曲线与 45° 线的**垂直差距就是 gain（增益）**；曲线越向左上角鼓越好。
* **Lift 图**：某箱 lift =（该箱响应率）÷（总体响应率）。示例说法：`"Cumulative lift at 20% is 55/20 = 2.75× random."`

**怎么批判性读（重点）**：

* **Top-decile lift（首箱 lift）是标准的单一数字摘要**——先报这个数。
* **Lift 应当从头箱往下单调衰减（decay monotonically）**；**非单调（第 3 箱优于第 2 箱）是稳定性或过拟合的红旗，不只是噪声**。
* **在你的运营产能（operating capacity）处读图**：若 SIU 团队只能查 2% 的索赔，**10% 处的 lift 无关紧要**。
* **连续目标（赔付成本）**同样构造：用每箱的**平均实际值**；**首位箱 / 末位箱实际赔付成本之比（top-decile to bottom-decile ratio）**是定价里「我们获得了多少区分度」的标准统计量。
* 在每箱里再加上**实际 vs 预期（actual vs expected）**，这张图就同时变成**校准检查**，不只是排序检查。

**相关图**：洛伦兹 / 集中曲线（Lorenz / concentration curve）；**双 lift 图（double lift chart）——用于把「拟议的新评级方案」与「现行方案」对比**。

**一个容易踩的反直觉点**：lift 的分母是基础率，所以同一个模型、同一个阈值，基础率从 30% 掉到 10% 时命中率会腰斩，而 lift 反而从 1.875 升到 2.50（第四节的表）。报 lift 绝对水平的人，会把「人群变了」说成「效果更好了」。

> 来源：MAGNet §6（Q: Explain a lift chart and a gain chart. How do you read one?）；[[MAGNet 面试真题全解]]

#### 建模后的 EDA（Posterior EDA, Exploratory Data Analysis after Modeling）

* **用途（purpose）**：理解模型本身以及它输出结果的行为。
* **关注点（focus areas）**：

  * **预测概率 / 分数的分布（distribution of predicted probabilities or scores）**。
  * **特征贡献（feature contributions）**，例如 SHAP 值（[[7.4. Quantifying Feature Importance]]）。
  * **分群表现（segment-wise performance）** —— 按组、地区或类别分别评估。
  * **预测不确定性（prediction uncertainty）** —— 在概率模型或贝叶斯方法里尤其相关。
* **使用场景（use case）**：

  * 事后检查可解释性与公平性（interpretability and fairness）。
  * 找出模型的薄弱环节与可改进之处。

## 四、算一遍

### 第 1 步：12 单排一遍序

| 名次 | 单号 | 真实标签 $y$ | 预测概率 $p$ |
|---|---|---|---|
| 1 | #1 | **0**（负） | 0.95 ← 完全分错 |
| 2 | #2 | 1（正） | 0.90 |
| 3 | #3 | 0 | 0.83 |
| 4 | #4 | 1 | 0.78 |
| 5 | #5 | 1 | 0.70 |
| 6 | #6 | 0 | 0.66 |
| 7 | #7 | 1 | 0.62 |
| 8 | #8 | 0 | 0.58 |
| 9 | #9 | 0 | 0.50 |
| 10 | #10 | 0 | 0.42 |
| 11 | #11 | 0 | 0.34 |
| 12 | #12 | 0 | 0.10 |

正例 4 个、负例 8 个，样本基础率 $4/12 = 33.3\%$。分数没有并列，这一步先省掉并列的口径问题（并列的口径在第 2 步末尾说）。

### 第 2 步：把 ROC 的每一步都写出来

阈值从高往低走，每挪一次就多标一单。TPR 的分母是 4，FPR 的分母是 8，所以 TPR 每次跳 0.25、FPR 每次跳 0.125：

| 阈值（p ≥） | 累计标记 | 累计 TP | 累计 FP | TPR | FPR |
|---|---|---|---|---|---|
| —（起点） | 0 | 0 | 0 | 0.000 | 0.000 |
| 0.95 | 1 | 0 | 1 | 0.000 | 0.125 |
| 0.90 | 2 | 1 | 1 | 0.250 | 0.125 |
| 0.83 | 3 | 1 | 2 | 0.250 | 0.250 |
| 0.78 | 4 | 2 | 2 | 0.500 | 0.250 |
| 0.70 | 5 | 3 | 2 | 0.750 | 0.250 |
| 0.66 | 6 | 3 | 3 | 0.750 | 0.375 |
| 0.62 | 7 | 4 | 3 | 1.000 | 0.375 |
| 0.58 | 8 | 4 | 4 | 1.000 | 0.500 |
| 0.50 | 9 | 4 | 5 | 1.000 | 0.625 |
| 0.42 | 10 | 4 | 6 | 1.000 | 0.750 |
| 0.34 | 11 | 4 | 7 | 1.000 | 0.875 |
| 0.10 | 12 | 4 | 8 | 1.000 | 1.000 |

这 13 行就是 ROC 上的 13 个顶点，把后两列当坐标连起来就是曲线。

**手算 AUC（路一：梯形法）**。只有水平段（FPR 增加）才贡献面积，竖直段的宽度是 0。每段宽 $1/8 = 0.125$：

$$\text{AUC} = 0.125\times0.25 + 0.125\times0.75 + 5\times0.125\times1 = 0.03125 + 0.09375 + 0.625 = \mathbf{0.750}$$

读一下这三项：高度 0.25 的那段在标到第 3 单时结束（抓到 1/4 正例），高度 0.75 的那段在标到第 5 单时结束（抓到 3/4），剩下 5 段是 TPR 已经满格之后纯加误杀的部分。

**手算 AUC（路二：数对子）**。AUC 的定义是「随机取一个正例、它的得分高于随机取一个负例」的概率，那就直接把对子数出来：正例 4 个 × 负例 8 个 = 32 对，逐个数赢了多少对——0.90 赢 7 对、0.78 赢 6 对、0.70 赢 6 对、0.62 赢 5 对，合计 24 对：

$$\text{AUC} = \frac{24}{32} = \mathbf{0.750}$$

两条路必须相等，这里都是 0.750——对得上说明表和曲线没有算错。

**并列得分的口径**：如果两个样本分数相同（比如把 #2 的 0.90 改成与 #3 相同的 0.83），这一对按 0.5 计，AUC 变成 $(23 + 0.5)/32 = \mathbf{0.734}$。工具之间报的数不一样，往往是这里没对齐。

### 第 3 步：手算 KS

KS 就是 $\max(\text{TPR} - \text{FPR})$，把上表逐行相减，最大出现在 $1.000 - 0.375 = \mathbf{0.625}$（阈值 $p \ge 0.62$，标 7 单）。换成分布口径也一样：正例得分的累计分布与负例得分的累计分布之间的最大间距就是 0.625。

**KS 和 AUC 不是一回事**：AUC 0.750 说的是整条曲线下的面积，KS 0.625 说的是离对角线最远的那个点。KS 最大点在 $p \ge 0.62$——那时召回已经是 100%，代价是 3/8 的负例被误杀。这个点的位置很重要：如果业务产能只有 3 单，KS 告诉你的「最优切点」根本用不上。

### 第 4 步：在自己的产能点上读图（业务真正要的数）

| 场景 | 阈值 | 标记单数 | 命中率（precision） | 召回 | 误杀 |
|---|---|---|---|---|---|
| 只查 1 单（8% 产能） | p ≥ 0.95 | 1 | **0/1 = 0%** | 0% | 1（正是 #1） |
| 只查前 3 单（25% 产能） | p ≥ 0.83 | 3 | 1/3 = **33.3%** | 1/4 = 25% | 2 |
| 软件默认阈值 | p ≥ 0.50 | 9 | 4/9 = 44.4% | 100% | 5 |
| KS 最大点 | p ≥ 0.62 | 7 | 4/7 = 57.1% | 100% | 3 |
| 全量复核 | p ≥ 0.10 | 12 | 4/12 = 33.3% | 100% | 8 |

同一张 ROC，同一个 AUC，五种做法给出五种不同的命中率。**要报的数字取决于产能**：查 1 单的人拿到 0%，查 3 单的人拿到 33%，而同一个模型在默认 0.5 下要标 9 单才换回全部 4 个正例。


### 第 5 步：AUC 相同的两个排序，曲线可以完全不同

12 个位次上保持不变、只把标签换个位置（相当于换一个模型给出的排序），AUC 恰好也是 0.750 的排法一共有 15 种，它们的 KS 落在 0.500 / 0.625 / 0.750 三个值上。挑两个极端的：

| 排序（按分数降序的标签，1 = 正例） | AUC | KS | KS 所在点 (FPR, TPR) | 前 3 单命中 |
|---|---|---|---|---|
| 本文算例 `010110100000` | 0.750 | 0.625 | (0.375, 1.000) | 1/3 |
| 对照排序 `111000000001` | 0.750 | 0.750 | (0.000, 0.750) | **3/3** |

两个模型的 AUC 一模一样，第一个把误杀排在前头、KS 最大点落在召回 100% 的深处，第二个前三单全是正例、KS 最大点在 FPR = 0 处。**报 AUC 的人看不出这个差别，报 KS 加产能点命中率的人看得到。**

### 条件检验：正类比例从 30% 改成 10%

取阈值 $p \ge 0.70$（标前 5 单）作为操作点，此时 TPR $= 3/4 = 0.75$、FPR $= 2/8 = 0.25$。下面假设类内的得分分布不变、只换人群的基础率 $\pi$：第一行就是本文这 12 单，后两行按 1000 单折算。

| 人群基础率 $\pi$ | 正例数 | 负例数 | TP | FP | Precision | Recall | F1 | lift | ROC 上的点 | AUC |
|---|---|---|---|---|---|---|---|---|---|---|
| 33.3%（本文 12 单样本） | 4 | 8 | 3 | 2 | **60.0%** | 75% | 0.667 | 1.80 | (0.25, 0.75) | 0.750 |
| 30%（部署人群） | 300 | 700 | 225 | 175 | **56.25%** | 75% | 0.643 | 1.875 | (0.25, 0.75) | 0.750 |
| 10%（换成低风险人群） | 100 | 900 | 75 | 225 | **25.0%** | 75% | 0.375 | **2.50** | (0.25, 0.75) | 0.750 |

三行要一起读：

* **ROC 和 AUC 一动没动**。同一组顶点、同一个 0.750，因为它只用类内的排序信息。
* **命中率腰斩**：60.0% → 56.25% → 25.0%。第一段的下滑只是样本基础率（33.3%）与部署人群（30%）的差；第二段才是真正要小心的——基础率掉到 10% 之后，标出来的 300 单里有 225 单是误杀（75%），而召回一点没变。
* **lift 反向上升**：1.80 → 1.875 → 2.50。基础率越低，同样的命中率换算成的 lift 越高，所以 lift 的绝对水平不能跨人群比。

**PR 曲线层面同样会动**。把同一组 ROC 顶点按 $\pi$ 换算成 PR 曲线上的点，曲线下的面积：

| $\pi$ | 随机基线 | PR 面积（AP 口径） | PR 面积（梯形口径） |
|---|---|---|---|
| 30% | 0.30 | **0.505** | 0.405 |
| 10% | 0.10 | **0.211** | 0.163 |

两个口径的绝对值不一样（AP 按每个召回台阶乘该台阶的 precision 求和，梯形按直线插值积分），方向一致：同一模型、同一组 ROC 顶点，基础率从 30% 掉到 10%，PR 面积从 0.505 掉到 0.211。**这就是「不平衡时更喜欢 PR」的量化版本**：ROC 说「模型没变」，PR 说「你每天的实际收益变了」。顺带一个口径提醒——跨工具比 PR 面积之前，先确认对方用的是哪一个口径。

## 五、什么情况下会失灵

### 承重假设

**假设一：样本量够，图上的台阶才代表真实形状。** 12 单只画出 13 个顶点，FPR 只能取 $1/8$ 的格子，AUC 的取值最小间隔是 $1/(4\times8) = 0.031$。撤掉它：把排第一那单的标签从负改成正，AUC 立刻从 0.750 跳到 0.886（$31/35$，动了 0.136），前 3 单命中率从 1/3 变成 2/3——同一个数据集，只动一个标签。小样本里一个复核错案就能把整份报告改写。

**假设二：有一个站得住的对比基线。** AUC 要跟 0.5（ROC 的对角线）比，lift 要跟 1 比，PR 面积要跟基础率比。撤掉它：「AUC 0.750」「lift 2.5」就是两个没有单位的数。更麻烦的是 PR 的基线随人群移动（第四节那张 PR 面积表里 0.30 → 0.10），所以 PR 面积不能跨人群比。

**假设三：读的是同质段，而不是聚合后的平均。** 曲线把地区、渠道、时间段混在一起画。撤掉它：一个段全错、另一个段很好，合起来的 AUC 仍然可能好看，而全错的那些段恰恰是上线后要挨骂的地方。修法是分段读（by segment），至少在报告里附上最差那个段的数。

**假设四：分数分布本身没被改动。** 「ROC 对基础率不敏感」这句的前提是类内的得分分布不变。撤掉它：过采样正类、SMOTE、按先验比例做截距校正都会改分数分布，这时 ROC 也要重画，不能拿训练前的曲线解释校正后的分数（[[6.3 Performance Metrics]] 里重采样破坏校准是同一件事的另一面）。

**假设五：标签可信。** 本文那单负例被排到第一，最常见的原因是标签错或个案异常。撤掉它：标签噪声会把每一个顶点的位置都推歪，而 AUC / KS 只会给出一个更低的数，不会提示你「问题出在标签上」。做评估集时把复核过的与未复核的分开。

**图能看见的前提**：残差图只显示模型与数据的可见部分（OLS 残差与 $X$ 正交、被杠杆摊平）；8 个点的残差表只有 3 段连号，而随机噪声下出现「≤3 段连号」的概率是 $20/70 = 28.6\%$，所以这张图在 8 个点上的功效本来就很低。撤掉它：图看着没问题，你报「模型没问题」，实际上可能只是看不见（[[1.7 Assumptions]] 的承重假设二、三）。

### 与其他工具的边界

| 你想回答的问题 | 用谁 | 为什么不用别的 |
|---|---|---|
| 全阈值排序好不好 | ROC + AUC / Gini | 与阈值、基础率都无关 |
| 正类很稀，只看正类 | PR 曲线 / AP / Lift@k | ROC 看不出误杀的绝对数量 |
| 评分卡截断点选哪里 | KS | 只看一个切点，与 AUC 互补 |
| 我这条产线能捞多少 | Lift / Gain 图 | 面积给不出产能点上的收益 |
| 函数形式对不对 | 残差图 | AUC 对设定错误完全不敏感 |
| 方差齐不齐 | 标准化残差、得分残差、White / Breusch–Pagan | 原始残差图会被杠杆摊平 |
| 概率能不能当频率用 | 校准曲线、逐箱 A/E | AUC 对校准不敏感 |
| 某个点在左右结论吗 | 杠杆值 + Cook 距离 | 残差大小看不出影响力 |
| 补数据还是加容量 | 学习曲线（[[6.2 Model Diagnosis_Bias-Variance Tradeoff]]） | 单张诊断图不告诉你该动哪个旋钮 |

## 六、常见误解

### 误解一：「AUC 0.750 已经不错了，先上线」

**错误想法**：AUC 0.75、KS 0.625，模型排得开，上线跑起来再说。

**为什么容易这么想**：AUC 是阈值无关、基础率无关的「干净」数字（[[6.3 Performance Metrics]] 也是这么介绍的），报告里它通常排在最前面，看着像总评分。

**错在哪一步**：AUC 里没有阈值、没有产能、没有校准。第四节里同一个模型，只查前 3 单时命中 1 单，只查第 1 单时命中 0；换成 10% 基础率的人群，命中率掉到 25%。上线与否要回答的是「在我准备用的那个阈值上，能捞回多少、要付多少误杀」，那是产能点加混淆矩阵的活。

### 误解二：「残差图看着随机，说明设定对了」

**错误想法**：残差就是一团随机散布，函数形式没问题。

**为什么容易这么想**：3.2 那张表给的是「弯曲 → 加项、喇叭 → 加权」的映射，形状既然没出现，自然觉得没事。

**错在哪一步**：把「没有可见结构」当成了「没有结构」。OLS 残差与自变量正交、还被杠杆值摊平，高杠杆点上的大方差基本看不出来；小样本的游程检验也没有功效（8 个点里出现 3 段连号的概率是 28.6%）。要加检查就用标准化残差、得分残差，或者跑异方差检验。

### 误解三：「AUC 一样，两个模型就没区别」

**错误想法**：两个模型 AUC 都是 0.750，随便挑一个。

**为什么容易这么想**：AUC 是「曲线压成一个数」，很容易把面积相等当成曲线相等。

**错在哪一步**：面积相同、形状可以差很多。第四节那两个排序 AUC 都是 0.750，一个 KS 0.625、前 3 单命中 1 单，另一个 KS 0.750、前 3 单命中 3 单。[[10.5 模型评估与监控]] 也说过 AUC 相同而 KS 可以差很多，所以两个一起报，再叠一个产能点的 lift。

### 误解四：「不平衡时 ROC 会虚高，所以只看 PR」

**错误想法**：正类只有 1%，AUC 没意义，直接看 PR 曲线。

**为什么容易这么想**：PR 的纵轴就是命中率，低基础率下它确实立刻显示出「标出来的多是误杀」。

**错在哪一步**：两个视图是同一组 (TPR, FPR) 的两种画法，谁也没有藏着信息；ROC 不是虚高，它只是不把基础率放进纵轴。真正会骗人的动作是拿 PR 面积跨人群比——同一个模型、同一个阈值，AP 从 0.505 掉到 0.211，可以完全只是人群变了。修法不是换图，而是固定人群（或固定基础率）再比，并把召回、产能点命中率、校准各自报清楚。

## 七、面试怎么答

### 30 秒版

> 我先问这张图要回答什么。排序好不好用 ROC 和 AUC——AUC 等于随机正例的得分高于随机负例的概率；只看一个切点就报 KS，`Gini = 2·AUC − 1`。正类很稀时换成 PR 或 lift，因为它们的基线就是基础率，能看出误杀的绝对量。能不能上线看的是我这条产线的产能点：这篇的算例里 AUC 0.750、KS 0.625，可只查前 3 单时命中率只有 33%。结构问题看残差图和 Q-Q 图，概率要直接当频率用就看校准曲线。

### 2 分钟版（要包含的四块）

1. **选图逻辑**：一张图回答一个问题——残差图看结构与异方差，学习曲线看数据量够不够，验证曲线看超参数，校准曲线看概率能不能信，SHAP / PDP 看方向与交互。
2. **口径**：ROC 横轴 FPR、纵轴 TPR；AUC = P(正得分 > 负得分)；KS = max(TPR − FPR)，只看一个切点；0.5 只是软件默认阈值，不是业务阈值。
3. **一个带数字的例子**：12 单、4 个正例，AUC = 24/32 = 0.750（梯形法与数对子两条路都得这个数），KS 0.625；只查前 3 单命中 1 单，只查第 1 单命中 0。
4. **口径敏感性**：同一模型、同一阈值，基础率 30% → 10% 时 Precision 从 56.25% 掉到 25%，PR 面积（AP 口径）从 0.505 掉到 0.211，而 ROC 和 AUC 一动不动；lift 反而从 1.875 升到 2.50。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「AUC 和 KS 什么关系？」 | 都衡量排序：AUC 是整条曲线下的面积，KS 是离对角线最远那点的 TPR − FPR，只看一个切点，两者不可互推 |
| 「为什么不直接看 precision？」 | precision 同时依赖基础率和阈值；比之前先说清是哪个产能点、哪个基础率 |
| 「残差图里看到喇叭口怎么办？」 | 系数仍然无偏、坏的是标准误：加权最小二乘、稳健标准误、对 $y$ 取 log |
| 「Q-Q 图不压线，模型还能用吗？」 | 正态性只影响小样本下的检验；先看样本量与是否需要推断，再查异方差与独立性 |
| 「lift 图怎么构造、怎么读？」 | 验证集打分 → 降序 → 切十等分 → 每箱实际响应率；lift = 该箱响应率 / 总体响应率，在产能点上报 top-decile lift |
| 「概率要当费率用，看什么？」 | 校准曲线加逐箱 A/E；AUC / KS 对校准完全不敏感 |
| 「样本太小画不出曲线怎么办？」 | 说明分辨率：12 单时 AUC 只能落在 1/32 的格子上，动一个标签就是 0.136；这时报区间，或用交叉验证把折合起来估 |

### Q: Explain a lift chart and a gain chart. How do you read one?

> 🎯 真题问法（MAGNet §6）｜ 深潜来源：MAGNet §6（lift / gain 的**连续目标**部分）＋ 上文「🔬 批判性阅读 Lift / Gain」＋ [[10.4 评分卡与 WOE 落地]]

> ⚡ 先说的那一句
> 「分类目标看的是**抓到多少事件**；**连续目标（赔付成本）**同样构造，只是每箱换成**平均实际值** —— **首位箱与末位箱实际赔付成本之比**就是定价里「我们获得了多少区分度」的标准统计量；再在每箱里加上**实际 vs 预期（actual vs expected, A/E）**，这张图就同时变成**校准检查**，而不只是排序检查。」

**连续目标（赔付成本）怎么构造**：① 在**验证集**上打分 → ② 按**预测赔付成本降序**排列 → ③ 切十等分（或 20 等分）→ ④ 每箱算**平均实际值（average actual value per bin）**，而不是响应率。其余读法（**单调衰减**、**在运营产能处读图**）与分类版一致。

**连续目标的三个标准统计量**：

* **首位箱 / 末位箱实际赔付成本之比（top-decile to bottom-decile ratio）**：定价里报「我们获得了多少区分度」的那个数。
* **逐箱 A/E（actual vs expected）**：同时是**校准检查（calibration check）**；A/E 系统性偏离 1 的箱位说明该段费率偏高或偏低。
* **Gini / 洛伦兹面积**：把排序能力压缩成一个数（连续目标版本的 AUC / Gini）。

**相关图要点名**：**洛伦兹 / 集中曲线（Lorenz / concentration curve）**；以及**双 lift 图（double lift chart）—— 用于把拟议的新评级方案与现行方案对比**（同一张图上两条累计曲线，回答「换方案到底换来了什么」）。

**速查（背这三行）**：

* `连续目标的 lift = 排序 + 区分度`
* `A/E = 校准`
* `双 lift = 方案对比`

> 🔗 会被追问到
> - 「**赔付成本里有很多 0（零赔付）怎么办？**」→ 先做**频率 × 严重度（frequency–severity）**分解：频率用分类版 lift，严重度用连续版 lift；直接对合并损失做 lift 会被零膨胀稀释（是否两段式建模**需核对**具体团队口径）。
> - 「**按预测赔付成本排序，会不会只排出了大额案件？**」→ 会，所以要在**同质段内（by segment）**读，并且看 **A/E 而不只是比值**。
> - 「**双 lift 图怎么看结论？**」→ 比两方案在**同一产能点**的累计 A/E 或累计 lift；新方案要在**大部分产能区间**都不差、**尾部不劣化**，才叫改进。
> - 「**lift 高但 Gini 一般？**」→ 说明**头部强、中段弱**：运营上是好事（决定产能的是头部），定价上要看**整条曲线**（费率表在各段都要准）。
> - 「**为什么不能只看 AUC？**」→ AUC 是**全局、阈值无关**的排序指标；它不告诉你**前 2% 产能处的收益**，也不管**校准**，而这两件事才是保险 / 催收 / 反欺诈真正付钱的地方。

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "I choose the plot by the question. ROC and AUC answer whether the model ranks well — AUC is the probability that a random positive scores above a random negative, so it's threshold-free. When the event rate is very low I'd rather look at a precision-recall curve or a lift chart, because their baseline is the event rate itself, so they show the false positives that ROC hides."

**How I read each plot**

> "For structure I look at residuals against fitted values: curvature means the functional form is wrong and a funnel means heteroscedasticity, so I'd add a quadratic term, or switch to weighted least squares or a log target. A Q-Q plot tells me about the tails, and leverage plus Cook's distance tell me whether a single policy is driving the fit."

**If they push back**

> "The trap is reading a lift or gain chart at the wrong point. I read it at my operating capacity — if the SIU team can only review 2% of claims, the lift at 10% is irrelevant. And I'd never compare lift or precision across populations with different event rates: on the same model and the same threshold, going from a 30% to a 10% event rate cut precision from about 56% to 25% while the ROC curve didn't move at all."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话说明 |
|---|---|---|
| 受试者工作特征曲线 | ROC curve | 横轴 FPR、纵轴 TPR 的全阈值曲线 |
| 真正例率 / 召回率 | true positive rate (TPR) / recall | $TP/(TP+FN)$ |
| 假正例率 | false positive rate (FPR) | $FP/(FP+TN)$ |
| 曲线下面积 | AUC / area under the ROC curve | $=P(\text{正得分}>\text{负得分})$ |
| 基尼系数 | Gini | $2\cdot\text{AUC}-1$ |
| KS 统计量 | Kolmogorov–Smirnov statistic | $\max(\text{TPR}-\text{FPR})$，正负得分分布最大间距 |
| 精确率-召回率曲线 | precision-recall (PR) curve | 基线 = 基础率，不平衡时看它 |
| 平均精度 | average precision (AP) | PR 曲线面积的常用口径 |
| 阈值 | threshold | 判定为正的分界，0.5 只是默认值 |
| 残差图 | residual plot | 残差对拟合值；弯曲 / 喇叭口各对应一种修正 |
| 残差 | residual | 实际值 − 预测值 |
| 异方差 | heteroscedasticity | 方差不齐；系数无偏、标准误错 |
| Q-Q 图 | quantile-quantile plot | 样本分位数对理论分位数 |
| 杠杆值 | leverage | 该观测对自身拟合值的影响力 |
| Cook 距离 | Cook's distance | 删除该点后系数的变化量 |
| 缩尾 | winsorizing | 把极值替换为分位点值，限制杠杆 |
| 提升图 | lift chart | 各箱响应率 ÷ 总体响应率 |
| 增益图 | gain chart | 累计捕获事件占比对累计人群占比 |
| 双 lift 图 | double lift chart | 拟议方案 vs 现行方案的累计曲线 |
| 洛伦兹曲线 | Lorenz / concentration curve | 连续目标版的排序曲线 |
