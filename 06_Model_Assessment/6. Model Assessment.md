# 6. 模型评估（Model Assessment）

## 速览 At a glance

**速记**

模型评估要回答两句：「能不能上线」和「往哪改」，答案由四件事共同决定。一是数字从哪来——训练 / 验证 / 测试怎么切、有没有泄漏，测试集用过一次就不再是无偏估计。二是容量对不对——训练与验证误差都高是欠拟合（高偏差），训练低、验证高是过拟合（高方差），先看训练误差再决定加容量还是加正则化。三是报哪个数——一切从混淆矩阵出发，误杀贵看精确率、漏掉贵看召回率，不平衡时准确率会被多数类带偏，排序才用 AUC / KS / Gini / Lift。四是配哪张图——ROC 与 PR 看排序，残差图与 Q-Q 图看结构，Lift / Gain 看产能点的收益，校准曲线看概率能不能直接当频率用。面试的分水岭不在会不会算，而在能不能说出「在我这个基础率和这个阈值下，哪类错误更贵」。

**一句面试答法**

> "Model assessment has three layers: how the numbers were produced — splits and leakage; whether the capacity is right — training error versus validation error; and which metric answers my question. I start from the confusion matrix, use precision when false positives are expensive and recall when false negatives are, and report AUC, KS or lift when ranking and business payoff are what matter."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 训练 / 验证 / 测试集 | train / validation / test split | 拟合参数 / 调超参 / 只用一次的评估 |
| 交叉验证 | cross-validation (CV) | 折间轮转，取平均 |
| 数据泄漏 | data leakage | 训练时看到预测时拿不到的信息 |
| 欠拟合 | underfitting | 高偏差：训练与验证误差都高 |
| 过拟合 | overfitting | 高方差：训练低、验证高 |
| 混淆矩阵 | confusion matrix | TP / FP / FN / TN 四个格子 |
| 精确率 / 召回率 | precision / recall | 标记里真的比例 / 真的抓到的比例 |
| 曲线下面积 | AUC | 与阈值无关的排序能力 |
| KS 统计量 | KS statistic | $\max(\text{TPR}-\text{FPR})$，只看一个切点 |
| 提升度 | lift | 前 k% 人群里正类的富集倍数 |
| 校准 | calibration | 预测概率与真实频率对齐 |
| 诊断图 | diagnostic plot | 一张图回答一个问题 |

## 这一章怎么组织

看一次模型评估的完整顺序：先确认数字可信，再看容量对不对，然后选指标，最后用图回答具体问题。

| 顺序 | 环节 | 笔记 | 一句话定位 |
|---|---|---|---|
| 1 | 数据准备与验证 | [[6.1 Data Preparation & Validation]] | 你报出去的数字代表什么：切分、交叉验证、泄漏 |
| 2 | 偏差-方差诊断 | [[6.2 Model Diagnosis_Bias-Variance Tradeoff]] | 该加容量还是加正则化：误差分解与诊断顺序 |
| 3 | 指标 | [[6.3 Performance Metrics]] | 用哪个数说「好」，以及它会在什么条件下骗你 |
| 4 | 诊断与可视化 | [[6.4 Diagnostic & Visualization Tools]] | 排序 / 结构 / 收益 / 校准：一张图回答一个问题 |

这四步不能跳着做：切分一破，后面所有数字都不用看了；容量没判断就去比指标，相当于在不知道「该改哪」的情况下挑一个最好看的数。

---

### 🔹 **[[6.1 Data Preparation & Validation]]**

* **Train/Validation/Test Splits** —— 把数据切成**训练集 / 验证集 / 测试集**三段：训练集拟合参数，验证集做模型选择与调参，测试集只在最后用一次。这样切分是为了让性能评估**无偏（unbiased）**：如果用训练数据自评，模型一定显得比实际好。
* **Cross-Validation** —— 交叉验证（cross-validation）：用 k-fold 或分层抽样（stratified sampling）轮流留出一折做验证，把 K 次结果平均。好处是评估不依赖某一次切分的运气，样本少时也能用上全部数据，结果更稳健。
* **Data Leakage** —— 数据泄漏（data leakage）：训练时不小心让测试集信息（或目标变量的未来信息）进了特征，离线指标虚高、上线立刻崩。要主动识别并阻断泄漏路径。Data leakage inside target/feature

---

### 🔹 **[[6.2 Model Diagnosis_Bias-Variance Tradeoff]]**

* **Underfitting**（欠拟合，对应高偏差 high bias）：
  * 训练集和验证 / 测试集上的误差**都高** —— 模型太简单，没学到数据里的结构。
* **Overfitting**（过拟合，对应高方差 high variance）：
  * 训练集误差低，但验证 / 测试集误差**明显更高** —— 模型把训练集的噪声也背下来了。

诊断口诀：**两边都高 = 欠拟合；一边低一边高 = 过拟合。**

---

### 🔹 **[[6.3 Performance Metrics]]**

#### 🟦 *Regression Metrics*（回归指标）：

* **RMSE**（Root Mean Squared Error，均方根误差）—— 与目标同量纲，因为平方而对大误差惩罚更重。
* **MAPE**（Mean Absolute Percentage Error，平均绝对百分比误差）—— 百分比形式、跨数据集可比，但真值接近 0 时会被放大甚至除零。
* **R-squared (R²)**（决定系数 coefficient of determination）—— 模型解释了多少目标方差；注意它**可以为负**（比直接用均值预测还差时）。

#### 🟩 *Classification Metrics*（分类指标）：

* **Accuracy**（准确率）—— 类别平衡时好用，不平衡时会被多数类带偏。
* **Precision**（精确率）—— 预测为正的里面真正为正的比例；错判为正的代价高时看它。
* **Recall**（召回率）—— 真正为正的里面被找出来的比例；漏掉正例代价高时看它。
* **AUC**（Area Under the ROC Curve，ROC 曲线下面积）—— 遍历所有阈值衡量排序能力，与阈值无关。

---

### 🔹 **[[6.4 Diagnostic & Visualization Tools]]**

* **ROC Curve** —— ROC 曲线：横轴 FPR、纵轴 TPR 的轨迹，用于评估二分类器，读的是各阈值下的取舍。
* **Residual Chart** —— 残差图：画残差对预测值（或某特征）的散点，检查回归模型是否还残留没被解释的结构；出现弯曲或喇叭形就说明设定有问题。
* **Lift/Gain Chart** —— Lift / Gain 图：把样本按预测分位排序，衡量「取前 X% 能捞到多少目标样本」，是把排序效果翻译成业务收益的工具。
* **Posterior EDA** —— 建模后的探索性分析（posterior EDA）：看模型输出与各特征的分布关系，用来解读模型行为、发现异常群体。

## 面试串讲路径

面试官问「你怎么知道模型好不好」，按这个顺序讲，每一步都在为下一步扫清前提：

1. **先问用途**。要的是排序（谁会出事）、阈值决策（标多少单去核查）、还是把概率当频率用（定价、准备金）？用途决定看哪一类指标，也决定要不要校准。
2. **说清数字从哪来**。训练 / 验证 / 测试怎么切，有没有泄漏，测试集用过几次。这一段对应 [[6.1 Data Preparation & Validation]]；一句话收口：「一破，后面所有数都不用看了」。
3. **先诊断容量，再谈好坏**。训练误差高不高？高就是欠拟合（高偏差），加容量 / 加特征 / 减正则；训练误差已经很低而验证高，才谈过拟合（高方差），加正则 / 补数据 / 早停。对应 [[6.2 Model Diagnosis_Bias-Variance Tradeoff]]。
4. **报指标，从混淆矩阵出发**。误杀贵讲精确率，漏掉贵讲召回率，不平衡时先点明准确率会骗人；排序用 AUC / KS / Gini，业务收益用 Lift。对应 [[6.3 Performance Metrics]]。
5. **配一到两张图把话讲死**。ROC / PR 看排序与不平衡，残差图与 Q-Q 图看结构，Lift / Gain 看产能点的收益，校准曲线看概率能不能直接用。对应 [[6.4 Diagnostic & Visualization Tools]]。
6. **收口报三个东西**：一个基线（随机、现行规则或上一版模型）、一个产能点（我实际只能查多少）、一句口径（基础率、阈值、样本量）。再补一句「什么条件下这个结论会翻」——例如基础率从 30% 掉到 10% 时命中率会腰斩，而 AUC 一动不动。

被追问时最容易加分的两句：**Lift / Gain 要在运营产能处读**（查不了 10% 就别报 10% 处的 lift）；**AUC / KS 是排序指标，对校准不敏感**（概率要直接用就得另看校准曲线）。
