## 速览 At a glance

**速记**

p 值问的是「**假如真的没效应，我看到的这批数据有多罕见**」：条件在 $H_0$ 上，不是条件在数据上。所以 p=0.03 不等于「97% 是真的」，p>0.05 也不等于「没效应」。判决只有两种错误：Type I（假阳性，概率是事先定的 $\alpha$）和 Type II（假阴性，概率 $\beta$，取决于效应量、样本量和 $\alpha$），功效 $=1-\beta$ 的行业目标是 0.80。p 值里混着三样东西——效应量、样本量、噪声，所以它**不能回答「效应有多大」**：1 个单位的差异在每组 n=10⁴ 时 p=0.48，n=10⁶ 时 p≈1.5×10⁻¹²。要谈大小就报效应量 + 置信区间（95% CI 不含 0 与双尾 p<0.05 等价）。还有两个必须说出口的坑：**反复偷看结果**会把实际假阳性率从 5% 抬到 19%（10 次查看）、32%（50 次查看）；**同时检验 20 个指标**有 64% 的概率至少撞到一个假阳性。

**一句面试答法**

> "A p-value is the probability of seeing data at least as extreme as ours, assuming the null is true — it is not the probability that the null is true. With p = 0.04 I'd reject at the 5% level, but I'd immediately report the effect size and the confidence interval, because significance and practical importance are different questions."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 零假设 | null hypothesis ($H_0$) | 默认立场：没有效应 / 没有差异 |
| 备择假设 | alternative hypothesis ($H_1$) | 想证明的效应，决定单尾还是双尾 |
| 检验统计量 | test statistic | 把数据压成「离 $H_0$ 多远」的一个数 |
| p 值 | p-value | $H_0$ 为真时出现当前或更极端结果的概率 |
| 显著性水平 | significance level ($\alpha$) | 事先定的假阳性容忍度，惯例 0.05 |
| 第一类错误 | Type I error | 假阳性：没效应说成有 |
| 第二类错误 | Type II error ($\beta$) | 假阴性：有效应没检出 |
| 功效 | power ($1-\beta$) | 真有效应时能检出的概率 |
| 效应量 | effect size | 差异的大小（原始单位或 σ 为单位） |
| 等价检验 | equivalence test (TOST) | 正面证明「差异足够小」 |
| 多重比较 | multiple comparisons | 检验越多，假阳性越多 |
| 窥视 | peeking | 反复看 A/B 结果会抬高实际 $\alpha$ |
| 最小有意义效应 | minimum detectable effect (MDE) | 功效分析要先定的目标效应 |
| 置信区间 | confidence interval (CI) | 效应量 + 精度的报告口径 |

## 一、先看一个问题

面试官的原话是「给你 p=0.04，你会怎么解读？」，这句话背后在考什么：你会不会把 p 值当成「效应为真的概率」或者「效应大小」。

先看一个真实会遇到的场面。A/B 测试：对照组 1000 次曝光 100 次转化（10%），实验组 1000 次曝光 130 次转化（13%）。算出来双尾 **p ≈ 0.036**。产品经理问两件事：

1. 「能上线吗？」——这里要的是决策，而 p=0.036 只说明「这 3 个百分点的差异不太像纯噪声」；
2. 「能提升多少？」——p 值**答不了**这个问题。要看差异的 95% 置信区间：$[0.2\%,\ 5.8\%]$。下界离 0 很近，意味着真实提升可能只有 0.2 个百分点。

同一份数据，p 值给的是「像不像噪声」，CI 给的是「差多少、可能差到多小」。第四步会把这两个数从头算一遍，并且回答一个更扎手的问题：如果这个 3 个百分点的效应放到一个 100 万人的样本里，p 会变成多少。

## 二、核心直觉

### 法庭类比

$H_0$ = 「被告无罪」，数据 = 证据，$\alpha$ = 「判错人的容忍度」，p 值 = 「**如果被告真的无罪**，出现这么可疑的证据的概率」。p 很小 → 证据与「无罪」太不兼容 → 判有罪。

**像什么**：举证责任的分配很像——默认立场是无罪，要有足够强的证据才推翻。
**不像什么**：法庭只说「证据不足，不能定罪」，不说「证明无罪」；而且法庭不会因为「起诉了 20 个人」而自动调高每个人的定罪门槛（多重比较问题在统计里才需要专门处理）。

### 一个反直觉的性质：$H_0$ 为真时，p 值在 $[0,1]$ 上均匀分布

这句话的意思是：在一个「真的什么效应都没有」的世界里，p 值有 5% 的概率落在 0–0.05，也有 5% 的概率落在 0.5–0.55。**p 值小不证明 $H_0$ 假，它只说明「数据在 $H_0$ 下不太常见」。**

由此直接得到两个后果：做 20 次独立检验，有 64% 的概率至少撞到一个 p<0.05；反复偷看同一个实验的结果，等于反复检验。

## 三、机制

### 3.1 p 值的严格定义

| 概念 | English | 是什么 | 例子 |
|---|---|---|---|
| 零假设 | null hypothesis, $H_0$ | 默认立场：**没有效应 / 没有差异** | 「新费率和新旧费率赔付率相同」 |
| 备择假设 | alternative hypothesis, $H_1$ / $H_a$ | 你希望证明的东西 | 「新费率赔付率更低」 |
| 检验统计量 | test statistic | 把数据压成一个数，衡量「离 $H_0$ 多远」 | $z=2.10$、$t=3.4$、$\chi^2=8.33$ |
| 拒绝域 / 显著性水平 | rejection region / $\alpha$ | 事先定好的「多离谱才算离谱」的门槛 | $\alpha=0.05$ |
| p 值 | p-value | 观测到「当前或更极端」结果的概率（$H_0$ 为真时） | $p=0.0355$ |
| 结论 | reject / fail to reject $H_0$ | 只允许说「拒绝」或「不拒绝」，**不说「接受 $H_0$」** | 「在 5% 水平上拒绝 $H_0$」 |

> **p 值 = 在 $H_0$ 为真的前提下，观测到「当前结果或更极端结果」的概率。**

$$p=P\!\left(\,\underbrace{T(\text{data})\ \text{至少和观测值一样极端}}_{\text{“更极端”的方向由 } H_1 \text{ 决定}}\ \Big|\ H_0\ \text{为真}\right)$$

**🔊 怎么读这个公式**：$T(\text{data})$ 读「检验统计量（由数据算出的那个数）」；竖线「$|$」读作「**在……条件下**」——这是全句的灵魂：**条件在 $H_0$ 上**，不是条件在数据上。所以：

| 说法 | 对不对 |
|---|---|
| 「$H_0$ 为真时，出现这么极端结果的概率是 3.5%」 | ✅ 正确（这就是 p 值） |
| 「$H_0$ 为真的概率是 3.5%」 | ❌ 反了（这是贝叶斯后验，还要先验，见 [[9.6 贝叶斯基础与基础率谬误]]） |
| 「效应为真的概率是 96.5%」 | ❌ 反了，且混入了先验 |
| 「效应这么大的概率是 3.5%」 | ❌ 混淆了 p 和效应量 |

**关键一步在「更极端」的方向**：$H_1:\mu\ne\mu_0$ → 双尾（两侧都算「极端」）；$H_1:\mu>\mu_0$ → 单尾。**同一个数据、同一个 z 值**，双尾 p 是单尾的 2 倍——所以「先看数据再决定用单尾还是双尾」是一种作弊（等价于多重比较，见 [[9.7 多重比较与选择偏差]]）。

**什么时候不能用这个定义**：$H_0$ 必须是**事先定好的**一个具体假设。数据看完再回头挑一个 $H_0$、或者把「p 值最大的那个指标」当主指标，检验的逻辑就失效了（这属于 [[9.7 多重比较与选择偏差]] 的范围）。

### 3.2 两类错误、显著性水平与功效

| 判决 ↓ / 真相 → | $H_0$ 为真（真的没效应） | $H_0$ 为假（真的有效应） |
|---|---|---|
| **拒绝 $H_0$**（说「有显著差异」） | **第一类错误 Type I error**（假阳性），概率 = $\alpha$ | ✅ 正确发现，概率 = **功效 power = 1 − β** |
| **不拒绝 $H_0$**（说「不显著」） | ✅ 正确，概率 = $1-\alpha$ | **第二类错误 Type II error**（漏检/假阴性），概率 = $\beta$ |

**中文讲清这两个错误（面试必问）**：

- **第一类错误（Type I error, $\alpha$）**：**误报**——本来没效应，你说有（保险类比：把好客户误判成高风险）。$\alpha$ 就是你**事先**愿意接受的误报率，通常取 0.05。
- **第二类错误（Type II error, $\beta$）**：**漏报**——本来有效应，你说没有（把高风险客户放过）。它没有固定值，取决于效应量、样本量和 $\alpha$。
- **功效（power）= 1 − β**：真有戏的时候，你能把它检出来的概率。行业惯例目标是 **0.80**（**经验值，各机构不一致**）。
- **权衡**：固定 n 时，把 $\alpha$ 收紧（比如 0.05→0.01）会**降低功效**（更难拒绝），这就是「宁可放过一千，不可错杀一个」的代价；要两头都改善，只能**加样本量**。

$$\text{Power}(\alpha,n,\delta)=\Phi\!\left(\frac{\delta\sqrt n}{\sigma}-z_{1-\alpha/2}\right)+\Phi\!\left(-\frac{\delta\sqrt n}{\sigma}-z_{1-\alpha/2}\right)$$

**🔊 怎么读这个公式**：$\delta$ 读「delta」= **效应量（effect size）**，写成真实差异（例如「平均赔付低 300 元」）；$\sigma$ 是数据本身的标准差；$\frac{\delta\sqrt n}{\sigma}$ 读「**信噪比 × √n**」——这是功效的发动机；$z_{1-\alpha/2}$ 是门槛（双尾 0.05 时 = 1.96）；$\Phi$ 读「标准正态的 CDF」，把「离门槛多少个标准差」翻译成概率。第二项很小时可以忽略。

#### 功效的三个决定因素（中文一句话版）

| 因素 | 变大时功效怎么变 | 为什么 |
|---|---|---|
| **效应量（effect size）$\delta$** | **变大** | 信号更强，更容易被看见（$\delta$ 在分子） |
| **样本量 $n$** | **变大**（但只是 $\sqrt n$ 的速度） | 噪声被平均掉，SE 变小（$\sqrt n$ 在分子） |
| **显著性水平 $\alpha$** | **变大**（放松门槛） | 门槛低了更容易拒绝，但误报也更多（$z_{1-\alpha/2}$ 变小） |

#### 具体数字（可以现场算）

在双尾 $\alpha=0.05$、单样本 z 检验下：

| 效应量 $\delta$（以 $\sigma$ 为单位） | 样本量 n | 功效 power | 说明 |
|---|---|---|---|
| 0.5 | 64 | **0.979** | 大效应 + 中等样本 → 几乎必被检出 |
| 0.3 | 100 | **0.851** | 刚过 80% |
| 0.2 | 100 | **0.516** | 小效应 + 小样本 → **约一半的案子会漏掉** |
| 0.2 | 400 | **0.979** | 同样的小效应，样本翻 4 倍就检出来了 |
| 0.1 | 100 | **0.170** | 极小效应 → 基本检不出来（**「不显著」只是样本不够**） |

要达到 **80% 功效**需要的样本量（**单样本**、同 $\alpha=0.05$）：$n=(z_{0.975}+z_{0.80})^2/\delta^2=(1.96+0.8416)^2/\delta^2$（**两组比较时每组再乘 2**）

| $\delta$（以 $\sigma$ 为单位） | 0.5 | 0.3 | 0.2 | 0.1 |
|---|---|---|---|---|
| 需要 n | **32** | **88** | **197** | **785** |

→ **规律**：效应量减半，样本量要变 4 倍。所以「做功效分析（power analysis）」是**实验前的标准动作**：先定最小有意义的效应量，再反推样本量。


**招聘/面试里的加分句**：「如果一个 A/B 实验做完不显著，我会先算它的功效。如果功效只有 0.2，那结论应该是『样本不够，无法判定』，而不是『这个改动没效果』。」

### 3.3 检验怎么选、多重比较怎么处理

| 场景 | 用哪个检验 | 前提/备注 |
|---|---|---|
| 一个均值 vs 一个定值 | **单样本 t 检验**（$t_{n-1}$） | 近似正态或 n 大；σ 未知 → 用 t 不用 z |
| 两组均值比较（独立） | **双样本 t 检验**（Welch 更稳） | 方差不齐就用 Welch；n 小且偏 → Mann–Whitney |
| 同一批对象前后比较 | **配对 t 检验（paired t）** | 配对能消掉个体差异 → 功效更高 |
| 两组比例比较 | **两比例 z 检验 / 卡方检验** | A/B 测试最常用 |
| 分类变量是否独立（r×c 表） | **卡方检验（chi-square test）** | 每格期望频数 ≥5（经验值）；否则用 **Fisher 精确检验** |
| 单个分类变量是否服从某个分布 | 卡方拟合优度检验 | 自由度 = 类别数 − 1 − 估计参数个数 |
| **三组以上均值比较** | **ANOVA（F 检验）** | 总检验（omnibus）：「至少有一组不同」；具体哪组不同要做事后多重比较 |
| 嵌套模型比较 / 回归整体显著性 | **F 检验** | 比较 RSS 或 $R^2$ 的增量，自由度差 = 参数个数差 |
| GLM/逻辑回归的单个系数 | **Wald 检验**（$z=\hat\beta/\text{SE}$） | 大样本渐近正态；分离时失效（[[1.6 Estimation Issues & Separation]]） |
| GLM 的嵌套模型比较 | **似然比检验（likelihood ratio test）** | $\text{LR}=-2(\ell_0-\ell_1)\sim\chi^2_{\Delta p}$ |
| 不满足正态、样本小 | 非参数：Mann–Whitney / Wilcoxon / Kruskal–Wallis / permutation | 换的是「中位数/秩」的假设 |
| 多个实验组 vs 一个对照 | Dunnett 校正 | 只比较 vs 对照，比 ANOVA + 全部两两更有效 |

**卡方的具体数字例子**：某险种按「是否有安全气囊」×「一年内是否出险」交叉表，两行各 100 个保单：

|  | 出险 | 未出险 |
|---|---|---|
| 无气囊 | 30 | 70 |
| 有气囊 | 50 | 50 |

期望频数都是 40 与 60（行合计 100、列合计 80/120、总数 200）：

$$\chi^2=\frac{(30-40)^2}{40}+\frac{(70-60)^2}{60}+\frac{(50-40)^2}{40}+\frac{(50-60)^2}{60}=2.5+1.67+2.5+1.67=8.33$$

**🔊 怎么读这个公式**：$\chi^2$ 读「卡方」，是「**每个格子的（实际 − 期望）的平方除以期望**」再加起来——也就是「偏离独立性有多远」的一个总分。自由度 $=(行-1)(列-1)=1$，临界值 3.84（$\alpha=0.05$）。这里 $\chi^2=8.33>3.84$ → **拒绝独立性**（$p\approx0.004$）：气囊与出险率有关联。
（注意：这里**只能说关联**，不能说气囊导致出险变化——相关≠因果，见 [[9.5 相关、协方差与相关不等于因果]]。）

#### 多重比较：为什么「多试几次」总会显著

做 $m$ 次**独立**检验、每次 $\alpha=0.05$、全部 $H_0$ 为真时：

$$P(\text{至少一次假阳性})=1-(1-\alpha)^m=1-0.95^{m}$$

**🔊 怎么读这个公式**：$(1-\alpha)$ 是「这一次**没**误报」的概率；$(1-\alpha)^m$ 是「**m 次全都没**误报」（独立才可乘）；整个式子读「**1 减去全都没误报**」= 至少有一次误报的概率。

| 检验次数 m | 5 | 10 | 20 | 50 | 100 |
|---|---|---|---|---|---|
| 至少一次假阳性 | **22.6%** | **40.1%** | **64.2%** | **92.3%** | **99.4%** |

→ **做 20 次检验，有 64% 的概率至少出现一个「p<0.05」但其实什么都没有的发现。** 校正方法（Bonferroni / Holm / FDR）与机器学习里对应的选择偏差，全部在 [[9.7 多重比较与选择偏差]]。

**同一件事的另一种形式：偷看（peeking）**。A/B 测试里每来一批数据就看一次、显著了就停，等价于把同一个假设检验做了很多次。用布朗运动模拟等间隔查看（每次查看的统计量是累计 z 值）：

| 查看次数 | 2 | 5 | 10 | 20 | 50 |
|---|---|---|---|---|---|
| 实际假阳性率（名义 5%） | 8.3% | 14.2% | **19.4%** | 24.8% | 32.0% |

（40 万次模拟，`np.random.default_rng(11)`。）**只查一次的 5%，在查看 10 次之后变成 19.4%。** 这不是「看数据」的错，是「看数据之后做了决定」的错——要正式允许中途查看，就用序贯检验（sequential test / group sequential design、alpha spending）。

### 3.4 置信区间比 p 值信息更多

| | p 值 | 95% 置信区间 |
|---|---|---|
| 给「方向」吗 | ❌ 不给（只有双侧的话连正负都不知道） | ✅ 给（区间在哪一侧） |
| 给「大小」吗 | ❌ 不给 | ✅ 给（点估计） |
| 给「精度」吗 | ❌ 不给 | ✅ 给（区间多宽） |
| 受样本量影响 | 直接受影响 | 也受影响，但**同时**显示效应与精度 |
| 一致性 | — | 95% CI 不含 0 ⇔ 双尾 p<0.05（同一个 Wald 检验） |

## 四、算一遍

### 第 1 步：最小可复算的 p 值——10 次全正面

一枚硬币抛 10 次，10 次都是正面。$H_0$：硬币公平（$p=0.5$）。双尾精确 p 值：

$$p=2\times P(X=10\mid H_0)=2\times\binom{10}{10}0.5^{10}=2\times0.5^{10}=\mathbf{0.001953}$$

比 0.05 小得多 → 拒绝「公平」。**这一步的价值在于「更极端」的方向**：双尾要把 $X=10$ 和 $X=0$ 两种情况都算进去（它们同样极端），所以是 2/1024，不是 1/1024。

顺带一个校准：如果用正态近似算这个 p 值（$z=(10-5)/\sqrt{10\times0.25}=3.162$），得到 0.00157，**比精确值小 20%** —— 小样本的尾部照例不准（[[9.2 抽样分布与中心极限定理]] 第 3 步那组尾部的数字）。

### 第 2 步：A/B 测试的完整演算

对照组 1000 次曝光 100 次转化（$\hat p_1=0.10$），实验组 1000 次 130 次（$\hat p_2=0.13$）。

合并比例（两比例 z 检验的标准做法，因为 $H_0$ 说两组同一个 $p$）：

$$\bar p=\frac{100+130}{2000}=0.115$$

$$\text{SE}=\sqrt{\bar p(1-\bar p)\left(\frac1{n_1}+\frac1{n_2}\right)}=\sqrt{0.115\times0.885\times\frac{2}{1000}}=\mathbf{0.014267}$$

$$z=\frac{0.13-0.10}{0.014267}=\mathbf{2.103}\ \Longrightarrow\ \text{双尾 }p=2\Phi(-2.103)=\mathbf{0.0355}$$

差异的 95% CI（直接用差异的 SE，不用合并比例）：

$$0.03\pm1.96\times0.014267=[\mathbf{0.00204},\ \mathbf{0.05796}]$$

把两个数字并排放：

| 口径 | 数字 | 它回答的问题 |
|---|---|---|
| p 值 | 0.0355 | 「这么极端的差异，在没效应的世界里出现的概率是 3.6%」 |
| 95% CI | [0.2%, 5.8%] | 「真实提升可能是 0.2 个百分点，也可能是 5.8 个百分点」 |

**CI 的下界离 0 只有 0.2 个百分点**，说明这个显著性很脆弱：再来一点噪声就没了。这正是「p<0.05 就上线」的问题所在——0.2 个百分点的提升在业务上往往不值得做。

### 第 3 步：同一个效应，样本量换三次

固定「两组均值差 = 1 个单位」，数据标准差 $\sigma=100$（所以这是个很小的效应量 $\delta=0.01\sigma$），差的标准误是 $100\sqrt{2/n}$：

| 每组 n | SE | $z$ | 双尾 p | 结论 |
|---|---|---|---|---|
| 10,000 | 1.414 | 0.71 | **0.4795** | 不显著 |
| 100,000 | 0.447 | 2.24 | **0.0253** | 显著 |
| 1,000,000 | 0.141 | 7.07 | **≈1.5×10⁻¹²** | 天文级显著 |

**同一个 1 单位的效应，从「完全不显著」走到「天文级显著」，唯一的变量是样本量。** 所以面试里绝不能说「p 值越小，效应越大」——这里效应一点没变。

**实践里的说法**：报告时 **p 值 + 效应量（effect size）+ 置信区间** 三件一起给。保险定价里真正的判据是业务量级：「费率因子让赔付率变动 0.05% 就算显著也不值得上线」。

### 第 4 步：多重比较与偷看

两个数字都从同一个公式出来：

- **20 次独立检验**：$1-0.95^{20}=\mathbf{0.6415}$。也就是说，一个「完全没效果」的仪表盘上挂着 20 个指标，跑一次实验就是 64% 的概率至少亮一个红灯。m 取 5/10/50/100 时分别是 22.6% / 40.1% / 92.3% / 99.4%。
- **偷看 10 次同一个实验**：实际假阳性率 **19.4%**（名义 5%）。2 次偷看是 8.3%，50 次是 32.0%。

两者不是一回事，要说清区别：多重比较是「多个不同的假设」，偷看是「同一个假设被反复检验」；处理办法也不同——前者用 Bonferroni / FDR / 预注册主指标，后者用序贯检验或事先定死样本量。

### 第 5 步：功效与样本量的核对

把 3.2 节那两张表重算一遍（单样本 z 检验、双尾 $\alpha=0.05$）：

| $\delta$（以 σ 计） | n | 手算 power $=\Phi(\delta\sqrt n-1.96)+\Phi(-\delta\sqrt n-1.96)$ | 表里写的 |
|---|---|---|---|
| 0.5 | 64 | $\Phi(4-1.96)=\Phi(2.04)+0=0.979325$ | 0.979 ✓ |
| 0.3 | 100 | $\Phi(3-1.96)=\Phi(1.04)+0.0000004=0.850830$ | 0.851 ✓ |
| 0.2 | 100 | $\Phi(2-1.96)=\Phi(0.04)+0.000037=0.515990$ | 0.516 ✓ |
| 0.2 | 400 | $\Phi(4-1.96)=\Phi(2.04)+0=0.979325$ | 0.979 ✓ |
| 0.1 | 100 | $\Phi(1-1.96)=\Phi(-0.96)+\Phi(-2.96)=0.168528+0.001538=0.170066$ | 0.170 ✓ |

要达到 80% 功效：$n=(1.96+0.8416)^2/\delta^2$ 给出 31.4 / 87.2 / 196.2 / 784.9 → 取整 **32 / 88 / 197 / 785**。两组比较时每组再乘 2。

### 条件检验一：把「不显著」当成「没效应」会错多少

$\delta=0.2\sigma$、每组 n=100 时，功效只有 **0.516**。也就是说，**如果真有 0.2 个标准差的效应，这个实验有一半的概率检不出来**。看到 p>0.05 的结论时，正确说法是「样本不够，无法判定」，而不是「没有效应」。要正面证明「差异足够小」，得做等价检验（TOST）：把 $H_0$ 设成「差异大于某个有意义的阈值」，拒绝它才能说「差异足够小」。

### 条件检验二：把 χ² 的样本量翻倍会怎样

上面的气囊例子（200 份），$\chi^2=8.33$、p≈0.004。保持**比例完全不变**（33.3% vs 50% 出险率），把样本量翻 10 倍到 2000 份（每行 1000）：

| 样本量 | 出险率（无气囊 vs 有气囊） | $\chi^2$ | p |
|---|---|---|---|
| 200 | 30% vs 50% | 8.33 | 0.004 |
| 2000 | 30% vs 50% | 83.3 | ≈7×10⁻²⁰ |

比例一模一样，$\chi^2$ 随 n 线性放大——**卡方值本身也在混入样本量**，所以它和 p 值一样不能当效应量用。要报强度就用比例差或 odds ratio（这里是 2.33），那才是与 n 无关的量。

## 五、什么情况下会失灵

### 承重假设

**假设一：$H_0$ 与「更极端」的方向事先定好。** 撤掉它的后果：看完数据再选单尾的方向、或者挑一个最好看的切分方式，实际 $\alpha$ 会显著高于 0.05（等价于多重比较）。第 4 步的数字：20 次比较就是 64%。

**假设二：只检验一次、且不偷看。** 撤掉它的后果：每次偷看都是一次新的检验，而且这些检验高度相关。第 4 步实测：查看 10 次把 5% 抬到 **19.4%**，查看 50 次抬到 **32.0%**。

**假设三：检验统计量的分布假设成立。** 撤掉它的后果：t 检验要求近似正态（或大样本），小样本 + 重尾下 p 值不可信（[[9.2 抽样分布与中心极限定理]] 第 4、5 步：n=5 时名义 95% 的区间实际覆盖率 0.88/0.81）；卡方要求每格期望频数 ≥5，否则要用 Fisher 精确检验；GLM 的 Wald 检验要求大样本 + 参数不在边界，分离时直接失效。

**假设四：观测独立。** 撤掉它的后果：SE 被算小、p 值被算小。同一保单多行、同一客户的多个产品线都会破坏它；处理办法是聚类稳健 SE 或按实体聚合后再检验。

**假设五：样本量足够（否则 p 值没有信息）。** 撤掉它的后果：功效不足时「不显著」什么都说明不了。$\delta=0.2\sigma$、n=100 的功效是 0.516 —— 有一半概率漏掉真效应。**做实验前先做功效分析**，别在事后解释 p=0.09。

**假设六：效应是「两个总体没差异」这种精确假设。** 撤掉它的后果：现实里几乎所有组间都有微小差异，样本足够大时 $H_0$ 必然被拒绝（第 3 步：n=10⁶ 时 1 个单位的差异 p≈10⁻¹²）。所以「是否显著」这个问题的答案随样本量变化，而「差多少」不随样本量变化。

### 与其他方法的边界

| 你想回答的问题 | 用谁 | 为什么不用别的 |
|---|---|---|
| 有没有差异（且样本量事先定好） | NHST + p 值 | p 值不回答「差多少」 |
| 差多少、精度如何 | 效应量 + 置信区间 | CI 同时给方向、大小、精度 |
| 想正面证明「差异足够小」 | 等价检验（TOST） | 不显著 ≠ 等价 |
| 多个指标 / 多次偷看 | 预注册 + Bonferroni / FDR / 序贯检验 | 单次检验的 $\alpha$ 会膨胀 |
| 探索性分析（还没有假设） | 报告效应量与 CI，把 p 值当筛选 | 探索集上的 p 值不可当确证 |
| 贝叶斯视角（想直接说「效应为真的概率」） | 贝叶斯因子 / 后验概率 | NHST 的 p 值不是那个概率 |
| 样本小、分布偏 | 置换检验 / bootstrap | t 与卡方的分布假设不成立 |
| GLM 的系数显著性 | Wald 或似然比检验 | 分离时 Wald 失效 → 用 LR 或 Firth |

## 六、常见误解

### 误解一：「p=0.03，说明效应有 97% 的概率是真的」

**错误想法**：p 值小，说明这件事是真的；0.03 对应的「真实概率」就是 97%。

**为什么容易这么想**：p 值是从软件里蹦出来的唯一一个「概率」，报告里又只有它，于是被当成「这件事有多真」的读数。

**错在哪一步**：p 值讲的是 $P(\text{data}\mid H_0)$，你说的是 $P(H_0\mid\text{data})$——两者不是一回事（贝叶斯定理里差一个先验）。要算后者必须有先验概率和功效，那叫**贝叶斯的后验 / 阳性预测值**。数字反驳：若只有 10% 的假设是真的、$\alpha=0.05$、功效 0.8，则 1000 次检验里真效应 100 个（检出 80 个）、假效应 900 个（假阳性 45 个）→ **显著结果里只有 $80/(80+45)=64\%$ 是真的**。详见 [[9.6 贝叶斯基础与基础率谬误]]。

### 误解二：「p>0.05，说明没有效应」

**错误想法**：检验做完了，不显著，那这件事就是没效果。

**为什么容易这么想**：判决词只有「显著 / 不显著」两种，读起来像「有 / 没有」。

**错在哪一步**：这是**「缺乏证据 ≠ 证据表明不存在」（absence of evidence is not evidence of absence）**。功效表给了具体数字：$\delta=0.2\sigma$、n=100 时功效只有 0.516，**有真实效应却检不出来**的概率接近一半；$\delta=0.1\sigma$、n=100 时功效 0.170，八成会漏。想要正面证明「没差异」，要用**等价检验（equivalence test, TOST）**：把 $H_0$ 设成「差异大于某个有意义的阈值」，拒绝它才能说「差异足够小」。

### 误解三：「p 值越小，效应越大」

**错误想法**：p=10⁻¹² 的那个因子，效果肯定比 p=0.03 的那个强得多。

**为什么容易这么想**：p 值看起来像一个分数——越小越「强」。

**错在哪一步**：p 值 = 效应量 × $\sqrt n$ ÷ 噪声，是**三个东西的混合物**。第 3 步的表就是反例：效应量固定为 1 个单位，n 从 10⁴ 涨到 10⁶，p 从 0.4795 变成 1.5×10⁻¹²。**要谈大小就报效应量 + CI。**

### 误解四：「p<0.05，所以结果可以上线」

**错误想法**：显著就够了，剩下的是产品决策。

**为什么容易这么想**：0.05 这条线在所有人心里都像「通过/不通过」的考试分数线。

**错在哪一步**：统计显著只说「不像随机波动」，不说「值得行动」。第 2 步的 A/B 例子：p=0.0355 显著，但 CI 下界是 0.2 个百分点——真实提升可能小到没有业务价值。要问三件事：效应量够不够大？相对变化多少？业务成本收益怎么算？

### 误解五：「p=0.04 比 p=0.049 更好 / 0.05 是一条真实的分界线」

**错误想法**：0.049 就是通过，0.051 就是没过，两者有本质差别。

**为什么容易这么想**：所有流程、论文、上线审批都按 0.05 写死了。

**错在哪一步**：$\alpha=0.05$ 是 Fisher 时代留下的**惯例**，不是自然常数。p=0.051 和 p=0.049 在证据强度上几乎没区别（差的那一点可能只来自多一个样本），但传统的「显著/不显著」二分法会给出相反的结论。现代做法：**连续地报 p 值 + CI，不做二元判决**（或者干脆用贝叶斯因子/后验概率）。

## 七、面试怎么答

### 30 秒版

> p 值是在 $H_0$ 为真的前提下、看到当前或更极端数据的概率。它不等于 $H_0$ 为真的概率，也不代表效应大小。判决有两类错误：Type I 是你事先定的 α，Type II 是漏检，功效 = 1−β 目标 0.80，靠效应量、样本量、α 三者决定。拿到 p=0.04 我会拒绝 $H_0$，但一定会补上效应量和置信区间，因为显著和重要是两个问题。

### 2 分钟版（要包含的四块）

1. **定义**：$p=P(\text{data}\mid H_0)$，条件在 $H_0$ 上；$H_0$ 为真时 p 值在 $[0,1]$ 上均匀分布。
2. **两类错误与功效**：α 是误报率，β 是漏检率，power=1−β；固定 n 时收紧 α 会降功效，两头都要好只能加样本。
3. **一个数字**：固定的 1 单位效应，每组 n=10⁴ 时 p=0.48，n=10⁶ 时 p≈1.5×10⁻¹² —— p 值混了效应量和样本量。
4. **决策口径**：报 p 值 + 效应量 + CI；多重比较与偷看要处理（20 个指标 64%、偷看 10 次 19.4%）。

### 会被追问到哪

#### Q1：「给你 p=0.04，你会怎么解读？」（**标准答案，必须背**）

> 「如果零假设为真——也就是真的没有效应——那么出现『当前这么极端或更极端』的结果的概率是 4%。所以在 5% 的显著性水平下我会**拒绝 $H_0$**。但我要补三句：**第一，p 值不是效应为真的概率，也不是效应大小**；第二，我还会看**效应量和置信区间**，因为大样本下 0.1% 的差异也能显著；第三，0.04 和 0.05 之间没有本质差别，我不会因为 0.049 和 0.051 做相反的决定。」

#### Q2：「A/B 测试里 p 值怎么用？」

> 「流程是：① **先定指标和最小有意义效应（MDE）**，做功效分析确定样本量（80% 功效、$\alpha=0.05$）；② 样本到位后算两比例 z 检验或卡方，得到 p 值和**差异的置信区间**；③ 结论不能只看 p——要看 CI 下界是否跨过 0、以及效应量是否有业务价值。另外三个坑：**别中途偷看结果就停**（peeking 会让 $\alpha$ 膨胀）、**别同时看十个指标**（多重比较）、**别只报显著的指标**（选择性报告）。」

#### Q3：「p=0.06，你会怎么说？」（考点：不能反向解读）

> 「我会说**没有足够证据拒绝 $H_0$**，而不是『$H_0$ 成立』或『没有效应』。0.06 和 0.04 的证据强度几乎一样，差别只是跨过了一条人为的线。如果功效不足（比如只有 0.3），正确结论是『样本不够，无法判定』；想要正面说『没有实质差异』，应该做等价检验（TOST）或直接看 CI 是否整个落在有意义的范围内。」

#### Q4：「α 和 β 分别对应业务里的什么损失？」

> 「$\alpha$（假阳性/误报）是『把没风险的说成有风险』：例如误判好客户，损失是流失和人工复核成本；$\beta$（假阴性/漏报）是『把有风险的说成没风险』：损失是赔付和坏账。**两个损失不对称，所以最优阈值不该是 0.05 或 0.5，而是按成本收益算出来的**——这也是模型部署时的工作点选择。想同时降低两者只能加样本量/加特征（提高功效）。」

#### Q5：「为什么不能反复看 A/B 结果，显著了就停？」（peeking 问题）

> 「因为每次偷看都是一次新的检验，**多重比较**会让实际的假阳性率远大于 5%。模拟数字：等间隔查看 10 次，实际假阳性率是 19.4%；查看 50 次是 32.0%。正确做法是**事先定样本量**，或用序贯检验（sequential test / group sequential design、alpha spending）来正式地允许中途查看。」

#### Q6：「功效怎么算？」

> 「四件东西互相决定：$\alpha$、样本量 $n$、效应量 $\delta$、功效 $1-\beta$；已知三件求第四件。单样本时 $n\approx(z_{1-\alpha/2}+z_{1-\beta})^2\sigma^2/\delta^2$，**双样本每组还要再乘 2**。数字上（单样本、80% 功效、双尾 5%）：检出 0.5 个标准差的差异需要 32 个样本；0.2 个标准差需要 197 个；0.1 个标准差要 785 个——换成两组比较，每组分别约 63 / 393 / 1570 个。规律是**效应量减半，样本量涨 4 倍**。」

#### Q7：「等价检验和普通检验差在哪？」

> 「普通检验的 $H_0$ 是『差异 = 0』，拒绝它说明『有差异』；等价检验（TOST）把 $H_0$ 设成『差异超出 ±Δ』（Δ 是业务上可忽略的边界），**拒绝它才能说『差异小到可以忽略』**。这两个方向不能互换，这就是为什么 p>0.05 永远推不出『没效应』。」

## 🗣️ 英文表达 / How to Say It in an Interview

1. "A p-value is **the probability of observing data at least as extreme as what we saw, assuming the null hypothesis is true** — it is *not* the probability that the null hypothesis is true."
2. "With p equal to 0.04 I would reject the null at the 5% level, but I would immediately report **the effect size and the confidence interval**, because significance and practical importance are different questions."
3. "If the study was underpowered, **failing to reject is not evidence of no effect** — absence of evidence is not evidence of absence. To claim equivalence I'd need an equivalence test."
4. "Power depends on three things: **effect size, sample size, and the significance level**; with a fixed sample, tightening alpha buys fewer false positives at the cost of more false negatives."
5. "The same one-unit difference can go from p = 0.48 to p = 0.025 to about 10 to the minus twelve, just by increasing n from ten thousand to a million — **p-values are a mixture of effect size and sample size**."
6. "Two things would make me nervous about this A/B test: **peeking at the results and stopping when it turns significant**, and testing twenty metrics at once without any multiple-comparison correction."

| 显著性水平 | significance level ($\alpha$) | 事先定的假阳性容忍度，惯例 0.05 |
| 第一类错误 | Type I error | 假阳性：没效应说成有 |
| 第二类错误 | Type II error ($\beta$) | 假阴性：有效应没检出 |
| 功效 | power ($1-\beta$) | 真有效应时能检出的概率，惯例目标 0.8 |
| 效应量 | effect size | 差异的大小（以原始单位或 σ 为单位） |
| 检验统计量 | test statistic | 把数据压成「离 $H_0$ 多远」的一个数 |
| 拒绝 / 不拒绝 | reject / fail to reject | 永远不说「接受 $H_0$」 |
| 卡方检验 | chi-square test | 分类变量的独立性检验 |
| 方差分析 | ANOVA | 三组以上均值检验（F 检验） |
| Wald 检验 | Wald test | GLM 系数显著性：$z=\hat\beta/\text{SE}$ |
| 似然比检验 | likelihood ratio test | 嵌套模型比较，$\text{LR}\sim\chi^2_{\Delta p}$ |
| 等价检验 | equivalence test (TOST) | 正面证明「差异足够小」 |
| 多重比较 | multiple comparisons | 检验越多，假阳性越多 |
| 窥视 / 中途查看 | peeking | 反复看 A/B 结果会抬高实际 $\alpha$ |
| 最小有意义效应 | minimum detectable effect (MDE) | 功效分析要先定的目标效应 |
| 序贯检验 | sequential test | 正式允许中途查看的实验设计 |
