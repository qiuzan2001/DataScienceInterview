# 4. 缺失数据（Missing Data）

## 速览 At a glance

**速记**

处理缺失值的第一步不是「填什么」，而是「为什么缺」。三种机制：**MCAR**（缺失与任何东西无关）→ 手上剩下的行仍是随机子样本，删行分析**无偏**，代价只有功效；**MAR**（缺失只取决于**已观测到**的变量，例如年轻人更爱跳过收入题）→ 删行会**有偏**，但用其他变量插补是站得住的；**MNAR**（缺失取决于**缺失值本身**，例如高收入者更拒答）→ 所有从观测数据学关系的插补方法都会系统性偏低，没有统计上的正道，只能显式建模缺失过程或做敏感性分析。均值插补的具体后果是**方差被压缩**（4 个观测值加 1 个均值，样本方差掉 25%）并稀释相关性，标准误过小。MAR 下最正确的做法是 MICE：填 m 套数据、各跑一遍分析、再用 Rubin 规则把点估计与两段方差合起来（填补内 + (1+1/m)×填补间），这样才把「不知道该填哪个」写进了标准误。

**一句面试答法**

> "The first question isn't how to fill the missing values — it's why they're missing. Under MCAR the rows I have left are still a random subsample, so complete-case analysis stays unbiased and I just lose power. Under MAR the missingness depends on variables I did observe, so imputation is defensible. Under MNAR it depends on the value itself, and standard imputation is biased."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 完全随机缺失 | missing completely at random (MCAR) | 缺失与一切无关 |
| 随机缺失 | missing at random (MAR) | 缺失只依赖已观测变量 |
| 非随机缺失 | missing not at random (MNAR) | 缺失依赖缺失值本身 |
| 完整案例分析 | complete-case analysis | 删掉任何含缺失的行 |
| 多重插补 | multiple imputation (MICE) | 填 m 套数据，合并时带上填补不确定性 |

## 一、先看一个问题

手上有 1000 行申请人数据，10 个字段。做描述统计时发现每个字段各缺 5%，你打算「把含缺失的行删掉，反正只有 5%」。

删完剩多少行？

$$
(1-0.05)^{10} = 0.5987 \;\Rightarrow\; 599\ \text{行}
$$

**每个变量只缺 5%，你丢掉了 40% 的样本。** 标准误变成原来的 $\sqrt{1000/599} = 1.29$ 倍，一个原本 $p=0.04$ 的系数直接掉出显著。

再想一步：如果缺失不是随机的呢？比如收入这一栏，**年轻人填得少**。删行等于成比例地删掉年轻人，剩下的样本平均年龄偏大 —— 这时的 599 行不只是「少」，而是**系统性偏离总体**。

所以面试官问 "What are the missing-data mechanisms?" 时，他真正想听的是：**你怎么知道这批缺失能不能删、能不能填、填完之后还准不准。** 下面把三种机制、各自的后果与补救办法依次拆开。

## 二、核心直觉

### 缺失机制 = 缺失这件事跟谁有关

三种机制的区别只有一句话：**「缺失的概率」取决于什么。**

| 机制 | 缺失概率取决于 | 一句话识别 |
|---|---|---|
| **MCAR** | 什么都不取决于 | 好运，剩下的样本仍代表总体 |
| **MAR** | **已观测到**的变量 | 原因看得见，可以用它们补 |
| **MNAR** | **没观测到**的值本身 | 原因藏在洞里 |

黄金法则：**先诊断，再处理（Diagnose first, then treat）。** 任何真实数据分析里，你都一定会遇到缺失值；直接忽略或删掉，会得到有缺陷、有偏、不可靠的结论。所以顺序永远是**先搞清它「为什么」缺失，再选处理方案**。

**这里像什么、不像什么**：可以把 MCAR 想成有人拿**随机打孔机**在表格上打洞 —— 洞不聚集、不挑位置。但要注意后面两种**看起来和随机打孔机出来的结果一样**：光看表格上洞的样子，你分不出这是随机打孔、还是「年轻人更容易被打到」。机制是**关于数据生成过程的一句话**，不是能从数据本身读出来的属性（第六节会讲这条有多要紧）。

### 为什么「删干净」在 MAR 下就不行了

MCAR 下删掉的行是原数据的随机子样本，剩下的仍是无偏的一份缩影，损失的是**量**：置信区间变宽、犯 Type II error（第二类错误，漏掉真效应）的概率上升。

MAR 下损失的是**质**。用收入那道题举例：年轻人跳过得多。你删掉他们，样本里剩下的年轻人不足，年龄一栏的分布整体右移。**估计出来的「平均收入」不再朝着总体真值收敛，而是朝着「愿意回答的人的平均收入」收敛。** 这两者可以差很多，第四节的算例给出具体数字：真值 56k，删行后报出 61.8k，高估 10.4%。

数据变少只是难受，系统性偏了是错的。

## 三、机制

### 3.1 定义与逐项说明：三种机制、判别、后果与补救

#### **🎲 MCAR (Missing Completely At Random): The Case of Pure Bad Luck**

这是最简单、最无害的一类缺失数据。

**核心逻辑：** 想象一次设计得很完美的调查。研究员手滑打翻了试管，样本丢了；录入员的电脑崩了，随机一批记录没了。这些情况下，「某个值缺失」这件事**与该值本来会是多少毫无关系**，也与数据集里任何其他信息无关。

这就是 MCAR（missing completely at random，完全随机缺失）。某个数据点缺失的概率，与所有其他变量、以及该缺失值本身，**完全独立**。

*   **正式检验（Little's MCAR Test）：** 这是检验 MCAR 的常用统计方法。
    *   **它问的问题：** 「我手上的这份数据，看起来像不像完整假想数据集的一个完全随机子样本？」
    *   **原理：** 它比较「有缺失」与「无缺失」两组在变量均值上是否有差异。若没有显著差异，说明缺失是随机的。
    *   **怎么读结果：**
        *   **原假设（Null Hypothesis, H₀）：** 数据是 MCAR。
        *   **p 值 > 0.05：** **无法拒绝**原假设 —— 统计上可以认为数据是 MCAR，可以按 MCAR 适用方法处理。
        *   **p 值 < 0.05：** **拒绝**原假设 —— 有统计证据表明缺失有模式，数据很可能属于 MAR 或 MNAR。

**后果（The Implication: Lost Power, Not Lost Integrity）：** 如果数据真是 MCAR，那么你**手上这部分数据**是完整数据集的一个**无偏（unbiased）**但更小的版本。因为缺失是随机的，剩下的观测仍然代表整体。

主要后果是**统计功效（power）下降**。功效指的是「真有真实效应时你能检测出它」的能力。数据变少 ⇒ 估计变得不精确，于是：

*   置信区间变宽（你对结论更不确定）。
*   犯 **Type II error（第二类错误）** 的概率变高（真实存在的显著结果，你没检出来）。

**补救（Fixes for MCAR: Simplicity vs. Preservation）**

| 方法（Method） | 详细说明（Detailed Explanation） |
| :--- | :--- |
| **完整案例分析（Complete Case Analysis，即删行）** | **逻辑：** 在 MCAR 下，你删掉的行本来就是原数据集的随机样本，所以剩下的数据仍是一个随机的、有代表性的样本，分析因此**保持无偏**。<br><br>**什么时候用：** 只建议在缺失比例非常小（例如 **<5%**）时使用。<br><br>**坑在哪：** 假设你有 10 个变量，每个变量各有 3% 的概率缺失（MCAR）。那么一行**完整**的概率是 (0.97)¹⁰ ≈ 0.74 —— 意味着你会**丢掉大约 26% 的数据集！** 统计功效损失巨大，还浪费了宝贵数据。 |
| **均值 / 众数插补（Mean / Mode Imputation）** | **逻辑：** 用集中趋势（central tendency）把空缺填上，从而保住样本量。直觉、省事。<br><br>🚨 **为什么它通常是个坏主意：**<br>1.  **它毁掉方差（destroys variance）：** 方差衡量数据的散布。反复填入完全相同的均值，等于人为压缩了散布，数据看起来比实际更紧地挤在均值附近。这让你过度自信，得到人为偏小的 p 值与置信区间。<br>  *例子：* 数据 `[1, 5, 9, NA]`，均值是 5，插补后是 `[1, 5, 9, 5]` —— 自然散布被压缩了。<br>2.  **它扭曲相关性（distorts correlations）：** 假设 `Study Hours` 与 `Exam Score` 正相关。现在有个 `Study Hours` 很高的学生，`Exam Score` 缺失。用**均值**去填，就会把这个点从它本该在的位置往下拽，让观察到的相关性变弱、趋势线被压平。 |

#### **🔗 MAR (Missing At Random): The Case of the Systematically Explainable Gap**

这是设计良好的研究里最常见的情形，通常也被当作插补的「最好情况（best-case scenario）」。

**核心逻辑：** 某个值缺失的概率**不是随机的**，但它可以被**你已经测量到的其他变量**完全解释。关键在于：缺失的原因**是观测得到的（observed）**。

*   **经典例子：** 调查里问收入。你发现**年轻人**更可能跳过这道题。`Income` 的缺失不是完全随机，它依赖于 `Age` 变量。
*   **关键区分：** 缺失依赖于**观测到的**数据（`Age`），而不是缺失的 `Income` 值本身。一个人跳过这道题，是因为他年轻，而不是因为他的收入特别高或特别低。

**后果（The Implication: Bias if Handled Poorly, Unbiased if Handled Smartly）：** 这是分析里的一个分水岭。

*   **坏消息：** 如果你用完整案例分析（删行），就会引入**偏差（bias）**。在上面的例子里，把所有收入缺失的人删掉，等于不成比例地删掉年轻人，剩下的样本平均年龄偏大，你的结论可能不适用于总体。
*   **好消息：** 既然缺失的原因就藏在你的其他变量里，你就可以利用这些关系，对缺失值做出**无偏**的推断。

**补救（Fixes for MAR: Using Relationships to Fill Gaps）**

| 方法（Method）                                    | 详细说明（Detailed Explanation）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| :---------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **回归插补（Regression Imputation）**                 | **逻辑：** 把有缺失的变量当作目标变量，用其他列当预测变量。在有缺失的那部分之外**完整行**上训练一个回归模型（`y ~ x1 + x2 + ...`），模型学到关系（例如 `Age` 与 `Education` 如何预测 `Income`），再用它去预测缺失行该填多少。<br><br>**坑（以及修法）：** 普通回归预测的是**平均值**，会把所有插补点精确放在回归线上 —— 这跟均值插补一样，人为压低了方差。更好的做法是**随机回归插补（Stochastic Regression Imputation）**：给每个预测值加一点随机噪声（从模型的误差分布里抽），插出来的值更真实，保住了自然方差。                                                                                                                                 |
| **k 近邻插补（k-Nearest Neighbors, k-NN）** | **逻辑：** 一种「物以类聚」的方法。对某个含缺失值的行，在**其余所有可用变量**上找出最相似的 *k* 行（「邻居」），再用这些邻居取值的平均（数值型）或众数（类别型）填上。<br><br>**关键优势：** 它是**非参数（non-parametric）**的 —— 不假设线性或任何刚性关系，能捕捉非常复杂、曲折的模式。<br><br>**重要注意事项：**<br>1.  **特征缩放（Feature Scaling）：** 如果一个变量（如美元计的 `Income`）量纲远大于另一个（如以年计的 `Age`），它会主导距离计算。用 k-NN 前**必须**先缩放特征（例如缩到 0–1 区间）。<br>2.  **`k` 怎么选：** `k` 太小会对离群值敏感；`k` 太大则会过度平滑，行为越来越像均值插补。 |
| ✨ **Multiple Imputation (MICE)** ✨        | **The Logic (The Gold Standard):** MICE（Multiple Imputation by Chained Equations）承认一个事实：**我们不知道缺失值到底是几，所以不要假装知道**。它生成 `m` 个（如 5 或 10 个）"看起来都合理"的完整数据集，并把"填补本身的不确定性"显式写进最后的方差里。<br><br>**The Three-Step Process:**<br>1.  **Imputation Phase:** 用其余所有变量做回归，逐变量迭代地填补缺失值；每一轮都**注入随机性**（从后验预测分布抽样），所以 `m` 个数据集各不相同，代表 `m` 种合理的"missing 世界"。<br>2.  **Analysis Phase:** 在**每个**填补好的数据集上独立跑你要做的分析（线性回归、t 检验……），得到 `m` 套结果：`m` 个点估计 $\hat Q_k$ 和 `m` 个方差 $U_k$。<br>3.  **Pooling Phase (Rubin's Rules):** 用 **Rubin 规则**把 `m` 套结果合并成**一个点估计 + 一个总方差**：总方差 = within-imputation variance + (1 + 1/m) × between-imputation variance（公式见下表下方）。**这一步才是 MICE 的灵魂**——它把"我不知道该填哪个值"量化为方差的一部分。 |

##### **✨ MICE Step 3 in detail: Pooling with Rubin's Rules**

设第 $k$ 个填补数据集（$k=1,\dots,m$）上的点估计为 $\hat Q_k$、其方差估计为 $U_k$：

* **Point estimate（点估计 = $m$ 次平均）**

  $$\bar Q = \frac{1}{m}\sum_{k=1}^{m}\hat Q_k$$

* **Within-imputation variance（填补内方差）**

  $$\bar U = \frac{1}{m}\sum_{k=1}^{m}U_k$$

* **Between-imputation variance（填补间方差）**

  $$B = \frac{1}{m-1}\sum_{k=1}^{m}\left(\hat Q_k - \bar Q\right)^2$$

* **Total variance（总方差）**

  $$T = \bar U + \left(1+\frac{1}{m}\right)B$$

  （多出来的 $B/m$ 是对"只用了有限个 $m$"的补偿；$m\to\infty$ 时 $T\to\bar U+B$。）

* **推断：自由度与大样本近似**

  $$\frac{\bar Q - Q_0}{\sqrt{T}} \;\sim\; t_{\nu},
  \qquad
  \nu = (m-1)\left[1+\frac{\bar U}{(1+1/m)B}\right]^{2}$$

  置信区间：$\bar Q \pm t_{\nu,\,1-\alpha/2}\sqrt{T}$。

  * **大样本近似**：当 $m$ 与样本量都大时，$(1+1/m)B$ 的估计稳定、$\nu\to\infty$，$t_\nu$ 可用标准正态近似 ⇒ $\bar Q \pm 1.96\sqrt{T}$（$m=5\sim10$ 且缺失比例不高时通常够用）。
  * **对照**：完整数据（无缺失）时的参考自由度是 $n-p$（样本量减参数个数）；Rubin 的 $\nu$ 一般更小，正因为填补带来了额外的不确定性。

* **缺失信息比例与 $m$ 的选取**：$\gamma = \dfrac{(1+1/m)B}{T}$（方差中由缺失贡献的比例）。$m$ 次填补相对无穷次填补的效率为 $(1+\gamma/m)^{-1}$：缺失 10–20% 时 $m=5\sim10$ 已接近满效率；缺失严重（或 $\gamma$ 大）时用 $m=20+$。

#### **❓ MNAR (Missing Not At Random): The Case of the Unseen Cause**

这是最复杂、最危险的一类缺失数据。处理不当几乎必然导致有偏、错误的结论。

**核心逻辑：** 某个值缺失的概率与**该缺失值本身的大小**有关。缺失的原因是内在的（intrinsic），就藏在你看不到的那部分数据里。于是形成恶性循环：**要理解缺失模式，需要的数据恰恰就是缺失的那部分数据。**

*   **与 MAR 的关键区分：**
    *   在 **MAR** 里，`Income` 缺失能由**观测到的** `Age` 解释 —— 原因在数据里看得见。
    *   在 **MNAR** 里，`Income` 缺失由**收入水平本身**解释。例如：收入非常高的人更可能拒绝回答。原因藏在缺失值里面。

*   **经典例子：**
    *   **收入调查（Income Surveys）：** 收入极高或来源不合法的人更倾向于隐瞒。`Income` 缺失的概率是收入值本身的函数。
    *   **医学研究（Medical Studies）：** 病情最重的患者可能病得无法来随访。缺失的「Health Outcome」之所以缺失，**正是因为**健康结局很差。
    *   **行为调查（Behavioral Surveys）：** 有严重成瘾的人可能因为羞耻或否认而不报告用药量。`Substance Use` 变量的缺失直接与「用量高」相关。

**怎么发现它：** MNAR **没有简单的统计检验**。识别几乎完全依赖**领域知识（domain knowledge）**与对数据采集过程的**批判性思考**。你必须问自己：「有没有现实上说得通的原因，使得某个变量的取值会影响它自己被记录的概率？」

**后果（The Implication: Severe and Systematic Bias）：** 这是最麻烦的情形，因为标准插补方法**会失效**，产出**有偏结果**。

为什么？前面 MAR 的所有方法（回归、k-NN、MICE）都是**从观测数据里学关系**。但在 MNAR 下，观测数据与缺失数据**本质上是不同的**。

*   **例子拆解：** 回到收入调查。观测到的收入来自**愿意分享**的人（多半是低到中等收入者）。在这个群体上训练的回归模型，学到的是 `Age`、`Education` 与**正常**收入之间的关系。当你让它去插补高收入者的缺失收入时，它会预测出「正常」收入，因为它只知道这些。结果你会**系统性地、严重地低估**总体的真实平均收入。

你的分析不只是「不够精确」，而是**明确错了**。

**补救（Fixes for MNAR: Advanced Approaches and Honest Caveats）：** MNAR 没有轻松的解。方案更复杂，而且要求你**对自己的假设保持透明**。

| 做法（Approach） | 详细说明（Detailed Explanation） |
| :--- | :--- |
| **给缺失机制建模（Model the Missingness）** | **核心思路：** 如果你认为缺失不是随机的，就必须把「缺失过程」显式地建进分析里。这在统计复杂度上是明显加档的。<br><br>**怎么做：** 常用 **Heckman 选择模型（Heckman Selection Models）** 或 **模式混合模型（Pattern-Mixture Models）**。以选择模型为例，它建两个互相联系的方程：<br>1.  一个「结果模型（outcome model）」预测关注的变量（如 `Income ~ Age + Education`）。<br>2.  一个「选择模型（selection model）」预测收入被观测到的概率（如 `Observed ~ Age + Education + other variables`）。<br>联合建模后，模型可以尝试修正非随机选择带来的偏差。<br><br>**关键考量：** 这是进阶统计方法。它要求你对「取值与它自己是否缺失之间的关系形式」做一个很强的、**无法检验的假设**。你必须有扎实的理论或领域依据来支持这个假设。 |
| **敏感性分析（Sensitivity Analysis）** | **核心思路：** 既然真实缺失原因不可知，那就检验你的结论在一系列**合理的不同假设**下是否站得住 —— 也就是检验结论的**稳健性（robustness）**。<br><br>**怎么做：** 不做单一插补，而是按几个「如果……会怎样」的 MNAR 情景，造出多个插补数据集：<br>•   **情景 1（悲观 Pessimistic）：** 假设所有缺失的收入都很高，按观测数据的 90 分位插补，然后跑分析。<br>•   **情景 2（乐观 Optimistic）：** 假设所有缺失值都很低，按 10 分位插补，然后跑分析。<br>•   **情景 3（领域特定 Domain-Specific）：** 假设年收入超过 $200k 的人报告概率低 50%，按这个理论插补，然后跑分析。<br><br>**关键考量：** 这种做法不给你一个「正确答案」，而是给你一个**答案区间**。如果你的核心结论（如「教育是收入的显著预测变量」）在所有合理情景下都成立，你就可以有信心地说结论是稳健的。如果某个情景下结论变了或消失了，你就必须如实报告：结论对缺失数据的假设敏感。这既诚实，也科学。 |
| **去收集更多数据（Collect More Data）** | **核心思路：** 想在不做无法检验的假设的前提下真正解决 MNAR，唯一的办法就是**把缺失的数据拿回来**。<br><br>**怎么做：** 这是数据采集策略，不是统计方法 —— 回到源头去：<br>•   能不能用另一种方法做追踪调查（follow-up survey）？<br>•   能不能给提供缺失信息的人一点激励？<br>•   能不能把敏感问题换个更让人愿意回答的说法？<br><br>**关键考量：** 虽然这是修 MNAR 的理论「黄金标准」，但往往最贵、最耗时，甚至根本做不到。不过它说明了一点：**处理缺失数据最好的方式，常常是通过严谨的研究设计从一开始就别让它缺失**。 |

### 3.2 它是怎么来的

三种机制的差别，都能追到同一个式子上。当缺失只依赖观测到的变量时，缺失指示变量 $M$ 满足

$$
P(M=1 \mid X, Y) = P(M=1 \mid X)
$$

**关键一步在这里**：右边没有 $Y$。所以**在给定 $X$ 之后**，$Y$ 的缺失与 $Y$ 的取值无关 —— 于是「用 $X$ 预测 $Y$」这件事在观测行与缺失行上是同一套关系，插补出来的 $Y$ 无偏。这就是 MAR 下插补成立的**全部理由**，也是 MCAR 与 MAR 的唯一区别：

* **MCAR**：$P(M=1\mid X,Y) = P(M=1)$，连 $X$ 都不依赖 ⇒ 直接删行也无偏。删行等价于随机抽子样本，损失的是样本量。
* **MAR**：依赖 $X$，不依赖 $Y$ ⇒ 删行有偏（因为丢掉的行与 $X$ 有关），但**条件在 $X$ 上**就无偏 ⇒ 回归插补 / MICE 站得住。
* **MNAR**：$P(M=1\mid X,Y)$ 真的依赖 $Y$ ⇒ 上面那个条件不再成立，观测行上的 $Y\mid X$ 关系与缺失行上的不同 ⇒ 所有从观测数据学关系的插补都偏。

删行的偏差也可以直接写出来：完整案例分析估的是 $E[Y\mid X, M=0]$，我们要的是 $E[Y\mid X]$。两者相等当且仅当 $M \perp Y \mid X$ —— 这正是 MAR/MCAR 的条件。**MNAR 时它们不等，而且差多少无法从数据里估计**（因为缺失的 $Y$ 没被观测到），这解释了为什么 MNAR 只能做敏感性分析。

### 3.3 变形与口径

**① 插补家族的分层。** 按「保住了什么」排：

| 层次 | 做法 | 保住方差 | 保住相关性 | 保住「曾经缺失」 |
|---|---|---|---|---|
| 最省事 | 均值 / 众数插补 | ✗ 压缩 | ✗ 稀释 | ✗ |
| 中间 | 回归插补（条件均值） | ✗（点全落在回归线上） | ✓ | ✗ |
| 中间 | 随机回归插补 / kNN / hot-deck | ✓ | ✓（kNN 捕捉局部） | ✗ |
| 最正确 | MICE（多重插补） | ✓ | ✓ | ✓（指示变量另说） |

**缺失指示变量（missing indicator）** 是横切所有层次的一招：把「这一格曾经缺失」做成 0/1 旗标再加进模型。它的价值在 MNAR 场景最大 —— 缺失本身常常就是信号（新车手无历史、第三方数据没匹配上、该险种不适用）。

**② 生产口径（这一条和统计口径同等重要）。** 在划分之前插补 = 泄漏。每一个插补参数 —— 均值、中位数、回归模型、kNN 索引 —— 都是从数据学来的：**在训练集上学，套用到验证 / 测试 / 生产；在 CV 内属于 pipeline，每折重新拟合**。

还有一条：**生产需要同一条规则**。如果某字段在打分时可能缺失，模型必须有明确定义的行为；「我们在训练时把那些行删掉了」不是一个打分规则（上线后你删不掉当天的新申请）。

**③ 参数口径。** Rubin 规则里那个 $(1+1/m)$ 是对「只用了有限个 $m$」的补偿；有些软件（如 `mice` 的默认输出）会额外报 $\lambda$（缺失信息比例）与 $fmi$（fraction of missing information），读法与这里的 $\gamma$ 是同一个东西的两种写法。自由度 $\nu$ 在小样本、高缺失率下可以小到个位数，这时用正态近似会**低估**区间宽度。

**④ 树模型不是免检通道。** XGBoost / LightGBM 会为每个分裂学一个默认方向，CART 用**代理分裂（surrogate splits）** —— 训练时确实不用你插补。但**打分时仍然需要一条明确的规则**：缺失样本走哪条分支必须固定下来，报备时也要写清楚。

## 四、算一遍

两个算例：先算「删行」在 MAR 下的偏差与功效损失，再算「均值插补」对方差的压缩。两组数都能自己按表格复算。

### 第 1 部分：完整案例分析的偏差与功效损失

场景：1000 位受访者，分成两组。

| 组 | 人数 | 真实平均收入 | 不回答的比例 | 实际观测到的人数 |
|---|---|---|---|---|
| 30 岁以下 | 600 | 40k | 50% | 300 |
| 30 岁及以上 | 400 | 80k | 10% | 360 |

**第 1 步：算总体真值。** 这是我们要估的目标：

$$
\frac{600 \times 40 + 400 \times 80}{1000} = \frac{24{,}000 + 32{,}000}{1000} = 56.00\text{k}
$$

**第 2 步：算完整案例（删行）给出的估计。** 删行之后剩下的样本里，年轻人只有 300 人、年长者 360 人：

$$
\frac{300 \times 40 + 360 \times 80}{300+360} = \frac{12{,}000 + 28{,}800}{660} = \frac{40{,}800}{660} = 61.818\text{k}
$$

**第 3 步：偏差。** $61.818 - 56.00 = +5.818$k，相对真值**高估 10.39%**。方向符合直觉：年轻人（低收入组）被删得更多，剩下的样本年龄偏大。

注意：这里的偏差**不是**「收入缺失」直接造成的，而是**「不回答」与年龄相关、年龄又与收入相关**造成的。这就是 MAR 的定义在具体数据上的样子。

**第 4 步：功效损失。** 样本从 1000 掉到 660，标准误按 $\sqrt{n}$ 走：

$$
\frac{\mathrm{SE}_{\text{after}}}{\mathrm{SE}_{\text{before}}} = \sqrt{\frac{1000}{660}} = 1.231
$$

**SE 放大 23.1%**，等价于「你用 66% 的成本只买到原来 100% 的信息量的 66%」。真实效应原本刚好显著的系数，现在很难检出来了。

### 第 2 部分：均值插补怎样压缩方差（5 个数）

取 5 个观测值，其中一个缺失：$[2,\ 4,\ 6,\ 8,\ \mathrm{NA}]$。

**第 1 步：均值。** $\bar x = (2+4+6+8)/4 = 5$。

**第 2 步：插补前的样本方差**（分母用 $n-1 = 3$）：

$$
s^2_{\text{obs}} = \frac{(2-5)^2+(4-5)^2+(6-5)^2+(8-5)^2}{4-1} = \frac{9+1+1+9}{3} = \frac{20}{3} = 6.667
$$

**第 3 步：把均值填进去。** 数据变成 $[2,\ 4,\ 6,\ 8,\ 5]$，均值仍是 5，偏差平方和**一个都没变**（新填的 5 贡献 $0^2$），但分母从 3 变成 4：

$$
s^2_{\text{imp}} = \frac{20}{4} = 5.000
$$

**第 4 步：压缩了多少。** $5.000/6.667 = 0.75$，即**方差被压掉 25%**。标准差从 2.582 掉到 2.236。

这不是这个例子的巧合，有一个一般式：

$$
\frac{s^2_{\text{imp}}}{s^2_{\text{obs}}} = \frac{n_{\text{obs}}-1}{n_{\text{total}}-1}
$$

**每用均值补一格，方差就按这个比例被削一次。** 缺失 20% 时大概是 0.8 左右；缺失 50% 时方差只剩一半，标准误跟着缩小 $\sqrt{2}$，置信区间假性变窄 —— 你会**更确定一个错答案**。换成教材里那个 `[1, 5, 9, NA]` 也一样：插补前 $s^2 = 32/2 = 16$，插补后 $s^2 = 32/3 = 10.667$，压缩 33.3%。

### 条件检验：把缺失率换成 MCAR

同一组数，把所有「不回答」的比例都设成一样（比如两组都删 20%），机制就从 MAR 变成 MCAR：

| 缺失机制 | 删行后的样本构成 | 删行估计值 | 偏差 |
|---|---|---|---|
| MCAR（两组各删 20%） | 480 年轻人 / 320 年长者（比例仍是 6:4） | $(480\times40+320\times80)/800 = 56.00$k | **0** |
| MAR（本例：30% / 10%） | 420 / 360（比例变成 5.4:4.6） | $(420\times40+360\times80)/780 = 58.46$k | +2.46k（+4.4%） |
| MAR（本例：50% / 10%） | 300 / 360（比例 4.5:5.5） | 61.82k | +5.82k（+10.4%） |

两件事一起看清了：**偏差的大小由「两组的缺失率之差」决定，而不是由总缺失率决定**（第一行总缺失率 20%，偏差 0）；**差值翻两倍半，偏差也几乎翻两倍半**（2.46k → 5.82k）。所以「我这边只缺了 20%，问题不大」这句话在没有检查机制之前是不能说的。

## 五、什么情况下会失灵

### 承重假设一：机制假设本身无法检验

这是最要命的一条。**MAR 与 MNAR 对观测数据给出同一份似然**（这就是为什么 MNAR 可以叫「不可忽略的缺失」）。撤掉 MAR 的成本无法从数据里估出来：你可以在同一份数据上同时装着两个都讲得通的机制解释，结论差很多。

具体后果（接第四节）：如果 30 岁以下那组不回答的人，恰好是**收入偏高**的那部分（MNAR），删行的偏差会**比 10.4% 更大**，而且方向可能变。任何声称「我们已经用 MICE 处理过缺失，所以没问题」的说法，都在偷偷假设 MAR。

处理：把机制假设**写进报告**，做敏感性分析给出结论区间，而不是给一个点估计。

### 承重假设二：插补模型包含了正确的解释变量

MAR 是「条件在 $X$ 上缺失与 $Y$ 无关」。$X$ 集合选错（漏掉那个真正驱动缺失的变量），MAR 就不成立，插补会退回成有偏。具体后果：漏掉「年龄」这个变量之后，收入插补会把年轻人的低收入平均到所有人头上，均值被拉高 —— 和删行反方向的偏差。

**推论：插补模型该包含的变量比最终模型更多**（含辅助变量），因为它们的作用是修缺失结构，不是做解释。

### 承重假设三：插补与划分的先后正确

在划分之前插补，参数把测试集信息带进训练集。具体后果：CV 报告的误差偏低、λ 或超参数选偏，上线后误差反弹。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 分类变量缺失 | 「Missing」当一个类别 + WoE | 保留信号，且生产上规则明确 |
| 数值变量、低缺失率、要上线 | 缺失指示 + 插补值（train 学参数） | 简单、可复现、抗 MNAR 一部分 |
| 需要正确的标准误（MAR） | MICE + Rubin 规则 | 把填补不确定性写进方差 |
| 梯度提升树 | 模型原生默认方向 | 训练免插补，但打分规则仍要固定 |
| 缺失与结局强相关（MNAR） | 显式建模（Heckman / pattern-mixture）+ 敏感性分析 | 没有「统计上的正确答案」 |
| 缺失 > 50–70% | 先看指示变量有没有信号，没信号再删列 | 单变量信息太少 |

## 六、常见误解

### 误解一：「My data is MCAR」——机制是能从数据里读出来的

**错误想法**：跑一遍 Little's test，p 值大于 0.05，所以是 MCAR，可以放心删行。

**为什么容易这么想**：Little's test 的 H₀ 就是 MCAR，看起来像一张免检证书；而且软件真的会输出一个 p 值。

**错在哪一步**：检验只能**拒绝** MCAR，不能**确认**它。p 值不显著的可能原因是样本太小、检验功效不足 —— 你的数据可能仍然是 MAR，只是没检出模式。而 MCAR 与 MAR 对删行分析的影响是**有偏 vs 无偏**的区别，不是程度区别。把「没检出模式」当成「没有模式」，是把无证据当成了证据。

### 误解二：「缺失只有 5%，怎么处理都行」

**错误想法**：缺失率很低，均值插补、删行都无所谓。

**为什么容易这么想**：盯着**单变量**的缺失率看（5% 确实很小），也符合「数据越完整越好」的直觉。

**错在哪一步**：漏了**变量个数**这一维。10 个变量各缺 5%，完整行只剩 59.87%（第一节的算式）；模型里 20 个变量时只剩 35.8%。而且缺失率低**不等于偏差小** —— 第四节的条件检验里，MCAR 下总缺失 20%、偏差恰好是 0；MAR 下同样 20% 量级的缺失、偏差 10.4%。**低缺失率保证的是「精度损失小」，不保证「无偏」。**

### 误解三：「用平均数填上，反正不会错得太离谱」

**错误想法**：均值是中枢，填均值至少不会引入大偏差。

**为什么容易这么想**：从「估值」的角度看，均值确实是无偏的；而且它填完之后所有统计量都还能算出来，看不出问题。

**错在哪一步**：均值插补错的两件事都不在「均值」上，而在**分布的形状**上。第一，方差被压缩（第 2 部分算过：4 个观测值加 1 个均值 → 方差掉 25%），标准误跟着偏小，p 值偏小、置信区间假性变窄。第二，相关性被稀释向 0：`Study Hours` 高的那个人 `Exam Score` 缺失，你把他拉到均值线上，趋势线就被压平 —— 真实关系被衰减（attenuated）。**一个「不会错」的插补值，换来的是「虚假的确定性」。**

### 误解四：「树模型能处理缺失，所以不用管」

**错误想法**：XGBoost 有默认方向，CART 有代理分裂，缺失不用操心。

**为什么容易这么想**：这确实是树模型相对 GLM 的一个真实优势，文档里也写着「handle missing values natively」。

**错在哪一步**：把「训练时能跳过插补」当成了「全程不需要规则」。打分时缺失样本走哪条分支必须**固定且可复现**，否则同一个客户在两个版本的系统里会拿到不同的分数；报送时也必须能回答「缺失时模型怎么做」。还有一层：默认方向是从**训练数据的缺失模式**学出来的，上线后缺失率或字段口径变了，这条学到的规则就失效了 —— 而它不会报错，只会悄悄改变分数。

## 七、面试怎么答

### 30 秒版

> 第一句话先说机制：MCAR 下缺失与一切无关，删行仍然无偏，只是功效下降；MAR 下缺失只依赖已观测的变量，可以插补，但要保证插补参数只在训练集上学；MNAR 下缺失取决于缺失值本身，所有插补都会偏，只能显式建模或做敏感性分析。均值插补的具体代价是压缩方差、稀释相关性。

### 2 分钟版（三块）

1. **机制**：用「缺失概率取决于什么」一句话区分三种。补一句：MAR 与 MNAR 对观测数据给出同一份似然，所以机制是假设、不是检验结论。
2. **方法分层**：删行（MCAR + 低缺失率）→ 指示变量 + 插补值（实务主力）→ 随机回归 / kNN（保住方差）→ MICE + Rubin 规则（要正确的标准误）。MICE 的关键在第三步的合并：$T = \bar U + (1+1/m)B$。
3. **工程口径**：插补参数只能在训练集上估计、在 CV 内逐折重做；生产必须有一条明确的缺失处理规则。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「均值插补为什么不好？」 | 方差被压缩（每补一格按 $(n_{\text{obs}}-1)/(n_{\text{tot}}-1)$）、相关性被稀释向 0、标准误偏小、还丢掉了「曾经缺失」这个信号 |
| 「普通回归插补和随机回归插补差在哪？」 | 前者把点放在回归线上、方差低估；后者加随机残差，方差恢复 |
| 「kNN 插补的坑？」 | 必须先标准化、选距离度量与 k；大数据上慢；高维下距离失去意义 |
| 「MNAR 怎么办？」 | 指示变量 + 显式建模缺失机制（Heckman / pattern-mixture）+ 敏感性分析；没有「统计上的正确答案」 |
| 「树模型不是能自己处理缺失吗？」 | 训练时可以（默认方向 / 代理分裂），但打分时你仍然要告诉它缺失走哪条路，报备时也要写清楚 |
| 「删行和填充怎么选？」 | 先算完整行比例 $（1-m)^p$；再看机制。MCAR + 缺失率低 → 删行；MAR → 插补；MNAR → 谁的插补都别信 |
| 「m 取多少？」 | 靠缺失信息比例 $\gamma$：缺失 10–20% 用 5–10，$\gamma$ 大时 20+；m 增大主要降低合并方差里的 $B/m$ 项 |

### Q: What are the imputation methods and when do you use each?

> 🎯 真题问法（MAGNet §3「What are the imputation methods and when do you use each?」）｜ 深潜来源：MAGNet §3 完整菜单；本笔记上文 MCAR / MAR / MNAR 三节（MICE + Rubin 合并的推导在那里）

**先给菜单（按「从最省事到最贵」说，并说明各自的前提）**

| 方法 | 做什么 | 什么时候用 / 代价 |
| --- | --- | --- |
| **Complete-case（listwise）删除行** | 删掉任何含缺失的行 | 只在 MCAR + 缺失比例很低时站得住 |
| **删列（drop the variable）** | 整列去掉 | 缺失 **> 50–70%** 时合理 —— 但**先检查缺失指示变量有没有信号**，有信号就别删 |
| **均值 / 中位数插补** | 用中心值填 | 快；压低方差、稀释相关性、标准误过小；只在低缺失率下可接受，且**一定搭配指示变量** |
| **众数 / 显式「Missing」类别** | 缺失当一个类别 | 分类变量的默认做法；配上 WoE 让 missing 箱有自己的 log-odds |
| **缺失指示 + 插补值（missing indicator + imputed value）** | 0/1 旗标 + 填充值 | **实务主力**：保留「它曾经缺失」的信息，因此**部分抵御 MNAR** |
| **回归 / 条件均值插补** | 用其它变量预测缺失值 | 比均值好；但插补点精确落在回归线上，方差仍被低估 |
| **随机回归插补（stochastic regression imputation）** | 回归预测 **+ 随机残差** | 修掉普通回归插补**低估方差**的问题，恢复自然波动 |
| **kNN 插补** | k 个最相似记录的均值 / 众数 | 捕捉局部结构、非参数；**需要标准化与距离度量**，大规模下昂贵，k 的取值要调 |
| **MICE / 多重插补** | 逐变量迭代填补 m 套数据，分别建模，**Rubin 规则**合并 | MAR 下统计上最正确（把填补不确定性写进方差）；重，且在生产打分 pipeline 里不好落地 |
| **模型原生处理** | XGBoost / LightGBM **为每个分裂学一个默认方向**；CART 用**代理分裂（surrogate splits）** | 树模型里简单有效；**但打分时仍需要一条明确的规则** |
| **热卡插补（hot-deck）** | 从相似捐赠记录（donor）复制取值 | 调查研究的传统做法 |

**两条会被扣分的（必须主动说）**

1. **在划分之前插补 = 泄漏**。每一个插补参数 —— 均值、中位数、回归模型、kNN 索引 —— 都是从数据学来的：**在训练集上学，套用到验证 / 测试 / 生产；在 CV 内属于 pipeline，每折重新拟合**。
2. **生产需要同一条规则**。如果某字段在打分时可能缺失，模型必须有明确定义的行为；**「我们在训练时把那些行删掉了」不是一个打分规则**（上线后你删不掉当天的新申请）。

**FOLLOW-UP 要能答：均值插补错在哪？**

- 在均值处堆出一个**尖峰**：**方差下降**、与其它变量的**相关性被稀释向 0**、**标准误过小**、任何涉及该变量的关系都被**衰减（attenuated）**；
- 而且它**毁掉了「曾经缺失」这个信号** —— 这正是指示变量重要的原因。缺失在保险里几乎总是有信息的（新车手无历史、第三方数据没匹配上、该险种不适用）。

> ⚡ 先说的那一句
>
> "It depends on why it's missing. For categoricals I make 'missing' its own level; for continuous variables my default is a missing indicator plus an imputed value, because that keeps the fact that it was missing — which is often signal in insurance. If I need correct standard errors under MAR I go to multiple imputation with Rubin's rules. The two rules I never break: fit every imputation parameter on train only, and make sure the scoring pipeline has a defined behavior when the field is missing."

> 🔗 会被追问到
>
> - 「均值插补为什么不好？」→ 见上面 FOLLOW-UP（尖峰、方差、相关性、标准误、信号）。
> - 「普通回归插补和随机回归插补差在哪？」→ 前者把点放在回归线上、方差低估；后者加随机残差，方差恢复。
> - 「kNN 插补的坑？」→ 必须先标准化、选距离度量与 k；大数据上慢；高维下距离失去意义。
> - 「MNAR 怎么办？」→ 指示变量 + 显式建模缺失机制（Heckman / pattern-mixture）+ 敏感性分析；没有「统计上的正确答案」。
> - 「树模型不是能自己处理缺失吗？」→ 训练时可以（默认方向 / 代理分裂），但**打分时你仍然要告诉它缺失走哪条路**，报备时也要写清楚。

> 📌 MICE 的三步（Imputation → Analysis → Pooling）与 Rubin 规则公式见上文 MAR 一节。

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "The first question isn't how to fill the missing values — it's why they're missing. Under MCAR the missingness is unrelated to everything, so the rows I have left are still a random subsample and complete-case analysis stays unbiased, we just lose power. Under MAR the missingness depends on variables I did observe, so imputation is defensible. Under MNAR it depends on the value itself, and standard imputation is biased."

**Mechanism**

> "For MAR my default is multiple imputation: generate several plausible complete datasets, analyse each one, then pool with Rubin's rules, where the total variance is the within-imputation variance plus a factor times the between-imputation variance. That pooling step is the whole point — it puts the imputation uncertainty into the standard error."

**If they push back**

> "A common pitfall is mean or mode imputation. It destroys variance and flattens the correlations, so you end up with confidence intervals that are too narrow. The deletion trap is also easy to miss: ten variables each missing three percent can drop about a quarter of your rows. And for MNAR there's no statistical fix — I'd model the missingness explicitly or, more realistically, run a sensitivity analysis and report how much the conclusion moves."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 缺失机制 | missingness mechanism | 缺失概率取决于什么 |
| 完全随机缺失 | missing completely at random (MCAR) | 与一切无关；删行无偏 |
| 随机缺失 | missing at random (MAR) | 只看已观测变量；插补可行 |
| 非随机缺失 | missing not at random (MNAR) | 取决于缺失值本身；插补必偏 |
| 完整案例分析 | complete-case analysis | 删掉含缺失的行，完整率 $(1-m)^p$ |
| 可得案例 | available-case analysis | 每个统计量用它自己有的数据算（变量间不可比） |
| 多重插补 | multiple imputation (MICE) | 填 m 套、跑 m 次、合并一次 |
| 填补内方差 | within-imputation variance $\bar U$ | 各套数据内部的方差平均 |
| 填补间方差 | between-imputation variance $B$ | 各套点估计之间的方差 |
| Rubin 规则 | Rubin's rules | $T=\bar U+(1+1/m)B$ 的合并方式 |
| 缺失信息比例 | fraction of missing information $\gamma$ | 方差里由缺失贡献的比例 |
| 缺失指示变量 | missing indicator | 0/1 旗标，保留「曾经缺失」的信号 |
| 随机回归插补 | stochastic regression imputation | 回归预测 + 随机残差 |
| k 近邻插补 | k-nearest-neighbour imputation | 用相似记录填，需先标准化 |
| 代理分裂 | surrogate split | CART 为缺失样本准备的替代分裂 |
| 敏感性分析 | sensitivity analysis | 给结论一个区间，而不是一个点 |
| Little 检验 | Little's MCAR test | 只能拒绝 MCAR，不能确认它 |
