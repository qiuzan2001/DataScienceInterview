# 06. 中英术语对照表

> 面试是英文的，但**理解用中文更快**。这份表就是这两者之间的桥：
> 左边帮你确认「我懂这个概念」，右边给你「面试时怎么说出口」的原句。
> 全表 **8 组 · 280 条**，第三列以英文句子为主——**能直接念出来的句子**比名词重要。

---

## 怎么用这份表

**① 先看中文确认理解**：扫第一列，凡是**看一眼说不出 30 秒版本**的，先回原笔记补，别急着背英文
（GLM → [[1.2 Generalized Linear Models (GLMs)]]、树 → [[7.2.2 Decision Tree]]、保险 → [[10. 保险风控考点总览]]）。

**② 记住英文**：只看第二列，把英文术语和中文概念对上。目标不是「认识」，而是**听到英文能在 1 秒内反应过来**。
面试官的提问里出现 `deviance`、`shrinkage`、`stratified`，你不该卡壳。

**③ 读出声练句子**：第三列**必须出声念**。念的时候注意三件事：
- 句子的**结构词**——`The intuition is…` / `In practice…` / `One caveat is…`（这些才是得分点，见 [[03. 答题模板与追问应对]]）
- **数字和阈值要带 "as a rule of thumb"**，别把经验值说成定理
- 念不顺的句子就改短，面试时**短的句子不会翻车**

> ⚠️ 表格里约定：`∣` 表示条件或绝对值的竖线（避免破坏表格）；`%Goods` / `%Bads` 按全库统一约定
> ——**正 WOE = 低风险**（见 [[2.3.1 WOE & IV]]）；所有「经验值」都不是定理，口头要说明。

## 1. 统计学基础

| 样本 | sample | 面试常见说法："The sample is our only window into the data-generating process, so how we draw it matters as much as what we fit." |

| 协方差 / 相关系数 | covariance / correlation | 面试常见说法："Correlation is covariance scaled to a −1 to 1 range, so it's comparable across variables." |
| 混淆变量 | confounder | 面试常见说法："A confounder is associated with both the treatment and the outcome — that's when correlation stops being causation." |

## 2. GLM 与回归

| 中文 | English | 一句话说明 / 面试常见说法 |
|---|---|---|
| 广义线性模型 | generalized linear model (GLM) | 面试常见说法："A GLM has three pieces: a distribution from the exponential family, a linear predictor, and a link function connecting the mean to that predictor." |
| 线性预测子 | linear predictor (η) | 面试常见说法："Eta is just the weighted sum of the features — the same X-beta as in linear regression." |
| 连接函数 | link function | 面试常见说法："The link maps the mean onto the real line so a linear model makes sense even when the mean is constrained." |
| 标准连接 | canonical link | 面试常见说法："With the canonical link the natural parameter equals the linear predictor, which simplifies the estimating equations and makes IRLS natural." |
| 指数族 | exponential family | 面试常见说法："Gaussian, binomial, Poisson and Gamma all belong to the exponential family, so one GLM framework covers them all." |
| 自然参数 | natural parameter (θ) | 面试常见说法："Theta controls the location of the distribution — for a Bernoulli it's exactly the log-odds." |
| 累积函数 | cumulant function, b(θ) | 面试常见说法："The mean is the first derivative of b and the variance is the second derivative scaled by phi — that's why this form is so convenient." |
| 散度参数 | dispersion parameter (φ) | 面试常见说法："For binary and Poisson models phi is fixed at one; for Gamma or Gaussian we estimate it." |
| 方差函数 | variance function | 面试常见说法："The variance function encodes how the spread changes with the mean — constant for Gaussian, mean-squared for Gamma." |
| 逻辑回归 | logistic regression | 面试常见说法："Logistic regression is a GLM with a binomial response and a logit link — we're fitting a linear model to the log-odds." |
| 几率 | odds | 面试常见说法："Odds are the probability of the event divided by the probability of not the event — at low probabilities they're close to the risk." |
| 对数几率 | log-odds | 面试常见说法："The log-odds are unbounded, which is exactly why they pair so naturally with a linear predictor." |
| 几率比 | odds ratio (OR) | 面试常见说法："The odds ratio is e to the beta — it tells you how many times the odds multiply for a one-unit increase in that feature." |
| Sigmoid / 反 logit | sigmoid / inverse logit | 面试常见说法："The sigmoid squashes the linear predictor back into zero-to-one, which is why the output is always a valid probability." |
| probit 模型 | probit model | 面试常见说法："Probit uses the inverse normal CDF instead of the logit — the fitted curves are very close except in the tails." |
| 二项分布 | binomial distribution | 面试常见说法："A binary outcome is a binomial with one trial, so its variance is p times one minus p and depends on the mean." |
| 泊松回归 | Poisson regression | 面试常见说法："Poisson regression with a log link is the standard model for claim counts, and it gives multiplicative rate relativities." |
| 暴露量偏移 | offset (log exposure) | 面试常见说法："We include log exposure as an offset with the coefficient fixed at one, so we model the rate rather than the raw count." |
| 过散布 | overdispersion | 面试常见说法："Overdispersion means the variance is larger than the mean — the coefficients are still consistent but the standard errors are too small." |
| 负二项回归 | negative binomial regression | 面试常见说法："A negative binomial adds a dispersion parameter to the Poisson, which fixes the standard errors under overdispersion." |
| 零膨胀模型 | zero-inflated model | 面试常见说法："When there are more zeros than a Poisson can produce, a zero-inflated model splits the process into a structural-zero part and a count part." |
| Gamma 回归 | Gamma regression | 面试常见说法："Claim severity is positive and right-skewed, so a Gamma GLM with a log link is the natural starting point." |
| Tweedie 分布 | Tweedie distribution | 面试常见说法："Tweedie lets us model pure premium directly because it has a point mass at zero and a continuous positive part." |
| 偏差 | deviance | 面试常见说法："Deviance is twice the difference in log-likelihood between the saturated model and our model — it plays the role of the residual sum of squares." |
| 残差偏差 | residual deviance | 面试常见说法："I compare the residual deviance to the degrees of freedom as a rough goodness-of-fit check." |
| AIC / BIC | AIC / BIC | 面试常见说法："AIC and BIC penalise complexity; BIC penalises harder because its penalty grows with the log of the sample size." |
| Wald 检验 | Wald test | 面试常见说法："The Wald test divides the estimate by its standard error — that's the z-value software reports next to each coefficient." |
| 似然比检验 | likelihood ratio test | 面试常见说法："For nested models I prefer the likelihood ratio test — it behaves better than Wald when coefficients are large." |
| 迭代加权最小二乘 | iteratively reweighted least squares (IRLS) | 面试常见说法："IRLS is Newton-Raphson in disguise — each step is a weighted least squares solve with data-driven weights." |
| 完全分离 | complete separation | 面试常见说法："Complete separation means some combination of predictors perfectly splits the two classes, so the coefficients run off to infinity." |
| 准分离 | quasi-separation | 面试常见说法："With quasi-separation the optimiser chases ever larger coefficients and the standard errors explode — the numbers may converge but they're meaningless." |
| Firth 惩罚 | Firth's penalised likelihood | 面试常见说法："Firth's penalty is what actually gives you a finite estimate under separation — that's what logistf does in R." |
| 正则化 | regularization | 面试常见说法："Regularisation adds a penalty for complexity, which trades a little bias for a lot less variance." |
| 岭回归 | ridge regression (L2) | 面试常见说法："Ridge shrinks coefficients smoothly but never sets them exactly to zero, which helps when predictors are correlated." |
| Lasso 回归 | lasso regression (L1) | 面试常见说法："Lasso produces sparse solutions because the constraint region has corners on the axes — that's automatic feature selection." |
| 弹性网 | elastic net | 面试常见说法："Elastic net blends L1 and L2, so it keeps Lasso's sparsity but handles correlated groups more gracefully." |
| 惩罚强度 λ | tuning parameter λ | 面试常见说法："Lambda is chosen by cross-validation; zero means no penalty and infinity shrinks everything to the intercept." |
| 1-SE 规则 | one-standard-error rule | 面试常见说法："The one-SE rule picks the simplest model whose cross-validated error is within one standard error of the best — it favours stability over a marginal gain." |
| 共线性 | multicollinearity | 面试常见说法："Multicollinearity mostly hurts interpretation, not prediction — the coefficients become unstable even when the fit looks fine." |
| 方差膨胀因子 | variance inflation factor (VIF) | 面试常见说法："VIF measures how much the variance of a coefficient is inflated; the standard error only grows by the square root of VIF, so a VIF of ten is about a threefold standard error, not tenfold." |
| 每个变量的事件数 | events per variable (EPV) | 面试常见说法："A common rule of thumb is at least ten to twenty events per variable in the rarer class — below that the estimates get unstable." |
| 病例对照抽样 | case-control / retrospective sampling | 面试常见说法："With case-control sampling the slopes are essentially unchanged and only the intercept shifts, so we can correct the intercept afterwards." |
| 截距校正 | intercept correction | 面试常见说法："The intercept absorbs the prior, so if we change the sampling ratio we just subtract the difference in log-odds to get back to population probabilities." |

## 3. 评估指标

| 中文 | English | 一句话说明 / 面试常见说法 |
|---|---|---|
| 混淆矩阵 | confusion matrix | 面试常见说法："Everything starts from the confusion matrix — precision, recall and accuracy are just different ways of reading it." |
| 假阳性 | false positive (FP) | 面试常见说法："A false positive is a false alarm — in insurance it costs an unnecessary review." |
| 假阴性 | false negative (FN) | 面试常见说法："A false negative is a missed case, and in fraud or claims work that's usually the expensive one." |
| 准确率 | accuracy | 面试常见说法："Accuracy is misleading under imbalance — predicting the majority class alone already looks great." |
| 精确率 | precision | 面试常见说法："Precision answers: of everything we flagged, how much was real?" |
| 召回率 / 灵敏度 | recall / sensitivity / true positive rate | 面试常见说法："Recall answers: of all the real cases, how many did we catch?" |
| F1 分数 | F1 score | 面试常见说法："F1 is the harmonic mean of precision and recall, so it punishes a model that's good at only one of them." |
| 分类阈值 | decision threshold | 面试常见说法："The threshold is a business decision, not a modelling one — I'd tune it against the cost matrix rather than leave it at 0.5." |

| 曲线下面积 | AUC / AUROC | 面试常见说法："AUC is the probability that a random positive scores higher than a random negative — it's threshold-free and purely about ranking." |
| 基尼系数 | Gini coefficient | 面试常见说法："In risk work we often report Gini, which is just two times AUC minus one." |
| KS 统计量 | Kolmogorov-Smirnov statistic | 面试常见说法："KS is the maximum distance between the cumulative score distributions of the good and the bad — a rule of thumb is above 0.3 is usable." |

| 累积增益图 | cumulative gains chart | 面试常见说法："A gains chart says: if we act on the top ten percent, what share of all events do we capture?" |

| 校准 | calibration | 面试常见说法："A model can rank well and still be badly calibrated — if the business uses the probability itself, calibration matters as much as AUC." |
| 可靠性图 | reliability diagram / calibration curve | 面试常见说法："I plot predicted probability against observed frequency — if it's not close to the diagonal, the probabilities aren't trustworthy." |
| Platt 缩放 | Platt scaling | 面试常见说法："Platt scaling fits a logistic regression on the scores to map them back to calibrated probabilities." |

| 对数损失 | log loss | 面试常见说法："Log loss punishes confident mistakes very heavily, which is why it's the natural loss for probability models." |
| 均方根误差 | root mean squared error (RMSE) | 面试常见说法："RMSE is in the units of the target and penalises large errors more than MAE." |
| 平均绝对误差 | mean absolute error (MAE) | 面试常见说法："MAE is more robust to outliers but it doesn't punish big misses as much." |
| 平均绝对百分比误差 | mean absolute percentage error (MAPE) | 面试常见说法："MAPE blows up when the actual value is near zero, so I'd use it only when the target is comfortably away from zero." |
| 加权绝对百分比误差 | weighted absolute percentage error (WAPE) | 面试常见说法："WAPE aggregates first and then takes the ratio, so it stays stable when individual values are zero." |
| 决定系数 | R-squared | 面试常见说法："R-squared can be negative — that just means the model is worse than predicting the mean." |
| 早停 | early stopping | 面试常见说法："I early-stop on the validation loss, because the training loss will keep going down forever." |
| 群体稳定性指标 | population stability index (PSI) | 面试常见说法："PSI compares the current score distribution with the baseline — below 0.1 is stable, above 0.25 is a real drift signal." |
| 模型监控 | model monitoring | 面试常见说法："Once a model is live, monitoring inputs and outputs matters more than squeezing out another point of AUC." |
| 漂移 | drift | 面试常见说法："There are two kinds of drift: the inputs move, or the relationship between inputs and outcome moves — PSI catches the first, performance tracking catches the second." |
| 时间外样本 | out-of-time (OOT) sample | 面试常见说法："For anything with a time dimension I validate on an out-of-time sample, because a random split is optimistically biased." |
| 交叉验证 | cross-validation (CV) | 面试常见说法："Cross-validation gives a more stable estimate than a single split, because every observation gets to be in the validation set once." |
| K 折交叉验证 | k-fold cross-validation | 面试常见说法："Five or ten folds is the usual default; more folds means less bias but more compute." |
| 分层 K 折 | stratified k-fold | 面试常见说法："I stratify on the label so rare events appear in every fold at the same rate." |
| 分组交叉验证 | grouped cross-validation | 面试常见说法："If one customer appears many times, I group by customer so the same entity never shows up in both train and validation." |
| 嵌套交叉验证 | nested cross-validation | 面试常见说法："Nested CV keeps the tuning inside the inner loop, so the outer score isn't contaminated by the search." |
| 数据泄漏 | data leakage | 面试常见说法："Leakage is when information from outside the training fold sneaks into the features — it makes the offline numbers look great and the live model fail." |

## 4. 树与集成

| 中文 | English | 一句话说明 / 面试常见说法 |
|---|---|---|
| 决策树 | decision tree | 面试常见说法："A decision tree recursively partitions the feature space into regions and predicts a constant inside each region." |
| 树深 | tree depth | 面试常见说法："Depth controls how many interactions the tree can represent, and it's the main lever for the bias-variance trade-off." |
| 不纯度 | impurity | 面试常见说法："Impurity measures how mixed the node is — the algorithm keeps splitting until the nodes are pure or a stopping rule kicks in." |
| 熵 | entropy | 面试常见说法："Entropy is measured in bits and peaks at one for a balanced binary node." |
| 信息增益 | information gain | 面试常见说法："Information gain is the parent's impurity minus the weighted average of the children's — higher means a better split." |
| 增益率 | gain ratio | 面试常见说法："Gain ratio divides information gain by split information — that's C4.5's fix for the bias toward many-valued features." |
| Gini 指数 | Gini index | 面试常见说法："Gini is the probability of misclassifying a randomly drawn pair, and it's cheaper than entropy because there's no logarithm." |
| 误分类率 | misclassification error | 面试常见说法："Misclassification error is piecewise linear, so two children on the same side of one half give exactly zero gain — that's why we don't grow trees with it." |
| 严格凹函数 | strictly concave function | 面试常见说法："Entropy and Gini are strictly concave, so any split that makes the children purer gives a strictly positive gain." |
| 分段线性 | piecewise linear | 面试常见说法："Because the error rate is piecewise linear, it flat-lines and the algorithm can't see the improvement at all." |
| 预剪枝 | pre-pruning / early stopping | 面试常见说法："Pre-pruning is cheap but it's short-sighted — you stop before you can see whether the branch would have paid off." |
| 后剪枝 | post-pruning | 面试常见说法："Post-pruning grows the full tree first and then removes branches that don't earn their keep, which is usually more accurate." |
| 代价复杂度剪枝 | cost-complexity pruning (CCP) | 面试常见说法："CCP minimises R of T plus alpha times the number of leaves, so alpha is the price you pay per leaf." |
| 复杂度参数 α | complexity parameter α | 面试常见说法："Alpha equal to zero gives the maximal tree, and alpha going to infinity collapses everything to the root." |
| 最弱环节剪枝 | weakest-link pruning | 面试常见说法："Weakest-link pruning removes the branch with the smallest increase in error per leaf saved, which generates a nested sequence of trees." |
| 袋装法 | bagging (bootstrap aggregating) | 面试常见说法："Bagging trains the same learner on many bootstrap samples and averages — it's a variance-reduction technique." |
| 自助样本 | bootstrap sample | 面试常见说法："Each bootstrap sample is the same size as the original, drawn with replacement, so about a third of the rows are left out." |
| 袋外误差 | out-of-bag (OOB) error | 面试常见说法："Every tree has its own out-of-bag rows, so we get a validation estimate for free." |
| 随机子空间 | random subspace | 面试常见说法："Random subspace means each split only considers a random subset of features, which de-correlates the trees." |
| 随机森林 | random forest | 面试常见说法："A random forest is bagging plus feature sampling — the feature sampling lowers the correlation between trees, which is what actually drives the variance reduction." |
| 每次分裂的特征数 | number of features per split, m | 面试常见说法："The usual defaults are the square root of p for classification and p over three for regression." |
| 特征重要性 | feature importance | 面试常见说法："I report importance but I never treat it as a causal statement — it's a description of what the model uses." |
| 平均不纯度下降 | mean decrease in impurity (MDI) | 面试常见说法："MDI is free because it comes out of training, but it's biased toward high-cardinality features." |
| 置换重要性 | permutation importance | 面试常见说法："Permutation importance should be computed on out-of-bag or held-out data — on the training set the model has memorised the pattern and the score barely moves." |
| 高基数变量 | high-cardinality variable | 面试常见说法："A variable with many levels gets more chances to split, so both MDI and, to a lesser extent, permutation importance inflate it." |
| SHAP 值 | SHAP values | 面试常见说法："SHAP gives a per-prediction attribution, which is what we need when an underwriter asks why this application was flagged." |
| 集成学习 | ensemble learning | 面试常见说法："Ensembles work because the base models are accurate and diverse — if they all make the same mistake, averaging won't help." |
| 提升法 | boosting | 面试常见说法："Boosting fits learners sequentially, each one on the mistakes of the previous ensemble — it mainly reduces bias." |
| 自适应提升 | AdaBoost | 面试常见说法："AdaBoost reweights the misclassified points each round and takes a weighted vote at the end." |
| 加权误差 | weighted error | 面试常见说法："The weighted error is the sum of the sample weights on the misclassified points; if it hits one half, the learner gets no say." |
| 投票权重 | vote weight, α | 面试常见说法："The vote weight is half the log of one minus epsilon over epsilon, so it blows up as the learner gets more accurate." |
| 前向分步加性模型 | forward stagewise additive model | 面试常见说法："Both AdaBoost and gradient boosting are forward stagewise additive models — they just use different losses." |
| 指数损失 | exponential loss | 面试常见说法："AdaBoost is exactly forward stagewise additive modelling with exponential loss, which is where the alpha formula comes from." |
| 梯度提升 | gradient boosting | 面试常见说法："Gradient boosting fits each new tree to the negative gradient of the loss, so it works with any differentiable loss." |
| 伪残差 | pseudo-residual | 面试常见说法："For squared error the pseudo-residual is the ordinary residual; for other losses it's just the negative gradient direction." |
| 学习率 / 收缩因子 | learning rate / shrinkage, eta | 面试常见说法："A smaller learning rate means each tree contributes less, so you need more trees but you usually generalise better." |
| 子采样 | subsampling | 面试常见说法："Row and column subsampling add randomness, which helps against overfitting and speeds up training." |
| 堆叠法 | stacking | 面试常见说法："Stacking trains a meta-learner on out-of-fold predictions from the base models — the out-of-fold part is what keeps it honest." |
| 偏差-方差权衡 | bias-variance trade-off | 面试常见说法："Total error is bias squared plus variance plus irreducible noise — bagging attacks the middle term, boosting attacks the first." |

## 5. 特征工程与数据质量

| 中文 | English | 一句话说明 / 面试常见说法 |
|---|---|---|
| 特征工程 | feature engineering | 面试常见说法："In tabular insurance problems feature engineering usually buys more than model choice." |
| 缺失值 | missing value | 面试常见说法："The first question isn't how to fill it, it's why it's missing — that determines whether any fix is valid." |
| 缺失机制 | missingness mechanism | 面试常见说法："The mechanism decides everything: under MAR imputation is defensible, under MNAR it isn't." |
| 完全随机缺失 | missing completely at random (MCAR) | 面试常见说法："Under MCAR the remaining rows are still a random subsample, so complete-case analysis stays unbiased — we just lose power." |
| 随机缺失 | missing at random (MAR) | 面试常见说法："Under MAR the missingness depends on observed variables, so we can model it and impute without bias." |
| 非随机缺失 | missing not at random (MNAR) | 面试常见说法："Under MNAR the missingness depends on the value itself — the people who don't report income are the high earners — so standard imputation is biased." |
| 完整案例分析 | complete case analysis | 面试常见说法："Complete-case analysis is fine under MCAR with a small missing rate — the trap is that ten variables each missing three percent can drop a quarter of the rows." |
| 均值插补 | mean / mode imputation | 面试常见说法："Mean imputation destroys variance and flattens correlations, so it makes the model look more confident than it is." |
| 多重插补 | multiple imputation (MICE) | 面试常见说法："Multiple imputation admits we don't know the missing values, generates several plausible datasets, and folds that uncertainty into the variance." |
| Rubin 合并规则 | Rubin's rules | 面试常见说法："We pool the estimates with Rubin's rules: the total variance is the within-imputation variance plus a factor times the between-imputation variance." |
| 回归插补 | regression imputation | 面试常见说法："Plain regression imputation puts every point on the line, so I'd add noise and use stochastic regression imputation instead." |
| k 近邻插补 | k-nearest-neighbour imputation | 面试常见说法："k-NN imputation is non-parametric but it needs scaled features, otherwise distance is dominated by the largest-scale variable." |
| 虚拟变量 | dummy variable | 面试常见说法："A categorical feature becomes k minus one dummies so we don't fall into the dummy variable trap." |
| 独热编码 | one-hot encoding | 面试常见说法："One-hot is fine for low cardinality; above that I'd rather use WOE or target encoding." |
| 分箱 | binning | 面试常见说法："Binning stabilises the relationship and lets the scorecard express it as a step function." |
| 细分类 / 粗分类 | fine classing / coarse classing | 面试常见说法："We start fine — ten to twenty bins — then merge adjacent bins until every bin has at least five percent and the WOE is monotone." |
| 证据权重 | weight of evidence (WOE) | 面试常见说法："WOE is the log of the percentage of goods over the percentage of bads, so a positive WOE means lower risk." |
| 信息值 | information value (IV) | 面试常见说法："IV sums the differences in the distributions times WOE; as a rule of thumb, below 0.02 is useless, 0.1 to 0.3 is medium and above 0.5 is suspicious." |
| 目标编码 | target encoding | 面试常见说法："Target encoding is the general version of WOE for non-binary targets, and it needs out-of-fold computation to stay leak-free." |
| 标准化 / 归一化 | standardization / normalization | 面试常见说法："Linear models and distance-based methods need scaling; trees don't, because they only look at the ordering." |
| 交互项 | interaction term | 面试常见说法："An interaction says the effect of one feature depends on another — in insurance that's exactly what a rating factor is doing when it's applied on top of a base class." |
| 变量筛选 | variable selection | 面试常见说法："Feature selection is either filter, wrapper or embedded — I pick based on how much compute and how much interpretability I need." |
| 过滤法 | filter method | 面试常见说法："Filter methods score each feature on its own and are fast, but they ignore interactions." |
| 包装法 | wrapper method | 面试常见说法："Wrapper methods evaluate subsets with the actual model, so they're accurate but expensive." |
| 嵌入法 | embedded method | 面试常见说法："Embedded methods select during training — lasso and tree-based importance are the usual examples." |
| 逐步回归 | stepwise selection | 面试常见说法："Stepwise selection optimises fit, not inference — the p-values afterwards are no longer valid." |
| 递归特征消除 | recursive feature elimination (RFE) | 面试常见说法："RFE repeatedly fits the model and drops the weakest feature until the target number remains." |
| 互信息 | mutual information | 面试常见说法："Mutual information captures non-linear dependence, which chi-square or correlation can miss." |
| 主成分分析 | principal component analysis (PCA) | 面试常见说法："PCA gives uncorrelated components with VIF of one, but you lose the ability to explain any single coefficient." |
| 异常值 | outlier | 面试常见说法："An outlier may be a data error or a real large loss — I check the source before deciding whether to drop it." |
| 数据质量检查 | data quality check | 面试常见说法："Before modelling I always check ranges, duplicates, joins and the event rate over time — most 'model problems' are data problems." |

## 6. 保险与精算

| 中文 | English | 一句话说明 / 面试常见说法 |
|---|---|---|
| 索赔频率 | claim frequency | 面试常见说法："Frequency is the number of claims per unit of exposure, and we model it with a Poisson GLM with a log link." |
| 索赔严重度 | claim severity | 面试常见说法："Severity is the average cost per claim, typically positive and right-skewed, so I'd start with a Gamma GLM." |
| 纯保费 | pure premium | 面试常见说法："The pure premium is frequency times severity — it's the expected loss per unit of exposure, before expenses." |
| 赔付率 | loss ratio | 面试常见说法："The loss ratio is losses divided by premium, and it's the number the underwriters actually watch." |
| 暴露量 | exposure | 面试常见说法："Exposure is the amount of risk we actually covered — a policy written mid-year contributes half a year." |
| 风险单位 | unit of exposure | 面试常见说法："We model the rate per unit of exposure and put log exposure in as an offset with coefficient one." |
| 免赔额 | deductible | 面试常见说法："A deductible truncates the loss distribution, so historical severity understates the true ground-up cost." |
| 赔偿限额 | policy limit | 面试常见说法："A limit censors the large losses, which is why the observed severity curve flattens at the cap." |
| 赔案 / 损失事件 | claim / loss event | 面试常见说法："Each claim is a loss event; the modelling question is whether it's a frequency or a severity problem." |
| 准备金 | reserves / loss reserves | 面试常见说法："Reserving answers how much we should hold today for claims that haven't been settled yet." |
| 链梯法 | chain-ladder method | 面试常见说法："The chain-ladder is the workhorse deterministic reserving method — it develops each accident year to ultimate with age-to-age factors." |
| 已发生未报案 | incurred but not reported (IBNR) | 面试常见说法："IBNR is the part of the reserve for claims that have happened but haven't been reported yet." |
| 风险分类 | risk classification | 面试常见说法:"Risk classification groups similar risks so that each group's premium reflects its own expected loss." |
| 费率因子 | rating factor | 面试常见说法："A rating factor is just a coefficient after exponentiation — a relativity that multiplies the base premium." |
| 相对数 | relativity | 面试常见说法："We report relativities because that's what goes into the rate manual — nobody files a raw coefficient." |
| 基准水平 | base level | 面试常见说法："Every categorical factor needs a base level, and every coefficient is read relative to it." |
| 乘性模型 | multiplicative model | 面试常见说法："With a log link the effects are multiplicative, so the premium is the base rate times a product of relativities." |
| 评分卡 | scorecard | 面试常见说法："A scorecard turns the model into points per bin, which business users can apply by hand if they need to." |
| 分数刻度 | score scaling | 面试常见说法："We scale the score as A minus B times the log-odds, so the score moves in the direction people expect." |
| 翻倍分数 | points to double the odds (PDO) | 面试常见说法："B equals PDO over the natural log of two — with a PDO of twenty that's about 28.85." |
| 基准几率 | base odds / offset | 面试常见说法："The offset and the base odds set the anchor of the scale; everything else is relative to that." |
| 信度 | credibility | 面试常见说法："Credibility blends the experience of this group with the experience of the broader portfolio — it's how we avoid pricing on ten claims." |
| 信度因子 | credibility factor, Z | 面试常见说法："Z is the weight on the group's own experience; with little exposure Z is close to zero and we lean on the portfolio." |
| Bühlmann 模型 | Bühlmann credibility model | 面试常见说法："The Bühlmann model derives the credibility weight from the within-group variance and the variance of the group means." |
| 逆选择 | adverse selection | 面试常见说法："Adverse selection is what happens when the people who buy your product are the ones you underpriced." |
| 道德风险 | moral hazard | 面试常见说法："Moral hazard is behaviour changing after cover is in place — it's a pricing problem, not a modelling one." |
| 核保 | underwriting | 面试常见说法："Underwriting decides whether to accept the risk, and at what rate — that's where a risk model adds the most value." |
| 拒付 / 拒赔 | denial | 面试常见说法："Denials are the highest-stakes decision in this process, so a false positive costs a customer relationship." |
| 续保 | renewal | 面试常见说法："Retention modelling is a classic churn problem, but here the features are policy and claims history." |
| 退保 | lapse | 面试常见说法:"Lapse is the policyholder walking away — it's the mirror image of renewal and it changes the book's risk mix." |
| 欺诈识别 | fraud detection | 面试常见说法："Fraud is rare, adversarial and delayed, so recall and stability matter more than accuracy." |
| 索赔倾向 | claim propensity | 面试常见说法："Claim propensity is the probability that a policyholder will claim at all — it's a binary model on top of the frequency one." |
| 损失分布 | loss distribution | 面试常见说法："We choose a loss distribution that matches the tail, because the mean alone won't price a catastrophe." |
| 大额损失 | large loss | 面试常见说法："Large losses are rare but they dominate the average, so I'd look at the truncated and the full view side by side." |
| 再保险 | reinsurance | 面试常见说法："Reinsurance caps our tail exposure, which changes the economics of the model but not the underlying risk." |
| 预期损失 | expected loss | 面试常见说法："Expected loss is probability of default times loss given default times exposure — the three factors are modelled separately." |
| 聚合损失 | aggregate loss | 面试常见说法："Aggregate loss combines frequency and severity into one distribution, often through a Tweedie GLM." |

## 7. 实验与业务

| 中文 | English | 一句话说明 / 面试常见说法 |
|---|---|---|
| A/B 测试 | A/B test | 面试常见说法："An A/B test is the only way to establish causality cheaply — randomisation balances everything we didn't measure." |
| 对照组 | control group | 面试常见说法："The control group is the counterfactual — without it we're just describing what happened, not what caused it." |
| 处理组 | treatment group | 面试常见说法："Treatment and control should differ only in the intervention, which is what randomisation buys us." |
| 随机化 | randomization | 面试常见说法："Randomisation is the key step, because it makes the treatment independent of everything else." |
| 分流 | traffic split | 面试常见说法："A fifty-fifty split maximises power for a fixed sample size, but if the change is risky I'd start smaller." |
| 样本量计算 | sample size calculation / power analysis | 面试常见说法："You size the test from the minimum effect you care about, not from the data you happen to have." |
| 最小可检测效应 | minimum detectable effect (MDE) | 面试常见说法："If the MDE is bigger than the business cares about, the test isn't worth running." |

| 因果推断 | causal inference | 面试常见说法："Causal inference is about what would have happened under the other treatment; prediction alone can't answer that." |
