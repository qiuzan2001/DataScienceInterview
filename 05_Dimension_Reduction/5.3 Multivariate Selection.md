# 5.3 多变量筛选（Multivariate Selection）

## 速览 At a glance

**速记**

单变量筛选（IV、单变量 AUC、相关系数）只看「一条特征单独多强」，抓不到冗余和交互。四类多变量做法各管一段：相关 / VIF 过滤管线性冗余，代价是漏掉非单调依赖，所以要配 Spearman + Hoeffding's D 四格表，把「低相关但高 Hoeffding D」的 U 形变量救回来；互信息管任意依赖（含非线性），代价是对分箱与样本量敏感；RFE 和 stepwise 以模型为中心，能抓交互，代价是贵、且只到局部最优，p 大时很慢。所有方法共享一条铁律：**选择和评估必须在同一折内隔开**（嵌套 CV），否则分数乐观、上线反弹。选完再用 stability selection 看选择本身稳不稳。

**一句面试答法**

> "Univariate screening — correlations, IV, single-variable AUC — tells me what works alone, not what works together. For redundancy I use correlation and VIF; for non-monotone dependence I pair Spearman with Hoeffding's D so I don't throw away U-shaped variables; mutual information covers any kind of dependence. For interactions I let a model decide, with RFE or stepwise, and I always do the selection inside the cross-validation folds."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 过滤法 / 包裹法 / 嵌入法 | filter / wrapper / embedded | 按「用不用模型、选择在哪一步」分三类 |
| 互信息 | mutual information | 任意依赖的信息量，不假设形状 |
| 递归特征消除 | recursive feature elimination (RFE) | 训练 → 删最弱 → 重训，循环 |
| 逐步选择 | stepwise selection | 贪心加 / 删，用 AIC / BIC / CV 打分 |
| 稳定性选择 | stability selection | bootstrap 下出现频率高的变量才留 |

## 一、先看一个问题

手上是一张 200 列的宽表。单变量筛完你留下 40 列，每一列的 IV 都不差。然后：

* 跑逻辑回归，VIF 报 12；删掉两列之后，第三列的系数**正负翻转**。
* 200 列全丢进 GBM，测试集 AUC 0.81；按 IV 取前 20 列，AUC 反而掉到 0.77。
* 再换：RFE 在训练集上选出 15 列，报出的 CV-AUC 是 0.86；上线第一个月实际只有 0.79。

第三个现象是最贵的那种错 —— **模型没坏，是选变量的流程坏了**。

面试官的原话就摆在开头那张真题清单里：**"Walk me through your variable reduction workflow on a wide dataset."** 这句话背后考三件事：你知道有几类方法、每类解决什么、以及**选的这一步放在流程的哪个位置**。下面按这三件事拆。

## 📖 标准定义

> **教材原文 · PSL §3.1.2 Selection Criteria、§3.1.4 Search Algorithms（页面 w3_1_subset.html）**（<https://liangfgithub.github.io/PSL/w3/w3_1_subset.html>）
> > "The score for model selection typically comprises two components: A goodness of fit measure: often an increasing function of the residual sum of squares. A complexity penalty term: often an increasing function of p, the number of non-intercepted variables."
> >
> > "A popular method is the ‘level-wise search algorithm’, which works as follows: Grouping Models by Size : Imagine there are p potential predictors. Models can then be grouped into p groups. For instance: The first group consists of models with just one predictor, the second group has models with two predictors, and so on, until the last group, which contains a model with all predictors."
> >
> > "Backward Search : Start with the full model and sequentially eliminate predictors until the score no longer improves."
> >
> > "Forward Search : Start with a null model (only the intercept) and sequentially add predictors until the score no longer improves."
> >
> > "The nature of greedy algorithms, given their specific path of search, means they may stop at a locally optimal solution rather than a globally optimal one. However, they’re faster and often yield solutions that are practically sufficient."

**标准记法**：

- 模型由二元向量索引，$2^p$ 个候选；打分 = 拟合优度 + 复杂度惩罚：minimize $\text{RSS} + \lambda |\mathcal{M}|$。
- 常见准则（通用形式）：$\text{AIC} = n \log(\text{RSS}/n) + 2|\mathcal{M}|$；$\text{BIC} = n \log(\text{RSS}/n) + \log(n)\,|\mathcal{M}|$；Mallow's $C_p = \text{RSS}/\hat{\sigma}^2 + 2|\mathcal{M}| - n$。

**中文解释**：子集选择＝在 $2^p$ 个候选模型里按「拟合好 + 惩罚复杂度」打分找最优。全枚举（level-wise）在 $p>40$ 基本不可行，于是用贪心：backward 从全模型删、forward 从截距模型加、stepwise 两者结合且允许反悔。贪心只能到局部最优，但快且够用。

> 完整条目与更多来源见 [[定义原文库#B6. 子集选择（best subset / forward / backward / stepwise）|B6 子集选择（best subset / forward / backward / stepwise）]]

## 二、核心直觉

### 单变量问「他一个人多能打」，多变量问「已经招了他，再招他还能补什么」

单变量筛选（IV、单变量 AUC、相关系数）给出的是**一条特征单独看有多强**。多变量筛选要回答的是另一件事：**把这一组特征放在一起，谁还有增量信息。**

**这里像什么、不像什么**：像组队。单变量筛选是看每个人的简历分；多变量筛选是看「在已经招了 A 的前提下，B 还能补什么」。**不一样的地方在于**：简历分可以各自独立地看，特征之间却会互相顶替 —— 两条高度相关的特征，谁进谁不进，会随样本抖动而换人。所以多变量筛选的结果天生比单变量筛选**更不稳定**，需要重抽样或稳定性选择来兜。

### 冗余和交互是两件事，方法要配着用

| 你要抓的问题 | 用什么 | 为什么 |
|---|---|---|
| 两条特征说的是同一件事（冗余） | 相关矩阵、VIF | 线性冗余，算得快、解释清楚 |
| 特征与目标是非单调关系（U 形） | Spearman + Hoeffding's D 配对表 | 相关系数看不见非单调信号 |
| 任意形式的依赖（含非线性冗余） | 互信息（MI） | 不看形状，只看信息量 |
| 特征之间要一起才有效（交互） | RFE、stepwise 这类以模型为中心的方法 | 打分由模型出，交互自然进得来 |

**这一节真正的操作含义**：没有哪一个多变量筛选方法能同时把冗余和交互都抓好。面试里被问「你怎么做变量筛选」，一个能加分的答法是**说清每一层在解决什么**，而不是背一个方法名。

## 三、机制

### 3.1 定义与逐项说明：三类筛选思路与四个方法

先给一张选型表，再逐个拆开。


| **方法（Method）** | **最适合（Best For）** | **什么时候别用（Avoid When）** |
|:-----------|:-------------|:---------------|
| **相关 / VIF 过滤（Correlation/VIF Filter）** | 快速发现共线性、线性关系 | 非线性依赖、特征集很小 |
| **互信息（Mutual Information）** | 非线性关系、任意类型的依赖 | 样本量小、维度很高 |
| **递归特征消除（Recursive Feature Elimination, RFE）** | 结合具体模型做优化、捕捉交互 | 特征很多（p > 100）、时间紧 |
| **逐步选择（Stepwise Selection）** | 找小而优的特征子集、模型可解释 | 高维数据、算力受限 |
**💡 最佳实践（Best Practice）：** 先用 correlation/VIF 处理线性冗余，再用 MI 或 RFE 处理复杂交互，并且**用交叉验证做验证**以防过拟合。


### 3.2 它是怎么来的

**为什么「用同一份数据选变量、又用同一份数据评估」一定乐观。** 变量选择本质上是在 $2^p$ 个候选里取一个**极值**（打分最大或最小）。极值统计量带正的偏置：候选够多时，纯噪声里最好的那一组也会显得不错。这不是理论上的小修正，它是这一章所有方法共同的风险来源。

**关键一步在这里**：你报出来的那个 CV 分数，**已经包含了「哪一组最好」这条信息**。这条信息在测试集上不存在。所以流程只有一条：**把「选」和「评」隔开** —— 选择放内层、评估放外层（嵌套 CV），或者用 stability selection 看选择本身稳不稳。

**filter 与 wrapper 的差别也在这里。** filter（相关、VIF、MI）的打分不依赖具体模型，偏置主要来自「在多少条里挑」；wrapper（RFE、stepwise）的打分就是模型表现，还额外把超参数一起挑，所以 p 大时特别容易给出乐观结果。

**一个能自己复算的例子**在第四节：5 行数据配 4 个变量，辅助回归的 $R^2$ 已经到 0.9879。变量一多、样本一少，「看起来有解释力」会自动出现。

### 3.3 变形与口径：四个方法的原理、公式与代价

几条口径先统一，后面逐个方法就只看细节：

* **三类口径（filter / wrapper / embedded）**：filter 只看统计量不看模型（相关、VIF、MI），快而稳，但和最终目标未必在一条线上；wrapper 用模型打分（RFE、stepwise），贴目标但贵、选择偏置更大；embedded 把选择写进目标函数（lasso、树重要性），一步完成。
* **阈值口径**：$|r|>0.8$ 与 VIF $>10$ 是两条经验线，**不等价** —— 两个变量时 $\mathrm{VIF} = 1/(1-r^2)$，$r=0.8$ 只对应 VIF 2.78。
* **打分口径**：stepwise 用 AIC（$2k$）、BIC（$k\log n$）还是 CV，会选出不同的子集；BIC 惩罚更重、更保守。
* **泄漏口径**：标准化、筛选、超参搜索，任何一步都要在 CV 折内完成。
* **重要性口径**：树 importance、lasso 系数、单变量 IV，三者在相关变量组内的分配方式不同，不能混着比。

#### **[[3.4.2 Variance Inflation Factor (VIF) | 1. Correlation/VIF Filter]]**

##### **Core Idea**
把彼此高度相关的特征删掉，消除冗余。VIF（variance inflation factor，方差膨胀因子）衡量的是：**一个特征能被其他特征解释到什么程度** —— VIF 高就说明存在共线性（multicollinearity）问题。

##### **Mathematical Foundation**

**Pearson 相关系数（Pearson Correlation Coefficient）：**
$$r_{XY} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

**方差膨胀因子（Variance Inflation Factor）：**
$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

其中 $R_j^2$ 是把特征 $j$ 对其余所有特征做回归时的决定系数（coefficient of determination）。

> [! Step-by-Step Calculation]-
>
> **示例：特征相关性分析（Feature correlation analysis）**
>
> **Step 1: 算相关矩阵（correlation matrix）**
>
> 数据集：
> | ID | Age | Experience | Income | Education |
> |----|-----|------------|--------|-----------|
> | 1  | 25  | 2          | 35000  | 12        |
> | 2  | 30  | 8          | 45000  | 16        |
> | 3  | 35  | 12         | 55000  | 14        |
> | 4  | 40  | 15         | 65000  | 18        |
> | 5  | 45  | 20         | 75000  | 16        |
>
> **Age 与 Experience 的相关系数：**
> - $\bar{x}_{age} = 35$，$\bar{x}_{exp} = 11.4$
> - $\sum(x_i - \bar{x})(y_i - \bar{y}) = (25-35)(2-11.4) + ... = 370$
> - $\sum(x_i - \bar{x})^2 = (25-35)^2 + ... = 250$
> - $\sum(y_i - \bar{y})^2 = (2-11.4)^2 + ... = 324.8$
> - $r_{age,exp} = \frac{370}{\sqrt{250 \times 324.8}} = \frac{370}{285.1} = 0.898$
>
> **Step 2: 建相关矩阵**
>
> |            | Age   | Experience | Income | Education |
> |------------|-------|------------|--------|-----------|
> | **Age**    | 1.000 | **0.898**  | 0.856  | 0.234     |
> | **Experience** | **0.898** | 1.000 | 0.945  | 0.345     |
> | **Income** | 0.856 | 0.945      | 1.000  | 0.456     |
> | **Education** | 0.234 | 0.345   | 0.456  | 1.000     |
>
> **Step 3: 套相关系数阈值**
> - 阈值：$|r| > 0.8$
> - 高相关：Age-Experience（0.898）、Age-Income（0.856）、Experience-Income（0.945）
> - **结论（Decision）：** 在 Age 与 Experience 之间删掉一个（它们相关最高）
>
> **Step 4: 给剩余特征算 VIF**
>
> **Age 的 VIF（把 Age 对 Experience、Income、Education 回归）：**
> - 跑回归：$Age = \beta_0 + \beta_1 \times Experience + \beta_2 \times Income + \beta_3 \times Education$
> - 假设 $R^2 = 0.85$
> - $\text{VIF}_{Age} = \frac{1}{1-0.85} = 6.67$
>
> **Experience 的 VIF：**
> - 跑回归：$Experience = \beta_0 + \beta_1 \times Age + \beta_2 \times Income + \beta_3 \times Education$
> - 假设 $R^2 = 0.90$
> - $\text{VIF}_{Experience} = \frac{1}{1-0.90} = 10.0$
>
> **Step 5: 套 VIF 阈值**
> - 常用阈值：VIF > 10
> - **结论（Decision）：** 删掉 Experience（VIF = 10.0 > 阈值）

> **易错点**：**VIF 作用于方差**，标准误只放大 $\sqrt{\text{VIF}}$ —— VIF = 10 时标准误约放大 $\sqrt{10} \approx 3.16$ 倍，**不是 10 倍**。另外 **Tolerance = 1/VIF**，所以 `Tolerance < 0.1 ⇔ VIF > 10`。

##### **Pros & Cons**
| **优点（Pros）** | **缺点 / 要留意（Cons/Watch-outs）** |
|:---------|:-------------------|
| **简单直观，能很快发现线性冗余** | **只能抓线性关系** |
| 中等规模数据上算得很快 | **阈值是人定的** |
| 对共线性程度有清晰解释 | 漏掉非线性依赖 |
| 阈值有共识（r > 0.8、VIF > 10） | 只做两两配对，可能漏掉复杂交互 |
| 有利于模型稳定性与解释 | 可能因为相关性而删掉重要特征 |

#### Spearman + Hoeffding 配对诊断表（非线性依赖）

**为什么需要它**：上面 §1 的 Correlation/VIF 过滤（以及常见的「按相关系数排序」）只看得见**线性 / 单调**依赖。**Hoeffding's D** 度量**任意依赖（any dependence, including non-monotone）**，取值范围约 **−0.5 到 1**，能捕捉 Spearman 完全看不见的 **U 形与非单调结构**。两个统计量一起看，才是完整的单变量筛查。

| Spearman | Hoeffding's D | 诊断 | 动作 |
| --- | --- | --- | --- |
| High | High | 干净的单调关系（clean monotone） | 直接用（as-is） |
| **Low** | **High** | **有真实信号，但是非单调形状** | **分箱 / 样条 / 变换 —— 不要丢** |
| Low | Low | 检测不到任何单变量信号 | 候选删除 |
| High | Low | 罕见 / 不稳定（rare, unstable） | 回去查数据（泄漏、分组、异常值） |

**⭐ 加分点就在「Low Spearman + High D」那一格**：朴素的相关筛选（correlation filter）会把这类变量整批扔掉，而它们**常常是最好的变量**（典型 U 形例子：年龄 vs 风险、账户余额 vs 流失）。被问到「你怎么做单变量筛选」时，能把四个格子讲出来，比背 IV 阈值亮眼得多。

**🔗 跨章联系**：它既是**筛选（selection）工具**，也是**变换识别（transformation detection）工具** —— 「低 Spearman + 高 D」的意思是**该做变换**，不是「该删」。识别出形状之后做什么变换，见 [[2. Transformations]] 的 empirical logit plot 与箱均值-响应图；在 [[5.2 Univariate Selection]] 的排序清单里，除了 Spearman 再加一列 Hoeffding's D，就能白捡这些变量。

> 来源：MAGNet §5（单变量筛查 + Spearman/Hoeffding 配对表）与 §2（变换识别）；[[MAGNet 面试真题全解]]

#### **2. Mutual Information (MI)**

##### **Core Idea**
互信息（mutual information）衡量一个变量包含了另一个变量的多少信息。贪心式做法是：**选那些「对目标 MI 高、但已选特征 MI 低」的特征**，并且它能捕捉任意类型的依赖（线性或非线性）。

##### **Mathematical Foundation**

**互信息（Mutual Information）：**
$$I(X;Y) = \sum_{x \in X} \sum_{y \in Y} p(x,y) \log\left(\frac{p(x,y)}{p(x)p(y)}\right)$$

**连续变量（用核密度估计 kernel density estimation）：**
$$I(X;Y) = \int \int p(x,y) \log\left(\frac{p(x,y)}{p(x)p(y)}\right) dx dy$$

**归一化（Normalization，可选）：**
$$\text{NMI}(X;Y) = \frac{I(X;Y)}{\sqrt{H(X)H(Y)}}$$

其中 $H(X) = -\sum p(x) \log p(x)$ 是熵（entropy）。

> [! Step-by-Step Calculation]-
>
> **示例：基于 MI 的特征选择（MI-based feature selection）**
>
> **Step 1: 算每个特征与目标的 MI**
>
> 数据集：
> | ID | Feature_A | Feature_B | Feature_C | Target |
> |----|-----------|-----------|-----------|---------|
> | 1  | 1         | 3         | 5         | 0       |
> | 2  | 2         | 4         | 3         | 1       |
> | 3  | 3         | 2         | 4         | 0       |
> | 4  | 4         | 1         | 2         | 1       |
> | 5  | 5         | 5         | 1         | 1       |
>
> **Feature_A 对 Target：**
> - 把 Feature_A 离散化成箱：{1-2: "Low", 3-4: "Med", 5: "High"}
> - 建联合概率表（joint probability table）：
>
> | Feature_A | Target=0 | Target=1 | P(Feature_A) |
> |-----------|----------|----------|--------------|
> | Low       | 1/5      | 1/5      | 2/5          |
> | Med       | 1/5      | 1/5      | 2/5          |
> | High      | 0        | 1/5      | 1/5          |
> | P(Target) | 2/5      | 3/5      | 1            |
>
> **算 MI：**
> $$I(A;T) = \sum_{a,t} p(a,t) \log\left(\frac{p(a,t)}{p(a)p(t)}\right)$$
>
> $$= \frac{1}{5}\log\left(\frac{1/5}{(2/5)(2/5)}\right) + \frac{1}{5}\log\left(\frac{1/5}{(2/5)(3/5)}\right) + ... $$
>
> $$= \frac{1}{5}\log(1.25) + \frac{1}{5}\log(0.83) + ... \approx 0.13$$
>
> **Step 2: 算所有特征的 MI**
> - $I(A;Target) = 0.13$
> - $I(B;Target) = 0.08$
> - $I(C;Target) = 0.15$
>
> **Step 3: 选 MI 最高的特征**
> - **选中（Selected）：** Feature_C（MI = 0.15）
>
> **Step 4: 算剩余特征与已选特征之间的 MI**
> - $I(A;C) = 0.05$
> - $I(B;C) = 0.12$
>
> **Step 5: 贪心选择准则**
> 对每个剩余特征算：$\text{Score} = I(X;Target) - \alpha \times I(X;Selected)$
> - $\text{Score}_A = 0.13 - 0.5 \times 0.05 = 0.105$
> - $\text{Score}_B = 0.08 - 0.5 \times 0.12 = 0.02$
>
> **Step 6: 选下一个特征**
> - **选中（Selected）：** Feature_A（分数更高）
> - **最终选择（Final selection）：** {Feature_C, Feature_A}

##### **Pros & Cons**
| **优点（Pros）** | **缺点 / 要留意（Cons/Watch-outs）** |
|:---------|:-------------------|
| **能识别任何类型的依赖（含非线性）** | **计算量可能很大** |
| 与模型无关（model-agnostic） | **对小样本敏感** |
| 天然捕捉特征交互 | 连续变量需要先离散化 |
| 给出可解释的「信息量」 | MI 估计本身可能有噪声 |
| 混合数据类型都能用 | 需要调参（α、分箱数） |

#### **3. Recursive Feature Elimination (RFE)**

##### **Core Idea**
这就是「淘汰赛」式的做法：训练一个模型 → 找出最不重要的特征 → 删掉它 → 重复，直到剩下想要的个数。它的思路是**以模型为中心（model-centric）**，很擅长捕捉交互。

##### **Mathematical Foundation**

**RFE 算法（RFE Algorithm）：**
1. 用全部特征训练模型：$f(X_1, X_2, ..., X_p) \rightarrow Y$
2. 给特征的重要性排序：$w_1, w_2, ..., w_p$
3. 删掉重要性最低的特征：$w_{min}$
4. 重复，直到剩下 $k$ 个特征

**重要性怎么取（Feature Importance Examples）：**
- **线性模型：** $|w_j|$（系数绝对值）
- **树模型：** split importance、gain importance
- **通用：** permutation importance

> [! Step-by-Step Calculation]-
>
> **示例：用线性回归做 RFE（RFE with Linear Regression）**
>
> **Step 1: 训练初始模型**
>
> 数据集：
> | ID | X1  | X2  | X3  | X4  | Y   |
> |----|-----|-----|-----|-----|-----|
> | 1  | 2   | 4   | 1   | 3   | 10  |
> | 2  | 3   | 2   | 5   | 1   | 8   |
> | 3  | 1   | 6   | 2   | 4   | 12  |
> | 4  | 4   | 3   | 3   | 2   | 9   |
> | 5  | 5   | 1   | 4   | 5   | 11  |
>
> **初始模型：** $Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_3 X_3 + \beta_4 X_4$
>
> 用最小二乘：$\hat{\boldsymbol{\beta}} = (X^T X)^{-1} X^T Y$
>
> **结果：**
> - $\hat{\beta}_1 = 0.8$（重要性 = 0.8）
> - $\hat{\beta}_2 = 1.2$（重要性 = 1.2）
> - $\hat{\beta}_3 = 0.3$（重要性 = 0.3）← **最低**
> - $\hat{\beta}_4 = 0.9$（重要性 = 0.9）
>
> **Step 2: 删掉最不重要的特征**
> - **删（Remove）：** X3（重要性最低 = 0.3）
> - **剩余（Remaining）：** {X1, X2, X4}
>
> **Step 3: 重训模型**
>
> **新模型：** $Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_4 X_4$
>
> **结果：**
> - $\hat{\beta}_1 = 0.7$（重要性 = 0.7）← **最低**
> - $\hat{\beta}_2 = 1.3$（重要性 = 1.3）
> - $\hat{\beta}_4 = 1.0$（重要性 = 1.0）
>
> **Step 4: 删掉下一个最不重要的**
> - **删（Remove）：** X1（重要性最低 = 0.7）
> - **剩余（Remaining）：** {X2, X4}
>
> **Step 5: 重训模型**
>
> **新模型：** $Y = \beta_0 + \beta_2 X_2 + \beta_4 X_4$
>
> **结果：**
> - $\hat{\beta}_2 = 1.4$（重要性 = 1.4）
> - $\hat{\beta}_4 = 1.1$（重要性 = 1.1）← **最低**
>
> **Step 6: 最终选择**
>
> **如果目标是 2 个特征：** 就停在这里，得到 {X2, X4}
> **如果目标是 1 个特征：** 再删 X4，只留 X2
>
> **RFE 排名（重要性从高到低）：**
> 1. X2（活得最久）
> 2. X4（第二久）
> 3. X1（第 2 轮被淘汰）
> 4. X3（第 1 轮被淘汰）
>
> **交叉验证增强（Cross-validation enhancement）：**
> - 在不同的 CV 折上重复整个 RFE 过程
> - 选那些**跨折都稳定排名靠前**的特征
> - 用平均排名做最终选择

##### **Pros & Cons**
| **优点（Pros）** | **缺点 / 要留意（Cons/Watch-outs）** |
|:---------|:-------------------|
| **以模型为中心：最终模型的结构本身能参与决策** | **暴力枚举式做法，可能非常慢（O(p²)）** |
| **很擅长捕捉交互** | **有把「选择过程」本身过拟合的风险** |
| 任何能给特征重要性的模型都能用 | p 大时计算代价高 |
| 给出所有特征的清晰排名 | 小样本下可能不稳定 |
| 可以加交叉验证来增强 | 每一步都要重新训练模型 |

#### **4. Stepwise Selection**

##### **Core Idea**
一种「贪心」搜索策略：从空模型开始（前向 forward）或从全模型开始（后向 backward），每次根据交叉验证后的**性能提升**加入或删除一个特征。它能找到小而强的特征子集，但也可能卡在局部最优（local optima）。

##### **Mathematical Foundation**

**前向选择算法（Forward Selection Algorithm）：**
1. 从空集开始：$S = \emptyset$
2. 对每个 $x_j \notin S$，评估：$\text{Score}(S \cup \{x_j\})$
3. 加入让分数最大的特征：$S = S \cup \{x_{best}\}$
4. 重复，直到没有提升或达到目标个数

**后向消除算法（Backward Elimination Algorithm）：**
1. 从全集开始：$S = \{x_1, x_2, ..., x_p\}$
2. 对每个 $x_j \in S$，评估：$\text{Score}(S \setminus \{x_j\})$
3. 删掉让分数最大的特征：$S = S \setminus \{x_{worst}\}$
4. 重复，直到没有提升或达到目标个数

**打分函数（Scoring Functions）：**
- **AIC：** $\text{AIC} = -2\log(L) + 2k$
- **BIC：** $\text{BIC} = -2\log(L) + k\log(n)$
- **交叉验证：** $\text{CV-Score} = \frac{1}{K}\sum_{i=1}^K \text{Performance}(\text{fold}_i)$

> [! Step-by-Step Calculation]-
>
> **示例：带交叉验证的前向选择（Forward Selection with Cross-Validation）**
>
> **Step 1: 初始化**
> - 可用特征：{Age, Income, Education, Experience}
> - 已选特征：$S = \emptyset$
> - 目标：二分类（用 AUC 当分数）
>
> **Step 2: 逐个评估单个特征**
>
> 用 5 折 CV 训练模型：
> - 只有 Age 的模型：$\text{CV-AUC} = 0.72$
> - 只有 Income 的模型：$\text{CV-AUC} = 0.78$ ← **最好**
> - 只有 Education 的模型：$\text{CV-AUC} = 0.65$
> - 只有 Experience 的模型：$\text{CV-AUC} = 0.70$
>
> **Step 3: 加入最好的特征**
> - $S = \{Income\}$
> - **基线 CV-AUC = 0.78**
>
> **Step 4: 评估再加入第二个特征**
>
> 用 5 折 CV 训练模型：
> - {Income, Age}：$\text{CV-AUC} = 0.82$ ← **最好**
> - {Income, Education}：$\text{CV-AUC} = 0.79$
> - {Income, Experience}：$\text{CV-AUC} = 0.80$
>
> **Step 5: 加入第二个特征**
> - $S = \{Income, Age\}$
> - **新 CV-AUC = 0.82**（提升 = 0.04）
>
> **Step 6: 评估再加入第三个特征**
>
> 用 5 折 CV 训练模型：
> - {Income, Age, Education}：$\text{CV-AUC} = 0.83$
> - {Income, Age, Experience}：$\text{CV-AUC} = 0.84$ ← **最好**
>
> **Step 7: 加入第三个特征**
> - $S = \{Income, Age, Experience\}$
> - **新 CV-AUC = 0.84**（提升 = 0.02）
>
> **Step 8: 评估再加入第四个特征**
>
> 用 5 折 CV 训练模型：
> - {Income, Age, Experience, Education}：$\text{CV-AUC} = 0.83$
>
> **Step 9: 停止（没有提升）**
> - 加入 Education 会让性能下降
> - **最终选择（Final selection）：** {Income, Age, Experience}
> - **最终 CV-AUC：** 0.84
>

> [! Backward Elimination Example]-
>
> **Step 1: 从全部特征开始**
> - $S = \{Age, Income, Education, Experience\}$
> - **基线 CV-AUC = 0.83**
>
> **Step 2: 评估逐个删除**
>
> 用 5 折 CV 训练模型：
> - 删掉 Age：$\text{CV-AUC} = 0.79$
> - 删掉 Income：$\text{CV-AUC} = 0.71$
> - 删掉 Education：$\text{CV-AUC} = 0.84$ ← **最好**（有提升！）
> - 删掉 Experience：$\text{CV-AUC} = 0.80$
>
> **Step 3: 删掉 Education**
> - $S = \{Age, Income, Experience\}$
> - **新 CV-AUC = 0.84**（提升 = 0.01）
>
> **Step 4: 评估再删掉每个剩余特征**
>
> 用 5 折 CV 训练模型：
> - 删掉 Age：$\text{CV-AUC} = 0.78$
> - 删掉 Income：$\text{CV-AUC} = 0.70$
> - 删掉 Experience：$\text{CV-AUC} = 0.82$
>
> **Step 5: 停止（没有提升）**
> - 再删任何一个都不会提升性能
> - **最终选择（Final selection）：** {Age, Income, Experience}
> - **最终 CV-AUC：** 0.84
>
> **注意：** 前向与后向最后走到了同一个解！

##### **Pros & Cons**
| **优点（Pros）** | **缺点 / 要留意（Cons/Watch-outs）** |
|:---------|:-------------------|
| **有时能找到小而强的特征子集** | **可能卡在局部最优，错过更好的组合** |
| 天然把交叉验证纳进来 | **特征多时很慢** |
| 有清晰的选择路径 | 贪心做法可能错过全局最优 |
| 任何性能指标都能用 | 需要反复重训模型 |
| 可以用统计准则（AIC、BIC） | 迭代次数多时可能对验证集过拟合 |

#### **Advanced Variations & Enhancements**

##### **Bidirectional Stepwise Selection**
把前向与后向结合起来：
1. 前向一步：加入最好的特征
2. 后向一步：删掉最差的特征（如果这样能提升分数）
3. 重复，直到收敛

##### **Regularization Path Methods**
**LASSO 路径（LASSO Path）：**
- 让正则化参数 λ 从 0 变到 ∞
- 特征会在特定的 λ 值上进 / 出模型
- 能高效地给出整条正则化路径

**Elastic Net 路径（Elastic Net Path）：**
- 把 L1（LASSO）与 L2（Ridge）惩罚结合起来
- 同时控制稀疏性（sparsity）与分组效应（grouping effects）
- 对相关特征组的处理更好

##### **Stability Selection**
给任何方法加一层增强：
1. 对数据做 B 次 bootstrap 抽样
2. 在每个 bootstrap 样本上跑一遍特征选择
3. 选那些在 > 50% 的 bootstrap 轮次里都出现的特征
4. 控制错误发现率（false discovery rate）

---

#### **Computational Complexity Comparison**

| **方法（Method）** | **时间复杂度（Time Complexity）** | **空间复杂度（Space Complexity）** | **可扩展性（Scalability）** |
|:-----------|:-------------------|:-------------------|:---------------|
| **Correlation/VIF** | O(p²n) | O(p²) | 到 p ≈ 1000 都还行 |
| **Mutual Information** | O(p²n log n) | O(pn) | 中等，取决于分箱方式 |
| **RFE** | O(kp²) × model_cost | O(p) | p 大时很差 |
| **Stepwise** | O(p²) × model_cost | O(p) | p 大时很差 |

**其中（Where）：**
- p = 特征数
- n = 样本数
- k = 要选出来的特征数
- model_cost = 训练一个模型的计算开销

#### **Practical Implementation Tips**

##### **1. Pipeline Integration**
```python
# Example sklearn pipeline
from sklearn.pipeline import Pipeline
from sklearn.feature_selection import RFE
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline([
    ('correlation_filter', CorrelationFilter(threshold=0.8)),
    ('rfe', RFE(LogisticRegression(), n_features_to_select=10)),
    ('classifier', LogisticRegression())
])
```

##### **2. Cross-Validation Best Practices**
- 特征选择**必须**在 CV 折内完成
- 用嵌套 CV（nested CV）：外层评估模型，内层做特征选择
- 不要把测试集用于选择，否则数据泄漏（data leakage）

##### **3. Stopping Criteria**
- **性能阈值：** 提升 < ε 就停
- **统计显著性：** 看 p 值或置信区间
- **算力预算：** 设定最大时间 / 迭代次数
- **收益递减：** 边际收益下降就停

**记住（Remember）：** 目标不是找到绝对最优的子集，而是找到一个**能在未见数据上泛化好**的子集。

## 四、算一遍

两段。第一段核验开头那张小表印出来的数字，第二段换一组能真算的数据把整条流程走完。

### 第 1 步：核验第 1 节那张 5 行表

第 1 节那张表（Age / Experience / Income / Education，5 行）印了一组相关系数，并写了「假设 $R^2 = 0.85$ / $0.90$」。把原始数字真算一遍：

| 量 | 印出来的值 | 真算值 |
|---|---|---|
| $\sum(x_{\text{age}}-\bar x)^2$ | 250 | **250**（对得上） |
| $\sum(x_{\text{exp}}-\bar x)^2$ | 324.8 | **187.2** |
| $\sum(x-\bar x)(y-\bar y)$（Age, Experience） | 370 | **215** |
| $r_{\text{age, exp}}$ | 0.898 | $215 / \sqrt{250 \times 187.2} = 215/216.33 = \mathbf{0.994}$ |

其余几对真算值也与印出来的对不上：$r_{\text{age,inc}} = 1.000$、$r_{\text{exp,inc}} = 0.994$、$r_{\text{age,edu}} = 0.693$、$r_{\text{exp,edu}} = 0.699$、$r_{\text{inc,edu}} = 0.693$。**那张表的相关系数是示意值，不是从它自己的原始数字里算出来的。**

更要紧的是辅助回归。用同样的 5 行数据跑 `Experience ~ Age + Income + Education`：

$$
R^2 = 0.9879 \quad\Longrightarrow\quad \mathrm{VIF} = \frac{1}{1-0.9879} = 82.6
$$

而 `Age` 与 `Income` 的辅助回归 $R^2 = 1.000000$，VIF $=\infty$ —— 在那张表里它们本来就是线性关系。

**为什么必然如此**：5 行数据配 4 个变量的辅助回归，参数个数（截距 + 3 个斜率）已经接近样本量，$R^2$ 想不高都难。所以「假设 $R^2 = 0.85$ / $0.90$」只能当**占位符**用：它演示的是换算关系，不是数据事实。**小表上「真算 VIF」本来就没有意义，这本身就是这一节的结论。**

### 第 2 步：换一组能真算的数据

10 行、4 个变量（Income 单位是千）：

| Age | Experience | Income | Education |
|---|---|---|---|
| 25 | 3 | 42 | 16 |
| 28 | 8 | 55 | 14 |
| 31 | 6 | 44 | 17 |
| 34 | 13 | 78 | 15 |
| 37 | 11 | 62 | 18 |
| 40 | 17 | 95 | 16 |
| 43 | 20 | 88 | 19 |
| 46 | 16 | 70 | 15 |
| 49 | 23 | 118 | 17 |
| 52 | 25 | 132 | 20 |

**先看相关矩阵（真算）**：$r_{\text{age,exp}} = 0.953$、$r_{\text{age,inc}} = 0.878$、$r_{\text{exp,inc}} = 0.957$、$r_{\text{age,edu}} = 0.554$、$r_{\text{exp,edu}} = 0.536$、$r_{\text{inc,edu}} = 0.528$。

按「$|r| > 0.8$ 就处理」的经验线，前三个相关对都超标；但 $r_{\text{exp,edu}} = 0.536$ 这种「看着没事」的变量，下一步 VIF 会告诉你别急着放行。

**再做辅助回归，换成 VIF**：

| 变量 | 辅助回归 | $R_j^2$ | VIF | SE 放大倍数 $\sqrt{\mathrm{VIF}}$ |
|---|---|---|---|---|
| Age | Age ~ Exp + Income + Edu | 0.9263 | 13.56 | 3.68 |
| **Experience** | Exp ~ Age + Income + Edu | 0.9720 | **35.72** | **5.98** |
| Income | Income ~ Age + Exp + Edu | 0.9303 | 14.36 | 3.79 |
| Education | Edu ~ Age + Exp + Income | 0.3220 | 1.47 | 1.21 |

**最后按 VIF 顺序删一个，然后重算全部**（这一步不能省：VIF 是变量集合的属性）：

| 删掉谁 | 剩下各变量的 VIF |
|---|---|
| **Experience**（VIF 最大，35.72） | Age **4.57**、Income **4.40**、Education **1.46** → 全部低于 5 |
| Education（VIF 最小，1.47） | Age 12.95、Experience 35.33、Income 14.05 → **几乎没动** |

结论：删掉 `Experience` 一个动作就把整套拉回合格线；删错对象则一点用没有，还白丢一个变量。


### 条件检验 A：为什么必须删 VIF 最大的那个

上面第二行就是答案。`Education` 是 VIF 最低的变量，它不参与那条坏方向（年龄、经验、收入三者的线性组合）；删掉它，坏方向还在，`Age`（13.56 → 12.95）与 `Experience`（35.72 → 35.33）几乎不动。**「删一个变量试试看」只有配上「每次重算、盯最大 VIF」才是有效流程。**

### 条件检验 B：换一个筛选准则，结论会不会变

上面的流程全建立在线性（$R^2$）上。换成互信息，用教材那张联合概率表（$P(\text{Target}=0)=2/5$、$P(\text{Target}=1)=3/5$）重算：

$$
I(A;T) = \sum_{a,t} p(a,t)\log\frac{p(a,t)}{p(a)p(t)}
= 0.0446 - 0.0365 + 0.0446 - 0.0365 + 0.1022 = \mathbf{0.1185}\ \text{nats}
$$

（原文写的 $\approx 0.13$ 是手算取整；按 nats 精确值是 0.1185，折成 bits 是 0.1710。）贪心准则 $I(X;T) - \alpha I(X;\text{Selected})$ 与 $\alpha = 0.5$ 不变：

* $\text{Score}_A = 0.1185 - 0.5 \times 0.05 = \mathbf{0.0935}$
* $\text{Score}_B = 0.08 - 0.5 \times 0.12 = \mathbf{0.02}$

结论与原文一致（选 A），但**换准则的意义不在这一个点上**：VIF 用的是线性 $R^2$，互信息看的是任意依赖，两者筛出来的集合本来就不该相同。这就是第 3.1 节那条最佳实践的由来 —— 先用相关 / VIF 处理线性冗余，再用 MI 或 RFE 抓非线性和交互。

## 五、什么情况下会失灵

### 承重假设一：筛选准则与最终目标同向

用单变量 IV 或 AUC 排序、却用负对数似然（或校准）评估，撤掉这条假设的后果很直接：**选出来的变量对排序有用，对概率水平没用**。具体表现是 AUC 不降、但预测概率的偏差变大 —— 费率表上就是「排序没问题、乘数不对」。

处理：排序用的准则要和上线指标对齐；概率模型用似然类准则（AIC / BIC / CV 的 log-loss）。

### 承重假设二：选择发生在折内，且每折重做

在任何 CV 之外的预处理都算泄漏。撤掉这条的后果是**乐观偏差**，而且幅度随候选变量数增长：3.2 节已经说明，报出来的分数里包含「哪一组最好」这条测试集上不存在的信息。RFE 与 stepwise 额外把超参数也一起挑了，偏置更大。

### 承重假设三：相关结构在训练与线上一致

共线性下选出的「代表」可能换人 —— 训练时留 `Age`，换一份样本后可能留 `Experience`。撤掉这条假设的后果不是精度掉得很多，而是**解释变了**：去年的费率表说「年龄是主驱动」，今年变成「经验」。处理：stability selection（bootstrap 出现频率），或者干脆合并成一组。

### 一个反例：两两相关不高，也能进完全共线

在上面的 10 行数据里再加一列 `YearsSinceGrad = Age − Education − 6`：

* 两两相关看起来温和：$r(\text{Age},\ \text{YSG}) = 0.981$，但 $r(\text{Education},\ \text{YSG}) = 0.384$。
* 真算辅助回归：`Age`、`Education`、`YSG` 三个的 $R^2$ 全是 1.000000，VIF 全是 $\infty$。

**光看相关矩阵，这一列「只和年龄相关」，看着像重复变量而不是麻烦。** 这就是为什么相关矩阵必须配 VIF，而 VIF 又要配条件指数（condition index + 方差分解比例）—— 后者才指出「是哪几个变量共享了那条坏方向」。

### 小样本 + 大 p：打分会自己虚高

辅助回归里有 $p-1$ 个自变量时，纯噪声数据上 $R^2$ 的期望也有约 $p/(n-1)$：$n=10$、3 个辅助变量时期望 $R^2 = 0.333$ → 期望 VIF 1.50；$n=20$ 时 0.158 → 1.19。**宽表 + 小样本下，「筛出来的变量看起来很强」有一部分是流水线的产物。**

### 与其他手段的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 要一组可解释的变量、要报送 | stepwise / 按 VIF 顺序删 | 每个变量都能逐条辩护 |
| 变量成组相关、又要稀疏 | lasso / elastic net | 分组进出，比单变量筛选稳 |
| 只要预测精度、不在乎用哪些变量 | GBM + 原生重要性 + 早停 | 交互自动进模型，不需要显式筛 |
| 输入必须正交 | PCA / PLS | 成分按构造不相关 |
| 变量多到 p > 1000 | 先 filter（IV / MI）粗筛，再 wrapper | wrapper 的 $O(p^2)$ 撑不住 |
| 需要因果解释 | 都不是 | 筛选只优化预测，不识别因果 |

## 六、常见误解

### 误解一：「单变量筛完就够了，多变量筛选只是精细化」

**错误想法**：先用 IV 或单变量 AUC 把 200 列筛到 40 列，剩下的交给模型就行。

**为什么容易这么想**：单变量筛选快、可解释、还能画图汇报；而且「先粗筛再细筛」听起来就是标准流程。

**错在哪一步**：单变量的强不等于多变量的增量。两条各自 IV 很高的变量可能说的是同一件事，一起进去只会把标准误撑大（第 4 节第 2 步那张表：`Age`、`Experience`、`Income` 单独看都不弱，VIF 却都在 13 以上）。单变量筛选解决的是「变量太少」，多变量筛选解决的是「变量之间互相顶替」，两件事不能互相替代。

### 误解二：「VIF 高就删，VIF 低就留」

**错误想法**：把 VIF 当门槛一条条筛过去，超标的删掉。

**为什么容易这么想**：VIF 有阈值表（5 / 10），删完数字确实会降，反馈是正面的。

**错在哪一步**：VIF 是**集合**的属性，不是变量的属性。第 4 节算过：删掉 VIF 最大的 `Experience`，其余三个立刻掉到 5 以下；而删掉 VIF 最低的 `Education`，其余三个几乎不动。**逐变量地判断该不该留，是对着影子做决定。** 另外它只抓线性冗余（`YSG` 那种完全共线是被抓到了，但非单调依赖它看不见）。

### 误解三：「树模型的 importance 就是现成的变量筛选」

**错误想法**：跑一遍 GBM，按 importance 排序取前 20 个，省掉 RFE 和 stepwise。

**为什么容易这么想**：一行代码就有重要性排名，而且它是「模型自己的判断」，看起来比 filter 更贴目标。

**错在哪一步**：两个问题。第一，importance 在相关变量组内的分配是任意的（同一组信息给 `Age` 还是给 `Experience` 取决于样本）；第二，它是在**训练数据**上算的，直接拿来选变量等于把选择和评估混在一起 —— 这就是 3.2 节说的乐观偏差。要用就配 permutation importance（在验证集上算）+ stability selection。

### 误解四：「stepwise 选出的 AIC 最小模型就是最好的模型」

**错误想法**：让算法贪心搜到 AIC 不再下降，收工。

**为什么容易这么想**：AIC 有明确的公式和惩罚项，看起来像一个客观答案；软件也会老老实实给出最终模型。

**错在哪一步**：贪心只到局部最优（教材原文里那句 "locally optimal solution rather than a globally optimal one" 就是这个意思）—— 用 $2^p$ 全枚举可能找到 AIC 更低的组合。更要紧的是**选完之后的推断不再是寻常的推断**：p 值和置信区间没有把「选择」这一步的不确定性算进去，所以会偏窄、偏显著。要么报选择后的校正结果，要么用嵌套 CV 评估整条流水线。

## 七、面试怎么答

### 30 秒版

> 我会分三层讲。先看冗余：相关矩阵配 VIF，注意到相关矩阵只看两两、VIF 只看线性，非单调依赖要再补 Spearman 配 Hoeffding's D。再看依赖形状：互信息抓任意依赖，代价是分箱和样本量。最后看交互：RFE 或 stepwise 让模型自己选，但必须在折内做、只用嵌套 CV 报分数。

### 2 分钟版（三块）

1. **顺序**：先 filter（快、稳、无模型）粗筛 → 再 wrapper / embedded 细筛 → 最后用稳定性选择确认。
2. **机制**：filter 的偏置来自「在多少条里挑」，wrapper 还把超参数一起挑，所以偏置更大。这条决定了两者放在流程的哪一步。
3. **工程**：所有预处理与选择都在 CV 折内完成；上线要有一条固定的打分规则；选择后的 p 值要说明它没算选择的不确定性。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「200 列怎么开始？」 | 先删缺失率过高、单值列、泄漏列；再 filter 粗筛；再 wrapper / embedded；每层都报「这一步前后」的指标 |
| 「为什么用 Hoeffding's D？」 | 相关系数和 Spearman 都看不见非单调（U 形）依赖；「低 Spearman + 高 D」那一格的变量常常是最好的变量，该做变换而不是删 |
| 「互信息的坑？」 | 连续变量要先离散化（分箱数敏感）、小样本有偏（要校正）、高维下慢 |
| 「RFE 和 lasso 怎么选？」 | 要稀疏且快 → lasso（有路径、CV 直接选 λ）；要捕捉交互 → RFE，代价是 $O(p^2)$ 次模型拟合 |
| 「选出来的变量换一份样本就变了怎么办？」 | 先看是不是共线组内的任意选择；处理：合并、elastic net、stability selection |
| 「选择之后的 p 值能用吗？」 | 不能直接当寻常推断用（post-selection inference）；报嵌套 CV 的整条流水线表现，或做校正 |
| 「树模型的 importance 能选变量吗？」 | 可以当线索，但要在验证集上用 permutation importance，且不能替掉折内选择这一步 |

| 中文 | English | 一句话 |
|---|---|---|
| 过滤法 | filter method | 只看统计量不看模型：相关、VIF、MI |
| 包裹法 | wrapper method | 用模型打分选变量：RFE、stepwise |
| 嵌入法 | embedded method | 选择写进目标函数：lasso、树重要性 |
| 单变量筛选 | univariate screening | IV、单变量 AUC、相关系数，各看各的 |
| 方差膨胀因子 | variance inflation factor (VIF) | $1/(1-R_j^2)$，系数方差被放大的倍数 |
| 互信息 | mutual information (MI) | 任意依赖的信息量，单位 nats / bits |
| 熵 | entropy $H(X)$ | 不确定度；NMI 用 $H$ 做归一化 |
| Hoeffding's D | Hoeffding's D | 抓任意依赖（含非单调），范围约 −0.5 到 1 |

| 双向逐步 | bidirectional stepwise | 加一步、删一步，直到收敛 |
