## 速览 At a glance

**速记**

长满的树训练误差趋近 0，但换一份数据就换一套分裂，所以要往回砍。砍法分两代：预剪枝在长之前设门槛（`max_depth`、`min_samples_leaf`），便宜但一刀切、还有视野局限；后剪枝先长满再砍，按每一枝自己的收益决定去留。CART 的后剪枝叫代价复杂度剪枝：给树定价 $R_\alpha(T)=R(T)+\alpha\lvert T\rvert$，$\alpha$ 是每个叶子的价钱；对每个内部节点算临界值 $\alpha_t=\frac{R(t)-R(T_t)}{\lvert T_t\rvert-1}$，每次剪掉最小的那一枝，得到一串嵌套子树，一个 $\alpha$ 唯一对应一棵树。$\alpha$ 本身由 K 折 CV 选，通常再用 1-SE 规则：在 CV 误差最小值 1 个标准误以内，取叶子最少的那棵——因为 CV 曲线在最小值附近是平的，更小的树方差更低、更稳。

**一句面试答法**

> "Pre-pruning stops the tree early with depth or leaf-size limits; post-pruning grows the full tree and cuts back, which is usually more accurate because it can see the whole structure. CART's version is cost-complexity pruning: minimise R of T plus alpha times the number of leaves, use the weakest-link algorithm to generate a nested sequence of subtrees, and pick alpha by cross-validation, usually with the one-standard-error rule."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 预剪枝 | pre-pruning / early stopping | 生长过程中就停，便宜但容易欠拟合 |
| 后剪枝 | post-pruning | 先长满再自底向上砍 |
| 代价复杂度剪枝 | cost-complexity pruning (CCP) | 最小化 $R(T)+\alpha\lvert T\rvert$ |
| 复杂度代价 | complexity cost $R_\alpha(T)$ | 训练误差 + 叶子数的价钱 |
| 最弱环节算法 | weakest link | 每步剪掉「每省一个叶子误差涨得最少」的枝 |
| 临界值 | critical value $\alpha_t$ | 剪与不剪 $R_\alpha$ 相等的那个 $\alpha$ |
| 嵌套子树序列 | nested subtree sequence | $T_0\supset T_1\supset\cdots\supset T_M=\{\text{root}\}$ |
| 1-SE 原则 | one-standard-error rule | 在最优 CV 误差 1 个标准误内取最小的树 |
| 视野局限 | horizon effect | 提前停止看不到「先分下去、再剪回来」更好的结构 |

## 🎯 一句话

**剪枝 = 先让树长到过大，再按「复杂度代价」自底向上砍掉收益不足的枝，用更少的节点换更好的泛化。**

> 逻辑：单棵决策树是**低偏差、高方差**的学习器。长满的树可以把每个叶子切到几乎纯净（训练误差 → 0），代价是给噪声也建了分支。剪枝就是往回退一步：牺牲一点训练集拟合，换验证集/测试集误差下降。
> 出处：PSL §4.1.5（Cost-Complexity Pruning）、PSL §12.3（剪枝阶段可换准则）。

## 一、先看一个问题

4 万条保单，你建了一棵 CART，让它自然长满：**62 个叶子**。训练集上的不纯度是 **0.001**——每个叶子几乎是纯的，看起来完美。同一份数据的 5 折 CV 误差是 **0.340**。

问题很直白：这棵树把训练集背下来了。你决定砍。接着是两个具体问题，两个问题的性质完全不同：

1. **先砍哪一枝？** 62 个叶子里，哪一枝是「最不值得留」的？
2. **砍到几个叶子停？** 8 个？12 个？还是 30 个？

第一个问题有确定的答案：CART 用 weakest-link（最弱环节）算出一个唯一的顺序，谁最便宜谁先被砍。第二个问题没有闭式答案——它只能靠在留出数据上看误差，所以要用交叉验证；而且 CV 曲线的最小值附近往往是平的，误差差 0.005 的两棵树，谁更好在统计上分不出来。

这两个问题的答案就是本节的全部：**先按 $\alpha_t$ 排出一个剪枝顺序，再用 CV 挑一个 $\alpha$**。手算部分（第四节）用 8 个观测的小树把 $\alpha$ 序列从头算一遍，你会看到三个数字：81、100、840.5——它们就是这棵树的三次「砍价」。

## 📖 标准定义

> **教材原文 · PSL §4.1.3 Complexity Cost、§4.1.4 Weakest Link Algorithm、§4.1.5 Cross-Validation；1-SE 定义引 ESL §7.10（p. 244）**（<https://liangfgithub.github.io/PSL/w4/w4_1_reg_tree.html>）
> > "The complexity cost for a tree T is defined as: $R_{\alpha}(T) = \text{RSS}(T) + \alpha |T|$"
> >
> > "… is the number of leaf nodes in the tree. This quantifies the size or complexity of the tree."
> >
> > "The Weakest Link Algorithm can be used to find the optimal subtree for all possible values of $\alpha$ . The algorithm proceeds as follows:"
> >
> > "The algorithm generates a sequence of increasingly smaller trees corresponding to increasing $\alpha$ values, starting from the largest tree down to a single-node tree (the root)."
> >
> > "Finally, we select the optimal $\alpha$ value based on either the minimum CV error or using the one standard error principle."
>
> **教材原文 · ESL §7.10（p. 244）· 1-SE 原则**（<https://hastie.su.domains/ElemStatLearn/>）
> > "Often a “one-standard error” rule is used with cross-validation, in which we choose the most parsimonious model whose error is no more than one standard error above the error of the best model."
> >
> > "Such a rule acknowledges the fact that the tradeoff curve is estimated with error, and hence takes a conservative approach."（ESL §3.4.3, p.61）

**标准记法**：复杂度代价 $R_{\alpha}(T) = \text{RSS}(T) + \alpha \vert T\vert$；$\vert T\vert$ 是叶节点数，$\alpha \ge 0$ 控制拟合与复杂度的权衡。对每个内部节点 $t$，weakest link 计算 $\alpha^* = \frac{\text{RSS}(t) - \text{RSS}(T_t)}{\vert T_t \vert - 1}$（剪掉该枝「最便宜」的代价），取最小的 $\alpha_1$ 依次剪枝，得到随 $\alpha$ 递增的子树序列。

**中文解释**：CCP 用 $\text{RSS}(T)+\alpha|T|$ 给树定价：$\alpha$ 大则树小。Weakest Link 每步剪掉「每单位复杂度换来的 RSS 改善最少」的那一枝，从而生成一整条子树路径（含单节点树）。$\alpha$ 由 K 折 CV 选，可以用最小值，也可以用 1-SE 原则选更稳的小树。

> 完整条目与更多来源见 [[定义原文库#C12. 代价复杂度剪枝（CCP）/ weakest link / 1-SE 原则|C12. 代价复杂度剪枝（CCP）/ weakest link / 1-SE 原则]]

## 二、核心直觉

### 剪枝换的是什么

树在长满的时候，偏差最低、方差最高。剪枝是用**一点点偏差换掉一大块方差**：砍掉一枝，训练集上多错几个，但叶子的取值不再依赖那几条恰好落进来的样本。

这也是它成立的前提：**第二阶段必须从一棵真的长满了的树出发**。如果第一阶段已经预剪枝，$\alpha$ 路径会跟着变，你看的不再是「哪枝值得留」，而是「哪些枝当初就没长出来」。

**这里像什么、不像什么**：像一个团队年终缩编——先按每个人「单位成本的产出」排一个裁撤顺序，再决定总共裁到几人。**像的地方**是顺序确实由边际收益定，一次只砍一个，砍完重算。**不像的地方**是团队裁掉还能招回来，树剪掉的枝**永远不会长回去**；所以这个顺序必须是自底向上的（先叶子、后高层），否则一次误剪会连带抹掉一整片本有价值的结构——代价复杂度剪枝的「嵌套」性质就是为这件事上保险的。

### 预剪枝与后剪枝的区别不在早晚，在视野

预剪枝在生长时设门槛：节点样本数少于 k 就不分了、深度到 4 就停。后剪枝先让树长满，再自底向上把子树换成叶子。

两者的差别在**看到了多少信息才做决定**。预剪枝做决定时，只知道「这一枝眼下增益不显著」；后剪枝做决定时，已经把那一枝下面的全部结构看完了，所以能分辨「局部像有用、全局多余」的分枝。这就是 CART 只做后剪枝的原因。

## 三、机制

### 3.1 代价复杂度剪枝（CCP）的定义

对任意子树 $T \subseteq T_{max}$：

$$
R_\alpha(T) = R(T) + \alpha\,|T|
$$

* $R(T)$：子树 $T$ 的**训练误差**。实现里两种口径：
  * **误分类率**——每个叶子用它多数类预测；
  * **节点不纯度之和**——Gini / 熵（分类）或 SSE（回归）。scikit-learn、`rpart` 默认用这一类，因为它比误分类率更敏感。
* $|T|$：$T$ 的**叶节点个数**，即复杂度的度量。
* $\alpha \ge 0$：复杂度参数，含义是「**每多一个叶节点要付的代价**」。

α 的作用：

* $\alpha = 0$：只看拟合 ⇒ 一定选最大树 $T_{max}$；
* $\alpha \to \infty$：惩罚压倒一切 ⇒ 退化成只剩根节点的单节点树；
* α 居中：在「拟合」与「树的大小」之间权衡——和 Ridge/Lasso 里的 λ 是同一个角色的**正则化参数**。

### 3.2 weakest-link（最弱环节）算法：得到嵌套子树序列

对内部节点 $t$，记 $T_t$ 为以 $t$ 为根的子树、$R(t)$ 为把 $t$ 整枝塌成一个叶节点后的误差，则**剪掉 $t$ 的临界 α**（令"剪"与"不剪"的 $R_\alpha$ 相等）：

$$
\alpha_t = \frac{R(t) - R(T_t)}{|T_t| - 1}
$$

分子是"剪掉这枝带来的误差增量"，分母是"剪掉后少掉的叶节点数"（子树的 $|T_t|$ 个叶子被 1 个叶子替代）。所以 $\alpha_t$ = **每减少一个叶节点、误差增加多少**。

**关键一步在这里**：$\alpha_t$ 是「剪与不剪一样亏」的那个价格。$\alpha$ 低于它，留着这枝更划算；$\alpha$ 高于它，剪掉更划算。于是**所有内部节点各有一个自己的临界价**，其中最低的那个就是「当下最不值得留」的枝——这一步把一个连续的超参数选择，变成了一张可以排序的价目表。

算法：

1. 从 $T_{max}$ 出发；
2. 算所有内部节点的 $\alpha_t$，挑**最小**的那个（"最弱环节"：每省一个叶子，误差涨得最少）；
3. 剪掉它得到 $T_1$，重复，得到**嵌套**子树序列

$$
T_{max} = T_0 \supset T_1 \supset \cdots \supset T_M = \{\text{root}\},
\qquad 0 = \alpha_0 < \alpha_1 < \cdots < \alpha_M
$$

4. 最优子树在 α 上是**分段常数**的：区间 $[\alpha_k,\ \alpha_{k+1})$ 内最优解都是 $T_k$。所以只要在这 $M+1$ 棵树里挑一棵即可。

注意第 2 步的重复：**每剪一次都要重算**，因为剪掉一枝会改变它上层节点的 $R(t)$ 与 $|T_t|$。第四节的算例里，根的临界值就随着两次剪枝从 340.5 变到 470.25、再到 840.5。

> **为什么叫 weakest link**：每一步剪的都是"性价比最差"的分支——它每省一个叶子带来的误差增加最小（PSL §4.1.5 的 weakest-link 剪枝）。

### 3.3 怎么选 α

$R_\alpha$ 只看训练误差，α 越大训练误差越差，必然选 $\alpha = 0$ 的最大树 ⇒ 必须用**留出数据**。标准做法是 **K 折 CV**：

1. 在训练集内做 K 折；
2. 对 α 路径上的每个 α（或每棵 $T_k$）算
   $$CV(\alpha) = \frac{1}{K}\sum_{k=1}^{K}\text{Err}^{(k)}(\alpha)$$
   并记录它的**标准误** $SE(\alpha)$；
3. $\alpha^\* = \arg\min_{\alpha} CV(\alpha)$（CV 误差最小）；
4. **1-SE 原则（one-standard-error rule）**：在 $CV(\alpha) \le CV(\alpha^\*) + SE(\alpha^\*)$ 的候选里，取**α 最大**（= 树最小）的那棵。

**为什么用 1-SE**：CV 曲线在最小值附近通常是平的，好几个 α 的 CV 误差在统计上不可区分；此时**偏好更简单的模型**能降方差、提高稳定性。PSL §4.1.5 把它作为代价复杂度剪枝的标准做法：*choose the smallest tree whose cross-validated error is within one standard error of the minimum*。

> 面试常追问的点：**不是 CV 误差绝对值最小的树最好，而是在 1 个标准误之内越简单越好。**

### 3.4 预剪枝 vs 后剪枝

| 维度 | 预剪枝 Pre-pruning (early stopping) | 后剪枝 Post-pruning |
| --- | --- | --- |
| **何时停止** | 生长过程中就停：节点一旦满足停止条件就不再分裂 | 先长成 $T_{max}$（长到近纯叶），之后自底向上把子树换成叶 |
| **判据** | 提前设的阈值：`max_depth`、`min_samples_split`、`min_samples_leaf`、`min_impurity_decrease`；节点样本数 < k；χ² 检验不显著 | 剪枝后某个准则（验证集误差 / 惩罚后的误差 / 代价复杂度 $R_\alpha$）是否不变差 |
| **优点** | 快、省算力；直接控制模型大小；实现简单 | 更可靠：先看到完整结构再决定留不留；不易欠拟合；能剪掉"局部像有用、全局多余"的枝 |
| **缺点** | 容易**欠拟合**；阈值难先验确定；有「**视野局限**」（horizon effect）——贪心地提前停，可能错过"先分下去、再剪回来"会更好的结构 | 计算量大（先长满 + 在每个候选子树上算准则）；树大时开销高；需要一个数据划分或 CV 来估计剪枝准则 |
| **偏差-方差影响** | 早停 ⇒ 偏**高偏差、低方差**；模型小、稳定，但可能漏掉真实结构 | 从高方差出发往下砍 ⇒ **方差明显下降、偏差略升**；通常停在比预剪枝更"刚好"的位置 |
| **一句话记忆** | 「不让它长」 | 「让它长完再修」 |

> 注：ID3 完全没有剪枝；C4.5 用 pessimistic error pruning（后剪枝，基于训练集的连续性修正）；CART 用 cost-complexity pruning（后剪枝 + CV 选 α）。见 [[7.2.2.3.1 ID3 Algorithm]]、[[7.2.3.3 C4.5 Algorithm]]、[[7.5 CART Algorithm]]。

### 3.5 实操

#### scikit-learn

* 关键参数 **`ccp_alpha`** ↔ 上面的 α；默认 `0.0`（不剪枝）。
* **`DecisionTreeClassifier.cost_complexity_pruning_path(X, y)`** 一次性返回 α 路径：`ccp_alphas`（递增，从 0 到"只剩根节点"）与 `impurities`（对应每棵树叶节点的不纯度之和）。
* 预剪枝参数：`max_depth`、`min_samples_split`、`min_samples_leaf`、`min_impurity_decrease`。标准流程是**先长一棵过大的树，再用 CV 选 `ccp_alpha`**。

```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, cross_val_score, KFold
from sklearn.tree import DecisionTreeClassifier

X, y = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)

# 1) 先长一棵"过大"的树（不加任何预剪枝限制）
base = DecisionTreeClassifier(random_state=0).fit(X_tr, y_tr)
print("unpruned depth =", base.get_depth(), " leaves =", base.get_n_leaves())

# 2) alpha 路径：ccp_alphas 递增（0 -> 只剩根节点），impurities 为叶节点不纯度之和
path = base.cost_complexity_pruning_path(X_tr, y_tr)
alphas, impurities = path.ccp_alphas, path.impurities

# 3) 对每个 alpha 做 K 折 CV，记录平均误差与其标准误
cv = KFold(n_splits=5, shuffle=True, random_state=0)
mean_err, se_err = [], []
for a in alphas:
    scores = cross_val_score(DecisionTreeClassifier(random_state=0, ccp_alpha=a),
                             X_tr, y_tr, cv=cv, scoring="accuracy")
    mean_err.append(1.0 - scores.mean())
    se_err.append(scores.std() / np.sqrt(len(scores)))   # 均值的标准误
mean_err, se_err = np.array(mean_err), np.array(se_err)

# 4) 1-SE 规则：在 min CV error + 1 SE 之内，选最小的树（最大的 alpha）
i_best = int(mean_err.argmin())
thr = mean_err[i_best] + se_err[i_best]
alpha_1se = max(a for a, e in zip(alphas, mean_err) if e <= thr)

# 5) 用选定的 alpha 在全部训练集上重训，最后在测试集上评估
final = DecisionTreeClassifier(random_state=0, ccp_alpha=alpha_1se).fit(X_tr, y_tr)
print("alpha*(min CV) =", alphas[i_best], " alpha_1se =", alpha_1se)
print("pruned depth =", final.get_depth(), " leaves =", final.get_n_leaves(),
      " test acc =", round(final.score(X_te, y_te), 4))
```

#### R（`rpart`）

`rpart.control(cp = ...)` 里的 **`cp` 就是 α**：

```r
library(rpart)

# cp = 0 先把树长到最大，再做后剪枝
fit <- rpart(Species ~ ., data = iris, method = "class",
             control = rpart.control(cp = 0, minsplit = 2, xval = 10))

printcp(fit)   # cp 表：nsplit / rel error / xerror / xstd
plotcp(fit)    # xerror vs cp（横轴 cp 递减，越往右树越大）

# 1-SE 规则：在 xerror <= min(xerror) + xstd 的行里，取 cp 最大者
tb <- fit$cptable
i  <- which.min(tb[, "xerror"])
cp_1se <- max(tb[tb[, "xerror"] <= tb[i, "xerror"] + tb[i, "xstd"], "CP"])
pruned <- prune(fit, cp = cp_1se)
```

## 四、算一遍

用一棵 8 个观测的小回归树，把 $\alpha$ 序列从原始数据算到 CV 选树，全程可复算。

**数据与树结构**（y = 赔付额，千元）。这棵树已经长好了，形状是：根先切一刀分成左右两块；左块（B）再切一刀得到 $B_1$、$B_2$；右块（C）再切一刀得到 $C_1$、$C_2$。四个叶子里装的 y 是：

| 叶子 | 观测值 | 叶子均值 | 叶子 SSE $R(\cdot)$ |
|---|---|---|---|
| $B_1$ | 1, 3 | 2.0 | $(1-2)^2+(3-2)^2 = 2$ |
| $B_2$ | 10, 12 | 11.0 | $(10-11)^2+(12-11)^2 = 2$ |
| $C_1$ | 21, 23 | 22.0 | $(21-22)^2+(23-22)^2 = 2$ |
| $C_2$ | 30, 34 | 32.0 | $(30-32)^2+(34-32)^2 = 8$ |

### 第 1 步：最大树 $T_0$ 的代价

$$
R(T_0) = 2+2+2+8 = 14.0000, \qquad |T_0| = 4
$$

### 第 2 步：三个内部节点各算一个临界值

**节点 B（含 $\{1,3,10,12\}$）**：塌成一个叶子时用它的均值 6.5：

$$
R(B) = (1-6.5)^2+(3-6.5)^2+(10-6.5)^2+(12-6.5)^2 = 30.25+12.25+12.25+30.25 = 85.0000
$$
$$
\alpha_B = \frac{R(B)-R(T_B)}{|T_B|-1} = \frac{85.0000-(2+2)}{2-1} = \frac{81}{1} = \mathbf{81.0}
$$

读法：剪掉 B 枝，训练误差从 4 涨到 85（**涨 81**），叶子数从 2 减到 1（**省 1 个叶子**）。所以「每省一个叶子」的代价是 81。

**节点 C（含 $\{21,23,30,34\}$）**：均值 27：

$$
R(C) = (21-27)^2+(23-27)^2+(30-27)^2+(34-27)^2 = 36+16+9+49 = 110.0000
$$
$$
\alpha_C = \frac{110.0000-(2+8)}{2-1} = \frac{100}{1} = \mathbf{100.0}
$$

**根节点**：塌成一个叶子时用全体均值：

$$
\bar y = \frac{1+3+10+12+21+23+30+34}{8} = \frac{134}{8} = 16.7500
$$
$$
R(\text{root}) = 248.0625+189.0625+45.5625+22.5625+18.0625+39.0625+175.5625+297.5625 = 1035.5000
$$
$$
\alpha_{\text{root}} = \frac{1035.5000-14.0000}{4-1} = \frac{1021.5}{3} = \mathbf{340.5}
$$

到这里，三个价目是 **81 / 100 / 340.5**。最小的是 81 → **第一刀剪 B 枝**，得到

$$
T_1:\ \{B,\ C_1,\ C_2\},\qquad R(T_1) = 85+2+8 = 95.0000,\qquad |T_1| = 3
$$

### 第 3 步：剪完之后重算（这一步最容易漏）

剪掉 B 之后，$T_1$ 的内部节点只剩 C 和根，两个都要重算：

$$
\alpha_C = \frac{110.0000-10.0000}{2-1} = 100.0 \quad(\text{C 的子树没动，不变})
$$
$$
\alpha_{\text{root}} = \frac{R(\text{root})-R(T_1)}{|T_1|-1} = \frac{1035.5000-95.0000}{3-1} = \frac{940.5}{2} = \mathbf{470.25}
$$

根的价从 340.5 涨到 470.25——**因为省叶子的分母变小了**（从 $4-1=3$ 变成 $3-1=2$）。次小的是 100 → 第二刀剪 C 枝：

$$
T_2:\ \{B,\ C\},\qquad R(T_2) = 85+110 = 195.0000,\qquad |T_2| = 2
$$

### 第 4 步：最后一刀

$$
\alpha_{\text{root}} = \frac{1035.5000-195.0000}{2-1} = \mathbf{840.5} \;\Rightarrow\; T_3 = \{\text{root}\},\ R(T_3) = 1035.5000,\ |T_3| = 1
$$

**完整的 α 序列**（这就是「一个旋钮」的含义）：

| 树 | 叶子数 | $\alpha$ 区间 | $R(T_k)$ | 叶子取值 |
|---|---|---|---|---|
| $T_0$ | 4 | $[0,\ 81)$ | 14.0 | 2.0 / 11.0 / 22.0 / 32.0 |
| $T_1$ | 3 | $[81,\ 100)$ | 95.0 | **6.5** / 22.0 / 32.0 |
| $T_2$ | 2 | $[100,\ 840.5)$ | 195.0 | 6.5 / **27.0** |
| $T_3$ | 1 | $[840.5,\ \infty)$ | 1035.5 | **16.75** |

**验算临界值**（剪与不剪的 $R_\alpha$ 必须相等）：

| $\alpha$ | $R_\alpha(T_0)$ | $R_\alpha(T_1)$ | 是否相等 |
|---|---|---|---|
| 81 | $14+81\times4 = 338.0$ | $95+81\times3 = 338.0$ | ✓ |
| 100 | $95+100\times3 = 395.0$ | $195+100\times2 = 395.0$ | ✓ |
| 840.5 | $195+840.5\times2 = 1876.0$ | $1035.5+840.5\times1 = 1876.0$ | ✓ |

### 第 5 步：CV 挑 α，以及 1-SE 规则改了哪个答案

假设 10 折 CV 交出下面这张表（误差按归一化 MSE 记）：

| 候选 | 叶子数 | $\alpha$ 区间 | CV 误差 | 标准误 $SE$ |
|---|---|---|---|---|
| $T_0$ | 4 | $[0,\ 81)$ | 0.286 | 0.018 |
| $T_1$ | 3 | $[81,\ 100)$ | **0.275** | 0.017 |
| $T_2$ | 2 | $[100,\ 840.5)$ | 0.284 | 0.016 |
| $T_3$ | 1 | $[840.5,\ \infty)$ | 0.402 | 0.019 |

* **CV 误差最小**：$T_1$（0.275）→ 按「取最小值」你会选 3 个叶子的树。
* **1-SE 规则**：阈值 $= 0.275+0.017 = 0.292$；$CV \le 0.292$ 的有 $T_0$（0.286）、$T_1$（0.275）、$T_2$（0.284）。取其中 $\alpha$ 最大（树最小）的 → **$T_2$，2 个叶子**。

两棵树的 CV 误差只差 0.009，而阈值 0.292 比两者都高——这正是「CV 曲线在最小值附近是平的」的样子。1-SE 规则把答案从 3 个叶子挪到 2 个叶子。

### 条件检验：$\alpha$ 落在两个临界值之间，选哪棵树

让 $\alpha$ 取四个值，代入 $R_\alpha = R(T_k)+\alpha|T_k|$ 逐棵树算：

| $\alpha$ | $T_0$（4 叶） | $T_1$（3 叶） | $T_2$（2 叶） | $T_3$（1 叶） | winner |
|---|---|---|---|---|---|
| **90**（81 与 100 之间） | 374.0 | **365.0** | 375.0 | 1125.5 | $T_1$ |
| **150**（100 与 840.5 之间） | 614.0 | 545.0 | **495.0** | 1185.5 | $T_2$ |
| **800**（同上） | 3214.0 | 2495.0 | **1795.0** | 1835.5 | $T_2$ |
| **900**（> 840.5） | 3614.0 | 2795.0 | 1995.0 | **1935.5** | $T_3$ |

三个结论：

1. **$\alpha$ 的具体数值不重要，重要的是它落在哪个区间**。$\alpha=150$ 与 $\alpha=800$ 差 5 倍多，选出的却是同一棵树。
2. **$\alpha=90$ 与 $\alpha=150$ 之间那一步（跨过 100）换了树**：$T_1$ 只在 $[81,100)$ 这个宽度只有 19 的区间里最优。实务上这意味着 CV 曲线要能把这种窄区间分辨出来，否则你选到的树可能只是噪声——1-SE 规则偏向大树（更小的叶子数）正是为了避开这种窄区间的抖动。
3. **$\alpha$ 大于 840.5 之后，最优解是单节点树**：训练误差 1035.5、什么特征都不用。这是一个必要的提醒——剪枝路径的尽头是无模型，所以「$\alpha$ 越大越稳」不成立，CV 必须在路径中间停下来。

## 五、什么情况下会失灵

### 承重假设一：有独立数据估计剪枝准则

$R_\alpha$ 只看训练误差，一定选最大树；$\alpha$ 必须靠留出数据定。

撤掉它的后果：在一份数据上既长树又选 $\alpha$，得到的是那棵把这份数据背下来的树，你报的 CV 误差会明显偏乐观。数据很小（几百行）时更糟：K 折 CV 的每折只有几十行，$\alpha$ 的排序本身很不稳定，相邻两棵树的顺序会来回翻。处理：重复 CV 或 bootstrapped 0.632 估计，并且把「1-SE 之内谁都行」当成常态而不是异常。

### 承重假设二：$R(T)$ 的增长能代表真实损失

$R(T)$ 是训练集上的不纯度 / SSE 之和。

撤掉它的后果：如果某个叶子的训练误差很小不是因为它的预测准，而是因为它只装了 1 个样本（必然纯），那么 $R(t)-R(T_t)$ 会被系统性压低，这枝的 $\alpha_t$ 因此偏小、**排在前面被剪掉**。这是「剪枝顺手帮你清理小叶子」的好运气。反过来说，如果业务代价不对称（漏掉一个欺诈比多审十个贵得多），$R(T)$ 用误分类率或 Gini 都不是你要的东西，剪枝顺序会朝着「整体误差最小」走，而不是「漏检最少」。处理：换加权不纯度，或者把 $\alpha$ 路径拿来做候选、用你真正的代价函数去挑。

### 承重假设三：树结构本身稳定

weakest-link 是在**给定的那棵树**上排序的。

撤掉它的后果：换 5% 的样本重训，第一层分裂可能就换了变量，整棵树结构跟着变，$\alpha$ 序列也随之换一套。所以「$\alpha^*=0.0031$」这种精确到四位小数的结论没有跨数据集的含义——它是**这份数据上这棵树**的价目表。这也是随机森林直接不做剪枝、改用平均来压方差的原因。

### 承重假设四：预剪枝与后剪枝花的是同一种预算

后剪枝要先把树长满，再在整条 $\alpha$ 路径上做 CV。

撤掉它的后果：`n=200 万、p=500` 时，长满的树可能有几万个叶子，`cost_complexity_pruning_path` 与随后的 CV 会慢到不可用；此时先做预剪枝（`min_samples_leaf=50`、`max_depth=12`）把规模压下来，再在压缩后的树上做 CCP，得到的树大概率不如纯 CCP，但能在预算内跑完。这不是理论问题，是工程取舍。

### 与其他方法的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 要紧凑规则、要给业务讲 | CCP + CV（常配 1-SE） | 一个旋钮 $\alpha$ 控制树大小，输出是一串嵌套子树 |
| 数据小（< 1000 行） | 预剪枝 + 重复 CV | CCP 的 CV 波动更大，简单策略更稳 |
| 需要现成的样本外估计 | 预剪枝的 `min_samples_leaf` 网格 | 后剪枝必须额外切数据或跑 CV |
| 树只是集成的基学习器 | 不剪枝 | RF / GBM 靠平均或收缩压方差（见 [[7. Random Forest]]） |
| 要的是概率校准 | 剪枝后再做校准 | 剪枝改变叶子里的频率，概率会跟着变 |
| 代价不对称（欺诈、核保） | 加权不纯度 + 自定义选树 | 标准 CCP 优化的是整体误差 |

## 六、常见误解

### 误解一：「预剪枝和后剪枝差不多，选便宜的那个」

**错误想法**：都在限制树的大小，预剪枝还快，`max_depth=4` 一步到位。

**为什么容易这么想**：两个方向的目标看起来一致，而预剪枝确实便宜得多、参数也好解释；而且深度限制常常能拿到接近的效果，于是形成习惯。

**错在哪一步**：把「限制大小」和「按收益修剪」当成同一件事。预剪枝是**全局一刀切**：深度 4 以下的枝一律停，好枝坏枝一起砍，还有视野局限（horizon effect）——它看不到「先分下去、再剪回来」更好的结构，因为决定是在信息不全的时候做的。后剪枝允许树**不对称**：某个方向可以很深、另一个方向已经剪成叶，而且每个枝按自己的 $\alpha_t$ 决定去留。同样叶子数下，后剪枝通常更准；预剪枝的价值在预算而不是精度。

### 误解二：「1-SE 规则是把标准误当成容错，可以随便宽松一点」

**错误想法**：既然 CV 曲线是平的，那就在最小值附近挑个小的，差个 0.05 也无所谓。

**为什么容易这么想**：1-SE 的名字听起来像「允许误差」，第四节那张表里 $T_1$ 与 $T_2$ 又只差 0.009，看起来确实可以随便挪。

**错在哪一步**：1-SE 的阈值是 $CV(\alpha^\*) + SE(\alpha^\*)$，其中 $SE$ 是**CV 均值本身的标准误**（$\text{sd}/\sqrt{K}$），不是任意容差。K=10 折时它通常只有 0.01–0.02 量级；如果你手上的 CV 曲线最小值与次小值差 0.05，那已经超出 1 个标准误，1-SE 规则**不会**帮你挪树。另外，方向是固定的：在阈值内取**叶子最少**的那棵，不是「取次小」。

### 误解三：「剪枝是通用解药，树过拟合就剪」

**错误想法**：CV 误差比训练误差高，先剪枝再说。

**为什么容易这么想**：剪枝确实能降方差，而「训练好、测试差」又是过拟合的典型症状，两边看起来对得上。

**错在哪一步**：训练/测试差距也可能是**分布漂移**或**泄漏**造成的。这两种情况下剪枝改变不了任何事——第 10 折的样本和训练样本本来就不是一回事，剪掉几个叶子不会让它们变像。判断顺序应该是：先看特征构造与切分方式（有没有用到未来信息、按时间切了没有），再看样本量与标签噪声，最后才动模型容量。第四节的 CV 表里，$T_3$（单节点树）的 CV 误差反而是最高的 0.402——剪过头同样会掉分，剪枝不是单调的保险。

### 误解四：「CCP 的 α 和 Ridge/Lasso 的 λ 是同一回事，方法可以照搬」

**错误想法**：形式都是「损失 + 惩罚」，那就照 Ridge 的做法：在网格上搜 λ、取 CV 最小。

**为什么容易这么想**：$R(T)+\alpha|T|$ 与 $\text{Loss}+\lambda\|\beta\|$ 长得太像，连「α 越大模型越小」都一致。

**错在哪一步**：**结构不同**。λ 是连续的，可以在任意网格上取；$\alpha$ 只能取那条 $\alpha_t$ 路径上的离散值（81、100、840.5……），中间的值没有对应的树。原因是 $R_\alpha$ 对树结构不可微，不能梯度下降，只能靠 weakest-link 枚举。所以做法也不同：先把路径枚举出来（`cost_complexity_pruning_path` / `cp=0` + `printcp`），再在**这几十个候选**上做 CV，而不是在 $\alpha$ 的连续区间里搜。顺带一个实操后果：$\alpha$ 的取值必须来自路径，随便填一个 `ccp_alpha=0.003` 很可能落不到任何一棵树上，sklearn 会给你一棵比预期更小的树。

## 七、面试怎么答

### 30 秒版

> 决策树长满会过拟合，所以要么**预剪枝**（`max_depth`、`min_samples_leaf` 等，早停、便宜但容易欠拟合、有视野局限），要么**后剪枝**（先长满再剪，更可靠但更贵）。CART 的后剪枝叫**代价复杂度剪枝**：最小化 $R_\alpha(T) = R(T) + \alpha|T|$，用 weakest-link 算法按 α 从小到大生成一串**嵌套子树**，再用 **K 折 CV** 选 α，通常配 **1-SE 原则**取 1 个标准误内最小的树。scikit-learn 里就是 `ccp_alpha` + `cost_complexity_pruning_path`，R 里是 `rpart` 的 `cp`。

### 2 分钟版（要包含的三块）

1. **机制**：$R_\alpha$ 给每个叶子定价；$\alpha_t=\frac{R(t)-R(T_t)}{|T_t|-1}$ 是剪这枝的临界价；每次剪最小的一枝、剪完重算，得到 $0=\alpha_0<\alpha_1<\cdots<\alpha_M$ 与嵌套序列，$\alpha$ 落在 $[\alpha_k,\alpha_{k+1})$ 就对应 $T_k$。
2. **一个数字**：本页算例的价目表是 81 / 100 / 840.5（8 个观测的小树），根的价会随着剪枝从 340.5 变到 470.25 再变到 840.5——因为分母 $|T_t|-1$ 在缩小。
3. **选 α 的分寸**：CV 最小值附近的曲线是平的，所以用 1-SE 取更小的树；但阈值是 $CV+SE$ 不是随便宽松，而且路径尽头是单节点树，不能在区间的极端处停。

### 追问 1：为什么建树时不用误分类率，剪枝时却可以用？

* 误分类率 $1 - \max_c p(c)$ 是**分段线性**的、**不严格凹**：如果一次分裂把两个子节点都推到 $p = 0.5$ 的同一侧，按误分类率算的增益**恰好为 0**，你会"看不出这个分裂的价值"；而**熵与 Gini 是严格凹函数**，任何分裂的增益恒为正，会持续鼓励生成更纯的节点。
* 到了剪枝阶段，目标变成"整棵树的代价"而不是"选哪个分裂"，用哪个准则都行——只要符合你真正要优化的目标。PSL §12.3 的结论就是：**建树用熵或 Gini 指数，剪枝阶段可以改用误分类率**（或任何与目标一致的准则）。详见 [[7.2.2 Decision Tree|§2.3 误分类率为什么不适合建树]]。

### 追问 2：CCP 的 α 与 Ridge/Lasso 的 λ 有什么类比？

* 形式上同构：$R_\alpha(T) = R(T) + \alpha|T|$ ↔ $\text{Loss} + \lambda\|\beta\|$。两者都是「拟合 + 复杂度惩罚」的**正则化路径**：α/λ 从小到大 ⇒ 模型从大到小 / 系数从大到小；都用 CV 选超参。
* 差别：λ 惩罚的是**参数大小**（L1 下等价于非零参数个数），α 惩罚的是**叶节点个数**（结构复杂度）。$R_\alpha$ 对树结构不可微，所以不能梯度下降，只能靠 weakest-link 枚举出路径再挑。

### 追问 3：剪枝和"减 `max_depth`"有什么区别？

* 减 `max_depth` 属于**预剪枝**：全局一刀切，所有分支被限制在同一深度，好枝坏枝一起砍（视野局限）。
* 后剪枝允许树**不对称**：某个方向可以很深、另一个方向已经剪成叶；它按**每个分支自己的收益**决定去留，所以同样节点数下通常更准。
* 但预剪枝便宜得多：特征多/数据大、或只想快速拿 baseline 时仍然首选。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么叫 weakest link？」 | 每步剪掉「每省一个叶子、误差涨得最少」的枝，即最低的 $\alpha_t$ |
| 「$\alpha_t$ 的分子分母各是什么？」 | 分子 = 剪掉这枝的误差增量 $R(t)-R(T_t)$；分母 = 少掉的叶子数 $|T_t|-1$ |
| 「剪完为什么要重算？」 | 上层节点的 $R(t)$ 与 $|T_t|$ 都变了；算例里根的等价价从 340.5→470.25→840.5 |
| 「为什么能得到嵌套序列？」 | 每次只剪一棵子树且不再改回去，所以 $T_0\supset T_1\supset\cdots$，一个 $\alpha$ 唯一对应一棵 |
| 「1-SE 里的 SE 是什么的 SE？」 | CV 均值本身的标准误 $\text{sd}/\sqrt{K}$，不是单个观测的标准差 |
| 「RF 为什么不用剪枝？」 | 集成靠平均压方差，单棵树保持低偏差是前提；剪枝会抬高偏差，平均压不掉 |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "A fully grown tree is low bias and high variance, so pruning gives back a bit of training fit to buy generalisation. Pre-pruning stops growth early with depth or leaf-size limits; post-pruning grows the full tree and then cuts back, which is usually more accurate but more expensive to compute."

**Mechanism**

> "CART's version is cost-complexity pruning: minimise R of T plus alpha times the number of leaves, where alpha is the price per leaf. The weakest-link algorithm removes the branch with the smallest increase in error per leaf saved, and that gives a nested sequence from the maximal tree down to the root, with an increasing alpha for each tree."

**If they push back**

> "A common pitfall is assuming the tree with the lowest cross-validated error wins. The CV curve is usually flat near the minimum, so the one-SE rule — take the smallest tree whose error is within one standard error of the best — is the standard choice, because a simpler tree is more stable. In practice that's ccp_alpha with cost_complexity_pruning_path in scikit-learn, or cp in rpart."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 剪枝 | pruning | 砍掉在未见数据上无收益的枝 |
| 预剪枝 | pre-pruning / early stopping | 生长中设门槛，快但视野受限 |
| 后剪枝 | post-pruning | 先长满再自底向上砍 |
| 代价复杂度剪枝 | cost-complexity pruning (CCP) | 最小化 $R(T)+\alpha\lvert T\rvert$ |
| 复杂度代价 | complexity cost | $R_\alpha(T)$，训练误差 + 叶子数的价钱 |
| 最弱环节 | weakest link | 每步剪掉最低 $\alpha_t$ 的那一枝 |
| 临界值 | critical value | $\alpha_t=\frac{R(t)-R(T_t)}{\lvert T_t\rvert-1}$ |
| 嵌套子树序列 | nested subtree sequence | $T_0\supset T_1\supset\cdots\supset T_M=\{\text{root}\}$ |
| 分段常数 | piecewise constant | 区间 $[\alpha_k,\alpha_{k+1})$ 内最优树不变 |
| 1-SE 原则 | one-standard-error rule | 在 $CV+SE$ 之内取叶子最少的那棵 |
| 视野局限 | horizon effect | 提前停止会错过更好的后续结构 |
| 悲观误差剪枝 | pessimistic error pruning | C4.5 的后剪枝，用连续性修正估叶子误差 |
| 减少误差剪枝 | reduced-error pruning | 用验证集误差决定是否把子树换成叶子 |
