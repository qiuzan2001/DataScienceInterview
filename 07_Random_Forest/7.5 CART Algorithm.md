## 速览 At a glance

**速记**

CART 用一句话概括是**二分 + 剪枝 + 支持数值目标**。分类用 Gini 不纯度、回归用平方误差和（SSE），每个节点只问一个是非题，所以类别变量也要被切成两堆；数值特征的最优切点靠「排序一次 + 从左往右扫一遍」找，复杂度在每个节点上是线性的，类别特征则按「类别 1 的概率」排序后当数值用（Breiman 证明二分类下这样能得到 Gini 的精确最优）。缺失值不插补，用代理分裂（surrogate split）——找一个在主分裂上划分最一致的替代特征，并给每条分支一个默认方向，预测保持确定性。第二阶段是代价复杂度剪枝：先长到最大，最小化 $R_\alpha(T)=R(T)+\alpha|T|$，用 weakest-link 生成一串嵌套子树，再用 K 折 CV 配 1-SE 原则选 $\alpha$。本页算例把 5 套房的四个候选切点全部算了一遍：最优切点在 60 平方米，$\Delta\text{SSE}=13653.33$；再加两套房，最优切点就移到 80 平方米，说明切点的位置是数据决定的、不是固定的。

**一句面试答法**

> "CART is binary, pruned, and it handles regression as well as classification. Classification splits on Gini, regression on the sum of squared errors, and every node asks a yes/no question. Missing values are handled with surrogate splits rather than imputation, and the second stage is cost-complexity pruning with alpha chosen by cross-validation."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 分类与回归树 | classification and regression tree (CART) | 一套框架同时做分类与回归，每个节点只二分 |
| 基尼不纯度 | Gini impurity | $\sum_c p_c(1-p_c)$，随机取两个样本类别不一致的概率 |
| 平方误差和 | sum of squared errors (SSE) | $|S|\cdot\text{Var}(S)$，回归树的分裂准则 |
| 代理分裂 | surrogate split | 主分裂变量缺失时用来替代的分裂 |
| 代价复杂度剪枝 | cost-complexity pruning (CCP) | 最小化 $R(T)+\alpha\lvert T\rvert$，$\alpha$ 是每个叶子的价格 |
| 最弱环节 | weakest link | 每步剪掉「每省一个叶子误差涨得最少」的那一枝 |

## 一、先看一个问题

你手上有 1200 条车险保单，想建一棵树给业务看。同事在 R 里用 `rpart` 建了一棵，你在 Python 里用 `DecisionTreeClassifier` 建了同一份数据的树。

两棵树不一样。同一份数据、同一个目标变量，连特征顺序都一样。

差异来自三处**规定动作**，而 CART 把这些规定动作都写死了：

| 分岔点 | 可选做法 | CART 的选择 |
|---|---|---|
| 一个节点切成几份 | 多路（ID3/C4.5）或二分 | **只二分** |
| 用哪个准则挑分裂 | 熵、增益率、Gini、误分类率、SSE | 分类 **Gini**、回归 **SSE** |
| 什么时候停、怎么简化 | 预剪枝、悲观误差剪枝、代价复杂度剪枝、不剪 | **代价复杂度剪枝 + CV 选 $\alpha$** |

把这三处固定下来，两个软件的树就会非常接近——因为它们做的是同一件贪心的事。

再具体一点，问题可以缩到一行：**8 笔赔案按 x 排好序，$y$ 是赔付额，第一刀切在哪？** 看完这一节你会知道，答案不是「切在中间」——本页算例里最优切点落在 60，而它离中位数不远不近，纯粹是数据说出来的。

本笔记在真题里是支撑知识：§8.1「随机森林算法」里 CART 的分裂准则、缺失值处理和 CCP 剪枝都由它兜底。

## 📖 标准定义

> **教材原文 · PSL §4.1.1–§4.1.2（页面 w4_1_reg_tree.html）**（<https://liangfgithub.github.io/PSL/w4/w4_1_reg_tree.html>）
> > "Trees models are constructed by recursively splitting regions of X into two sub-regions, beginning with the entire feature space X. For simplicity, we’ll focus on recursive binary partitions."
> >
> > "When you focus on minimizing the squared error between observed and predicted values, the best prediction for each leaf node is simply the average response of the samples in that node."
> >
> > "Trees are built in a top-down and greedy fashion. For each node, we try all possible splits (both features and split values) and pick the one that provides the most significant gain in RSS."
> >
> > "Each leaf node corresponds to a rectangular-shaped region in the feature space."

**标准记法**：回归树 $\hat{f}(x) = \sum_{m=1}^{M} c_m \mathbf{1}\{x \in R_m\}$，$c_m = \text{ave}(y_i \mid x_i \in R_m)$。分裂准则（最小化子节点平方误差和）$\min_{j,\,s} \Big[ \min_{c_L} \sum_{x_i \in R_L(j,s)} (y_i - c_L)^2 + \min_{c_R} \sum_{x_i \in R_R(j,s)} (y_i - c_R)^2 \Big]$。

**中文解释**：回归树把特征空间递归二分，每个叶节点是一个矩形区域，区域内用响应均值作为常数预测。分裂变量与切点靠贪心地最大化 RSS 的下降量来选。优点是可解释、自动做变量选择、不要求变量变换（对单调变换不变）。

## 二、核心直觉

### 三个直觉，先不碰公式

1. **只问二分问题。** 每个内部节点都问一个是/否：数值特征是*「这个特征 ≤ τ 吗？」*，类别特征是*「这个项目落在子集 S 里吗？」*。搜索更简单、更平衡，后续评估也更快——而且对 CPU 的分支预测友好，这一点在实时打分里是真实收益。

2. **「不纯度」依旧是主宰。** *分类* 选那个最能降低**基尼不纯度（Gini impurity）**的分裂；*回归* 选那个最能降低**平方误差和（sum-of-squared errors，即方差）**的分裂。判断「好」的标准还是那一个：分裂之后，孩子比父亲纯多少。

3. **先长满，再剪枝。** 先建一棵会过拟合的树；然后用*一个*超参数 $\alpha$ 在「精度 vs 复杂度」之间做权衡，把弱子树砍掉。顺序不能反——你没法在生长时判断一枝将来是不是多余的。

**这里像什么、不像什么**：可以把它想成一个只会问是非题的面试官，每问一句就把候选人分成两堆，追问下去直到每个人都归到自己那一小堆。像的地方是「每次只切一刀、切完再切」这个流程；不像的地方是，面试官的第二问要人听得懂，而 CART 的第二问可以是「面积 ≤ 62.5 吗？」这种纯粹由数据决定的碎问题——它不要求问题有意义，只要求把 $y$ 切得更整齐。

## 三、机制

### 3.1 定义与逐项说明

#### 分类：Gini 不纯度

$$
G(S)=\sum_{c=1}^{C}p(c)\,[1-p(c)]=1-\sum_{c} p(c)^2
$$

$C$ 是类别数，$p(c)$ 是节点 $S$ 里类别 $c$ 的样本占比。两个写法恒等：把 $\sum_c p(c)=1$ 代进去就能展开。

| 视角 | 结论 |
|---|---|
| **随机取两个样本、类别不一致的概率**（probability-of-mis-pairing） | 纯节点时为 0，各类等比例混合时最大 |
| **计算上的红利** | 不用对数 → 比熵更快 |

算一遍量级：二分类、$p=0.5$ 时 $G=2\times0.5\times0.5=0.5$；$p=0.9$ 时 $G=0.18$；纯节点 $G=0$。

#### 回归：方差与 SSE

对目标值为 $y_i$ 的节点 $S$：

$$
\text{Var}(S)=\frac{1}{|S|}\sum_{i}(y_i-\bar{y})^2
\qquad\Longrightarrow\qquad
\text{SSE}(S)=|S|\;\text{Var}(S)
$$

方差越小 ⇒ 响应值抱得越紧 ⇒ 用一个数（区域均值）去预测就越容易。**SSE 与方差只差一个乘数 $|S|$**，所以选切点时用哪个都行，报数时说清是哪一个就行——本页算例统一用 SSE。

#### 分裂后的加权不纯度

$$
\text{ImpurityAfter}(S,\text{split})
   =\frac{|S_L|}{|S|}\,I(S_L)+\frac{|S_R|}{|S|}\,I(S_R)
$$

选让这个值**最小**的分裂（等价地说，让不纯度*下降*最大），其中 $I$ 取上面的 Gini 或 SSE。这个式子与 ID3 的信息增益是同一个套路，只是准则换了。

### 3.2 它是怎么来的

#### 生长的四步

1. 从根节点开始，装下全部数据。
2. 在当前节点上，把所有候选分裂（所有特征的所有切点）试一遍。
3. 选使 $\text{ImpurityAfter}$ 最小的那个（等价于最大化 RSS/SSE 的下降），把节点切成两个子节点。
4. 对每个子节点递归，直到触发停止条件（`max_depth`、`min_samples_leaf`、增益 < ε，或节点已纯）。

**关键一步在这里**：第 2 步「所有切点都试一遍」听起来是 $O(n^2)$，CART 的效率就藏在这一步怎么被化简——下面两小节。

#### 数值属性怎么找最优切点（线性扫一遍）

1. 把该属性上的 $(x,y)$ 配对**排序一次**。
2. 从左往右扫描，一边更新类别计数 / 滚动求和。
3. 只在 $x$ 发生变化的边界处评估不纯度。

*每个节点的成本：* $O(n_a)$（就是你在 C4.5 那里见过的线性技巧）。排序是 $O(n_a\log n_a)$，扫描是 $O(n_a)$，所以没有 $O(n_a^2)$ 的那一层。

#### 类别属性：为什么可以排序后当数值用

* 因为 CART 坚持只问二分问题，它必须把类别集合分成**两组**。
* 如果暴力枚举全部 $2^{k-1}-1$ 种划分，最优分裂是 NP-hard 的。
* 实践中的做法：

  1. 按「类别 1 的概率」从小到大给类别排序。
  2. 把这个顺序当成数值，套用上面的数值扫描。
     *（Breiman 证明了：在二分类情形下这样能得到 Gini 的精确最优解。）*

#### 缺失值——代理分裂（surrogate splits）

机制讲清楚：如果主分裂用的是属性 $A$，而某个待预测样本的 $A$ 是缺失的（$A=?$），就去找**另一个属性**——它在**训练数据**上产生的划分与主分裂最接近。这个「最接近」是有衡量标准的：在**主分裂属性没有缺失**的那些训练样本上，分别用主分裂与候选分裂去切，统计两者把样本分到同一侧的比例（一致率），一致率最高的候选就成为代理分裂。

实际实现里通常还会：

* 给代理分裂的一致性加一个修正量（考虑该属性自身缺失的比例），避免选到一个「看起来一致、实际常常缺失」的属性；
* 为每条分支再给一个默认方向（default direction），保证任何样本都能走到底。

这样做的好处：**预测保持确定性（deterministic）**——不需要任何全局插补（global imputation），也不会因为插补把缺失值变成虚假信息。缺失越严重时，代理分裂越可能「退化」为只按多数方向走的决定，但流程本身不会崩。

#### 剪枝：代价复杂度（α 剪枝）

* **代价（cost）。** $R_\alpha(T) = R(T) + \alpha \cdot |T|$ —— $R(T)$ 是训练误差（Gini 不纯度之和或 SSE），$|T|$ 是叶节点个数，$\alpha$ 是「每多一个叶子要付的代价」。
* **流程（procedure）。** 先把树长到最大 $T_0$ → 用 **weakest-link 剪枝**生成嵌套子树序列 $T_0 \supset T_1 \supset \dots \supset T_M$（从最大树一直到只剩单节点的根）→ 用 **K 折 CV** 选 $\alpha$，常用 **1-SE 原则**（在 CV 误差最小值 1 个标准误内选最小的树）。
  * 每一步砍掉的是「当下最弱的一环」：对每个内部节点 $t$ 算临界值 $\alpha_t = \dfrac{R(t)-R(T_t)}{|T_t|-1}$（把子树 $T_t$ 压成一个叶子所能省下的误差，均摊到它多出来的每个叶子上），选 $\alpha_t$ 最小的那个节点压掉，并让该步对应的 α 取这个值。
  * 于是每个 $\alpha$ 区间恰好对应序列里的一棵树，**一个 α 就唯一确定一棵树**——这就是「单个旋钮」的含义。
* **为什么它优于 C4.5 的误差剪枝。** 它把剪枝变成了一个 **ℓ₀ 正则化（ℓ₀-regularised）的最优化问题**，只有*一个*旋钮 α，而不是几千次彼此独立的叶子检验；而且它可证明地给出一串嵌套的树序列，调参极为方便。

> 📎 **细节（α 的两种口径、临界值 $\alpha_t = \dfrac{R(t)-R(T_t)}{|T_t|-1}$、weakest-link 算法、1-SE 规则、`ccp_alpha` / `rpart::cp` 代码）全部移到 [[7.2.2.4. Pruning Decision Trees]]。** 本页第四节的算例给出手算的 $\alpha$ 序列。

#### 伪代码：结构就是「分裂 → 递归」，只切两刀，多一个阶段

```text
function CART(S, Features, task):
    # ----- growing -----
    node ← best_split(S, Features, task)    # Gini or SSE; returns None if stop
    if node is None: return Leaf(prediction(S, task))
    node.left  = CART(S_L, Features, task)
    node.right = CART(S_R, Features, task)
    return node

full_tree = CART(training_data, all_features, task)

# ----- pruning -----
sequence = weakest_link_prune(full_tree)    # produces T_0, T_1, …, T_M
α*        = choose_alpha_by_CV(sequence)    # k-fold cross-validation
final_tree = tree_in_sequence_closest_to(α*)
```

### 3.3 变形与口径

| 口径 | 各家的写法 | 报数时要注意什么 |
|---|---|---|
| 分裂准则 | scikit-learn：`criterion="gini"` / `"entropy"` / `"squared_error"`；`rpart`：`split="gini"`（分类）/ `"anova"`（回归） | 换了准则，长出来的树会变；「Gini 还是熵」多数时候只是细节差异，但极不平衡时会有不同 |
| 误差口径 | Gini/熵是**不纯度**（每个样本一个数，与 $n$ 无关）；SSE 是**和**、MSE 是**均值**、方差是 MSE | 三者差一个 $|S|$ 的倍数。选切点结果一样，**报数时不能混**——本页算例全部用 SSE |
| 复杂度参数 | scikit-learn 的 `ccp_alpha`（默认 0 不剪枝）；`rpart` 的 `cp` | 名字不同、含义相同；两个的默认值不同，默认值不是「最优值」 |
| 候选切点 | 数值：相邻取值的中点；类别：按类别均值/类别 1 概率排序后取前缀 | 实现里常有阈值子采样（比如只取前 30 个候选），这会改变最优切点，也会改变特征重要性（见 [[7.4. Quantifying Feature Importance]]） |
| 缺失值 | `rpart` 有 surrogate；scikit-learn 的 `DecisionTreeClassifier` 历史上要求先自己补缺失 | 同一个「CART」在不同实现里缺失值行为不同，别把一种实现的默认行为当成 CART 的定义 |
| 树的大小 | 「长满」在实现里是 `max_depth=None` + `min_samples_leaf=1` | 「先长满再剪枝」需要一个真的会长满的第一阶段，若第一阶段已经预剪枝，$\alpha$ 路径也跟着变 |

### 3.4 CART 在决策树家族里的位置

| 算法 | 分裂准则 | 分裂方式 | 剪枝？ | 支持回归？ |
| --------- | -------------------------- | --------------- | ------------------------------- | ------------------- |
| **ID3**   | 熵 / 增益 | 多路（multi-way）       | 无                             | ✖                   |
| **C4.5**  | 增益率（Gain Ratio）                 | 多路       | 基于误差（后剪枝）              | ✖                   |
| **CART**  | Gini（分类） / SSE（回归） | **只做二分** | **代价复杂度（α 剪枝）** | **✔**               |

*记忆口诀*：**CART = Binary + Pruned + Works for Y as number**（二分、剪枝、目标可以是数值）。

**口袋里的心智模型**：

```
ID3          = entropy  + multiway splits + no pruning
C4.5         = ID3      + gain-ratio      + error-prune
CART         = gini/sse + binary splits   + α-prune (+ regression!)
```

中文对照：**ID3** = 熵 + 多路分裂 + 不剪枝；**C4.5** = ID3 + 增益率 + 误差剪枝；**CART** = gini/sse + 二分分裂 + α 剪枝（外加支持回归！）。

### 3.5 复杂度速查

| 阶段 | 时间复杂度 | 空间复杂度 | 备注 |
| ------------------ | -------------------------- | ---------------- | ------------------------------------------------------------------- |
| 生长（每层） | O(nm) | O(nm) | 与 C4.5 相同；实践里常常更快，因为 Gini 的数学更简单 |
| 剪枝 | O(n + \|T₀\| × log \|T₀\|) | O(\|T₀\|) | 高效的 weakest-link 剪枝；不需要为每个叶子单独做检验 |
| 预测（单样本） | 与树深成正比 | — | 平衡树里深度 ≈ log(n) ⇒ 预测很快 |

### 3.6 CART 的强项

1. **分类与回归一套引擎** – 同一个框架既能解分类也能解回归。
2. **需要可解释性** – 后剪枝给出紧凑的模型。
3. **实时打分** – 二分问题对 CPU 的分支预测（branch prediction）很友好。
4. **Bagging / 随机森林** – CART 是标准的基学习器（快 + 二分）。

## 四、算一遍

用 5 套房子手算一遍回归树的第一刀。数据只有一列特征（面积，平方米）和一列目标（价格，千美元），所以候选切点可以全列出来。

| 房子 | 面积 $x$ | 价格 $y$（千美元） |
| ----- | ---------- | --------------- |
| A | 30 | 100 |
| B | 50 | 150 |
| C | 70 | 200 |
| D | 90 | 230 |
| E | 110 | 265 |

### 第 1 步：根节点的基线

$$\bar y = \frac{100+150+200+230+265}{5} = \frac{945}{5} = 189.0000$$

$$\text{SSE} = (100-189)^2+(150-189)^2+(200-189)^2+(230-189)^2+(265-189)^2 = 17020.0000$$

（要报 MSE 就是 $17020/5 = 3404.0000$。**下面统一用 SSE**，因为 CART 的 $R(T)$ 是「不纯度之和」这个口径。）

### 第 2 步：候选切点只有 4 个

相邻面积的中间值：(30+50)/2 = **40**、(50+70)/2 = **60**、(70+90)/2 = **80**、(90+110)/2 = **100**。每个都算一遍。

**切在 40（左 1 右 4）**

左组只有 A：均值 100，$\text{SSE}_L = (100-100)^2 = 0$。
右组 B–E：均值 $(150+200+230+265)/4 = 845/4 = 211.25$，逐项

$$(150-211.25)^2+(200-211.25)^2+(230-211.25)^2+(265-211.25)^2 = 3751.5625+126.5625+351.5625+2889.0625 = 7118.7500$$

合计 $0 + 7118.7500 = 7118.7500$，$\Delta\text{SSE} = 17020 - 7118.75 = \mathbf{9901.2500}$。

**切在 60（左 2 右 3）**

左组 A、B：均值 $(100+150)/2 = 125$，$\text{SSE}_L = 625 + 625 = 1250.0000$。
右组 C、D、E：均值 $695/3 = 231.6667$，逐项

$$(200-231.6667)^2+(230-231.6667)^2+(265-231.6667)^2 = 1002.7778+2.7778+1111.1111 = 2116.6667$$

合计 $1250.0000+2116.6667 = 3366.6667$，$\Delta\text{SSE} = 17020 - 3366.6667 = \mathbf{13653.3333}$。

**切在 80（左 3 右 2）**

左组 A–C：均值 $(100+150+200)/3 = 150$，$\text{SSE}_L = 2500+0+2500 = 5000.0000$。
右组 D、E：均值 $(230+265)/2 = 247.5$，$\text{SSE}_R = 306.25+306.25 = 612.5000$。

合计 $5612.5000$，$\Delta\text{SSE} = 17020-5612.5 = \mathbf{11407.5000}$。

**切在 100（左 4 右 1）**

左组 A–D：均值 $(100+150+200+230)/4 = 170$，$\text{SSE}_L = 4900+400+900+3600 = 9800.0000$。
右组只有 E：$\text{SSE}_R = 0$。

合计 $9800.0000$，$\Delta\text{SSE} = 17020-9800 = \mathbf{7220.0000}$。

### 第 3 步：四个候选并列

| 切点 | 左组 | 左均值 | $\text{SSE}_L$ | 右组 | 右均值 | $\text{SSE}_R$ | 合计 SSE | $\Delta$SSE |
|---|---|---|---|---|---|---|---|---|
| 40 | A | 100.0000 | 0.0000 | B–E | 211.2500 | 7118.7500 | 7118.7500 | 9901.2500 |
| **60** | A、B | **125.0000** | **1250.0000** | C–E | **231.6667** | **2116.6667** | **3366.6667** | **13653.3333** |
| 80 | A–C | 150.0000 | 5000.0000 | D、E | 247.5000 | 612.5000 | 5612.5000 | 11407.5000 |
| 100 | A–D | 170.0000 | 9800.0000 | E | 265.0000 | 0.0000 | 9800.0000 | 7220.0000 |

**最优切点是 60**，不是两端（两端都只把一边切纯，另一边更乱），也不是离根均值 189 最近的那个。CART 就在这里分裂，两个叶子的预测值分别是 125.0 和 231.6667。


**两处口径与算术更正**（原笔记这几行的数字需要改）：

* 原文写的「MSE = (100−125)²+(150−125)² = 625+625 = 1250」用的是 **SSE 口径**（没有除以 $n$）。要报 MSE 应是 $1250/2 = 625$。选切点不受影响，但报数时要写清。
* 原文右组写的是 $1012.89+2.89+1106.89 = 2122.67$。按精确均值 231.6667 应该是 $1002.7778+2.7778+1111.1111 = 2116.6667$；就算按四舍五入的 231.7 算，也应是 $1004.89+2.89+1108.89 = 2116.67$。原文那三项与任何一个一致的均值都对不上，总计因此多了 6.0（$3372.67$ 应为 $3366.6667$）。

### 第 4 步：用这棵树预测一套 85 平方米的新房

85 ≥ 60 → 走右边 → 落在右叶，预测价格 = 右组均值 **231.6667** 千美元。

如果允许继续分裂，右组还会再被切（例如 D 与 E 之间），预测会换成更细的叶子均值。**深度 1 的树只能给两个预测值** 125.0 和 231.6667——这就是「分段常数」的样子。

### 条件检验：再加两套房，最优切点会动吗

往数据里加 F（130 平方米，290 千）和 G（150 平方米，310 千），现在 $n=7$、根均值 220.7143、根 SSE 34821.4286，候选切点变成 6 个：

| 切点 | 左组 | 右组 | 合计 SSE | $\Delta$SSE |
|---|---|---|---|---|
| 40 | A | B–G | 17820.8333 | 17000.5952 |
| 60 | A、B | C–G | 9170.0000 | 25651.4286 |
| **80** | A–C | D–G | **8568.7500** | **26252.6786** |
| 100 | A–D | E–G | 10816.6667 | 24004.7619 |
| 120 | A–E | F、G | 17220.0000 | 17601.4286 |
| 140 | A–F | G | 25520.8333 | 9300.5952 |

最优切点从 **60 移到 80**。两个细节值得记住：

1. 冠军和第二名（80 与 60）的 $\Delta$SSE 只差 $26252.6786-25651.4286 = 601.25$，占前者的 2.3%。**多了两行数据，第一刀就换了位置**——这就是为什么单棵树的「规则」很脆弱。
2. 加数据之后，60 这个切点从「最优」掉到「次优」，但它仍然是右边那一组的边界：说明**样本量一变，最优切点会跟着挪**，没有哪个切点是数据本身的固有属性。

## 五、什么情况下会失灵

### 承重假设一：贪心地切当前这一刀就够

CART 是**自顶向下、贪心**的：每个节点只看眼前的 $\Delta\text{SSE}$ 最大，不看后面几步。

撤掉它的后果：一种「必须先分一个看似没用的刀、后面才能变纯」的结构会被错过。经典形态是 XOR 型关系——单看任一变量都无信息，两个一起用才可分。表现是：树会先切一个变量、再切另一个，用两次分裂换到本来「一刀不好、两刀刚好」的效果；成本是树更深、叶子更碎，而且没有机制保证它在所有数据上都做对。

### 承重假设二：预测可以分段常数

叶子的预测是那一格里的 $y$ 均值。

撤掉它的后果：**树不能外推**。训练数据的面积在 30–110 之间，给它一套 300 平方米的房子，预测仍然是 231.6667（或者更深的叶子的均值）——树给不出「面积每多 1 平方米多多少钱」的斜率。真实关系如果是线性的，树只能在训练区间内用很多小台阶去逼近直线。

### 承重假设三：数据位置稳定

分裂靠的是「特征 ≤ 阈值」这种比较。

撤掉它的后果：**单调变换不改变树**（这是 CART 的优点：$x$ 换成 $\log x$ 之后切点位置变了、分区不变），但数据里只要有测量误差导致顺序变化，切点就可能跳到很远的另一处。第五节的算例已经展示过弱版本：加两行数据、$\Delta$SSE 只差 2.3% 的两个切点就对调了名次。

### 与其他模型的边界

| 场景 | 用谁 | 为什么 |
|---|---|---|
| 需要紧凑规则、要给业务讲 | CART（CCP 剪枝后） | 单一旋钮 $\alpha$ 控制树大小，规则可读 |
| 数量级不同的变量混在一起 | CART / 任何树 | 只比较大小关系，不需要标准化 |
| 类别变量水平很多 | 谨慎用单棵 CART | 二分规则要连续切好几刀才能分开 300 个水平 |
| 需要外推、需要斜率 | GLM / GAM | 树给分段常数，给不出区间外的趋势 |
| 需要稳定预测 | 随机森林 / GBM | 单棵 CART 对数据扰动敏感，集成压方差 |
| 缺失值很多又不想插补 | `rpart` 或支持原生缺失的实现 | surrogate 让预测保持确定性，但实现之间不一致 |

## 六、常见误解

### 误解一：「CART 和 GLM 一样需要先把变量标准化」

**错误想法**：面积是 30–110、价格是 100–265，量纲差很多，得先标准化或者取对数，否则大的变量会压住小的。

**为什么容易这么想**：线性模型里系数会被量纲放大，正则化对尺度很敏感——这个习惯从回归那边带过来很正常。

**错在哪一步**：分裂只用**大小关系**，不用距离。把面积乘 1000 或者取对数 $x_j \le t$ 的分区完全不变，$\Delta\text{SSE}$ 的数值也不变。**单调变换对 CART 没有任何影响**。真会变的是：多个变量之间的相对尺度不影响树，但会影响后续要做正则化的模型（比如拿树的叶子做特征再喂给 GLM）。

### 误解二：「Gini 和熵选出来的树总是一样的」

**错误想法**：反正两个都是凹函数，谁大谁小差不多，随便用一个。

**为什么容易这么想**：多数数据上两者选出的分裂确实一致，跑几次没看到差别，就默认等价。

**错在哪一步**：两者对**节点纯度**的惩罚形状不同。Gini 是 $2p(1-p)$（二次），熵是 $-p\log p-(1-p)\log(1-p)$，熵在 $p$ 接近 0.5 附近更陡、对不纯的节点惩罚更重。在类别分布极不平衡时，两者会给不同的分裂不同名次。而且差异会放大到第二、三层的分裂上——**第一层一样、第二层开始分岔，最后是两棵结构性不同的树**。所以「Gini 快、熵略慢」是对的，但别把它说成「结果一样」。

### 误解三：「数据里有缺失值就一定要先插补」

**错误想法**：CART 只能吃完整的数值矩阵，缺失值必须先填上均值/中位数。

**为什么容易这么想**：很多实现（包括 scikit-learn 的经典 `DecisionTreeClassifier`）确实要求你先处理缺失；而 GLM 那边除了丢掉或插补也没有别的路。

**错在哪一步**：把**某个实现的要求**当成了**算法的性质**。Breiman 的 CART 从 1984 年就带着 surrogate splits：不插补，而是找一个与主分裂划分最一致的其他特征顶班，再给每条分支一个默认方向。区别在后果上：均值插补会造出一大批「面积 = 82.4」的假样本，把这一格的不纯度算低；surrogate 不碰数据，只是换一条路走。代价是训练时多存代理分裂，树更大。

### 误解四：「预剪枝更省事，效果差不多」

**错误想法**：既然剪枝的目的是别长太大，那生长时就设个 `max_depth=4` 不是一步到位？后剪枝还要长满再砍，多花一遍时间。

**为什么容易这么想**：两个方向都在限制树的大小，而预剪枝确实快得多、参数还更好理解。

**错在哪一步**：把「限制大小」和「按收益修剪」当成了同一件事。预剪枝是**全局一刀切**：深度 4 以下的所有分支一律停，好枝坏枝一起砍，而且有视野局限（horizon effect）——看不到「先分下去、再剪回来」更好的结构。后剪枝按**每个分支自己的收益**决定去留，允许树不对称，同样节点数下通常更准。CART 选的是后者，这也是它比 C4.5 多出来的一层。

## 七、面试怎么答

### 30 秒版

> CART 三个词：二分、剪枝、支持回归。分类用 Gini，回归用 SSE，每个内部节点只问一个是非题，类别变量也要切成两堆。数值变量排序一次扫一遍就能找到最优切点，类别变量按类别 1 的概率排序后当数值用。缺失值用代理分裂，不插补。剪枝是代价复杂度：最小化 $R(T)+\alpha|T|$，weakest-link 生成一串嵌套子树，CV 选 $\alpha$，常配 1-SE 规则。

### 2 分钟版（三块）

1. **生长**：自顶向下贪心，每个节点把所有候选分裂试一遍，选不纯度下降最大的；数值属性靠排序 + 扫描做到线性，类别属性靠排序把 NP-hard 的穷举绕开（Breiman 的二分类最优性）。
2. **缺失值**：代理分裂 + 默认方向，预测确定，不造假的插补值；实现之间不一致，要按你手上的库说。
3. **剪枝与取舍**：先长满再一次剪，$\alpha$ 是每个叶子的价格，1-SE 原则倾向更小更稳的树；代价是不能外推、对数据扰动敏感、类别水平多时要切很多刀。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么 Gini 比熵常用？」 | 不用对数，快；两者都是严格凹，多数场景结论接近，但极不平衡时会给不同结果 |
| 「类别变量为什么能排序后当数值用？」 | 二分类情形下按类别 1 概率排序，前缀划分里就含有 Gini 最优解（Breiman） |
| 「代理分裂怎么选？」 | 在主分裂变量没缺失的样本上，比一致率（分到同一侧的比例），最高者入选；还要加缺失比例修正 + 默认方向 |
| 「CCP 和 Ridge/Lasso 什么关系？」 | 形式同构（拟合 + 复杂度惩罚），α 罚叶子数、λ 罚参数大小；$R_\alpha$ 不可微，只能靠 weakest-link 枚举 |
| 「SSE 和 MSE 报哪个？」 | 选切点等价，差一个 $|S|$；报数必须说清口径，混用会让两棵树的分数没法比 |
| 「树为什么不标准化？」 | 只用大小关系，单调变换不改变分区；会变的只有后续再做正则化的模型 |

## 🗣️ 英文表达 / How to Say It

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "CART is binary, pruned, and it works for regression as well as classification — that's the three-word summary. Classification splits on Gini, regression splits on variance or sum of squared errors, and every internal node asks a yes/no question, even for categorical variables."

**Mechanism**

> "For numeric features you sort once and scan, so it's linear in the number of observations at each node. For categorical features CART has to divide the levels into two groups, which is NP-hard if you brute-force it, so it orders the categories by the class-one probability and treats them as numeric. Missing values are handled with surrogate splits rather than imputation."

**If they push back**

> "A common pitfall is assuming CART needs standardised inputs. It doesn't — it only uses the ordering of values, which is why a monotone transformation leaves the tree unchanged. The part I'd make sure to mention is the second stage: grow the maximal tree, then cost-complexity prune, with alpha chosen by cross-validation, often using the one-SE rule."

## 🔤 本页术语 / Key Terms

| 中文 | English | 一句话 |
|---|---|---|
| 分类与回归树 | classification and regression tree (CART) | 二分 + 剪枝 + 支持数值目标 |
| 递归二分 | recursive binary partitioning | 每层把一个区域切成两个矩形区域 |
| 基尼不纯度 | Gini impurity | $\sum_c p_c(1-p_c)$，不用对数 |
| 误配对概率 | probability of mis-pairing | Gini 的另一种读法：随机取两个样本类别不一致的概率 |
| 平方误差和 | sum of squared errors (SSE) | $|S|\cdot\text{Var}(S)$，回归树的分裂准则 |
| 分段常数 | piecewise constant | 叶子给一个常数，所以树不能外推 |
| 贪心自顶向下 | top-down greedy | 只看当前节点的增益，不回溯 |
| 代理分裂 | surrogate split | 主分裂变量缺失时的替代分裂，按一致率选 |
| 默认方向 | default direction | 代理也缺失时样本走哪一侧 |
| 代价复杂度剪枝 | cost-complexity pruning (CCP) | 最小化 $R(T)+\alpha\lvert T\rvert$ |
| 最弱环节 | weakest link | 每步剪掉每省一个叶子误差涨得最少的那枝 |
