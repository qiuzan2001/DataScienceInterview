# 写作规范（语言政策）

> 用户要求：**「中文讲概念（母语容易理解），英文是工作语言（理解之后需要知道英文表达）」**。
> 本文是**全库唯一语言标准**。改写或新增笔记一律照此执行。

## 1. 一句话原则

> **讲解用中文，术语用英文，面试话术用英文。**

## 2. 分类规则（哪些必须中文、哪些必须英文）

| 内容类型 | 语言 | 说明 |
|---|---|---|
| 概念讲解、推理、直觉、举例、对比 | **中文** | 这是「母语容易理解」的部分 |
| 小标题、段落说明、表格表头/说明列 | **中文** | 可保留英文术语 |
| **术语首次出现** | `中文（English）` | 例：`离差（deviance）`、`标准误（standard error, SE）`、`代价复杂度剪枝（cost-complexity pruning, CCP）` |
| 术语后续出现 | 任选，保持同段一致 | 英文术语可单独使用 |
| **真题问法标题** | **英文原话，逐字不改** | `### Q: "What is a logit?"` —— 这是面试官的原话，必须保留 |
| **`🗣️ 英文表达 / How to Say It` 块** | **英文** | 这是「要背下来能说出口」的句子，**不要翻译、不要删** |
| `⚡ 先说的那一句` | 中英混合 | 中文讲思路 + 关键句给英文 |
| 公式、符号、代码 | 原样 | 代码注释可中文 |
| 人名、论文名、库名、参数名 | 英文 | 如 `Tweedie`、`PROC LOGISTIC`、`max_features` |
| 引用原文（PSL / LDA / MAGNet） | 原样保留英文 | 可在其后加中文解释 |
| 数值、阈值、单位 | 原样 | 经验值必须标注「经验值」 |

## 3. 硬性禁止

1. **不要整段英文讲解**。凡是「解释一个概念为什么这样、什么情况下用、有什么坑」的段落，一律中文。
2. **不要翻译真题原话**。`### Q: "..."` 里的英文是面试官原话，必须逐字保留。
3. **不要删减技术内容**。改语言 ≠ 缩内容 —— 改写后**信息量只能持平或增加**，公式、数字、链接、表格行一个都不能少。
4. **不要动**：frontmatter、`<!-- priority-banner -->`、`<!-- real-exam-questions -->`、`🗣️ 英文表达` 块、代码块内容。
5. **不要把英文术语硬译成中文生造词**。没有通行中文译名的直接写英文（如 `Tweedie`、`deviance` 可保留英文）。

## 4. 目标比例

| 指标 | 目标 |
|---|---|
| 中文占比（不含代码/公式/表格分隔） | **≥ 60%** |
| `🗣️ 英文表达` 块 | 保持纯英文（**不计入**上面的比例） |
| 真题问法标题 | 保持英文（**不计入**） |

> 审计脚本：`_meta/tools/lang_audit.py`

## 5. 模板（一篇笔记的骨架）

```markdown
---
（frontmatter 不动）
---

<!-- priority-banner -->（不动）
<!-- real-exam-questions -->（不动）

# <标题>

## 🎯 一句话
**中文**讲清它解决什么问题。

## 📐 公式与推导
先中文说「这个公式在表达什么」，再给公式，公式后逐符号用中文解释。

## ⚠️ 假设 / 边界
中文逐条说明「什么时候成立、什么时候失效」。

## 🛠️ 实操
代码原样；代码前后用中文说明。

## 🗣️ 英文表达 / How to Say It
（英文，不翻译 —— 这是要背的句子）

## 🔤 本页术语 / Key Terms
| 中文 | English | 一句话说明 |
```

## 6. 示例对照

**❌ 不合格（整段英文）**
> Bagging reduces variance by averaging. Each tree is grown on a bootstrap sample, and the variance of the average is ρσ² + (1−ρ)σ²/B. The 1/B term vanishes as B grows, but ρσ² is a floor.

**✅ 合格（中文讲解 + 英文术语）**
> **Bagging 靠「平均」降方差（variance）**。每棵树长在一个 bootstrap 样本上，平均后的方差是 `ρσ² + (1−ρ)σ²/B`。
> 读这个式子：`1/B` 那一项随着树数 `B` 增大而消失，但 **`ρσ²` 是地板** —— 它由树间相关性 `ρ` 决定，加再多树也压不下去。
> **这就是随机森林为什么要在每次分裂时随机抽特征**：这是唯一能压低 `ρ` 的旋钮。

### 7.1 双语对照型文件的分档达标线

对于**英文本身就是交付物**的文件（英文答案句必须保留），≥60% 是结构性达不到的。这类文件单独设档：

| 类型 | 文件 | 中文占比达标线 | 说明 |
|---|---|---|---|
| 一般笔记 | 其余全部 | **≥ 60%** | 中文讲解为主 |
| **双语对照型** | `00_SF真题/MAGNet 面试真题全解.md` | **≥ 40%** | 11,344 个英文词是「面试要说出口的话」，不可翻译；中文以 `💬 中文精讲` 形式逐题补入（57 条） |
| **英文句子库** | `06. 中英术语对照表.md` | **不适用** | 第三列本就是「面试常见说法」英文句；中文在第一列 |

> 审计脚本不做剔除，所以上面三类文件的原始读数天然偏低。**判断是否达标时请对照本表，而不是一律要求 60%。**

### 7.2 判定标准（一句话）

> 一篇笔记**达标**的充要条件是：**把一个只懂中文的读者放进去，他能读懂全部讲解** —— 术语认不认得不影响理解。英文只出现在「术语」「要背的话」「真题原话」「代码与公式」「来源引用」这五个位置。
