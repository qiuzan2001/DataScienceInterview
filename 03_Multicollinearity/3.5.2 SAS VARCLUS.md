# 变量聚类（Variable Clustering, VARCLUS）

## 速览 At a glance

**速记**

共线性的第三条补救路线：不删数据、也不造新变量，先把「谁和谁在说同一件事」找出来。VARCLUS 只拿变量的相关矩阵做**分裂式聚类**：起点是所有变量挤在一个簇里，只要某个簇的第二特征值 $\lambda_2 > 1$（说明簇里还藏着一个完整的维度），就沿第二特征向量把它劈成两半，再让每个变量搬到与簇成分 $R^2$ 最高的那一簇，如此循环。劈完每簇只留一个**原始变量**当代表，判据是本簇 $R^2$ 最大的那个 —— 变量名、方向、阈值规则都留住了。代价有两处：它只是把冗余分了组，簇内的共线性仍在；而且全程不看 $Y$，代表未必是最会预测的那个，要拿 IV / 单变量 AUC 复核。它和 PCA 的分工是：VARCLUS 是选择（保留原变量），PCA 是投影（造出新变量）。

**一句面试答法**

> "VARCLUS groups correlated variables into clusters, and then I keep one representative per cluster — usually the variable with the highest R-squared with its own cluster component, cross-checked against its univariate predictive power. It's a selection method, so the business names and the thresholds survive, unlike PCA which projects everything into new components. The stopping rule is the second eigenvalue: if a cluster's second eigenvalue is above one, it still hides another dimension and gets split."

**术语**

| 中文 | English | 一句话 |
|---|---|---|
| 变量聚类 | variable clustering (VARCLUS) | 把相关变量分成互不相交的簇，每簇留一个代表 |
| 簇成分 | cluster component | 代表一簇的潜在因子；Principal 法取簇内第一主成分 |
| 第二特征值 | second eigenvalue ($\lambda_2$) | $>1$ = 簇内还剩一个完整维度，该劈 |
| 1-$R^2$ 比值 | 1-$R^2$ ratio ($\rho_i$) | $>1$ = 这个变量放到别的簇拟合更好 |
| 分裂式聚类 | divisive clustering | 从一大簇开始不断劈分，不需要先定簇数 |
| 代表变量 | representative variable | 每簇留下的那个原始变量 |

## 一、先看一个问题

面试问 **"How do you fix it?"**（共线性怎么修），标准答案里有一条是「聚类，每簇留一个代表」。真到工位上，这一步长这样：

车险纯保费模型有 40 个候选变量。相关矩阵里有个 8 个变量互相相关（两两 $r$ 在 0.7–0.9 之间）的方块，VIF 全部超标。业务方要的是**能逐条写进费率表**的模型：`年行驶里程`、`驾龄`、`车龄` 这些名字必须留在报表上。

于是两条路都被堵住了：

- 按 VIF 顺序删变量：删掉的 `年行驶里程` 恰好是精算最想留的；剩下几个重算之后还是超标，因为坏掉的是整块结构，删一个救不了。
- 上 PCA：数学上干净，但费率表上得写「PC₁ = 0.41 × income − 0.33 × credit_score + …」—— 业务方看不懂，监管也不会接受。

你要的是第三条路：**把 8 个变量按「说同一件事」分成几组，每组自己挑一个发言人，其余的名字退到幕后。** 发言人还是原始变量，乘法因子、分箱阈值、业务解释全部照旧。

难点在于「怎么分组」和「谁当发言人」这两件事都得有可辩护的数字，不能凭感觉。VARCLUS 给的就是这套数字。

## 二、核心直觉

### 把变量当成一群发言的人

40 个变量像 40 个人在会议室里发言。有些人在说同一件事（`年行驶里程` 和 `年均通勤距离` 都在讲「开得多不多」），有些人在说别的事（`历史赔付次数` 讲风险暴露的历史）。

聚类做两件事：

1. 按发言内容分组，组内的人互相替对方说话，组间尽量各说各的；
2. 每组留一个代表去汇报，其余人退场。

**这里像什么、不像什么**：像的是「组内互相替代」这个结构 —— 代表换了，整组的结论几乎不变。**不像的是删变量**：删掉的变量是真的没了，而这里其余变量还在手里，只是没进模型；也**不像 PCA**：PCA 是把所有人的话混成一句合成语，谁说的都认不出来。

### 为什么判据是「第二特征值 > 1」

先把变量标准化：每个变量的方差都是 1。一个簇的相关矩阵做特征分解后，特征值就是各个方向上的方差，加起来正好等于变量个数。

- $\lambda_1$ 是这一簇的**公共方向**，会被簇成分（第一主成分）抓住；
- $\lambda_2$ 是**剩下的最大方向**。

如果 $\lambda_2 \le 1$，说明第二个方向上的方差还不到一个原始变量那么多 —— 再劈一次，分出来的「新维度」抵不上一个变量的分量，不值。反过来，$\lambda_2 > 1$ 意味着除了公共方向之外，剩下的方差还够撑起**另一个完整维度**，这个簇里其实住了两个因子。

一个立刻能验证的推论：**两个变量的簇永远不会被这条判据劈开**。两个标准化变量的相关矩阵特征值是 $1+r$ 和 $1-r$，只要 $r \ge 0$ 就有 $\lambda_2 = 1-r \le 1$。所以这条判据只在三个及以上变量的簇里起作用。

### 为什么要沿「第二特征向量」劈

第一特征向量是公共方向，沿它劈等于把整簇一分为二地复制；真正区分两个隐藏因子的方向藏在**第二特征向量**里。它的元素符号把变量分成两组：正号一边、负号一边。第四节的算例里，第二特征向量是 $[0.474, 0.469, 0.434, -0.339, -0.354, -0.357]$，前三个正、后三个负，一刀就把两个方块切开了。

> **一句话区分 PCA / VarClus / LDA（MAGNet 原话，务必背下来）**
>
> **PCA 是特征投影（projection）—— 创造新变量。VarClus 是特征选择（selection）—— 保留原始变量。两者都是无监督的；LDA 是有监督的投影对应物。**
>
> * **VarClus**（本节）：聚类后**保留原始变量**（每簇挑一个代表变量；也可用簇成分）⇒ 保住业务可解释的名字，报价单（rating plan）还能写。
> * **PCA**（[[3.5.4 PCA]]）：投影出**正交的新变量**，正交 ⇒ 共线性由构造消除，代价是丢名字、丢阈值规则。
> * **LDA**：有监督的投影，方向由**类间 / 类内散度之比**决定 ⇒ 目标是分类可分性，不是重建方差。
>
> 来源：MAGNet §4（"Explain PCA" 末尾 the one-line distinction）；[[MAGNet 面试真题全解]]

## 三、机制

### 3.1 定义与逐项说明

**问题（Problem）**：给定一个 $n \times p$ 的矩阵 $\mathbf{X}$（变量之间可能彼此相关），要把这 $p$ 个变量划分成 $K$ 个互不相交的簇（cluster），要求：

- 每个簇代表**一个**潜在特征（underlying trait）
- 簇与簇之间尽可能独立（independent）

原文那句关键洞察是这么说的：**关键洞察（Key Insight）**：PCA 旋转的是数据空间的坐标轴（rotate data space axes），而 VARCLUS 分组的是**轴本身**（groups the axes themselves）。

簇怎么表示，有两种口径：

| 方法（Method） | 定义（Definition） | 性质（Properties） |
| ----------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Principal**（默认） | 用相关矩阵 $\mathbf{R}_C$ 的**第一主成分**做簇成分 | • 捕获方差最大<br>• 各变量的**载荷（loadings）**大小不等 |
| **Centroid** | 简单（带符号）平均：$z_j = \frac{1}{C} \sum_{i \in C} x_i$ | • 所有变量等权<br>• 对离群值（outlier）更稳健 |

> **注意**：所有簇成分都被标准化到方差 = 1，这样诊断量之间才可比（comparable diagnostics）

Principal 口径下簇成分写成加权和：$z_C = \sum_{i \in C} w_i x_i$，其中 $\mathbf{w} = \mathbf{v}_1 / \sqrt{\lambda_1}$，$\mathbf{v}_1$ 是 $\mathbf{R}_C$ 的第一特征向量。除以 $\sqrt{\lambda_1}$ 就是为了让 $z_C$ 的方差落在 1 上。

**对每个变量 $x_i$：**

1. **本簇 $R^2$（own-cluster $R^2$）**：$R_i^2 = \operatorname{corr}^2(x_i, z_{C(i)})$ —— 该变量与**自己所属簇**成分的平方相关
2. **次优簇 $R^2$（nearest-other $R^2$）**：$R_{i,\text{next}}^2 = $ 该变量与**其他任何**簇成分的最大平方相关
3. **1-$R^2$ 比值（1-$R^2$ Ratio）**：$\rho_i = \frac{1-R_i^2}{1-R_{i,\text{next}}^2}$

逐项读：$z_{C(i)}$ 是变量 $i$ 所在簇的成分；$R_i^2$ 是「这一簇对我解释得有多好」，$R_{i,\text{next}}^2$ 是「别家最好的那一簇对我解释得有多好」。分子 $1-R_i^2$ 是留在这里的残差方差，分母 $1-R_{i,\text{next}}^2$ 是搬走之后的残差方差。

**1-$R^2$ 比值怎么读：**

- 分子 = 变量留在当前簇时的残差方差（residual variance）
- 分母 = 变量改投最优备选簇时的残差方差
- **$\rho_i > 1$** → 这个变量放到别的簇里会拟合得更好（即：放错位置了）

**对每个簇：**

- **$\lambda_2$**（相关矩阵 $\mathbf{R}_C$ 的**第二特征值**，second eigenvalue）：衡量簇内**剩余**的公共方差（leftover common variance）
- **$\lambda_2 > 1$** → 簇里还藏着**另一个完整维度** → 是「该分裂」的候选

**数学摘要（Mathematical Summary）：**

**核心目标函数（Core Objective Function）：**
$$\text{Maximize within-cluster } R^2 \text{ while minimizing between-cluster correlations}$$

**分裂判据（Splitting Criterion）：**
$$\text{Split cluster } C \text{ if } \lambda_2(\mathbf{R}_C) > 1$$

**变量重分配规则（Variable Reassignment Rule）：**
$$x_i \rightarrow C^* \text{ where } C^* = \arg\max_C R^2(x_i, z_C)$$

**收敛条件（Convergence Condition）：**
$$\forall C: \lambda_2(\mathbf{R}_C) \leq \text{MAXEIGEN}$$

**三个必须记住的统计量：**

| 统计量（Statistic） | 衡量什么（What It Measures） | 关键阈值（Key Threshold） |
|-----------|------------------|---------------|
| **成分载荷（Component Loadings）** | 变量与簇的关联强度 | 越大关联越强 |
| **第二特征值（Second Eigenvalue, $\lambda_2$）** | 簇内**剩余**维度 | $>1$ = 需要分裂 |
| **1-$R^2$ 比值（$\rho_i$）** | 变量是否被放错簇 | $>1$ = 放到别处拟合更好 |

### 3.2 它是怎么来的：从「一大簇」劈到「每个变量都在对的地方」

**第一步要解决的问题**：起手谁也不知道该分几组，所以算法从「所有变量都在一个簇」开始，用矩阵层面的 $\lambda_2$ 判断这一大簇里有没有多于一个维度。

**逐步流程（Step-by-Step Process）**

1. **初始化（Initialize）**：所有变量先塞进一个巨大的簇

2. **找出最不合群的变量（Find worst-fitting variable）**：$i^* = \arg\max_i \rho_i$

3. **检查簇的同质性（Check cluster homogeneity）**：
   - 若 $\lambda_2 \leq \text{threshold}$（默认 = 1）→ **停止**（该簇已经同质）
   - 若 $\lambda_2 > \text{threshold}$ → **分裂**该簇

4. **执行分裂（Execute split）**：
   - 找出与 $\lambda_2$ 对应的特征向量 $\mathbf{v}$（eigenvector）
   - 载荷为正 → 归入簇 A
   - 载荷为负 → 归入簇 B

5. **重新分配变量（Reassign variables）**：每个变量都搬到 $R^2$ 最高的那个簇

6. **迭代（Iterate）**：重复，直到满足停止准则（stopping criteria）

**停止准则（Stopping Rules）**

- 所有簇都满足 $\lambda_2 \leq \text{MAXEIGEN}$
- 达到簇数上限 $K_{\max}$

**为什么 split 方向要取第二特征向量，而不是别的方向**：簇成分已经吃掉了第一方向 $\lambda_1$；剩下的方差里最大的那一块就在第二方向上，把变量按第二特征向量的符号分到两边，等于把「隐藏因子之差」这个方向切开。

**为什么重分配会让 $\rho_i$ 降下来**：每个变量都搬到 $R^2$ 最高的簇，搬完这个变量在本簇的 $R^2$ 就不会低于任何别的簇 —— 这正是 $\rho_i \le 1$ 的含义。所以「分裂 → 重分配」这个循环同时把簇推向两个目标：簇内单维度（$\lambda_2 \le 1$）与簇间近似正交（簇间相关趋近 0）。

**这一步是可以算给人看的**：Principal 口径下，变量 $i$ 与簇成分的协方差是 $(\mathbf{R}_C\mathbf{v}_1)_i = \lambda_1 v_{1i}$，而 $\operatorname{Var}(z_C) = \lambda_1$、$\operatorname{Var}(x_i)=1$，于是

$$R_i^2 = \operatorname{corr}^2(x_i, z_C) = \frac{(\lambda_1 v_{1i})^2}{\lambda_1} = \lambda_1 v_{1i}^2$$

也就是**载荷的平方**（载荷 $\sqrt{\lambda_1}v_{1i}$ 的平方）。这条式子有两个直接后果：第一，挑代表变量等价于挑第一特征向量上权重最大的那个；第二，第四节的整张诊断表都能手算出来。

**原笔记给的直觉（Why It Works）：**

1. **问题识别（Problem Detection）**：低 $R^2$ 说明变量拟合得差；而最大的 $\rho_i$ 精确指出症状最明显的那个变量

2. **数学根据（Mathematical Foundation）**：
   - 簇的总方差 = $\lambda_1 + \lambda_2 + \ldots$
   - $\lambda_1$ 由簇成分捕获
   - $\lambda_2 > 1$ 意味着**至少还多存在 $\geq 1$ 个因子**（factor）

3. **最优分裂方向（Optimal Splitting）**：第二特征向量的方向能够最大程度地把隐藏因子分开

4. **贪心式改进（Greedy Improvement）**：不断重新分配变量会提高簇内 $R^2$，并压低平均 $\rho_i$

### 3.3 变形与口径

**① Principal 还是 Centroid。**

| 方面（Aspect） | Principal | Centroid |
|--------|-----------|----------|
| **加权方式（Weighting）** | 最优（最大化方差） | 等权 |
| **离群值敏感度（Outlier Sensitivity）** | 中等 | 更低 |
| **可解释性（Interpretability）** | 看变量载荷（loadings） | 每个变量影响相同 |
| **计算成本（Computational Cost）** | 特征分解（eigen-decomposition） | 简单算术平均 |

**用 Principal**：当统计效率（statistical efficiency）重要，或各变量重要性不等时
**用 Centroid**：当优先考虑稳健性和可解释性时

**② SAS 里怎么跑。** `PROC VARCLUS` 只需要变量的相关矩阵 —— `MODEL`（响应变量）那一行根本不写。

```sas
proc varclus data=mydat maxeigen=1 proportion=0.7 short summary outtree=work.tree;
  var x1-xk;      /* 只列候选变量；VARCLUS 不看 Y，是无监督的 */
run;
/* maxeigen=1：簇的第二特征值超过 1 就继续劈，想少几个簇就把它调低（如 0.5）；
   proportion=0.7 是第二条停止判据（要求每个簇解释的方差达到一定比例），
   它与 maxeigen 谁先触发谁生效；outtree= 把分裂过程输出成树，方便画谱系图看簇数变化。
   选项默认值与输出表名以 SAS 文档为准（本笔记未在 SAS 上实跑）。 */
```

**③ 输出怎么读。** 与本节有关的是四张表：

- `Cluster Summary`：每个簇的变量数、`Variation Explained`（簇成分抓住的方差 $\lambda_1$）、`Proportion Explained`（$\lambda_1$ 除以该簇变量数）、`Second Eigenvalue`（$\lambda_2$）。
- `R-squared with Own Cluster / Next Closest`：每个变量的 $R_i^2$ 与 $R_{i,\text{next}}^2$。
- `1-R**2 Ratio`：$\rho_i$，大于 1 就是「该挪窝」的变量。
- `Inter-Cluster Correlations`：簇成分两两相关，越接近 0 越好；`Standardized Scoring Coefficients` 给出簇成分的权重 $w_i$（符号可整体取反）。

**④ 三条诊断曲线（Key Diagnostic Plots）：**

1. **$\rho_i$ 的直方图（histogram）** → 一眼看出哪些变量「不合群」（misfit）
2. **各簇的 $\lambda_2$ 图** → 找出还需要继续分裂的簇
3. **簇间相关（inter-cluster correlations）** → 应该趋近于 0

**要带走的四句话：**

- 簇成分 = 潜在因子的替身（surrogate factor）
- $\lambda_2 > 1$ = 存在隐藏维度的数学红旗（red flag）
- 1-$R^2$ 比值精确定位隐藏维度从哪里泄漏出来
- 「分裂 → 重新分配」这一循环同时把簇推向：内部单维度（unidimensionality）+ 簇间正交（orthogonality）

## 四、算一遍

用一份 6 变量的相关矩阵把流程走完。设计上它有两个「主题」：$X_1,X_2,X_3$ 讲第一件事，$X_4,X_5,X_6$ 讲第二件事，两块之间只有很弱的相关。

| | $X_1$ | $X_2$ | $X_3$ | $X_4$ | $X_5$ | $X_6$ |
|---|---|---|---|---|---|---|
| $X_1$ | 1.00 | 0.80 | 0.60 | 0.20 | 0.15 | 0.10 |
| $X_2$ | 0.80 | 1.00 | 0.50 | 0.15 | 0.12 | 0.08 |
| $X_3$ | 0.60 | 0.50 | 1.00 | 0.10 | 0.08 | 0.05 |
| $X_4$ | 0.20 | 0.15 | 0.10 | 1.00 | 0.85 | 0.70 |
| $X_5$ | 0.15 | 0.12 | 0.08 | 0.85 | 1.00 | 0.65 |
| $X_6$ | 0.10 | 0.08 | 0.05 | 0.70 | 0.65 | 1.00 |

### 第 1 步：一整簇的特征值，看要不要劈

整张矩阵的特征值是 $2.740$、$2.011$、$0.535$、$0.382$、$0.190$、$0.142$（六个加起来 = 6，对上了迹）。有两个大于 1，所以 $\lambda_2 = 2.011 > 1$：这一大簇必须劈。

第二特征向量（统一取符号）是 $[0.474,\ 0.469,\ 0.434,\ -0.339,\ -0.354,\ -0.357]$ —— 前三个正号、后三个负号，一刀切出 $\{X_1,X_2,X_3\}$ 与 $\{X_4,X_5,X_6\}$。这就是「沿第二特征向量分裂」的字面意思。

### 第 2 步：劈完检查两个子簇

| 簇 | $\lambda_1$ | $\lambda_2$ | $\lambda_3$ | $\lambda_1/3$（解释比例） | 结论 |
|---|---|---|---|---|---|
| $A = \{X_1,X_2,X_3\}$ | 2.275 | 0.536 | 0.189 | 0.758 | $\lambda_2 \le 1$，停 |
| $B = \{X_4,X_5,X_6\}$ | 2.470 | 0.384 | 0.146 | 0.823 | $\lambda_2 \le 1$，停 |

两个簇都过关，算法在这里收敛到 2 个簇。总解释方差比例 $= (2.275+2.470)/6 = 0.791$。

### 第 3 步：每个变量算 own / next / $\rho$，挑代表

权重取 $\mathbf{w} = \mathbf{v}_1/\sqrt{\lambda_1}$，本簇 $R^2$ 用上一步推出来的 $R_i^2 = \lambda_1 v_{1i}^2$。

| 变量 | 所属簇 | 簇内载荷 $\sqrt{\lambda_1}v_{1i}$ | 本簇 $R_i^2$ | 次优簇 $R_{i,\text{next}}^2$ | $\rho_i$ | 簇内权重 $w_i$ |
|---|---|---|---|---|---|---|
| $X_1$ | A | 0.929 | **0.863** | 0.028 | 0.141 | 0.408 |
| $X_2$ | A | 0.891 | 0.794 | 0.017 | 0.210 | 0.392 |
| $X_3$ | A | 0.786 | 0.618 | 0.007 | 0.384 | 0.346 |
| $X_4$ | B | 0.941 | **0.886** | 0.031 | 0.118 | 0.381 |
| $X_5$ | B | 0.923 | 0.851 | 0.018 | 0.151 | 0.374 |
| $X_6$ | B | 0.856 | 0.733 | 0.008 | 0.269 | 0.347 |

**挑代表的依据就在「本簇 $R^2$」这一列**：簇 A 选 $X_1$（0.863），簇 B 选 $X_4$（0.886）。$\rho_i$ 全部小于 1，说明没有变量放错位置；簇间相关只有 0.148。

用 $X_1$ 代表簇 A 的含义可以量化：它解释了簇成分方差的 86.3%，丢掉 13.7%。这个数字就是「用代表换掉三个变量」的价格，也是面试里能拿出来的话。

### 第 4 步：和 SAS 的输出对上

把同样的数字翻译成 `PROC VARCLUS` 的列名（**下表是按同一公式手算的对应值，不是 SAS 原始日志**）：

| Cluster | Number of Variables | Variation Explained | Proportion Explained | Second Eigenvalue |
|---|---|---|---|---|
| 1 | 3 | 2.275 | 0.758 | 0.536 |
| 2 | 3 | 2.470 | 0.823 | 0.384 |

**Total variation explained by clusters = 0.791（79.1%）**

```python
import numpy as np
rows = [
    [1, .8, .6, .2, .15, .1],
    [.8, 1, .5, .15, .12, .08],
    [.6, .5, 1, .1, .08, .05],
    [.2, .15, .1, 1, .85, .7],
    [.15, .12, .08, .85, 1, .65],
    [.1, .08, .05, .7, .65, 1],
]
R = np.array(rows)
np.linalg.eigvalsh(R)[::-1]        # [2.740, 2.011, 0.535, 0.382, 0.190, 0.142]
np.linalg.eigh(R[:3, :3])[0]       # 簇 A： [0.189, 0.536, 2.275]
np.linalg.eigh(R[3:, 3:])[0]       # 簇 B： [0.146, 0.384, 2.470]
# 载荷与 own R²：lam, v = np.linalg.eigh(R[:3,:3]); lam = lam[-1]; v = v[:, -1]
# v 归一化到单位长度：np.sqrt(lam) * v  就是载荷；lam * v**2 就是 own R²
```

### 条件检验

**换一个条件一：把 $X_3$ 塞进簇 B 会怎样？** 它对本簇（A）的 $R^2$ 是 0.618，对簇 B 只有 0.0073。按定义算

$$\rho_{X_3 \in B} = \frac{1-0.0073}{1-0.618} = 2.60 > 1$$

大于 1 就意味着「放错位置了」—— 重分配这一步会把它搬回 A。$\rho_i$ 的作用正是把这种搬动写成数字，而不是靠人看名字猜。

**换一个条件二：把门槛从 `maxeigen=1` 降到 0.5。** 簇 B（$\lambda_2 = 0.384$）仍然过关，簇 A（$\lambda_2 = 0.536$）不再过关，必须再劈一刀 —— 同一个相关矩阵，簇数从 2 往上走。整张矩阵里有 3 个特征值大于 0.5（$2.740$、$2.011$、$0.535$），也提示这个门槛下至少要有 3 个簇才装得下这些方向。**门槛不是数据给的，是建模的人给的**，它直接决定最后进模型的是 2 个代表还是 3 个代表。

**换一个条件三：这 6 个变量如果全进 GLM，共线性有多严重？** 它们的 VIF 是 $3.33$、$2.79$、$1.57$、$4.27$、$3.69$、$2.01$。按上面的结论只留 $X_1$ 与 $X_4$，两者的相关是 0.20，VIF 掉到 $1/(1-0.2^2) = 1.042$。**这就是「聚类取代表」在 VIF 上的效果：从 2–4 的水平换到接近 1。**

## 五、什么情况下会失灵

### 承重假设一：相关矩阵是对「冗余」的正确刻画

VARCLUS 从头到尾只用一个矩阵，所以它的结论完全继承这个矩阵的毛病：

- **只认线性**。两个变量 $U$ 形相关（$r \approx 0$）时，它们在相关矩阵里看起来毫不相干，会被分到两个簇里，而业务上它们可能在讲同一件事。非单调关系会完整溜过去，补救是先做变换（分箱、WOE）再聚类。
- **对离群值敏感**。少数极端点可以把一对变量的 $r$ 从 0.2 抬到 0.6，分组随之改变；Centroid 口径比 Principal 稳健一些，但矩阵本身还是那个矩阵。
- **变量多、样本少时噪声撑起假分组**。相关矩阵有 $p(p-1)/2$ 个元素要靠 $n$ 行数据估出来：$p = 40$ 时是 780 个相关系数，$n$ 只有几千时每个都不太准。**在噪声矩阵上聚类，簇是随机的**。

### 承重假设二：不加 $Y$ 也能找对结构

它和 PCA 一样是**无监督**的。挑出来的代表是「这一簇的中心」的意思，不是「最能预测 $Y$」的意思。具体后果：某个簇里 IV 最高的变量可能就是代表（好），但完全可能不是 —— 代表与簇内其他变量的 $R^2$ 高，只说明它像这一簇，不说明它和 $Y$ 有关。**做完 VARCLUS 必须补一步有监督复核**：把代表变量按 IV / 单变量 AUC / 业务可得性过一遍，必要时从同一簇里换一个。

### 承重假设三：簇是数据的固有属性

簇是**相关矩阵 + 变量集合 + 门槛**三者的函数，换任何一个都可能重排：

- 从候选列表里加一个或删一个变量，$\lambda_2$ 会变，分裂点会变；
- `maxeigen` 从 1 降到 0.5，第四节的例子里簇 A 就要再劈一刀（2 个代表变 3 个）；
- 换一批样本重估相关矩阵，边界上的变量（$\rho_i$ 接近 1 的那种）可能在两簇之间来回跳。

工程上的后果：**簇的编号和名字不能当作稳定资产**。今天叫「驾驶暴露」的簇，下个月加了两个变量后可能多出一个新簇，用它做的费率表要重新审。

### 承重假设四：簇内共线性会自己消失

不会。VARCLUS 只是**把共线变量装进同一个箱子**，箱子内部它们还是高度相关。第四节里簇 A 的 $\lambda_1 = 2.275$（三个标准化变量的总方差才 3），说明簇内公共方向仍然吃掉大头。真正让模型摆脱共线的是「每簇只留一个代表」这一步；如果选择用簇成分代替整簇，那又回到了 PCA 的投影形态，语义也就跟着丢掉。

### 什么时候用聚类、什么时候用 PCA

两种方法都无监督，都在处理「变量挤在一起」这件事，但输出的东西完全不同。按四个维度对齐：

| 维度 | 变量聚类（VARCLUS） | 主成分分析（PCA） |
|---|---|---|
| **目标** | 找出「谁和谁在说同一件事」：把 $p$ 个变量分成 $K$ 组 | 找出方差最大的少数几个正交方向：用 $k$ 个成分替代 $p$ 个变量 |
| **输出** | 互不相交的簇 + 每簇一个**原始变量**代表（也可用簇成分） | $k$ 个**新变量** = 全部原始变量的线性组合 |
| **可解释性** | 代表还是原始变量：名字、方向、分箱阈值都在，费率表能写 | 成分是混合物，丢名字、丢阈值；只能退而看载荷与符号 |
| **业务适用性** | 要出费率表 / 评分卡、要逐条向业务和监管解释 → 选它 | 只做预测或预处理、单个变量不必解释 → 选它（要正交输入时它也是唯一选择） |

再补三条边界：

1. **要「VIF 恒为 1」的干净输入** → PCA，簇间相关只是「趋近 0」，不是 0。
2. **树模型 / GBM**：两者都不必做，它们对共线性不敏感（代价是特征重要性排名不稳，见 [[3. Multicollinearity]]）。
3. **稀疏特征或 one-hot**：两者都要小心 —— PCA 会把 $0/1$ 的离散信号抹平成一个连续轴；VARCLUS 的相关矩阵在低频类别上估计噪声很大。

## 六、常见误解

### 误解一：「VARCLUS 和 PCA 可以互相替代」

**错误想法**：都是降维、都为了共线性，用哪个看心情。

**为什么容易这么想**：两者都无监督、都从相关矩阵出发、都能把 $p$ 个变量压成几个东西，连 MAGNet 都要专门用一句话把它们分开，说明确实容易混。

**错在哪一步**：输错的不是「降维效果」，是**交给下游的东西**。VARCLUS 交出去的是原始变量（选择），PCA 交出去的是线性组合（投影）。下游要写费率表、要按 60 岁切分客群，PCA 的成分做不了这件事；下游要严格正交的输入矩阵，VARCLUS 也保证不了。判断顺序是：先说下游需要「名字」还是「正交」，再选方法。

### 误解二：「$\lambda_2 \le 1$ 说明簇里的变量互不相关了」

**错误想法**：停止准则满足了，这一簇就是独立变量了。

**为什么容易这么想**：判据的名字叫「第二特征值」，听起来像在检验独立性；而且停下来的簇确实「看起来干净」。

**错在哪一步**：把「只剩一个维度」读成了「没有相关」。第四节簇 A 的 $\lambda_1 = 2.275$，簇内三个变量相关 0.5–0.8，一点也不独立；$\lambda_2 \le 1$ 只说明第二个维度不值一个变量。想消掉簇内共线，还得靠「只留一个代表」或「用簇成分替换」。

### 误解三：「聚出来的簇就是数据的真实分组」

**错误想法**：跑完 `PROC VARCLUS`，$K$ 个簇就是 $K$ 个业务概念，簇名可以直接写进文档。

**为什么容易这么想**：多数时候簇真的有业务味道（驾驶暴露、赔付历史、车辆价值），一看就信了。

**错在哪一步**：簇是**相关矩阵的函数**，不是数据的固有标签。加一个变量、换一批样本、把 `maxeigen` 从 1 调到 0.5，分组都可能变（第四节的簇 A 就是那种边界情况：$\lambda_2 = 0.536$，门槛一松就散）。务实的做法是给簇命名，但同时记录「用哪些变量、什么门槛、哪一批数据」跑出来的，下次重跑要复核。

### 误解四：「代表变量挑 $R^2$ 最大的就行」

**错误想法**：`R-squared with Own Cluster` 排序取第一，收工。

**为什么容易这么想**：这个数字是 SAS 直接给的，规则清楚，$R^2$ 越大越像这一簇，逻辑顺。

**错在哪一步**：$R^2$ 最大只回答「谁最能代表这一簇」，不回答「谁最能预测 $Y$」。这一簇如果整体与 $Y$ 关系很弱，再高的 $R^2$ 也救不了；反过来，簇里 IV 最高的变量可能 $R^2$ 排第二。所以代表的最终选择是两步：**先按 $R^2$ 排序，再用 IV / 单变量 AUC / 业务可得性定夺**；如果两者冲突太大，说明这一簇的「主题」和预测目标本来就对不上，要回头检查变量设计。

## 七、面试怎么答

### 30 秒版

> 变量聚类是把相关变量分组、每组留一个代表，用来替代「一个一个删变量」。判据有三种数字：本簇 $R^2$ 看变量和自己的簇有多贴近，1-$R^2$ 比值大于 1 说明它放错了簇，第二特征值大于 1 说明这个簇还得继续劈。代表通常取本簇 $R^2$ 最大的那个，但还要用 IV 或单变量 AUC 复核，因为聚类是无监督的。它的价值在于代表还是原始变量，费率表上的名字和阈值都保得住。

### 2 分钟版

1. **它解决什么**：共线性补救里，删变量丢信息、PCA 丢名字，VARCLUS 两者都不丢 —— 把变量按共享方差分组，每组留一个原始变量当代表（[[3. Multicollinearity]] 的 Method 2）。
2. **怎么跑**：从所有变量一大簇开始；矩阵层面 $\lambda_2 > 1$ 就沿第二特征向量劈；劈完每个变量搬到 $R^2$ 最高的簇；重复到每个簇的 $\lambda_2 \le \text{MAXEIGEN}$。整条链只用到相关矩阵，没有 $Y$。
3. **怎么读输出**：`Cluster Summary` 看每个簇的 `Variation Explained`、`Proportion Explained`、`Second Eigenvalue`；变量表看 own / next $R^2$ 与 `1-R**2 Ratio`；最后挑代表。
4. **收尾**：把簇成分、$\lambda_2$、$\rho_i$ 这三个概念吃透，VARCLUS 就懂了，剩下的全是实现细节。

### 会被追问到哪

| 追问 | 答法要点 |
|---|---|
| 「为什么门槛是 $\lambda_2 > 1$？」 | 变量标准化后方差为 1，第二方向上的方差超过 1 才算一个完整维度；两变量簇恒有 $\lambda_2 = 1-r \le 1$，所以这条判据只在三个以上变量的簇里起作用 |
| 「$\rho_i$ 大于 1 代表什么？」 | 变量搬到别的簇后残差更小，也就是放错位置；第四节把 $X_3$ 硬塞进簇 B，$\rho$ 立刻变成 2.60 |
| 「代表变量怎么挑？」 | 先按本簇 $R^2$ 排序（第四节是 $X_1$、$X_4$），再用 IV / 单变量 AUC / 业务可得性复核；无监督的 $R^2$ 只保证「像这一簇」 |
| 「和 PCA 差在哪？」 | 选择 vs 投影：VARCLUS 保留原始变量与业务语义，PCA 造正交新变量、VIF 恒为 1；两者都无监督，LDA 才是有监督的投影 |
| 「簇数谁定？」 | `maxeigen`（和 `proportion`）是旋钮，不是数据给的答案：第四节门槛从 1 降到 0.5，簇 A 就得再劈一刀 |
| 「共线性消掉了吗？」 | 只消掉了簇间的；簇内还是相关（簇 A 的 $\lambda_1 = 2.275$）。真正去掉共线的是「每簇只留一个代表」这一步 |
| 「无监督有什么风险？」 | 代表不一定最有预测力；还要小心相关矩阵只抓线性、对离群值与 $p/n$ 敏感 |
| 「SAS 里怎么落地？」 | `proc varclus data=... maxeigen=1 short summary outtree=...; var x1-xk; run;` 读 `Cluster Summary` 与 `R-squared with Own Cluster / Next Closest`，细节见 [[10.7 SAS 实操速查]] |

## 🗣️ 英文表达 / How to Say It

**30-second version**

> "Variable clustering groups correlated variables and keeps one representative per cluster. Three numbers drive it: the R-squared with its own cluster shows how well a variable fits, the one-minus-R-squared ratio above one means it belongs somewhere else, and a second eigenvalue above one means the cluster still hides another dimension and should be split."

**How I pick the representative**

> "I take the variable with the highest R-squared with its own cluster component — in the example I worked through, that's the one with a loading of about point nine three. But clustering is unsupervised, so I cross-check the representative against its own IV or univariate AUC before it goes into the model."

**If they push back**

> "The trade-off versus PCA is selection versus projection: here I keep the original variables, so the rating factors still have business names and I can put a number on what I gave up — the representative explains about eighty-six percent of its cluster component. What I would flag is that clusters are a function of the correlation matrix, the variable list and the threshold, so they are not stable assets; and a second eigenvalue below one only means the cluster is unidimensional, not that the variables inside it are independent."
