**问题（Problem）**：给定一个 $n \times p$ 的矩阵 $\mathbf{X}$（变量之间可能彼此相关），要把这 $p$ 个变量划分成 $K$ 个互不相交的簇（cluster），要求：

- 每个簇代表**一个**潜在特征（underlying trait）
- 簇与簇之间尽可能独立（independent）

**关键洞察（Key Insight）**：PCL 旋转的是数据空间的坐标轴（rotate data space axes），而 VARCLUS 分组的是**轴本身**（groups the axes themselves）。

> **一句话区分 PCA / VarClus / LDA（MAGNet 原话，务必背下来）**
**关键洞察（Key Insight）**：PCA 旋转的是数据空间的坐标轴（rotate data space axes），而 VARCLUS 分组的是**轴本身**（groups the axes themselves）。
> **PCA 是特征投影（projection）—— 创造新变量。VarClus 是特征选择（selection）—— 保留原始变量。两者都是无监督的；LDA 是有监督的投影对应物。**
>
> * **VarClus**（本节）：聚类后**保留原始变量**（每簇挑一个代表变量；也可用簇成分）⇒ 保住业务可解释的名字，报价单（rating plan）还能写。
> * **PCA**（[[3.5.4 PCA]]）：投影出**正交的新变量**，正交 ⇒ 共线性由构造消除，代价是丢名字、丢阈值规则。
> * **LDA**：有监督的投影，方向由**类间 / 类内散度之比**决定 ⇒ 目标是分类可分性，不是重建方差。
>
> 来源：MAGNet §4（"Explain PCA" 末尾 the one-line distinction）；[[MAGNet 面试真题全解]]

## 🔧 **Core Mechanics**

### **簇的表示方法（Cluster Representation Methods）**

| 方法（Method） | 定义（Definition） | 性质（Properties） |
| ----------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Principal**（默认） | 用相关矩阵 $\mathbf{R}_C$ 的**第一主成分**做簇成分 | • 捕获方差最大<br>• 各变量的**载荷（loadings）**大小不等 |
| **Centroid** | 简单（带符号）平均：$z_j = \frac{1}{C} \sum_{i \in C} x_i$ | • 所有变量等权<br>• 对离群值（outlier）更稳健 |

> **注意**：所有簇成分都被标准化到方差 = 1，这样诊断量之间才可比（comparable diagnostics）

### **关键诊断量（Critical Diagnostics）**

**对每个变量 $x_i$：**

1. **本簇 $R^2$（own-cluster $R^2$）**：$R_i^2 = \operatorname{corr}^2(x_i, z_{C(i)})$ —— 该变量与**自己所属簇**成分的平方相关
2. **次优簇 $R^2$（nearest-other $R^2$）**：$R_{i,\text{next}}^2 = $ 该变量与**其他任何**簇成分的最大平方相关
3. **1-$R^2$ 比值（1-$R^2$ Ratio）**：$\rho_i = \frac{1-R_i^2}{1-R_{i,\text{next}}^2}$

**1-$R^2$ 比值怎么读：**

- 分子 = 变量留在当前簇时的残差方差（residual variance）
- 分母 = 变量改投最优备选簇时的残差方差
- **$\rho_i > 1$** → 这个变量放到别的簇里会拟合得更好（即：放错位置了）

**对每个簇：**

- **$\lambda_2$**（相关矩阵 $\mathbf{R}_C$ 的**第二特征值**，second eigenvalue）：衡量簇内**剩余**的公共方差（leftover common variance）
- **$\lambda_2 > 1$** → 簇里还藏着**另一个完整维度** → 是「该分裂」的候选

## 🔄 **The Divisive Algorithm**

### **逐步流程（Step-by-Step Process）**

1. **初始化（Initialize）**：所有变量先塞进一个巨大的簇

2. **找出最不合群的变量（Find worst-fitting variable）**：$i^* = \arg\max_i \rho_i$

3. **检查簇的同质性（Check cluster homogeneity）**：
   - 若 $\lambda_2 \leq \text{threshold}$（默认 = 1）→ **停止**（该簇已经同质）
   - 若 $\lambda_2 > \text{threshold}$ → **分裂**该簇

4. **执行分裂（Execute split）**：
   - 找出与 $\lambda_2$ 对应的特征向量 $\mathbf{v}$（eigenvector）
   - 载荷为正 → 归入簇 A
   - 载荷为负 → 归入簇 B

5. **重新分配变量（Reassign variables）**：每个变量都搬到 $R^2$ 最高的那个簇

6. **迭代（Iterate）**：重复，直到满足停止准则（stopping criteria）

### **停止准则（Stopping Rules）**

- 所有簇都满足 $\lambda_2 \leq \text{MAXEIGEN}$
- 达到簇数上限 $K_{\max}$

---

## 💡 **Why It Works: Intuitive Proof**

1. **问题识别（Problem Detection）**：低 $R^2$ 说明变量拟合得差；而最大的 $\rho_i$ 精确指出症状最明显的那个变量

2. **数学根据（Mathematical Foundation）**：
   - 簇的总方差 = $\lambda_1 + \lambda_2 + \ldots$
   - $\lambda_1$ 由簇成分捕获
   - $\lambda_2 > 1$ 意味着**至少还多存在 $\geq 1$ 个因子**（factor）

3. **最优分裂方向（Optimal Splitting）**：第二特征向量的方向能够最大程度地把隐藏因子分开

4. **贪心式改进（Greedy Improvement）**：不断重新分配变量会提高簇内 $R^2$，并压低平均 $\rho_i$

## ⚖️ **Principal vs. Centroid Comparison**

| 方面（Aspect） | Principal | Centroid |
|--------|-----------|----------|
| **加权方式（Weighting）** | 最优（最大化方差） | 等权 |
| **离群值敏感度（Outlier Sensitivity）** | 中等 | 更低 |
| **可解释性（Interpretability）** | 看变量载荷（loadings） | 每个变量影响相同 |
| **计算成本（Computational Cost）** | 特征分解（eigen-decomposition） | 简单算术平均 |

**用 Principal**：当统计效率（statistical efficiency）重要，或各变量重要性不等时
**用 Centroid**：当优先考虑稳健性和可解释性时

## 🎯 **Master These Three Statistics**

| 统计量（Statistic） | 衡量什么（What It Measures） | 关键阈值（Key Threshold） |
|-----------|------------------|---------------|
| **成分载荷（Component Loadings）** | 变量与簇的关联强度 | 越大关联越强 |
| **第二特征值（Second Eigenvalue, $\lambda_2$）** | 簇内**剩余**维度 | $>1$ = 需要分裂 |
| **1-$R^2$ 比值（$\rho_i$）** | 变量是否被放错簇 | $>1$ = 放到别处拟合更好 |

## 🔑 **Key Takeaways**

✅ **簇成分 = 潜在因子的替身（surrogate factor）**
✅ **$\lambda_2 > 1$ = 存在隐藏维度的数学红旗（red flag）**
✅ **1-$R^2$ 比值精确定位隐藏维度从哪里泄漏出来**
✅ **「分裂 → 重新分配」这一循环同时把簇推向：内部单维度（unidimensionality）+ 簇间正交（orthogonality）**

## 🧮 **Mathematical Summary**

**核心目标函数（Core Objective Function）：**
$$\text{Maximize within-cluster } R^2 \text{ while minimizing between-cluster correlations}$$

**分裂判据（Splitting Criterion）：**
$$\text{Split cluster } C \text{ if } \lambda_2(\mathbf{R}_C) > 1$$

**变量重分配规则（Variable Reassignment Rule）：**
$$x_i \rightarrow C^* \text{ where } C^* = \arg\max_C R^2(x_i, z_C)$$

**收敛条件（Convergence Condition）：**
$$\forall C: \lambda_2(\mathbf{R}_C) \leq \text{MAXEIGEN}$$
